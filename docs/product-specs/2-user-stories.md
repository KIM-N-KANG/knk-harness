# 2-USER-STORIES

이 문서는 **마냑 서비스 사용자가 각 화면에서 무엇을, 왜 하고 싶어 하는지**를 유저 스토리로 정리합니다. [`1-background.md`](./1-background.md)가 정의한 주요 기능과 사용자 흐름을 화면 단위의 사용자 요구로 풀어 쓰며, 기능 스펙과 분석 스펙을 작성할 때 "한 화면에서 사용자가 기대하는 행동"의 기준으로 사용합니다.

## 2-1 사용자 정의

마냑 MVP(Phase 0)는 로그인 없이 익명 사용자 기준으로 동작하며, Phase 1부터 Google 로그인과 회원 계정을 도입합니다([`roadmap.md §R-3`](../planning/roadmap.md)). 익명 식별자 정책은 [`6-analytics.md §6-2`](./6-analytics.md)를 따릅니다.

Phase 1 범위의 유저 스토리는 ID 옆에 `Phase 1` 라벨을 붙입니다. 라벨이 없는 스토리는 모두 MVP 범위입니다.

유저 스토리에 등장하는 사용자는 다음과 같이 나뉩니다.

| 사용자 구분 | 설명 |
| --- | --- |
| 사용자 | 마냑을 사용하는 사람. MVP에서는 전원 게스트(익명)이고, Phase 1부터 게스트와 회원이 공존한다. |
| 게스트 | 로그인 없이 마냑을 사용하는 익명 사용자. 데이터는 기기 단위로 기억된다. |
| 회원 | `Phase 1` Google 로그인으로 가입한 사용자. 닉네임·프로필 이미지를 갖고 크레딧을 적립·소모한다. |
| 처음 온 사용자 | 마냑에 처음 진입한 사용자. 시작 방법을 안내받아야 한다. |
| 처음 만드는 사용자 | 스토리 생성 흐름을 처음 사용하는 사용자. 단계별 가이드가 필요하다. |
| 처음 플레이하는 사용자 | 채팅을 처음 사용하는 사용자. 채팅 사용법 안내가 필요하다. |

> 온보딩 안내가 필요한 사용자(처음 온 · 처음 만드는 · 처음 플레이하는)는 동일한 익명 사용자가 각 화면을 처음 사용하는 상태를 가리킵니다. 온보딩은 한 번만 노출합니다([US-8-3](#2-8-공통--네비게이션)).

## 2-3 스토리 생성

| US-9-4 `Phase 1` | 회원 | 다른 기기에서 로그인해도 내 스토리·채팅을 이어서 쓰고 싶다 | 기기를 바꿔도 같은 경험을 유지하고 싶다 |
| US-9-5 `Phase 1` | 회원 | 로그아웃하고 싶다 | 공용 기기에서 내 계정을 보호하고 싶다 |

## 2-10 크레딧 — `Phase 1`

크레딧을 보상으로 모으고, 스토리 제작·채팅에 소모하는 흐름입니다. 크레딧은 회원 전용이며, 게스트는 제한된 체험 후 로그인으로 유도합니다(체험 한도는 크레딧 스펙 반영에서 확정). 용어는 [`0-glossary.md §0-3-5`](./0-glossary.md)를 따릅니다.

| ID | 사용자 | 원하는 것 | 이유 |
| --- | --- | --- | --- |
| US-10-1 `Phase 1` | 회원 | 내 크레딧 잔액을 확인하고 싶다 | 얼마나 더 만들고 채팅할 수 있는지 알고 싶다 |
| US-10-2 `Phase 1` | 회원 | 회원가입·친구 초대·출석체크로 크레딧을 받고 싶다 | 결제 없이 서비스를 계속 쓰고 싶다 |
| US-10-3 `Phase 1` | 회원 | 스토리 제작·채팅에 크레딧이 얼마나 드는지 미리 알고 싶다 | 예상치 못한 소모 없이 계획적으로 쓰고 싶다 |
| US-10-4 `Phase 1` | 회원 | 크레딧이 부족하면 안내받고 받을 방법을 알고 싶다 | 막힌 지점에서 바로 해결하고 싶다 |
| US-10-5 `Phase 1` | 게스트 | 로그인 없이 제한된 체험을 해보고, 한도가 끝나면 로그인 안내를 받고 싶다 | 가입 전에 서비스의 가치를 확인하고 싶다 |
