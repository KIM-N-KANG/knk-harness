# 2-USER-STORIES

이 문서는 **마냑 서비스 사용자가 각 화면에서 무엇을, 왜 하고 싶어 하는지**를 유저 스토리로 정리합니다. [`1-background.md`](./1-background.md)가 정의한 주요 기능과 사용자 흐름을 화면 단위의 사용자 요구로 풀어 쓰며, 기능 스펙과 분석 스펙을 작성할 때 "한 화면에서 사용자가 기대하는 행동"의 기준으로 사용합니다.

```text
§2-1   사용자 정의        누가 쓰는가 (익명 사용자 · 처음 온 사용자)
§2-2   스토리 목록        내 스토리 조회 · 진입 · 생성 · 삭제 · 온보딩
§2-3   스토리 생성        키워드 선택 → 스토리라인 선택 → 추가 정보 → 완료
§2-4   스토리 상세        설정 확인 · 채팅 시작 · 삭제
§2-5   채팅 목록          진행 중 채팅 조회 · 재개 · 삭제
§2-6   채팅               대화 진행 · 스트리밍 · 선택지 · 강조 · 온보딩
§2-7   피드백             의견 작성 · 회신 메일 · 제출 확인
§2-8   공통 · 네비게이션  하단 탭 · 비로그인 기억 · 온보딩 1회 노출
```

## 2-1 사용자 정의

마냑 MVP는 로그인 없이 익명 사용자 기준으로 동작합니다. 사용자 한 명이 스토리를 만들고 채팅으로 이야기를 이어가며, 익명 식별자 정책은 [`6-analytics.md §6-2`](./6-analytics.md)를 따릅니다.

유저 스토리에 등장하는 사용자는 다음과 같이 나뉩니다.

| 사용자 구분 | 설명 |
| --- | --- |
| 사용자 | 로그인 없이 마냑을 사용하는 익명 사용자. 스토리를 만들고 채팅으로 이야기를 이어간다. |
| 처음 온 사용자 | 마냑에 처음 진입한 사용자. 시작 방법을 안내받아야 한다. |
| 처음 만드는 사용자 | 스토리 생성 흐름을 처음 사용하는 사용자. 단계별 가이드가 필요하다. |
| 처음 플레이하는 사용자 | 채팅을 처음 사용하는 사용자. 채팅 사용법 안내가 필요하다. |

> 온보딩 안내가 필요한 사용자(처음 온 · 처음 만드는 · 처음 플레이하는)는 동일한 익명 사용자가 각 화면을 처음 사용하는 상태를 가리킵니다. 온보딩은 한 번만 노출합니다([US-8-3](#2-8-공통--네비게이션)).

## 2-2 스토리 목록

사용자가 자신이 만든 스토리를 한눈에 보고, 다시 들어가거나 새로 만들고 정리하는 화면입니다.

| ID | 사용자 | 원하는 것 | 이유 |
| --- | --- | --- | --- |
| US-2-1 | 사용자 | 내가 만든 스토리들을 카드 목록으로 보고 싶다 | 어떤 이야기들을 만들었는지 한눈에 파악하고 다시 들어가고 싶다 |
| US-2-2 | 사용자 | 스토리 카드를 눌러 상세 페이지로 이동하고 싶다 | 이야기 설정을 다시 확인하거나 채팅을 시작하고 싶다 |
| US-2-3 | 사용자 | 새 스토리를 만들고 싶다 | 새로운 이야기를 시작하고 싶다 |
| US-2-4 | 사용자 | 더 이상 필요 없는 스토리를 삭제하고 싶다 | 목록을 깔끔하게 관리하고 싶다 |
| US-2-5 | 처음 온 사용자 | 환영 온보딩 투어로 시작 방법을 안내받고 싶다 | 무엇부터 해야 할지 알고 싶다 |
| US-2-6 | 사용자 | 목록 로딩이 실패하면 다시 시도하고 싶다 | 일시적 오류로 막히고 싶지 않다 |

## 2-3 스토리 생성

키워드 선택, 스토리라인 선택, 추가 정보 입력, 완료의 4단계로 스토리를 만드는 흐름입니다. 단계별 제작 흐름은 [`1-background.md §1-5-4`](./1-background.md)를 따릅니다.

### 2-3-1 Step 1 — 키워드 선택

| ID | 사용자 | 원하는 것 | 이유 |
| --- | --- | --- | --- |
| US-3-1 | 사용자 | 장르·주인공 특징·주변 인물 특징을 단계별로 골라 이야기의 뼈대를 정하고 싶다 | 단계별로 원하는 설정을 쌓아가고 싶다 |
| US-3-2 | 사용자 | 각 카테고리에서 원하는 태그를 선택하거나 해제하고 싶다 | 내가 원하는 분위기를 조합하고 싶다 |
| US-3-3 | 사용자 | 원하는 태그가 없으면 직접 키워드를 입력해 추가하고 싶다 | 정해진 보기로는 표현이 부족하다 |
| US-3-4 | 사용자 | 선택을 마치고 AI 스토리라인 생성을 요청하고 싶다 | 내 키워드 기반의 이야기 후보를 보고 싶다 |

| US-3-6 | 사용자 | 각 스토리라인에 좋아요·별로예요로 평가하고 싶다 | AI 추천 품질에 피드백을 주고 싶다 |
