## 1-1 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 마냑: 내가 쓰고 AI가 이어가는 나만의 이야기 |
| 한 줄 소개 | 마냑은 사용자가 스토리와 세계관을 3단계로 간단하게 만들고, 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스입니다. |

## 1-2 문제와 기회

### 1-2-1 해결하려는 문제

기존 웹툰과 웹소설은 완성된 콘텐츠를 읽는 수동적 소비 경험이 중심입니다. 사용자가 직접 이야기를 만들고 전개에 참여하려면 스토리 설계, 세계관 구성, 캐릭터 설정 같은 높은 진입 장벽을 넘어야 합니다.

### 1-2-2 시장 기회

AI 캐릭터 대화와 인터랙티브 콘텐츠에 대한 관심이 커지고 있습니다. 사용자가 단순히 콘텐츠를 소비하는 것을 넘어, 직접 이야기를 만들고 AI와 상호작용하는 경험을 원하는 만큼 쉬운 제작 도구와 몰입형 채팅 경험을 결합한 서비스 기회가 있습니다.

## 1-5 주요 사용자 흐름

### 1-5-1 스토리 탐색 흐름

```text
홈 화면 진입
↓
추천 / 인기 / 신작 / 장르별 스토리 확인
↓
관심 있는 스토리 선택
↓
스토리 상세 정보 / 좋아요 수 / 공유 / 댓글 확인
```

### 1-5-2 스토리 플레이 흐름

> 로그인은 MVP 이후에 도입하는 단계입니다. MVP에서는 로그인 없이 익명 사용자 기준으로 진행합니다.

```text
로그인
↓
홈 화면 진입
↓
스토리 탐색
↓
스토리 상세 정보 확인
↓
플레이 시작
↓
사용자 입력 또는 AI 추천 선택지 선택
↓
AI 응답 생성
↓
채팅 저장 또는 이어가기
```

### 1-5-3 채팅 이어가기 흐름

> 로그인은 MVP 이후에 도입하는 단계입니다. MVP에서는 로그인 없이 익명 사용자 기준으로 진행합니다.


## 1-6 MVP 개발 기능

### 1-6-1 간편 모드 스토리 제작

- 장르, 주인공 특징, 주변 인물 특징 키워드 선택
- 선택한 키워드를 바탕으로 AI 스토리라인 생성
- 생성된 스토리라인 중 원하는 스토리라인 선택
- 스토리라인 완성에 필요한 추가 정보 입력
- AI가 스토리 등록 필수 항목 생성
- 스토리 생성 후, 바로 시작

### 1-6-2 내 스토리 목록

- 내가 제작한 스토리 목록 조회
- 스토리 목록 중 하나를 선택해서 채팅 시작

### 1-6-3 스토리 플레이

- 텍스트 직접 입력
    - 상황 묘사
    - 캐릭터 대사
    - 일반 내용
- AI 추천 선택지 선택
- 상황 묘사 출력
- 캐릭터 대사 출력
- 다음 행동 선택지 출력

### 1-6-4 내 채팅 목록

- 진행 중인 채팅 목록 조회
- 채팅 삭제
- 과거 채팅 이어가기

### 1-6-5 고객 지원

- 피드백 내용 작성
- 피드백 응답 메일 선택적 작성
