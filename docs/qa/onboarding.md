## ONBD-GUEST — 게스트 환영 온보딩 페이지

처음 온 게스트에게 시작 방법을 안내하는 전용 페이지(`/onboarding`)입니다. `(main)` 레이아웃(`/`, `/chats`, `/more`)에 마운트된 게이트가 게스트(비로그인) 세션 + 로컬 스토리·채팅 ID 모두 0개 + `manyak:onboarding-seen` 미설정을 확인하면 하이드레이션 완료 직후 `/onboarding`으로 주소를 교체해 이동시킵니다. 조건을 만족하지 않는 상태로 `/onboarding`에 직접 접근하면 홈으로 되돌립니다. 화면은 두 줄 제목 + 설명 + 미리보기 콘텐츠 + 하단 버튼 두 개로 구성되며, 두 버튼 모두 열람 처리(`manyak:onboarding-seen = '1'`)를 저장하고 주소를 교체해 이동하므로 뒤로가기로 온보딩에 돌아올 수 없습니다.

## ONBD-INVITE — 신규 가입(회원) 초대 코드 온보딩

## ⚠️ 확인 필요

작성 중 스펙과 구현이 어긋나거나 판단이 필요한 항목입니다. 팀 확인 후 스펙 갱신 또는 수정 이슈로 전환합니다.

1. **게스트 환영 다이얼로그 문구 개편 미배포.** dev HEAD는 온보딩을 페이지로 옮기며 제목을 "눈을 떠보니 / 스토리 속 주인공이 되었다"로 바꾸고 게스트 한도·로그인 혜택 안내 카드 2개를 제거했습니다. 배포된 v0.2.2는 여전히 옛 제목("나만의 스토리, 바로 만들어볼까요?") + 2카드 구성이며, 그 카드의 스토리라인 한도도 백엔드 정책(5회)과 다른 "10회"로 표기합니다(#72 KNK-599에서 5회로 수정했으나 함께 미배포). v0.2.2 릴리스 QA에서는 배포본이 ONBD-GUEST-01·02 기대 결과와 다른 알려진 상태입니다.
2. **단계별·채팅 온보딩 미구현.** 스토리 생성 단계별 가이드(US-3-14)와 채팅 사용법 온보딩(US-6-9)은 코드에 구현 흔적이 없으며, 스펙도 §3-13 G4로 "미구현 — 필요성 재확인 후 검토"를 기록하고 있어 이 문서의 QA 범위에서 제외했습니다.
3. **localStorage 차단 환경의 반복 노출.** 프라이빗 모드 등에서 열람 저장이 실패하면 매 진입마다 온보딩이 다시 뜹니다(ONBD-GUEST-10). 코드 주석상 의도된 무시(저장 건너뜀)이지만 반복 노출 UX가 허용 범위인지 확인이 필요합니다.
