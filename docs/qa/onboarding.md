## ⚠️ 확인 필요

작성 중 스펙과 구현이 어긋나거나 판단이 필요한 항목입니다. 팀 확인 후 스펙 갱신 또는 수정 이슈로 전환합니다.

1. **FE-SCREEN-007 화면 구성 서술 드리프트.** 스펙은 알파 버전 고지를 "만든 스토리와 채팅은 이 브라우저에만 저장"으로만 서술하지만, 구현은 게스트 한도(스토리라인 5·스토리 1·채팅 5회) 카드 + 로그인 혜택 카드의 2카드 구성입니다. 또한 구현은 비로그인 세션(`unauthenticated`)에서만 노출하는 조건을 추가로 갖는데 스펙 노출 조건에는 세션 조건이 없습니다. 스펙 서술 갱신이 필요합니다.
2. **v0.2.2 배포본의 게스트 한도 오표기.** 배포된 v0.2.2 다이얼로그는 스토리라인 생성 한도를 "10회"로 표기합니다. #72(KNK-599)에서 백엔드 정책과 같은 "5회"로 수정되었으나 미배포 상태이므로, v0.2.2 릴리스 QA에서는 배포본 문구가 정책과 다른 알려진 상태입니다.
3. **단계별·채팅 온보딩 미구현.** 스토리 생성 단계별 가이드(US-3-14)와 채팅 사용법 온보딩(US-6-9)은 코드에 구현 흔적이 없으며, 스펙도 §3-13 G4로 "미구현 — 필요성 재확인 후 검토"를 기록하고 있어 이 문서의 QA 범위에서 제외했습니다.
4. **localStorage 차단 환경의 반복 노출.** 프라이빗 모드 등에서 열람 저장이 실패하면 매 진입마다 온보딩이 다시 뜹니다(ONBD-GUEST-10). 코드 주석상 의도된 무시(저장 건너뜀)이지만 반복 노출 UX가 허용 범위인지 확인이 필요합니다.
