## ONBD-GUEST — 게스트 환영 온보딩 페이지

처음 온 게스트에게 시작 방법을 안내하는 전용 페이지(`/onboarding`)입니다. 서버 프록시가 메인 4탭(`/`, `/chats`, `/studio`, `/my`) 요청에 열람 쿠키(`manyak_onboarding_seen`)와 세션 쿠키가 모두 없으면 첫 응답 전에 `/onboarding`으로 리다이렉트합니다(홈 깜빡임 없음). 리다이렉트 URL에는 원본 요청의 쿼리스트링(UTM 등)을 `from`과 병합해 그대로 유지합니다. 노출 판정의 정본(비로그인 + 로컬 스토리·채팅 ID 0개 + `manyak:onboarding-seen` 미설정)은 페이지 가드가 확인하며, 미충족이면 열람 쿠키를 심고 원래 목적지(`from` 쿼리, 메인 탭만 허용)로 되돌립니다. 직접 접근도 같은 가드가 처리합니다. 화면은 헤더(왼쪽 로고, 오른쪽 "둘러보기" 보조 버튼 + "바로 시작하기" 주 버튼) + 두 줄 제목 + 설명 + 사용 흐름 순서(스토리 만들기 → 채팅 → 공유)의 소개 섹션 6개(순번·소제목·설명·앱 스크린샷 1~3장) + 본문 끝 "바로 시작하기" 전체 폭 CTA + 서비스 정보 푸터(소개·서비스 안내·이용약관·개인정보 처리방침 링크·문의 이메일·인스타그램·저작권)로 이어지는 세로 스크롤 랜딩입니다(KNK-1004·KNK-1185 — 하단 고정 CTA·로고 홈 링크·마무리 문장은 제거). "둘러보기"와 두 "바로 시작하기" 모두 열람 처리(`manyak:onboarding-seen = '1'`)를 저장하고 주소를 교체해 이동하므로 뒤로가기로 온보딩에 돌아올 수 없습니다. 검색 크롤러·링크 스크래퍼(User-Agent 판별)는 이 게이트를 적용받지 않고 요청한 경로를 그대로 받습니다(KNK-699·988).

## ONBD-INVITE — 신규 가입(회원) 초대 코드 온보딩

첫 로그인(신규 가입) 직후 세션 플래그 `inviteOnboardingPending`이 켜진 회원에게 초대 코드 등록을 안내하는 모달 바텀 시트입니다(KNK-1045). 루트 레이아웃에 마운트되어 모든 화면에서 뜰 수 있고, "닫기" 버튼·배경 탭·ESC 또는 코드 등록 완료로 세션 플래그를 소비해 닫습니다. 초대 코드 입력의 사유별 오류 응답(404·409 등) 상세는 초대 페이지와 공유하므로 `my.md`의 MY-INVITE 섹션에서 다루고, 여기서는 바텀 시트 유지 동작만 확인합니다.
