## ⚠️ 확인 필요

작성 중 스펙과 구현이 어긋나거나 판단이 필요한 항목입니다. 팀 확인 후 스펙 갱신 또는 수정 이슈로 전환합니다.

1. **스펙 라벨 드리프트 — 재생성·크레딧 게이팅.** `3-frontend.md`는 재생성(§3-6)과 크레딧 402 다이얼로그(§3-6 예외 처리)를 `Phase 1 · 계획`으로 라벨링하지만, dev에는 둘 다 구현되어 있습니다(재생성은 미배포, 402 게이팅·게스트 한도 다이얼로그는 v0.2.2에 포함). §3-1 구현 상태 라벨 표의 갱신이 필요합니다.
2. **전송 경로의 EOF 미처리(G5).** `completed`·`error` 없이 스트림이 끝나면 전송 경로는 스트리밍 상태가 멈춥니다(CHAT-SEND-11). 스펙이 §3-13 G5로 이미 기록한 알려진 간극이며, 재생성 경로는 refetch로 처리하고 있어 전송 경로만 남았습니다.
3. **엔딩 배지·채팅 이미지 미구현.** `reachedEnding`은 재생성 버튼 숨김에만 사용되고 엔딩 배지 렌더(US-6-13)와 이미지 마커 렌더(US-6-11)는 미구현(`Phase 1 · 계획` 유지)이라 이 문서의 QA 범위에서 제외했습니다.
4. **게스트 한도 로컬 카운터의 우회 가능성.** 로컬 카운터는 UX용 선차단이고 실제 강제는 서버 402입니다. 로컬스토리지를 지우면 선차단이 풀리지만 서버가 차단하므로 정책상 문제 없는지(다이얼로그 문구가 동일한지) CHAT-LIMIT-02로 확인이 필요합니다.
