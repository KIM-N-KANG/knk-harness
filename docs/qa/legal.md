## ⚠️ 확인 필요

작성 중 스펙과 구현이 어긋나거나 판단이 필요한 항목입니다. 팀 확인 후 스펙 갱신 또는 수정 이슈로 전환합니다.

1. **시행일·버전 미표기 — 검수 기준 위반.** 스펙은 "본문 최상단에 시행일과 버전을 표기"를 검수 기준으로 명시하고, 콘텐츠 데이터에도 `effectiveDate: '2026-07-10'`·`version: 'v1.0'`이 정의되어 있으나 `legal-document-view.tsx`가 두 값을 렌더하지 않습니다. 원본 `docs/legal/*.md`에는 상단 표기가 있어 TS 변환 과정에서 누락된 것으로 보입니다(LEGAL-DOC-03).
2. **FE-SCREEN-011 라벨 드리프트.** 스펙은 서비스 안내를 `계획`으로 표기하지만 #72(KNK-599)로 dev에 구현·머지되었습니다(미배포). 로그인 후 두 문서의 상시 진입점(개인정보 보호법 제30조 근거)이 곧 생기므로 §3-1 구현 상태 라벨 갱신이 필요합니다.
3. **콘텐츠 소스 이중화.** 스펙은 `docs/legal/terms.md`·`privacy.md`를 페이지가 렌더한다고 서술하지만, 구현은 이를 수동 변환한 TS 모듈(`src/features/legal/content/`)을 렌더합니다. 두 소스가 수동 동기화 대상이라 개정 시 드리프트 위험이 있으며, 정본이 무엇인지(md인지 TS인지) 확정이 필요합니다.
4. **법무 검토 미완.** 스펙과 `docs/legal/*.md` 주석 모두 사업자 정보·문의처 등 확정값의 법무 검토 필요를 명시하고 있습니다(현 문의처 `manyak.help@gmail.com`, 보호책임자 실명 표기). 릴리스 전 검토 완료 여부 확인이 필요합니다.
