# 공용 클라이언트 요구사항

기준: [사용자 목표](USER-STORY.md).

<br>

### 적용 범위

| 항목 | 공통 | 웹 | Android |
|---|---|---|---|
| CLIENT-US-001 | 홈, 채팅, 제작, 마이 네 탭과 현재 선택 표시 | 탭 이동은 기록 교체, 문서 수명 안에서 스크롤 복원 | 탭별 상태 유지, 다른 탭 뒤로가기는 홈, 홈에서는 앱 밖 |
| CLIENT-US-002 | 이용 정책, AI 콘텐츠와 문의 안내, 법적 문서 열람 | 로그인 전에도 열람, 서비스 안내는 새 탭 | 앱 안 문서 열람. 게스트 안내에 웹 전용임을 표시 |
| CLIENT-US-003 | 시스템 설정이 기본, 사용자가 선택한 테마를 기기에 보존하고 즉시 적용 | 브라우저별 저장 | 앱 기기별 저장 |
| CLIENT-US-004 | 웹에서 앱 또는 설치 안내로 연결 | 기기와 방문 횟수에 따라 배너, 앱 소개 링크 제공 | 전용 앱 열기 링크를 받고 로그인 이후 목적지 진입 |

<br>

### 이동과 화면 상태

| 조건 | 요구사항 |
|---|---|
| 오버레이 뒤로가기 | 시트, 다이얼로그, 전체 이미지, 안내 중 최상위 하나만 닫음. 드롭다운과 팝오버 및 선택 메뉴는 이 규칙의 대상이 아님 |
| 처리 중 잠금 | 전송이나 삭제 등 잠금 상태에서는 뒤로가기로 닫지 않음. 취소 의미가 있는 기능은 해당 도메인 조건 적용 |
| 자동 표시 웹 오버레이 | 사용자가 열지 않은 안내는 별도 뒤로가기 기록을 만들지 않으며 뒤로가기로 화면을 떠남 |
| 최초 조회 | 빠른 응답에서 로딩 표시가 깜빡이지 않도록 지연. 지연 전에는 표시하지 않음 |
| 빈 상태 | 정상 조회가 성공하고 결과가 없을 때만 표시 |
| 조회 실패 | 최초 실패는 오류와 재시도, 추가 실패는 기존 목록과 수동 재시도 유지 |
| 요청 버튼 | 중복 실행을 막고 기존 문구 공간과 접근 가능한 이름 유지 |
| 입력 오류 | 해당 필드 가까이 표시하고 필드와 연결. 폼 또는 요청 전체의 실패는 토스트 |
| 오류 노출 | 서버 원본 메시지와 스택을 사용자에게 그대로 보여주지 않음 |
| 데이터 보호 | 자유 입력 원문과 토큰을 로그나 분석 이벤트에 넣지 않음 |

인증과 세션 종료는 [ACCOUNT 요구사항](../domain/ACCOUNT/CLIENT/REQUIREMENTS.md)을 따른다. 목록 재시도 횟수와 자동 재조회는 플랫폼별 조건이며 웹의 기본값을 Android에 적용하지 않는다.

<br>

### 안내와 접근성

서비스 안내에는 게스트 동의 후 체험, 브라우저 저장 한계, 최초 회원 이관, AI 콘텐츠 특성과 문의 방법을 포함한다. 체험 한도나 이프 수치는 복제하지 않고 실제 사용 지점에서 서버 값으로 보여준다. 문의는 마이의 피드백 위치를 링크 없는 문장으로 안내한다. 서비스 안내에서 회원 탈퇴 문의 이메일을 별도로 표시하지 않는다.

조작 요소에는 접근 가능한 이름을 제공하고 상태를 색상만으로 구별하지 않는다. 웹의 키보드 조작, 화면 크기와 모션 조건 및 Android의 시스템 바와 구성 변경은 각 플랫폼의 적용 조건 안에서 구체화한다. 확정하지 않은 전체 글자 확대 지원 범위를 추가하지 않는다.
