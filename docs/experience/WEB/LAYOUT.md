# 웹 공용 표현

### 셸과 공용 요소

| 요소 | 표현 |
|---|---|
| 프레임 | 중앙 한 열, 동적 뷰포트 높이. 배너 아래에 헤더, 스크롤 본문과 푸터. CTA와 탭은 본문 형제 |
| 문서 배경 | 앱과 같은 테마 배경. 프레임 밖 좌우 여백만 다른 배경이며 입력을 가리지 않음 |
| 메인 헤더 | 홈은 로고와 화면 읽기용 “홈” 제목, 채팅과 제작 및 마이는 20px semibold. 헤더 보더 없음 |
| 하단 탭 | 24px 아이콘과 라벨, 같은 전경색. 현재 경로만 filled와 aria-current=page, 나머지 outline. 상하 16px과 하단 안전 영역 |
| 헤더 아이콘 | 40px 버튼 안 20px 글리프를 화면 좌우 16px 기준에 맞춤 |
| 바텀 시트 | 프레임 안 표시, 본문만 스크롤. 닫기는 전체 너비 ghost 버튼, 보조 텍스트 색상과 큰 버튼 규격 |
| 상태 접근성 | 폼 label, aria-invalid와 role=alert, 상태 role=status와 aria-label |
| 가로 탐색 | 스크롤바 숨김. 넘치는 영역만 grab, 드래그 중 grabbing. 클릭 가능한 칩과 탭의 기존 커서는 유지 |
| 당김 표시자 | “당겨서 새로고침” → “놓으면 새로고침” → “새로고침 중”. 마스코트가 뛰어올라 한 바퀴 돌기를 최소 한 주기 완료, 동작 줄이기는 깜빡임 |

헤더의 게스트 로그인과 공지, 회원 알림함 버튼은 [NOTIFICATION 표현](../../domain/NOTIFICATION/CLIENT/WEB/LAYOUT.md)을 따른다. 서비스 안내 메뉴에는 새 창 아이콘을 표시하고 안내 화면 로고는 링크가 아니다.

기본 서체는 Pretendard, 서사 서체는 MaruBuri다. 서사 자간은 -2%, 행간은 175%이며 본문 16px/28px, 추천 14px/24.5px다. 공용 목록 행은 가로 16px, 세로 8px, 열 간격 16px과 하단 8px을 사용한다. 도메인 카드의 표지와 텍스트 배치는 각 도메인이 소유한다.

### 앱 안내

배너는 프레임 최상단에 앱 아이콘, “마냑”과 안내 두 줄, 오른쪽 동작과 닫기 버튼을 둔다. 이름과 안내는 각각 한 줄이며 375px 폭에서도 줄바꿈하지 않고 넘치면 말줄임한다.

| 대상 | 문구 | 버튼 |
|---|---|---|
| Android | 앱에서 이어서 볼 수 있어요 | 앱 열기 |
| iOS 인앱 | 외부 브라우저에서 이어서 봐요 | 열기 |
| iOS Safari와 Chrome | 홈 화면에 추가해 앱처럼 열어요 | 추가하기 |

배너 영역 이름은 “앱 안내”다. 동작 이름은 “앱 열기”, “외부 브라우저로 열기”, “홈 화면에 추가하기”, “닫기”이며 닫은 뒤 배너 아래 화면으로 포커스를 옮긴다. 동작 줄이기에서는 표시와 닫기 애니메이션을 제거한다.

“홈 화면에 추가하기” 시트는 iPhone Safari 26 이상에서 스크린샷 네 장을 단계 번호와 점 표시로 넘긴다. 순서는 하단 ⋯와 공유, 더 보기, 홈 화면에 추가, 추가다. 연락처와 기기 이름을 가린다. 이전 Safari, iPad와 iOS Chrome은 “공유 버튼 누르기”, “"홈 화면에 추가" 누르기”와 “공유 버튼이 안 보이면 ⋯를 먼저 눌러주세요” 텍스트를 쓴다.

외부 열기 안내는 “외부 브라우저로 열어주세요”, “⋯ 메뉴에서 "브라우저로 열기"를 눌러주세요”, “링크 복사하기”다. 결과는 “링크를 복사했어요” 또는 “링크를 복사하지 못했어요”로 알린다.

### 앱 소개와 메타데이터

앱 소개 화면은 링크 없는 로고, 앱 아이콘, “마냑 앱으로 이동하고 있어요”, “앱이 열리지 않으면 아래에서 받을 수 있어요”를 표시한다. 소개 세 줄은 “키워드만 고르면 스토리가 완성돼요”, “채팅으로 스토리를 이어가요”, “실시간 이미지로 장면이 살아나요”다. 하단에는 “Google Play에서 받기”와 “웹에서 먼저 둘러보기”를 둔다.

문서 제목 템플릿은 `%s - 마냑`이다. 법적 문서와 안내는 콘텐츠 제목, 작품과 채팅 및 공유는 조회한 제목을 사용하고 조회 전에는 서버 제목을 유지한다. 공지 목록과 상세 및 알림함은 기본 제목을 상속한다.

홈 canonical은 `https://manyak.app/`이다. 홈 description, Open Graph와 Twitter 설명은 다음과 같다.

> 키워드를 골라 스토리를 만들면 주변 인물 이미지까지 한 번에 완성되는 AI 스토리챗, 마냑. 채팅으로 스토리를 이어가 보세요. 실시간 이미지를 켜면 대화에 따라 인물의 표정과 행동, 스토리 속 장소가 달라져요. 생생한 장면을 보며 스토리에 푹 빠져보세요.

앱 소개 미리보기는 제목 “마냑”, 위 홈 설명, 루트 브랜드 이미지와 `https://manyak.app/app` canonical을 사용한다. 문서 제목은 기본 제목이며 robots는 noindex, follow다.
