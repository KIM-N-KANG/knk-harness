# 웹 공용 상태 관리

기준: [구성](../../platform/WEB/COMPONENT-ARCHITECTURE.md).

<br>

### 상태 수명

| 상태 | 저장과 복원 |
|---|---|
| 탭 스크롤 | 문서 단위 Map, 경로별 위치. 돌아올 때 복원하고 내용이 짧으면 ResizeObserver로 최대 2초 재시도 |
| 테마 | 기기 저장 선택과 시스템 테마를 next-themes가 적용 |
| 앱 배너 횟수 | 지속 저장소의 방문 수와 세션 저장소의 현재 방문 및 닫힘. 저장소 실패는 첫 방문이고 닫지 않은 상태로 처리 |
| 앱 공유 자동 이동 | 세션 저장소의 한 번 실행 플래그. 새로고침과 복원 및 앱 복귀에서 반복하지 않음 |
| 외부 전환 대기 | 페이지 숨김과 반복 탭에 이전 타이머 취소. 복귀를 실패로 취급하지 않음 |
| 오버레이 | close와 guard 레이어, 더미 기록과 작업 큐. 현재 URL이 예상과 다르면 레이어 상태 폐기 |

<br>

### 늦은 결과와 복구

당겨 새로고침은 구독 중인 쿼리만 다시 읽고 기존 내용을 유지한다. 비활성 화면에서는 당김 리스너를 제거하고 진행 중 당김을 복원하되 시작한 요청은 완료까지 유지한다. 홈과 제작의 스크롤 기반 표시 상태는 실제 복원된 위치와 동기화한다.

앱 배너는 서버 렌더링에서 숨기고 클라이언트 상태로 판정한다. 저장값을 읽기 전의 임시 화면을 실제 노출과 방문으로 집계하지 않는다. 회원과 기기별 도메인 저장소는 공용 셸에서 임의로 정리하지 않는다.
