# 공용 화면 흐름

기준: [화면 구성](INFORMATION-ARCHITECTURE.md).

<br>

### 탭과 오버레이

1. 하단 탭을 누르면 해당 화면과 선택 상태를 함께 바꾼다.
2. 상세나 하위 화면에서 돌아오면 탭의 읽던 위치를 복원한다. 웹 새 탭과 새로고침은 맨 위에서 시작한다.
3. 사용자가 연 오버레이 위에서 뒤로가면 최상위 오버레이만 닫는다. 처리 중 잠금이면 그대로 둔다.
4. 오버레이에서 다른 화면으로 이동하면 먼저 오버레이를 정리한다. 다시 돌아와 빈 오버레이 기록을 거치지 않는다.

Android에서 다른 메인 탭의 뒤로가기는 홈으로 이동한다. 홈의 뒤로가기는 앱 밖으로 나가며 방문한 탭을 역순으로 순회하지 않는다. 웹은 메인 탭 진입 이전 기록으로 이동한다.

<br>

### 테마와 서비스 안내

테마 변경은 시스템 설정 → 라이트 모드 → 다크 모드 → 시스템 설정 순으로 순환한다. 선택 즉시 화면에 적용하고 다음 실행에도 유지한다.

마이에서 서비스 안내를 열면 웹은 새 탭에서, Android는 앱 안에서 문서를 보여준다. 법적 문서와 서비스 안내는 원래 화면의 입력이나 진행 상태를 변경하지 않는다.

<br>

### 앱 진입

웹 배너의 앱 열기는 스토리 상세에서 같은 스토리를, 다른 화면에서는 앱 홈을 연다. Android 앱이 없으면 스토어로 연결한다. 설치 뒤 원래 화면까지 보내는 디퍼드 딥링크는 제공하지 않는다. iOS는 외부 브라우저 열기 또는 홈 화면 추가 안내를 제공한다.

앱 소개 링크는 Android 앱 홈 또는 스토어로, 다른 기기는 웹 홈으로 보낸다. 같은 탭에서 앱 복귀나 새로고침 뒤 반복해서 이동시키지 않는다.
