# 2-2 운영 요구사항

본 문서는 채팅의 사용자 기대를 충족하기 위한 품질, 처리 시간과 비용의 요구 수준을 정한다.

운영 우선순위, 결과의 허용 기준과 품질 지표, 처리 시간과 생성 비용의 한도를 정의한다.

<br>

### 2-2-1 태스크의 유저

이 문서의 유저는 운영 요구사항을 정하고 결과를 확인하는 AI 담당자와 제품 정책 담당자이다. 두 담당자는 배포 전에 AI 결과를 평가하고, 배포 후에는 생성 품질과 실패, 처리 시간, 생성 비용을 확인한다. AI 결과는 사람의 검수 없이 사용자에게 전달되므로 잘못된 결과가 사용자에게 미치는 영향을 기준으로 개선 우선순위를 정한다.

<br>

### 2-2-2 품질

**우선순위와 허용 기준**

| 대상 | 기준 | 이유 |
|---|---|---|
| 본문 전달 | 판정과 이미지 처리의 복구 가능한 오류는 대체 결과로 처리함<br>설정 오류와 내부 예외는 상위로 전파함 | 본문이 있어야 사용자가 이야기를 이어갈 수 있음 |
| 엔딩 판정 | 엔딩을 놓치는 오류보다 엔딩에 도달했다고 잘못 판정하는 오류를 먼저 줄임 | 잘못 기록한 엔딩 도달은 되돌릴 수 없지만, 놓친 엔딩은 이후 턴에서 다시 도달할 수 있음 |
| 이야기 전개 | 사건이나 엔딩으로 이끄는 것보다 사용자 입력에 따른 전개를 우선함 | 사용자의 선택을 무시하고 결말로 이끌면 자유롭게 이야기를 만드는 경험을 해침 |
| 선택지 | 생성한 선택지가 부족하면 대체 문구로 채워 제공함 | 선택지가 없으면 사용자가 다음 행동을 직접 구상해야 함 |

<br>

**콘텐츠 안전성**

창작 표현을 넓게 허용하고 최소한의 안전성 기준을 적용한다. 미성년자나 실존 인물을 성적으로 착취하는 내용, 현실의 중대 범죄를 돕는 내용처럼 법적, 사회적으로 용인될 수 없는 수준은 허용하지 않는다. 이 기준은 사용자에게 전달하는 본문과 이미지에 적용한다.

금지 안내를 출력한 턴도 정상 응답으로 처리한다. 사건과 엔딩 판정, 실시간 이미지와 선택지 생성에는 일반 턴과 같은 조건을 적용한다. 회원의 이프도 일반 턴과 동일하게 소모하며 사용자는 이후 채팅을 이어갈 수 있다.

<br>

**품질 지표**

생성에 성공했는지와 결과가 기대에 맞는지를 구분해 확인한다. 아래 지표의 목표값은 미정이다.

| 지표 | 측정 기준 |
|---|---|
| 이야기의 재미 | 정해진 대화의 마지막 본문을 새로 생성하고, 채팅을 계속하고 싶은 이야기인지 평가기로 채점한 점수 |
| 사건 판정 정확도 | 정답을 붙인 평가 데이터에서 목표 사건과 완결 사건이 정답과 일치한 비율 |
| 채팅 응답 생성 성공률 | 전체 채팅 턴 요청 중 본문을 끝까지 전달한 요청의 비율 |
| 판정 성공률 | 판정을 호출한 턴 중 유효한 판정 결과를 얻은 턴의 비율 |
| 선택지 생성 완성률 | 전체 선택지 요청 중 대체 문구 없이 선택지 3개를 생성한 요청의 비율 |
| 실시간 이미지 생성 성공률 | 실시간 이미지 생성 시도 중 새 이미지를 전달한 비율 |
| 본문 재생성률 | 전체 턴 중 사용자가 본문을 재생성한 턴의 비율 |
| 선택지 사용률 | 전체 사용자 입력 중 선택지를 고르거나 고쳐서 보낸 입력의 비율 |

판정 성공률은 유효한 결과를 얻었는지 나타내며 판정의 정확도를 뜻하지 않는다. 본문 재생성률과 선택지 사용률은 사용자 행동을 나타내는 보조 지표이다. 두 값만으로 품질이나 만족도를 판단하지 않고 결과물 평가와 함께 해석한다.

<br>

### 2-2-3 시간

채팅 턴의 처리 시간에는 본문 생성, 사건과 엔딩 판정, 저장 이미지 선택 또는 실시간 이미지 생성, 본문 전송이 포함된다. 선택지 생성은 채팅 응답 생성이 끝난 뒤 별도로 요청하므로 처리 시간도 따로 측정한다.

| 항목 | 채팅 턴 | 선택지 생성 |
|---|---|---|
| 처리 시간 상한 | 백엔드 SSE 연결 120초 | 미정 |
| 본문이 나오기 시작할 때까지의 대기 시간 목표 | 미정 | 해당 없음 |
| 결과를 모두 받을 때까지의 대기 시간 목표 | 미정 | 미정 |
| 처리해야 할 동시 요청 수 | 미정 | 미정 |

<br>

### 2-2-4 비용

**AI 생성 비용**

| 항목 | 산정 기준 |
|---|---|
| 포함 범위 | 본문, 사건과 엔딩 판정, 선택지, 저장 이미지 선택, 실시간 이미지와 재호출 비용을 합산함 |
| 제외 범위 | 평가용 AI 비용 |
| 산정 단위 | 턴당 비용 <br> 재생성은 비용 산정에서 별도 1건으로 셈 |
| 구분 | 실시간 이미지가 있는 턴과 없는 턴을 나눠 확인함 |
| 대화 길이 | 매 턴 대화 원문을 전달해 입력 비용이 늘어나므로 누적 턴 수도 함께 확인함 |

<br>

**사용자 과금**

회원은 턴과 재생성마다 이프를 소모한다. 실시간 이미지는 추가로 과금하며 생성에 실패하면 해당 이미지 결제를 취소한다. 게스트는 정해진 턴 수까지만 이용한다.
