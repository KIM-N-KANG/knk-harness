# 1. 배경

본 문서는 채팅이 해결하려는 문제와 AI에 맡길 역할을 설명한다.

서비스 배경, 사용자의 어려움, 채팅의 흐름과 참여 주체, 공통 용어를 정리한다.

<br>

### 1-1 도메인

AI 인터랙티브 채팅은 사용자가 만든 캐릭터와 세계관을 바탕으로 AI가 인물을 연기하고, 사용자가 대화로 이야기를 진행하는 서비스 영역이다. 사용자는 완성된 이야기를 읽는 데서 나아가 인물의 대사와 행동을 직접 정하며 전개에 참여한다.

이때 AI의 응답은 사용자가 읽을 이야기이자 다음 행동을 정하는 바탕이 된다. AI는 사용자의 입력에 반응하면서 인물과 상황을 묘사하고, 앞선 대화에서 이어지는 다음 장면을 만들어야 한다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고, 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스이다. 사용자는 스토리 속 주인공을 1인칭으로 연기하고 AI는 주변 인물을 연기한다.

마냑은 사용자가 채팅하면서 웹소설 한 편을 완성하는 경험을 목표로 한다. 스토리에는 여러 엔딩과 그 엔딩으로 방향을 잡아 주는 주요 사건이 있다. 사용자는 주요 사건을 따르거나 벗어나 자유롭게 이야기를 이어가고, 엔딩 조건을 충족하면 결말을 본다. 엔딩 이후에도 같은 이야기에서 채팅을 계속할 수 있다.

채팅의 대상은 간편 제작과 일반 제작으로 만든 스토리, 마냑이 제공하는 오리지널 스토리이다. 사용자는 제작 단계에서 마련한 스토리 설정과 시작 설정을 바탕으로 이야기를 시작한다.

<br>

### 1-3 현재 업무와 문제

사용자는 주인공의 대사와 행동을 정하며 이야기를 즐기려 한다. 그런데 AI가 입력에 반응하기만 하면 다음 사건과 전개 방향까지 사용자가 계속 구상해야 한다. 다음 행동이 떠오르지 않으면 채팅이 멈추고, 대화를 이어가더라도 같은 상황만 반복되면 이야기가 진전되거나 완결된다는 느낌을 받기 어렵다.

이 부담을 줄이는 것이 채팅 태스크의 목적이다. 다만 부담의 크기와 발생 빈도는 확인하지 않았으며, 문제 정의는 서비스 목표를 바탕으로 세운 제품 기획의 가설이다.

AI는 사용자가 입력한 대사와 행동에 따라 주변 인물의 반응과 다음 상황을 만든다. 주요 사건과 엔딩은 전개의 방향을 잡고 결말에 도달할 기준이 된다. 선택지는 다음 행동을 직접 쓰기 어려울 때 이야기를 이어갈 수 있도록 돕는다. 사용자는 주요 사건이나 선택지를 따를지 직접 정한다.

<br>

**채팅 품질이 미치는 영향**

| 항목 | 사용자와 서비스에 미치는 영향 |
|---|---|
| 재미와 일관성 | 밋밋한 전개, 설정과 어긋난 인물의 성격과 말투, 앞선 대화와의 모순은 몰입을 깨고 이탈로 이어질 수 있음 |
| 사건과 엔딩 판정 | 판정이 틀리면 사건이 반복되거나 결말이 너무 일찍 나오고, 조건을 충족해도 결말을 보지 못할 수 있음 |
| 대기 시간과 실패 | 응답이 늦거나 생성에 반복해서 실패하면 이야기의 흐름이 끊김 |
| 이용 비용과 생성 비용 | 회원은 턴과 재생성마다 이프를 소모함 <br> 낮은 품질로 재생성이 늘면 사용자 부담과 AI 생성 비용이 커짐 <br> 실시간 이미지를 만들면 이미지 생성 비용도 더해짐 |
| 콘텐츠 안전성 | AI가 만든 글과 이미지는 사람의 검수 없이 전달되므로 부적절한 콘텐츠가 사용자에게 바로 노출될 수 있음 |

<br>

### 1-4 채팅의 흐름과 주체

사용자는 다음 순서로 채팅한다.

1. 스토리의 시작 설정을 골라 채팅을 시작하고 프롤로그를 읽는다.
2. 주인공의 대사나 행동을 직접 입력하거나 선택지를 골라 보낸다.
3. AI가 이어 쓴 본문과 이미지를 보고 다음 입력을 보낸다.
4. 엔딩 조건을 충족하면 결말과 엔딩 도달 표시를 확인한다.

사용자는 매 턴 직접 입력할지 선택지를 쓸지 정한다. 응답이 마음에 들지 않으면 같은 턴의 본문을 재생성하고, 엔딩에 도달한 뒤에도 채팅을 이어갈 수 있다. AI가 만든 결과는 사람의 검수 없이 사용자에게 바로 전달된다.

<br>

**AI가 맡는 일**

본문과 선택지는 이야기를 이어가는 데 쓰이고, 이미지는 사용자가 화자와 장면을 떠올리도록 돕는다.

| 작업 | 역할 |
|---|---|
| 채팅 응답 생성 | 스토리 설정과 앞선 대화를 바탕으로 사용자 입력에 따른 상황 묘사와 주변 인물의 대사를 작성함 |
| 사건과 엔딩 판정 | 대화 내용을 바탕으로 주요 사건의 진행과 완결, 엔딩 도달 여부를 판단함 |
| 선택지 생성 | 현재 상황에서 주인공이 할 수 있는 다음 행동을 제안함 |
| 이미지 연결과 생성 | 제작 단계에서 저장한 인물 이미지를 본문에 연결함 <br> 실시간 이미지는 채팅 중 장면에 맞춰 새로 생성함 |

스토리 설정, 시작 설정, 주요 사건, 엔딩과 기본 인물 이미지는 제작 단계에서 마련한다. 본 태스크는 해당 자료를 받아 채팅에 사용한다. 간편 제작의 생성 작업은 별도 태스크로 다룬다. ([1 배경](../SIMPLE-GENERATION-STORY/1-BACKGROUND.md))

대화 요약 생성은 본 태스크에 포함하지 않는다. 현재 백엔드는 대화 기록을 원문으로 전달하며 요약은 미구현 상태이다.

<br>

**흐름에 관여하는 주체**

| 주체 | 누구인가 | 이 태스크에서 하는 일 |
|---|---|---|
| 사용자 | AI와 이야기를 이어가는 이용자 <br> 회원과 게스트로 나뉨 | 주인공의 대사와 행동을 직접 입력하거나 선택지를 고름 <br> 응답을 읽고 재생성 여부를 정함 |
| 회원 | 로그인한 사용자 | 턴과 응답 재생성마다 이프를 소모함 |
| 게스트 | 로그인 없이 쓰는 사용자 | 제한된 턴 수만 채팅해 보고 회원 가입을 결정함 |
| 스토리 제작자 | 스토리를 만든 사용자 또는 마냑 공식 계정 | 채팅의 바탕이 되는 스토리 설정, 시작 설정, 주요 사건과 엔딩을 정함 |
| 클라이언트 | 웹과 안드로이드 앱 | 사용자의 입력을 받고 본문, 이미지, 선택지와 엔딩 도달을 보여줌 |
| 백엔드 | `manyak-server` | 채팅, 대화 기록과 사건 진행 상태를 저장함 <br> 매 턴 필요한 값을 모아 AI 서버에 생성을 요청함 |
| AI 담당자 | 프롬프트, 모델, 평가를 맡는 팀 구성원 | 품질과 비용을 보고 프롬프트와 모델을 바꿈 |

<br>

### 1-5 공통 용어

| 용어 | 뜻 |
|---|---|
| 채팅 | 스토리를 기반으로 진행하는 플레이 단위 <br> 저장, 이어쓰기와 삭제의 단위 |
| 턴 | 사용자 입력 1회, AI 출력 1회와 선택지 1세트 |
| 사용자 입력 | 턴에서 사용자가 보낸 글 |
| 본문 | AI가 생성하는 상황 묘사와 인물 대사 <br> 선택지는 포함하지 않음 |
| 선택지 | 턴 끝에 AI가 제안하는 다음 행동 후보 3개 |
| 재생성 | 마음에 들지 않는 본문을 같은 턴에서 다시 생성하는 것 |
| 주인공 | 사용자가 1인칭으로 연기하는 인물 |
| 주변 인물 | AI가 연기하는 인물 |
| 스토리 설정 | 세계관, 등장인물, 주인공, 규칙 설정 <br> 채팅의 바탕이 됨 |
| 시작 설정 | 채팅이 시작되는 장면 <br> 상황 이름, 시작 상황과 프롤로그를 담음 |
| 프롤로그 | 채팅을 시작할 때 먼저 보여주는 도입 글 |
| 대화 기록 | 백엔드가 매 턴 원문으로 전달하는 이전 턴의 사용자 입력과 본문 |
| 주요 사건 | 이야기가 엔딩을 향하도록 방향을 잡아 주는 사건 <br> 이름, 설명과 키 문장으로 구성됨 |
| 키 문장 | 사용자 입력이 주요 사건과 관련되는지 판단하는 기준 문장 |
| 목표 사건 | 채팅이 현재 향하고 있는 주요 사건 <br> 채팅마다 최대 1개 |
| 엔딩 | 스토리의 결말 <br> 이름, 엔딩 조건과 엔딩 에필로그로 정의함 |
| 엔딩 조건 | 엔딩 도달을 판정하는 조건 <br> 최소 턴 수와 달성 조건을 모두 충족해야 함 |
| 엔딩 에필로그 | 엔딩에 도달한 턴의 본문을 어떻게 쓸지 정한 안내 |
| 엔딩 도달 | 엔딩 조건을 충족해 엔딩 본문을 표시한 상태 <br> 채팅마다 최초 1회만 인정함 |
| 인물 이미지 | 제작 단계에서 저장된 주변 인물의 기본 이미지 |
| 실시간 이미지 | 턴 진행 중에 AI가 장면에 맞춰 새로 만드는 이미지 |
| 콘텐츠 안전성 기준 | AI가 생성한 글과 이미지에서 허용하지 않는 내용을 정한 최소한의 기준 |
| 상황 설명 | 상황과 행동을 묘사하는 글 <br> 사용자 입력과 본문에서 `*...*`로 감싸 표기함 |
| 이프 | 회원이 AI 기능을 쓸 때 소모하는 서비스 내 재화 |
