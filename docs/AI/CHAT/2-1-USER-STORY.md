# 2-1 유저 스토리

본 문서는 사용자가 채팅의 AI 결과에 기대하는 경험과 품질을 구체화한다.

본문, 사건과 엔딩, 선택지와 이미지에 대한 기대와 응답 시간, 이용 비용의 요구를 정리한다.

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 스토리 속 주인공을 연기하며 채팅하는 사용자이다. 회원과 게스트, 간편 제작과 일반 제작으로 만든 스토리, 오리지널 스토리에 같은 결과물 품질 기준을 적용한다.

사용자는 AI가 만든 본문을 읽고 직접 입력하거나 선택지를 골라 이야기를 이어간다. 이미지는 화자와 장면을 떠올리는 데 사용한다. 사건과 엔딩의 판정 결과는 이후 이야기의 전개와 엔딩 도달 표시로 확인한다.

AI 결과는 사람의 검수 없이 사용자에게 전달된다. 결과가 기대와 다르면 사용자는 같은 턴의 본문을 재생성하거나 다음 입력으로 전개를 바꿀 수 있다.

<br>

### 2-1-2 품질에 대한 기대

**본문**

사용자는 주인공의 대사와 행동을 정하고, AI가 만든 주변 인물의 반응과 다음 상황을 읽는다. 설정을 지키면서도 새로운 전개가 나와 사용자가 매번 다음 사건을 구상하지 않아도 이야기를 이어갈 수 있어야 한다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 이야기가 재미있어 다음 장면을 계속 읽고 싶음 | 설정과 입력은 지키지만 전개가 밋밋해 계속할 흥미가 생기지 않음 |
| 입력한 대사와 행동이 이야기에 반영되고 그에 따른 결과가 나옴 | 문을 여는 행동을 입력했는데 문을 열었는지 알 수 없이 무관한 장면이 이어짐 |
| 주인공의 대사와 행동은 사용자가 정함 | AI가 사용자가 입력하지 않은 주인공의 대사나 결정을 지어냄 |
| 주변 인물의 성격과 말투가 일관되고, 관계와 사건에 따라 태도가 자연스럽게 달라짐 | 경계하던 인물이 계기 없이 친근해지거나, 신뢰가 쌓였는데도 처음처럼 경계함 |
| 세계관과 규칙 설정이 지켜짐 | 마법이 없는 세계관에서 인물이 마법을 사용함 |
| 앞선 대화에서 일어난 일과 모순되지 않음 | 앞선 대화에서 죽은 인물이 설명 없이 다시 등장해 말을 검 |
| 턴마다 새로운 상황이나 반응이 나와 이야기가 앞으로 나아감 | 여러 턴 동안 같은 묘사와 질문만 반복됨 |
| 본문에서 다음 행동을 떠올릴 단서를 얻음 | 다음에 할 수 있는 일이 드러나지 않아 사용자가 새 사건부터 구상해야 함 |
| 상황 설명과 인물의 대사가 구분되고 화자를 알 수 있음 | 여러 인물이 대화하는데 누가 말하는지 구분되지 않음 |
| 같은 입력으로 재생성하면 다른 전개를 읽을 수 있음 | 이전 본문의 표현만 바뀌고 전개는 같음 |

<br>

**사건과 엔딩**

사용자는 자신의 선택에 따라 이야기를 진행하면서 결말에 도달하기를 기대한다. 주요 사건은 전개 방향을 잡아 주되 사용자가 다른 행동을 선택할 자유를 유지해야 한다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 입력과 관련된 주요 사건이 대화 속에서 자연스럽게 진행됨 | 사건과 관련된 행동을 계속 입력해도 사건이 시작되지 않음 |
| 주요 사건과 무관한 행동을 선택해도 그 방향으로 이야기가 이어짐 | 다른 곳으로 가려는데 본문이 주요 사건으로 억지로 되돌림 |
| 진행 중인 사건이 개연성 있게 마무리되고 완결된 사건은 반복되지 않음 | 이미 끝난 사건이 다음 턴에 처음부터 다시 벌어짐 |
| 엔딩 조건을 충족한 턴에 본문이 결말을 맺고 엔딩 도달 표시가 나옴 | 조건을 충족했는데 결말이 나오지 않거나, 본문은 일반 전개인데 엔딩 도달 표시만 나옴 |
| 엔딩 조건을 충족하기 전에는 결말에 도달하지 않음 | 이야기가 충분히 진행되지 않았거나 달성 조건을 충족하지 않았는데 엔딩에 도달함 |
| 엔딩 이후에도 앞선 결말을 반영한 이야기를 이어갈 수 있음 | 엔딩 이후 인물이 앞선 결말을 모르는 것처럼 말함 |

<br>

**선택지**

사용자는 직접 쓸 내용이 떠오르지 않을 때 선택지로 다음 행동을 정한다. 선택지는 현재 장면에 맞고 서로 다른 전개를 제안해야 고를 이유가 생긴다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 방금 읽은 본문의 상황에 맞는 행동을 제안함 | 이미 방을 나왔는데 방 안을 둘러보는 행동을 제안함 |
| 선택지 3개가 서로 다른 행동과 전개 방향을 제안함 | 세 선택지가 모두 말을 거는 행동을 표현만 바꿔 제안함 |
| 주인공이 할 수 있는 행동을 제안함 | 주인공이 결정할 수 없는 주변 인물의 행동을 제안함 |
| 진행할 주요 사건이 있으면 그 사건으로 이어갈 행동을 제안함 | 사건의 단서가 있는데도 선택지가 모두 잡담에 머묾 |
| 선택지를 수정하지 않고 그대로 입력으로 사용할 수 있음 | 문장이 끊겨 있거나 뜻이 불분명해 수정해야 보낼 수 있음 |
| 매 턴 다음 행동을 고를 선택지 3개를 받음 | 선택지가 비어 있거나 하나만 나와 행동을 고르기 어려움 |

<br>

**이미지**

사용자는 인물 이미지로 화자를 구분하고, 실시간 이미지로 장면 속 인물의 표정과 상황을 떠올린다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 인물 이미지가 해당 인물의 대사에 연결됨 | 다른 인물의 이미지가 대사 앞에 나옴 |
| 실시간 이미지의 표정이 본문의 상황에 맞음 | 본문에서는 인물이 울고 있는데 이미지에서는 환하게 웃고 있음 |
| 실시간 이미지에서 같은 인물의 외형이 일관되게 유지됨 | 이미지마다 얼굴이나 머리색이 달라져 다른 인물처럼 보임 |
| 이미지 생성에 실패해도 본문을 읽고 채팅을 이어갈 수 있음 | 이미지 생성 실패로 해당 턴의 본문까지 받지 못함 |

<br>

**콘텐츠 안전성**

사용자에게 전달하는 본문과 이미지에는 콘텐츠 안전성 기준이 금지한 내용이 없어야 한다. 허용 범위와 금지 기준은 운영 요구사항을 따른다. ([2-2-2 품질](2-2-OPERATION-REQUIREMENTS.md#2-2-2-품질))

<br>

### 2-1-3 시간에 대한 기대

사용자는 본문을 읽고 다음 행동을 정하는 동안 이야기의 흐름이 끊기지 않기를 기대한다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 입력을 보내면 본문이 곧 나오기 시작해 끊김 없이 이어짐 | 본문이 나오기까지 오래 걸려 생성에 실패한 것으로 받아들임 |
| 본문을 다 읽었을 때 다음 행동을 고를 선택지가 준비되어 있음 | 본문을 읽은 뒤에도 선택지를 오래 기다림 |
| 재생성할 때도 처음과 비슷한 시간 안에 본문을 받음 | 재생성의 대기 시간이 길어 어색한 본문을 그대로 넘김 |
| 실시간 이미지를 기다리느라 이야기의 흐름이 끊기지 않음 | 이미지 생성에 오래 걸려 다음 턴을 이어가기 어려움 |

<br>

### 2-1-4 비용에 대한 기대

회원은 턴과 재생성마다 이프를 소모하므로 지불한 비용에 맞는 결과를 기대한다.

| 기대하는 결과 | 기대에 어긋나는 사례 |
|---|---|
| 이프를 지불한 턴에서 이야기를 이어갈 수 있는 본문을 받음 | 이프를 썼지만 본문이 중간에 끊기거나 생성에 실패함 |
| 본문 품질 문제로 재생성을 반복하지 않아도 됨 | 설정과 어긋난 본문이 반복되어 한 턴에서 여러 번 재생성함 |
| 부담할 만한 이용 비용으로 엔딩까지 채팅을 이어갈 수 있음 | 턴마다 드는 이프가 부담스러워 엔딩 전에 채팅을 그만둠 |
