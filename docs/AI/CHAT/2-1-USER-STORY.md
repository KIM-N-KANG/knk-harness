# 2-1 유저 스토리

본 문서는 사용자가 기대하는 채팅 AI의 성능을 구체화한다.

본문, 사건과 엔딩, 선택지와 이미지에 대한 기대와 응답 시간, 이용 비용의 요구를 정리한다.

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 스토리 속 주인공을 연기하며 채팅하는 사용자(고객)이다. 회원과 게스트, 간편 제작과 일반 제작으로 만든 스토리, 오리지널 스토리에 같은 결과물 성능 기준을 적용한다.

사용자는 AI가 만든 본문을 읽고 직접 입력하거나 선택지를 골라 이야기를 이어간다. 이미지는 화자와 장면을 떠올리는 데 사용하고, 사건과 엔딩의 판정 결과는 이야기의 전개와 엔딩 도달 표시로 확인한다.

<br>

### 2-1-2 성능에 대한 기대

#### 본문

사용자는 주인공의 대사와 행동을 입력하고, 주변 인물의 반응과 다음 상황을 읽는다.

| 기대 |
|---|
| 이야기가 재미있어 다음 장면을 계속 읽고 싶음 |
| 주변 인물의 성격과 말투가 일관되고 관계와 사건에 따라 태도가 자연스럽게 달라짐 |
| 스토리의 세계관과 규칙이 지켜짐 |
| 앞선 대화에서 일어난 일과 모순되지 않음 |
| 턴마다 새로운 상황이나 반응이 나와 이야기가 전개됨 |

<br>

#### 선택지

사용자는 직접 쓸 내용이 떠오르지 않을 때 선택지로 다음 행동을 정한다.

| 기대 |
|---|
| 방금 읽은 본문의 상황에 맞는 행동을 제안함 |
| 선택지마다 행동과 전개 방향이 달라서 고를 이유가 있음 |
| 주인공이 할법한 행동을 제안함 |
| 매 턴 다음 행동을 고를 선택지 3개를 받음 |

<br>

#### 실시간 이미지 생성

사용자는 실시간 이미지를 켜고 채팅하면서 새로 생성된 인물 이미지를 본다.

| 기대 |
|---|
| 인물의 표정이 본문의 상황에 맞음 |
| 같은 인물의 외형이 일관되게 유지됨 |
| 이미지 생성에 실패해도 본문을 읽고 채팅을 이어갈 수 있음 |

<br>

#### 저장 이미지 선택

사용자는 실시간 이미지를 끄고 채팅하면서 스토리에 저장된 인물 이미지를 본다.

| 기대 |
|---|
| 저장된 이미지 중 현재 대화에 맞는 이미지가 표시됨 |
| 이미지 선택에 실패해도 기존 이미지와 본문을 받음 |
