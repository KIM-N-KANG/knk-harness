# 7-3 관측

기록 항목과 원문 수집 조건은 AI 서버 명세와 분석 명세를 따른다. ([AI 서버 명세 5-6 운영과 관측](../../spec/5-ai-server-spec.md#5-6-운영과-관측), [분석 명세 6-7 개인정보와 원문 수집 원칙](../../spec/6-analytics.md#6-7-개인정보와-원문-수집-원칙))

<br>

### 7-3-1 요청 조회

백엔드가 전달한 `request_id`로 Langfuse 추적과 백엔드 호출 기록을 연결한다. 헤더가 없거나 값이 `unknown`인 식별자는 기록하지 않는다. ([5-5 요청 헤더와 메타데이터](5-CONTRACT.md#5-5-요청-헤더와-메타데이터))

| 확인할 내용 | 조회 위치 | 확인 항목 |
|---|---|---|
| 생성 입력과 출력 | Langfuse의 요청 추적과 하위 호출 | 프롬프트, 모델 출력, 토큰과 비용 |
| 호출 오류 | Sentry의 `feature`, `error_code` | 공급자, 모델, 오류 원문과 스택 |
| 요청 전체의 성공과 실패 | 백엔드 AI 호출 기록 | HTTP 상태, 출력 `meta`, `request_id` |
| 텍스트 호출 시간과 사용량 | AI 서버 로그 | 호출 종류, 소요 시간, 입출력 토큰과 캐시 적중 토큰 |

<br>

| 식별자 | 기록 위치 | 연결 대상 |
|---|---|---|
| `request_id` | Langfuse metadata, 로그 | 백엔드 요청과 AI 호출 |
| `session_id` | Langfuse 세션 | 같은 접속 세션의 요청 |
| 기기 식별자 해시 | Langfuse 사용자 | 같은 기기의 요청 <br> 원본 식별자 수신 안 함 |
| `creation_id` | Langfuse metadata | 스토리라인부터 컴파일까지의 제작 과정 <br> 분석 이벤트의 동명 식별자와 별개 |
| `parent_creation_id` | 스토리라인 metadata | 재생성으로 버린 이전 결과 |
| `storyline_id`, `storyline_order` | 컴파일 metadata | 선택한 후보 |

<br>

### 7-3-2 기록 항목과 구현 위치

Anthropic과 Google 텍스트 호출의 자동 계측은 미완성이다. 해당 공급자에서는 하위 호출 기록이 빠질 수 있다.

| 단위 | 기록 시점과 이름 | 기록 내용 | 구현 위치 (`manyak-ai` 기준) |
|---|---|---|---|
| 요청 추적 | 요청마다 1건 <br> `스토리라인 생성`, `스토리 컴파일` | 입력, 장르, 식별자, 프롬프트 버전, 재호출 횟수 | `src/core/langfuse.py`의 `observe_request` |
| 텍스트 호출 | 최초 생성, 재생성과 보완마다 <br> 호출 이름은 SDK에서 지정 | 프롬프트, 출력과 사용량 | `src/core/langfuse.py`의 `init_langfuse` <br> OpenAI SDK 자동 계측 |
| 이미지 호출 | 이미지 한 장마다 <br> `이미지 생성:인물`, `이미지 생성:썸네일` | 모델, 크기, 화질, 형식, 사용량과 결과 바이트 수 | `src/core/langfuse.py`의 `observe_generation` |
| 오류 | 실패한 시도마다 <br> 복구된 실패도 포함 | 기능, 공급자, 모델, 프롬프트 버전, 오류 분류, 재호출 횟수와 시간 | `src/core/sentry.py`의 `capture_ai_exception` |
| 인물 누락 경고 | 보완 뒤에도 인물이 빠진 후보 출력 시 | 후보 번호만 기록 <br> 이름과 본문 제외 | `src/services/story_llm.py`의 `_report_names_still_missing` |

<br>

**실행 정보**

| 정보 | 출력 `meta` | Langfuse | Sentry |
|---|---|---|---|
| 환경과 코드 버전 | 없음 | 환경, 릴리스 | 환경 <br> 릴리스 지정 없음 |
| 기능 | 없음 | 추적 이름 | `feature` |
| 공급자와 모델 | `provider`, `model` | 호출 기록의 모델 | `provider`, `model` |
| 프롬프트 버전 | `prompt_versions` | metadata | `ai` 컨텍스트 |
| 재호출 횟수 | `retry_count` | metadata | `ai` 컨텍스트 |
| 토큰 수 | `input_token_count`, `output_token_count` <br> 이미지 사용량 제외 | 호출별 사용량 | 없음 |
| 소요 시간 | 없음 | 시작과 종료 시각 | `ai.latency_ms` |
| 오류 분류 | 없음 | 오류 수준, 예외 타입 | `error_code` |
| 장르 | 없음 | `genre:` 태그 | 없음 |
| 단가 구간 | 없음 | DeepSeek의 `pricing_window` | 없음 |

<br>

| 기록 규칙 | 적용 방식 |
|---|---|
| 프롬프트 버전 | 호출 전에 기록 <br> 컴파일은 텍스트와 두 이미지 템플릿 버전 포함 <br> Gemini 사용 시 해당 템플릿 버전 적용 |
| 재호출 횟수 | 최초 0, 종료 시 실제 값으로 갱신 <br> 502로 종료해도 반영 <br> SDK 재시도 횟수는 수집 안 함 |
| 엔딩 빈 배열 대체 | 로그에만 기록 <br> 추적과 출력 메타에서 제외 |
| 모델 폴백 | 미사용 |
| 호출 옵션과 스키마 버전 | 별도 기록 없음 <br> 코드 릴리스로 구분 |

### 7-3-3 오류 확인

입력 오류와 엔딩 빈 배열 대체는 별도 보고하지 않는다. 처리하지 않은 내부 예외는 별도 분류 없이 자동 보고한다.

| 적용 대상 | Sentry `feature` |
|---|---|
| 스토리라인 | `storyline_generation` |
| 컴파일 | `story_completion` |
| 인물 이미지 | `character_image_generation` |
| 썸네일 | `thumbnail_image_generation` |

<br>

| 오류 | `error_code` | 확인 대상과 조치 |
|---|---|---|
| 시간 초과 | `provider_timeout` | 호출 시간, 공급자 장애와 제한 시간 확인 |
| 호출량 제한 | `provider_rate_limited` | 공급자 호출량 한도와 동시 호출량 확인 |
| 공급자 요청 거부(400) | `provider_bad_request` | 오류 원문에서 거부된 인자 확인 <br> 해당 요청 인자와 모델 설정 수정 |
| 그 밖의 공급자 오류 | `provider_unavailable` | 공급자 장애 공지 확인 <br> 공급자 장애면 복구 대기 |
| 파싱과 형식 위반 | `invalid_ai_response` | Langfuse 출력과 검증 코드 대조 <br> 출력 위반은 프롬프트, 검증 오류는 코드 수정 |
| 인물 누락 지속 | `invalid_ai_response`, 경고 | 후보 번호로 출력과 입력 인물 대조 |
| 명세와 출력 변환 실패 | `schema_validation_failed` | 스택과 스키마 위반 필드 확인 <br> 명세 검증과 변환 코드 점검 |
| 이미지 로직 예외 | `unexpected_error` | 스택의 실패 위치 확인 <br> 해당 이미지 처리 코드 수정 |

<br>

### 7-3-4 지표

대시보드는 미구현이다. 운영 기록으로 집계하며 목표값은 운영 요구사항을 따른다. ([2-2 운영 요구사항](2-2-OPERATION-REQUIREMENTS.md))

| 지표 | 계산 | 자료 |
|---|---|---|
| 요청 수 | 기능별 추적 수 <br> 장르별 구분 가능 | Langfuse |
| 요청 실패율 | 502 또는 500 요청 수 / 전체 요청 수 | 백엔드 AI 호출 기록 |
| 오류 분포 | `error_code`별 보고 수 <br> 복구된 실패 포함 | Sentry |
| 재호출 분포 | 요청별 `retry_count` | 백엔드 AI 호출 기록, Langfuse |
| 인물 누락 빈도 | 인물 누락 경고 수 / 스토리라인 요청 수 | Sentry, Langfuse |
| 이미지 실패율 | 실패 이미지 수 / 시도한 이미지 수 <br> 인물 이미지와 썸네일 구분 | Langfuse 이미지 호출 |
| 처리 시간 | 요청 소요 시간의 백분위, 중앙값과 최댓값 <br> 백엔드 대기 한도 초과 건수 | Langfuse |
| 텍스트 비용 | 요청별 텍스트 호출 비용 합 | Langfuse 텍스트 호출 |
| 이미지 비용 | 요청별 인물 이미지와 썸네일 비용 합 | Langfuse 이미지 호출 |

<br>

**집계 조건**

| 항목 | 기준 |
|---|---|
| 오류 건수 | 개별 시도의 오류와 요청 전체의 실패 구분 |
| 모델 단가 | Langfuse 프로젝트에 등록 <br> 모델 변경 시 단가도 갱신 <br> AI 서버에서 비용 계산 안 함 |
| 이미지 비용 | 세부 사용량별 단가 적용 <br> 전체 사용량에 중복 적용 안 함 |
| 사용량 누락 | 출력이 없어 사용량을 받지 못한 호출은 비용에서 제외 <br> 집계액과 실제 청구액 차이 발생 가능 |

<br>

### 7-3-5 사용자 반응

사용자 반응 기록은 계획 단계다. 백엔드가 해당 생성 결과에 점수를 붙이며 점수 metadata에는 식별자만 넣는다. ([분석 명세 6-6-12 AI LLM 트레이싱과 선호 신호](../../spec/6-analytics.md))

`GOOD` 비율은 사용자 반응 지표이며 내용의 정답률이나 LLM 채점 점수로 사용하지 않는다.

| 반응 | 기록 대상 | 연결 방법 |
|---|---|---|
| 스토리라인 `GOOD`, `BAD` | 후보 3편을 만든 추적 | `request_id`로 조회 <br> `storyline_id`, `storyline_order`로 후보 구분 |
| 스토리라인 재생성 | 버린 이전 스토리라인 추적 | 이전 제작 결과에 점수 기록 |
| 시작 추천 입력의 노출과 선택 | 컴파일 추적 | 해당 생성 결과에 행동 점수 기록 |
| 컴파일 내용과 이미지 평가 | 없음 | 직접 평가 수집 없음 |

<br>

### 7-3-6 알림

일일 요약의 조회식과 메시지 형식은 기존 스킬을 따른다. ([daily-sentry-report](../../../../manyak-ai/.agents/skills/daily-sentry-report/SKILL.md))

| 항목 | 현재 기준 |
|---|---|
| 전달 | 매일 오전 10시(KST), 지난 24시간의 Sentry 오류를 슬랙에 요약 |
| 범위 | AI 서버, 백엔드와 웹의 Sentry 프로젝트 |
| 오류 없음 | 오류가 없다는 요약 전송 |
| 조회 실패 | 오류 없음과 구분해 조회 실패로 표시 |
| 실시간 알림 | 없음 |
| 알림 임계값, 측정 기간과 최소 건수 | 미정 |
| 담당과 대응 시간 | AI 담당자 <br> 대응 시간 미정 |

### 7-3-7 수집 조건과 실패 처리

원문은 Langfuse의 운영 추적에서만 수집한다. 사용자 입력은 태그와 metadata에서 제외하되 장르는 `genre:` 태그로 기록한다.

**1. 수집 범위**

| 데이터 | Langfuse | Sentry | 로그 |
|---|---|---|---|
| 입력, 프롬프트와 생성 출력 원문 | 기록 | 제외 | 제외 |
| 이미지 프롬프트 | 기록 | 제외 | 제외 |
| 이미지 바이너리 | 제외 <br> 형식과 바이트 수만 기록 | 제외 | 제외 |
| 공급자 오류 원문 | 제외 <br> 예외 타입만 기록 | 기록 | 제외 |
| 인물 이름 | 입력에만 포함 | 제외 <br> 누락 후보 번호만 기록 | 제외 |
| 인물 특징 태그 | 입력에만 포함 <br> 관측 태그에서 제외 | 제외 | 제외 |
| 기기 식별자 | 해시만 기록 | 제외 | 제외 |
| API 키 | 제외 | 제외 | 제외 |

<br>

**2. 활성화와 보존**

| 항목 | 조건 |
|---|---|
| Langfuse 활성화 | 키 설정, 일본 리전 주소, `prod` 환경을 모두 충족 |
| Sentry 활성화 | DSN 설정 시 활성화 |
| 저장 리전 | Langfuse 일본 리전 |
| 접근과 삭제 권한 | AI 담당자로 한정 |
| 원문 보존 | 수집일부터 1년 |
| 환경 분리 | Langfuse는 운영만 기록 <br> 로컬, 테스트와 실험 제외 |
| 활용 | 결과 점검, 원인 분석과 평가 자료 구성 <br> 자체 모델 학습에 사용 안 함 |
| 제외와 삭제 요청 | 해당 추적 삭제 <br> 평가 자료에서 제외 |

<br>

**3. 수집 실패**

관측 오류 로그에는 입력과 생성 원문을 넣지 않는다. 생성 처리에서 발생한 예외는 호출부로 전파한다. ([7-2-6 공통 오류 처리](7-2-TEST-CASES.md#7-2-6-공통-오류-처리))

| 상황 | 처리 |
|---|---|
| Langfuse 초기화 실패 | 관측 없이 서버 시작 |
| 추적 시작과 기록 실패 | 경고 로그 기록 <br> 생성 요청 처리 유지 |
| 서버 종료 | 남은 기록 전송 <br> 전송 실패 시 미전송 기록 유실 |
| 재전송 | SDK 배치 전송 사용 <br> 코드의 별도 재전송 없음 |
| 표본 추출 | 사용 안 함 <br> 운영 요청 전체 기록 |
