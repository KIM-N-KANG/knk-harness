# 2-1 유저 스토리

| 항목 | 값 |
|---|---|
| 적용 태스크 | 스토리라인 생성, 스토리 컴파일 |
| 버전 | 0.1 |

이 문서는 간편 제작 사용자가 AI가 만든 결과물에 거는 기대를 정리한다. ([1번 배경](1-BACKGROUND.md))

스토리라인 후보, 컴파일 결과, 인물 이미지와 썸네일로 나누어 기대와 어긋난 예를 적고, 기대에 어긋났을 때 사용자가 하는 일을 다룬다. 화면의 사용 흐름은 다루지 않는다. 품질, 시간과 비용의 운영 기준은 운영 요구사항에서 정한다. ([2-2 운영 요구사항](2-2-OPERATION-REQUIREMENTS.md))

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 간편 제작으로 스토리를 만들고 그 스토리로 채팅하는 사용자다. 회원과 게스트에게 적용하는 결과물 품질 기준은 같다.

AI가 만든 결과물을 사람이 대신 확인해 주는 단계는 없다. 사용자는 스토리라인 후보를 직접 보고 고르고, 컴파일이 끝나면 그 결과로 바로 채팅을 시작한다. 그래서 결과물이 기대에 어긋나면 사용자가 그 자리에서 알아차리고 이탈하거나 다시 만든다.

사용자가 AI에게서 받는 것은 스토리라인 후보와 컴파일 결과다. 후보를 보고 이야기의 방향을 고르고, 컴파일 결과로 채팅한다. 컴파일 결과에는 채팅의 바탕이 되는 스토리 설정과 인물 이미지, 썸네일이 들어 있다.

<br>

### 2-1-2 스토리라인 후보에 대한 기대

사용자는 태그와 인물 정보를 넣고 나서 후보 중 하나를 고르려고 한다. 후보를 고르는 사람의 기대는 다음과 같다.

| 기대 | 어긋난 예 |
|---|---|
| 내가 고른 태그의 장르와 분위기가 이야기에 드러난다 | 로맨스 태그를 골랐는데 연애 관계가 없는 모험담이 나온다 |
| 내가 적은 인물이 빠짐없이 나오고 이름과 성별이 바뀌지 않는다 | 두 명을 적었는데 한 명만 나오거나 여성으로 적은 인물이 남성으로 나온다 |
| 입력한 인물의 특징이 행동과 관계에 드러난다 | "냉정하다"라고 적었는데 이야기에서는 그 인물이 냉정하다는 말만 반복된다 |
| 후보끼리 전개가 뚜렷하게 달라서 고를 이유가 있다 | 세 편이 인물 이름만 다르고 사건이 같다 |
| 주인공인 내가 무엇을 하며 이야기에 들어가는지 보인다 | 주변 인물끼리만 사건을 벌이고 주인공은 구경만 한다 |
| 한 편만 읽어도 이야기가 어디로 가는지 알 수 있다 | 배경 설명만 있고 사건이 없거나, 끝이 어디인지 알 수 없다 |
| 인물 정보를 비워 두면 이야기에 맞는 인물을 AI가 대신 정해 준다 | 이름이 비어 있다고 "이름 없음"으로 나온다 |
| 추천 추가 정보가 해당 후보의 설정을 구체화한다 | 추천 정보가 후보와 상관없는 일반적인 문구다 |

<br>

### 2-1-3 컴파일 결과에 대한 기대

사용자는 후보 하나를 고르고 추가 정보를 붙인 뒤 완성된 스토리로 채팅을 시작하려고 한다. 채팅을 시작하는 사람의 기대는 다음과 같다.

| 기대 | 어긋난 예 |
|---|---|
| 내가 고른 스토리라인이 그대로 확장되고 다른 이야기로 바뀌지 않는다 | 후보에서 고른 사건이 사라지고 새 사건이 들어 있다 |
| 내가 쓴 추가 정보가 설정에 반영된다 | "학교가 배경"이라고 썼는데 회사가 배경이다 |
| 태그, 인물 이름과 성별은 후보 단계와 같다 | 컴파일 뒤 인물 이름이 달라진다 |
| 첫 화면부터 무슨 상황이고 내가 누구인지 알 수 있다 | 시작 장면이 없거나 주인공이 누구인지 설명이 없다 |
| 처음 고를 행동이 상황에 맞고 서로 다르다 | 첫 선택지가 셋 다 "말을 건다"다 |
| 주변 인물마다 성격, 말투와 나를 대하는 태도가 달라서 채팅에서 구분된다 | 모든 인물이 같은 말투로 말한다 |
| 이야기가 어디로 흘러가고 어떻게 끝날 수 있는지 방향이 있다 | 사건이 없어 채팅이 잡담으로만 이어진다 |
| 제목과 소개만 봐도 내 스토리라는 것을 알 수 있다 | 제목이 장르 이름이거나 소개가 후보와 다른 이야기다 |
| 결과가 기다릴 만한 시간 안에 나온다 | 화면이 오래 멈춰 있어 실패한 줄 알고 나간다 |
| 완성이라고 나온 스토리는 곧바로 채팅할 수 있다 | 완성 표시 뒤 채팅에 들어가면 설정이 비어 있다 |

<br>

### 2-1-4 인물 이미지와 썸네일에 대한 기대

| 기대 | 어긋난 예 |
|---|---|
| 인물 이미지가 설정의 외형과 성별에 맞는다 | 은발이라고 적힌 인물이 검은 머리로 나온다 |
| 인물 이미지는 채팅에서 누가 말하는지 알아보게 해 준다 | 두 인물의 이미지가 구분되지 않는다 |
| 썸네일은 목록에서 이 스토리의 장르와 분위기를 짐작하게 한다 | 공포 스토리의 썸네일이 밝은 학원물처럼 보인다 |
| 인물 이미지나 썸네일 생성에 실패해도 완성된 스토리로 채팅할 수 있다 | 이미지 생성 실패 때문에 스토리를 사용할 수 없다 |
| 생성된 이미지는 해당 인물에게 붙고, 이미지가 없으면 다른 그림으로 대체하지 않는다 | 다른 인물의 그림이 그 인물에게 붙는다 |

<br>

### 2-1-5 기대에 어긋났을 때 사용자가 하는 일

결과물이 기대에 어긋났을 때 사용자가 할 수 있는 일은 단계마다 다르다.

- 스토리라인 후보가 마음에 들지 않으면 사용자는 후보를 평가하고 다시 생성한다.
- 다시 생성해도 나아지지 않으면 사용자는 태그와 인물 정보를 바꾸거나 제작을 포기한다.
- 컴파일 결과가 마음에 들지 않으면 사용자는 그 스토리를 버리고 새로 제작한다.
- 컴파일 결과의 일부를 고치거나 다시 컴파일하는 방법은 없다.

단계마다 결과가 마음에 들지 않을 때 드는 부담이 다르다. 스토리라인 후보는 고르기 전이라 아쉬우면 다시 생성할 수 있다. 컴파일 결과가 마음에 들지 않으면 스토리를 새로 제작해야 한다. 회원은 제작에 이프도 지불하므로, 결과가 기대에 어긋나면 불만이나 이탈로 이어질 수 있다.
