# 2-1 유저 스토리

| 항목 | 값 |
|---|---|
| 적용 태스크 | 스토리라인 생성, 스토리 컴파일 |
| 버전 | 0.1 |

본 문서는 ([1 배경](1-BACKGROUND.md))에서 정의한 목적을 바탕으로 사용자가 AI 결과에 기대하는 바를 구체화한다.

먼저 결과를 사용하는 사람이 누구이며, 후보 선택과 채팅에 결과를 어떻게 사용하는지 설명한다. 스토리라인, 스토리 설정과 이미지에 기대하는 품질을 문제 사례와 함께 정리하고, 생성 대기 시간과 제작 비용에 대한 기대를 구분한다.

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 간편 제작으로 스토리를 만들고 그 스토리로 채팅하는 사용자(고객)이다. 회원과 게스트에게 적용하는 결과물 품질 기준은 같다.

사용자가 AI에게서 받는 것은 스토리라인 후보와 컴파일 결과다. 후보를 보고 이야기의 방향을 고르고, 컴파일 결과로 채팅한다. 컴파일 결과에는 채팅의 바탕이 되는 스토리 설정과 인물 이미지, 썸네일이 들어 있다.

<br>

### 2-1-2 품질에 대한 기대

#### 스토리라인

사용자는 태그와 인물 정보를 넣고 나서 스토리라인 중 하나를 고른다.

| 기대 | 문제 사례 |
|---|---|
| 내가 고른 태그의 장르와 분위기가 이야기에 드러남 | 로맨스 태그를 골랐는데 연애 관계가 없는 모험담이 나옴 |
| 내가 적은 인물이 빠짐없이 나오고 이름과 성별이 바뀌지 않음 | 두 명을 적었는데 한 명만 나오거나 여성으로 적은 인물이 남성으로 나옴 |
| 입력한 인물의 특징이 행동 및 관계에 드러남 | "냉정하다"라고 적었는데 이야기에서는 그 인물이 냉정하다는 말만 반복됨 |
| 후보끼리 전개가 뚜렷하게 달라서 고를 이유가 있음 | 세 편이 인물 이름만 다르고 사건이 같음 |
| 주인공인 내가 무엇을 하며 이야기에 들어가는지 보임 | 주변 인물끼리만 사건을 벌이고 주인공은 구경만 함 |
| 한 편만 읽어도 이야기가 어디로 가는지 알 수 있음 | 배경 설명만 있고 사건이 없거나, 끝이 어디인지 알 수 없음 |
| 인물 정보를 비워 두면 이야기에 맞는 인물을 AI가 대신 정해 줌 | 이름이 비어 있다고 "이름 없음"으로 나옴 |
| 추천 추가 정보가 해당 후보의 설정을 구체화함 | 추천 정보가 후보와 상관없는 일반적인 문구임 |

<br>

#### 컴파일 결과

사용자는 스토리라인을 하나 고르고, 추가 정보를 붙인 뒤 완성된 스토리로 채팅을 시작한다.

| 기대 | 문제 사례 |
|---|---|
| 내가 고른 스토리라인이 그대로 확장되고 다른 이야기로 바뀌지 않음 | 후보에서 고른 사건이 사라지고 새 사건이 들어 있음 |
| 내가 쓴 추가 정보가 설정에 반영됨 | "학교가 배경"이라고 썼는데 회사가 배경임 |
| 태그, 인물 이름과 성별은 후보 단계와 같음 | 컴파일 뒤 인물 이름이 달라짐 |
| 첫 화면부터 무슨 상황이고 내가 누구인지 알 수 있음 | 시작 장면이 없거나 주인공이 누구인지 설명이 없음 |
| 처음 고를 행동이 상황에 맞고 서로 다름 | 첫 선택지가 셋 다 "말을 건다"임 |
| 주변 인물마다 성격, 말투와 나를 대하는 태도가 달라서 채팅에서 구분됨 | 모든 인물이 같은 말투로 말함 |
| 이야기가 어디로 흘러가고 어떻게 끝날 수 있는지 방향이 있음 | 사건이 없어 채팅이 잡담으로만 이어짐 |
| 제목과 소개만 봐도 내 스토리라는 것을 알 수 있음 | 제목이 장르 이름이거나 소개가 후보와 다른 이야기임 |
| 완성이라고 나온 스토리는 곧바로 채팅할 수 있음 | 완성 표시 뒤 채팅에 들어가면 설정이 비어 있음 |

<br>

#### 인물 이미지와 썸네일
컴파일 과정에서 생성되는 이미지로, 사용자가 채팅 할 때 출력된다.

| 기대 | 문제 사례 |
|---|---|
| 인물 이미지가 설정의 외형과 성별에 맞음 | 은발이라고 적힌 인물이 검은 머리로 나옴 |
| 인물 이미지는 채팅에서 누가 말하는지 알아보게 해 줌 | 두 인물의 이미지가 구분되지 않음 |
| 썸네일은 목록에서 이 스토리의 장르와 분위기를 짐작하게 함 | 공포 스토리의 썸네일이 밝은 학원물처럼 보임 |
| 인물 이미지나 썸네일 생성에 실패해도 완성된 스토리로 채팅할 수 있음 | 이미지 생성 실패 때문에 스토리를 사용할 수 없음 |
| 생성된 이미지는 해당 인물에게 붙고, 이미지가 없으면 다른 그림으로 대체하지 않음 | 다른 인물의 그림이 그 인물에게 붙음 |

<br>

### 2-1-3 시간에 대한 기대

사용자는 후보를 고르고 채팅을 시작하기까지 오래 기다리지 않기를 기대한다.

| 기대 | 문제 사례 |
|---|---|
| 스토리라인 후보가 기다릴 만한 시간 안에 나옴 | 후보가 나오기까지 오래 걸려 제작을 포기함 |
| 후보를 다시 생성할 때도 오래 기다리지 않고 비교를 이어갈 수 있음 | 재생성할 때마다 대기가 길어 후보 선택을 포기함 |
| 컴파일이 기다릴 만한 시간 안에 끝나 채팅을 시작할 수 있음 | 생성이 오래 걸려 실패한 줄 알고 나감 |

<br>

### 2-1-4 비용에 대한 기대

로그인한 사용자(회원)는 제작 비용이 부담스럽지 않고, 지불한 비용에 맞는 결과를 기대한다.

| 기대 | 문제 사례 |
|---|---|
| 이프를 지불해 제작한 스토리로 채팅을 시작할 수 있음 | 제작에 이프를 썼지만 결과를 사용할 수 없어 채팅을 시작하지 못함 |
| 부담할 만한 비용으로 스토리를 제작할 수 있음 | 제작에 필요한 이프가 너무 비싸서 제작을 포기함 |
