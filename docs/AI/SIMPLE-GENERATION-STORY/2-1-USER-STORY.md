# 2-1 유저 스토리

본 문서는 ([1 배경](1-BACKGROUND.md))에서 정의한 목적을 바탕으로 사용자가 AI 결과에 기대하는 바를 구체화한다.

먼저 결과를 사용하는 사람이 누구이며, 후보 선택과 채팅에 결과를 어떻게 사용하는지 설명한다. 스토리라인, 스토리 설정과 이미지에 기대하는 성능을 정리한다.

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 간편 제작으로 스토리를 만들고 그 스토리로 채팅하는 사용자(고객)이다. 회원과 게스트에게 적용하는 결과물 성능 기준은 같다.

사용자가 AI에게서 받는 것은 스토리라인 후보와 컴파일 결과다. 후보를 보고 이야기의 방향을 고르고, 컴파일 결과로 채팅한다. 컴파일 결과에는 채팅의 바탕이 되는 스토리 설정과 인물 이미지, 썸네일이 들어 있다.

<br>

### 2-1-2 성능에 대한 기대

#### 스토리라인

사용자는 태그와 인물 정보를 넣고 나서 스토리라인 중 하나를 고른다.

| 기대 |
|---|
| 내가 고른 태그의 장르와 분위기가 이야기에 드러남 |
| 내가 적은 인물이 빠짐없이 나오고 이름과 성별이 바뀌지 않음 |
| 입력한 인물의 특징이 행동 및 관계에 드러남 |
| 후보끼리 전개가 뚜렷하게 달라서 고를 이유가 있음 |
| 주인공인 내가 무엇을 하며 이야기에 들어가는지 보임 |
| 한 편만 읽어도 이야기가 어디로 가는지 알 수 있음 |
| 인물 정보를 비워 두면 이야기에 맞는 인물을 AI가 대신 정해 줌 |
| 추천 추가 정보가 해당 후보의 설정을 구체화함 |

<br>

#### 컴파일 결과

사용자는 스토리라인을 하나 고르고, 추가 정보를 붙인 뒤 완성된 스토리로 채팅을 시작한다.

| 기대 |
|---|
| 내가 고른 스토리라인이 그대로 확장되고 다른 이야기로 바뀌지 않음 |
| 내가 쓴 추가 정보가 설정에 반영됨 |
| 태그, 인물 이름과 성별은 후보 단계와 같음 |
| 첫 화면부터 무슨 상황이고 내가 누구인지 알 수 있음 |
| 처음 고를 행동이 상황에 맞고 서로 다름 |
| 주변 인물마다 성격, 말투와 나를 대하는 태도가 달라서 채팅에서 구분됨 |
| 이야기가 어디로 흘러가고 어떻게 끝날 수 있는지 방향이 있음 |
| 제목과 소개만 봐도 내 스토리라는 것을 알 수 있음 |
| 완성이라고 나온 스토리는 곧바로 채팅할 수 있음 |

<br>

#### 인물 이미지와 썸네일
컴파일 과정에서 생성되는 이미지로, 사용자가 채팅 할 때 출력된다.

| 기대 |
|---|
| 인물 이미지가 설정의 외형과 성별에 맞음 |
| 인물 이미지는 채팅에서 누가 말하는지 알아보게 해 줌 |
| 썸네일은 목록에서 이 스토리의 장르와 분위기를 짐작하게 함 |
| 인물 이미지나 썸네일 생성에 실패해도 완성된 스토리로 채팅할 수 있음 |
| 생성된 이미지는 해당 인물에게 붙고, 이미지가 없으면 다른 그림으로 대체하지 않음 |
