# 1. 배경

본 문서는 간편 제작이 해결하려는 문제와 AI에 맡길 역할을 설명한다.

마냑이 어떤 서비스인지, 사용자가 스토리를 만들 때 어떤 어려움을 겪는지 설명한다. 간편 제작에서 사용자와 AI가 맡는 역할, 해결하려는 문제의 영향과 공통 용어를 정리한다.

<br>

### 1-1 도메인

AI 인터랙티브 채팅은 사용자가 만든 캐릭터와 세계관을 바탕으로 AI가 인물을 연기하고, 사용자가 대화로 이야기를 진행하는 서비스 영역이다. 국내에서는 제타(스캐터랩), 크랙(뤼튼테크놀로지스), 케이브덕(워프스페이스), 베이비챗이 이 영역의 대표 서비스이다.

이 서비스들은 다음 구조를 공유한다.

| 구성 | 내용 |
|---|---|
| 제작 | 사용자가 캐릭터의 이름, 성격, 세계관, 관계 설정을 직접 써서 등록함 |
| 탐색 | 다른 사용자가 만든 캐릭터를 추천, 인기, 장르별로 찾아 채팅함 |
| 채팅 | 사용자가 주인공을, AI가 캐릭터를 연기함 <br> 메신저형 단답이 아니라 소설에 가까운 지문과 묘사를 주고받음 |
| 재화 | 채팅과 제작에 코인이나 구독 같은 서비스 내 재화를 씀 |

<br>

### 1-2 서비스 배경

**마냑의 포지션**

마냑은 사용자가 스토리와 세계관을 만들고, 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스이다.

마냑은 같은 영역 안에서 두 가지가 다르다.
- 콘텐츠의 단위가 캐릭터가 아니라 엔딩과 주요 사건을 가진 스토리이다.
- 제작을 사용자가 직접 쓰는 방식이 아니라 방향만 정하면 AI가 채우는 방식으로 낮췄다.

<br>

**타겟**

이용 대상은 만 14세 이상이며, 마냑은 전연령 콘텐츠만 제공한다.

| 구분 | 사용자 |
|---|---|
| 핵심 | 스토리 제작과 세계관 구성에 어려움을 느끼는 AI 인터랙티브 서비스 사용자 |
| 보조 | AI 캐릭터챗, 웹소설, 웹툰, 인터랙티브 콘텐츠를 즐기는 기존 콘텐츠 소비자 |

<br>

### 1-3 현재 업무와 문제

사용자가 자신만의 이야기를 만들려면 세계관, 등장인물, 주인공 역할, 전개 규칙과 시작 상황을 정해야 한다. 직접 입력형 제작 방식을 사용하는 유사 서비스와 마냑의 일반 제작은 이런 항목을 빈칸으로 제시하고 사용자가 모두 작성하게 한다. 사용자가 이야기를 세밀하게 통제할 수 있지만, 무엇을 어떻게 써야 할지 처음부터 결정해야 하므로 제작 부담이 크다.

위와 같은 이유로 마냑은 스토리 간편 제작 기능(이하 간편 제작)을 제공하고자 한다. 간편 제작에서는 사용자가 이야기의 방향만 정하고 AI가 나머지 설정을 만든다.

<br>

**서비스가 주는 가치**

기존 웹소설은 작가가 집필한 완성된 콘텐츠를 읽는 수동적 소비 경험이다. 마냑은 사용자가 채팅을 하면서 하나의 웹소설을 만들었다는 느낌을 받는 것을 목표로 한다. 이를 위해 스토리에는 엔딩과 그 엔딩으로 방향을 잡아 주는 주요 사건이 있어 대화가 서사의 뼈대를 따라 흐른다. 사용자는 뼈대를 벗어나 자유롭게 이야기를 이어갈 수 있고, 엔딩 조건을 충족하면 완결의 경험을 얻는다.

간편 제작은 직접 작성할 항목을 줄이지만, 태그, 인물 정보와 짧은 추가 정보만으로는 채팅할 만한 세계관과 인물이 만들어지지 않는다. 사용자가 쓰지 않은 나머지를 AI가 채워 채팅할 수 있는 스토리로 완성하는 것이 본 태스크이다.

<br>

### 1-4 간편 제작의 흐름과 주체

**제작 방식**

스토리를 만드는 방식은 두 가지다.

| 방식 | 사용자가 하는 일 | 특징 |
|---|---|---|
| 간편 제작 | 태그 선택, 스토리라인 선택, 추가 정보 입력 | 이야기의 방향만 정하고 나머지는 AI가 만듦 |
| 일반 제작 | 기본 정보, 스토리 설정, 시작 설정 등을 폼에 직접 입력 | 세밀하게 통제할 수 있으나 모든 항목을 직접 씀 |

본 태스크는 간편 제작에서 AI가 맡는 생성만 다룬다.

<br>

**채팅과 스토리의 관계**

채팅에서 사용자는 주인공을 1인칭으로 연기하고 AI가 주변 인물을 연기한다. AI는 스토리에 담긴 설정을 바탕으로 인물을 연기하고 이야기를 전개하므로, 채팅의 품질은 스토리가 채팅할 수 있게 구성되어 있는지에 좌우된다. 스토리는 다음 요소로 구성된다.

| 요소 | 내용 | 채팅에서의 쓰임 |
|---|---|---|
| 스토리 설정 | 세계관, 등장인물, 주인공, 규칙 | 매 턴의 배경과 인물 연기의 기준 |
| 시작 설정 | 상황 이름, 시작 상황, 프롤로그 | 채팅의 첫 장면 |
| 주요 사건 | 엔딩을 향해 이야기의 방향을 잡아 주는 사건 | 이야기의 진행 판단 |
| 엔딩 | 이름, 달성 조건, 에필로그 가이드 | 이야기의 끝 판정 |
| 썸네일, 인물 이미지 | 스토리와 주변 인물을 나타내는 이미지 | 스토리 소개와 채팅 화면에 표시 |

<br>

간편 제작은 다음 순서로 진행한다.

1. 장르 태그와 인물 정보를 입력한다.
2. AI가 생성한 스토리라인 후보 중 하나를 선택한다.
3. 선택한 스토리라인에 추가 정보를 붙인다.
4. AI가 스토리를 컴파일하면 제작이 완료된다.

이 흐름에서 AI는 스토리라인 후보, 스토리 설정, 인물 이미지와 썸네일을 만든다. 무엇을 고를지와 다시 만들지는 사용자가 정한다. 컴파일 결과는 사람이 검수하지 않으며, 결과가 마음에 들지 않으면 사용자가 새 스토리를 제작한다.

이 흐름에 관여하는 주체는 다음과 같다.

| 주체 | 누구인가 | 이 태스크에서 하는 일 |
|---|---|---|
| 사용자 | 스토리 제작과 세계관 구성에 어려움을 느끼는 AI 인터랙티브 서비스 이용자 <br> 회원과 게스트로 나뉨 | 태그와 인물 정보를 고르고, 후보를 선택하고, 추가 정보를 쓰고, 결과로 채팅함 |
| 회원 | 로그인한 사용자 | 이프를 내고 스토리를 제작함 |
| 게스트 | 로그인 없이 쓰는 사용자 | 제한된 횟수만 제작해 보고 회원 가입을 결정함 |
| 클라이언트 | 웹과 안드로이드 앱 | 사용자의 입력을 받고 결과를 보여줌 |
| 백엔드 | manyak-server | 사용자와 스토리를 관리하고 AI 서버에 생성을 맡김 |
| AI 담당자 | 프롬프트, 모델, 평가를 맡는 팀 구성원 | 품질과 비용을 보고 프롬프트와 모델을 바꿈 |

<br>

### 1-5 공통 용어

| 용어 | 뜻 |
|---|---|
| (스토리) 간편 제작 | 태그 선택, 스토리라인 선택, 추가 정보 입력으로 스토리를 만드는 제작 방식 |
| 인물 정보 | 사용자가 입력하는 인물 한 명의 이름, 성별, 특징 <br> 비우면 AI가 이야기에 맞게 정함 |
| 주인공 | 사용자가 1인칭으로 연기하는 인물 |
| 주변 인물 | AI가 연기하는 인물 |
| 인물 카드 | 컴파일이 만드는 주변 인물별 설정 <br> 성격, 말투, 동기, 주인공을 대하는 태도와 외형을 담음 |
| 스토리라인 | AI가 생성하는 이야기 전개 방향 후보 |
| 추가 정보 | 사용자가 선택한 스토리라인에 붙이는 보강 정보 |
| 컴파일 | 선택한 스토리라인, 추가 정보와 태그를 스토리 설정으로 확장하는 AI 작업 |
| 스토리 설정 | 컴파일이 만드는 세계관, 등장인물, 주인공, 규칙 설정 <br> 채팅의 바탕이 됨 |
| 인물 이미지 | 주변 인물을 나타내는 기본 이미지 |
| 썸네일 | 스토리를 대표하는 이미지 |
