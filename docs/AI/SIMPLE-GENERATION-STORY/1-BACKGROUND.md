# 1. 배경

| 항목 | 값 |
|---|---|
| 적용 태스크 | 스토리라인 생성, 스토리 컴파일 |
| 버전 | 0.1 |

이 문서는 간편 제작 스토리 생성 태스크의 배경을 정리한다. 현재 업무와 문제, 간편 제작의 흐름과 주체, 태스크의 목적과 영향, 공통 용어를 다룬다. 사용자와 운영의 요구사항은 유저 스토리와 운영 요구사항에서 정한다. ([2-1 유저 스토리](2-1-USER-STORY.md), [2-2 운영 요구사항](2-2-OPERATION-REQUIREMENTS.md))

<br>

### 1-1 현재 업무와 문제

AI 채팅형 스토리 서비스에서 사용자가 자신만의 이야기를 만들려면 세계관, 등장인물, 주인공 역할, 전개 규칙과 시작 상황을 정해야 한다. 직접 입력형 제작 방식을 사용하는 유사 서비스에서는 이런 항목을 빈칸으로 제시하고 사용자가 모두 작성하게 한다. 사용자가 이야기를 세밀하게 통제할 수 있지만, 무엇을 어떻게 써야 할지 처음부터 결정해야 하므로 제작 부담이 크다.

위와 같은 이유로 마냑은 스토리 간편 제작 기능(이하 간편 제작)을 제공한다. 간편 제작에서는 사용자가 이야기의 방향만 정하고 AI가 나머지 설정을 만든다.

간편 제작은 직접 작성할 항목을 줄이지만, 태그, 인물 정보와 짧은 추가 정보만으로는 채팅할 만한 세계관과 인물이 만들어지지 않는다. 사용자가 쓰지 않은 나머지를 AI가 채워 채팅할 수 있는 스토리로 완성하는 일이 이 태스크다.

<br>

### 1-2 간편 제작의 흐름과 주체

간편 제작은 다음 순서로 진행한다.

1. 장르 태그와 인물 정보를 입력한다.
2. AI가 생성한 스토리라인 후보 중 하나를 선택한다.
3. 선택한 스토리라인에 추가 정보를 붙인다.
4. AI가 스토리를 컴파일하면 제작이 완료된다.

이 흐름에서 AI는 스토리라인 후보, 스토리 설정, 인물 이미지와 썸네일을 만든다. 무엇을 고를지와 다시 만들지는 사용자가 정한다. 컴파일 결과는 사람이 검수하지 않으며, 결과가 마음에 들지 않으면 사용자가 새 스토리를 제작한다.

이 흐름에 관여하는 주체는 다음과 같다.

| 주체 | 누구인가 | 이 태스크에서 하는 일 |
|---|---|---|
| 사용자 | 스토리 제작과 세계관 구성에 어려움을 느끼는 AI 인터랙티브 서비스 이용자. 회원과 게스트로 나뉜다 | 태그와 인물 정보를 고르고, 후보를 선택하고, 추가 정보를 쓰고, 결과로 채팅한다 |
| 회원 | 로그인한 사용자 | 이프를 내고 스토리를 제작한다 |
| 게스트 | 로그인 없이 쓰는 사용자 | 제한된 횟수만 제작해 보고 회원 가입을 결정한다 |
| 클라이언트 | 웹과 안드로이드 앱 | 사용자의 입력을 받고 결과를 보여준다 |
| 백엔드 | manyak-server | 사용자와 스토리를 관리하고 AI 서버에 생성을 맡긴다 |
| AI 담당자 | 프롬프트, 모델, 평가를 맡는 팀 구성원 | 품질과 비용을 보고 프롬프트와 모델을 바꾼다 |

<br>

### 1-3 목적과 영향

이 태스크의 목적은 사용자가 태그, 인물 정보와 짧은 추가 정보만으로 채팅에 사용할 스토리를 완성하도록 돕는 것이다.

이 태스크는 돈과 이탈에 직접 걸려 있다.
- 스토리를 만들지 못한 사용자는 채팅을 시작하지 못하므로 제작 단계의 이탈은 서비스 전체의 이탈이다.
- 스토리 제작은 사용자가 이프를 쓰는 지점이라 결과가 나쁘면 돈을 낸 사용자의 불만으로 이어진다.
- AI 생성은 쓸 때마다 비용이 들기 때문에 품질과 비용을 같이 관리하지 않으면 쓸수록 손해가 난다.
- 생성이 느리거나 실패하면 사용자는 기다리다가 제작을 포기하고 이탈한다.

<br>

### 1-4 공통 용어

아래 표는 이 태스크를 이해하는 데 필요한 용어만 요약한다.

| 용어 | 뜻 |
|---|---|
| (스토리) 간편 제작 | 태그 선택, 스토리라인 선택, 추가 정보 입력으로 스토리를 만드는 제작 방식 |
| 인물 정보 | 사용자가 입력하는 인물 한 명의 이름, 성별, 특징. 비우면 AI가 이야기에 맞게 정한다 |
| 주인공 | 사용자가 1인칭으로 연기하는 인물 |
| 주변 인물 | AI가 연기하는 인물 |
| 인물 카드 | 컴파일이 만드는 주변 인물별 설정. 성격, 말투, 동기, 주인공을 대하는 태도와 외형을 담는다 |
| 스토리라인 | AI가 생성하는 이야기 전개 방향 후보 |
| 추가 정보 | 사용자가 선택한 스토리라인에 붙이는 보강 정보 |
| 컴파일 | 선택한 스토리라인, 추가 정보와 태그를 스토리 설정으로 확장하는 AI 작업 |
| 스토리 설정 | 컴파일이 만드는 세계관, 등장인물, 주인공, 규칙 설정. 채팅의 바탕이 된다 |
| 인물 이미지 | 주변 인물을 나타내는 기본 이미지 |
| 썸네일 | 스토리를 대표하는 이미지 |
