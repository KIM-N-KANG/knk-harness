# 2-2 운영 요구사항

| 항목 | 값 |
|---|---|
| 적용 태스크 | 스토리라인 생성, 스토리 컴파일 |
| 버전 | 0.1 |

이 문서는 AI 담당자와 제품 정책 담당자의 운영 요구사항을 품질, 시간, 비용으로 나누어 정리한다. AI는 사람의 검수 없이도 유저 스토리의 기대에 맞는 결과를 만들어야 한다. ([2-1 유저 스토리](2-1-USER-STORY.md))

생성 시간과 비용도 정해진 한도를 지켜야 한다. 합의된 값이 없는 항목은 미정으로 둔다.

<br>

### 2-2-1 품질

| 단계 | 실패 | 품질이 낮은 결과 |
|---|---|---|
| 스토리라인 생성 | 사용자는 이프를 쓰지 않고 다시 요청할 수 있다 | 사용자가 후보를 평가하고 다시 생성한다 |
| 컴파일 | 기다린 뒤 실패를 겪는다. 회원은 이프도 지불하므로 불만이나 이탈로 이어질 수 있다 | 사용자는 검수되지 않은 결과로 채팅하다가 문제를 알아차린다 |

결과가 나오지 않으면 실패로 본다. 결과가 나와도 사용자 기대에 어긋나면 품질이 낮은 결과로 본다. 사용자에게 미치는 영향은 단계마다 다르다.

단계별로 결과를 허용하거나 실패로 처리할 기준은 다음과 같다.

- 스토리라인 생성은 품질 저하보다 생성 실패를 줄이는 데 우선순위를 둔다.
- 컴파일 결과로 채팅할 수 없으면 실패로 처리한다.
- 채팅에 필요한 설정과 인물이 빠진 컴파일 결과는 허용하지 않는다.
- 인물 이미지나 썸네일 생성에 실패해도 필수 스토리 설정을 갖췄으면 컴파일 결과를 반환한다. 이미지 실패는 컴파일 실패와 구분한다.
- 필수 항목과 누락을 허용하는 항목은 태스크 정의에서 정한다. ([3-TASK-DEFINITION.md](3-TASK-DEFINITION.md))

| 기준 | 측정 방법 | 목표값 |
|---|---|---|
| 입력한 인물의 이름과 성별이 결과에 그대로 남는다 | 입력과 결과를 비교한 비율 | 미정 |
| 컴파일 결과가 채팅에 필요한 설정을 모두 갖춘다 | 필수 항목을 모두 갖춘 결과의 비율 | 미정 |
| 인물 이미지와 썸네일의 생성 성공률 | 이미지 생성 시도 중 성공한 비율 | 미정 |
| 스토리라인 후보가 사용자 마음에 든다 | 사용자가 남긴 평가 중 좋음의 비율 | 미정 |
| 후보 중에 고를 만한 것이 있다 | 사용자가 다시 생성한 비율 | 미정 |
| 이야기가 재미있다 | 미정 | 미정 |
| 태그의 장르와 분위기가 이야기에 드러난다 | 미정 | 미정 |
| 인물의 특징이 행동에 드러난다 | 미정 | 미정 |
| 후보끼리 전개가 뚜렷하게 다르다 | 미정 | 미정 |
| 인물 이미지가 설정의 외형과 맞는다 | 미정 | 미정 |

### 2-2-2 시간

| 항목 | 스토리라인 생성 | 컴파일 |
|---|---|---|
| 백엔드 응답 대기 제한 시간 | 90초 | 180초 |
| 사용자 대기 시간 목표 | 미정 | 미정 |
| 처리해야 할 동시 요청 수 | 미정 | 미정 |

백엔드는 AI 서버에 동기로 요청한다. 제한 시간 안에 응답이 없으면 실패로 처리하고 사용자에게 오류를 보여준다. 응답 시간은 백엔드가 요청을 보낸 시점부터 응답을 받은 시점까지 측정한다.

재시도와 대기에 대한 요구는 다음과 같다.

- 백엔드는 AI 호출을 자동으로 재시도하지 않는다.
- 90초와 180초는 백엔드의 응답 대기 제한 시간이다. AI 서버의 최초 생성과 보완 호출은 각각 별도의 제한 시간을 사용하므로 전체 실행 시간은 백엔드의 대기 제한 시간을 넘을 수 있다.
- 백엔드 연결이 끝나도 진행 중인 모델 호출은 취소되지 않는다.
- 요청을 큐에 쌓지 않으므로 큐 대기 시간 제한은 적용하지 않는다.

<br>

### 2-2-3 비용

| 항목 | 스토리라인 생성 | 컴파일 |
|---|---|---|
| 1건당 비용 상한 | 미정 | 미정 |
| 1건당 비용 측정 방법 | 미정 | 미정 |

비용은 스토리라인 요청과 컴파일 요청별로 1건당 측정한다. 컴파일 비용에는 스토리 설정, 인물 이미지와 썸네일의 생성 비용을 모두 포함한다.

사용자의 이프 지불과 이용 한도는 제품 정책을 따른다. 회원은 컴파일마다 이프를 지불한다. 게스트는 스토리라인 생성과 재생성을 합쳐 최대 5회, 컴파일은 최대 1회 이용할 수 있다.
