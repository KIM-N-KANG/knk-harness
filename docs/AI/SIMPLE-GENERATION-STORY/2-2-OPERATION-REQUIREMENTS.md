# 2-2 운영 요구사항

| 항목 | 값 |
|---|---|
| 적용 태스크 | 스토리라인 생성, 스토리 컴파일 |
| 버전 | 0.1 |

본 문서는 ([2-1 유저 스토리](2-1-USER-STORY.md))에서 정의한 사용자 기대를 충족하기 위한 품질, 처리 시간과 비용의 요구 수준을 정한다.

생성 실패와 낮은 품질이 사용자에게 미치는 영향을 구분하고, 어떤 결과를 허용할지와 무엇을 우선할지 정한다. 이를 바탕으로 품질 지표의 목표값, 처리 시간과 동시 요청 수, 요청 한 건의 생성 비용 한도를 정의한다. 합의하지 않은 값은 미정으로 남긴다.

<br>

### 2-2-1 태스크의 유저

운영 관점에서 이 태스크의 요구사항을 정하고 결과를 확인하는 주체는 AI 담당자와 제품 정책 담당자다. 이들은 사용자가 기대하는 결과를 제공하면서 품질, 처리 시간과 생성 비용을 운영 가능한 수준으로 유지해야 한다. 스토리를 제작하고 채팅하는 사용자의 기대는 [2-1 유저 스토리](2-1-USER-STORY.md)에서 다룬다.

<br>

### 2-2-2 품질

**실패와 낮은 품질의 정의**

| 단계 | 실패 (결과 없음) | 낮은 품질 (사용자 기대 미충족) |
|---|---|---|
| 스토리라인 생성 | 사용자는 이프를 쓰지 않고 다시 요청할 수 있음 | 사용자가 후보를 평가하고 다시 생성함 |
| 컴파일 | 기다린 뒤 실패를 겪음 <br> 회원은 이프도 지불하므로 불만이나 이탈로 이어질 수 있음 | 사용자는 검수되지 않은 결과로 채팅하다가 문제를 알아차림 |

<br>

**우선순위와 허용 기준**

| 대상 | 기준 |
|---|---|
| 스토리라인 생성 | 품질 저하보다 생성 실패를 줄이는 것을 우선함 |
| 스토리 컴파일 | 채팅에 필요한 설정과 인물의 누락을 허용하지 않음 <br> 채팅할 수 없는 결과는 실패로 처리함 |
| 인물 이미지·썸네일 | 이미지 생성에 실패해도 필수 스토리 설정을 갖췄으면 결과를 반환함 <br> 이미지 실패는 컴파일 실패와 구분함 |

<br>

**품질 지표와 목표값**

| 기준 | 측정 방법 | 목표값 |
|---|---|---|
| 입력한 인물의 이름과 성별이 결과에 그대로 남음 | 입력과 결과를 비교한 비율 | 미정 |
| 컴파일 결과가 채팅에 필요한 설정을 모두 갖춤 | 필수 항목을 모두 갖춘 결과의 비율 | 미정 |
| 인물 이미지와 썸네일의 생성 성공률 | 이미지 생성 시도 중 성공한 비율 | 미정 |
| 스토리라인 후보가 사용자 마음에 듦 | 사용자가 남긴 평가 중 좋음의 비율 | 미정 |
| 후보 중에 고를 만한 것이 있음 | 사용자가 다시 생성한 비율 | 미정 |
| 이야기가 재미있음 | 미정 | 미정 |
| 태그의 장르와 분위기가 이야기에 드러남 | 미정 | 미정 |
| 인물의 특징이 행동에 드러남 | 미정 | 미정 |
| 후보끼리 전개가 뚜렷하게 다름 | 미정 | 미정 |
| 인물 이미지가 설정의 외형과 맞음 | 미정 | 미정 |

<br>

### 2-2-3 시간

| 항목 | 스토리라인 생성 | 컴파일 |
|---|---|---|
| 처리 시간 상한 | 미정 | 미정 |
| 사용자 대기 시간 목표 | 미정 | 미정 |
| 처리해야 할 동시 요청 수 | 미정 | 미정 |

<br>

### 2-2-4 비용

비용은 스토리라인 요청과 컴파일 요청별로 1건당 측정한다. 컴파일 비용에는 스토리 설정, 인물 이미지와 썸네일의 생성 비용을 모두 포함한다.

사용자의 이프 지불과 이용 한도는 제품 정책을 따른다. 회원은 컴파일마다 이프를 지불한다. 게스트는 스토리라인 생성과 재생성을 합쳐 최대 5회, 컴파일은 최대 1회 이용할 수 있다.

| 항목 | 스토리라인 생성 | 컴파일 |
|---|---|---|
| 1건당 비용 상한 | 미정 | 미정 |
| 1건당 비용 측정 방법 | 미정 | 미정 |
