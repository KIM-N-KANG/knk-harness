# ROADMAP

이 문서는 **마냑 서비스의 Phase 0~3 개발 목표, 기간, 작업 범위와 백로그**를 정리하는 계획 문서입니다. 각 Phase는 사용자에게 전달할 핵심 경험을 목표로 삼고, 그 목표를 이루기 위한 작업 리스트와 진행 기간을 담습니다. 릴리스 계획과 우선순위를 논의할 때 어떤 기능을 어느 단계에서 다루는지 확인하는 기준 문서입니다.

```text
§R-1   Phase 요약        Phase 0~3 목표·기간·핵심 작업 영역 한눈에 보기
§R-2   Phase 0           MVP 개발 — 간편 제작으로 스토리를 만들어 채팅 시작
§R-3   Phase 1           내가 만든 스토리로 돌아와 채팅
§R-4   Phase 2           남이 만든 스토리를 찾아 채팅
§R-5   Phase 3           결제하고 앱으로 계속 돌아오기
§R-6   백로그            아직 Phase에 배정하지 않은 전체 작업 리스트
§R-7   참고 문서         MVP 범위·용어 기준 문서
```

## R-1. Phase 요약

| Phase | 목표 | 개발 기간 | 검증 기간 | 핵심 작업 영역 |
| --- | --- | --- | --- | --- |
| Phase 0 (MVP) | 간편 제작으로 스토리를 만들어 채팅을 시작한다 | 6/10 ~ 6/23 (스프린트 4) | 6/24 ~ 7/7 (스프린트 5) | 스토리 제작(간편) · 채팅 · 피드백 |
| Phase 1 | 내가 만든 스토리로 계속 돌아와 채팅한다 | 7/8 ~ 7/21 (스프린트 6) | 7/22 ~ 8/4 (스프린트 7) | 계정 · 크레딧 · 제작/채팅 확장 · 퀄리티 |
| Phase 2 | 남이 만든 스토리를 찾아 채팅한다 | 8/5 ~ 8/18 (스프린트 8) | 8/19 ~ 9/1 (스프린트 9) | 채팅 메모리 · 스토리 피드 · 응답 편집 · **안드로이드 앱 출시** |
| Phase 3 | 기꺼이 결제하고 앱으로 계속 돌아온다 | 9/2 ~ 9/15 (스프린트 10) | 9/16 ~ 9/29 (스프린트 11) | 앱 전환 · 과금 · 개인화 |

> 각 Phase의 **검증 기간**은 사용자 검증과 QA(품질 검증)를 함께 진행하는 기간입니다.

## R-2. Phase 0 (MVP)

### 목표

간편 제작으로 스토리를 만들어 채팅을 시작한다.

### 기간

- 개발: 6월 10일 ~ 6월 23일 (스프린트 4)
- 검증: 6월 24일 ~ 7월 7일 (스프린트 5)

Phase 0은 **MVP 개발 단계**이며, 상세 기능 범위는 [`1-background.md`](../product-specs/1-background.md) §1-6 "MVP 개발 기능"을 따릅니다.

### 작업 리스트

- **스토리 제작(간편 제작)**
    - 태그 선택
    - 스토리라인 선택
        - 스토리라인 재생성
    - 스토리 추가 정보 입력
        - 추천 추가 정보 선택
        - 사용자 직접 입력
- **채팅**
    - 추천 입력 선택
    - 입력 모드 선택
        - 블럭 입력
        - 일반 입력
- **피드백**
    - 피드백 기능

## R-3. Phase 1

### 목표

내가 만든 스토리로 계속 돌아와 채팅한다.

### 기간

- 개발: 7월 8일 ~ 7월 21일 (스프린트 6)
- 검증: 7월 22일 ~ 8월 4일 (스프린트 7)

### 작업 리스트

- **계정 시스템**
    - 로그인/회원가입
        - 기기간 사용자 데이터 마이그레이션
        - 랜덤 닉네임 적용
        - 랜덤 프로필 이미지 적용
        - 카카오 로그인 추가(KNK-721 — provider 일반화, 계정 통합 없이 별개 계정)
- **크레딧 시스템**
    - 크레딧 보상
        - 사용자별 크레딧 지갑
        - 회원가입 500 크레딧 보상
        - 사용자 초대 코드 크레딧 보상(초대자·피초대자 각각 500, 계정별 월 10회 — 링크 어트리뷰션에서 코드 입력으로 개편, KNK-567)
        - 출석체크 250 크레딧 보상
    - 크레딧 소모
        - 스토리 간편 제작 20 크레딧 소모 적용
        - 채팅 1턴당 10 크레딧 소모 적용
    - 게스트 체험 한도
        - 디바이스 ID별 스토리라인 생성·재생성 5회
        - 디바이스 ID별 스토리 생성 1회
        - 디바이스 ID별 전체 채팅 턴 5회
- **제작 기능 확장**
    - 일반 제작
    - 스토리 수정
- **채팅 기능 확장**
    - AI 응답 재생성
    - 이미지 출력
        - 스토리 제작 시 썸네일
        - 채팅 출력 시 이미지 출력
- **퀄리티 개선**
    - AI 평가 로직 추가
        - 평가 지표
        - 입력 데이터/이벤트 로깅 기반 자가개선 루프
    - AI 채팅 응답 퀄리티 개선
        - 채팅 분량 고정
    - AI 스토리 제작 퀄리티 개선
        - 장르 태그 안 섞이는 문제 보완
        - 주인공 이름 설정
        - LLM 모델 변경
        - 주요 사건 추가
        - 엔딩 추가
        - 로어북 추가
    - 프론트엔드 UI/UX 개선
        - 사파리 버그 개선
        - 애니메이션 개선

> 이미지 출력(Phase 1)은 팀이 미리 만들어 둔 이미지를 스토리 제작 시 자동 연결해 표시하는 것이고, 이미지 생성(Phase 3)은 사용자가 직접 트리거하는 커스텀 생성입니다.

## R-4. Phase 2

### 목표

남이 만든 스토리를 찾아 채팅한다.

### 기간

- 개발: 8월 5일 ~ 8월 18일 (스프린트 8)
- 검증: 8월 19일 ~ 9월 1일 (스프린트 9)

### 작업 리스트

- **채팅 메모리**
    - 채팅 메모리 구현
    - 채팅 메모리 편집
- **모바일 앱 확장**
    - 안드로이드 네이티브(Jetpack Compose) 클라이언트 개발과 Play 스토어 출시 심사 등록 (기술 선택 확정 KNK-772 선행 완료). **출시 일정·마일스톤·선행 작업은 [`3-3-android-app.md §3-3-7`](../product-specs/3-3-android-app.md#3-3-7-테스트빌드definition-of-done)이 소유하며, 개발이 Phase 2 검증 스프린트 기간까지 이어집니다**
- **스토리 피드**
    - 다른 사용자가 만든 스토리 조회
        - 누적 채팅 수 조회
        - 좋아요/싫어요
        - 찜
        - 댓글
        - 채팅 시작
    - 스토리 조회
        - 스토리 추천
        - 스토리 랭킹
        - 스토리 검색
        - 스토리 조회 필터
    - 스토리 공유
- **채팅 응답 편집**
    - AI 응답 편집

> 스토리 좋아요·싫어요는 모두 수집하지만 화면에는 좋아요 수만 표시합니다. 싫어요는 스토리 추천 신호로 쓰며, 스토리라인 평가(GOOD/BAD)와는 별개입니다. 스토리 소셜(좋아요·찜·댓글)과 채팅 소셜은 대상이 달라 서로 별도로 둡니다.

## R-5. Phase 3

### 목표

더 좋은 경험을 위해 기꺼이 결제하고, 앱으로 계속 돌아온다.

### 기간

- 개발: 9월 2일 ~ 9월 15일 (스프린트 10)
- 검증: 9월 16일 ~ 9월 29일 (스프린트 11)

### 작업 리스트

- **앱 전환**
    - 푸시 알림 확대 (v1은 스토리 생성 완료 알림 1종만 — `3-3-android-app.md §3-3-5`, 서버 계약 `4-backend.md §4-3-12`. 채팅·재참여 유도 등 다른 알림 유형과 알림 설정 화면이 여기 범위)
    - 딥링크·App Link 전략 (마케팅 링크·채팅 공유 열람의 앱 열람 여부를 함께 결정. v1의 알림 탭 랜딩은 앱 내 내비게이션으로만 처리)
    - 안드로이드 Gradle 규약 플러그인 도입 (v1은 모듈 12개를 규약 플러그인 없이 운영 — `3-3-android-app.md §3-3-2`)
    - 안드로이드 Baseline Profile 도입 (시작 성능 최적화. v1은 미도입이며 `testTag`만 붙여 둠 — `3-3-android-app.md §3-3-7`. 도입 시 시작 시간 측정 수단이 함께 따라옴)
- **과금**
    - 크레딧 충전
- **개인화·커스터마이징**
    - AI 모델 선택
    - AI 응답 출력량 조절
    - 이미지 생성
    - UI 커스터마이징

## R-6. 백로그(전체 작업 리스트)

아직 특정 Phase에 배정하지 않은 작업입니다. 우선순위가 정해지면 해당 Phase로 이동합니다.

- **인증/안전**
    - 성인 인증
- **제작 고급 기능**
    - 제작 모드 확장
        - 스토리 제작 전문가 모드
        - 스토리 시작 전 페르소나 프로필 설정
    - 참고 자료 관리
        - 유저노트
        - 키워드북
- **채팅 형태 확장**
    - 채팅 상대 확장
        - 캐릭터 챗
        - 파티 챗
    - 채팅 진행 방식 확장
        - 채팅 분기
        - 채팅 자동 진행
- **타인 플레이 채팅 소셜**
    - 다른 사용자가 플레이한 채팅
        - 조회
        - 중간에 분기
        - 좋아요/싫어요
        - 찜
        - 댓글

> **키워드북 vs 로어북.** 키워드북(`keyword_notes`)은 특정 키워드가 입력되면 반응·사건을 트리거하는 키워드-반응 저장소이고, 로어북(`lorebook`)은 진행 중 참고하는 비트리거 설정집입니다([`0-glossary.md`](../product-specs/0-glossary.md) §0-3-1). 서로 다른 기능입니다.
>
> **전연령 콘텐츠·안전.** 마냑은 전연령 콘텐츠만 제공하며, 전연령 보장을 위한 콘텐츠 필터링은 SAFETY 레이어([`0-glossary.md`](../product-specs/0-glossary.md) §0-6)에 내장되어 별도 로드맵 항목으로 두지 않습니다. 성인 인증은 이 정책에 따라 보류합니다.
