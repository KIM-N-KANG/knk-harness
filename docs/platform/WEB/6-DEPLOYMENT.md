### 6-1 설정과 호환

환경과 생성 계약은 [웹 연동](4-1-CONTRACT.md)을 따른다.

브라우저의 API 요청은 같은 출처 BFF를 거친다. 서버 주소와 비밀 설정을 브라우저에 공개하지 않는다. 정확한 패키지 버전과 생성 명령은 구현 저장소의 설정과 안내를 기준으로 한다.

공용 빌드, CI, 환경 분리와 되돌리기는 [배포 Design](../../operations/DEPLOYMENT.md)을 따른다. 이전 /studio/story 영구 리다이렉트의 브라우저 캐시 영향은 배포 뒤에도 남을 수 있다. 앱 설치와 외부 브라우저 전환은 실기기 증거로 확인하며 모의 E2E를 배포 성공으로 표시하지 않는다.
