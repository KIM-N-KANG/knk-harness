# 1. 배경

이 문서는 마냑의 게스트와 회원, ACCOUNT 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 설명한다.

<br>

### 1-1 도메인

ACCOUNT 도메인은 사용자가 누구인지 확인하고 계정을 지키는 일을 다룬다. 마냑에는 로그인 없이 쓰는 게스트와 소셜 로그인으로 가입한 회원이 있다. ACCOUNT는 게스트가 회원이 되는 과정부터 탈퇴와 재가입까지 계정을 관리한다. 가입과 동의, 세션, 게스트 데이터를 계정으로 옮기는 일을 맡는다. 계정의 프로필, 페르소나, 초대 코드도 관리한다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 서비스 이용 대상은 만 14세 이상이다. 처음 온 사용자는 로그인 없이 게스트로 체험한다. 체험을 모두 사용하거나 내 데이터를 어느 기기에서나 보고 싶어지면 소셜 로그인으로 회원이 된다. 가입하면서 이용약관, 개인정보 처리방침, 만 14세 이상 확인에 동의한다. 계정은 소셜 계정마다 따로 생긴다. 같은 사람이 두 계정을 갖지 않도록 로그인 수단을 한 계정에 연동할 수 있다.

| 흐름 | 사용자가 하는 일 |
|---|---|
| 게스트 체험 | 로그인 없이 스토리를 만들고 채팅을 시작<br>만든 스토리와 채팅의 식별자는 기기에 남음<br>게스트용 개인정보 수집 동의에 응답 |
| 가입과 로그인 | Google 또는 Kakao로 로그인<br>처음이면 필수 약관에 동의한 뒤 계정을 받음<br>약관이 개정되면 다시 동의 |
| 게스트 데이터 가져오기 | 로그인 직후 기기에 남은 스토리와 채팅을 계정으로 옮김 |
| 계정 연동 | 이미 쓰는 소셜 로그인으로 본인을 다시 확인한 뒤 다른 소셜 로그인을 추가 |
| 프로필 | 가입 시 받은 랜덤 닉네임과 이미지를 원하는 닉네임과 프리셋 이미지로 변경 |
| 페르소나 | 채팅에서 주인공으로 쓸 이름과 설명을 최대 10개 저장 |
| 초대 | 내 초대 코드를 공유하고 다른 회원의 코드를 입력해 양쪽이 이프를 받음 |
| 내 스토리와 채팅 | 로그인하면 어느 기기에서나 내가 만든 스토리와 채팅 목록을 봄 |
| 탈퇴 | 계정을 삭제<br>같은 소셜 계정으로 다시 가입하면 새 계정으로 시작 |

<br>

### 1-3 백엔드의 역할

소셜 제공자는 그 사람이 누구인지만 증명한다. 계정의 생성, 동의 증빙, 세션, 데이터 소유권, 보상 자격은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 소셜 인증 | 소셜 제공자가 발급한 신원 증명을 검증하고 계정을 찾거나 만듦<br>필수 동의가 없으면 계정을 만들기 전에 동의를 받음 |
| 세션 | 수명이 짧은 접근 토큰과 수명이 긴 갱신 토큰을 발급하고 회전<br>탈취가 의심되면 그 세션을 폐기 |
| 동의 기록 | 회원의 약관 동의를 문서 버전별로 보존<br>게스트의 개인정보 수집 동의를 기기 단위로 보존 |
| 이관 | 게스트가 만든 스토리와 채팅의 소유권을 계정에 설정<br>계정당 1회로 제한해 체험 한도 우회를 막음 |
| 계정 연동 | 본인 재확인 뒤 다른 소셜 로그인을 같은 계정에 추가 |
| 프로필 | 가입 시 랜덤 닉네임과 프리셋 이미지를 발급<br>닉네임 변경 시 다른 회원과 겹치지 않게 보장 |
| 페르소나 | 회원별 페르소나를 저장하고 채팅 시작 시 스냅샷을 제공 |
| 탈퇴와 재가입 | 계정을 비활성화하고 개인정보를 파기<br>재가입은 새 계정으로 하되 1회성 보상 자격과 제재는 이어받게 함 |
| 초대 | 초대 코드를 발급하고 코드 입력 시 자격을 판정해 양쪽에 보상 요청 |
| 계정 정지와 해제 | 관리자가 사유와 함께 회원을 정지하거나 해제<br>감사 로그에 남김 |
| 계정 상태 집행 | 정지 계정의 쓰기 요청과 탈퇴 계정의 모든 요청을 거절<br>미동의 회원의 접근을 제한 |
| 다른 도메인에 전달 | 스토리와 채팅: 이관 시 소유권과 내 목록 조회<br>이프: 가입과 초대 보상 요청 및 체험 사용량 스냅샷<br>관리자: 신원 검증기, 회원 조회와 검색, 계정 상태 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자 | 게스트용 개인정보 수집 동의 |
| 회원 | 소셜 로그인으로 가입한 사용자 | 로그인, 동의, 이관, 연동, 프로필과 페르소나 관리, 초대, 탈퇴 |
| 클라이언트 | 사용자가 쓰는 웹과 Android 앱 | 소셜 제공자에게서 신원 증명을 받아 백엔드에 전달<br>토큰을 보관하고 갱신<br>게스트가 만든 스토리와 채팅의 식별자를 기기에 보관 |
| 소셜 제공자 | Google, Kakao | 사용자의 신원 증명을 발급 |
| 관리자 | 관리자 역할을 받은 팀 구성원 | 관리자 페이지에서 계정 정지와 해제 |
| 운영자 | 팀 구성원 | 약관 버전 갱신<br>관리자 역할 부여와 회수 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자<br>백엔드는 기기 식별자로만 구분 |
| 회원 | 소셜 로그인으로 가입해 계정이 있는 사용자 |
| 소셜 연동 | 회원 계정과 소셜 제공자 계정의 연결<br>제공자와 제공자 쪽 사용자 식별자의 조합이 하나의 계정을 가리킴<br>탈퇴로 끊긴 연동은 끊긴 연동, 그 외는 활성 연동 |
| 끊긴 연동 | 탈퇴로 끊긴 소셜 연동 행<br>제공자 쪽 식별자를 보존해 재가입 판정에 사용 |
| 계정 연동 | 로그인한 계정에 다른 소셜 제공자의 로그인 수단을 추가하는 것 |
| 신원 증명 | 소셜 제공자가 발급한 서명된 토큰<br>백엔드는 서명과 발급자, 대상을 검증해 그 사람의 제공자 쪽 식별자를 얻음 |
| 접근 토큰 | 회원임을 증명하며 모든 요청에 포함하는 짧은 수명의 토큰 |
| 갱신 토큰 | 접근 토큰을 다시 받는 데 쓰는 긴 수명의 1회용 토큰 |
| 세션 | 한 번의 로그인에서 시작해 회전으로 이어지는 갱신 토큰의 묶음<br>로그아웃하거나 탈취를 탐지하면 세션 단위로 폐기 |
| 필수 동의 | 이용약관, 개인정보 처리방침, 만 14세 이상 확인<br>현행 버전에 동의해야 회원으로 서비스를 씀 |
| 동의 대기 코드 | 신원은 확인됐지만 필수 동의가 없을 때 발급하는 1회용 코드<br>동의를 제출하면 신규 사용자는 계정 생성과 로그인을, 기존 회원은 재동의 기록과 로그인을 완료함 |
| 이관 | 게스트가 만든 스토리와 채팅의 소유권을 로그인 계정으로 옮기는 것 |
| 링크 코드 | 계정 연동 전에 본인을 다시 확인하고 받는 1회용 코드 |
| 프리셋 이미지 | 팀이 만든 프로필 이미지 40종<br>닉네임의 명사마다 하나씩 대응 |
| 페르소나 | 회원이 저장한 주인공 이름과 설명<br>채팅 시작 시 선택 |
| 간편 제작 진행 | 간편 제작 1회의 입력과 결과를 관리하는 단위<br>스토리를 이관하면 함께 이관 |
| 초안 | 회원이 작성 중인 제작 입력을 서버에 보관한 것<br>탈퇴 시 삭제 |
| 제출본 | 검수를 기다리는 등록 또는 수정 요청<br>탈퇴 시 삭제 |
| 탈퇴 | 계정을 삭제 상태로 바꾸고 개인정보를 파기하는 것<br>기록은 보존 |
| 재가입 | 탈퇴한 소셜 계정으로 다시 로그인해 새 계정을 받는 것 |
| 1회성 표식 | 초대 코드 제출 여부, 이관 횟수와 이관 닫힘 여부, 체험 이전 완료 시각, 보상 신원처럼 혜택의 중복 지급이나 중복 처리를 막기 위해 회원 행에 두는 값 |
| 원장 | 이프 증감을 빠짐없이 담은 불변 기록<br>보상의 멱등 키를 보존해 1회성 판정에 사용 |
| 보상 신원 | 가입, 출석, 초대 같은 1회성 보상의 자격을 판정하는 단위<br>재가입해도 최초 계정을 가리킴 |
| 초대 코드 | 회원마다 하나씩 발급하는 8자 코드<br>다른 회원이 입력하면 양쪽이 이프를 받음 |
| 정지 계정 | 관리자가 쓰기 요청을 막은 계정<br>로그인과 조회는 가능하며 관리자가 해제할 때까지 유지 |
| 사유 | 관리자가 정지와 해제마다 적는 이유<br>관리자 도메인의 감사 로그에 남고 사용자에게는 노출하지 않음 |
| 회원 체험 | 회원이 이프 없이 쓸 수 있는 사용량<br>가입 시 게스트 시절 사용량을 이어받음 |
