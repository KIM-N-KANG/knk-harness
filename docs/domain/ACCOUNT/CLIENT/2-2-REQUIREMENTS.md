# 2-2 ACCOUNT 요구사항

<br>

### 2-2-1 적용 범위

| 항목 | 웹 | Android |
|---|---|---|
| 로그인 전 | 공개 열람과 동의 후 게스트 체험 | 로그인 화면과 법적 문서 열람 |
| 게스트 서재와 회원 이관 | 적용 | 비적용 |
| 소셜 로그인, 필수 동의, 프로필, 연동, 페르소나, 초대, 로그아웃과 탈퇴 | 적용 | 적용 |
| 초대 안내의 다음 접속 | 다음 탭 세션 | 다음 프로세스 실행 |
| 프로필과 페르소나 입력 수명 | 화면 및 브라우저 이탈 규칙 | 구성 변경에서 유지, 프로세스 종료 뒤 복원하지 않음 |
| 시작 시 동의 조회 실패 | 시트에서 재시도와 로그아웃 | 저장 세션의 시작 화면에서는 재시도만 제공, 뒤로가기는 앱 종료 |
| 초대 안내 닫기 기록 실패 | 닫기 재시도 제공 | 현재 실행에서 닫고 재표시 차단, 다음 실행 재확인 |

<br>

### 2-2-2 로그인과 동의

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 소셜 로그인 | Google과 Kakao 제공. 실패나 취소 후 재시도 가능 | ACCOUNT-US-001 |
| 가입 대기 | 필수 동의 전 계정과 세션 생성 안 함. 동의 거절은 가입 취소 | ACCOUNT-US-002 |
| 명시 동의 | 필요한 이용약관, 개인정보 처리방침, 만 14세 이상 확인에 각각 동의. 문서 열람과 로그인 버튼 클릭은 동의 아님 | ACCOUNT-US-002 |
| 동의 완료 | 서버가 필수 항목 전체의 완료를 확인한 뒤 회원 기능, 자동 조회, 이관, 분석 식별과 푸시 등록 시작 | ACCOUNT-US-002 |
| 회원 재동의 | 기존 계정과 콘텐츠 유지. 로그인 시 가입 대기 절차, 이미 로그인했으면 회원 동의 절차 | ACCOUNT-US-011 |
| 재동의 거절 | 기존 세션 종료. 가입 대기 취소와 구분 | ACCOUNT-US-011 |
| 요청 복귀 | 로그인과 회원 동의 완료 후 원래 화면 복귀. 이전 제작이나 전송 요청 자동 재실행 안 함 | ACCOUNT-US-003, ACCOUNT-US-002 |
| 선택 동의 | 광고성 정보 수신 동의는 선택 항목. 전체 동의에 포함하되 회원 이용 조건에 포함하지 않음 | ACCOUNT-US-002 |
| 문서 동일성 | 로그인 전에도 전문 열람. 플랫폼 간 시행일, 표시 버전과 본문 일치 | ACCOUNT-US-002 |
| 버전 구분 | 서버 요구 버전으로 동의. 재동의 없는 문구 개정은 표시 버전만 변경 가능 | ACCOUNT-US-002, ACCOUNT-US-011 |

선택 동의의 저장과 재질문은 알림 계약의 적용 대상이다. ([웹 PWA 푸시](../../../spec/3-2-web-spec.md#pwa-푸시), [Android 알림](../../../spec/3-3-android-spec.md#3-3-5-알림))

### 2-2-3 프로필과 페르소나

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 회원 서재 | 재로그인과 다른 기기에서도 같은 계정의 서버 서재 유지 | ACCOUNT-US-005 |
| 최초 프로필 | 가입 시 닉네임과 프리셋 이미지 자동 부여 | ACCOUNT-US-006 |
| 닉네임 | 2~20자, 완성형 한글과 영문 및 숫자만 허용. 공백과 단독 자모 등은 거절 | ACCOUNT-US-007 |
| 이미지 | 프리셋에서 선택. 선택만으로 저장하지 않음 | ACCOUNT-US-007 |
| 저장 | 변경 없으면 비활성화. 성공 시 프로필과 작성자 표시 갱신, 실패 시 입력 유지 | ACCOUNT-US-007 |
| 프로필 이탈 | 미저장 변경이 있으면 확인 후 이탈. 변경 없으면 바로 복귀 | ACCOUNT-US-007 |
| 페르소나 입력 | 이름 최대 20자, 성별 남성 또는 여성, 특징 최대 500자. 앞뒤 공백을 뺀 이름과 특징 및 성별 필수 | ACCOUNT-US-009 |
| 페르소나 수 | 회원당 최대 10개. 상한이면 추가 이동과 초과 생성 차단 | ACCOUNT-US-009 |
| 페르소나 적용 | 상세에서 생성하면 해당 상세에 선택. 수정은 새 채팅부터 적용, 삭제해도 기존 채팅 유지 | ACCOUNT-US-009 |
| 이전 소개 호환 | 성별을 분리할 수 없는 소개는 전체를 특징에 표시하고 성별은 미선택 | ACCOUNT-US-009 |
| 생성과 수정 | 저장 중 중복 요청 차단, 실패 시 입력 유지. 성공 시 목록 갱신 후 진입 화면 복귀 | ACCOUNT-US-009 |

<br>

### 2-2-4 연동과 초대

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 계정 연동 | 현재 계정 재인증 뒤 다른 로그인 수단 추가. 계정 통합, 연동 해제와 세션 교체는 제공하지 않음 | ACCOUNT-US-008 |
| 다른 계정에 연동됨 | 현재 세션 유지. 로그아웃 후 해당 계정으로 로그인하도록 안내하고 즉시 전환 버튼은 제공하지 않음 | ACCOUNT-US-008 |
| 초대 보상 | 서버 정책값 표시. 코드 조회, 복사, 공유와 등록 제공 | ACCOUNT-US-010 |
| 코드 입력 | 앞뒤 공백 제거와 대문자 변환 후 대문자 및 숫자 8자 | ACCOUNT-US-010 |
| 초대 등록 | 계정당 평생 1회. 서버의 자격 및 보상 판정 결과 표시 | ACCOUNT-US-010 |
| 신규 안내 | 가입한 접속에서는 미표시. 다음 접속 홈에서 표시. 보기 전 종료하면 이후 접속에서 표시 | ACCOUNT-US-010 |
| 안내 닫기 | 등록 자격 유지. 제출 중 입력, 등록과 닫기를 잠금 | ACCOUNT-US-010 |
| 지급 후 닫기 실패 | 보상 지급과 닫기 기록을 구분. 보상 재요청 없이 닫기 기록만 재시도 | ACCOUNT-US-010 |

<br>

### 2-2-5 종료와 데이터 보호

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 로그아웃 | 서버 로그아웃 실패에도 로컬 종료 계속. 이전 계정의 토큰, 프로필과 늦은 결과가 다음 계정에 노출되지 않음 | ACCOUNT-US-012 |
| 제작 데이터 | 플랫폼별 정리 또는 소유 계정 격리. 웹 게스트에서 회원 전환 시 복구 데이터 유지 | ACCOUNT-US-003, ACCOUNT-US-012 |
| 탈퇴 확인 | 잔여 이프 소멸, 비공개 서재 복구 및 이전 불가, 공개 콘텐츠 잔존, 재로그인 시 이전 계정 복구 불가의 네 항목 모두 확인 | ACCOUNT-US-013 |
| 탈퇴 성공 | 서버 성공 확인 뒤 세션 종료. 프로필과 소셜 연결 제거, 닉네임 익명화. 공개 스토리와 공유 채팅 링크는 유지 가능 | ACCOUNT-US-013 |
| 민감 정보 | 토큰과 대기 코드를 UI, 로그, 분석에 노출하지 않음 | ACCOUNT-US-012, ACCOUNT-US-002 |

### 2-2-6 실패와 복구 결과

| 상황 | 사용자 결과 |
|---|---|
| 동의 조회나 저장의 일시 실패 | 회원 기능 차단 유지, 재시도와 로그아웃. Android 저장 세션 시작 조회는 2-2-1의 예외 적용 |
| 가입 대기 만료 또는 가입 중 요구 변경 | 대기 종료, 안내 후 사용자가 소셜 로그인부터 재시작. 자동 인증과 자동 동의 제출 없음 |
| 로그인한 회원의 동의 버전 변경 | 최신 요구를 다시 표시하고 체크 초기화. 사용자 재확인 뒤 제출 |
| 회원 동의의 권한 거절 | 이용 제한 안내와 로그아웃만 제공 |
| 세션 만료 확정 | 플랫폼 세션 종료. 일시적 네트워크 실패와 구분 |
| 프로필 조회 또는 프리셋 조회 실패 | 해당 영역에서 안내와 재시도 |
| 닉네임 중복 또는 허용하지 않는 값 | 필드 오류 표시, 입력 유지. 수정하면 오류 해제 |
| 페르소나 조회 실패, 없는 항목, 개수 초과 | 조회 재시도, 찾을 수 없음, 10개 상한을 각각 안내 |
| 연동 중복 또는 신원 확인 실패 | 현재 계정 유지. 중복은 상태 갱신, 신원 확인 실패는 재시도 안내 |
| 탈퇴 요청의 일시 실패 | 체크 상태와 화면 유지, 재시도 허용 |

필수 문서는 만 14세 이상 이용, 명시 동의 후 회원 이용, 웹 게스트 체험과 저장 범위, 회원 및 게스트 동의 기록의 항목과 목적을 고지한다. 브라우저 저장소 삭제와 서버 콘텐츠 및 동의 기록 삭제를 구분한다.
