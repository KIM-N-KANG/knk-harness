# 2-2 요구사항: 웹

<br>

### 2-2-1 게스트와 회원

공통 요구사항의 웹 적용 범위를 구체화한다. ([2-2-1 적용 범위](../2-2-REQUIREMENTS.md#2-2-1-적용-범위))

| 상황 | 조건과 결과 |
|---|---|
| 동의 없는 진입 | 공개 콘텐츠, 채팅방 생성과 프롤로그, 제작 FAB, 직접 제작 URL, 초안 재개, 공유 CTA 및 키워드 입력 허용 |
| 게스트 동의 확인 | 입력 검증을 통과한 스토리라인 생성 직전. 재생성, 스토리 완성, 채팅 전송, 추천 입력 전송, 응답 재생성과 추천 입력 생성 및 재시도에도 적용 |
| 확인 결과 | 같은 기기의 서버 동의가 유효하면 진행. 조회 실패와 식별자 누락 시 요청 차단 |
| 동의 제출 | 확인한 버전으로 명시 동의. 저장 확인 뒤 대기한 동작 한 개만 재개 |
| 취소와 이탈 | 배경, Escape, 뒤로가기, 경로 및 인증 변경 시 대기 요청 취소, 입력 유지. 늦은 응답으로 재실행하지 않음 |
| 저장 뒤 취소 | 이미 서버에 저장된 동의를 철회하지 않음 |
| 재방문 | 새로고침과 다른 탭도 동작 전 서버 확인. 새 기기 식별자 또는 요구 버전 변경 시 재동의 |
| 회원과의 구분 | 게스트 동의에 광고 동의 포함 안 함. 회원 필수 동의로 이관하지 않음 |
| 브라우저 데이터 삭제 | 서버 콘텐츠와 동의 기록의 삭제가 아님. 시크릿 모드 탐지 없이 기기 식별자로 구분 |

ACCOUNT-US-004의 웹 게스트 체험에 해당한다. ([2-1-1 가입과 서비스 이용](../2-1-USER-STORY.md#2-1-1-가입과-서비스-이용))

### 2-2-2 서재와 체험

| 항목 | 조건과 결과 |
|---|---|
| 게스트 서재 | 같은 브라우저의 공개 ID로 열람, 삭제, 공유. 저장소 삭제와 기기 변경 시 접근 불가 안내 |
| ID 보관 | 스토리와 채팅 각각 중복 없이 최신 생성순 최대 100개. 밀린 ID의 서버 레코드는 삭제하지 않음. 민감 정보 저장 금지 |
| 목록 표시 | 읽기 전 로딩, 손상 배열은 빈 목록. 비어 있지 않은 목록만 조회. 스토리는 로컬 순서, 채팅은 서버 최근 활동순 |
| 삭제 | 먼저 목록에서 제외하고 실패 시 복원. 404는 삭제 완료 |
| 엔딩 배지 | 로컬 서재의 채팅 응답에 있는 엔딩만 스토리별 합산 |
| 소유 판정 | 로컬 제작 ID로 판단. 판정 전 좋아요 버튼 잠금, 게스트 신고 메뉴 미표시 |
| 회원 서재 | 서버가 기준. 게스트 ID를 회원 목록으로 사용하지 않음 |
| 체험 수치 | 서버의 한도와 사용량으로 잔여 계산. 브라우저 카운터 없음 |
| 체험 갱신 | 채팅 턴 완료, 스토리라인 생성 성공, 스토리 완성 및 로그인 상태 변경 뒤 재조회 |
| 잔여 0 | 유료 체험의 생성, 재생성, 완성, 전송을 요청하지 않고 로그인 안내. 잔여 확인 전에는 서버의 한도 판정 적용 |
| 무료 진입 | 채팅방 생성과 제작 입력 화면 진입은 체험 한도로 선차단하지 않음 |

<br>

### 2-2-3 로그인과 이관

| 항목 | 조건과 결과 |
|---|---|
| 가입 대기 | 로그인 시작 탭에서만 표시. 같은 탭 새로고침은 유지, 표시 없는 탭과 법적 문서에서는 미표시 |
| 미완료 로그인 | 뒤로가기와 앞으로가기 복원, OAuth 오류 복귀 시 대기를 취소. 종료된 로그인과 동의 시트를 함께 표시하지 않음 |
| 기존 세션 재동의 | 탭 로그인 표시와 무관하게 유지. 법적 문서에서는 시트 없이 회원 기능만 차단 |
| 재동의 거절 | 페이지 전체 재조회 없이 같은 화면을 비로그인 상태로 변경 |
| 복귀 | 시작 화면의 경로, 쿼리, 해시 보존. 앱 안 경로만 허용, 외부 URL과 `//` 거절. 기본은 홈 |
| 자동 이관 | 회원 필수 동의 완료 뒤 로컬 ID와 이전 탭 저장 ID 제출. 실제 이관 수만 안내 |
| 이관 결과 | 서버가 평가한 ID만 정리. 닫힌 계정은 ID 유지 및 해당 계정 재시도 중단 |
| 평가 전 실패 | ID 유지, 다음 방문 재시도. 실패가 로그인 완료를 막지 않음 |
| 손상 ID | 입력 오류이면 유효한 UUID만 한 번 재제출하고 손상 ID 폐기. 무한 재시도 없음 |
| 게스트 사용량 | 이관할 ID 유무와 무관하게 인증 확정 뒤 정리 |
| 로그인 입력 | 로그인 안내 직전 채팅 초안은 같은 탭 복원. 게스트에서 회원 전환 시 제작 복구 데이터 유지 |
| 종료 | 명시적 로그아웃, 탈퇴와 만료 뒤 회원 로컬 상태 및 제작 복구와 완성 요청 기록 정리 |
| 초대 안내 | 가입한 탭의 새로고침은 같은 접속. 새 탭 세션의 홈에서 표시. 저장소 이용 불가 시 안내를 미루지 않음 |
| 프로필 이탈 | 새로고침과 탭 닫기는 브라우저 기본 확인창 |

### 2-2-4 인앱과 인증 팝업

| 항목 | 조건과 결과 |
|---|---|
| 인앱 체험 | KakaoTalk, Instagram, Threads에서도 같은 브라우저 체험과 로그인 후 이관 제공. 외부 로그인 핸드오프 없음 |
| 기본 인증 | 원래 페이지 유지, 인증 팝업 우선. 일반 브라우저 팝업 차단 시 같은 탭 인증 |
| 인앱 Kakao | 같은 탭 인증 |
| 인증 성공 | 원래 탭의 세션과 인증 확인용 회원 정보가 같은 회원일 때만 성공. 다른 저장소의 인증만으로 성공 표시 금지 |
| 가입 대기 결과 | 원래 화면에서 동의 시트. 동의 전 온보딩과 이관 금지 |
| 실패와 5분 만료 | 원래 입력 유지, 잠금 해제와 재시도. 만료만으로 인증창을 강제 종료하지 않음 |
| 창 참조 단절 | 취소로 단정하지 않고 원래 탭 복귀 때 인증 재확인 |
| 늦은 응답 | 종료된 시도의 응답으로 화면 이동 금지. 응답 대기 중 인증 시작 요청 중복 금지 |
| 인앱 계정 연동 | 시작하지 않고 외부 브라우저 이용 안내 |
| 보안 | 팝업 메시지에 토큰과 회원 정보 전달 금지. Google 인증과 연동에서 PKCE, state, nonce 검증 |

인앱별 창 연결과 쿠키 공유는 환경에 따라 다르다. 팝업 시도 지원이 Google의 WebView 공식 지원을 뜻하지 않는다.
