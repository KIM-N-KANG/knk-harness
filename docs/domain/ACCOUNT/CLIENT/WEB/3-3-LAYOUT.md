# 3-3 ACCOUNT 웹 화면 표현

<br>

### 3-3-1 게스트 동의 시트

| 영역 | 표시 |
|---|---|
| 제목 | "시작하기 전에 확인해주세요" 한 줄. 입력 검증을 통과한 "스토리라인 만들기" 등의 실행 직전에 표시 |
| 안내 1 | "AI가 만든 내용은 직접 확인해주세요" / "사실과 다르거나 부적절한 내용이 있을 수 있어요" |
| 안내 2 | "개인정보와 민감한 정보는 입력하지 마세요" / "다른 사람의 권리를 침해하는 내용도 입력하거나 공유하지 마세요" |
| 안내 3 | "이용에 필요한 동의를 확인해주세요" / "‘동의하기’를 누르면 만 14세 이상임을 확인하고, 서비스 이용약관과 개인정보 수집 및 이용에 동의해요" |
| 카드 표현 | 제목 16px 볼드, 설명 14px 일반과 보조 전경색, 끝 마침표 없음 |
| 자세히 보기 | 마지막 제목 행 오른쪽, 밑줄 없음, 높이 24px |
| 안내 간격 | 제목과 카드, 카드와 버튼 각각 32px. 카드 사이 8px |
| 상세 | "게스트 이용 동의". 이용 조건, 목적, 항목, 보유기간, 거부 권리와 제한, AI 처리, 권리 행사, 만 14세 이상 확인 |
| 상세 높이 | 콘텐츠에 따라 증가, 화면 높이에서 6rem을 뺀 값 이하. 제목과 버튼 고정, 본문만 스크롤 |
| 제출 | 체크박스 없이 단일 동의하기 버튼. 광고 동의 없음 |
| 조회 실패 | "동의 상태를 확인하지 못했어요", "다시 시도" |
| 저장 실패 | "동의를 저장하지 못했어요. 잠시 후 다시 시도해주세요" |
| 버전 변경 | "약관이 갱신되어 최신 내용으로 다시 확인해주세요" |

<br>

### 3-3-2 회원 시트와 팝업

| 요소 | 표현 |
|---|---|
| 회원 동의 시트 | 공통 배치, 초기 초점은 시트. 스와이프 핸들 없음 |
| 선택 동의 | 필수 항목 뒤 "[선택] 광고성 알림 수신 동의"와 보조 설명 |
| 동의와 조회 실패의 로그아웃 | 제출 또는 재시도 아래 `ghost` 보조 버튼 |
| 권한 거절의 로그아웃 | `outline` 단독 버튼 |
| 초대 닫기와 닫기 재시도 | 공용 닫기 버튼 변형과 크기, 등록 버튼 아래 8px |
| 초대 시트 | 제목과 설명 사이 8px, 설명과 폼 사이 32px |
| 탈퇴 체크박스 | motion `Checkbox`, 20px, 보더 2px `muted-foreground/50`, 선택 시 `primary`와 체크 패스, 문구 간격 16px |
| 팝업 완료 제목 | "Google 로그인" |
| 인증 확인 안내 | "인증 처리가 끝났어요. 원래 화면으로 돌아가 주세요." |
| 실패 안내 | "로그인을 완료하지 못했어요. 원래 화면에서 다시 시도해 주세요." |

공통 ACCOUNT 배치와 웹 디자인 토큰을 적용한다. ([공통 3-3](../3-3-LAYOUT.md), [공용 바텀 시트 닫기](../../../APP/CLIENT/WEB/3-3-LAYOUT.md#3-3-1-셸과-공용-요소), [웹 표현 값](../../../APP/CLIENT/WEB/3-3-LAYOUT.md#3-3-1-셸과-공용-요소))
