기준: [동의 모델](../3-2-INTERACTION-FLOWS.md#3-2-1-로그인과-필수-동의) ,  [웹 로그인과 회원 이관(가입 대기, 로그인한 세션의 재동의)](3-2-INTERACTION-FLOWS.md#3-2-2-로그인과-회원-이관) ,  [동의 게이트 구조](4-3-STATE-MANAGEMENT.md#4-3-3-회원-동의-상태). OAuth 자체는 외부 의존이라 E2E는 세션 목, 가입 대기 BFF 목과 탭 로그인 표시(`sessionStorage`)로 재현한다. AUTH-CONSENT-01~12와 14는 이미 로그인한 세션(문서 개정, 기존 로그인 경로로 만든 세션)의 회원 동의, AUTH-CONSENT-15 이후는 세션 없는 가입 대기다. 인앱 실기기 복귀(P2 AUTH-CONSENT-13)는 가입 대기 흐름이다.
