# 3-1 화면 구성: 웹

<br>

### 3-1-1 경로

| 화면 | 경로 | 접근과 직접 진입 복귀 |
|---|---|---|
| 로그인 | `/login` | 회원의 직접 접근도 허용 |
| 마이 | `/my` | 게스트와 회원 |
| 친구 초대 | `/my/invite` | 회원, 기본 복귀 마이 |
| 회원 탈퇴 | `/my/account-deletion` | 회원, 기본 복귀 마이 |
| 프로필 수정 | `/my/profile/edit` | 회원, 기본 복귀 마이. 게스트는 로그인 |
| 페르소나 관리 | `/my/personas` | 회원, 기본 복귀 마이 |
| 페르소나 생성 | `/my/personas/new` | 회원, 직접 진입 시 페르소나 관리로 복귀 |
| 페르소나 수정 | `/my/personas/[personaId]/edit` | 회원, 게스트는 로그인 |
| 약관과 개인정보 처리방침 | `/terms`, `/privacy` | 로그인 전 허용 |

공통 화면 구성과 웹의 접근 범위를 적용한다. ([공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md), [웹 2-2](2-2-REQUIREMENTS.md))

<br>

### 3-1-2 마이와 문서

| 영역 | 구성 |
|---|---|
| 회원 프로필 | 행 전체가 수정 링크, 닉네임 오른쪽 꺾쇠. 안쪽 연동 버튼은 독립 동작 |
| 게스트 프로필 | 수정 링크 없음, 로그인 버튼 |
| 페르소나 | 이프 카드 아래, 이벤트 위에 관리 메뉴 |
| 법적 문서와 서비스 안내 | 링크 없는 로고 헤더와 스크롤 본문. 문서 간 링크 허용, 앱 밖 웹 화면으로 이동하는 내부 링크 없음 |
| 서비스 안내 | 마이에서 새 탭으로 열기 |
| 문서 제목 | `제목 - 마냑`, 본문에 시행일과 표시 버전 |
