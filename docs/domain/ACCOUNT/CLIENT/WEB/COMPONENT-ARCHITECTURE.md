# ACCOUNT 웹 구성

<br>

### 책임과 의존 방향

| 구성 | 책임 | 경계 |
|---|---|---|
| Auth.js와 BFF | 소셜 인증, 세션과 비공개 토큰 보관 | 브라우저에 토큰 전달 안 함 |
| 루트 회원 동의 게이트 | 서버 동의로 회원 기능 허용 판정 | 하위 화면은 같은 판정 재사용 |
| 게스트 동의 프로바이더 | 제작과 채팅의 실행 직전 비동기 확인 | 회원 동의 게이트 내부, 한 동작만 대기 |
| 동의 시트 | 표시, 입력과 결과 전달 | 회원 판정을 별도로 만들지 않음 |
| 회원 부수 효과 | 분석 식별, 이관, 초대 안내, 자동 조회 | 필수 동의 완료 상태에서만 실행 |
| 마이 기능 | 프로필, 페르소나와 초대 | 서버 결과로 화면 상태 갱신 |
| 로컬 회원 정리 | 명시적 로그아웃, 탈퇴와 만료의 공통 정리 | 세 경로가 같은 정리 사용 |

```text
화면 → 회원 동의 판정 → 필요한 경우 게스트 동의 → API 클라이언트
     → 브라우저 재발급 게이트 → BFF → 백엔드
```

루트 밖 회원 판정의 기본값은 회원과 게스트 모두 거짓이다. 세션 미확정 상태를 게스트로 처리하지 않는다. ([ACCOUNT 웹 요구사항](REQUIREMENTS.md))
