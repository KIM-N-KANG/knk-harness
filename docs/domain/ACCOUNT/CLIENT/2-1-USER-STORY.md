# 2-1 유저 스토리

<br>

### 2-1-1 가입과 서비스 이용

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| ACCOUNT-US-001 | 로그인하려는 사용자 | 평소 쓰는 소셜 계정으로 가입하거나 로그인하고 싶다 | 별도 비밀번호를 만들고 기억하는 부담 없이 서비스를 쓰고 싶다 |
| ACCOUNT-US-002 | 가입하려는 사용자 | 가입 전에 이용약관과 개인정보 처리방침 전문을 읽고, 필수 항목에 각각 동의하거나 가입을 취소하고 싶다 | 내용을 이해하고 선택하며, 동의하지 않은 계정이 남지 않게 하고 싶다 |
| ACCOUNT-US-003 | 웹 게스트 | 로그인 뒤에도 체험 중 만든 스토리와 채팅, 남은 체험 횟수가 계정에 이어지길 원한다 | 체험한 브라우저에서 쌓은 콘텐츠와 사용량을 잃고 싶지 않다 |
| ACCOUNT-US-004 | 웹 게스트 | 공개 스토리를 둘러보고, 제작이나 채팅을 실행하기 전에 안내와 상세를 확인해 동의한 뒤 체험하고 싶다 | 가입 전에 서비스를 알아보고, 입력한 내용을 잃지 않은 채 사용하고 싶다 |
| ACCOUNT-US-005 | 회원 | 다시 로그인하거나 다른 기기에서도 내 스토리와 채팅을 이어서 쓰고 싶다 | 접속 환경이 바뀌어도 같은 서재를 유지하고 싶다 |

<br>

### 2-1-2 프로필과 계정 관리

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| ACCOUNT-US-006 | 새 회원 | 가입하면 닉네임과 프로필 이미지가 자동으로 만들어지길 원한다 | 프로필을 꾸미는 수고 없이 바로 쓰고 싶다 |
| ACCOUNT-US-007 | 회원 | 닉네임과 프로필 이미지를 직접 바꾸고 싶다 | 공개 스토리 작성자로 보이는 이름과 모습을 내가 고르고 싶다 |
| ACCOUNT-US-008 | 회원 | 다른 소셜 로그인 수단을 같은 계정에 연결하고 싶다 | 로그인 수단을 바꿔도 같은 서재를 사용하고 싶다 |
| ACCOUNT-US-009 | 회원 | 페르소나를 만들고 수정하거나 삭제하고 싶다 | 여러 스토리에서 원하는 주인공으로 플레이하고 싶다 |
| ACCOUNT-US-010 | 회원 | 내 초대 코드를 공유하고 받은 코드를 등록하고 싶다 | 친구와 함께 가입 혜택을 받고 싶다 |
| ACCOUNT-US-011 | 기존 회원 | 바뀐 필수 동의 내용을 확인하고 이용 여부를 선택하고 싶다 | 기존 계정과 콘텐츠를 유지하며 새 조건을 이해하고 싶다 |

### 2-1-3 이용 종료

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| ACCOUNT-US-012 | 회원 | 사용을 마친 뒤 로그아웃하고 싶다 | 공용 기기의 다음 사용자에게 내 계정과 콘텐츠가 노출되지 않게 하고 싶다 |
| ACCOUNT-US-013 | 회원 | 서비스 안에서 계정을 직접 탈퇴하고 싶다 | 더 이상 서비스를 이용하지 않을 때 계정과 소셜 연결을 정리하고 싶다 |
