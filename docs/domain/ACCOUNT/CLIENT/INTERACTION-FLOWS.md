# ACCOUNT 화면 흐름

<br>

### 로그인과 필수 동의

```text
소셜 로그인 선택
  ├─ 필수 동의 완료 → 회원 상태 확인 → 원래 화면
  └─ 필수 동의 필요 → 가입 대기 시트
       ├─ 동의 → 가입 완료 → 회원 동의 확인 → 원래 화면
       └─ 로그아웃 또는 뒤로가기 → 가입 취소 → 비로그인 화면
기존 회원의 재동의 시트
  ├─ 동의 → 완료 확인 → 회원 화면
  └─ 로그아웃 또는 뒤로가기 → 세션 종료 → 비로그인 화면
```

| 조작 또는 상태 | 화면 동작 |
|---|---|
| 소셜 버튼 탭 | 해당 버튼에 스피너, 두 공급자 버튼 잠금. 실패와 취소 시 해제 |
| 필수 문서 보기 | 전문 열기. 열람만으로 체크하지 않음 |
| 전체 동의 | 필수 및 선택 항목 함께 전환 |
| 필수 항목 일부 미체크 | 동의하기 비활성화 |
| 동의 제출 중 | 입력, 제출과 종료 잠금 |
| 배경 탭, 스와이프, Escape | 필수 동의 시트 유지 |
| 동의 후 복귀 | 원래 화면 표시. 이전 제작 및 전송 요청은 다시 누를 때 실행 |

가입 대기, 기존 회원 재동의와 실패 결과를 구분한다. ([로그인과 동의](REQUIREMENTS.md#로그인과-동의), [실패와 복구 결과](REQUIREMENTS.md#실패와-복구-결과))

### 프로필과 페르소나

| 시작 | 조작 | 결과 |
|---|---|---|
| 마이 | 프로필 행 선택 | 프로필 수정. 행 안의 연동 버튼은 연동 동작 유지 |
| 프로필 수정 | 이미지 선택 | 프리셋 시트. 선택하면 미리보기만 변경하고 시트 닫기 |
| 프로필 수정 | 저장 | 성공 안내 후 진입 화면, 없으면 마이 |
| 미저장 프로필 | 뒤로가기 | 확인창. 닫기는 편집 유지, 나가기는 변경 폐기 |
| 페르소나 목록 | 행 선택 | 이름과 특징 전체 펼침, 다시 선택하면 접힘 |
| 페르소나 목록 | 추가 | 생성 화면. 10개이면 상한 안내 |
| 스토리 상세 | 페르소나 생성 | 생성 성공 후 해당 상세로 복귀하여 새 항목 선택 |
| 페르소나 생성 | 저장 | 성공 후 진입 화면, 공통 기본 복귀는 홈. 플랫폼 내비게이션의 직접 진입 복귀 적용 |
| 페르소나 옵션 | 수정 | 기존 값으로 수정 폼 열기. 성공 후 목록 갱신과 복귀 |
| 페르소나 옵션 | 삭제 | 시트 닫기 → 확인창 → 삭제 → 목록 갱신 |

입력과 보존 조건은 프로필과 페르소나 요구사항을 적용한다. ([2-2-3](REQUIREMENTS.md#프로필과-페르소나))

<br>

### 연동과 초대

```text
계정 연동 버튼 → 혜택과 재인증 순서, 해제 불가 확인
              → 현재 공급자 재인증 → 대상 공급자 인증
              → 기존 계정의 연동 목록 갱신과 성공 안내
```

| 상황 | 화면 동작 |
|---|---|
| 연동 목록 조회 중 | Chip 골격 2개 |
| 연동 목록 없음 또는 필드 누락 | 섹션 숨김. 미연동 버튼 추정 안 함 |
| 가입한 접속 | 초대 안내 미표시 |
| 다음 접속의 홈 | 초대 코드 입력 시트 |
| 안내에서 닫기, 배경 탭 또는 Escape | 안내 종료, 등록 자격 유지 |
| 초대 코드 제출 중 | 입력, 등록, 닫기 잠금 |
| 보상 성공 | 닫기 기록 저장까지 진행 표시 |
| 보상 성공 뒤 닫기 기록 실패 | 지급 결과 안내. 보상 요청 없이 닫기 기록 재시도 |

연동 실패의 계정 유지와 플랫폼별 안내 닫기 조건은 요구사항에 있다. ([2-2-1](REQUIREMENTS.md#적용-범위), [2-2-4](REQUIREMENTS.md#연동과-초대), [2-2-6](REQUIREMENTS.md#실패와-복구-결과))

### 로그아웃과 탈퇴

| 시작 | 조작 | 결과 |
|---|---|---|
| 마이 | 로그아웃 | 세션 종료 후 플랫폼의 비로그인 화면 |
| 필수 동의 시트 | 로그아웃 | 가입 대기면 취소, 기존 세션이면 종료 |
| 회원 탈퇴 | 네 항목 모두 확인 | 탈퇴 버튼 활성화 |
| 회원 탈퇴 | 제출 | 버튼 잠금과 진행 표시 |
| 탈퇴 성공 | 서버 성공 확인 | 계정 데이터 정리와 세션 종료, 비로그인 화면 |
| 탈퇴 일시 실패 | 실패 안내 | 체크와 화면 유지, 재시도 |

탈퇴 후 데이터의 복구 가능 여부와 종료 경계는 종료 요구사항을 적용한다. ([2-2-5](REQUIREMENTS.md#종료와-데이터-보호))
