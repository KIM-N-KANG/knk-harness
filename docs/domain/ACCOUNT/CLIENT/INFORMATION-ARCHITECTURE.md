# ACCOUNT 화면 구성

<br>

### 화면과 진입

| 화면 | 진입 | 정보와 기능 |
|---|---|---|
| 로그인 | 로그인 진입점 | 가입 혜택, 소셜 로그인, 법적 문서 |
| 필수 동의 | 가입 대기 또는 회원 재동의 | 필요한 필수 항목, 선택 동의, 전문 열람과 거절 |
| 마이 | 마이 탭 | 프로필, 연동 계정, 이프, 페르소나, 초대, 계정 종료 |
| 프로필 수정 | 마이의 프로필 행 | 이미지 프리셋, 닉네임과 저장 |
| 페르소나 관리 | 마이 | 목록, 추가, 수정과 삭제 |
| 페르소나 생성과 수정 | 관리 목록 또는 스토리 상세의 "페르소나 생성하기" | 이름, 성별, 특징 |
| 친구 초대 | 마이 | 보상 안내, 내 코드와 월 보상 횟수, 받은 코드 등록 |
| 회원 탈퇴 | 마이 계정 메뉴 | 네 가지 확인 항목과 탈퇴 |
| 서비스 이용약관과 개인정보 처리방침 | 로그인, 동의 시트, 서비스 안내 | 시행일, 버전과 전문 |

회원 기능의 접근 조건은 로그인과 필수 동의 상태로 구분한다. ([적용 범위](REQUIREMENTS.md#적용-범위), [로그인과 동의](REQUIREMENTS.md#로그인과-동의))

<br>

### 마이 정보 순서

| 위치 | 표시 |
|---|---|
| 프로필 | 이미지와 닉네임, 수정 꺾쇠, 연동 계정 |
| 이프 | 잔액과 충전 버튼. 출석 체크는 무료 충전 탭 |
| 페르소나 | 페르소나 관리 메뉴 |
| 이벤트 | 친구 초대, 보조 문구 "하고 N 이프 받기" |
| 계정 | 기본색 로그아웃, 위험색 회원 탈퇴 순서 |

헤더와 하단 내비게이션의 접근 가능한 이름은 "마이"이다. 웹은 테마, 피드백과 서비스 안내를 비로그인 상태에서도 제공한다. 이프와 보상 수치는 서버 정책값을 표시한다. ([연동과 초대](REQUIREMENTS.md#연동과-초대))
