# 1 ACCOUNT 클라이언트 배경

<br>

### 1-1 사용자와 목적

회원은 소셜 계정으로 로그인해 여러 기기에서 같은 서재를 이용한다. 닉네임과 프로필 이미지를 바꾸고, 채팅에 사용할 페르소나를 관리한다. 웹 방문자는 가입 전에 공개 콘텐츠와 게스트 체험을 이용한다.

| 주체 | 필요한 경험 |
|---|---|
| 처음 온 사용자 | 로그인과 이용 조건을 이해하고 가입 여부 선택 |
| 회원 | 같은 계정으로 콘텐츠 이용, 프로필과 로그인 수단 관리 |
| 웹 게스트 | 입력과 체험 데이터를 잃지 않고 가입으로 연결 |

<br>

### 1-2 범위

| 도메인 | 책임 |
|---|---|
| ACCOUNT | 로그인, 필수 동의, 계정 연동, 웹 게스트 이관, 프로필, 페르소나, 초대, 로그아웃과 탈퇴 |
| STORY와 CHAT | 제작과 플레이, 페르소나 사용, 콘텐츠 표시 |
| PAYMENT | 이프와 체험 한도, 가입 및 초대 보상 판정 |
| NOTIFICATION | 푸시 등록과 선택 동의의 저장 및 재질문 |
| 공용 클라이언트 | 앱 셸, 디자인 시스템, 공통 네트워크와 빌드 |

<br>

### 1-3 용어

| 용어 | 의미 |
|---|---|
| 가입 대기 | 소셜 신원은 확인됐으나 필수 동의를 마치지 않아 세션이 없는 상태 |
| 재동의 | 기존 회원이 변경된 필수 동의 요구에 응답하는 것 |
| 게스트 이관 | 웹 브라우저의 콘텐츠 식별자로 접근하던 데이터를 회원 계정에 연결하는 것 |
| 페르소나 | 새 채팅에서 주인공으로 사용할 이름과 소개 |
| 접속 | 웹은 탭 세션, Android는 프로세스 실행 |
