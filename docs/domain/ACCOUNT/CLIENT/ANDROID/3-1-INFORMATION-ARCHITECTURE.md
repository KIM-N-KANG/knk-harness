# 3-1 ACCOUNT Android 화면 구성

<br>

### 3-1-1 진입 화면

| 조건 | 표시 화면 |
|---|---|
| 세션 미판정 | 시작 화면 |
| 비로그인 | 로그인 화면, 필요한 경우 가입 동의 시트 |
| 저장 회원의 동의 확인 | 시작 화면, 필요한 경우 회원 동의 시트 |
| 로그인 뒤 동의 확인 | 로그인 화면과 진행 표시, 필요한 경우 회원 동의 시트 |
| 동의 완료 회원 | 회원 내비게이션. 첫 가입은 스토리 온보딩 |
| 종료 정리 실패 | 정리 재시도 화면 |

공통 화면 구성과 Android 진입 요구사항을 적용한다. ([공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md), [2-2-1](2-2-REQUIREMENTS.md#2-2-1-진입과-동의))

<br>

### 3-1-2 마이와 문서

| 화면 | 진입과 복귀 |
|---|---|
| 프로필 수정 | 마이 프로필 행 전체. 안쪽 연동 버튼은 자기 동작 유지, 마이로 복귀 |
| 페르소나 관리 | 이프 카드 아래, 이벤트 위의 페르소나 관리 |
| 페르소나 생성과 수정 | 관리 또는 스토리 상세에서 진입, 들어온 화면으로 복귀 |
| 친구 초대와 탈퇴 | 마이 회원 메뉴 |
| 법적 문서 | 로그인과 마이에서 문서 화면. 동의 시트에서는 그 위 전체 화면 창 |
| 문서 닫기 | 진입한 화면 또는 체크가 유지된 동의 시트 |
