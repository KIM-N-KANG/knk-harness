# 3-3 ACCOUNT Android 화면 표현

<br>

### 3-3-1 공통 화면의 Android 표현

| 영역 | 표시 |
|---|---|
| 가입 혜택 | "지금 가입하고 N 이프 받기". N 바로 앞 이프 마크, 특정 공급자를 가리키지 않음 |
| 로그인 실패와 종료 안내 | 가입 혜택 배지 위 |
| 시작 화면 | 로고 심벌, 확인이 길어지면 제자리에서 튀는 로딩. 시스템 스플래시는 첫 프레임까지만 유지 |
| 조회 실패 재시도 | 앱의 공통 문구 "다시 시도" |
| 프로필 프리셋 | 4열, 격자 높이는 화면의 70% 이내에서 스크롤 |
| 동의 시트 | 공통 배치, 끌어내리기와 바깥 탭 차단. 전체 화면 문서 창은 시트 위 표시 |
| 페르소나 선택 요약 | 상세 CTA 라벨 아래 `labelTiny` 한 줄, 선택한 페르소나와 시작 상황. 전체 높이는 하트 버튼과 같은 48dp |

나머지 문구와 배치는 공통 ACCOUNT 화면을 적용한다. ([공통 3-3](../3-3-LAYOUT.md))
