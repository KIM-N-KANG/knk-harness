# 2-2 ACCOUNT Android 요구사항

<br>

### 2-2-1 진입과 동의

공통 요구사항의 Android 적용 범위를 구체화한다. ([공통 2-2-1](../2-2-REQUIREMENTS.md#2-2-1-적용-범위))

| 상황 | 조건과 결과 |
|---|---|
| 비로그인 | 로그인 필수. 게스트 온보딩, 로컬 서재와 이관, 게스트 체험 선차단 비적용 |
| 법적 문서 | 로그인 전 열람 허용, 닫으면 진입 화면 복귀 |
| 가입 대기 | 로그인 화면 위 동의 시트. 새 로그인은 이전 대기 폐기, 프로세스 재시작 후 로그인부터 재개 |
| 가입 대기 취소 | 로그아웃 버튼과 뒤로가기는 대기 취소. 제출 중 무시 |
| 가입 완료 후 확인 | 서버 필수 동의 재확인까지 로그인 화면 유지, 소셜 버튼 잠금. 뒤로가기는 로그아웃 |
| 저장 세션 기동 | 시스템 스플래시 뒤 시작 화면에서 동의 확인. 완료하면 로그인 화면 없이 회원 화면 |
| 시작 조회 실패 | 일시 실패는 재시도만 제공. 뒤로가기는 앱 종료, 세션 유지 |
| 시작 재동의 | 시작 화면 위 동의 시트. 시트의 거절과 뒤로가기는 세션 종료 |
| 권한 거절 | 이용 제한과 로그아웃만 표시. 일반 403과 계정 정지를 혼동하지 않음 |
| 동의 전 | 회원 화면 생성, 외부 목적지 소비, 분석 식별, 푸시 등록, 프로필 및 회원 체험 조회 차단 |
| 동의 완료 | 회원 화면과 알림 권한 요청 → 선택 동의 처리 → 초대 안내 → 광고 재질문 |
| 첫 회원 화면 | 신규 가입은 스토리 온보딩. 초대 안내는 가입 실행을 건너뛴 다음 실행의 홈 |
| 세션 판정 중 | 로그인과 회원 화면 어느 쪽도 확정하지 않음 |
| 정리 실패 | 복구와 재시도 화면, 완료 전 새 로그인 금지 |
| 일시적 세션 복원 실패 | 네트워크 실패만으로 세션 폐기하지 않음. 무한 대기 금지 |

첫 스토리 온보딩의 내용은 기존 STORY 계약에 있다. ([신규 가입 온보딩](../../../STORY/CLIENT/ANDROID/2-2-REQUIREMENTS.md))

### 2-2-2 편집과 법적 문서

| 대상 | 조건과 결과 |
|---|---|
| 프로필 | 저장과 이탈 후 마이 복귀. 저장 중 뒤로가기 차단. 헤더와 기기 뒤로가기는 같은 이탈 확인 |
| 프로필 반영 | 마이와 재기동 프로필 갱신. 홈 작성자는 조용히 재조회하고 실패를 알리지 않음 |
| 페르소나 | 저장 후 스토리 상세 또는 관리 목록 복귀. 기존 채팅 유지 |
| 편집 상태 | 입력, 선택한 프리셋과 시트 및 확인창은 구성 변경에서 유지. 프로세스 종료 뒤 복원하지 않음 |
| 문서 창 | 동의 시트 위 전체 화면으로 열고 닫으면 체크 유지 |
| 문서 링크 | 앱 안 문서 화면, 외부 HTTP(S)는 외부 브라우저. 같은 호스트의 문서 외 경로와 다른 스킴 차단 |
| 게스트 안내 | 웹 브라우저 전용임을 표시 |
| 초대 | 시스템 복사와 공유, 서버 보상 수치 사용 |
| 안내 닫기 기록 실패 | 현재 실행에서 시트 닫기와 재표시 및 재제출 차단. 다음 실행 재확인 가능 |
| 보상 후 닫기 실패 | 지급 결과와 닫기 실패를 구분, 보상 재요청 없음 |
