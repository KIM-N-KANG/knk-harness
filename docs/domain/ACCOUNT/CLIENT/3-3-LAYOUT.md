# 3-3 ACCOUNT 화면 배치

<br>

### 3-3-1 로그인과 필수 동의

| 영역 | 구성 |
|---|---|
| 로그인 버튼 위 | "지금 가입하고 N 이프 받기". 서버 가입 보상 수치, 조회 전 자리표시 숫자 |
| 소셜 버튼 | 카카오, Google 순서. 진행 중 문구 영역 크기를 유지한 중앙 스피너 |
| 버튼 아래 | 서비스 이용약관과 개인정보 처리방침 링크. 동의 간주 문구와 이관 안내 없음 |
| 동의 시트 제목 | "서비스 이용을 위해 동의가 필요해요", 보조 설명 없음 |
| 동의 목록 | 전체 동의 → 필요한 "[필수] 만 14세 이상입니다", "[필수] 서비스 이용약관 동의", "[필수] 개인정보 처리방침 동의" → 선택 광고성 정보 수신 동의와 보조 설명 |
| 문서 항목 | 보기 버튼 |
| 하단 | 동의하기, 보조 로그아웃 버튼. 스와이프 핸들 없음 |
| 간격 | 제목과 목록, 목록과 버튼 각각 32px. 항목 최소 높이 48px, 줄 간격 8px, 체크박스 20px, 라벨 간격 12px |
| 구분선과 초점 | 전체 동의 아래 구분선은 줄 간격 안. 초기 초점은 시트 자체 |

수치 표시는 공용 이프 표시 규칙을 적용한다. ([이프 정책 수치 표시](../../../spec/3-1-client-spec.md#이프-정책-수치-표시))

<br>

### 3-3-2 프로필 수정

| 영역 또는 상태 | 표시 |
|---|---|
| 골격 | "프로필 수정" 뒤로가기 헤더, 스크롤 본문, 하단 고정 "저장하기" |
| 이미지 | 본문 위쪽 가운데 원형 버튼과 연필 표시. 접근 이름 "프로필 이미지 바꾸기" |
| 닉네임 | 현재 값, 최대 20자와 카운터. "한글, 영문, 숫자로 2~20자까지 쓸 수 있어요" |
| 프로필 조회 | 로딩은 이미지와 입력 자리 골격. 실패는 "프로필을 불러오지 못했어요", "다시 시도하기" |
| 이미지 시트 | "프로필 이미지", 응답 순서의 4열 프리셋. 접근 이름은 프리셋 키 |
| 프리셋 선택 | 현재 이미지 URL과 같은 항목에 선택 테두리와 선택 상태. 일치 항목 없으면 미선택 |
| 프리셋 조회 | 로딩은 격자 골격. 실패는 "이미지를 불러오지 못했어요", "다시 시도하기" |
| 2자 미만 | 닉네임 안내 대신 "닉네임은 2자 이상 입력해 주세요" |
| 허용하지 않는 문자 | 닉네임 안내 대신 "한글, 영문, 숫자만 쓸 수 있어요" |
| 저장 중 | 입력과 이미지 버튼 잠금. 같은 버튼 크기의 스피너, "프로필 저장 중" |
| 저장 성공 | "프로필을 저장했어요" 토스트 |
| 닉네임 중복 또는 서버 입력 거절 | "이미 사용 중인 닉네임이에요" 또는 "쓸 수 없는 닉네임이에요" 필드 오류 |
| 그 밖의 저장 실패 | "프로필을 저장하지 못했어요" 토스트 |
| 이탈 확인 | "저장하지 않은 내용이 있어요", "지금 나가면 수정한 내용이 사라져요", 닫기, 나가기 |

필드 검증, 입력 유지와 이탈 동작은 프로필 요구사항과 화면 흐름을 적용한다. ([2-2-3](2-2-REQUIREMENTS.md#2-2-3-프로필과-페르소나), [3-2-2](3-2-INTERACTION-FLOWS.md#3-2-2-프로필과-페르소나))

### 3-3-3 페르소나 생성과 수정

| 영역 또는 상태 | 표시 |
|---|---|
| 생성 골격 | "페르소나 생성" 뒤로가기 헤더, 스크롤 본문, 하단 고정 "생성하기" |
| 생성 제목과 설명 | "어떤 사람으로 플레이할까요?", "만든 페르소나는 어떤 스토리에서든 고를 수 있어요" |
| 기본 정보 | 이름과 20자 카운터, 성별 Select를 한 줄에 배치. "스토리 속에서 불릴 이름과 성별이에요" |
| 특징 | 500자 글 칸과 카운터. "어떤 사람인지에 따라 인물들의 반응이 달라져요" |
| 입력 오류 | "이름을 입력해 주세요", "성별을 선택해 주세요", "특징을 입력해 주세요". 기본 정보는 이름 오류 우선, 해당 칸 수정 시 해제 |
| 수정 골격 | "페르소나 수정", "수정한 내용은 새로 시작하는 채팅부터 적용돼요", "저장하기" |
| 요청 중 | 입력 잠금, 버튼 크기를 유지한 스피너. "페르소나 생성 중" 또는 "페르소나 저장 중" |
| 성공 | "페르소나를 생성했어요" 또는 "페르소나를 수정했어요" |
| 실패 | "페르소나를 생성하지 못했어요" 또는 "페르소나를 수정하지 못했어요" |
| 없는 수정 대상 | "페르소나를 찾을 수 없어요" |
| 개수 상한 | "페르소나는 10개까지 만들 수 있어요" |

### 3-3-4 페르소나 관리

| 영역 또는 상태 | 표시 |
|---|---|
| 목록 | "페르소나 관리" 뒤로가기 헤더. 응답 순서로 굵은 이름과 특징 요약 최대 두 줄, 넘으면 말줄임 |
| 요약 | 소개에서 성별 절과 `#`로 시작하는 절 제목 줄을 제외하고 나머지 줄 연결 |
| 펼침 | 이름 전체와 특징 원문 전체, 절 제목과 줄바꿈 유지 |
| 조회 중, 실패, 빈 목록 | 스피너 / "페르소나를 불러오지 못했어요"와 "다시 시도하기" / "아직 만든 페르소나가 없어요" |
| 추가 | 마지막 행 또는 빈 안내 아래 가운데 더하기 아이콘과 "페르소나 추가". 일반 제작 "인물 추가"와 같은 보조 버튼 |
| 옵션 | 행 오른쪽 "{이름} 페르소나 옵션". 종류 "페르소나", 제목은 이름, 수정하기와 위험색 삭제하기 순서 |
| 삭제 확인 | "페르소나를 삭제할까요?", "이 페르소나로 진행 중인 채팅은 그대로 이어갈 수 있어요", 남겨두기, 위험색 삭제하기 |
| 삭제 결과 | "페르소나를 삭제했어요" 또는 "페르소나를 삭제하지 못했어요" |

### 3-3-5 연동과 초대

| 영역 | 표시 |
|---|---|
| 연동 계정 | Google, Kakao 순서. 연동됨은 로고와 이름 Chip, 미연동은 점선 "Google 연동하기" 또는 "카카오 연동하기" |
| 연동 확인창 | 같은 계정 이용 혜택, 현재 공급자 재인증 후 대상 공급자 연동 순서, 해제 불가. 나중에 하기와 연동하기, X 버튼 없음 |
| 초대 화면 | "친구가 내 초대 코드를 등록하면 모두 N 이프를 받아요". 코드와 월 보상 횟수 카드, 복사와 공유 버튼 |
| 초대 안내 시트 | "초대 코드를 등록하면 / N 이프를 받을 수 있어요", "지금은 건너뛰고 나중에 등록해도 돼요" |
| 시트 입력 아래 | 등록하기, 닫기 세로 배치. 초기 초점은 시트 자체 |
| 지급 후 닫기 실패 | "N 이프는 정상 지급되었지만, 창을 닫는 데 실패했어요". 같은 크기와 정렬의 닫기 재시도 |

N은 서버 초대 보상 수치이다. ([2-2-4 연동과 초대](2-2-REQUIREMENTS.md#2-2-4-연동과-초대))

### 3-3-6 탈퇴와 공통 오류

| 영역 또는 상태 | 표시 |
|---|---|
| 탈퇴 골격 | 뒤로가기 헤더, 확인 목록, 하단 위험색 CTA |
| 탈퇴 제목과 설명 | "탈퇴하기 전에 / 아래 내용을 모두 확인해주세요", "모든 항목을 확인해야 탈퇴할 수 있어요" |
| 탈퇴 제출 | "회원 탈퇴하기", 요청 중 같은 크기의 "회원 탈퇴 중" 스피너 |
| 탈퇴 일시 실패 | "회원 탈퇴에 실패했어요" |
| 이미 연동됨 | "이미 연동된 계정이에요" 토스트 |
| 다른 회원에 연동됨 | 현재 계정에 연결할 수 없다는 설명과 로그아웃 후 해당 계정 로그인 안내 다이얼로그. 확인 버튼만 제공 |
| 연동 신원 확인 실패 | "계정 연동에 실패했어요" 토스트 |
| 동의 저장 일시 실패 | "약관 동의 내역을 저장하지 못했어요"와 재시도 |
| 가입 대기 만료 | "로그인 시간이 지났어요. 다시 로그인해주세요" |
| 가입 중 동의 요구 변경 | "약관이 갱신되었어요. 다시 로그인해주세요" |

네 가지 탈퇴 확인 항목과 오류별 복구 결과는 요구사항에 있다. ([2-2-5](2-2-REQUIREMENTS.md#2-2-5-종료와-데이터-보호), [2-2-6](2-2-REQUIREMENTS.md#2-2-6-실패와-복구-결과))
