### 5-1-2 기록 규칙

- P0는 주요 흐름과 데이터 유실 위험으로 릴리스마다 확인한다. P1은 주요 기능과 오류 안내로 시간이 허락하면 확인하며, P2는 우회 가능한 경계와 표현 품질로 회귀가 의심되는 영역을 확인한다.
- QA ID는 재사용하지 않는다. 기존 자동화 표시는 이번 실행 결과가 아니며 skip은 검증 완료가 아니다.
- 계약과 구현이 다르면 기대 결과를 구현에 맞춰 바꾸지 않고 차이를 Jira에 기록한다.
- 실행한 커밋, 환경, 실제 기기 여부와 결과는 PR 및 CI에 남긴다. 여러 화면에 걸친 사례는 한 문서에서 소유하고 다른 문서에서 참조한다.
- 픽스처와 모의 응답은 실제 서버와 배포 검증으로 표시하지 않는다. 문서 변경은 링크, 앵커, 유저 스토리와 QA ID 중복을 확인하고 git diff --check를 실행한다.
