### 3-2-1 기록과 뒤로가기

| 조작 | 결과 |
|---|---|
| 하단 탭 이동 | 현재 기록 교체, 탭 전환 이력을 뒤로 순회하지 않음 |
| 앱 안에서 온 하위 화면 헤더 | 바로 아래가 같은 문서에서 이동한 실제 화면 기록이면 뒤로 이동 |
| 직접 진입한 하위 화면 헤더 | 각 도메인의 기본 복귀 화면으로 교체. 공지 목록과 알림함은 홈, 공지 상세는 목록, 마이 하위는 마이 |
| 삭제나 제작 종료로 탭 복귀 | 가장 가까운 아래 탭 기록까지 되돌아감. 다른 탭이면 목적 탭을 그 위에 쌓고 같은 탭이면 멈춤 |
| 아래 기록을 모름 | 현재 화면을 목적 탭으로 교체. 이전 문서 기록인 경우도 같으며 떠나며 띄운 토스트 유지 |
| 사용자가 연 오버레이 | 같은 주소의 기록 한 칸, 뒤로가기면 최상위만 닫힘. UI 닫기에서도 칸을 소비해 빈 앞으로가기 기록 없음 |
| 자동으로 열린 안내 | 기록을 쌓지 않음. 뒤로가기는 화면 이탈 |
| 시트 안에서 다른 화면 이동 | 오버레이 기록을 먼저 소비한 뒤 이동 |
| 제작 이탈 확인 | 위 시트가 열렸으면 시트만 닫음. 직접 진입은 첫 입력부터 이탈 확인 적용 |

탭별 스크롤은 문서 수명 안에서 기억한다. 아직 내용이 짧으면 자라는 동안 복원하며 새로고침과 새 탭에서는 맨 위로 시작한다. 같은 사이트의 미존재 화면은 새 문서여도 이전 기록이 있으면 이전 화면으로 돌아갈 수 있다.

<br>

### 3-2-2 새로고침과 가로 탐색

홈, 채팅, 제작, 공지 목록, 알림함의 소식과 활동, 이프 충전의 무료 충전과 내역은 맨 위에서 터치로 당겨 새로고침한다. 마이에는 제공하지 않는다. 마우스와 펜 당김은 없으며 커서도 바꾸지 않는다. 기존 내용은 응답까지 유지하고 실패 안내는 각 목록 계약을 따른다.

가로 영역은 터치 스와이프와 마우스 드래그로 이동한다. 드래그 뒤 클릭으로 칩이나 탭이 선택되지 않으며 카드 스냅 영역은 가장 가까운 카드에 맞춘다.

<br>

### 3-2-3 앱 열기와 복귀

Android 배너는 상세에서 같은 스토리, 다른 화면에서 앱 홈을 연다. 앱이 열리지 않으면 0.7초 뒤 Play 스토어 앱으로 이동하고 이미 화면이 숨겨졌으면 취소한다. iOS 외부 전환은 1.5초 동안 화면이 그대로면 여는 방법과 링크 복사를 안내한다.

`/app`은 Android 앱 홈을 시도하고 0.7초 뒤에도 그대로면 스토어로 교체한다. 카카오톡 인앱은 먼저 외부 브라우저로 여는 단계를 거친다. 다른 기기는 홈으로 교체한다. 앱 복귀 후에는 받기와 웹 둘러보기 버튼이 있는 화면에 머문다.
