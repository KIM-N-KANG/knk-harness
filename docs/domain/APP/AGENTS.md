# APP 도메인

앱 전체 탐색, 테마, 서비스 안내와 외부 앱 진입을 다룬다. 계정, 작품, 플레이, 결제와 알림의 기능 계약은 각 도메인에서 관리한다.

<br>

### 1 세트

| 세트 | 범위 |
|---|---|
| [CLIENT](CLIENT/AGENTS.md) | 공통 사용자 목표와 화면 계약, WEB과 ANDROID 차이 |

공통 기술 규칙은 [플랫폼 기반](../../platform/AGENTS.md), 문서 배치는 [클라이언트 작성 가이드](../../reference/CLIENT-SPEC-WRITING-GUIDE.md)를 따른다.
