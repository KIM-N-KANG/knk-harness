### 3-2-1 이동과 복귀

앱 안에서 열었으면 뒤로가기 헤더가 히스토리를 되돌린다. 주소나 알림으로 직접 연 공지 목록과 알림함은 홈으로, 공지 상세는 공지 목록으로, 알림 설정은 마이로 replace한다.

알림 카드는 허용된 목적지가 있으면 링크로 즉시 이동하고 읽음 요청은 뒤에서 마친다. 갈 곳이 없으면 버튼으로 읽음만 처리한다. 알림함 분류 탭은 URL에 남기지 않는다.

공지 및 알림 목록의 당김은 터치에서만 동작하고 기존 내용을 응답까지 유지한다. 각 알림 탭은 자기 목록을 새로 읽는다.
