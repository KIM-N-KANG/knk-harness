# 2-2 웹 NOTIFICATION 요구사항

기준: [공통 요구사항](../2-2-REQUIREMENTS.md).

<br>

### 2-2-1 브라우저와 설정

| 조건 | 결과 |
|---|---|
| 푸시 설정 없음 | 서비스 워커, 토큰 발급과 프롬프트 모두 비활성. CI E2E와 설정 없는 Preview에 적용 |
| 알림 권한 미결정 | 기기당 한 번 자동 요청. 신규 회원은 필수 동의 제출 클릭 직전에 요청. 브라우저가 무시하면 설정의 알림 켜기 사용 |
| 차단 | 자동 재요청하지 않음. 설정에서 사이트 권한을 바꾸는 방법 안내 |
| iOS 비설치 | 권한 요청하지 않고 홈 화면 추가 안내 |
| 지원하지만 수신 불가 | 권한 미결정, 차단과 iOS 비설치에서는 수신 동의 행 비활성 |
| 브라우저 미지원 | 기기 수신 안내만 제공. 계정의 다른 기기 수신 동의를 관리할 수 있도록 설정 행은 활성 |
| 오프라인 | 토큰 발급을 건너뛰고 연결 복구 뒤 현재 회원과 권한을 다시 확인해 재시도 |
| 열린 앱 | 배경 알림 탭은 같은 origin의 열린 창을 목적지로 이동해 앞으로 가져옴. 없으면 새 창 |
| 전경 수신 | 현재 회원과 recipientId가 일치한 메시지만 토스트 |

신규 가입 안내가 예정되어 있으면 끝난 뒤 광고 재질문을 연다. 바깥 탭과 뒤로가기는 닫기와 같다. 처리 결과를 닫을 때 브라우저 알림이 꺼져 있으면 “브라우저 알림이 꺼져 있어 알림 설정에서 켜야 받을 수 있어요”를 알린다.
