# 3-3 화면 배치: 웹

기준: [공통 표현](../3-3-LAYOUT.md), [웹 이동](3-2-INTERACTION-FLOWS.md).

<br>

### 3-3-1 목록과 설정

| 조건 | 표현 |
|---|---|
| 공지와 알림 제목 | 최대 두 줄. 공지 행은 눌러도 배경 변화 없음 |
| 재시도 | 다시 시도하기 |
| 권한 미결정 | 브라우저 알림 설정이 꺼져 있어요, 알림 켜기 |
| 권한 요청 거부 | 브라우저 알림이 차단되어 있어요 토스트와 차단 배너 |
| 차단 안내 | 방법 보기 버튼, 사이트 설정에서 허용하는 방법 다이얼로그 |
| iOS 비설치 | 홈 화면 추가 안내, 요청 버튼 없음 |
| 미지원 | 지원하지 않는 브라우저 안내, 요청 버튼 없음 |
| 권한 허용 | 기기 상태 배너 없음 |
| 광고 행 | 라벨 옆 외부 링크 아이콘으로 개인정보 처리방침을 새 탭에서 열기 |
| 광고 재질문 | “이벤트·혜택 소식을 알림으로 받아 볼까요?”, 광고 알림 받기와 닫기 |

공지 목록, 상세와 알림함의 문서 제목은 공용 웹 기본 제목을 유지한다. 화면의 공지사항 및 알림 헤더는 그대로 표시한다.
