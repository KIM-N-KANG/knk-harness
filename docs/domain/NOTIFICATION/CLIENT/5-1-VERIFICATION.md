### 5-1-1 목표별 검증 경계

| 유저 스토리 | 요구사항 | 확인 |
|---|---|---|
| NOTIFICATION-US-001 | [공지](2-2-REQUIREMENTS.md#2-2-2-공지사항) | 30일, 100개, 상세 성공과 404, 계정 전환, 태그와 평문, 페이지 실패 |
| NOTIFICATION-US-002 | [알림함](2-2-REQUIREMENTS.md#2-2-3-회원-알림함) | 분류와 최초 소식, 읽음 및 전체 복원, 링크 대체, 공개 제한의 의미와 제작 탭 이동, 페이지 실패와 공지 기록 분리 |
| NOTIFICATION-US-003 | [푸시](2-2-REQUIREMENTS.md#2-2-4-푸시와-계정-격리) | 권한, 등록과 종료 경합, 수신자, 잘못된 링크, 로그인 대기와 프로세스 복원 |
| NOTIFICATION-US-004 | [동의](2-2-REQUIREMENTS.md#2-2-5-수신-동의와-설정) | 선택 동의, 세 번째 재진입과 종료 조건, 야간 분리, 전체 저장과 실패 복원 및 처리 결과 |

단위 테스트와 모킹은 실제 FCM 발송, 브라우저 및 OS 권한, 배경 표시와 푸시 탭 결과를 대신하지 않는다. 실제 실행 환경과 결과는 PR 및 CI에 기록한다.
