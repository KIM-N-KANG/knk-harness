### 1-1 사용자와 목적

사용자는 서비스 공지를 확인하고, 받은 알림으로 제작 결과와 필요한 화면을 다시 찾는다. 푸시를 받을 수 있는 기기 상태와 계정의 수신 동의를 구분해 관리한다.

| 범위 | 책임 |
|---|---|
| 공지사항 | 게시된 공지 목록과 평문 상세, 기기별 읽음 표시 |
| 알림함 | 회원에게 발송 시점에 기록한 알림 사본과 서버 읽음 상태 |
| 푸시 | 토큰 등록, 권한, 수신과 표시, 탭 진입 |
| 알림 설정 | 서비스, 광고와 야간 광고 수신 동의 |
| 다른 도메인 | ACCOUNT의 회원과 동의, STORY의 제작 상태, PAYMENT의 보상과 내역 |

푸시 수신 실패나 차단은 회원 알림함에서 기록을 읽는 기능과 별개다. 알림을 열었다는 이유로 출석이나 보상을 실행하지 않는다.
