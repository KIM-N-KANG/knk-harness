# NOTIFICATION 공통 상태 관리

기준: [연동 계약](CONTRACT.md).

<br>

### 읽음의 기준

| 상태 | 기준과 수명 |
|---|---|
| 공지 읽음 | 기기 최신순 ID 목록 최대 100개. 같은 ID를 맨 앞으로 옮기고 초과 기록 제거. 로그아웃과 계정 전환에도 유지 |
| 공지 안 읽음 | 게시 30일과 읽은 ID로 계산. 공지 상세 성공이 기록 계기 |
| 회원 알림 | 서버 목록, readAt과 안 읽은 수. 계정의 서버 기록이 기준 |
| 낙관적 읽음 | 한 건은 해당 카드, 모두 읽음은 분류 전체 스냅숏을 사용. 모두 읽음 실패 때 복원 |
| 수신 동의 | 서버 세 boolean이 기준. 저장 중 값과 실패 복원 스냅숏을 구분 |
| 광고 질문 | 회원 귀속의 질문 단계와 재진입 횟수. 로그아웃 정리 |
| OS 권한 | 기기 권한. 서버 광고 동의와 같은 상태로 저장하지 않음 |

개인 알림 목록, 푸시 수신자와 보류 목적지를 다음 계정에 넘기지 않는다. 공지 읽음은 회원 알림 읽음과 별도 저장소다.
