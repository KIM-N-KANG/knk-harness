# 3-3 NOTIFICATION 화면 표현

기준: [화면 흐름](3-2-INTERACTION-FLOWS.md).

<br>

### 3-3-1 공지

| 요소 | 표현 |
|---|---|
| 태그 | SERVICE 서비스, UPDATE 업데이트, MAINTENANCE 점검, EVENT 이벤트, PROMOTION 혜택. 점검만 주의색, 나머지 보조 배지. 미지원 값은 숨김 |
| 목록 | 태그, 제목과 KST YYYY-MM-DD. 행 전체가 상세 이동 대상이며 좌우 전체 폭, 테두리 없음 |
| 안 읽은 줄 | 굵은 제목, 제목 끝 작은 빨간 점. 보조 기술 이름 새 공지 |
| 마이 메뉴 | 공지사항 오른쪽 연한 빨간 배경의 새 공지 배지 |
| 게스트 헤더 | 확성기 아이콘, 새 공지가 있으면 오른쪽 위 빨간 점과 새 공지사항 있음. 없으면 공지사항 |
| 상세 | 태그, 제목, 게시 YYYY-MM-DD와 조건부 수정 YYYY-MM-DD, 줄바꿈을 보존한 본문 |
| 로딩 | 실제 구조와 맞춘 지연 스켈레톤 |
| 빈 목록 | 아직 등록된 공지가 없어요 |
| 조회 실패 | 공지사항을 불러오지 못했어요 |
| 상세 없음 | 공지를 찾을 수 없어요, 공지사항 목록으로 |

<br>

### 3-3-2 알림함

| 요소 | 표현 |
|---|---|
| 헤더 | 알림, 모두 읽음 보조 버튼과 알림 설정 톱니 |
| 회원 종 버튼 | 안 읽은 total이 있으면 빨간 점과 새 알림 있음, 없으면 알림 |
| 탭 | 소식과 활동 라인 탭. 안 읽음이 있는 탭 라벨 오른쪽 위 작은 빨간 점, 보조 기술 이름 안 읽은 알림 있음 |
| 카드 | 테두리 없는 전체 폭. 위 왼쪽 분류 라벨, 오른쪽 상대 시각, 아래 제목과 최대 두 줄 본문 |
| 유형 라벨 | 공지, 이벤트, 스토리 완성, 검토 결과, 출석 체크, 이프 만료, 공개 제한. 공지 태그가 있으면 유형보다 우선 |
| 안 읽은 카드 | 굵은 제목과 제목 끝 빨간 점, 보조 기술 이름 안 읽음 |
| 읽은 카드 | 제목과 본문 보조색 |
| 소식 없음 | 아직 받은 소식이 없어요 / 공지와 이벤트 소식이 여기에 모여요 |
| 활동 없음 | 아직 활동 알림이 없어요 / 스토리가 완성되거나 검토가 끝나면 알려 드려요 |
| 조회 실패 | 알림을 불러오지 못했어요 |
| 모두 읽음 실패 | 알림을 읽음 처리하지 못했어요 |
| 로딩 | 카드 구조의 지연 스켈레톤 |

<br>

### 3-3-3 설정과 동의

| 요소 | 표현 |
|---|---|
| 설정 행 | 라벨과 설명, 오른쪽 스위치. 서비스 알림, 광고 알림, 조건부 야간 광고 허용 순서 |
| 조회 중 | 스위치 자리의 골격 |
| 조회 실패 | 알림 설정을 불러오지 못했어요, 재시도 |
| 저장 실패 | 알림 설정을 저장하지 못했어요 |
| 재질문 | 이벤트와 혜택 소식을 알림으로 받을지 묻는 제목과 한 줄 설명, 광고 알림 받기와 닫기 |
| 처리 결과 | 전송자: … / 일시: … / 처리 내용: … 세 줄과 확인 |

처리 내용은 광고 또는 야간 광고 알림 수신 동의 완료와 철회 완료를 구분한다. 야간 동의나 개인정보 고지를 재질문 시트 안에 별도 입력으로 추가하지 않는다.
