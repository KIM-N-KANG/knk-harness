# NOTIFICATION 화면 구성

기준: [요구사항](REQUIREMENTS.md).

<br>

### 화면과 진입점

| 화면 | 진입과 정보 |
|---|---|
| 공지 목록 | 마이 알림 섹션, 웹 게스트 헤더. 공지사항 뒤로가기 헤더와 게시 최신순 목록 |
| 공지 상세 | 목록, 공지 알림이나 직접 링크. 태그, 제목, 게시 및 수정일과 본문 |
| 알림함 | 회원 메인 세 탭 헤더 종. 알림 뒤로가기 헤더 오른쪽 모두 읽음, 그 오른쪽 알림 설정 톱니. 소식과 활동 탭 |
| 알림 설정 | 마이 알림 섹션, 알림함 톱니. 기기 상태와 서비스, 광고, 야간 광고 설정 |
| 광고 재질문 | 권한과 신규 가입 안내를 마친 뒤 조건부 시트 |
| 처리 결과 | 시트 또는 설정에서 변경한 결과 다이얼로그 |

마이의 알림 섹션은 화면과 기타 섹션 사이이며 알림 설정 아래에 공지사항을 둔다. 웹 게스트에게는 공지사항만 보인다.
