# Android NOTIFICATION 요구사항

기준: [공통 요구사항](../REQUIREMENTS.md).

<br>

### 기기와 수명

| 조건 | 결과 |
|---|---|
| 공지 목록 | 앱 공용 눌림 리플. 기존 목록에서만 당김 새로고침, 실패는 목록 유지와 토스트 |
| 공지 표시 갱신 | 셸이 다시 보일 때 첫 페이지를 읽어 판정. 실패하면 새 공지 점과 배지 끔 |
| 알림함 갱신 | 셸이 다시 보일 때 안 읽은 수를 갱신. 실패하면 헤더 점 끔 |
| 알림함 구성 변경 | 선택 탭과 탭별 목록 및 스크롤 유지. 새 진입은 소식 |
| 개인 알림 수명 | 회원 화면 수명에만 유지. 계정이 바뀌면 이전 목록을 표시하지 않음 |
| 검수 알림 | 서버 제목과 본문 사용. 다른 제출본은 별도, 같은 제출본 재발송은 교체. 잠금 화면 공개 버전은 제목만 |
| 권한 거부 | 설치 단위 반복 요청 방지. 로그아웃으로 질문 기록을 지우지 않음 |
| 광고 질문 | 회원 귀속 기록, 로그아웃 정리. 질문 기록 저장 실패는 시트 유지 |
| 동의 알림 | 기기 알림이 꺼진 채 동의한 결과를 닫으면 “기기 알림이 꺼져 있어 알림 설정에서 켜야 받을 수 있어요” 안내 |

알림 설정 토글은 행 전체가 아닌 스위치가 받는다. 광고 행에서 개인정보 처리방침을 연다.
