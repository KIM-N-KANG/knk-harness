# 2-1 유저 스토리

### 2-1-1 소식과 알림

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| NOTIFICATION-US-001 | 서비스 사용자 | 앱 안에서 공지와 새 공지 여부를 확인하고 싶다 | 점검과 업데이트 및 정책 변경 소식을 놓치고 싶지 않다 |
| NOTIFICATION-US-002 | 회원 | 받은 알림과 읽지 않은 알림을 구분하고 관련 화면으로 가고 싶다 | 푸시를 놓치거나 지운 뒤에도 제작 결과와 소식을 다시 찾고 싶다 |
| NOTIFICATION-US-003 | 회원 | 필요한 알림을 기기에서 받고 눌러 관련 화면을 열고 싶다 | 결과를 기다리며 같은 화면을 계속 확인하지 않고 싶다 |
| NOTIFICATION-US-004 | 회원 | 서비스, 광고와 야간 광고 알림 수신을 직접 선택하고 결과를 확인하고 싶다 | 원하는 소식과 시간대에 맞춰 알림을 관리하고 싶다 |
