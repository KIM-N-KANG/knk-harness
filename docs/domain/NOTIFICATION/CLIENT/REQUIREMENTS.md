### 적용 범위와 구분

| 기능 | 웹 | Android |
|---|---|---|
| 공지 | 게스트와 회원, 인증 없는 공개 조회 | 로그인 이후 화면, API는 공개 조회 |
| 회원 알림함과 설정 | 회원 전용, 게스트는 로그인 이동 | 로그인과 필수 동의를 마친 회원 전용 |
| 푸시 지원 | 데스크톱과 Android 브라우저, iOS 16.4 이상 홈 화면 설치본 | FCM과 OS 알림 |
| 초기 권한 요청 | 회원 화면 첫 진입, 페이지 로드 단위. 신규 동의 제출 클릭 경로 포함 | 회원 메인 그래프 첫 진입, 설치 단위 한 번 |
| 광고 재질문 재진입 단위 | 페이지 로드 | 회원 화면이 처음 그려지는 프로세스 실행 |
| 공지와 알림 제목 | 최대 두 줄 | 한 줄, 안 읽음 점은 말줄임 밖 유지 |
| 목록 당겨 새로고침 | 각 목록의 공용 웹 당김 | 기존 목록이 있을 때만. 첫 로딩과 빈 상태 및 오류에는 없음 |
| 알림 표시 | 전경 토스트, 배경 브라우저 알림 | 전경과 배경 모두 시스템 알림 |
| 수신자 검증 | 전경에서 현재 회원과 대조. 배경은 브라우저가 표시해 대조 불가 | 표시와 탭 모두 현재 회원과 대조 |

### 공지사항

NOTIFICATION-US-001.

| 조건 | 요구사항 |
|---|---|
| 진입 | 공지 전체는 마이의 알림 섹션에서 연다. 웹 게스트는 홈과 채팅 및 제작 헤더의 공지 버튼도 사용 |
| 목록 | 게시 최신순, 태그와 제목 및 게시일. 다음 페이지를 자동으로 이어 붙이고 별도 더 보기 없음 |
| 상세 | 태그, 제목, 게시일과 필요한 수정일, 평문 본문. 줄바꿈은 유지하고 Markdown 및 HTML로 해석하지 않음 |
| 수정일 | 수정 시각이 게시보다 늦고 KST 날짜도 다를 때만 표시 |
| 안 읽음 | 게시 30일 안이며 기기의 최근 읽은 ID 100개에 없으면 새 공지 |
| 읽음 계기 | 상세를 성공적으로 받았을 때만 기록. 목록만 열거나 상세 404면 기록하지 않음 |
| 범위 | 기기 귀속, 계정 전환과 로그아웃에도 유지. 다른 기기와 동기화하지 않음 |
| 목록 복귀 | 해당 줄의 점만 끄고 다른 새 공지가 남으면 헤더 점과 마이 배지 유지 |
| 실패 | 첫 조회는 재시도, 다음 페이지 실패는 기존 목록 유지와 수동 재시도. 자동 재요청 중단 |
| 없음 | 미게시와 삭제 등 상세 404는 공지 없음 안내와 목록 이동 제공 |

### 회원 알림함

NOTIFICATION-US-002.

| 조건 | 요구사항 |
|---|---|
| 기록 | 푸시를 보냈거나 보내지 못한 알림 모두 조회. 발송 시점 사본이며 원 공지와 스토리 수정으로 내용이 바뀌지 않음 |
| 진입 | 회원의 홈, 채팅 목록과 제작 헤더 종 버튼. 마이 헤더나 마이 메뉴에 알림함 추가하지 않음 |
| 분류 | 소식과 활동, 최초 진입은 소식. 분류는 URL에 남기지 않음 |
| 소식 | 공지와 이벤트. 공지 캠페인 시점의 활성 회원, 이벤트는 광고 동의 회원에게 기록. 가입 전이나 캠페인 없는 공지는 알림함에 없음 |
| 활동 | 스토리 완성, 검토 결과, 출석 체크, 이프 만료와 공개 제한 |
| 순서와 표시 | 분류별 최신순, 유형 라벨, 상대 시각, 제목과 본문. 알 수 없는 유형 라벨은 숨김 |
| 읽음 | readAt이 없으면 안 읽음. 카드와 탭 및 헤더 점이 같은 읽음 결과를 반영 |
| 카드 탭 | 안 읽은 경우에만 읽음 요청. 요청 결과를 기다리지 않고 허용된 목적지로 이동 |
| 이동 대상 | 허용된 서비스 deepLink, 공지 ID, 스토리 ID 순서. 모두 없으면 읽음만 기록 |
| 모두 읽음 | 현재 분류와 관계없이 전체 적용. 안 읽은 알림이 없으면 비활성 |
| 실패 복구 | 한 건 읽음은 조용히 실패 처리. 모두 읽음은 이전 상태로 복원하고 실패 안내 |
| 공지 알림 | 공지 상세를 성공적으로 열면 별도의 기기 공지 읽음 기록도 남김 |
| 페이지 실패 | 첫 조회는 재시도, 다음 페이지 실패는 기존 목록 유지와 수동 재시도. 자동 재요청 중단 |

### 푸시와 계정 격리

NOTIFICATION-US-003.

| 조건 | 요구사항 |
|---|---|
| 등록 | 회원과 필수 동의 확인 이후 등록. 웹은 알림 권한 허용도 필요. Android는 권한 거부가 세션과 토큰 등록을 막지 않음 |
| 권한 | OS 또는 브라우저 권한과 서버 수신 동의를 별도로 취급. 권한 거부를 반복해서 묻지 않음 |
| 종료 | 로그아웃, 탈퇴와 세션 종료에서 해당 기기 토큰 삭제를 시도. 실패 때문에 로그아웃을 막지 않음 |
| 웹 한계 | 배경 수신자는 대조할 수 없어 토큰 삭제가 방어선. 이 한계를 수신자 검증 완료로 표시하지 않음 |
| Android 격리 | 수신 회원을 확인하지 못하면 표시하지 않음. 탭 때 다른 회원이면 홈. 이전 계정 표시 알림과 보류 목적지 정리 |
| 링크 | 허용 범위를 벗어난 푸시 목적지는 홈. 푸시 링크를 보상 지급이나 출석 실행으로 사용하지 않음 |
| 로그인 대기 | Android는 목적지를 보류해 로그인 뒤 수신자를 다시 확인. 외부 인증 중 프로세스 종료에도 복원 |
| 검수 결과 중복 | Android는 해당 제출본 결과를 기다리는 화면 또는 같은 결과를 보여 준 뒤 2분 안에는 같은 알림 표시를 억제. 대기 상한 뒤 닫힌 화면은 억제하지 않음 |

### 수신 동의와 설정

NOTIFICATION-US-004.

| 조건 | 요구사항 |
|---|---|
| 첫 질문 | ACCOUNT 필수 동의 시트 맨 아래 선택 항목. 전체 동의에는 포함하고 완료 필수 조건에는 포함하지 않음 |
| 저장 | 선택 허용은 필수 동의 완료 후 서비스 설정을 유지하며 광고만 켬. 미선택은 첫 거절 기록 |
| 저장 실패 | 필수 동의 완료를 막지 않고 실패 안내. 설정 화면에서 다시 선택 가능 |
| 재질문 | 첫 거절 뒤 세 번째 회원 재진입에 한 번. 권한 응답과 신규 가입 안내 이후, 기기 알림이 켜져 있고 서버가 광고 미동의일 때만 |
| 재질문 종료 | 두 번째 거절 또는 한 번 허용 후 다시 묻지 않음. 닫기와 시트 바깥 닫기 조작은 거절 |
| 기록 | 회원 귀속. 로그아웃 정리 대상 |
| 야간 | 21:00~08:00 별도 동의. 재질문 시트에서 받지 않고 설정에서만 변경 |
| 설정 | 서비스 알림, 광고 알림, 야간 광고 허용. 야간 행은 광고가 켜졌을 때만 표시하고 광고를 끄면 야간도 끔 |
| 저장 결과 | 세 값을 전체 교체. 실패하면 이전 값 복원과 실패 안내. 조회 실패는 재시도 |
| 처리 결과 | 광고와 야간의 동의 및 철회 성공마다 전송자, 의사 표시 시점 기기 시각, 처리 내용을 즉시 통지. 서비스 변경과 저장 실패에는 통지하지 않음 |
| 기기 알림 꺼짐 | 동의 통지를 닫을 때 기기 또는 브라우저 설정에서 켜야 받을 수 있음을 안내 |
| 고지 | 개인정보 처리방침을 기준으로 하며 광고 설정 행에서 열 수 있음 |
