**OBS-AI-019. 설정 외부화와 오픈소스 전제**

|---|---|
| 날짜 | 2026-10-23 |

| 대안 | 시스템 설명서를 설정 파일의 한 절로 두는 안. 재생 구간마다 설정 파일 전체를 복제해야 하고 기준값을 바꿀 때 네 파일이 어긋날 수 있어 채택하지 않았다.<br>환경 변수로 비밀값을 받고 읽은 직후 지우는 안. 지우기를 빠뜨린 경로 하나로 `Bash`가 비밀값을 물려받는다. 비밀 파일 출처로 같은 일을 할 수 있어 채택하지 않았다.<br>운영 설정을 Secrets Manager 옆에 사람이 직접 올리는 안. 변경 검토와 이력이 남지 않아 채택하지 않았다.<br>운영 설정을 이미지에 넣는 안. 설정만 바꿔도 이미지를 다시 빌드해야 해서 채택하지 않았다. |
| 영향 | 탐지 기준값, 모델, 한도, 필드 이름은 코드가 아니라 설정을 고쳐 바꾼다. 기존 환경 변수 이름은 덮어쓰기 규칙에 맞춰 바뀐다(`DIAG_MODEL`은 `DIAG_MODEL_ID`, `AWS_REGION`은 `DIAG_AWS_REGION`). 채점기는 프롬프트 해시와 함께 `system_description`을 뺀 적용 설정 값이 실행 폴더끼리 같은지 확인한다. 운영 태스크 역할에 설정 파라미터 읽기가 더해진다. 영어 README, 라이선스, 프롬프트 영어판, 예시 데이터 정리 같은 공개 준비는 평가 뒤 단계에서 한다.<br>2026-10-24 정리: `system_description`, `log_samples`, `fields.log.message`, `action_repositories`, `limits.approval_wait_seconds`를 빼고 `limits.coordination_turns`를 `limits.conversation_turns`로 바꿈. `aws.profile`, `prometheus.workspace_url`, `service_map`을 더함. |
