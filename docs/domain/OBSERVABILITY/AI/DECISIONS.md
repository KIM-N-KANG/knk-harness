**OBS-AI-005. 채점은 필드별 규칙과 사람 채점을 섞음**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-15 |
| 상태 | 채택 |
| 배경 | 정답이 네 건뿐이라 LLM 판정기 자체를 검증할 자료가 없다. |
| 채택 | 탐지, 구성 요소, 첫 이상 시각, 근거, 시간, 비용은 코드가 채점하고 원인 가설과 오탐 확정은 운영자가 기준표로 채점한다. |

| 영향 | 평가 한 번에 사람 채점 네 건이 든다. 정답이 늘면 LLM 판정기를 다시 검토한다. |
