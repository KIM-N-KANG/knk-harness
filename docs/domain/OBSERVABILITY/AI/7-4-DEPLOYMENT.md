# 7-4 배포

이 문서는 에이전트의 실행 단위, 실행 조건, 환경 변수와 설정 변경을 정한다.

운영 제약은 2-2 운영 요구사항에 있다. ([2-2-6 운영 제약](2-2-OPERATION-REQUIREMENTS.md#2-2-6-운영-제약))

<br>

### 7-4-1 실행 단위

| 항목 | 구성 |
|---|---|
| 형태 | `manyak-diagnosis` 저장소의 Python 패키지 |
| 재생 모드 | 운영자 PC에서 명령줄로 실행 |
| 실시간 모드 | 컨테이너 하나를 상주시킴. 세션 저장 경로와 실행 폴더는 영속 볼륨. 슬랙은 소켓 모드라 공개 주소가 필요 없음. 컨테이너를 올리는 위치와 볼륨 종류는 정하지 않았다 |
| 포함 | 에이전트 코드, 프롬프트, 채점기, 재적재 스크립트, 시스템 설명서 예시 |
| 제외 | 벤치마크 보관 자료, 정답 파일의 사람 채점, 실행 폴더, 세션 파일 |
| 배포 파이프라인 | 없음. 저장소를 받아 의존성을 설치하면 실행 가능 |

| 의존 대상 | 연결 실패 시 동작 |
|---|---|
| 재생용 OpenSearch | 시작 검사 실패로 종료 |
| loadtest OpenSearch, CloudWatch | 실시간 모드 시작 검사 실패로 종료 |
| 슬랙 | 실시간 모드 시작 검사 실패로 종료. 실행 중 전송 실패는 실행 실패 기록 |
| 코드 저장소 | 시작 때 받지 못하면 실시간 모드 시작 검사 실패로 종료 |
| 모델 API | 키 누락은 시작 검사 실패. 호출 실패는 실행 실패 기록 |

<br>

### 7-4-2 실행 조건

| 조건 | 확인 |
|---|---|
| 스펙과 프롬프트 일치 | 6-1의 프롬프트 원문과 코드의 프롬프트가 같음 |
| 단위 테스트 통과 | 7-2-2~7-2-5 |
| 평가 통과 | 채택된 조합의 6-4 판정이 통과 |
| 설명서 최신 | 대상 환경의 동시성 상한과 확장 정책이 설명서와 같음 |
| 토큰 범위 | GitHub 토큰이 세 저장소의 내용 쓰기와 PR 생성만 가짐. 슬랙 봇이 알림 채널 하나에만 있음 |

<br>

### 7-4-3 환경 변수와 비밀 정보

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | 운영자 셸 | |
| `DIAG_MODEL` | `claude-opus-5-5` | 운영자 셸 | |
| `DIAG_EFFORT` | `medium` | 운영자 셸 | `low`, `medium`, `high` |
| `DIAG_OPENSEARCH_URL` | 없음 | 운영자 셸 | 재생용 또는 loadtest 주소 |
| `DIAG_OPENSEARCH_USER` | 없음 | 운영자 셸 | |
| `DIAG_OPENSEARCH_PASSWORD` | 없음 | 운영자 셸 | |
| `AWS_PROFILE` | 빈 값 | 운영자 셸 | 실시간 모드에만. 읽기 권한 프로파일 |
| `AWS_REGION` | `ap-northeast-2` | 운영자 셸 | |
| `DIAG_QUERY_BUDGET` | `25` | 운영자 셸 | |
| `DIAG_TIME_BUDGET_SECONDS` | `300` | 운영자 셸 | |
| `DIAG_SESSION_DIR` | 없음 | 운영자 셸, 컨테이너 환경 | 세션 파일 폴더. 실시간은 영속 볼륨 |
| `DIAG_SESSION_BUDGET_USD` | `2.00` | 운영자 셸, 컨테이너 환경 | |
| `SLACK_BOT_TOKEN` | 없음 | 컨테이너 환경 | 실시간 모드에만 |
| `SLACK_APP_TOKEN` | 없음 | 컨테이너 환경 | 실시간 모드에만. 소켓 모드 연결 |
| `DIAG_SLACK_CHANNEL` | 없음 | 컨테이너 환경 | 실시간 모드에만. 알림 채널 ID |
| `GITHUB_TOKEN` | 없음 | 컨테이너 환경 | 실시간 모드에만 |

시스템 설명서 경로, 실행 모드, 재생 구간, 지표 파일 경로는 실행 인자로 준다. 비밀값은 환경에만 두고 저장소, 실행 폴더, 스레드에 쓰지 않는다. `DIAG_OPENSEARCH_*`와 AWS 자격 증명은 에이전트 프로세스에만 두고 SDK가 띄우는 실행 환경에 넘기지 않는다.

<br>

### 7-4-4 설정 변경과 복구

| 변경 | 방법 | 확인 |
|---|---|---|
| 모델, 추론 강도, 예산, 세션 비용 한도 | 환경 변수 | `run.json`에 남은 값 |
| 탐지 기준값 | 코드의 상수 | 7-2-2 테스트 |
| 프롬프트 | 코드의 프롬프트 파일과 6-1 동시 수정 | 6-4 재평가. 조율 규칙만 바꿔도 같은 프롬프트 해시가 바뀌므로 재평가함 |
| 시스템 설명서 | YAML 파일 | 구간별 파일이면 구간 표와 대조 |

되돌리기는 저장소의 이전 커밋으로 컨테이너를 다시 띄우는 것이다. 세션 파일은 그대로 두어 열린 세션이 이어진다.
