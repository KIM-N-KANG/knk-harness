# 7-3 관측

이 문서는 에이전트 자신의 실행을 추적하고 품질, 시간, 비용의 변화를 확인하는 기록을 정한다.

실행 폴더의 파일은 5 계약에 있다. ([5-6 실행 폴더](5-CONTRACT.md#5-6-실행-폴더))

<br>

### 7-3-1 추적 단위

| 단위 | 식별자 | 연결 |
|---|---|---|
| 실행 | 실행 폴더 이름 | 모드, 구간, 모델, 프롬프트 해시 |
| 이상 후보 | `candidate_id` | 후보, 보고, 조회 기록, 실행 실패 |
| 조회 | 조회 번호 | 보고의 근거 |
| 모델 호출 | 루프 안의 순번 | `queries/` 파일의 메시지 줄 |
| 세션 | `session_id` | 스레드, 승인, 조치 PR, 세션 파일 |
| 승인 | `approvals.jsonl`의 줄 | 세션, 승인 메시지 |
| 조치 PR | `pr_url` | 세션, 저장소 |

<br>

### 7-3-2 기록 항목

| 항목 | 위치 | 내용 |
|---|---|---|
| 감시 진행 | 표준 출력 | 감시 시각, 확정 신호, 후보 열기와 닫기 |
| 진단 대화 | `queries/<candidate_id>.jsonl` | 모델 메시지와 도구 결과 전체 |
| 사용량 | 보고와 실행 실패의 `usage` | 모델, 조회 수, 토큰, 비용, 경과 시간 |
| 실패 | `failures.jsonl` | 단계와 사유 |
| 세션과 스레드 | `sessions.jsonl` | 세션 ID, 스레드, 누적 비용, 종료 시각 |
| 조율 대화 | 세션 저장 경로의 SDK 세션 파일 | 조율 턴의 메시지와 도구 호출 전체 |
| 승인 | `approvals.jsonl` | 도구, 대상, 결정, 승인자, 시각 |
| 조치 PR | `actions.jsonl` | 저장소, PR 주소, 시각 |
| 슬랙 | 채널과 스레드 | 알림, 답변, 승인 메시지, 종료와 실패 안내 |

프롬프트와 모델 출력은 전부 남긴다. 조회 결과에는 식별자가 없으므로 마스킹할 내용이 없다. 실행 폴더와 세션 파일은 에이전트가 도는 곳에만 있고 외부로 보내지 않는다. 슬랙에는 집계값과 구성 요소 이름만 올린다.

<br>

### 7-3-3 지표

| 지표 | 계산 | 확인 시점 |
|---|---|---|
| 후보 수 | `candidates.jsonl`의 고유 `candidate_id` 수 | 실행 끝 |
| 판정 분포 | 보고의 `verdict`별 수 | 실행 끝 |
| 진단 비용과 시간 | `usage` 합계와 최댓값 | 실행 끝 |
| 실행 실패율 | 실패 수 / 후보 수 | 실행 끝 |
| 근거 검증 실패 수 | `verified` 거짓인 근거 수 | 실행 끝 |
| 세션 비용 | `sessions.jsonl`의 `cost_usd` 최댓값과 합계 | 실행 끝 |
| 승인과 거부 수 | `approvals.jsonl`의 `decision`별 수 | 실행 끝 |
| 조치 PR 수 | `actions.jsonl`의 줄 수 | 실행 끝 |

Langfuse와 Sentry에는 기록하지 않는다.
