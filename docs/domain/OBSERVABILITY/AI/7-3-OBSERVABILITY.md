# 7-3 관측

이 문서는 에이전트 자신의 실행을 추적하고 품질, 시간, 비용의 변화를 확인하는 기록을 정한다.

실행 폴더의 파일은 5 계약에 있다. ([5-8 실행 폴더](5-CONTRACT.md#5-8-실행-폴더))

<br>

### 7-3-1 추적 단위

| 단위 | 식별자 | 연결 |
|---|---|---|
| 실행 | 실행 폴더 이름 | 실행 단계, 코드 사본 커밋, MCP 서버 패키지 버전, 적용 설정 값, 프롬프트 해시 |
| 진단 요청 | `diagnosis_id` | 이상 후보나 운영자 요청, 보고, 조회 기록, 실행 실패 |
| 조회 | 조회 번호 | 보고의 근거 |
| 모델 호출 | 루프 안의 순번 | `queries/` 파일의 메시지 줄 |
| 세션 | `session_id` | 스레드, 세션 파일 |

<br>

### 7-3-2 기록 항목

| 항목 | 위치 | 내용 |
|---|---|---|
| 감시 진행 | 표준 출력 | 판정한 분, 확정 신호, 후보 열기와 닫기, 진단 생략, 저장소 갱신 실패 |
| 운영자 요청 | `mentions.jsonl` | 요청 문장, 요청 시각, 스레드, 생략 사유 |
| 진단 대화 | `queries/<diagnosis_id>.jsonl` | 모델 메시지와 도구 결과 전체 |
| 사용량 | 보고와 실행 실패의 `usage` | 모델, 조회 수, 토큰, 비용, 경과 시간 |
| 실패 | `failures.jsonl`과 표준 출력 | 단계와 사유 |
| 세션과 스레드 | `sessions.jsonl` | 세션 ID, 스레드, 누적 비용, 종료 시각 |
| 대화 턴 대화 | 세션 저장 경로의 SDK 세션 파일 | 대화 턴의 메시지와 도구 호출 전체 |
| 슬랙 | 채널과 스레드 | 보고, 답변, 종료와 실패 안내 |

프롬프트와 모델 출력은 전부 남긴다. 조회 결과에는 FLS로 뺀 필드가 들어오지 않으므로 기록에서 따로 가릴 내용이 없다. 실행 폴더와 세션 파일은 에이전트가 도는 곳에만 있고 외부로 보내지 않는다. 2단계에서는 태스크가 멈추면 함께 사라지므로 보고는 슬랙에 남기고 감시 진행과 실행 실패는 표준 출력으로 남긴다. 2단계 표준 출력의 로그 그룹은 7-4-2에 있다. 슬랙에는 집계값, 구성 요소 이름, 파일 위치만 올린다.

<br>

### 7-3-3 지표

| 지표 | 계산 | 확인 시점 |
|---|---|---|
| 후보 수 | `candidates.jsonl`의 고유 `candidate_id` 수 | 실행 끝 |
| 운영자 요청 수 | `mentions.jsonl`의 고유 `mention_id` 수 | 실행 끝 |
| 진단 생략 수 | `skip_reason`이 있는 진단 요청 수 | 실행 끝 |
| 판정 분포 | 보고의 `verdict`별 수 | 실행 끝 |
| 진단 비용과 시간 | `usage` 합계와 최댓값 | 실행 끝 |
| 실행 실패율 | 실패 수 / 진단을 부른 진단 요청 수 | 실행 끝 |
| 근거 검증 실패 수 | `verified` 거짓인 근거 수 | 실행 끝 |
| 세션 비용 | `sessions.jsonl`의 `cost_usd` 최댓값과 합계 | 실행 끝 |

Langfuse와 Sentry에는 기록하지 않는다.
