# OBSERVABILITY AI

운영 관측 자료를 감시해 장애를 찾고 어떤 문제가 어디서 났는지 요약해 개선 방향을 슬랙으로 제안한 뒤, 스레드에서 운영자의 질문에 답하는 진단 에이전트의 AI 세트다. 코드 탐지기가 연 이상 후보와 운영자의 슬랙 멘션 요청이 진단을 시작한다. 1단계는 운영자 PC에서, 2단계는 운영 ECS에서 상주한다.

<br>

### 1. 문서의 역할

| 문서 | 정하는 것 |
|---|---|
| [1 배경](1-BACKGROUND.md) | 관측 도메인, 현재 문제, 진입 경로, 대상 서비스와 범위, 주체, 용어 |
| [2-1 유저 스토리](2-1-USER-STORY.md) | 운영자가 보고와 슬랙 대화에 기대하는 성질 |
| [2-2 운영 요구사항](2-2-OPERATION-REQUIREMENTS.md) | 품질, 시간, 비용 목표와 운영 제약, 운영 특성과 한계 |
| [3 태스크 정의](3-TASK-DEFINITION.md) | 처리 단위, 이상 후보와 운영자 요청, 진단과 대화의 입력과 출력 |
| [4-1 인지 구조](4-1-DESIGN-COGNITIVE-ARCHITECTURE.md) | 신호 규칙, 저장소 읽기를 포함한 진단 전략, 모델과 코드의 책임, 세션 종료 |
| [4-2 소프트웨어 설계](4-2-DESIGN-SOFTWARE-ARCHITECTURE.md) | 시스템 경계, 실행 단계, 구성 요소, 상태 |
| [5 계약](5-CONTRACT.md) | 설정 파일과 덮어쓰기 규칙, 자료 원천과 필드 대응표, OpenSearch 읽기 역할, 서비스 지도, 진단 요청과 진단 보고 필드, 실행 폴더, 슬랙 메시지 |
| [6-1 AI 실행](6-1-AI-EXECUTION.md) | 세션 설정과 격리, 프롬프트, MCP 서버와 도구, 권한, 응답 검사, 대화 턴 |
| [6-2 소프트웨어 구현](6-2-SOFTWARE-IMPLEMENTATION.md) | 실행 흐름, 설정 읽기와 시작 검사, 탐지 조회, MCP 서버 실행, 슬랙과 대화 턴, 저장소 사본, 저장, 공통 규칙 |
| [6-3 얼라인먼트](6-3-AI-ALIGNMENT.md) | 개선 수단과 원인 구분 |
| [6-4 평가 방법](6-4-AI-EVALUATION-METHOD.md) | 보류 |
| [6-5 평가 구현](6-5-AI-EVALUATION-IMPLEMENTATION.md) | 보류 |
| 6-6 성능 리포트 | 보류. 파일 없음 |
| [7-1 오류 처리](7-1-ERROR-HANDLING.md) | 설정 오류와 MCP 서버 오류를 포함한 오류 분류, 처리, 재시도와 한도 |
| [7-2 테스트 케이스](7-2-TEST-CASES.md) | 테스트 범위, 설정, 구성 요소별 케이스, 도구 범위와 자격, 슬랙, 통합 |
| [7-3 관측](7-3-OBSERVABILITY.md) | 추적 단위, 기록 항목, 지표 |
| [7-4 배포](7-4-DEPLOYMENT.md) | 실행 단위, 운영 태스크와 운영 설정 주입, 실행 조건과 단계 전환, 환경 변수와 비밀, 설정 변경, 운영 준비 |
| [DECISIONS](DECISIONS.md) | 결정의 배경, 채택, 대안, 영향 |

### 2. 읽는 순서

| 작업 | 먼저 읽을 문서 |
|---|---|
| 에이전트가 무엇을 하는지 알기 | 1 배경, 3 태스크 정의 |
| 탐지 규칙이나 진단 전략을 바꾸기 | 4-1 인지 구조, 2-2 운영 요구사항 |
| 보고 필드나 서비스 지도를 바꾸기 | 5 계약, 3 태스크 정의 |
| 설정 항목을 바꾸거나 다른 서비스에 붙이기 | 5 계약의 설정 파일, 자료 원천, 서비스 지도와 7-4 배포 |
| MCP 서버나 도구 권한을 바꾸기 | 6-1 AI 실행, 5 계약의 자료 원천, 7-2 테스트 케이스의 도구 범위와 자격 |
| 슬랙 멘션이나 스레드 대화를 바꾸기 | 3 태스크 정의, 5 계약의 슬랙 메시지, 6-2 소프트웨어 구현 |
| 진단 품질을 고치기 | 6-3 얼라인먼트, 7-3 관측 |
| 구현하기 | 6-1 AI 실행, 6-2 소프트웨어 구현, 7-1 오류 처리 |
| 실행 준비와 운영 배포 | 7-4 배포와 2-2 운영 요구사항 |
| 결정 이유 찾기 | DECISIONS |
