# 6 배포: 웹

<br>

### 6-1 결제 복귀 설정

| 조건 | 확인 |
|---|---|
| 그로블 상품의 이동 페이지와 진입 페이지 | 모두 서비스의 `/my/credits/return` |
| 복귀 문서 | 앱 셸 없는 정적 문서 응답 |
| 서버 선행 계약 | 상품의 웹 가격, 주문 생성과 조회 제공 |
| 실제 복귀 | iOS Safari, Android Chrome, 인앱 브라우저의 결제 앱 왕복과 완료 화면 닫기 |

목킹 테스트는 실제 결제 제공자와 브라우저 복귀를 대체하지 않는다. ([5-1 검증](5-1-VERIFICATION.md))
