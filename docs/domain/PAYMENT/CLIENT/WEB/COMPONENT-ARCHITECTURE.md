# PAYMENT 웹 구성

<br>

### 책임과 의존 방향

| 구성 | 책임 |
|---|---|
| 충전 화면 | 초기 탭 해석, 잔액, 탭과 결제 확인 카드 조립 |
| 구매 탭 | 상품 조회와 주문 시작. 외부 결제창 이동 |
| 무료 충전 탭 | 출석 상태와 보상 안내, 초대 화면 이동 |
| 내역 탭 | 커서 목록, 첫 페이지와 다음 페이지 오류, 스크롤 끝 감지 |
| 주문 확인 훅 | 대기 주문 조회, 폴링과 확인 상태 변환 |
| 대기 주문 저장소 | 주문 식별자와 기록 시각 보관, 만료와 종료 정리 |
| 복귀 문서 | 앱 셸 없이 히스토리 계산과 이동 |
| 공용 부족 시트 | 프로필 재조회, 출석과 잠금. 입력 저장과 충전 이동은 호출 화면에 위임 |
| 정책과 체험 훅 | 공용 조회 캐시와 세션 구분. 금액 계산은 동작을 담당하는 도메인 |

연동 결과는 공통 계약과 웹 화면 흐름으로 변환한다. ([공통 4-1](../CONTRACT.md), [3-2](INTERACTION-FLOWS.md))
