# 3-1 PAYMENT 웹 화면과 URL

<br>

### 3-1-1 경로와 탭

| 경로 | 접근 | 역할 |
|---|---|---|
| `/my` | 게스트와 회원 | 회원에게 이프 카드와 충전 버튼 |
| `/my/credits` | 회원 | 잔액, 구매, 무료 충전, 내역 |
| `/my/credits/return` | 결제 복귀 | 결제 전 충전 화면으로 복귀하는 정적 문서. 앱 셸 없음 |

| 처음 진입한 `tab` | 탭 |
|---|---|
| `purchase` | 구매 |
| `free` | 무료 충전 |
| `history` | 내역 |
| 없음, 모르는 값 | 구매 |

접근과 쿼리 소비 규칙을 적용한다. ([2-2-1](2-2-REQUIREMENTS.md#2-2-1-충전과-체험))
