# 2-2 PAYMENT 웹 요구사항

<br>

### 2-2-1 충전과 체험

| 상황 | 조건과 결과 |
|---|---|
| 충전 화면 접근 | 회원 전용. 게스트는 로그인으로 교체 이동 |
| 처음 열 탭 | `purchase`, `free`, `history`를 각각 구매, 무료 충전, 내역으로 해석. 미지정과 모르는 값은 구매 |
| 쿼리 소비 | 처음 선택에만 사용. `tab`만 제거하고 다른 쿼리 유지. 이후 탭 전환을 URL에 기록하지 않음 |
| 무료 충전 새로고침 | 프로필의 잔액과 출석 여부, 정책값 재조회 |
| 내역 새로고침 | 첫 페이지 재조회. 응답 전까지 기존 목록 유지 |
| 구매 탭 | 당겨서 새로고침 없음 |
| 내역 재진입 | 첫 페이지와 맨 위부터 다시 조회. 비활성 탭은 언마운트 |
| 체험 갱신 | 채팅 턴 완료, 스토리라인 생성, 스토리 완성, 로그인 상태 변경 후 재조회 |
| 게스트 잔여 0 | 유료 생성과 재생성, 완성, 전송에 로그인 안내. 입력과 초안 유지 |

회원과 게스트의 적용 범위를 구체화한다. ([공통 2-2-1](../2-2-REQUIREMENTS.md#2-2-1-적용-범위), [공통 2-2-3](../2-2-REQUIREMENTS.md#2-2-3-체험))

### 2-2-2 구매와 적립 확인

| 요구 | 조건과 결과 |
|---|---|
| 상품 | 서버 순서와 웹 가격 표시. 앱 가격 노출 없음 |
| 구매 사용 기간 | 적립일로부터 5년 |
| 구매 시작 | 선택한 상품만 요청. 처리 중 모든 가격 버튼 잠금 |
| 시작 실패 | 외부 이동 없이 실패 안내와 재시도 |
| 결제 복귀 | 복귀만으로 적립 성공 처리하지 않음. 서버 주문 상태 확인 |
| 완료 | 주문의 적립 총량 안내, 잔액 재조회 |
| 환불 | 환불된 주문 안내. 적립 완료로 표시하지 않음 |
| 없는 주문 | 확인 불가 안내, 재확인 버튼 없음 |
| 확인 지연 | 약 60초 대기 뒤 자동 확인 중단. 사용자가 다시 확인 가능 |
| 조회 실패 | 오류 안내, 자동 재조회 중단과 다시 확인 제공 |
| 확정 결과 | 닫거나 화면을 떠날 때까지 표시. 새로고침과 재진입에서 다시 확인하지 않음 |
| 미확정 결과 | 확인 중, 지연과 오류 상태로 떠나면 다음 진입에서 확인 가능 |
| 보관 한도 | 24시간 지난 대기 주문은 무시 |
| 계정 종료 | 로그아웃, 세션 만료와 탈퇴 뒤 대기 주문 제거 |

PAYMENT-US-007의 웹 구매 범위다. ([유저 스토리](../2-1-USER-STORY.md#2-1-2-내역과-구매))

### 2-2-3 부족 시트와 복귀

| 상황 | 결과 |
|---|---|
| 채팅에서 충전 | 입력 보관 후 충전 화면을 쌓음. 뒤로가기로 같은 방과 입력 복원 |
| 간편 제작에서 충전 | 초안 저장 성공 뒤 퍼널을 충전 화면으로 교체. 뒤로가기는 퍼널 이전 화면 |
| 저장 실패와 충돌 | 시트와 퍼널 유지, 기존 저장 실패 안내 |
| 제작 탭에서 확정된 완성 402 | "이프가 부족해요" 토스트만 표시. 직전 토스트를 지우고 표시 |
| 게스트 완성 실패 | 이미 제작 탭으로 떠났으면 실패 안내와 초안 보존. 시트를 다시 열지 않음 |
| 결제 복귀 후 뒤로가기 | 되감기가 가능하면 충전 진입 전 화면. 불가능하면 충전 화면으로 교체하며 브라우저 뒤로가기가 결제창에 갈 수 있음 |
