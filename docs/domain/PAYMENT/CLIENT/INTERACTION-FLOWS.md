# PAYMENT 화면 흐름

<br>

### 출석과 내역

| 시작 | 조작 | 결과 |
|---|---|---|
| 무료 충전 | 출석 하기 | 요청 중 잠금. 성공하면 결과 안내와 잔액 갱신, 출석 완료로 변경 |
| 출석 완료 | 재진입 | 완료 상태 유지, 추가 적립 없음 |
| 출석 실패 | 다시 누르기 | 새 요청 가능 |
| 무료 충전 | 친구 초대 선택 | 초대 코드 화면 |
| 내역 | 목록 끝 도달 | 다음 페이지 추가. 실패하면 기존 목록 아래 재시도 |
| 내역 | 빈 결과 | 빈 상태 표시 |

<br>

### 부족 안내

```text
유료 동작
  ├─ 잔액 부족을 미리 확인 → 요청 없이 부족 시트
  └─ 서버 응답
       ├─ 현재 화면의 회원 잔액 부족 → 입력 복구와 부족 시트
       ├─ 웹 게스트 체험 소진 → 입력 유지와 로그인 안내
       └─ 제작 탭으로 이동한 뒤 완성 실패 → 플랫폼별 실패 안내
부족 시트
  ├─ 닫기 → 입력 유지
  ├─ 출석 → 성공하면 안내 후 닫기, 실패하면 유지
  └─ 충전 → 입력 보관 또는 초안 저장 → 충전 화면
```

선검사와 입력 보존 조건을 적용한다. ([이프 부족과 입력 보존](REQUIREMENTS.md#이프-부족과-입력-보존))
