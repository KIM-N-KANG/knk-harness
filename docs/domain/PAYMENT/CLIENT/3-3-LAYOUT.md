# 3-3 PAYMENT 화면 표현

<br>

### 3-3-1 잔액과 무료 충전

| 요소 | 표시 |
|---|---|
| 헤더 | 뒤로가기와 "이프 충전". 하단 탭 없음 |
| 잔액 | 중립 배경 상자. "내 이프" 위, 큰 수치 아래 오른쪽. 천 단위 구분과 이프 마크 |
| 스크롤 | 잔액과 탭은 고정, 선택한 탭 내용만 스크롤 |
| 미수신 잔액 | 잔액 자리에 골격 |
| 출석 제목 | "매일 출석하고 / 매일 N 이프 받으세요". N은 서버 보상액 |
| 출석 버튼 | 전폭 강조색 "출석 하기". 요청 중 "출석 체크 중"과 잠금, 완료하면 "출석 완료" 비활성 |
| 출석 안내 | "매일 오전 00시에 초기화돼요", "보상으로 받은 이프는 적립일로부터 30일 동안 사용할 수 있어요" |
| 친구 초대 | 출석 상자 아래 메뉴와 "하고 N 이프 받기" |
| 출석 결과 | 지급 시 "출석 체크 보상으로 N 이프를 받았어요", 중복 시 "오늘은 이미 출석 체크했어요", 실패 시 "출석 체크에 실패했어요" |
| 수치 자리표시 | 문구는 유지하고 수치만 쉬머. 이프 마크는 장식이며 별도 접근성 이름 없음 |

<br>

### 3-3-2 내역

| 요소 | 표시 |
|---|---|
| 행 | 왼쪽 사유, 대상 제목, 날짜. 오른쪽 증감량 |
| 증감량 | 획득은 `+`, 소모와 소멸은 `-`. 절대값에 천 단위 구분 |
| 제목 없음 | 소모와 사용 취소는 "삭제된 스토리". 보상, 소멸, 구매와 결제 환불은 제목 줄 없음 |
| 날짜 | KST `YYYY-MM-DD`. 만료일이 있으면 발생일 옆에 만료 날짜와 "만료" 표시 |
| 알 수 없는 사유 | "이프 변동" |
| 첫 조회 중 | 내역 목록 자리의 골격 |
| 빈 상태 | "아직 이프 내역이 없어요" |
| 첫 조회 실패 | "이프 내역을 불러오지 못했어요"와 재시도 |
| 다음 페이지 실패 | 기존 목록 아래 재시도, 전체 오류로 교체하지 않음 |

| 사유 | 라벨 |
|---|---|
| `SIGNUP_REWARD` | 가입 보상 |
| `ATTENDANCE_REWARD` | 출석 체크 보상 |
| `INVITE_REWARD` | 친구 초대 보상 |
| `REFUND` | 사용 취소 |
| `STORY_CREATION` | 스토리 완성 |
| `CHAT_TURN` | 채팅 전송 |
| `CHAT_IMAGE` | 채팅 실시간 이미지 생성 |
| `EXPIRE` | 기간 만료 |
| `PURCHASE` | 이프 구매 |
| `PURCHASE_REVERSAL` | 구매 환불 |

<br>

### 3-3-3 부족 시트

| 요소 | 표시와 동작 |
|---|---|
| 제목 | "이프가 부족해요" |
| 설명 | "이프를 충전하면 이어서 할 수 있어요" |
| 주 버튼 | "이프 충전하기". 입력 보관 후 이동 |
| 보조 버튼 | 오늘 미출석일 때만 "출석 체크하기" |
| 닫기 | 다른 시트와 같은 보조색 텍스트 버튼. 입력 유지 |
| 출석 또는 이동 준비 중 | 중복 조작과 닫기 잠금 |

동작과 실패 시 유지할 상태는 요구사항과 흐름에 있다. ([2-2-5](2-2-REQUIREMENTS.md#2-2-5-이프-부족과-입력-보존), [3-2-2](3-2-INTERACTION-FLOWS.md#3-2-2-부족-안내))
