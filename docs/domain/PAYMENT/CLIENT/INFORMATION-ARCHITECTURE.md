# PAYMENT 화면 구성

<br>

### 진입과 정보 순서

| 화면 또는 영역 | 진입 | 주요 정보 |
|---|---|---|
| 마이 이프 카드 | 회원의 마이 | 현재 잔액, 충전 버튼 |
| 이프 충전 | 마이 충전, 부족 시트, 알림 | 잔액, 탭, 선택한 탭의 내용 |
| 무료 충전 탭 | 충전 화면 | 출석 보상, 당일 완료 여부, 친구 초대 |
| 내역 탭 | 충전 화면 | 사유, 대상 스토리, 발생일과 만료일, 증감량 |
| 구매 탭과 결제 결과 | 웹 충전 화면 | 상품과 웹 가격, 결제 상태 |
| 이프 부족 시트 | 회원의 유료 동작 | 충전, 가능한 출석, 닫기 |
| 게스트 로그인 안내 | 웹의 체험 소진 | 로그인과 가입 안내 |

탭과 로그인 적용 범위는 요구사항을 따른다. ([적용 범위](REQUIREMENTS.md#적용-범위))
