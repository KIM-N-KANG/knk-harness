### 5-1-2 검증의 한계

문서 이관은 앱 실행 결과가 아니다. 단위 테스트는 실제 계정의 보상 지급, 서버 402, 기기 복원과 앱 전환을 대체하지 않는다. 기존 구현 검증에 사용한 임시 잔액 조건은 실제 서버의 이프 부족 응답 증거로 사용하지 않는다.

시나리오는 Android 요구사항과 실행 경계를 검증한다. ([2-2 요구사항](2-2-REQUIREMENTS.md), [4-4 실행](4-4-EXECUTION.md))
