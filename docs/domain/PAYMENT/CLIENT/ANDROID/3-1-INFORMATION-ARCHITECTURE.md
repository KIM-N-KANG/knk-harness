# 3-1 화면 구성: 안드로이드

<br>

### 3-1-1 진입과 목적지

| 시작 | 목적지 | 처음 표시 |
|---|---|---|
| 마이 충전 버튼 | 이프 충전 | 무료 충전 탭 |
| 채팅과 제작의 부족 시트 | 이프 충전 | 무료 충전 탭 |
| 허용한 HTTPS `/my/credits?tab=history` | 이프 충전 | 내역 탭 |
| 같은 경로의 그 밖의 탭 값 | 이프 충전 | 무료 충전 탭 |
| 무료 충전의 친구 초대 | 친구 초대 | ACCOUNT의 초대 화면 |

허용 호스트와 알림 진입 해석은 공용 내비게이션에서 검사한다. 처음 탭의 적용 조건은 Android 요구사항에 있다. ([2-2-1](2-2-REQUIREMENTS.md#2-2-1-충전-화면))
