# PAYMENT Android 화면 표현

<br>

### 공통 표현과 Android 요소

| 요소 | Android 표현 |
|---|---|
| 탭 | 무료 충전과 내역의 밑줄 탭 |
| 헤더 보조 버튼 | 제목 옆 "이프 구매 안내" 접근성 이름, 웹 구매 안내 툴팁 |
| 잔액과 탭 | 위에 고정. 탭 내용만 스크롤 |
| 색, 서체와 간격 | Android 디자인 시스템의 기존 토큰 사용 |
| 부족 시트 | 공용 시트 UI와 문구, 처리 중 닫기 잠금 |

잔액, 내역, 출석과 부족 문구는 공통 표현을 적용한다. ([공통 3-3](../LAYOUT.md))
