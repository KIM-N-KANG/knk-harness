# 4-2 컴포넌트 구조: 안드로이드

<br>

### 4-2-1 책임과 의존 방향

| 구성 | 책임 |
|---|---|
| `my` | 출석과 내역 API, 정책과 체험 저장소 구현, 이프 충전 화면 |
| `common` | 정책과 체험, 출석 인터페이스. 부족 시트의 공용 절차 |
| `designsystem` | 이프 마크와 수치, 잔액 카드, 부족 시트 표현 |
| `chat`, `create` | 동작별 적용가와 잔액 선검사, 입력 보존, 부족 상태와 분석 이벤트 |
| `app` | 루트 정책 조회, 회원 체험 조회, 공용 값 전달과 충전 목적지 조립 |
| `navigation` | 처음 내역 탭을 열지 나타내는 목적지 값과 딥링크 해석 |

출석 화면과 부족 시트는 같은 출석 구현을 쓴다. `chat`과 `create`에서 `my`를 직접 참조하지 않는다. 공용 절차는 상태 변경을 호출 ViewModel에 전달하고 별도 화면 상태를 만들지 않는다. ([공통 4-1](../4-1-CONTRACT.md))
