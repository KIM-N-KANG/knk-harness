# 2-2 요구사항: 안드로이드

<br>

### 2-2-1 충전 화면

| 상황 | 조건과 결과 |
|---|---|
| 적용 범위 | 회원 잔액, 무료 충전, 내역 제공. 구매 탭과 Play 결제 없음 |
| 초기 탭 | 앱 안 진입은 무료 충전. 허용한 HTTPS 딥링크의 `tab=history`만 내역 |
| 다른 쿼리 | `purchase`, 모르는 값, 대소문자가 다른 값과 미지정은 무료 충전. UTM 등 무시 |
| 탭 선택 | 처음 탭만 목적지로 전달. 이후 선택은 화면 상태이며 구성 변경에서 유지 |
| 잔액과 출석 | 화면이 보일 때 회원 정보 갱신. 미수신을 0으로 표시하지 않음 |
| 당겨서 새로고침 | 무료 충전은 프로필, 내역은 프로필과 첫 페이지 갱신 |
| 갱신 실패 | 기존 목록 유지, 오류 안내 |
| 구매 안내 | 헤더에서 웹 구매 안내 열람. 앱에서 결제 절차를 시작하지 않음 |

공통 적용 범위를 구체화한다. ([공통 2-2-1](../2-2-REQUIREMENTS.md#2-2-1-적용-범위))

<br>

### 2-2-2 부족 안내와 수명

| 상황 | 결과 |
|---|---|
| 시트와 출석 요청 중 상태 | 구성 변경에서 유지. 채팅방 이탈과 프로세스 종료 뒤 복원하지 않음 |
| 채팅에서 충전 | 같은 채팅방과 입력을 백스택에 보관한 채 충전 열기 |
| 간편 제작에서 충전 | 버튼 임시 저장과 같은 저장을 기다림. 성공하면 퍼널을 걷고 제작 탭 위에 충전 열기 |
| 제작 저장 실패와 충돌 | 시트와 퍼널 유지. 기존 저장 실패 안내 |
| 충전 뒤 뒤로가기 | 채팅은 같은 방과 입력, 제작은 초안 카드가 있는 제작 탭 |
| 제출 뒤 확정된 완성 실패 | 이프 부족이어도 "스토리를 완성하지 못했어요". 복구 응답에 실패 사유가 없음 |

게스트 소진과 로그인 안내는 Android에 적용하지 않는다. ([공통 2-2-3](../2-2-REQUIREMENTS.md#2-2-3-체험))
