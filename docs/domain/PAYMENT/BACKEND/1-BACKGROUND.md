# 1. 배경

이 문서는 마냑의 이프와 결제, PAYMENT 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 설명한다.

<br>

### 1-1 도메인

PAYMENT 도메인은 사용자가 AI 기능을 쓸 때 치르는 비용과 그 재화를 다룬다. 마냑의 재화는 이프다. 회원은 가입, 출석, 초대로 이프를 받거나 결제로 충전한다. 이프는 간편 제작과 채팅에 소모한다. 게스트는 이프 대신 기기별 체험 한도 안에서 서비스를 쓴다. PAYMENT는 지갑과 원장, 체험 한도, 충전 결제, 보상과 소모의 정책값을 관리한다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. AI 호출마다 비용이 들기 때문에 간편 제작과 채팅 턴은 이프를 소모한다. 처음 온 사용자는 로그인 없이 체험 한도 안에서 서비스의 가치를 확인한다. 회원이 되면 보상으로 이프를 모은다. 이프가 부족하면 결제로 충전한다. 스토리라인 생성과 일반 제작은 이프를 소모하지 않는다.

| 흐름 | 사용자가 하는 일 |
|---|---|
| 게스트 체험 | 로그인 없이 기기별 한도 안에서 스토리라인 생성, 간편 제작, 채팅 턴, 채팅 이미지를 사용<br>한도가 끝나면 로그인 안내를 받음 |
| 가입과 보상 | 가입하면 가입 보상을 받고 게스트 시절 남은 체험을 회원으로 이어받음<br>매일 출석 보상을 받고 초대 코드로 양쪽이 보상을 받음 |
| 잔액과 내역 | 잔액, 적립과 소모 내역, 적립분의 만료 예정일을 확인 |
| 소모 | 간편 제작과 채팅 턴에 이프를 소모<br>채팅 턴은 채팅에 고른 모델 등급의 가격<br>회원 체험이 남아 있으면 먼저 무료로 사용<br>처리가 실패하면 소모한 이프를 자동으로 돌려받음 |
| 충전 | 웹의 그로블 결제창에서 상품 6종 중 하나를 구매<br>결제 후 주문 상태를 조회해 적립 여부 확인 |
| 환불 | 결제일 7일 이내의 미사용 구매는 환불을 요청<br>환불되면 그 구매분이 잔액에서 빠짐 |
| 수치 안내 | 화면의 보상액과 소모액은 서버가 지금 적용하는 값 |

<br>

### 1-3 백엔드의 역할

결제 제공자는 돈의 이동만 처리한다. 재화의 적립과 소모, 잔액의 정합성, 환불 회수, 체험 한도는 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 지갑과 원장 | 회원마다 지갑 하나를 두고 모든 증감을 불변 원장에 기록<br>잔액은 원장과 로트에서 계산 |
| 적립 | 보상과 구매를 멱등 키로 1회만 적립<br>적립마다 로트를 만들어 만료 시각을 부여 |
| 선차감과 환불 | 처리 시작 전에 먼저 차감하고 실패하면 같은 금액을 환불<br>잔액이 부족하면 처리 전에 거절 |
| 만료와 소진 순서 | 로트마다 사유별 유효기간을 두고 지나면 만료<br>만료가 가까운 로트부터 소진 |
| 체험 한도 | 게스트는 기기별, 회원은 계정별 체험 카운터로 무료 사용량을 관리<br>가입 시 기기 사용량을 계정으로 옮김 |
| 결제 검증 | 그로블 웹훅의 서명과 금액을 검증한 뒤에만 적립 |
| 환불 회수 | 제공자의 환불 통지를 받아 구매 로트의 남은 수량을 회수<br>잔액을 음수로 만들지 않음 |
| 정책값 | 보상액, 간편 제작과 이미지 소모액, 월 상한을 릴리스 없이 바꿀 수 있는 오버라이드 제공<br>클라이언트와 다른 도메인에 현재 값 제공<br>채팅 턴 가격은 채팅 도메인의 모델 등급이 정하며 정책값 응답에는 기본 등급 가격만 실음 |
| 대사 | 환불이 유실된 차감을 주기적으로 찾아 보정 |
| 다른 도메인에 전달 | 계정: 가입과 초대 보상 적립, 체험 스냅샷, 잔액과 출석 여부<br>스토리와 채팅: 차감, 환불, 체험 예약과 복원, 소모 정책값 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자 | 기기별 체험 한도 안에서 사용 |
| 회원 | 소셜 로그인으로 가입한 사용자 | 보상 수령, 소모, 충전, 잔액과 내역 조회 |
| 클라이언트 | 사용자가 쓰는 웹과 Android 앱 | 잔액과 수치 표시, 충전 화면 표시, 결제 후 복귀 시 주문 상태 확인 |
| 그로블 | 웹 결제 제공자 | 결제창 제공, 결제 완료와 환불을 웹훅으로 통지 |
| 운영자 | 팀 구성원 | 정책값 조정, 환불 자격 확인과 제공자 콘솔에서 환불 실행 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 이프 | AI 기능 사용에 소모하는 서비스 안의 재화<br>회원 전용 |
| 지갑 | 회원별 잔액 보관 단위<br>잔액 값은 원장 합계의 캐시 |
| 원장 | 이프 증감을 빠짐없이 담은 불변 기록<br>환불과 회수도 수정이 아니라 행 추가 |
| 로트 | 적립 1건으로 생기는 묶음<br>남은 수량과 만료 시각이 있음 |
| 적립 | 보상, 환불, 구매로 이프가 늘어나는 것 |
| 보상 | 가입, 출석, 초대로 받는 적립 |
| 선차감 | AI 처리를 시작하기 전에 먼저 소모액을 빼는 것 |
| 환불 | 선차감 뒤 처리가 실패해 같은 금액을 되돌려 주는 것<br>적립과 같은 방식으로 로트를 만듦 |
| 회수 | 결제 환불에 따라 구매 로트의 남은 수량을 빼는 것 |
| 만료 | 로트의 유효기간이 지나 남은 수량이 잔액에서 빠지는 것 |
| 체험 한도 | 이프 없이 쓸 수 있는 사용량 상한<br>스토리라인 생성, 간편 제작, 채팅 턴, 채팅 이미지의 4종 |
| 게스트 체험 | 기기 식별자별 체험 카운터 |
| 회원 체험 | 계정별 체험 카운터<br>가입 시 기기 사용량을 이어받으며 스토리라인 생성은 회원에게 무료라 제외 |
| 체험 예약 | 처리 시작 전에 체험 1회를 먼저 쓰는 것<br>실패하면 복원 |
| 정책값 | 보상액, 소모액, 초대 월 상한처럼 운영 중 바뀔 수 있는 수치<br>채팅 턴 가격은 제외 |
| 모델 등급 | 채팅 턴의 가격을 정하는 등급<br>채팅 도메인이 등급과 가격을 관리 |
| 오버라이드 | 기본값 대신 적용할 정책값과 종료 시각을 담은 행 |
| 상품 | 충전 상품 6종<br>기본 이프, 보너스 이프, 가격이 있음 |
| 주문 | 결제 1건의 상품, 금액, 상태, 적립 원장을 연결하는 단위 |
| 웹훅 | 그로블이 결제 완료와 환불을 서버에 알리는 서명된 요청 |
| 환불 표식 | 그로블 거래마다 두는 행<br>같은 거래의 완료와 환불 처리를 잠금으로 직렬화하고 완료보다 먼저 도착한 환불 금액을 완료 처리 때까지 보관 |
| 멱등 키 | 같은 적립이 두 번 기록되지 않게 원장 행에 두는 고유 값 |
| 보상 신원 | 가입, 출석, 초대 같은 1회성 보상의 자격을 판정하는 단위<br>재가입해도 최초 계정을 가리킴 |
| 대사 | 원장과 실제 처리 결과를 대조해 유실된 환불을 보정하는 작업 |
| 차감 그룹 | 같은 회원, 같은 참조 종류, 같은 참조 대상을 가리키는 소모 행의 묶음<br>대사의 단위 |
