# DECISIONS.md

PAYMENT 도메인 백엔드의 중요한 결정을 날짜, 상태, 배경, 채택, 대안과 영향으로 정리한다. 현재 적용 기준은 각 명세에 둔다. 여기에는 결정 당시의 이유와 변경 이력을 기록한다.

<br>

### 1. 기록 규칙

- 결정 하나를 표 하나로 기록한다.
- 상태는 결정 당시 기준이다. 결정이 바뀌면 이전 기록을 지우지 않고 후속 결정에 대체 범위와 근거를 적는다.

**2. 보상 이프는 30일, 구매 이프는 5년 뒤 만료하고 만료 임박순으로 소진한다**

|---|---|

| 영향 | 로트 도입 전 잔액은 무기한 로트 하나로 승계해 기존 사용자의 잔액이 바뀌지 않았다. 부족 판정은 만료 정리보다 먼저 해 실패한 차감이 정리를 롤백시키지 않는다. 이용내역 응답에는 획득 행의 만료 예정일을 함께 포함한다. |

**3. 유실 환불은 그룹 개수 대조 배치로 보정한다**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-07-07 |
| 상태 | 채택 |
| 배경 | 먼저 차감하고 실패하면 환불하는 구조에서 환불 코드가 실행되는 도중 프로세스가 중단되면 차감만 남는다. 채팅은 큐 대기 중 시간 초과나 취소로 워커가 실행되지 못해 환불이 누락될 수 있다. |
| 채택 | 주기 배치가 소모 행을 회원, 참조 종류, 참조 대상으로 묶는다. 차감 수와 완료 수를 대조해 부족한 환불만 추가한다. 마지막 차감이 기준 시각보다 오래된 그룹만 대상으로 해 진행 중 요청과 겹치지 않는다. 완료 수가 차감 수보다 많거나 참조 대상이 없으면 환불하지 않는다. 멱등은 지갑 잠금 뒤 환불 수 재확인으로 보장한다. |
| 대안 | 환불 행이 소모 행을 가리키게 해 행 단위로 대조하는 방식. 채팅과 간편 제작의 참조가 1대 N이라 요청 내 환불 경로 세 곳을 함께 바꿔야 해서 채택하지 않았다. |
| 영향 | 채팅의 완료 수는 저장된 턴 수와 완료된 재생성 수의 합이다. 재생성은 턴 수를 올리지 않는 유료 차감이라 더하지 않으면 성공한 재생성을 초과 환불한다. 채팅 이미지는 턴 저장 트랜잭션이 환불하므로 대상에서 뺀다. |

| 상태 | 채택 |

| 영향 | 회원의 소모 판정은 남은 체험을 확인한 뒤 이프를 확인하는 2단계가 됐다. 체험으로 처리된 요청이 실패하면 이프를 환불하지 않고 카운터를 복원한다. Redis 장애 시 회원 예약은 미예약으로 보고 이프 차감으로 진행해 유료 사용을 막지 않는다. 기기 헤더 누락 같은 제품 결함으로 잘못 소진된 계정은 운영자가 카운터를 직접 보정한다. |

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-08-31 |
| 상태 | 채택 |
