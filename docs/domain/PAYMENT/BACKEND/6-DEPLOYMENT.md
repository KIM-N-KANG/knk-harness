# 6. 배포

이 문서는 PAYMENT 도메인이 포함된 서버의 배포 단위와 의존 대상, 배포 경로, 이 도메인이 읽는 환경 변수와 시크릿, 설정 변경, 적용과 복구 절차를 정한다.

서버 전체 배포 절차 중 PAYMENT 도메인과 관련된 항목만 다룬다.

로트 수명과 배치 주기는 오류 처리에, 관측 스택과 조회 도구는 관측에 있다. ([5-3-5 재시도와 시간 한도](5-3-ERROR-HANDLING.md#5-3-5-재시도와-시간-한도), [5-4-1 관측 스택](5-4-OBSERVABILITY.md#5-4-1-관측-스택))

<br>

### 6-1 배포 단위와 의존성

배포 단위는 서버 컨테이너 하나다. PAYMENT만 따로 배포하지 않는다. 이 도메인이 기동과 요청 처리에 쓰는 의존 대상은 다음과 같다.

| 의존 대상 | 내용 | PAYMENT 도메인이 쓰는 것 |
|---|---|---|
| PostgreSQL | 기동 시 마이그레이션 적용 | 지갑, 원장, 로트, 정책 오버라이드, 주문, 환불 표식 테이블 |
| Redis | ElastiCache 비클러스터 | 체험 카운터 |
| 그로블 | 결제창과 웹훅 | 웹 결제 완료와 환불 통지 수신 |
| Secrets Manager | Terraform이 태스크 정의에 참조 주입 | 웹훅 시크릿 |
| Grafana Cloud | 지표 수신 | 결제 결과 카운터 |
| Amplitude | 서버 분석 이벤트 수신 | 출석, 주문, 구매, 환불 이벤트 |

<br>

| 의존 대상 | 연결과 설정 실패 시 동작 |
|---|---|
| 상품 설정 | 6종이 아니거나 ID가 겹치거나 수량과 가격이 범위 밖이면 기동 실패 |
| 정책 기본값 | 키별 최솟값 미만이면 기동 실패 |
| 웹훅 시크릿 | 비어 있으면 기동은 정상<br>웹 주문 생성과 웹훅은 처리 불가로 응답 |
| 상품의 결제창 주소 | 비어 있으면 그 상품의 웹 주문 생성만 처리 불가로 응답 |
| PostgreSQL | 연결할 수 없으면 기동 실패 |
| Redis | 필요한 시점에 연결하므로 서버는 기동<br>게스트 체험 경로는 서버 오류, 회원 체험은 이프 차감으로 진행 |
| 정책 저장소 | 적재 실패는 직전 스냅샷 유지<br>기동 시 실패는 기본값 |

<br>

### 6-2 배포 경로

테스트와 빌드를 마친 뒤 이미지를 게시하고 배포한다. `main` push는 같은 소스 트리의 `dev` 성공 실행이 있으면 테스트를 다시 실행하지 않는다. `dev`로 PR을 올리면 테스트와 빌드만 한다.

| 단계 | 개발 | 운영 |
|---|---|---|
| 자동 시작 | `dev` push | `main` push |
| 머지 규칙 | 기능 브랜치에서 `dev`로 squash | `release/vX.Y.Z`에서 `main`으로 merge commit |
| 이미지 태그 | 커밋 SHA 앞 7자리, 환경 태그 `dev` | 커밋 SHA 앞 7자리, 배포 시 `latest` 태그 지정<br>실패하면 이전 digest로 복원 |
| 상태 검사 | 배포 완료, 서버 컨테이너 정상, health `UP` | 동일 |

<br>

### 6-3 환경 변수와 시크릿

환경 변수가 설정 파일의 값보다 우선한다. 설정은 기동 시 읽으므로 변경 뒤 새 태스크를 시작해야 적용된다. 값은 Terraform이 태스크 정의에 주입하고 시크릿은 Secrets Manager에서 주입한다. 이 도메인이 읽는 설정만 적는다. 기본값이 "빈 값"이면 변수가 없어도 빈 문자열로 기동한다. "없음"이면 변수가 없을 때 기동에 실패한다.

<br>

**1. 결제 제공자**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_GROBLE_WEBHOOK_SECRET` | 빈 값 | 개발과 운영 Secrets Manager | 비어 있으면 웹 결제 비활성 |

상품 6종의 수량, 가격, 결제창 주소는 설정 파일의 고정값이다. 해당 환경 변수는 없다.

<br>

**2. 정책 기본값**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_CREDIT_SIGNUP_REWARD` | `1000` | 주입 없음 | |
| `MANYAK_CREDIT_INVITE_REWARD` | `2000` | 주입 없음 | |
| `MANYAK_CREDIT_INVITE_MONTHLY_CAP` | `10` | 주입 없음 | 횟수 |
| `MANYAK_CREDIT_ATTENDANCE_REWARD` | `250` | 주입 없음 | |
| `MANYAK_CREDIT_STORY_CREATION_COST` | `250` | 주입 없음 | |
| `MANYAK_CREDIT_CHAT_TURN_COST` | `20` | 주입 없음 | |
| `MANYAK_CREDIT_CHAT_IMAGE_COST` | `0` | 주입 없음 | 0이면 체험 소진 뒤에도 무료 |

운영 중 수치는 환경 변수로 바꾸지 않는다. 관리자 API의 정책 오버라이드로 변경한다.

<br>

**3. 배치와 체험**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_CREDIT_POLICY_REFRESH_ENABLED` | `true` | 주입 없음 | |
| `MANYAK_CREDIT_POLICY_REFRESH_INTERVAL_MS` | `60000` | 주입 없음 | 직전 갱신이 끝난 뒤의 대기 시간 |
| `MANYAK_CREDIT_RECONCILIATION_ENABLED` | `true` | 주입 없음 | |
| `MANYAK_CREDIT_RECONCILIATION_INTERVAL_MS` | `900000` | 주입 없음 | |
| `MANYAK_CREDIT_RECONCILIATION_INITIAL_DELAY_MS` | `60000` | 주입 없음 | |
| `MANYAK_CREDIT_RECONCILIATION_CHARGE_AGE_THRESHOLD` | `PT15M` | 주입 없음 | 진행 중 요청과의 경쟁을 피하는 기준 |
| `MANYAK_GUEST_TRIAL_STORYLINE_LIMIT` | `5` | 주입 없음 | |
| `MANYAK_GUEST_TRIAL_STORY_CREATION_LIMIT` | `1` | 주입 없음 | |
| `MANYAK_GUEST_TRIAL_CHAT_TURN_LIMIT` | `5` | 주입 없음 | |
| `MANYAK_GUEST_TRIAL_CHAT_IMAGE_LIMIT` | `5` | 주입 없음 | |

<br>

**4. 관측**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_ANALYTICS_AMPLITUDE_ENABLED` | `false` | 운영 Terraform 변수 | |
| `MANYAK_AMPLITUDE_API_KEY` | 빈 값 | 운영 Secrets Manager | 비어 있으면 발행 생략 |
| `MANYAK_OTLP_METRICS_ENABLED` | `false` | 운영 Terraform 변수, 전송 URL과 인증 헤더는 Secrets Manager | Grafana Cloud로 전송 |
| `SENTRY_DSN` | 빈 값 | 개발과 운영 Secrets Manager | |

<br>

**5. 다른 도메인이 관리하는 값**

| 이름 | PAYMENT가 쓰는 곳 |
|---|---|
| `MANYAK_AUTH_JWT_SECRET` | 이용내역 커서 봉인 키의 파생 원본<br>바꾸면 발급된 커서가 무효 |
| `MANYAK_ANALYTICS_DEVICE_ID_PEPPER` | 게스트 체험 카운터 키의 해시<br>바꾸면 기존 게스트의 사용량이 새 키로 분리 |

### 6-4 배포 조건

| 확인 항목 | 기준 | 자동 여부와 한계 |
|---|---|---|
| 상품 변경 | 수량과 가격 변경은 클라이언트 표시와 함께 검토<br>결제창 주소는 그로블 콘솔의 상품과 대조 | 수동 검토<br>서버는 주소가 어느 상품의 결제창인지 확인할 수 없음 |
| 정책 기본값 변경 | 설정 파일 변경은 오버라이드로 할 수 없는 상시 변경만 | 수동 검토 |
| 와이어 계약 변경 | 응답 형식이 바뀌면 서버와 클라이언트를 함께 배포 | 수동 검토 |
| 원장 사유 추가 | 저장소 CHECK 제약, 이용내역 분류, 대사 대상 여부를 같은 릴리스에서 반영 | 분류 매핑 누락은 컴파일 시 탐지<br>제약은 수동 검토 |
| 컬럼 제거 | 그 컬럼을 읽는 구버전 태스크가 사라진 다음 릴리스에서 제거 | 수동 검토 |
| 마이그레이션 | 기동 시 실행하므로 새 마이그레이션은 해당 코드보다 먼저 적용<br>재실행해도 같은 결과 | 기동 시 자동 적용<br>마이그레이션 경로 변경 PR은 `tbls lint`와 `dbdoc/` 비교를 CI에서 자동 실행 |
| 코드 테스트 | 전체 테스트 통과 | CI 자동 |
| 컨테이너 기동 | 컨테이너 헬스체크와 `/actuator/health` `UP` | CI 자동<br>결제 제공자 연결은 검사하지 않음 |

<br>

### 6-5 설정 변경

| 변경 대상 | 변경 위치와 적용 | 확인 조건 |
|---|---|---|
| 보상액, 소모액, 월 상한 | 관리자 API로 정책 오버라이드 기록 또는 삭제<br>갱신 주기 안에 반영<br>재배포 없음 | 정책값 조회의 값, 변경 로그, 감사 로그<br>종료 시각이 있으면 자동 복귀 |
| 회원별 이프 보정 | 관리자 API로 지급 또는 회수 | 회원 상세의 잔액<br>감사 로그 |
| 정책 기본값 | 환경 변수 또는 설정 파일 변경 후 새 태스크 시작 | 기동 로그의 현재 유효값 |
| 웹훅 시크릿 | 그로블 콘솔에서 교체 뒤 Secrets Manager 값 변경 후 새 태스크 시작 | 교체 기간에는 이전 서명 헤더로 검증<br>웹훅 지표의 `invalid`가 늘지 않음 |
| 상품 수량과 가격 | 설정 파일 변경 후 재빌드<br>그로블 결제창 금액도 함께 변경 | 상품 목록의 값<br>이미 생성된 대기 주문은 생성 시점의 값 유지 |
| 체험 한도 | 환경 변수 변경 후 새 태스크 시작<br>카운터는 리셋하지 않음 | 새 한도 이상 쓴 기기는 즉시 소진 상태 |
| 배치 주기와 활성화 | 환경 변수 변경 후 새 태스크 시작 | 대사 로그 |
| 지표 전송 | 운영 Terraform 변수 변경 후 apply | |

### 6-6 적용과 복구

**1. 적용 순서**

| 순서 | 작업 | 확인 항목 |
|---|---|---|
| 1 | 설정과 시크릿 확인 | 새 시크릿 키의 주입 참조, 상품 설정, 마이그레이션 순서 |
| 2 | 동반 배포 확인 | 클라이언트와 함께 배포해야 하는지와 배포 순서<br>원장 사유 추가는 제약 마이그레이션이 먼저 |
| 3 | 배포 실행 | |
| 4 | 적용 결과 확인 | 배포 후 확인 항목 |

<br>

**2. 진행 중인 요청**

| 상황 | 처리와 한계 |
|---|---|
| 롤링 교체 중 웹훅 | 어느 태스크가 받아도 멱등 키와 주문 상태로 같은 결과 |
| 롤링 교체 중 선차감 | 구버전 태스크의 환불 코드가 끊기면 대사가 보정 |
| 롤링 교체 중 배치 | 두 태스크가 동시에 실행해도 잠금과 재확인으로 중복 환불 없음 |
| 태스크 강제 종료 중 웹훅 처리 | 트랜잭션이 롤백되면 적립과 회수 모두 없음<br>그로블이 재전송하면 다시 처리 |
| 개발 stop-then-start | 교체 중 모든 요청 실패<br>데이터 컨테이너 재시작 |

<br>

**3. 복구**

자동 복구가 실행돼도 서비스가 정상으로 돌아오지 않았을 수 있으므로 실제 서버 상태를 확인한다.

| 상황 | 복구 방식 | 한계와 확인 사항 |
|---|---|---|
| 새 태스크 헬스체크 실패 | 직전 배포로 자동 복귀 | 환경 태그가 실패한 이미지를 가리킬 수 있으므로 다음 재배포 전에 태그 확인 |
| 배포는 정상이나 동작 오류 | revert 커밋 릴리스 또는 이전 이미지를 환경 태그로 다시 태깅한 뒤 새 배포 | health 기반 자동 복구는 결제 실패를 탐지하지 않음 |
| 잘못 지급한 이프 | 원장이 불변이라 자동 회수 없음<br>관리자가 확인 뒤 관리자 API로 회수 | 정책 오버라이드를 삭제해 추가 지급을 멈춤<br>삭제는 갱신 주기 뒤 반영되므로 정책값 조회로 확인<br>이미 소진한 이프는 부족분으로 남음 |
| 마이그레이션 적용 후 되돌리기 | 적용된 마이그레이션은 되돌리지 않음 | 새 컬럼과 제약 확장은 구버전 코드와 호환되도록 추가 |
| 설정 오류 | 잘못된 시크릿을 이전 값으로 복구 후 새 태스크 시작 | 이미지 태그 복원만으로 설정은 복원되지 않음 |

<br>

### 6-7 배포 후 확인

| 확인 항목 | 자료 | 기준 |
|---|---|---|
| 기동 | 해당 배포 ID의 태스크 상태, 헬스체크 `/actuator/health`, 스모크 테스트 | 의도한 이미지로 기동, `UP` |
| 정책값 | 기동 로그의 현재 유효값, 정책값 조회 | 의도한 값 |
| 상품 | 상품 목록 조회 | 6종의 수량과 가격 |
| 웹 결제 | 웹훅 지표의 `result` 분포 | `invalid`와 `ignored`가 배포 전과 같은 수준 |
| 소모와 환불 | 대사 로그 | 보정이 급증하지 않음 |
| 출석과 결제 | 출석, 구매, 환불 이벤트 | 배포 전과 같은 수준 |
| 체험 | 요청 로그의 `/api/v1/users/me/trials` 서버 오류 비율 | 배포 전과 같은 수준 |

<br>

### 6-8 배포 실패 진단

| 실패 상황 | 확인할 자료와 위치 | 원인별 조치 |
|---|---|---|
| 기동 중 설정 검증 실패 | 시작 로그의 예외 메시지 | 상품 설정과 정책 기본값 중 오류가 난 값 수정 후 새 태스크 시작 |
