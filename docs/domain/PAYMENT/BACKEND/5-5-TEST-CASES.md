# 5-5 테스트 케이스

이 문서는 PAYMENT 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에, 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 정책값 해석과 제외 규칙, 출석 멱등 키, 상품 설정 검증 | 없음 | CI |
| 통합 | 컨트롤러부터 저장까지, 지갑 연산, 로트 만료와 소진, 체험 카운터, 웹훅, 대사, 관리자 API | Redis는 테스트 JVM의 임베디드 서버 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 동시성 | 동시 첫 적립, 같은 멱등 키 동시 적립, 동시 차감, 월 상한 경계, 동시 웹훅 | 없음 | CI |
| 수동 | 엔드포인트 호출, 정책 오버라이드 반영, 실결제 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션과 두 배치 스케줄러를 비활성화한다. 배치는 서비스를 직접 호출해 검증한다. 전체 테스트를 통과해도 DB 제약이 검증된 것은 아니다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| 그로블 | 테스트 시크릿으로 서명한 본문을 직접 전송 |
| Redis | 테스트 JVM 시작 시 임베디드 서버를 띄우고 포트를 주입<br>장애는 연결할 수 없는 포트로 재현 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약은 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 시각 | 주입한 고정 시계로 KST 날짜 경계, 로트 만료, 웹훅 시각 범위 검증 |
| 회원 데이터 | 활성, 정지, 탈퇴, 재가입 계정과 지갑이 없는 계정 준비 |

### 5-5-2 지갑과 원장

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 첫 적립 | 지갑이 없는 회원에게 적립 | 지갑 생성, 원장 1행, 로트 1개, 잔액이 금액과 같음 |
| 멱등 적립 | 같은 키로 두 번 적립 | 두 번째는 적립 없이 `rewarded` false, 원장 1행 |
| 동시 첫 적립 | 지갑 없는 회원에게 다른 키로 동시 적립 | 지갑 1개, 두 적립 모두 기록 |
| 동시 같은 키 | 같은 키로 동시 적립 | 원장 1행, 나머지는 멱등 응답 또는 재시도 시 멱등하게 처리 |
| 월 상한 | 상한 2, 같은 달에 초대자 역할 키로 3회 적립 | 세 번째는 `monthlyCapped` true, 적립 없음 |
| 월 상한 역할 구분 | 제출자 역할 키의 적립 | 초대자 월 상한에 세지 않음 |
| 월 상한 신원 단위 | 재가입 계정의 초대자 적립, 이전 계정의 같은 달 행 존재 | 이전 계정의 행을 합쳐 집계 |
| 차감 | 잔액 100에서 30 차감 | 잔액 70, 음수 원장 1행 |
| 잔액 부족 | 잔액 20에서 30 차감 | 잔액 부족 예외, 원장과 로트 변화 없음 |
| 지갑 없음 | 지갑 없는 회원 차감 | 잔액 0의 잔액 부족 예외 |
| 항목 합산 차감 | 턴 20과 이미지 10을 한 번에, 잔액 25 | 전체 거절, 아무것도 기록하지 않음 |
| 항목별 원장 | 턴 20과 이미지 10, 잔액 100 | 원장 2행, 항목별 사유와 참조 기록, 잔액 70 |
| 동시 차감 | 잔액 50에서 30씩 동시 차감 | 하나만 성공, 잔액 20 |
| 로트 소진 순서 | 만료 임박 로트 30, 구매 로트 100, 승계 로트 50에서 60 차감 | 임박 로트 0, 구매 로트 70, 승계 로트 50 |
| 만료 정리 | 만료된 로트 40이 남은 회원의 적립 | `EXPIRE` 행 -40, 로트 잔여 0, 잔액에서 제외 |
| 만료와 부족 | 만료 로트 40, 활성 로트 10에서 20 차감 | 부족 예외, 만료 행 없음 |
| 잔액 조회 | 만료됐지만 정리 전인 로트 | 잔액에 포함하지 않음 |
| 로트 수명 | 보상, 환불, 구매 적립 | 만료 시각이 각각 30일 뒤, 30일 뒤, 5년 뒤 |
| 구매 회수 | 구매 로트 5,000 중 1,200 소진 뒤 회수 | 회수 3,800, 부족분 1,200, 잔액 변화 -3,800 |
| 전량 소진 회수 | 구매 로트 잔여 0 회수 | 회수 0, 원장 행 없음, 부족분이 원금 |

### 5-5-5 이용내역

| 만료일 | 획득 행, 만료 행, 소모 행, 회수 행 | 로트 만료 시각, 회수된 로트 만료 시각, null, null |

### 5-5-6 정책값

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 기본값 | 오버라이드 없음 | 설정 기본값 6종과 라이트(`LITE`) 가격의 `chatTurnCost` |

| 폐기된 턴 키 | `chat_turn_cost` 행 기록 뒤 갱신 | 무시, `chatTurnCost`는 모델 가격 유지, WARN |

| 종료 시각 | 종료 시각이 지난 행 | 갱신 없이 즉시 기본값 |
| 모르는 키 | 오타 키 행 | 무시, 나머지 키 정상, WARN |
| 최솟값 미만 | 출석 0, 월 상한 0 | 출석은 기본값, 월 상한은 0 |

| 첫 적재 실패 | 기동 시 DB 오류 | 기본값으로 기동 |
| 한 스냅샷 | 조회 중 갱신 | 한 응답의 정책 키 6종이 같은 스냅샷 |

| 조회 인증 | 토큰 없음, 만료 토큰, 탈퇴 계정의 유효 토큰 | 200, 200, 401 |

| 모델이 섞인 채팅 | 오로라 턴 50 차감이 연결 없이 남은 뒤 라이트 20 차감 2건이 연결됨, 기준 시각 경과 | 환불 1행 50, 혼합 단가 WARN 없음 |
| 재생성으로 옮긴 연결 | 차감 A가 버전 이력에, 차감 B가 메시지에 연결 | 둘 다 환불 없음 |
| 즉시 환불됨 | 연결 없는 차감에 `refund:charge:{id}` 환불 행 있음 | 환불 없음 |
| 대사와 저장의 동시 실행 | 대사가 차감 행을 잠근 동안 저장이 같은 차감을 연결하려 함 | 한쪽만 성공<br>환불됐으면 저장 폐기, 저장됐으면 환불 없음 |
| 참조 종류 `CHAT`의 채팅 턴 | `CHAT` 차감 2, 저장 턴 1, 환불 0, 기준 시각 경과 | 그룹 규칙으로 환불 1행 |
| 과거 UUID 키 환불 | `CHAT` 차감 1건이 `refund:chatturn:{UUID}` 키로 이미 환불됨, 저장 턴 0 | 환불 수 1로 세어 추가 지급 0 |
| 혼재 배포의 구버전 차감 | `CHAT` 차감 1건이 연결 없이 저장된 턴 1개와 함께 있음, 기준 시각 경과 | 행 단위 대상 아님, 그룹 규칙으로 차감 1과 완료 1이라 환불 없음 |
| 롤백 이미지의 차감 | `CHAT_TURN` 차감이 연결된 턴 1개 뒤 롤백한 구버전이 `CHAT` 차감으로 턴 1개 저장, 그 뒤 `CHAT` 차감 1건 유실 | 그룹 규칙에서 차감 2, 완료 3-1=2로 환불 없음(보수적), `CHAT_TURN` 차감은 환불 없음 |
| 롤백한 구버전 대사와 유실 `CHAT_TURN` 차감 | 연결 없는 `CHAT_TURN` 차감이 남은 채 구버전 대사가 실행된 뒤 새 버전 재배포 | 구버전 대사는 지원하지 않는 참조 종류라 환불 없음, 새 행 단위 대사가 1회만 환불 |
| 두 시기가 섞인 채팅의 과거 유실 | `CHAT` 차감 2(완료 1) 뒤 `CHAT_TURN` 차감 1이 연결됨, 그룹 환불 0 | 그룹 규칙 완료 수 2-1=1, 차감 2라 환불 1행 |
| 후보 조회 제외 | 연결된 차감 1,000건과 유실 차감 1건 | 후보는 1건만 조회, 행 잠금도 1건 |
| 후보 순회 | 처리에 실패하는 유실 차감 500건과 정상 유실 차감 1건 | 같은 실행에서 다음 페이지로 넘어가 정상 1건 환불 |
| 후보 페이지 | 유실 차감 600건 | 한 실행에서 500건과 100건 두 페이지로 모두 환불 |
| 이미 환불됨 | `CHAT` 차감 2, 저장 1, 환불 1 | 환불 없음 |
| 진행 중 차감 | 차감이 기준 시각 이내 | 대상 아님 |
| 재생성 완료 | `CHAT` 차감 2, 저장 턴 1, 재생성 1 | 환불 없음 |
| 완료 과다 | `CHAT` 그룹의 저장된 턴 수가 차감 수보다 많음 | 환불 없음 |
| 리소스 삭제 | `CHAT` 그룹의 채팅이 없음 | 환불 없음 |
| 간편 제작 | 차감 1, 진행이 완성 아님 | 환불 1행 |
| 간편 제작 완료 | 진행이 완성 | 환불 없음 |
| 이미지 제외 | 이미지 차감만 있는 그룹 | 대상 아님 |
| 재실행 | 같은 조건으로 두 번 실행 | 두 번째는 환불 없음 |
| 혼합 단가 | 간편 제작 차감 20과 30, 완료 0 | 환불 단가 20, WARN |
| 그룹 실패 격리 | 한 그룹에서 예외 | 나머지 그룹 처리, 실패 로그 |
| 차감 행 실패 격리 | 채팅 턴 차감 행 하나에서 예외 | 나머지 차감 행 처리, `credit_reconciliation_charge_failed` |
