# 5-5 테스트 케이스

이 문서는 PAYMENT 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에, 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 정책값 해석과 제외 규칙, 출석 멱등 키, 상품 설정 검증 | 없음 | CI |
| 통합 | 컨트롤러부터 저장까지, 지갑 연산, 로트 만료와 소진, 체험 카운터, 웹훅, 대사 | Redis는 테스트 JVM의 임베디드 서버 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 동시성 | 동시 첫 적립, 같은 멱등 키 동시 적립, 동시 차감, 월 상한 경계, 동시 웹훅 | 없음 | CI |
| 수동 | 엔드포인트 호출, 정책 오버라이드 반영, 실결제 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션과 두 배치 스케줄러를 비활성화한다. 배치는 서비스를 직접 호출해 검증한다. 전체 테스트를 통과해도 DB 제약이 검증된 것은 아니다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| 그로블 | 테스트 시크릿으로 서명한 본문을 직접 전송 |
| Redis | 테스트 JVM 시작 시 임베디드 서버를 띄우고 포트를 주입<br>장애는 연결할 수 없는 포트로 재현 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약은 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 시각 | 주입한 고정 시계로 KST 날짜 경계, 로트 만료, 웹훅 시각 범위 검증 |
| 회원 데이터 | 활성, 정지, 탈퇴, 재가입 계정과 지갑이 없는 계정 준비 |

### 5-5-2 지갑과 원장

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 첫 적립 | 지갑이 없는 회원에게 적립 | 지갑 생성, 원장 1행, 로트 1개, 잔액이 금액과 같음 |
| 멱등 적립 | 같은 키로 두 번 적립 | 두 번째는 적립 없이 `rewarded` false, 원장 1행 |
| 동시 첫 적립 | 지갑 없는 회원에게 다른 키로 동시 적립 | 지갑 1개, 두 적립 모두 기록 |
| 동시 같은 키 | 같은 키로 동시 적립 | 원장 1행, 나머지는 멱등 응답 또는 재시도 시 멱등하게 처리 |
| 월 상한 | 상한 2, 같은 달에 초대자 역할 키로 3회 적립 | 세 번째는 `monthlyCapped` true, 적립 없음 |
| 월 상한 역할 구분 | 제출자 역할 키의 적립 | 초대자 월 상한에 세지 않음 |
| 월 상한 신원 단위 | 재가입 계정의 초대자 적립, 이전 계정의 같은 달 행 존재 | 이전 계정의 행을 합쳐 집계 |

| 잔액 부족 | 잔액 20에서 30 차감 | 잔액 부족 예외, 원장과 로트 변화 없음 |
| 지갑 없음 | 지갑 없는 회원 차감 | 잔액 0의 잔액 부족 예외 |
| 항목 합산 차감 | 턴 20과 이미지 10을 한 번에, 잔액 25 | 전체 거절, 아무것도 기록하지 않음 |
| 항목별 원장 | 턴 20과 이미지 10, 잔액 100 | 원장 2행, 항목별 사유와 참조 기록, 잔액 70 |
| 동시 차감 | 잔액 50에서 30씩 동시 차감 | 하나만 성공, 잔액 20 |
| 로트 소진 순서 | 만료 임박 로트 30, 구매 로트 100, 승계 로트 50에서 60 차감 | 임박 로트 0, 구매 로트 70, 승계 로트 50 |
| 만료 정리 | 만료된 로트 40이 남은 회원의 적립 | `EXPIRE` 행 -40, 로트 잔여 0, 잔액에서 제외 |
| 만료와 부족 | 만료 로트 40, 활성 로트 10에서 20 차감 | 부족 예외, 만료 행 없음 |
| 잔액 조회 | 만료됐지만 정리 전인 로트 | 잔액에 포함하지 않음 |
| 로트 수명 | 보상, 환불, 구매 적립 | 만료 시각이 각각 30일 뒤, 30일 뒤, 5년 뒤 |
| 구매 회수 | 구매 로트 5,000 중 1,200 소진 뒤 회수 | 회수 3,800, 부족분 1,200, 잔액 변화 -3,800 |
| 전량 소진 회수 | 구매 로트 잔여 0 회수 | 회수 0, 원장 행 없음, 부족분이 원금 |
