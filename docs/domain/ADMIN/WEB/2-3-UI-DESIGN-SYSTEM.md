# 2-3 UI 디자인 시스템

이 문서는 관리자 웹의 차트 규칙, 계열 순서와 색과 선 모양, 숫자와 날짜 표기, 공용 요소의 사용 규칙을 정한다.

색, 글꼴, 간격, 모서리 토큰과 분석 화면 분포 차트의 모양은 관리자 저장소의 디자인 문서에, 화면별 차트 목록은 정보 구조에 있다. ([manyak-admin DESIGN.md](../../../../../manyak-admin/docs/DESIGN.md), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md))

<br>

### 2-3-1 기본 원칙

| 항목 | 규칙 |
|---|---|
| 색 모드 | 라이트 모드만 |
| 주색 | 마냑 초록 `--primary` |
| 강조 금지 | UI 강조에 그라디언트와 보라, 분홍, 파랑 계열을 쓰지 않음<br>차트 범주색(2-3-3)만 예외 |
| 글꼴 | Pretendard<br>식별자와 코드는 시스템 고정폭 글꼴 |
| 영문 머리말 | 쓰지 않음 |

<br>

### 2-3-2 차트

| 항목 | 규칙 |
|---|---|
| 축 | 차트 하나에 세로 축 하나<br>이중 세로 축을 쓰지 않음 |
| 단위 | 단위가 다른 값은 다른 차트<br>세로 축과 툴팁에 단위 표시 |
| 형태 | 일별 값은 2px 선, 점은 호버 때만<br>퍼널과 순위는 가로 막대<br>도달률은 기준 턴을 같은 간격의 가로 축으로 한 선 |
| 쌓기 | 전체와 부분처럼 겹치는 계열은 쌓지 않음 |
| 식별 | 계열이 하나면 차트 제목으로 식별<br>둘 이상이면 범례와 마지막 점 옆 값 라벨 |
| 툴팁 | 모든 차트에 호버 툴팁, 선 차트에는 세로 십자선 |
| 끊김 | 준비 중 날짜와 값이 없는 날은 선을 잇지 않음 |
| 움직임 | 데이터 전환 애니메이션 없음 |
| 대체 표 | 차트 카드마다 같은 값을 담은 접힌 수치 표 |
| 이동 | 목록으로 이어지는 차트는 막대, 점, 조각과 수치 표 링크를 모두 누를 수 있음 |

### 2-3-3 계열 순서와 모양

같은 묶음의 계열은 모든 화면에서 같은 순서와 색과 선 모양을 쓴다. 범례와 수치 표의 열도 이 순서다.

**1. 범주색**

| 토큰 | 값 | 비고 |
|---|---|---|
| `--chart-1` | `#01A76B` | 브랜드 초록, `--primary`와 같음 |
| `--chart-2` | `#3B6FD4` | 파랑 |
| `--chart-3` | `#E07A1F` | 주황<br>흰 배경 대비 2.93:1로 낮음 |
| `--chart-4` | `#8B5CD6` | 보라 |
| `--chart-5` | `#D9467A` | 분홍 |

- 다섯 색은 서로 다른 색상이다. 같은 초록의 농도 차이로 계열을 나누지 않는다.
- 색은 계열의 개체에 고정한다. 기간, 값의 크기, 순위가 바뀌어도 같은 개체는 같은 색이다.
- 주황은 대비가 낮아 선이나 막대만으로 읽게 두지 않는다. 마지막 점 옆 값 라벨과 수치 표를 함께 둔다.
- 선 모양은 색과 함께 계열을 구분하는 두 번째 수단이다.
- 관리자 웹은 라이트 모드만이라 다크 모드 값은 두지 않는다.

**2. 묶음별 순서와 모양**

| 플랫폼 | 1. 합계 또는 전체 | `--chart-1` | 실선 |

| 기능 | AI 응답 생성, 선택지 생성, 실시간 이미지 생성, 스토리라인 생성, 간편 제작 | 셋 이상 나열과 같음 | 셋 이상 나열과 같음 |

- 5xx 응답의 대상 5xx와 ALB 5xx, 읽기와 쓰기 지연은 두 계열 비교를 쓴다. 퍼널 막대는 `--primary`이고 단계 순서는 응답 순서다. 기간 평균 같은 기준선은 `--muted-foreground` 점선이다.

### 2-3-4 숫자와 날짜

| 값 | 표기 |
|---|---|
| 정수 | 천 단위 쉼표, 뒤에 단위 |
| 사람 수 | 명 |
| 이벤트 횟수 | 회 |
| 채팅과 스토리 수 | 개 |
| 비용 | 원<br>1원 미만 자리가 있으면 소수 둘째 자리까지 |
| 0~1 비율 | 100배한 %로 소수 첫째 자리까지<br>리텐션, 광고 유입 비중, 도달률, 스트림 오류율, 클라이언트가 계산한 전환율과 비중 |
| 0~100 백분율 | 100배하지 않고 그대로 %로 소수 첫째 자리까지<br>분석 화면 분포 차트에서 단위가 `%`인 값 |
| 평균 세션 길이와 사용자당 전송 수 | 소수 첫째 자리까지 |
| 용량 | 10진 단위로 1GB는 1,000,000,000바이트, 1MB는 1,000,000바이트<br>소수 첫째 자리까지<br>저장 공간과 데이터베이스 크기는 GB, 테이블 크기는 MB |
| 응답 시간과 지연 | ms, 소수 첫째 자리까지 |
| 날짜 | `YYYY-MM-DD`<br>차트 가로 축은 `MM-DD`<br>인프라 차트의 가로 축은 KST 시각이며 기간이 하루면 `HH:mm`, 그보다 길면 `MM-DD HH:mm` |
| 범위 | `{시작 날짜} ~ {끝 날짜} (KST)` |
| 시각 | KST로 바꿔 날짜와 시분 |

### 2-3-5 문구 표기

| 항목 | 규칙 |
|---|---|
| 기호 | em dash와 가운뎃점 나열을 쓰지 않음<br>나열은 쉼표, 범위는 물결표, 보충은 괄호 |
| 페이지 설명 | 화면 제목 아래를 포함해 화면에 늘 보이는 설명 문장을 두지 않음 |
| 도움말 툴팁 | 꼭 필요한 설명은 그 대상의 제목 옆 "?" 버튼에 두고 마우스를 올리거나 키보드 초점을 두면 툴팁으로 보임<br>출처 안내는 출처 이름의 툴팁으로 보임 |
| 화면에 두는 안내 | 기능상 필요한 안내(발송 동의와 야간 조건, 위험 작업 확인, 오류와 빈 상태, 기간 상한 안내)<br>값이 있을 때만 보이는 준비 중 알림과 누락 안내 |
| 상태 제목 | 명사형으로 끝냄 |
| 안내 문장 | 행동을 요청하는 안내는 "해 주세요"로 끝냄<br>설명 툴팁과 상태 안내는 평서형 |
| 내부 값 | enum, 이벤트 이름, 사유 코드를 그대로 보이지 않고 정해진 표시 이름으로 바꿈<br>표시 이름이 정해지지 않은 값만 원문 표시 |
| 값 없음 | 대시 기호 대신 그 의미의 문구 |
