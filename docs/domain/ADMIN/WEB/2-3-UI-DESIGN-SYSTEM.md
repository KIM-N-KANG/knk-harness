# 2-3 UI 디자인 시스템

이 문서는 관리자 웹의 차트 규칙, 계열 순서와 색과 선 모양, 숫자와 날짜 표기, 공용 요소의 사용 규칙을 정한다.

색, 글꼴, 간격, 모서리 토큰과 분석 화면 분포 차트의 모양은 관리자 저장소의 디자인 문서에, 화면별 차트 목록은 정보 구조에 있다. ([manyak-admin DESIGN.md](../../../../../manyak-admin/docs/DESIGN.md), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md))

<br>

### 2-3-1 기본 원칙

| 항목 | 규칙 |
|---|---|
| 색 모드 | 라이트 모드만 |
| 주색 | 마냑 초록 `--primary` |
| 강조 금지 | 그라디언트와 보라, 분홍, 파랑 계열을 쓰지 않음 |
| 글꼴 | Pretendard<br>식별자와 코드는 시스템 고정폭 글꼴 |
| 영문 머리말 | 쓰지 않음 |

<br>

### 2-3-2 차트

| 항목 | 규칙 |
|---|---|
| 축 | 차트 하나에 세로 축 하나<br>이중 세로 축을 쓰지 않음 |
| 단위 | 단위가 다른 값은 다른 차트<br>세로 축과 툴팁에 단위 표시 |
| 형태 | 일별 값은 2px 선, 점은 호버 때만<br>퍼널과 순위는 가로 막대<br>도달률 비교는 묶음 막대 |
| 쌓기 | 전체와 부분처럼 겹치는 계열은 쌓지 않음 |
| 식별 | 계열이 하나면 차트 제목으로 식별<br>둘 이상이면 범례와 마지막 점 옆 값 라벨 |
| 툴팁 | 모든 차트에 호버 툴팁, 선 차트에는 세로 십자선 |
| 끊김 | 준비 중 날짜와 값이 없는 날은 선을 잇지 않음 |
| 움직임 | 데이터 전환 애니메이션 없음 |
| 대체 표 | 차트 카드마다 같은 값을 담은 접힌 수치 표 |
| 이동 | 목록으로 이어지는 차트는 막대, 점, 조각과 수치 표 링크를 모두 누를 수 있음 |

<br>

### 2-3-3 계열 순서와 모양

같은 묶음의 계열은 모든 화면에서 같은 순서와 색과 선 모양을 쓴다. 범례와 수치 표의 열도 이 순서다.

| 묶음 | 순서 | 색 | 선 모양 |
|---|---|---|---|
| 플랫폼 | 1. 합계 또는 전체 | `--primary` | 실선 |
| 플랫폼 | 2. Web | `--muted-foreground` | 긴 점선(6, 3) |
| 플랫폼 | 3. Android | `--primary-text` | 짧은 점선(2, 3) |
| 플랫폼 | 4. 플랫폼 없음 | `--chart-3` | 1점 쇄선(8, 3, 2, 3) |
| 광고 구분 | 1. 전체 | `--primary` | 실선 |
| 광고 구분 | 2. 광고 유입 | `--primary-text` | 긴 점선(6, 3) |
| 광고 구분 | 3. 광고 외 유입 | `--muted-foreground` | 짧은 점선(2, 3) |
| 유입 소스 | 1. 광고 유입 | `--primary` | 실선 |
| 유입 소스 | 2. 인스타그램 | `--primary-text` | 긴 점선(6, 3) |
| 유입 소스 | 3. 쓰레드 | `--muted-foreground` | 짧은 점선(2, 3) |
| 유입 소스 | 4. 디시인사이드 | `--chart-3` | 1점 쇄선(8, 3, 2, 3) |
| 유입 소스 | 5. 그 밖 | `--chart-5` | 실선 |
| 가입 경로 | 1. 전체 | `--primary` | 실선 |
| 가입 경로 | 2. 구글 | `--primary-text` | 긴 점선(6, 3) |
| 가입 경로 | 3. 카카오 | `--muted-foreground` | 짧은 점선(2, 3) |
| 가입 경로 | 4. 그 외 | `--chart-3` | 1점 쇄선(8, 3, 2, 3) |
| 소유자 유형 | 1. 전체 | `--primary` | 막대 |
| 소유자 유형 | 2. 게스트 | `--muted-foreground` | 막대 |
| 소유자 유형 | 3. 회원 | `--primary-text` | 막대 |
| 입력 방식 | 1. 블럭 입력 | `--primary` | 실선 |
| 입력 방식 | 2. 일반 입력 | `--primary-text` | 긴 점선(6, 3) |
| 입력 방식 | 3. 선택지 | `--muted-foreground` | 짧은 점선(2, 3) |
| 입력 방식 | 4. 방식 정보 없음 | `--chart-3` | 1점 쇄선(8, 3, 2, 3) |
| 두 계열 비교 | 1. 앞 계열 | `--primary` | 실선 |
| 두 계열 비교 | 2. 뒤 계열 | `--muted-foreground` | 긴 점선(6, 3) |
| 셋 이상 나열 | 정보 구조의 나열 순서 | `--chart-1`부터 차례로, 다섯 번째 뒤로는 `--muted-foreground` | 실선, 긴 점선, 짧은 점선, 1점 쇄선 순서 반복 |
| 모델 코드 | 코드의 글자 순서 | 셋 이상 나열과 같음 | 셋 이상 나열과 같음 |
| 기능 | AI 응답 생성, 선택지 생성, 스토리라인 생성, 간편 제작 | 셋 이상 나열과 같음 | 셋 이상 나열과 같음 |

- 퍼널 막대는 `--primary`이고 단계 순서는 응답 순서다. 기간 평균 같은 기준선은 `--muted-foreground` 점선이다.

### 2-3-4 숫자와 날짜

| 값 | 표기 |
|---|---|
| 정수 | 천 단위 쉼표, 뒤에 단위 |
| 사람 수 | 명 |
| 이벤트 횟수 | 회 |
| 채팅과 스토리 수 | 개 |
| 비용 | 원<br>1원 미만 자리가 있으면 소수 둘째 자리까지 |
| 0~1 비율 | 100배한 %로 소수 첫째 자리까지<br>리텐션, 광고 유입 비중, 도달률, 스트림 오류율, 클라이언트가 계산한 전환율과 비중 |
| 0~100 백분율 | 100배하지 않고 그대로 %로 소수 첫째 자리까지<br>분석 화면 분포 차트에서 단위가 `%`인 값 |
| 평균 세션 길이와 사용자당 전송 수 | 소수 첫째 자리까지 |
| 날짜 | `YYYY-MM-DD`<br>차트 가로 축은 `MM-DD` |
| 범위 | `{시작 날짜} ~ {끝 날짜} (KST)` |
| 시각 | KST로 바꿔 날짜와 시분 |

<br>

### 2-3-5 문구 표기

| 항목 | 규칙 |
|---|---|
| 기호 | em dash와 가운뎃점 나열을 쓰지 않음<br>나열은 쉼표, 범위는 물결표, 보충은 괄호 |
| 상태 제목 | 명사형으로 끝냄 |
| 안내 문장 | "해 주세요"로 끝냄 |
| 내부 값 | enum, 이벤트 이름, 사유 코드를 그대로 보이지 않고 정해진 표시 이름으로 바꿈<br>표시 이름이 정해지지 않은 값만 원문 표시 |
| 값 없음 | 대시 기호 대신 그 의미의 문구 |
