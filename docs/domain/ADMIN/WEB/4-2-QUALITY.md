# 4-2 품질

이 문서는 관리자 웹 대시보드 그룹과 이프 내역, 검수 제출 화면의 접근성, 인증 상태 처리, 분석 이벤트를 정한다.

접근성과 성능의 목표는 요구사항에, 인증 만료의 화면 처리는 오류 처리에 있다. ([1-2 요구사항](1-2-REQUIREMENTS.md), [4-1 오류 처리](4-1-ERROR-HANDLING.md))

<br>

### 4-2-1 접근성

| 대상 | 규칙 |
|---|---|
| 사이드바 구역 버튼 | 펼침 상태와 하위 메뉴 영역의 관계를 알림<br>접힌 메뉴는 접근성 트리와 탭 이동에서 뺌 |
| 활성 메뉴 | 현재 페이지임을 알림 |
| 탭 막대 | 탭 목록과 선택된 탭, 탭 본문의 관계를 알림<br>좌우 방향키로 탭 사이 이동 |
| 기간 선택기 | 버튼 이름에 현재 기간을 넣음<br>닫으면 버튼으로 초점을 돌려줌<br>직접 선택 오류는 경고로 읽힘 |
| 출처 표시 | 버튼 이름 "{출처} 출처와 집계 안내", 안내 문구를 설명으로 연결 |
| 도움말 툴팁 | 버튼 이름 "{대상 제목} 도움말", 툴팁 문구를 설명으로 연결<br>키보드 초점으로도 열리고 Esc로 닫힘 |
| 차트 | 차트 영역에 "{차트 제목} 추이" 같은 이름 |
| 퍼널과 순위 막대 | 막대 옆에 값을 글자로 표시 |
| 상태 | 불러오는 중과 준비 중은 상태 알림, 실패와 기간 오류는 경고 알림 |
| 스켈레톤 | 기다리는 영역에 `aria-busy="true"`, 값이 오면 해제<br>스켈레톤 블록은 접근성 트리에서 숨김<br>상태 알림 영역에 숨김 문구 "데이터를 불러오는 중입니다…" |
| 표 | 정렬 가능한 머리글은 정렬 방향을 알림<br>현재 페이지 번호는 현재 페이지임을 알림 |
| 확인 대화상자 | 열면 사유 입력 칸에 초점, 닫으면 연 버튼으로 초점을 돌려줌<br>대화상자 밖으로 초점이 나가지 않음<br>오류 문구는 경고로 읽힘<br>Esc는 처리 중이 아닐 때만 닫음 |
| 성공 알림 | 상태 알림으로 읽힘 |
| 스토리 설정 이미지 | 대체 텍스트는 표지가 "표지", 인물 이미지가 `imageName`<br>작은 이미지는 버튼이고 이름은 "{대체 텍스트} 크게 보기"<br>상태 배지와 불러오기 실패는 글자로 읽힘 |
| 이미지 크게 보기 | 열면 닫기 버튼에 초점, 닫으면 누른 작은 이미지로 초점을 돌려줌<br>대화상자 밖으로 초점이 나가지 않음<br>Esc로 닫힘 |
| 움직임 | 펼침과 팝오버 전환은 150ms이고 움직임 줄이기 설정에서는 끔<br>스켈레톤의 깜빡임도 움직임 줄이기 설정에서는 멈추고 정지한 회색으로 둠 |

<br>

### 4-2-2 인증 상태

| 상황 | 처리 |
|---|---|
| 세션 쿠키 없음 | 화면 요청은 로그인 화면으로, BFF 요청은 인증 없음으로 응답 |
| 서버가 토큰을 거절 | 쿠키를 지우고 로그인 화면으로 전체 이동 |
| 로그아웃 | 쿠키를 지우고 전체 페이지 이동으로 조회 캐시를 비움 |
| 고정 데이터 미리보기 | 운영 외 환경에서 로그인 없이 화면을 엶<br>BFF는 서버를 부르지 않음 |

- 관리자의 역할과 계정 상태는 서버가 요청마다 확인한다. 웹은 쿠키가 있는지만 본다.

<br>

### 4-2-3 분석 이벤트

관리자 웹은 분석 이벤트를 보내지 않는다.
