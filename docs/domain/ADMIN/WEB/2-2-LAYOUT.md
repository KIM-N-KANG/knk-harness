# 2-2 배치

이 문서는 관리자 웹 화면의 영역 순서와 격자, 너비별 열 수를 정한다.

간격, 글자 크기, 모서리 같은 토큰 값은 관리자 저장소의 디자인 문서에, 각 영역에 담을 정보는 정보 구조에 있다. ([manyak-admin DESIGN.md](https://github.com/KIM-N-KANG/manyak-admin/blob/dev/docs/DESIGN.md), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md))

<br>

### 2-2-1 공통 틀

| 영역 | 배치 |
|---|---|
| 사이드바 | 1024px 이상은 왼쪽 고정 너비 224px<br>그보다 좁으면 본문 위 |
| 본문 | 사이드바 오른쪽, 별도 상단 바 없음 |
| 페이지 머리 | 본문 맨 위<br>왼쪽에 제목, 오른쪽 아래 맞춤으로 기간 선택기<br>사용자, 콘텐츠, 채팅, 수익과 그 관리 목록은 제목 바로 오른쪽에 상호 링크<br>지표 화면은 기간 선택기 바로 왼쪽에 플랫폼, 대상 선택을 이 순서로 두고 대상 라벨 옆 "?" 툴팁에 대상 도움말<br>그 탭이 쓰지 않는 선택은 자리 없이 숨기고 기간 선택기는 늘 오른쪽 끝<br>좁으면 선택 상자와 기간 선택기가 함께 제목 아래로 내려감 |
| 카드 | 흰 배경, 1px 테두리, 12px 모서리, 안쪽 여백 24px |
| 카드 사이 | 세로 20px 이상 |

### 2-2-2 개요

| 화면 | 순서 | 격자 |
|---|---|---|
| 개요 | 1. 페이지 머리<br>2. 요약 카드 6개<br>3. 일별 추이 카드 | 요약 카드는 1280px 이상 3열 2행, 640px 이상 2열, 그보다 좁으면 1열<br>오늘 활성 사용자 카드는 맨 앞, 앱 설치 카드는 맨 끝<br>일별 추이 카드 안의 그래프 하나는 카드 너비 전체 |

### 2-2-3 지표 화면

유입, 사용자, 콘텐츠, 채팅, 수익, 운영 화면이 같은 순서를 쓴다. 탭 본문은 영역을 정보 구조에 정한 순서로 위에서 아래로 쌓는다. 운영 저장소 하위 구분은 차트 카드를 RDS, Redis, OpenSearch 구역으로 나누고 구역마다 구역 제목을 둔다.

| 순서 | 자리 | 격자 |
|---|---|---|
| 1 | 페이지 머리 | |
| 2 | 탭 막대 | 한 줄, 넘치면 가로 스크롤<br>수익은 없음 |
| 3 | 하위 구분 막대 | 탭 막대와 같음<br>유입의 광고 캠페인 탭과 앱 탭, 운영의 서비스 탭만 |
| 4 | 조건 선택 줄 | 왼쪽부터 광고 캠페인, 광고 구분, 대상 스토리, 시작 집단 순서<br>그 탭이 쓰지 않는 조건은 자리 없이 숨김<br>상세 진입 채팅 카드의 대상 스토리는 이 줄이 아니라 카드 안 |
| 5 | 준비 중 알림 또는 누락 안내 | 탭에 하나, 한 줄 상자 |
| 6 | 영역 제목과 출처 표시 | 영역마다 한 줄<br>일별 추이 영역은 없음 |
| 7 | 요약 카드 | 1280px 이상 4열, 640px 이상 2열, 그보다 좁으면 1열 |
| 8 | 차트 카드 | 1280px 이상 2열, 그보다 좁으면 1열<br>퍼널, 코호트 표, 비용 표, 장르별 평균 턴 수, 평균 세션 길이, 세션 길이 분포는 두 열을 모두 차지<br>영역 안에서 한 줄에 혼자 남는 마지막 차트 카드도 두 열을 모두 차지<br>전환 퍼널 카드는 한 열에 정해진 순서로 위에서 아래로 쌓음<br>첫 사용자 입력까지 걸린 시간 카드는 같은 줄 카드의 높이로 늘이지 않고 내용 높이<br>수익의 일별 추이 카드 안의 그래프 4개는 1280px 이상 2열 2행, 640px 이상 2열, 그보다 좁으면 1열 |
| 9 | 전체 수치 표 | 접힌 상태로 영역 맨 아래, 표 안에서 세로 스크롤 |

- 6~9는 영역마다 차례로 되풀이한다.
- 영역의 기간 오류나 사용 불가 상태에서는 그 영역의 7~9 대신 상태 상자 하나를 둔다.

<br>

### 2-2-4 검수 제출

| 화면 | 순서 | 격자 |
|---|---|---|
| 목록 | 1. 페이지 머리<br>2. 필터 줄<br>3. 성공 알림(해제 뒤 4초)<br>4. 목록 표<br>5. 페이지 번호 | 표는 넓이 전체, 좁으면 표 안에서 가로 스크롤 |
| 상세 | 1. 머리(제출본 ID, 종류, 상태, 링크, 해제 버튼)<br>2. 처리 경과 카드<br>3. 검수 대상 필드 카드<br>4. 위반 항목 표<br>5. 이미지 결과 표 | 1280px 이상에서 처리 경과와 검수 대상 필드를 1:2 두 열, 그보다 좁으면 한 열 |

- 확인 대화상자는 화면 가운데의 모달이고 최대 너비 448px이다.
