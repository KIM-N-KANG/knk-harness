# 2-2 배치

이 문서는 관리자 웹 화면의 영역 순서와 격자, 너비별 열 수를 정한다.

간격, 글자 크기, 모서리 같은 토큰 값은 관리자 저장소의 디자인 문서에, 각 영역에 담을 정보는 정보 구조에 있다. ([manyak-admin DESIGN.md](../../../../../manyak-admin/docs/DESIGN.md), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md))

<br>

### 2-2-1 공통 틀

| 영역 | 배치 |
|---|---|
| 사이드바 | 1024px 이상은 왼쪽 고정 너비 224px<br>그보다 좁으면 본문 위 |
| 본문 | 사이드바 오른쪽, 별도 상단 바 없음 |
| 페이지 머리 | 본문 맨 위<br>왼쪽에 제목, 오른쪽 아래 맞춤으로 기간 선택기<br>좁으면 기간 선택기가 제목 아래로 내려감 |
| 카드 | 흰 배경, 1px 테두리, 12px 모서리, 안쪽 여백 24px |
| 카드 사이 | 세로 20px 이상 |

<br>

### 2-2-2 개요와 분석

| 화면 | 순서 | 격자 |
|---|---|---|
| 개요 | 1. 페이지 머리<br>2. 요약 카드 10개<br>3. 일별 추이 카드 | 요약 카드는 1280px 이상 5열 2행, 640px 이상 2열, 그보다 좁으면 1열<br>오늘 활성 사용자 카드는 맨 앞, 앱 설치 카드는 서버 DB 카드 8개 뒤의 맨 끝<br>일별 추이 카드 안의 그래프 8개는 1280px 이상 4열 2행, 640px 이상 2열, 그보다 좁으면 1열 |
| 분석 | 1. 페이지 머리<br>2. 범위<br>3. 구역마다 구역 제목과 차트 카드 | 차트 카드는 1280px 이상 2열<br>장르별 평균 턴 수 카드는 두 열을 모두 차지 |

<br>

### 2-2-3 지표 화면

유입 분석, 사용자, 전환, 기능과 품질, 인프라 화면이 같은 순서를 쓴다. 인프라 저장소 탭은 차트 카드를 RDS, Redis, OpenSearch 구역으로 나누고 구역마다 구역 제목을 둔다.

| 순서 | 영역 | 격자 |
|---|---|---|
| 1 | 페이지 머리 | |
| 2 | 탭 막대 | 한 줄, 넘치면 가로 스크롤 |
| 3 | 조건 선택 줄 | 왼쪽부터 광고 캠페인, 광고 구분, 플랫폼, 대상, 대상 스토리 순서<br>그 탭이 쓰지 않는 조건은 자리 없이 숨김<br>전환 퍼널의 대상 스토리는 이 줄이 아니라 상세 진입 채팅 카드 안 |
| 4 | 탭 제목과 출처 표시 | 한 줄 |
| 5 | 준비 중 알림 또는 누락 안내 | 한 줄 상자 |
| 6 | 요약 카드 | 1280px 이상 4열, 640px 이상 2열, 그보다 좁으면 1열 |
| 7 | 차트 카드 | 1280px 이상 2열, 그보다 좁으면 1열<br>퍼널, 코호트 표, 비용 표는 두 열을 모두 차지<br>전환 퍼널 카드 다섯 개는 한 열에 정해진 순서로 위에서 아래로 쌓음 |
| 8 | 전체 수치 표 | 접힌 상태로 맨 아래, 표 안에서 세로 스크롤 |

- 기간 오류나 사용 불가 상태에서는 5~8 대신 상태 상자 하나를 둔다.

<br>

### 2-2-4 검수 제출

| 화면 | 순서 | 격자 |
|---|---|---|
| 목록 | 1. 페이지 머리<br>2. 필터 줄<br>3. 성공 알림(해제 뒤 4초)<br>4. 목록 표<br>5. 페이지 번호 | 표는 넓이 전체, 좁으면 표 안에서 가로 스크롤 |
| 상세 | 1. 머리(제출본 ID, 종류, 상태, 링크, 해제 버튼)<br>2. 처리 경과 카드<br>3. 검수 대상 필드 카드<br>4. 위반 항목 표<br>5. 이미지 결과 표 | 1280px 이상에서 처리 경과와 검수 대상 필드를 1:2 두 열, 그보다 좁으면 한 열 |

- 확인 대화상자는 화면 가운데의 모달이고 최대 너비 448px이다.
