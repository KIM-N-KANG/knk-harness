# 5-1 검증

이 문서는 관리자 웹 대시보드 그룹과 이프 내역 화면의 테스트 범위와 화면별 케이스의 입력, 상황, 기대 결과를 정한다.

실행 명령은 AGENTS.md에, 화면별 기본값과 문구는 정보 구조와 오류 처리에 있다. ([AGENTS.md](AGENTS.md), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md), [4-1 오류 처리](4-1-ERROR-HANDLING.md))

<br>

### 5-1-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 |
|---|---|---|
| 단위 | 기간 해석과 상한 판정, URL 쿼리 해석, 전환율 계산, 표시 이름 변환, 계열 순서 | 없음 |
| BFF | 경로 대응, 생성 스키마 검증, 서버 응답 전달, 데이터 모드 판정 | 서버는 고정 응답을 돌려주는 대역 |
| 화면 | 탭 전환, 요청 막음, 준비 중 재요청, 상태 표시, 값 없음 문구 | BFF는 고정 응답 |
| 수동 | 서버 모드로 개발 서버에 붙여 화면 확인 | 실제 서버 |

- 테스트는 고정 시계로 KST 오늘을 정한다.

<br>

### 5-1-2 공통

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 기간 해석 | `range=last7d`<br>`from=2026-10-01&to=2026-10-10`<br>쿼리 없음 | 오늘을 포함한 7일<br>그 범위<br>탭의 기본 기간 |
| 예전 링크 | `days=30` | URL이 `range=last30d`로 바뀌고 기록이 늘지 않음 |
| 기간 오류 문구 | 시작 날짜가 끝 날짜보다 뒤, 끝 날짜가 내일, 367일 | 각각의 오류 문구, 적용 버튼 비활성 |
| 서버로 보내는 기간 | 어떤 기간 선택이든 | 요청 쿼리에 `from`과 `to`만 있고 `days` 없음 |
| 상한 초과 | 기간 30일로 간편 제작 퍼널 탭 진입 | 기간 확인 필요 상자, 요청 없음, 기간 쿼리 그대로 |
| 맞추기 버튼 | 위 상태에서 최근 20일로 맞추기 | 끝 날짜는 그대로, 시작 날짜가 20일 범위로 바뀌고 요청 |
| 빠른 범위 비활성 | 간편 제작 퍼널 탭에서 기간 선택기 열기 | 20일을 넘는 빠른 범위 비활성 |
| 준비 중 재요청 | 응답의 `pendingDates`가 2개 | 준비 중 날짜 2개 알림, 60초 뒤 같은 요청<br>준비 중 날짜와 준비 중 값이 모두 없는 응답이 오면 재요청 멈춤 |
| 준비 중 값만 남음 | 사용자 활동 응답의 `pendingDates`는 비었고 `monthlyActiveUsers`가 `null` | MAU 자리 "준비 중", 60초 뒤 다시 요청 |
| 고정 데이터 미리보기 | 운영 외 고정 데이터 모드, 쿠키 없이 지표 요청 | 로그인 없이 고정 데이터 응답 |
| 준비 중 날짜 그리기 | 범위 7일 중 2일이 준비 중 | 차트 선이 그 날짜에서 끊기고 표에 "준비 중", 0으로 그리지 않음 |
| 탭 격리 | 사용자 활동 요청이 사용 불가 | 그 탭만 "Amplitude 지표를 불러올 수 없음", 신규 가입자 탭은 정상 |
| 요청 범위 | 사용자 화면 진입 | 사용자 활동 요청만 보냄 |
| 출처 표시 | Amplitude 탭과 서버 DB 탭 | 각각 "Amplitude"와 "서버 DB" |
| 기호 | 모든 화면 문구 | em dash와 가운뎃점 나열 없음 |
| 페이지 설명 | 모든 화면의 제목 아래 | 설명 문장 없음 |
| 도움말 툴팁 | 분포 카드 제목 옆 "?" 버튼에 마우스를 올림<br>Tab으로 같은 버튼에 초점<br>Esc | 응답의 설명이 툴팁으로 열리고 카드 본문에는 없음<br>같은 툴팁이 열림<br>툴팁이 닫힘 |

### 5-1-4 유입 분석

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 기본 캠페인 | 캠페인 목록 4항목 중 4차만 종료일 없음, URL 비어 있음 | 4차 적용, 기간은 4차 시작일부터 오늘 |

| 진행 중 캠페인 없음 | 모든 항목에 종료일, URL 비어 있음 | "진행 중인 광고 캠페인이 없습니다. 광고 캠페인을 선택해 주세요.", 요청 없음 |
| 직접 입력 | "직접 입력"에 `TEST_2026` | `campaign=TEST_2026`으로 요청, 기본 기간 최근 30일 |

| 전환율 | 1단계 100, 2단계 40, 3단계 0, 4단계 0 | 2단계 40.0%, 3단계 0.0%, 4단계 "계산할 수 없음" |

| 상세 진입 기본 기간 | 3차 선택, 기간 쿼리 없음 | 3차 기간 35일이 31일 상한을 넘어 기간 확인 필요 상자, 요청 없음 |

| 스토리 형식 | 입력 `abc` | 형식 오류 문구, 요청 없음 |
| 유입 소스 조건 | 유입 소스 탭 | 광고 캠페인 선택 숨김, 요청에 `campaign` 없음 |

| 유입 소스 상한 | 3차 기간(35일)에서 유입 소스 탭 | 기간 확인 필요 상자, 최근 10일로 맞추기 |

| 상위 20개 | 소스 30개 | 차트 20개, 수치 표 30개 |
| 앱 설치 탭 | URL에 `tab=installs&range=last30d` | 기간 선택기 비활성과 "전체 기간", 광고 캠페인 선택 숨김<br>설치 지표 요청에 쿼리 없음, 캠페인 목록을 기다리지 않음<br>출처 표시 "Google Play" |
| 앱 설치 탭의 기간 유지 | 위 상태에서 캠페인 추이 탭으로 | URL의 `range=last30d`가 그대로 적용 |
