# 4-1 오류 처리

이 문서는 관리자 웹 대시보드 그룹과 이프 내역, 검수 제출 화면, 스토리 공개 중단의 불러오는 중, 실패, 사용 불가, 준비 중, 값 없음, 기간 오류, 조건 누락의 표시와 재시도, 복귀 경로를 정한다.

서버의 실패 조건은 BACKEND 오류 처리에, 재요청 간격은 데이터 연동에 있다. ([BACKEND 5-3 오류 처리](../BACKEND/5-3-ERROR-HANDLING.md), [3-2-2 준비 중 재요청](3-2-DATA-INTEGRATION.md#3-2-2-준비-중-재요청))

<br>

### 4-1-1 상태 구분

| 상태 | 판단 | 표시 범위 |
|---|---|---|
| 불러오는 중 | 첫 응답 전 | 그 탭이나 그 영역 |
| 실패 | 연결 실패, 서버 오류, 잘못된 요청 응답 | 그 탭이나 그 영역 |
| 분석 도구 사용 불가 | Amplitude 출처 요청이 사용 불가로 응답 | 그 탭이나 그 영역 |
| 인프라 지표 사용 불가 | 인프라 지표 요청이 사용 불가로 응답 | 서비스와 요청 탭과 저장소 탭 |
| AI 비용 사용 불가 | AI 비용 요청이 사용 불가로 응답 | AI 비용 탭 |
| 설치 지표 사용 불가 | 앱 설치 요청이 사용 불가로 응답 | 개요의 앱 설치 카드, 유입 분석의 앱 설치 탭 |
| 서버 미구현 | 사용 불가 응답의 문구가 "서버 미구현" | 그 탭이나 그 영역 |
| 인증 만료 | 인증 없음 응답 | 화면 전체 |
| 준비 중 | 응답의 `pendingDates`가 비어 있지 않거나 준비 중 값이 `null` | 그 탭의 알림과 값 자리 |
| 값 없음 | 계약이 `null`로 정한 값 | 그 값 자리 |
| 실제 0 | 응답 값이 0 | 그 값 자리 |
| 기간 오류 | 기간이 탭 상한을 넘거나 리텐션의 끝 날짜가 오늘 | 그 탭 본문 |
| 조건 누락 | 필수 조건이 비었거나 형식이 틀림 | 그 조건 입력과 탭 본문 |

- 불러오는 중은 그 영역의 최종 배치와 같은 크기와 자리의 스켈레톤으로 보인다. 요청 뒤 200ms 안에 응답이 오면 스켈레톤을 그리지 않고 바로 값을 그린다. 한 번 그린 스켈레톤은 깜빡임을 막으려고 최소 300ms 유지한다. ([2-4-2 공용 구성 요소](2-4-COMPONENT-ARCHITECTURE.md#2-4-2-공용-구성-요소))
- 요약 카드 안의 기간 합계 줄처럼 카드의 일부만 기다리는 값도 그 줄 높이의 인라인 스켈레톤으로 보인다.
- 준비 중 재요청, 해제 뒤 갱신처럼 이미 값이 있는 화면의 다시 요청은 스켈레톤을 그리지 않고 이전 값을 둔다.
- 한 영역의 실패는 다른 영역과 다른 탭을 가리지 않는다. 개요는 서버 DB 요약 카드 묶음, 일별 추이, 오늘 활성 사용자 카드, 앱 설치 카드가 각자 상태를 가진다.

| 실패 | 데이터 불러오기 실패 | 잠시 후 다시 시도해 주세요. 문제가 계속되면 담당자에게 문의해 주세요. | 다시 시도 |
| 분석 도구 사용 불가 | Amplitude 지표를 불러올 수 없음 | 잠시 후 다시 시도해 주세요. | 다시 시도 |
| 인프라 지표 사용 불가 | 인프라 지표를 불러올 수 없음 | 잠시 후 다시 시도해 주세요. 문제가 계속되면 서버의 CloudWatch 권한과 인프라 지표 설정을 확인해 주세요. | 다시 시도 |
| AI 비용 사용 불가 | AI 비용을 불러올 수 없음 | 잠시 후 다시 시도해 주세요. 문제가 계속되면 서버의 Langfuse 설정을 확인해 주세요. | 다시 시도 |
| 설치 지표 사용 불가 | 설치 지표 사용 불가 | 잠시 후 다시 시도해 주세요. 문제가 계속되면 Play 설치 지표 설정과 보고서 상태를 확인해 주세요. | 다시 시도 |
| 서버 미구현 | 기능 준비 중 | 이 기능은 서버 연결을 준비 중입니다. | 다시 시도 |
| 인증 만료 | 없음 | 없음 | 쿠키를 지우고 로그인 화면으로 전체 이동 |
| 준비 중 알림 | 없음 | 준비 중 날짜 {N}개. 60초 뒤 다시 요청합니다. | 날짜 목록 펼침 |
| 준비 중 값 | 없음 | 준비 중 | 60초 뒤 다시 요청 |
| 기간 상한 초과 | 기간 확인 필요 | 이 탭은 최대 {N}일까지 볼 수 있습니다. 기간을 {N}일 이내로 선택해 주세요. | 최근 {N}일로 맞추기 |
| 리텐션 끝 날짜 | 기간 확인 필요 | 리텐션은 어제까지의 신규 방문일만 볼 수 있습니다. 끝 날짜를 어제 이전으로 선택해 주세요. | 어제까지로 맞추기 |
| 캠페인 없음 | 없음 | 진행 중인 광고 캠페인이 없습니다. 광고 캠페인을 선택해 주세요. | 광고 캠페인 선택 |
| 대상 스토리 없음 | 없음 | 이 광고 캠페인에는 대상 스토리가 없습니다. 스토리 공개 식별자를 입력해 주세요. | 입력 칸에 초점 |
| 스토리 식별자 형식 | 없음 | 스토리 공개 식별자 형식을 확인해 주세요. | 없음 |
| 보류 해제 사유 누락 | 없음 | 처리 사유를 입력해 주세요. | 확인 버튼 비활성 |
| 보류 해제 409 | 없음 | 이미 보류가 풀린 제출본입니다. 목록을 새로 불러왔습니다. | 목록 다시 요청 |
| 보류 해제 404 | 없음 | 제출본을 찾을 수 없습니다. 목록을 새로 불러왔습니다. | 목록 다시 요청 |
| 보류 해제 실패 | 없음 | 보류를 해제하지 못했습니다. 잠시 후 다시 시도해 주세요. | 대화상자 유지, 다시 확인 가능 |
| 공개 중단 사유 분류 없음 | 없음 | 없음 | 확인 버튼 비활성 |
| 공개 중단 409 | 없음 | 공개 중단할 수 없는 상태의 스토리입니다. 상세를 새로 불러왔습니다. | 상세 다시 요청 |
| 공개 중단 404 | 없음 | 스토리를 찾을 수 없습니다. 상세를 새로 불러왔습니다. | 상세 다시 요청 |
| 공개 중단 실패 | 없음 | 공개를 중단하지 못했습니다. 잠시 후 다시 시도해 주세요. | 대화상자 유지, 다시 확인 가능 |

- 실패, 사용 불가, 서버 미구현의 다시 시도는 같은 요청을 한 번 보낸다. 자동 재시도는 없다.
- 준비 중 상태는 실패로 보지 않는다. 받은 날짜의 값은 그대로 그린다.

### 4-1-3 값 없음과 0

| 값 | 화면 |
|---|---|
| 실제 0 | 0과 단위 |
| 준비 중 날짜 | 차트는 선을 끊고 표는 "준비 중" |
| 리텐션 비율 `null` | 관찰 전 |
| 광고 유입 비중 `null` | 신규 방문자 없음 |
| 스트림 오류율 `null` | 전송 없음 |
| 사용자당 채팅 메시지 전송 수의 전체와 플랫폼 없음 | 표시하지 않음 |
| 평균 세션 길이의 플랫폼 없음 | 표시하지 않음 |
| 도달률의 채팅 수 0 | 채팅 없음 |
| 게스트에서 회원으로의 5턴 이상 채팅 수 0 | 대상 채팅 없음 |
| 채팅 옵션 비중의 채팅 수 합 0 | 채팅 비중 자리에 채팅 없음 |
| 채팅 옵션 비중의 턴 수 합 0 | 턴 비중 자리에 턴 없음 |
| AI 비용 `null` | 그 날짜가 `pendingDates`에 있으면 준비 중, `expiredDates`에 있으면 보관 기간 지남, 둘 다 아니면 비용 기록 없음 |
| 턴당 원가, 스토리당 원가 `null` | 범위의 해당 기능 호출 수 합이 0이면 호출 없음, 0보다 크면 계산할 수 없음 |
| 유입 소스 `null` | 소스 정보 없음 |
| 게시글 `null` | 게시글 정보 없음 |
| 퍼널 기준 단계 0 | 계산할 수 없음 |
| 설치 지표의 일별 활성 기기 수 `null` | 차트는 선을 끊고 표는 "보고서 값 없음" |
| 인프라 지표의 묶음 `null` | 그 구역에 "이 환경에는 {묶음 이름} 지표 설정이 없습니다." |
| 인프라 지표의 빈 구간 | 차트 선을 끊음, 건수 지표는 서버가 0으로 채워 옴 |
| 인프라 요약 카드의 점 목록이 빈 배열 | 수집된 값 없음 |
