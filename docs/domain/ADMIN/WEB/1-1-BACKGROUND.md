# 1-1 배경

이 문서는 관리자 웹의 대시보드 그룹과 이프 내역, 검수 제출 화면, 스토리 공개 중단이 왜 필요한지와 대상 사용자, 이 세트에서 쓰는 용어를 정한다.

<br>

### 1-1-1 배경

마냑의 운영 지표는 Amplitude 대시보드 여러 개, Grafana 통계, 운영 DB에 흩어져 있었다. 팀원은 지표를 보려고 도구를 옮겨 다녔고 Amplitude의 저장 차트는 정의가 차트마다 조금씩 달랐다. 관리자 웹은 서버가 명세의 정의로 계산한 값을 한 곳에서 보여 주고 차트에서 관련 목록으로 바로 이어 준다. 운영자는 지표를 보려고 DB나 외부 도구에 접속하지 않는다. 검수를 통과한 뒤 문제가 드러난 회원 스토리도 DB를 고치지 않고 스토리 상세에서 사유와 함께 공개 중단한다.

<br>

### 1-1-2 대상 사용자

| 사용자 | 하는 일 |
|---|---|
| 관리자 | 관리자 역할을 받은 팀 구성원<br>매일 개요로 서비스 상태를 보고 광고 캠페인 기간에는 성장의 유입 탭으로 광고 성과를 봄<br>지표가 이상하면 같은 도메인의 지표 화면과 관리 목록으로 원인을 찾음 |

<br>

### 1-1-3 용어

| 용어 | 의미 |
|---|---|
| 대시보드 그룹 | 사이드바의 대시보드 구역<br>개요, 성장, 스토리, 채팅, 결제, 운영 화면 |
| 지표 화면 | 성장, 스토리, 채팅, 결제, 운영 다섯 화면<br>지표를 출처가 아니라 도메인으로 묶고 화면마다 탭으로 나눔<br>결제는 탭 없이 화면 본문이 탭 하나 |
| 탭 | 지표 화면 안의 지표 묶음 하나<br>영역 하나 이상으로 이루어짐 |
| 하위 구분 | 탭 안을 한 번 더 나눈 묶음<br>성장의 유입 탭과 운영의 서비스 탭에만 있고 탭처럼 기본 기간, 기간 상한, 조건, 요청을 따로 가짐 |
| 영역 | 탭 본문을 이루는 지표 묶음<br>영역 제목, 출처, 기간 상한, 요청, 상태를 따로 가짐 |
| 출처 | 값을 계산한 곳<br>Amplitude, 서버 DB, Google Play, CloudWatch, Langfuse 중 하나 |
| 사용자 | Amplitude 지표의 집계 대상<br>계정이 없는 게스트를 포함함 |
| 회원 | 가입한 계정<br>서버 DB 지표와 목록의 대상 |
| 검수 보류 | 검수가 일시 오류로 재시도 예산을 다 써 운영자 조치를 기다리는 제출본의 상태<br>관리자가 사유를 적어 해제하면 대기로 돌아가 새 회차로 다시 검수됨 |
| 제출본 | 검수를 위해 스토리의 등록이나 수정 입력을 저장한 행<br>상태는 대기, 보류, 승인, 반려, 실패 |
| 검수 제출 | 관리 구역에서 모든 상태의 제출본을 보는 화면<br>승인 전에 반려된 새 스토리도 여기서만 보임 |
| 공개 중단 | 관리자가 회원 스토리를 비공개로 바꾸고 소유자가 다시 검수를 통과할 때까지 공개하지 못하게 하는 조치<br>사유 분류는 선정성, 저작권 침해, 혐오 표현, 기타이고 기타는 소유자에게 보일 사유를 직접 입력<br>소유자 화면과 알림에서는 공개 제한으로 부름<br>관리자는 되돌리지 않음 |
| 누적 가입자 | 탈퇴한 회원을 포함해 지금까지 가입한 회원 수<br>팀 계정 제외 |
| 기간 | 화면에서 고른 KST 날짜 범위<br>시작 날짜와 끝 날짜를 포함 |
| 기간 상한 | 탭마다 고를 수 있는 가장 긴 기간 |
| 준비 중 날짜 | 서버가 Amplitude에서 아직 받지 못해 응답에서 빠진 날짜<br>잠시 뒤 다시 요청하면 채워짐 |
| 플랫폼 | 사용자 속성 `platform`의 Web과 Android<br>속성이 없는 사용자는 플랫폼 없음 |
| 대상 | 지표를 게스트와 회원으로 나누는 구분 |
| 시작 집단 | 리텐션에서 시작일의 행동으로 묶는 사용자<br>방문자, 가입자, 채팅 시작자 |
| 이벤트 수신 없음 | 선택한 기간과 조건에서 지표의 기준 이벤트가 한 건도 없는 상태<br>실제 0과 구분해 보임 |
| 광고 구분 | 광고 캠페인 지표의 전체, 광고 유입, 광고 외 유입 |
| 퍼널 | 정해진 단계를 순서대로 거친 사용자 수 |
| 전환율 | 퍼널의 한 단계 사용자 수를 기준 단계 사용자 수로 나눈 비율 |
| 팀 계정 제외 목록 | 서버 DB 지표에서 빼는 팀원 회원 목록 |
| 팀 계정 코호트 | 개요의 오늘 활성 사용자에서 빼는 팀원 사용자 묶음 |
| BFF | 관리자 웹 서버의 경로 처리기<br>브라우저 요청을 검증해 manyak-server로 전달 |
| 고정 데이터 모드 | 서버 대신 저장소의 가상 데이터로 응답하는 운영 외 모드 |
