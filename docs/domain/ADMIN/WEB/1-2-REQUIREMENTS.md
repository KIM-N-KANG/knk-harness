# 1-2 요구사항

이 문서는 관리자 웹의 지원 범위, 화면 크기 조건, 접근성과 성능 목표를 정한다.

서버가 보장하는 지표 정의와 기간 상한은 BACKEND 요구사항에, 화면별 정보는 정보 구조에 있다. ([BACKEND 2-4 제품 제약](../BACKEND/2-REQUIREMENTS.md#2-4-제품-제약), [2-1 정보 구조](2-1-INFORMATION-ARCHITECTURE.md))

<br>

### 1-2-1 지원 범위

| 항목 | 범위 |
|---|---|
| 색 모드 | 라이트 모드만 |
| 언어 | 한국어만 |
| 시간대 | 모든 날짜와 시각은 KST로 표시<br>설치 지표의 날짜만 Play 기준 날짜 |
| 접근 경로 | 관리자 페이지 주소 하나<br>브라우저는 manyak-server와 Amplitude를 직접 부르지 않음 |

<br>

### 1-2-2 화면 크기

| 너비 | 배치 |
|---|---|
| 1024px 이상 | 왼쪽 사이드바와 본문 |
| 1024px 미만 | 사이드바가 본문 위로 이동 |
| 640px 이하 | 카드와 차트가 한 열 |

- 모든 지표 화면은 너비 360px에서 가로 스크롤 없이 읽을 수 있어야 한다. 표와 장르 차트처럼 항목이 많은 영역만 그 영역 안에서 가로 스크롤한다.

<br>

### 1-2-3 접근성

| 항목 | 목표 |
|---|---|
| 대비 | 본문 글자와 배경 4.5:1 이상 |
| 색 의존 | 차트 계열은 색과 선 모양과 범례로 함께 구분 |
| 키보드 | 메뉴, 탭, 기간 선택기, 조건 선택, 수치 표의 링크를 키보드로만 조작 |
| 상태 알림 | 불러오는 중, 준비 중, 실패를 화면 낭독기가 읽음 |

<br>

### 1-2-4 성능

| 항목 | 목표 |
|---|---|
| 요청 범위 | 분석 화면은 선택한 탭의 요청만 보냄 |
| 준비 중 재요청 | 같은 탭에서 60초에 한 번 |
| 같은 조건 재방문 | 60초 안에 같은 조건을 다시 열면 요청하지 않고 앞의 응답을 씀 |
