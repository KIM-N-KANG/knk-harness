# 2-4 구성 요소 구조

이 문서는 관리자 웹 대시보드 그룹과 이프 내역, 검수 제출 화면, 스토리 공개 중단의 구성 요소 경계와 책임, 재사용 단위를 정한다.

URL과 서버 상태의 저장 위치는 상태 관리에, BFF 호출과 재요청은 데이터 연동에 있다. ([2-5 상태 관리](2-5-STATE-MANAGEMENT.md), [3-2 데이터 연동](3-2-DATA-INTEGRATION.md))

<br>

### 2-4-1 계층

| 계층 | 책임 | 하지 않는 것 |
|---|---|---|
| 경로 페이지 | 화면 구성 요소 하나를 그림<br>예전 지표 경로는 이동 표대로 URL을 교체 | 데이터 조회, 상태 판단 |
| 화면 | URL 상태를 읽어 탭, 하위 구분, 조건을 정하고 탭 구성 요소를 고름 | 차트 그리기 |
| 탭 | 영역 구성 요소를 정한 순서로 놓고 영역들의 준비 중 날짜를 모아 준비 중 알림 하나를 그림 | 다른 탭의 요청, 응답 해석 |
| 영역 | 그 영역의 BFF 요청을 보내고 응답에서 그 영역이 쓰는 값만 요약 카드와 차트 입력으로 바꿈 | 다른 영역의 응답 해석 |
| 공용 구성 요소 | 아래 표의 표시 책임 | 서버 응답 해석 |
| BFF | 요청 검증과 서버 전달 | 응답 변환 |

- 영역은 자기가 쓰는 응답 값만 해석한다. 한 영역의 실패가 다른 영역과 다른 탭을 가리지 않는다. 여러 영역이 같은 요청을 보내면 서버 상태 캐시를 함께 쓴다.

<br>

### 2-4-2 공용 구성 요소

| 구성 요소 | 입력 | 책임 |
|---|---|---|
| 사이드바 | 현재 경로 | 구역 펼침, 활성 메뉴, 외부 도구, 닉네임과 로그아웃 |
| 워드마크 | 없음 | 마냑 관리자 SVG |
| 페이지 머리 | 제목, 제목 옆 상호 링크, 오른쪽 요소 | 화면 제목 영역과 상호 링크 |
| 기간 선택기 | 현재 기간, 탭의 기간 상한(영역 상한 가운데 가장 큰 값)과 끝 날짜 제한 | 빠른 범위와 직접 선택<br>상한을 넘는 빠른 범위 비활성<br>잘못된 직접 선택의 오류 문구 |
| 탭 막대 | 탭이나 하위 구분 목록, 현재 값 | 탭과 하위 구분 전환<br>하위 구분 막대도 같은 구성 요소 |
| 영역 머리 | 영역 제목, 출처, 집계 기준 시각 | 영역 제목 줄 |
| 조건 선택 | 선택지와 현재 값 | 광고 캠페인, 광고 구분, 플랫폼, 대상, 시작 집단 선택과 대상 스토리 입력<br>플랫폼과 대상은 광고 구분과 같은 선택 상자 |
| 출처 표시 | 출처, 안내 문구 | 출처 이름과 툴팁 |
| 전체 기준 표시 | 적용하지 않은 구분 | 카드, 차트, 표 제목 옆 회색 글자 |
| 도움말 툴팁 | 대상 제목, 설명 문구 | 제목 옆 "?" 버튼과 툴팁<br>마우스를 올리거나 초점을 두면 열리고 Esc를 누르거나 초점이 떠나면 닫힘 |
| 요약 카드 | 이름, 값, 단위, 보조 값 | 숫자 하나와 보조 줄 |
| 계열 차트 | 일별 행, 계열 목록, 단위 | 선 차트, 범례, 끝점 라벨, 끊김 처리 |
| 퍼널 차트 | 단계 목록 | 가로 막대, 사용자 수, 앞 단계 대비 전환율<br>첫 단계는 사용자 수만 |
| 퍼널 카드 | 퍼널 키, 적용 플랫폼, 그 퍼널의 조회 상태 | 퍼널 이름과 플랫폼 배지, 퍼널 차트, 요약 수치, 카드 안 상태 상자와 다시 시도<br>상세 진입 채팅은 대상 스토리 입력 칸 |
| 순위 막대 | 항목과 값, 최대 개수, 정렬 | 가로 막대<br>순위는 내림차순, 세션 길이 분포는 구간 순서와 중앙값 구간 표시 |
| 기준 턴 선 차트 | 기준 턴마다 계열 값 | 가로 축이 날짜가 아닌 기준 턴인 선 차트<br>눈금은 같은 간격 |
| 코호트 표 | 코호트 행 | 비율 칸 색과 "관찰 전" 표시 |
| 수치 표 | 머리글, 행 | 접힘, 정렬, 빈 결과, 링크 |
| 분포 카드 | 분포 응답 하나 | 차트 식별자마다 정한 모양, 설명 툴팁, 수치 및 관련 목록 표, 목록 이동 |
| 준비 중 알림 | 탭 영역들의 준비 중 날짜를 합친 목록 | 개수, 재요청 안내, 날짜 펼침 |
| 기간 오류 상자 | 오류 종류, 기간 상한 | 오류 문구와 맞추기 버튼 |
| 상태 상자 | 상태 종류, 재시도 동작 | 실패, 사용 불가 |
| 스켈레톤 | 대신할 구성 요소의 종류와 개수 | 최종 배치와 같은 격자, 개수, 높이의 회색 자리<br>200ms 지연 뒤 표시, 표시하면 최소 300ms 유지<br>깜빡임 애니메이션은 움직임 줄이기 설정이면 멈춤<br>화면 낭독기용 숨김 문구와 `aria-busy` |
| 확인 대화상자 | 제목, 확인 문구, 처리 사유 입력 또는 사유 분류 선택과 분류별 필수 입력 사유와 선택 메모, 처리 중 여부, 오류 문구 | 모달, 사유 검증, 취소와 확인<br>사유 분류를 쓰면 고르기 전까지 확인 비활성<br>입력 사유가 필요한 분류에서만 입력 사유 칸을 보이고 다른 분류로 바꾸면 값을 버림<br>처리 중에는 닫히지 않음 |
| 성공 알림 | 문구 | 표 위 한 줄, 4초 뒤 사라짐, 상태 알림으로 읽힘 |

| 스켈레톤 대상 | 모양 |
|---|---|
| 요약 카드 | 카드 이름 줄, 큰 숫자 블록, 작은 줄 한두 개<br>카드 크기와 격자는 실제 카드와 같음 |
| 요약 카드 안 인라인 | 기다리는 줄(기간 합계 줄 등)만 그 줄 높이의 블록 |
| 차트 카드 | 카드 제목 줄과 차트 영역 높이의 블록, 범례 자리 줄 |
| 퍼널과 순위 막대 | 막대 높이와 간격의 블록 5개 |
| 표와 목록 | 머리 행과 본문 행 10개<br>행 높이와 열 너비는 실제 표와 같음 |
| 상세 | 머리 줄과 영역마다 카드 블록<br>영역 순서와 격자는 실제 상세와 같음 |

- 스켈레톤 색은 `--muted`이고 깜빡임은 1.5초 주기의 불투명도 변화다. 스켈레톤에서 값으로 바뀔 때 배치가 밀리지 않아야 한다.
- 계열 차트는 계열 묶음 이름을 받아 순서와 색과 선 모양을 정한다. 화면이 색을 직접 고르지 않는다.
