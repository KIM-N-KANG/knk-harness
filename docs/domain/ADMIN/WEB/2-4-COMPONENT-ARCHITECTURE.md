# 2-4 구성 요소 구조

이 문서는 관리자 웹 대시보드 그룹과 이프 내역 화면의 구성 요소 경계와 책임, 재사용 단위를 정한다.

URL과 서버 상태의 저장 위치는 상태 관리에, BFF 호출과 재요청은 데이터 연동에 있다. ([2-5 상태 관리](2-5-STATE-MANAGEMENT.md), [3-2 데이터 연동](3-2-DATA-INTEGRATION.md))

<br>

### 2-4-1 계층

| 계층 | 책임 | 하지 않는 것 |
|---|---|---|
| 경로 페이지 | 화면 구성 요소 하나를 그림 | 데이터 조회, 상태 판단 |
| 화면 | URL 상태를 읽어 탭과 조건을 정하고 탭 구성 요소를 고름 | 차트 그리기 |
| 탭 | 그 탭의 BFF 요청 하나 또는 둘을 보내고 응답을 요약 카드와 차트 입력으로 바꿈 | 다른 탭의 요청 |
| 공용 구성 요소 | 아래 표의 표시 책임 | 서버 응답 해석 |
| BFF | 요청 검증과 서버 전달 | 응답 변환 |

- 탭은 자기 응답만 해석한다. 한 탭의 실패가 다른 탭과 다른 화면 영역을 가리지 않는다.

<br>

### 2-4-2 공용 구성 요소

| 구성 요소 | 입력 | 책임 |
|---|---|---|
| 사이드바 | 현재 경로 | 구역 펼침, 활성 메뉴, 외부 도구, 닉네임과 로그아웃 |
| 워드마크 | 없음 | 마냑 관리자 SVG |
| 페이지 머리 | 제목, 설명, 오른쪽 요소 | 화면 제목 영역 |
| 기간 선택기 | 현재 기간, 탭의 기간 상한과 끝 날짜 제한 | 빠른 범위와 직접 선택<br>상한을 넘는 빠른 범위 비활성<br>잘못된 직접 선택의 오류 문구 |
| 탭 막대 | 탭 목록, 현재 탭 | 탭 전환 |
| 조건 선택 | 선택지와 현재 값 | 캠페인, 광고 구분, 플랫폼, 퍼널 선택과 대상 스토리 입력 |
| 출처 표시 | 출처, 안내 문구 | 출처 이름과 툴팁 |
| 요약 카드 | 이름, 값, 단위, 보조 값 | 숫자 하나와 보조 줄 |
| 계열 차트 | 일별 행, 계열 목록, 단위 | 선 차트, 범례, 끝점 라벨, 끊김 처리 |
| 퍼널 차트 | 단계 목록 | 가로 막대, 사용자 수, 전환율 |
| 순위 막대 | 항목과 값, 최대 개수 | 내림차순 가로 막대 |
| 묶음 막대 | 기준마다 계열 값 | 도달률 묶음 막대 |
| 코호트 표 | 코호트 행 | 비율 칸 색과 "관찰 전" 표시 |
| 수치 표 | 머리글, 행 | 접힘, 정렬, 빈 결과, 링크 |
| 준비 중 알림 | 준비 중 날짜 목록 | 개수, 재요청 안내, 날짜 펼침 |
| 기간 오류 상자 | 오류 종류, 기간 상한 | 오류 문구와 맞추기 버튼 |
| 상태 상자 | 상태 종류, 재시도 동작 | 불러오는 중, 실패, 사용 불가 |

- 계열 차트는 계열 묶음 이름을 받아 순서와 색과 선 모양을 정한다. 화면이 색을 직접 고르지 않는다.

<br>

| 분석 | 구역별 분포 카드 | 페이지 머리, 기간 선택기, 수치 표, 상태 상자 |
| 캠페인 분석 | 추이, 간편 제작 퍼널, 상세 진입 퍼널, 유입 소스 | 탭 막대, 조건 선택, 요약 카드, 계열 차트, 퍼널 차트, 순위 막대, 수치 표, 준비 중 알림, 기간 오류 상자, 상태 상자 |

| 전환 | 전환 퍼널, 채팅 턴 도달률 | 탭 막대, 조건 선택, 요약 카드, 퍼널 차트, 묶음 막대, 수치 표, 기간 오류 상자, 상태 상자 |
| 기능과 품질 | 기능 사용과 안정성, 채팅 옵션 비중, AI 비용 | 탭 막대, 조건 선택, 요약 카드, 계열 차트, 수치 표, 준비 중 알림, 기간 오류 상자, 상태 상자 |
| 이프 내역 | 필터, 원장 표 | 페이지 머리, 수치 표, 상태 상자 |
