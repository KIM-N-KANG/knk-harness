# 2-1 정보 구조

이 문서는 관리자 웹의 메뉴와 경로, 화면별 탭과 요약 수치와 차트, 기본 선택, 화면 문구를 정한다.

차트 모양과 계열 순서는 디자인 시스템에, 불러오는 중과 실패와 준비 중의 표시는 오류 처리에, 서버 응답 필드는 계약에 있다. ([2-3 UI 디자인 시스템](2-3-UI-DESIGN-SYSTEM.md), [4-1 오류 처리](4-1-ERROR-HANDLING.md), [3-1 계약](3-1-CONTRACT.md))

<br>

### 2-1-1 메뉴와 경로

사이드바는 대시보드, 관리, 알림 세 구역이다. 메뉴는 번호 없이 이름만 표시한다.

|---|---|---|---|

| 대시보드 | 전환 | `/analytics/conversion` | 전환 |

| 항목 | 규칙 |
|---|---|
| 구역 펼침 | 현재 경로가 속한 구역은 항상 펼침<br>나머지 구역의 펼침 상태는 브라우저에 기억 |

### 2-1-2 분석 화면 공통 요소

개요, 분석, 지표 화면 다섯 개에 함께 적용한다.

**1. 화면 구성 요소**

| 요소 | 내용 |
|---|---|
| 페이지 머리 | 화면 제목, 오른쪽에 기간 선택기 |
| 탭 막대 | 지표 화면에만 있음<br>페이지 머리 아래에 탭 이름을 나란히 표시 |
| 조건 선택 | 탭이 받는 조건(캠페인, 광고 구분, 플랫폼, 퍼널, 대상 스토리)<br>탭 막대 아래 한 줄 |
| 출처 표시 | 탭 제목 옆에 "Amplitude", "서버 DB", "Google Play", "CloudWatch" 중 하나<br>마우스를 올리거나 초점을 두면 집계 기준 안내를 툴팁으로 표시 |
| 도움말 | 꼭 필요한 설명은 그 대상의 제목 옆 "?" 버튼에 둠<br>마우스를 올리거나 초점을 두면 툴팁으로 표시하고 본문에는 표시하지 않음 |
| 준비 중 알림 | 응답에 준비 중 날짜가 있을 때 요약 카드 위 |
| 요약 카드 | 기간 전체를 한 숫자로 보여 주는 카드 |
| 차트 카드 | 차트 하나와 제목, 단위 |
| 전체 수치 표 | 탭 맨 아래 접힌 표<br>차트에 그린 모든 값과 날짜 |

- 화면 문구 표에서 위치 이름이 "도움말"로 끝나는 문구는 그 대상의 제목 옆 "?" 툴팁에만 보인다. 이프 내역도 같은 방식을 쓴다.

**2. 기간**

| 항목 | 규칙 |
|---|---|
| 빠른 범위 | 오늘, 어제, 최근 7일, 최근 14일, 최근 30일, 최근 90일, 이번 주, 지난주, 이번 달, 지난달, 최근 6개월, 최근 1년 |
| 직접 선택 | 시작 날짜와 끝 날짜<br>끝 날짜는 오늘 이하이고 시작 날짜는 끝 날짜 이하 |
| 기본 기간 | URL에 기간이 없으면 화면이나 탭마다 정한 기본 기간 |
| 공유 | 기간을 고르면 그 화면의 모든 탭에 같은 기간을 적용 |
| 탭 상한 | 선택기는 현재 탭의 기간 상한을 넘는 빠른 범위를 비활성으로 표시하고 상한을 안내 |
| 상한 초과 | 다른 탭에서 고른 기간이 현재 탭의 상한을 넘으면 기간을 바꾸지 않고 탭 본문에 기간 오류를 표시<br>그 탭의 요청은 보내지 않음 |
| 끝 날짜 제한 | 리텐션 탭은 끝 날짜가 어제 이하<br>오늘이 포함된 기간이면 같은 방식으로 기간 오류 표시 |
| 서버로 보내는 값 | 화면이 정한 시작 날짜와 끝 날짜 |
| 기간 없는 탭 | 유입 분석의 앱 설치 탭과 인프라의 DB 테이블 탭은 기간을 받지 않음<br>기간 선택기를 비활성으로 두고 앱 설치는 "전체 기간", DB 테이블은 "현재"로 표시<br>URL의 기간은 지우지 않고 다른 탭에서 그대로 씀 |

**3. 값의 해석**

| 항목 | 규칙 |
|---|---|
| 재계산 금지 | 서버가 준 합계, 평균, 가중 평균, MAU, 전체 값을 쓰고 일별 값이나 플랫폼별 값으로 다시 계산하지 않음<br>일별 고유 사용자 수는 여러 날을 더하지 않음 |
| 기간 합 | 서버가 기간 값을 주지 않는 가산 지표만 일별 값을 더해 기간 합을 만듦<br>가산 지표는 이벤트 횟수, 채팅 수, 턴 수, 스토리 수, 가입 수, 이프 수량, 결제 건수, 결제 금액, 인프라의 요청 수와 5xx 응답 수<br>고유 사용자 수는 가산 지표가 아님 |
| 플랫폼 합 | 전체와 Web, Android, 플랫폼 없음은 따로 센 값이라 플랫폼별 합이 전체와 다를 수 있음 |
| 준비 중 날짜 | 0으로 채우지 않음<br>차트 선을 끊고 표에 "준비 중" 표시 |
| 0과 값 없음 | 실제 0은 0으로 표시<br>서버가 `null`을 준 값과 분모가 0인 비율은 오류 처리에 정한 문구로 표시 |
| 전환율 | 단계 사용자 수를 기준 단계 사용자 수로 나눔<br>100%를 넘어도 그대로 표시 |

### 2-1-3 개요

서비스의 오늘과 누적 현황, 선택 기간의 추이를 한 화면에서 본다. 기본 기간은 최근 30일이다.

**1. 요약 카드**

카드는 10개다. 서버 DB 카드 8개는 누적을 큰 숫자로, 오늘을 작은 줄로, 선택 기간 합계를 맨 아래 줄로 표시하며 카드를 누르면 관련 목록으로 이동한다.

| 카드 | 누적 | 오늘 | 기간 합계 | 단위 | 이동 |
|---|---|---|---|---|---|
| 가입자 | 누적 가입자 수(탈퇴 포함) | 오늘 가입 | 일별 가입 합 | 명 | 탈퇴 회원을 포함한 회원 목록 |
| 채팅 시작 | 채팅 시작 수 | 오늘 채팅 시작 | 일별 채팅 시작 합 | 개 | 채팅 목록 |
| 턴 | 턴 수 | 오늘 턴 | 일별 턴 합 | 턴 | 턴 수 순 채팅 목록 |
| 스토리 | 스토리 수 | 오늘 생성 | 일별 스토리 생성 합 | 개 | 스토리 목록 |
| 이프 적립 | 누적 적립 | 오늘 적립 | 일별 적립 합 | 이프 | 적립 이프 내역 |
| 이프 소모 | 누적 소모 | 오늘 소모 | 일별 소모 합 | 이프 | 소모 이프 내역 |
| 결제 건수 | 완료 주문 수 | 오늘 완료 | 일별 결제 건수 합 | 건 | 결제 목록 |
| 결제 금액 (환불 포함) | 완료 주문 금액 | 오늘 완료 금액 | 일별 결제 금액 합 | 원 | 결제 목록 |

- 가입자 카드 제목 옆 "?" 툴팁에 현재 회원 수(`members.active`)와 누적 탈퇴 수(`members.withdrawn`)를 둔다.

나머지 두 카드는 서버 DB 카드 뒤에 둔다.

| 카드 | 큰 숫자 | 작은 줄 | 단위 | 이동 |
|---|---|---|---|---|
| 오늘 활성 사용자 | 분석 지표의 `todayActiveUsers.total` | Web과 Android의 오늘 값 | 명 | 사용자 화면의 사용자 활동 탭 |
| 앱 설치(Android) | 설치 지표의 `totalInstalls` | `daily`의 마지막 항목의 날짜와 그날 기기 설치 수 | 대 | 유입 분석의 앱 설치 탭 |

- 두 카드는 페이지의 기간을 적용하지 않아 기간 합계 줄이 없다.
- 오늘 활성 사용자 카드는 분석 지표를 `from`과 `to` 모두 KST 오늘로 요청한다. 페이지의 기간을 보내지 않는다.
- 앱 설치 카드의 작은 줄은 Play 보고서가 며칠 늦게 반영되어 오늘이 아니라 가장 최근 보고일의 값이다.
- 두 카드의 출처와 지연 안내는 카드 제목 옆 "?" 툴팁에 둔다.

**2. 일별 추이**

카드 아래의 일별 추이 카드 안에 서버 DB 지표 8개의 작은 선 그래프를 둔다.

| 항목 | 내용 |
|---|---|
| 그래프 | 가입, 채팅 시작, 턴, 스토리 생성, 이프 적립, 이프 소모, 결제 건수, 결제 금액 (환불 포함)<br>서버 DB 카드와 같은 순서이고 그래프 제목은 지표 이름 |
| 가로 축 | 모든 그래프가 기간 선택기의 범위를 같은 날짜 축으로 씀 |
| 세로 축 | 그래프마다 세로 축 하나와 그 지표의 단위 |
| 선 | 그래프마다 일별 선 하나와 기간 평균 점선 |
| 툴팁 | 마우스를 올리면 날짜와 값 |
| 이동 | 점을 누르면 그 지표와 그날 조건의 목록 |
| 수치 표 | 그래프 아래 접힌 표 하나<br>날짜마다 8개 지표의 값과 목록 링크 |

- 오늘 활성 사용자와 앱 설치는 그래프 없이 카드만 둔다. 출석 회원 수는 개요에 표시하지 않는다.
- 분석 도구의 일별 활성과 신규 사용자는 사용자 화면의 사용자 활동 탭에서 본다. Play 설치 추이는 유입 분석의 앱 설치 탭에서 본다.

**3. 화면 문구**

| 위치 | 문구 |
|---|---|
| 기간 합계 줄 | {기간 이름} 합계 {값}{단위} |
| 가입자 카드 도움말 | 탈퇴한 회원을 포함한 누적 가입자 수입니다. 현재 회원 {현재 회원 수}명, 누적 탈퇴 {누적 탈퇴 수}명이며 팀 계정은 제외합니다. |
| 오늘 활성 사용자 작은 줄 | Web {값}명, Android {값}명 |
| 오늘 활성 사용자 카드 도움말 | Amplitude 출처 지표이며 {받은 시각} KST에 받은 값입니다. 집계가 몇 분 늦게 반영될 수 있습니다. 팀 계정 코호트가 설정된 경우 해당 사용자는 제외합니다. 국가가 한국이거나 국가 정보가 없는 사용자 중 플랫폼이 Web 또는 Android인 고유 사용자만 집계합니다. 같은 사람이 두 플랫폼에서 활동하면 합계에는 한 번만 들어가므로 Web과 Android를 더한 값과 합계는 다를 수 있습니다. Amplitude 사용자 수는 DB 회원 수와 다를 수 있습니다. |
| 앱 설치 작은 줄 | {보고일} 설치 {값}대 |
| 앱 설치 카드 도움말 | Google Play 설치 보고서 출처 지표입니다. 보고서는 며칠 늦게 반영되고 날짜는 Play 기준 태평양 시간입니다. 누적 기기 설치 수는 보고서 전체 기간의 일별 기기 설치 수를 합산한 값입니다. 페이지에서 선택한 기간은 이 카드에 적용되지 않습니다. |
| 일별 추이 제목과 범위 | 일별 추이<br>{시작 날짜} ~ {끝 날짜} (KST) |
| 수치 표 열기 | 일별 수치와 목록 이동 |

### 2-1-4 분석

선택 기간의 이용 분포 차트 8개를 보고 막대에서 관련 목록으로 이동한다. 기본 기간은 최근 30일이다.

| 항목 | 내용 |
|---|---|
| 구역 | 응답의 `category`로 나눔<br>사용자, 채팅 참여, 콘텐츠, AI 품질 순서 |
| 카드 | 응답의 제목, 차트, 접힌 "수치 및 관련 목록" 표<br>응답의 설명은 카드 제목 옆 "?" 툴팁에만 표시 |
| 차트 모양 | 차트 식별자마다 정한 모양 |
| 이동 | 막대, 점, 조각, 수치 표의 링크를 누르면 응답의 목록 조건으로 목록을 엶 |

| 위치 | 문구 |
|---|---|
| 범위 | {시작 날짜} ~ {끝 날짜} (KST) |
| 구역 제목 | 사용자, 채팅 참여, 콘텐츠, AI 품질 |

### 2-1-5 유입 분석
