# 5-2 동시성

이 문서는 ADMIN 도메인의 동시 요청 처리 규칙을 정한다. 감사 기록의 트랜잭션 참여, 멱등과 1회 처리, 역할 변경과의 경쟁, 수용한 경쟁 조건을 다룬다.

흐름별 단계는 처리 흐름에 있으며 토큰 수명은 오류 처리에 있다. ([4-1-4 감사 기록](4-1-PIPELINES.md#4-1-4-감사-기록)과 [5-3-5 재시도와 시간 한도](5-3-ERROR-HANDLING.md#5-3-5-재시도와-시간-한도))

<br>

### 5-2-1 감사 기록의 트랜잭션

ADMIN은 자체 행 잠금을 두지 않는다. 변경 작업의 잠금은 그 변경을 적용하는 도메인이 건다.

| 기록 | 트랜잭션 |
|---|---|
| 변경 감사 기록 | 호출 도메인의 트랜잭션에 참여<br>트랜잭션이 없으면 거부해 변경 없는 로그나 로그 없는 변경이 생기지 않게 함 |
| 접속 기록 | 조회 뒤 독립 트랜잭션<br>조회 자체는 트랜잭션이 없음 |

<br>

### 5-2-2 멱등과 1회 처리

| 대상 | 처리 |
|---|---|
| 관리자 로그인 | 요청마다 새 토큰<br>서버 상태가 없어 반복해도 부작용 없음 |
| 변경 감사 기록 | 변경 1건에 로그 1행<br>변경의 멱등은 그 도메인이 정하고 멱등으로 건너뛴 재시도는 로그를 남기지 않음 |
| 접속 기록 | 조회마다 1행<br>같은 회원을 반복 조회하면 행이 늘어남 |
| 대시보드, 목록, 상세 | 읽기 전용 |
| 분석 지표 캐시<br>캠페인 분석 캐시<br>설치 지표 캐시 | 분석 지표와 캠페인 분석은 캐시 키마다 캐시와 갱신 표식이 따로<br>만료 뒤 첫 요청 하나만 갱신 표식을 잡고 호출<br>그 사이 요청은 기다리지 않고 만료된 캐시 또는 사용 불가로 응답<br>실패 뒤 60초 쿨다운 동안은 아무 요청도 호출하지 않음 |

<br>

### 5-2-3 유니크 위반 처리

| 대상 | 처리 |
|---|---|
| 감사 로그 `public_id` | 서버가 생성하는 UUID라 충돌이 드러나지 않음 |
| 관리자 역할 `user_id` | 역할 관리 운영자가 직접 기록하므로 위반은 저장소가 거절 |

<br>

### 5-2-4 역할 변경과의 경쟁

| 상황 | 처리 |
|---|---|
| 판정 통과 뒤 역할 회수 커밋 | 그 요청은 끝까지 처리됨<br>다음 요청부터 거절 |
| 판정 통과 뒤 계정 정지 커밋 | 같음<br>변경 도메인이 사용자 행을 잠그는 경로는 그 도메인의 재검사를 따름 |

<br>

### 5-2-5 수용한 경쟁 조건

| 상황 | 수용 이유 |
|---|---|
| 역할 회수와 진행 중 요청이 겹쳐 회수 뒤 변경이 1건 커밋됨 | 요청마다 재확인하므로 영향이 요청 처리 시간으로 제한됨<br>감사 로그에 처리자가 남아 추적 가능 |
| 대시보드 집계가 도메인별로 다른 스냅샷을 읽음 | 읽기 트랜잭션을 하나로 묶지 않음<br>운영 현황 수치라 집계 사이의 수 건 차이를 수용 |
| 목록의 전체 건수와 현재 페이지가 다른 시점을 읽음 | 두 쿼리 사이에 행이 추가되면 `totalElements`와 마지막 페이지 건수가 어긋남<br>다음 요청에서 맞음 |
| 차트 막대 값과 그 막대가 연 목록의 건수가 다름 | 두 요청 사이의 새 행과 팀 계정 제외 차이<br>목록은 전체를 보여 주는 것이 목적 |
| 태스크마다 분석 지표 캐시 시각이 다름 | 같은 10분 안에 두 태스크가 다른 값을 줄 수 있음<br>분석 도구 자체가 몇 분 지연되는 수치라 수용 |
| 갱신 중인 요청이 끝나기 전의 요청이 10분 넘은 캐시를 받음 | 몇 초 차이이고 분석 도구 자체가 몇 분 지연되는 수치라 수용 |
| 쿨다운 60초 동안 분석 도구가 복구돼도 호출하지 않음 | 연속 실패로 한도를 소모하는 것을 막는 쪽을 택함 |
| 비용 예산 계수기가 태스크마다 따로라 두 태스크의 합이 5분 1,000을 넘을 수 있음 | 관리자 수가 적고 넘으면 분석 도구가 한도 초과로 응답해 쿨다운으로 흡수됨 |
| 캠페인 분석 엔드포인트 여럿을 같은 5분에 갱신하면 뒤의 요청이 예산 부족으로 사용 불가 | 엔드포인트 하나는 상한에서도 예산 안이고 관리자 페이지가 그 카드만 다시 시도함 |
| 오늘을 포함하지 않는 범위의 24시간 캐시 동안 분석 도구가 값을 소급 보정해도 반영되지 않음 | 지난 날짜의 보정은 드물고 다음 날 갱신으로 따라감 |
| 접속 기록 전에 조회 응답이 만들어짐 | 기록 실패 시 응답을 실패로 바꾸므로 기록 없는 조회 응답은 나가지 않음 |
