# 1. 배경

이 문서는 마냑의 관리자 페이지, ADMIN 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 정한다.

<br>

### 1-1 도메인

ADMIN 도메인은 팀 구성원이 서비스를 운영하는 데 필요한 관리자 기능 가운데 관리자 자체의 것을 다룬다. 누가 관리자인지 확인하고 관리자의 모든 변경 작업과 개인정보 조회를 감사 로그로 남기며 운영 현황 수치를 한 화면에 모은다. 회원의 이프를 바꾸거나 알림을 보내거나 계정을 정지하는 일은 그 데이터를 관리하는 도메인이 정하고 ADMIN은 요청자가 관리자인지만 판정한다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 운영 지표와 작업은 분석 도구, 오류 추적 도구, AI 관측 도구, 운영 DB에 흩어져 있다. 여러 운영 작업이 운영 DB를 직접 고치는 방식이라 DB에 접근할 수 있는 한 사람만 할 수 있고 원장과 아웃박스 같은 도메인 불변식을 우회할 위험이 있다. 관리자 페이지는 팀 구성원 누구나 같은 화면에서 현황을 보고 운영 작업을 안전하게 처리하게 한다.

| 흐름 | 관리자가 하는 일 |
|---|---|
| 로그인 | 관리자 페이지에서 Google 계정으로 로그인<br>관리자 역할이 없는 계정은 들어갈 수 없음 |
| 대시보드 | 개요에서 가입자, 채팅, 제작, 이프, 결제의 오늘과 누적 수치와 일별 추이를, 분석에서 사용자, 채팅 참여, 콘텐츠, AI 품질 구역의 분포 차트를 확인<br>사용자, 전환, 유입, 기능과 품질 메뉴에서 분석 도구와 DB 지표를 확인<br>분석 도구의 오늘 활성 사용자, 일별 활성과 신규 사용자, Play Console의 Android 누적 기기 설치 수를 함께 확인<br>인프라 메뉴에서 운영 AWS 리소스 지표와 DB 테이블 크기를 확인<br>차트를 눌러 조건이 걸린 목록으로 이동 |
| 콘텐츠 조회 | 스토리, 채팅, 결제, 이프 내역을 검색하고 정렬해 상세를 확인<br>채팅 대화 원문은 보지 않음 |
| 회원 조회 | 닉네임, 식별자, 이메일로 회원을 찾아 상태, 잔액, 회원 이프 내역, 출석을 확인 |
| 알림 통계 | 캠페인별 도달 수와 알림 종류별 날짜별 도달 통계 확인 ([NOTIFICATION 4-2-21 알림 통계](../../NOTIFICATION/BACKEND/4-2-CONTRACT.md#4-2-21-알림-통계)) |
| 운영 작업 | 이프 지급과 회수, 정책값 변경, 캠페인 예약, 공지 게시, 계정 정지, 검수 보류 해제, 오리지널 등록과 수정을 사유와 함께 처리 |
| 감사 | 누가 언제 무엇을 바꿨는지 감사 로그에서 확인 |

<br>

### 1-3 백엔드의 역할

관리자 페이지는 화면과 쿠키 보관을 맡는다. 관리자 판정, 토큰 발급, 감사 기록, 지표 계산은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 관리자 판정 | 관리자 역할을 받은 회원만 관리자 토큰을 발급<br>관리자 요청마다 역할을 저장소에서 다시 확인 |
| 토큰 구분 | 관리자 토큰과 앱 접근 토큰을 서로의 경로에서 거절 |
| 감사 로그 | 관리자의 모든 변경 작업과 회원 개인정보 조회를 처리자, 대상, 사유, 변경 전후 값과 함께 기록<br>삭제 경로 없음 |
| 대시보드 | 서버 DB에 있는 수치를 집계해 제공<br>요약, 일별 추이, 분포 차트 |
| 분석 지표 | 분석 도구가 집계한 활성과 신규 사용자 수를 서버가 받아 지난 날짜 값을 DB에 저장하고 제공 |
| 설치 지표 | Play Console 일괄 보고서의 Android 기기 설치 수를 서버가 읽어 집계하고 캐시해 제공 |
| 인프라 지표 | CloudWatch가 집계한 운영 AWS 리소스 지표와 DB 테이블 크기를 서버가 읽어 제공<br>앱 지표, 로그, 트레이스는 OpenSearch UI가 맡음 |
| 캠페인 분석 | 분석 도구의 이벤트로 광고 캠페인의 유입, 가입, 퍼널을 계산하고 지난 날짜 값을 DB에 저장해 제공 |
| 푸시 열람 | 서버 발송 결과의 도달 회원 수와 분석 도구의 페이지 조회로 관리자 캠페인과 활동 알림의 웹 푸시 열람 수와 열람률을 계산해 제공 |
| 사용자, 전환, 기능과 품질 지표 | 분석 도구와 서버 DB에서 플랫폼별 활동, 리텐션, 퍼널, 턴 도달률, 기능 사용, AI 비용을 계산해 제공 |
| 목록과 상세 | 스토리, 채팅, 회원, 결제를 다른 도메인 테이블에서 읽기만 해 조회<br>채팅 대화 원문은 제공하지 않음 |
| 회원 조회 | 운영 작업의 대상이 되는 회원을 찾고 상태와 잔액을 보여 줌 |
| 다른 도메인에 전달 | 이프, 알림, 공지, 계정, 검수 도메인에 관리자 요청자 식별과 감사 기록 연산 제공 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 관리자 | 관리자 역할을 받은 팀 구성원의 회원 계정 | 로그인, 대시보드 확인, 회원 조회, 운영 작업 |
| 관리자 페이지 | 팀 구성원이 쓰는 별도 웹 | 서버 측 처리기가 백엔드를 호출하고 관리자 토큰을 쿠키에 보관 |
| 회원 | 소셜 로그인으로 가입한 계정<br>용어집의 사용자(user) 중 계정이 있는 사람 | 조회와 운영 작업의 대상 |
| 역할 관리 운영자 | DB에서 관리자 역할을 부여하고 회수하는 팀 구성원 | 저장소에서 직접 역할을 부여하고 회수 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 관리자 역할 | 회원 계정에 부여하는 관리자 자격<br>부여와 회수는 저장소에서 직접 함 |
| 관리자 토큰 | 관리자 페이지가 백엔드를 호출할 때 쓰는 짧은 수명의 토큰<br>앱 접근 토큰과 구분됨 |
| 관리자 API | 관리자 토큰으로만 호출할 수 있는 경로의 묶음 |
| 감사 로그 | 관리자의 변경 작업과 개인정보 조회를 남긴 기록<br>처리자, 작업 분류, 작업 이름, 대상 종류와 식별자, 사유, 변경 전후 값, 시각 |
| 작업 분류 | 감사 로그의 `category`<br>변경 작업 `CHANGE`와 개인정보 조회 `ACCESS` |
| 작업 이름 | 감사 로그의 `action`<br>이프 지급처럼 세부 작업을 가리키는 이름 |
| 접속 기록 | 감사 로그 가운데 개인정보 조회를 남긴 기록 |
| 사유 | 관리자가 변경 작업마다 적는 이유<br>필수 |
| 대시보드 지표 | 서버 DB에서 집계한 운영 현황 수치<br>오늘과 누적, 일별 추이, 분포 |
| 누적 가입자 | 탈퇴 회원을 포함해 지금까지 생성된 회원 수<br>대시보드와 DB 분석 지표에서는 팀 계정 제외 목록을 뺌 |
| 분포 차트 | 기간 안의 데이터를 구간이나 범주별 건수, 평균, 백분율, 시간 통계로 보여 주는 차트<br>막대마다 같은 조건의 목록으로 이어짐 |
| 분석 지표 | 분석 도구 Amplitude가 집계한 활성 사용자와 신규 사용자 수<br>서버 DB에 없는 방문 기준 수치 |
| 팀 계정 코호트 | 분석 도구에 저장한 팀 계정 사용자 묶음<br>분석 지표에서 제외하는 기준이며 팀 계정 제외 목록과 따로 관리 |
| 설치 지표 | Play Console 일괄 보고서로 집계한 Android 누적 기기 설치 수, 활성 기기 수, 일별 기기 설치 수와 앱 삭제 수와 누계<br>Play 기준 날짜 |
| 인프라 지표 | ECS 서비스, ALB, RDS, ElastiCache Redis, OpenSearch 도메인의 CloudWatch 지표와 ECS 서비스의 태스크 수<br>집계 간격은 5분, 15분, 1시간 |
| DB 테이블 크기 | PostgreSQL 카탈로그가 알려 주는 데이터베이스와 테이블별 디스크 크기, 통계가 추정한 행 수 |
| 캠페인 분석 | UTM 캠페인 값 하나를 기준으로 분석 도구에서 계산한 웹 유입, 가입, 이용 횟수, 퍼널<br>전체, 광고 유입, 광고 외 유입 세그먼트 |
| 푸시 열람 | 푸시를 눌러 웹 페이지를 연 것<br>링크의 UTM `utm_source`가 `push`인 페이지 조회<br>도달 회원 수 대비 비율이 열람률 |
| 활동 알림 | 스토리 완성, 검수 완료, 출석 리마인드 알림<br>알림 내역의 `ACTIVITY` 분류와 같은 세 종류이며 푸시 열람에서 캠페인 대신 종류로 묶음 |
| 비용 예산 | 분석 도구가 프로젝트 전체에 5분마다 허용하는 조회 비용 1,000 가운데 서버 태스크 하나가 쓰는 몫<br>태스크마다 최근 5분 500이며 그 태스크의 모든 분석 도구 호출이 함께 소비 |
| 팀 계정 제외 목록 | 설정값의 회원 내부 ID 목록<br>DB 대시보드 요약과 차트, AI 비용을 뺀 DB 분석 지표의 집계에서 제외 |
| 오늘 | KST 자정부터 현재까지 |
| 확정일 | KST 오늘에서 2일 이전까지의 날짜<br>Amplitude 값을 그날이 끝난 뒤 한 번 받으면 다시 받지 않음 |
| 준비 중 날짜 | Amplitude 비용 예산이나 실패로 아직 값을 받지 못해 응답에서 빠진 날짜<br>다음 요청에서 이어 받음 |
| 운영 작업 | 다른 도메인의 데이터를 바꾸는 관리자 기능<br>그 도메인의 계약이 정함 |
