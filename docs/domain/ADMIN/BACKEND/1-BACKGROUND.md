# 1. 배경

이 문서는 마냑의 관리자 페이지, ADMIN 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 정한다.

<br>

### 1-1 도메인

ADMIN 도메인은 팀 구성원이 서비스를 운영하는 데 필요한 관리자 기능 가운데 관리자 자체의 것을 다룬다. 누가 관리자인지 확인하고, 관리자의 모든 변경 작업과 개인정보 조회를 감사 로그로 남기고, 운영 현황 수치를 한 화면에 모은다. 회원의 이프를 바꾸거나 알림을 보내거나 계정을 정지하는 일은 그 데이터를 관리하는 도메인이 정하고 ADMIN은 요청자가 관리자인지만 판정한다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 운영 지표와 작업은 분석 도구, 오류 추적 도구, AI 관측 도구, 운영 DB에 흩어져 있다. 여러 운영 작업이 운영 DB를 직접 고치는 방식이라 DB에 접근할 수 있는 한 사람만 할 수 있고, 원장과 아웃박스 같은 도메인 불변식을 우회할 위험이 있다. 관리자 페이지는 팀 구성원 누구나 같은 화면에서 현황을 보고 운영 작업을 안전하게 처리하게 한다.

| 흐름 | 관리자가 하는 일 |
|---|---|
| 로그인 | 관리자 페이지에서 Google 계정으로 로그인<br>관리자 역할이 없는 계정은 들어갈 수 없음 |
| 대시보드 | 가입자, 채팅, 제작, 이프, 결제의 오늘과 누적 수치, 일별 추이, 이용 분포 차트를 확인<br>분석 도구의 오늘 활성 사용자, 일별 활성과 신규 사용자, Play Console의 안드로이드 설치 수를 함께 확인<br>차트를 눌러 조건이 걸린 목록으로 이동 |
| 콘텐츠 조회 | 스토리, 채팅방, 결제, 이프 거래를 검색하고 정렬해 상세를 확인<br>채팅 대화 원문은 보지 않음 |
| 회원 조회 | 닉네임, 식별자, 이메일로 회원을 찾아 상태, 잔액, 이프 거래, 출석을 확인 |
| 알림 통계 | 캠페인별 도달 수와 알림 종류별 날짜별 도달 통계 확인 ([NOTIFICATION 4-2-21 알림 통계](../../NOTIFICATION/BACKEND/4-2-CONTRACT.md#4-2-21-알림-통계)) |
| 운영 작업 | 이프 지급과 회수, 정책값 변경, 캠페인 예약, 공지 게시, 계정 정지, 검수 보류 해제, 오리지널 등록과 수정을 사유와 함께 처리 |
| 감사 | 누가 언제 무엇을 바꿨는지 감사 로그에서 확인 |

<br>

### 1-3 백엔드의 역할

관리자 페이지는 화면과 쿠키 보관을 맡는다. 관리자 판정, 토큰 발급, 감사 기록, 지표 계산은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 관리자 판정 | 관리자 역할을 받은 회원만 관리자 토큰을 발급<br>관리자 요청마다 역할을 저장소에서 다시 확인 |
| 토큰 구분 | 관리자 토큰과 앱 접근 토큰을 서로의 경로에서 거절 |
| 감사 로그 | 관리자의 모든 변경 작업과 회원 개인정보 조회를 처리자, 대상, 사유, 변경 전후 값과 함께 기록<br>삭제 경로 없음 |
| 대시보드 | 서버 DB에 있는 수치를 집계해 제공<br>요약, 일별 추이, 분포 차트 |
| 분석 지표 | 분석 도구가 집계한 활성과 신규 사용자 수를 서버가 받아 캐시해 제공 |
| 설치 지표 | Play Console 일괄 보고서의 안드로이드 기기 설치 수를 서버가 읽어 집계하고 캐시해 제공 |
| 목록과 상세 | 스토리, 채팅방, 회원, 결제를 다른 도메인 테이블에서 읽기만 해 조회<br>채팅 대화 원문은 제공하지 않음 |
| 회원 조회 | 운영 작업의 대상이 되는 회원을 찾고 상태와 잔액을 보여 줌 |
| 다른 도메인에 전달 | 이프, 알림, 공지, 계정, 검수: 관리자 요청자 식별과 감사 기록 연산 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 관리자 | 관리자 역할을 받은 팀 구성원의 회원 계정 | 로그인, 대시보드 확인, 회원 조회, 운영 작업 |
| 관리자 페이지 | 팀 구성원이 쓰는 별도 웹 | 서버 측 처리기가 백엔드를 호출하고 관리자 토큰을 쿠키에 보관 |
| 회원 | 소셜 로그인으로 가입한 사용자 | 조회와 운영 작업의 대상 |
| 운영자 | 관리자 역할을 부여하고 회수하는 팀 구성원 | 저장소에서 직접 역할을 부여하고 회수 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 관리자 역할 | 회원 계정에 부여하는 관리자 자격<br>부여와 회수는 저장소에서 직접 함 |
| 관리자 토큰 | 관리자 페이지가 백엔드를 호출할 때 쓰는 짧은 수명의 토큰<br>앱 접근 토큰과 구분됨 |
| 관리자 API | 관리자 토큰으로만 호출할 수 있는 경로의 묶음 |
| 감사 로그 | 관리자의 변경 작업과 개인정보 조회를 남긴 기록<br>처리자, 작업 종류, 대상, 사유, 변경 전후 값, 시각 |
| 접속 기록 | 감사 로그 가운데 개인정보 조회를 남긴 기록 |
| 사유 | 관리자가 변경 작업마다 적는 이유<br>필수 |
| 대시보드 지표 | 서버 DB에서 집계한 운영 현황 수치<br>오늘과 누적, 일별 추이, 분포 |
| 분포 차트 | 기간 안의 채팅, 제작 세션, AI 호출을 구간이나 범주로 나눠 센 막대 묶음<br>막대마다 같은 조건의 목록으로 이어짐 |
| 분석 지표 | 분석 도구 Amplitude가 집계한 활성 사용자와 신규 사용자 수<br>서버 DB에 없는 방문 기준 수치 |
| 팀 계정 코호트 | 분석 도구에 저장한 팀 계정 사용자 묶음<br>분석 지표에서 제외하는 기준 |
| 설치 지표 | Play Console 일괄 보고서로 집계한 안드로이드 누적 기기 설치 수, 활성 기기 수, 일별 설치와 삭제와 누계<br>Play 기준 날짜 |
| 팀 계정 | 설정값 목록에 있는 회원<br>대시보드 집계에서만 제외 |
| 오늘 | KST 자정부터 현재까지 |
| 운영 작업 | 다른 도메인의 데이터를 바꾸는 관리자 기능<br>그 도메인의 계약이 정함 |
