# 5-5 테스트 케이스

이 문서는 ADMIN 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에 있으며 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 관리자 토큰 발급과 검증, 표식 판정, KST 오늘 범위 계산, 커서 해석 | 없음 | CI |
| 통합 | 로그인, 판정 필터, 감사 기록, 대시보드, 결제 내역, 회원 조회, 감사 로그 조회 | 신원 검증기는 고정 신원을 돌려주는 구성으로 대체 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 회귀 | 등록된 모든 관리자 경로의 인증과 권한 거절 | 없음 | CI |
| 수동 | 엔드포인트 호출 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션을 건너뛴다. 전체 테스트를 통과해도 DB 제약을 검증했다고 볼 수 없다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| Google | 통합 테스트는 고정 신원을 돌려주는 검증기를 등록 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약은 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 시각 | 주입한 고정 시계로 토큰 만료와 KST 자정 경계 검증 |
| 회원 데이터 | 관리자 역할이 있는 활성, 정지, 탈퇴 계정과 역할 없는 활성 계정 준비 |

<br>

### 5-5-2 관리자 로그인과 토큰

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 로그인 | 역할 있는 활성 회원의 유효 증명 | 200, `expiresIn` 3600, `admin.isAdmin` true, 성공 로그 |
| 자격 없음 | 역할 없는 회원, 역할 있는 정지 회원, 역할 있는 탈퇴 회원, 회원 없는 신원 | 전부 403, 같은 `message`, 거절 로그의 `reason` 4종 |
| 증명 오류 | 서명 불일치<br>만료 | 401 |
| 부수효과 없음 | 회원 없는 신원 | 계정, 세션, 보상, 로그인 분석 이벤트 없음 |
| 토큰 클레임 | 발급된 토큰 | 대상 `manyak-admin`, 주체는 회원 공개 식별자, 만료는 발급 뒤 1시간 |
| 앱 경로 거절 | 관리자 토큰으로 세션 조회 호출 | 401 |
| 관리자 경로 거절 | 앱 접근 토큰으로 대시보드 호출 | 401 |
| 만료 | 1시간 뒤 대시보드 호출 | 401 |

<br>

### 5-5-3 권한 판정과 회귀

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 모든 관리자 경로 | 등록된 핸들러 매핑에서 `/api/v1/admin/` 접두 경로를 자동 수집해 로그인을 제외한 전부를 토큰 없이 또는 일반 회원의 앱 접근 토큰으로 호출 | 전부 401<br>수집된 경로 수가 1 이상 |
| 역할 회수 | 유효한 관리자 토큰<br>역할 행 삭제 뒤 호출 | 403 |
| 정지 | 유효한 관리자 토큰<br>계정 정지 뒤 호출 | 403 |
| 탈퇴 | 유효한 관리자 토큰<br>탈퇴 뒤 호출 | 403 |
| 요청자 확정 | 변경 API 호출 | 감사 로그 처리자가 토큰 주체 |

<br>

### 5-5-4 감사 기록

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 변경 기록 | 다른 도메인의 변경 API 성공 | 변경과 같은 트랜잭션에 로그 1행, 작업 이름, 대상 식별자, 사유, 전후 값, 요청 ID |
| 기록 실패 | 감사 로그 삽입 예외 | 변경도 롤백<br>500 |
| 트랜잭션 없음 | 트랜잭션 밖에서 변경 기록 호출 | 거부 |
| 접속 기록 | 회원 검색<br>회원 상세 | `MEMBER_SEARCHED`와 검색어, `MEMBER_VIEWED`와 회원 공개 식별자, 사유와 전후 값 없음 |
| 접속 기록 실패 | 삽입 예외 | 500<br>응답 본문 없음 |
| 멱등 재시도 | 같은 멱등 키의 지급 재요청 | 로그 추가 없음 |
| 조회 필터 | 처리자, 작업 이름, 대상 종류와 식별자 | 조건에 맞는 행만 최신순 |
| 필터 오류 | `targetId`만 지정, UUID 아닌 `adminId`, 변조된 커서 | 400 |

<br>

### 5-5-5 대시보드와 결제 내역

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 회원 수 | 활성 2, 정지 1, 탈퇴 1 | `total` 3<br>`withdrawnTotal` 1 |
| 오늘 경계 | KST 23:59에 가입한 회원과 00:01에 가입한 회원<br>00:30 조회 | `joinedToday` 1 |
| 턴 수 | AI 응답 메시지 3개<br>그중 하나에 판본 2개 | `turnsTotal` 3 |
| 이프 지급과 소진 | 출석 250, 구매 5000, 관리자 지급 100, 채팅 턴 -20, 만료 -30, 환불 +20 | `grantedTotal` 5350<br>`spentTotal` 20 |
| 결제 | 완료 1건 4800<br>환불 1건 2000 | `completedTotal` 2, `amountKrwTotal` 6800, `refundedTotal` 1 |
| 보류 | 보류 제출본 1건<br>대기 1건 | `heldSubmissions` 1 |
| 기준 시각 | 응답 | `asOf`와 `todayStartsAt`이 같은 시계 기준 |
| 결제 내역 | 완료 2건, 환불 1건, 대기 1건, `limit` 2 | 첫 페이지 2건 최신순, 커서 있음, 둘째 페이지 1건, 대기 제외 |
| 결제 내역 커서 | 변조된 커서 | 400 |

<br>

### 5-5-6 회원 조회

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 닉네임 검색 | `등대`, `등 대`, `EQUAL`와 `equal` | 정규화 키 부분 일치<br>최대 20건 |
| 식별자 검색 | 회원 공개 식별자<br>없는 UUID | 1건<br>빈 배열 |
| 탈퇴 회원 | 익명화 이름으로 검색<br>공개 식별자로 검색 | 빈 배열<br>1건과 `DELETED` |
| 검색어 오류 | 빈 값<br>51자 | 400 |
| 상세 | 지갑 있는 회원<br>지갑 없는 회원 | `creditBalance` 잔액<br>0 |
| 상세 오류 | 없는 회원<br>UUID 아님 | 404<br>400 |
| 응답 범위 | 상세 응답 | 이메일과 소셜 식별자 필드 없음 |
