# 2. 요구사항

이 문서는 ADMIN 도메인의 백엔드가 처리해야 하는 동작, 요구 주체, 다른 주체와의 역할 분담, 제품 제약과 데이터 보존 기준을 정한다.

요청과 응답의 필드는 계약에, 처리 순서는 처리 흐름에, 토큰 수명은 오류 처리에 있다. ([4-2 계약](4-2-CONTRACT.md), [4-1 처리 흐름](4-1-PIPELINES.md), [5-3-5 재시도와 시간 한도](5-3-ERROR-HANDLING.md#5-3-5-재시도와-시간-한도))

<br>

### 2-1 요구 주체

백엔드는 관리자를 판정하고 관리자의 행위를 기록한다. 각 주체의 역할과 백엔드에 기대하는 동작은 다음과 같다.

| 주체 | 하는 일 | 백엔드에 기대하는 것 |
|---|---|---|
| 관리자 페이지 | Google 로그인으로 받은 신원 증명을 서버 측 처리기로 전달<br>관리자 토큰을 자기 호스트 전용 httpOnly 쿠키에 보관<br>백엔드 호출은 서버 측 처리기가 수행 | 신원 증명으로 관리자 토큰을 받는 엔드포인트<br>만료를 알 수 있는 응답<br>브라우저가 백엔드를 직접 호출하지 않으므로 CORS 허용 목록 변경 없음 |
| 관리자 | 대시보드 확인, 회원 조회, 운영 작업 | 누가 무엇을 바꿨는지 사후에 확인할 수 있는 기록<br>잘못된 요청을 저장 전에 거절 |
| 이프, 알림, 공지, 계정, 검수 | 관리자 API로 운영 작업을 처리 | 요청자가 관리자인지 판정한 결과<br>같은 트랜잭션에 감사 로그를 남기는 연산 |
| 운영자 | 관리자 역할을 저장소에서 부여하고 회수 | 회수 즉시 그 계정의 관리자 요청 거절 |

<br>

### 2-2 기능 요구사항

| 기능 | 백엔드가 보장하는 것 |
|---|---|
| 관리자 로그인 | Google 신원 증명을 앱 로그인과 같은 검증기로 검증<br>해당 신원의 회원이 관리자 역할을 보유하고 활성 상태일 때만 관리자 토큰 발급<br>역할 없음, 회원 없음, 정지, 탈퇴를 구분하지 않고 거절<br>로그인은 계정을 만들지 않음 |
| 관리자 토큰 | 앱 접근 토큰과 다른 표식을 가짐<br>갱신 없이 짧은 수명만 가지며 만료되면 다시 로그인 |
| 토큰 구분 | 앱 접근 토큰은 관리자 API에서 거절하고 관리자 토큰은 앱 API에서 거절 |
| 권한 판정 | 관리자 API 전체가 대상<br>요청마다 토큰 주체의 관리자 역할과 계정 상태를 저장소에서 다시 확인<br>정지와 탈퇴 계정은 역할이 있어도 거절 |
| 역할 관리 | 부여와 회수 API 없음<br>저장소의 역할 행 추가와 삭제로만 바뀌며 다음 요청부터 반영 |
| 감사 로그 | 관리자의 모든 변경 작업을 그 변경과 같은 트랜잭션에 기록<br>처리자, 작업 종류, 대상, 사유, 변경 전후 값, 요청 ID, 시각<br>회원 검색과 상세 조회도 접속 기록으로 남김<br>삭제 경로 없음 |
| 감사 로그 조회 | 최신순 페이지 조회<br>처리자, 작업 종류, 대상으로 필터 |
| 대시보드 | 서버 DB에서 집계한 지표를 한 번에 응답<br>오늘은 KST 자정 기준<br>설정값 목록의 팀 계정은 모든 지표에서 제외 |
| 결제 내역 | 완료와 환불된 주문을 최신순으로 페이지 조회 |
| 회원 조회 | 닉네임 부분 일치 또는 공개 식별자로 검색<br>상세는 상태, 가입 시각, 잔액, 소유 콘텐츠 수 포함<br>이메일과 소셜 식별자는 응답에 없음 |

<br>

### 2-3 다른 주체와의 역할 분담

| 판단과 작업 | 담당 |
|---|---|
| 관리자 역할 부여와 회수 | 운영자가 저장소에서 직접 변경 |
| Google 신원 증명 검증 | 계정 도메인의 검증기<br>백엔드는 결과만 사용 |
| 관리자 토큰 보관과 만료 뒤 재로그인 안내 | 관리자 페이지 |
| 운영 작업의 입력 검증과 적용 | 데이터를 관리하는 도메인<br>백엔드는 관리자 판정과 감사 기록 연산 제공 |
| 방문자 수 | 분석 도구<br>서버는 세지 않음 |
| 오류와 AI 호출 기록 | 오류 추적 도구와 AI 관측 도구<br>관리자 페이지가 링크만 둠 |

<br>

### 2-4 제품 제약

**1. 입력**

| 항목 | 규칙 |
|---|---|
| 사유 | 1~500자<br>공백만으로 구성된 값은 불가 |
| 회원 검색어 | 1~50자<br>UUID 형식이면 공개 식별자로 검색하고 아니면 닉네임 부분 일치로 검색 |
| 페이지 크기 | 1~100으로 보정<br>기본 50 |
| 커서 | 서버가 발급한 값 그대로 |

<br>

**2. 개수와 한도**

| 항목 | 값 |
|---|---|
| 관리자 | 상한 없음 |
| 회원 검색 결과 | 최대 20건 |
| 감사 로그 변경 전후 값 | 각 4,000자 이내의 JSON |

<br>

**3. 대시보드 지표**

모든 지표는 팀 계정의 행을 제외한다. 팀 계정은 설정값의 회원 내부 ID 목록이며 기본 목록은 운영 Terraform의 Grafana 서비스 통계 대시보드가 소비 활동에서 제외하는 팀 계정과 같다. 회원과 탈퇴는 그 회원 행을, 채팅과 턴과 스토리와 이프와 결제는 소유 회원이 팀 계정인 행을 뺀다. 소유자가 없는 게스트 행은 포함한다. 팀 계정 제외는 대시보드에만 적용하고 회원 조회와 감사 로그에는 적용하지 않는다.

| 지표 | 정의 | 오늘 |
|---|---|---|
| 회원 수 | 탈퇴하지 않은 회원 행 수 | 오늘 생성된 회원 행 수 |
| 탈퇴 수 | 탈퇴 상태 회원 행 수 | 오늘 탈퇴한 회원 행 수 |
| 채팅 시작 수 | 삭제 여부와 무관한 채팅 행 수 | 오늘 생성된 채팅 행 수 |
| 채팅 턴 수 | 채팅의 AI 응답 메시지 수<br>재생성은 같은 메시지의 판본이라 세지 않음 | 오늘 생성된 AI 응답 메시지 수 |
| 스토리 수 | 삭제 여부와 무관한 스토리 행 수 | 오늘 생성된 스토리 행 수 |
| 이프 지급 | 원장의 양수 행 합계<br>사유는 가입, 초대, 출석 보상, 구매, 관리자 지급 | 오늘 기록된 행만 |
| 이프 소진 | 원장의 소모 행 합계의 절댓값<br>사유는 간편 제작, 채팅 턴, 채팅 이미지 | 오늘 기록된 행만 |
| 결제 건수와 금액 | 완료 시각이 있는 주문의 수와 가격 합계<br>환불된 주문도 포함 | 오늘 완료된 주문만 |
| 환불 건수 | 환불 상태 주문 수 | 오늘 환불된 주문만 |
| 검수 보류 | 현재 보류 중인 제출본 수 | 없음 |

<br>

### 2-5 데이터 보존

| 대상 | 요구사항 |
|---|---|
| 감사 로그 | 영구 보존<br>수정과 삭제 없음<br>개인정보 접속 기록의 법정 최소 보존 기간 1년을 상회 |
| 관리자 역할 | 운영자가 지울 때까지 보존<br>회수는 행 삭제 |
| 관리자 토큰 | 저장하지 않음<br>만료로만 소멸 |
| 신원 증명 | 저장하지 않음 |
