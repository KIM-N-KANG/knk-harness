# 5-3 오류 처리

이 문서는 NOTICE 도메인의 응답 규칙, 앱 코드, 오류 분류, 복구 규칙, 재시도와 시간 한도, 전달 실패 처리, 오류 로그 기준을 정한다.

엔드포인트별 실패 조건과 응답 형식은 계약에, 흐름별 처리 순서는 처리 흐름에, 잠금과 1회 처리는 동시성에 있다. ([4-2 계약](4-2-CONTRACT.md), [4-1 처리 흐름](4-1-PIPELINES.md), [5-2-2 멱등과 1회 처리](5-2-CONCURRENCY.md#5-2-2-멱등과-1회-처리))

<br>

### 5-3-1 응답 규칙

| 항목 | 규칙 |
|---|---|
| `code` | HTTP 상태 이름이 기본<br>안내가 달라질 때만 앱 코드 사용 |
| `message` | 안내 문구<br>500은 고정 안내 문구 |
| `details` | 선언적 필드 검증 실패나 쿼리와 경로 변수의 타입 변환 실패 시 채움<br>서비스에서 판정한 400은 `details` 없이 `message`에 사유 기록 |

<br>

### 5-3-2 앱 코드

코드 문자열은 API 계약이므로 유지한다. NOTICE 고유의 앱 코드는 없다. 상태 거절은 `CONFLICT`, 부재는 `NOT_FOUND`로 응답한다.

<br>

### 5-3-3 오류 분류

| 오류 | 발생 위치 | 처리 |
|---|---|---|
| 입력 오류 | API 계층의 선언적 검증과 본문 파싱 | 400으로 변환 |
| 상태 거절 | 공지 서비스 | 게시된 공지의 게시와 삭제, 초안의 게시 해제, 알림을 요청한 공지의 삭제는 409 |
| 연결 불가 | 알림 연결 연산 | 초안, 게시 해제된 공지, 없는 공지는 연결 불가 결과를 돌려줌<br>알림 도메인이 캠페인 예약을 400으로 거절 |
| 부재 | 공지 서비스 | 관리자 경로는 404<br>형식 오류는 400<br>공개 상세는 초안과 형식 오류도 404 |
| 커서 오류 | 공개 목록 | 400 |
| 페이지와 정렬 오류 | 관리자 목록 | 400 |
| 감사 기록 실패 | 관리자 도메인 연산 | 변경과 함께 롤백<br>500 |
| 예상하지 못한 오류 | 모든 위치 | 전역 핸들러가 500 고정 문구로 응답하고 Sentry 전송 |

<br>

### 5-3-4 오류별 처리

- 캠페인 생성이 실패하면 알림 요청 시각 기록도 함께 롤백된다. 관리자가 캠페인 예약을 다시 요청한다.
- 캠페인 실행이 실패하는 것은 알림 도메인의 범위다. 공지의 상태와 알림 요청 시각은 바뀌지 않는다.

<br>

### 5-3-5 재시도와 시간 한도

**1. 재시도**

- 백엔드의 자동 재시도는 없다. 관리자 페이지와 클라이언트가 같은 요청을 다시 보낸다.

<br>

**2. 시간 한도**

NOTICE 고유의 시간 한도는 없다.

<br>

### 5-3-6 최종 실패와 부분 완료

| 결과 | 처리 |
|---|---|
| 캠페인은 생기고 알림 요청 시각만 실패 | 발생하지 않음<br>같은 트랜잭션 |
| 알림 연결 뒤 캠페인 실패 | 공지는 게시 상태 유지<br>캠페인 재실행은 알림 도메인의 관리자 API |
| 게시 뒤 잘못된 내용 발견 | 수정 또는 게시 해제<br>예약된 캠페인은 알림 도메인의 관리자 API로 취소<br>이미 발송된 알림은 회수 불가 |

<br>

### 5-3-7 전달 실패 처리

| 상황 | 백엔드 | 관리자 페이지와의 경계 |
|---|---|---|
| 작성 응답 유실 | 초안 생성됨 | 재요청은 새 초안<br>관리자 목록에서 정리 |
| 게시 응답 유실 | 게시 완료 | 재요청은 409<br>관리자 상세로 확인 |
| 수정 응답 유실 | 수정 완료 | 재요청은 같은 결과 |
| 삭제 응답 유실 | 삭제됨 | 재요청은 404 |

<br>

### 5-3-8 로그와 Sentry

| 대상 | 규칙 |
|---|---|
| 5xx | 스택트레이스와 함께 ERROR로 기록하고 Sentry 전송 |
| 예상 가능한 4xx | Sentry 미전송<br>원인 예외가 있으면 클래스와 메시지를 한 줄로 WARN<br>없으면 DEBUG |
| 공지 내용 | 로그에 제목, 본문, 사유를 기록하지 않음 |
