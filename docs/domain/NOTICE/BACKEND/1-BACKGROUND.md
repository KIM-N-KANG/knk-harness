# 1. 배경

이 문서는 마냑의 공지사항, NOTICE 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 정한다.

<br>

### 1-1 도메인

NOTICE 도메인은 운영자가 사용자에게 알리는 공지사항을 다룬다. 관리자가 공지를 쓰고 게시하면 회원과 게스트가 서비스 안에서 읽는다. 게시하면 공지를 알림으로도 보낸다. 공지마다 태그가 있고 태그가 정보성과 광고성을 정한다. 공지가 정보성인지 광고성인지에 따라 알림 경로가 다르다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 점검, 정책 변경, 이벤트 같은 소식을 사용자에게 전할 수단이 서비스 안에 없었다. 광고성 소식은 법에 따라 동의한 회원에게만 보내야 하고 정보성 소식은 그 제한이 없다. 공지는 서비스 안에 남아 알림을 놓친 사용자도 다시 읽을 수 있어야 한다.

| 흐름 | 사용자가 하는 일 |
|---|---|
| 공지 읽기 | 공지 목록에서 최신 공지를 보고 상세를 읽음<br>로그인 없이도 읽음 |
| 알림으로 진입 | 공지 알림을 눌러 공지 상세로 이동 |

| 흐름 | 관리자가 하는 일 |
|---|---|
| 작성 | 제목과 본문을 초안으로 저장하고 고침<br>푸시와 알림 내역에 쓸 알림 제목과 본문을 따로 씀 |
| 작성 태그 | 공지사항, 업데이트, 점검, 이벤트, 홍보 중 하나를 고름 |
| 게시 | 초안을 게시해 사용자에게 보임<br>게시하면 태그에 따라 정보성 또는 광고성 알림이 항상 감<br>알림 없이 게시하는 선택지는 없음 |
| 게시 해제 | 게시한 공지를 내려 사용자에게 보이지 않게 함 |

<br>

### 1-3 백엔드의 역할

공지 화면은 클라이언트가, 알림 발송은 알림 도메인이 맡는다. 공지의 저장과 상태, 공개 범위, 알림 요청은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 저장 | 공지를 초안과 게시의 두 상태로 보관 |
| 공개 조회 | 게시된 공지만 목록과 상세로 제공<br>초안과 게시 해제된 공지는 공개 조회에서 보이지 않음 |
| 관리자 작업 | 관리자 API로 작성, 수정, 게시, 게시 해제, 초안 삭제<br>모두 감사 로그 대상 |
| 알림 요청 | 게시하면 태그가 정한 유형으로 알림 도메인에 발송 요청<br>공지당 한 번 |
| 다른 도메인에 전달 | 알림: 공지 발송 요청<br>관리자: 요청자 식별과 감사 기록 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자 | 공지 읽기 |
| 회원 | 소셜 로그인으로 가입한 사용자 | 공지 읽기와 공지 알림 수신 |
| 클라이언트 | 사용자가 쓰는 웹과 Android 앱 | 공지 목록과 상세 표시 및 알림 딥링크 처리 |
| 관리자 | 관리자 역할을 받은 팀 구성원 | 작성, 수정, 게시, 게시 해제, 초안 삭제 |
| 관리자 페이지 | 팀 구성원이 쓰는 별도 웹 | 관리자 API 호출 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 공지 | 운영자가 사용자에게 알리는 글 1건<br>제목, 본문, 태그, 알림 문구 |
| 알림 문구 | 공지 알림의 푸시와 알림 내역에 쓰는 제목과 본문<br>공지 제목, 본문과 따로 관리자가 입력 |
| 태그 | 공지의 분류<br>`SERVICE` 공지사항, `UPDATE` 업데이트, `MAINTENANCE` 점검, `EVENT` 이벤트, `PROMOTION` 홍보<br>정보성과 광고성을 정함 |
| 초안 | 아직 게시하지 않았거나 게시를 해제한 공지<br>관리자만 봄 |
| 게시 | 공지를 사용자에게 보이게 하는 것<br>게시 시각이 기록됨 |
| 게시 해제 | 게시한 공지를 초안으로 되돌리는 것 |
| 공개 조회 | 회원과 게스트가 게시된 공지를 읽는 API |
| 공지 알림 | 게시 시 알림 도메인으로 보내는 발송 요청<br>정보성과 광고성 중 하나 |
| 정보성 | 광고가 아닌 공지<br>태그가 `SERVICE`, `UPDATE`, `MAINTENANCE` 중 하나<br>서비스 알림 설정을 켠 회원에게 감 |
| 광고성 | 재이용을 유도하는 공지<br>태그가 `EVENT`나 `PROMOTION`<br>광고 알림에 동의한 회원에게만 가고 광고 표기가 붙음 |
| 사유 | 관리자가 변경 작업마다 적는 이유<br>감사 로그에 남음 |
