# 2. 요구사항

이 문서는 NOTICE 도메인의 백엔드가 처리해야 하는 동작, 요구 주체, 다른 주체와의 역할 분담, 제품 제약과 데이터 보존 기준을 정한다.

요청과 응답의 필드는 계약에, 처리 순서는 처리 흐름에, 알림 발송 규칙은 알림 도메인에 있다. ([4-2 계약](4-2-CONTRACT.md), [4-1 처리 흐름](4-1-PIPELINES.md), [NOTIFICATION 4-1-9 캠페인](../../NOTIFICATION/BACKEND/4-1-PIPELINES.md#4-1-9-캠페인))

<br>

### 2-1 요구 주체

백엔드는 공지를 보관하고 게시된 것만 공개한다. 게시할 때 알림 도메인에 발송을 요청한다. 각 주체의 역할과 백엔드에 기대하는 동작은 다음과 같다.

| 주체 | 하는 일 | 백엔드에 기대하는 것 |
|---|---|---|
| 클라이언트 | 공지 목록과 상세를 표시<br>알림 딥링크로 상세를 염 | 웹과 Android가 같은 계약으로 호출할 수 있는 엔드포인트<br>로그인 없이 읽을 수 있는 공개 조회<br>게시된 공지만 보임 |
| 관리자 페이지 | 작성, 수정, 게시, 게시 해제, 초안 삭제 화면 | 초안과 게시를 모두 보는 관리자 목록<br>게시 시 알림 유형을 고를 수 있음<br>게시 응답으로 알림 요청 여부를 알 수 있음 |
| 알림 | 공지 발송 요청을 캠페인으로 받아 발송 | 공지 식별자, 제목, 본문, 종류, 딥링크를 담은 요청<br>공지당 한 번만 요청 |
| 관리자 도메인 | 관리자 판정과 감사 기록 | 모든 변경에 사유와 전후 값 전달 |

<br>

### 2-2 기능 요구사항

| 기능 | 백엔드가 보장하는 것 |
|---|---|
| 작성 | 관리자가 제목과 본문으로 초안 생성<br>외부 식별자는 공개 식별자 |
| 수정 | 초안과 게시된 공지 모두 제목과 본문 수정<br>게시된 공지의 수정은 즉시 공개 조회에 반영<br>수정은 알림을 다시 보내지 않음 |
| 게시 | 초안만 게시<br>게시 시각 기록<br>알림을 요청하면 정보성 또는 광고성 중 하나로 알림 도메인에 공지당 한 번만 요청하고 게시와 같은 트랜잭션에 기록 |
| 게시 해제 | 게시된 공지만 초안으로 되돌림<br>공개 조회에서 즉시 사라짐<br>다시 게시해도 알림은 다시 요청하지 않음 |
| 초안 삭제 | 초안만 삭제<br>게시된 공지와 게시 해제된 공지 중 알림을 이미 요청한 공지는 삭제하지 않음 |
| 공개 목록 | 게시된 공지를 게시 시각 내림차순으로 페이지 조회<br>본문은 포함하지 않음 |
| 공개 상세 | 게시된 공지의 제목과 본문<br>초안과 게시 해제된 공지는 없는 것으로 응답 |
| 관리자 조회 | 상태와 무관하게 목록과 상세 조회<br>알림 요청 여부와 시각 포함 |
| 감사 | 작성, 수정, 게시, 게시 해제, 삭제를 감사 로그에 기록 |

<br>

### 2-3 다른 주체와의 역할 분담

| 판단과 작업 | 담당 |
|---|---|
| 공지 화면과 본문 표시 | 클라이언트<br>본문은 줄바꿈이 있는 평문 |
| 알림 대상 판정, 동의 확인, 광고 표기, 야간 제한, 발송 | 알림 도메인<br>백엔드는 유형과 내용만 전달 |
| 정보성과 광고성의 판단 | 관리자<br>백엔드는 선택을 그대로 전달 |
| 관리자 판정과 감사 기록 | 관리자 도메인 |
| 공지 상세 화면의 주소 | 클라이언트<br>백엔드는 운영 웹 주소에 공지 경로를 붙인 딥링크를 알림에 실음 |

<br>

### 2-4 제품 제약

**1. 입력**

| 항목 | 규칙 |
|---|---|
| 제목 | 1~100자<br>공백만으로 구성된 값은 불가 |
| 본문 | 1~5,000자<br>공백만으로 구성된 값은 불가 |
| 알림 유형 | `SERVICE`와 `MARKETING` |
| 공지 식별자 | UUID |
| 페이지 크기 | 1~50으로 보정<br>기본 20 |
| 커서 | 서버가 발급한 값 그대로 |

<br>

**2. 개수와 한도**

| 항목 | 값 |
|---|---|
| 공지 수 | 상한 없음 |
| 공지당 알림 요청 | 1회 |
| 알림 본문 | 공지 본문의 앞 300자<br>줄바꿈은 공백으로 바꿈 |

<br>

**3. 공지 상태**

| 상태 | 의미 | 다음 상태 |
|---|---|---|
| `DRAFT` | 작성 중이거나 게시를 해제한 공지<br>관리자만 봄 | `PUBLISHED`<br>삭제 |
| `PUBLISHED` | 공개 조회에 보이는 공지 | `DRAFT` |

<br>

### 2-5 데이터 보존

| 대상 | 요구사항 |
|---|---|
| 게시된 공지 | 영구 보존<br>게시 해제해도 행은 남음 |
| 알림을 요청한 공지 | 삭제 불가<br>알림이 가리키는 딥링크의 대상이 사라지지 않게 함 |
| 초안 | 관리자가 삭제할 때까지 보존<br>알림을 요청한 적 없는 초안만 삭제 가능 |
| 변경 이력 | 공지 행에는 마지막 값만<br>이전 값은 관리자 도메인의 감사 로그 |
