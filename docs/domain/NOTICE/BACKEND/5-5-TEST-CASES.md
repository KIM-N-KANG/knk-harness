# 5-5 테스트 케이스

이 문서는 NOTICE 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에 있으며 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 커서 해석 | 없음 | CI |
| 통합 | 공개 조회, 관리자 작성과 수정, 게시와 알림 요청, 게시 해제, 삭제, 감사 기록 | 알림 도메인은 같은 서버의 서비스 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 동시성 | 동시 게시 및 게시와 해제의 경쟁 | 없음 | CI |
| 수동 | 엔드포인트 호출과 실기기 알림 도달 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션을 건너뛴다. 전체 테스트를 통과해도 DB 제약을 검증했다고 볼 수 없다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| 관리자 | 관리자 역할이 있는 활성 계정과 발급한 관리자 토큰 |
| 알림 도메인 | 캠페인 행이 같은 트랜잭션에 생기는지 저장 계층으로 확인 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약은 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 공지 데이터 | 초안, 게시, 게시 해제, 알림을 요청한 초안을 각각 준비 |

<br>

### 5-5-2 공개 조회

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 목록 | 게시 3건, 초안 1건, `limit` 2 | 게시만 게시 시각 내림차순 2건, 커서 있음, 둘째 페이지 1건 |
| 목록 본문 | 목록 응답 | `body`와 작성자 정보 없음 |
| 상세 | 게시된 공지 | 200<br>제목, 본문, 태그 |
| 부재 | 초안, 게시 해제된 공지, 없는 식별자, UUID 아님 | 전부 404 |
| 토큰 무시 | 토큰 없음, 만료된 접근 토큰, 유효한 접근 토큰으로 목록과 상세 조회 | 모두 200, 같은 공개 결과 |
| 태그 필터 | `SERVICE` 2건, `MAINTENANCE` 1건, `EVENT` 1건 게시, `tag=MAINTENANCE`, `tag=NOTICE` | 1건, 400 |
| 커서 오류 | 변조된 커서 | 400 |
| 페이지 한도와 종료 | `limit` 0, 100, `abc`, 마지막 페이지와 빈 목록 | 1과 50으로 보정, 타입 오류는 400, 마지막과 빈 목록의 `nextCursor`는 `null` |

<br>

### 5-5-3 작성과 수정

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 작성 | 유효한 제목, 본문, 태그 `UPDATE`, 알림 제목, 알림 본문, 사유 | 201, `DRAFT`, `tag` `UPDATE`, 알림 문구 저장, 작성자는 요청 관리자, 감사 로그 `NOTICE_CREATED` |
| 입력 오류 | 빈 제목, 101자 제목, 5,001자 본문, 공백으로만 구성된 본문, 태그 누락, 모르는 태그, 알림 제목 누락, 101자 알림 제목, 알림 본문 누락, 301자 알림 본문, 공백으로만 구성된 알림 본문, 사유 누락 | 400 |
| 수정 | 제목만, 본문만, 태그만, 알림 제목만, 다섯 다 | 보낸 필드만 바뀜<br>감사 로그에 전후 값 |
| 수정 오류 | 다섯 필드 모두 없음, 모두 `null`, 모르는 태그, 사유 누락 | 400 |
| 알림 문구 일부 | `notifiedAt`과 알림 문구가 `null`인 공지에 `notificationTitle`만 보냄 | 400 |
| 알림 요청 공지의 문구 일부 | `notifiedAt`이 있고 알림 문구가 `null`인 공지에 `notificationTitle`만 보냄 | 409 |
| 알림 문구 `null` 전송 | `notifiedAt`이 있는 공지에 `title`과 `notificationTitle: null` | 200, `null`은 생략과 같아 409 아님 |
| 알림 후 문구 수정 | `notifiedAt`이 있는 공지에 `notificationBody` 수정<br>같은 공지에 `title`만 수정 | 409<br>200, 캠페인 제목과 본문은 그대로 |
| 게시 뒤 태그 수정 | `SERVICE`로 알림을 요청한 공지를 `EVENT`로 수정 | 200, 캠페인 종류 `SERVICE` 유지, 캠페인 추가 없음 |
| 게시 중 수정 | 게시된 공지 수정 | 200, 공개 상세에 즉시 반영, 캠페인 추가 없음 |
| 관리자 목록 | `status` 필터 없음, `DRAFT`, `PUBLISHED`, `ARCHIVED` | 전체, 초안만, 게시만, 400 |
| 관리자 목록 검색과 정렬 | 제목 일부 `q`, `sort=notifiedAt` | 제목 일치 건만, 알림 없는 공지가 마지막 |

### 5-5-4 게시, 게시 해제, 삭제

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 게시 | 태그 `SERVICE` 초안 | 200, `PUBLISHED`, `publishedAt` 기록, 감사 로그 `NOTICE_PUBLISHED` |
| 정보성 알림 | 태그 `SERVICE`, `UPDATE`, `MAINTENANCE` 초안 각각 | 같은 트랜잭션에 캠페인 1건, 종류 `SERVICE`, 예약 시각은 현재, 공지 식별자와 딥링크, 캠페인 제목과 본문은 알림 문구, `notifiedAt` 기록, `notified` true |
| 광고성 알림 | 태그 `EVENT`와 `PROMOTION` 초안 각각 | 캠페인 종류 `MARKETING`, 캠페인에 태그 기록 |
| 예전 게시 본문 | 태그 `SERVICE` 초안에 `notify` false와 `notificationKind` `MARKETING` | 200, 캠페인 1건, 종류 `SERVICE`, `notified` true |
| 알림 문구 | 제목 "10월 25일 새벽 점검 안내", 알림 제목 "새로운 점검 안내가 도착했어요" | 캠페인 제목은 알림 제목, 본문은 알림 본문 그대로<br>공지 원문 제목과 본문은 쓰지 않음 |
| 알림 문구 없는 공지 | 알림 문구가 `null`이고 `notifiedAt`이 `null`인 초안 게시 | 409, 공지는 `DRAFT`, 캠페인 없음 |
| 알림 1회 | 알림을 요청했던 공지를 수정한 뒤 해제하고 재게시 | 수정과 재게시 모두 캠페인 추가 없음, 재게시는 200과 `notified` false |
| 알림 없던 공지 재게시 | `notifiedAt`과 알림 문구가 없는 게시 해제 공지에 알림 문구를 넣고 재게시 | 200, 캠페인 1건, `notified` true |
| 알림 문구 없는 재게시 | `notifiedAt`이 있고 알림 문구가 `null`인 게시 해제 공지를 재게시 | 200, 캠페인 추가 없음, `notified` false |
| 게시 오류 | 게시된 공지, 사유 누락 | 409, 400 |
| 기존 공지 태그 | 마이그레이션 전에 만든 공지 | `tag` `SERVICE` |
| 광고성 원문 제목 | 태그 `EVENT` 공지 게시 뒤 공개 목록과 상세 | 공개 목록과 상세의 `title`에 `(광고)` 없음<br>캠페인 제목은 `notificationTitle` 그대로이며 푸시의 광고 표기는 알림 도메인이 붙임 |
| 알림 요청 실패 | 캠페인 삽입 예외 | 500, 공지는 `DRAFT`, 감사 로그 없음 |
| 게시 해제 | 게시된 공지<br>초안 | 200과 `DRAFT`와 `publishedAt` 유지<br>409 |
| 삭제 | 알림 요청 없는 초안, 게시된 공지, 알림을 요청한 초안 | 204와 행 삭제와 감사 로그 `NOTICE_DELETED`, 409, 409 |
| 동시 게시 | 같은 초안에 동시 2건 | 한쪽 200, 다른 쪽 409, 캠페인 1건 |
| 공개 반영 | 게시 뒤 공개 상세<br>해제 뒤 공개 상세 | 200<br>404 |
