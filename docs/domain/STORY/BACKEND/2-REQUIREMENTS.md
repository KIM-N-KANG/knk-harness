# 2. 요구사항

이 문서는 STORY 도메인의 백엔드에 요구되는 동작, 요구 주체, AI 서버와의 역할 분담, 제품 제약과 데이터 보존 기준을 정한다.

요청과 응답의 필드는 계약에, 처리 순서는 처리 흐름에, 대기 한도와 복구는 오류 처리에 있다. ([4-2 계약](4-2-CONTRACT.md), [4-1 처리 흐름](4-1-PIPELINES.md), [5-3-5 재시도와 시간 한도](5-3-ERROR-HANDLING.md#5-3-5-재시도와-시간-한도))

<br>

### 2-1 요구 주체

백엔드는 클라이언트와 AI 서버 사이에서 요청과 결과를 중계한다. 각 주체가 맡는 일과 백엔드에 기대하는 동작은 다음과 같다.

| 주체 | 하는 일 | 백엔드에 기대하는 것 |
|---|---|---|
| 클라이언트 | 사용자의 입력을 받아 제작과 수정을 요청하고 목록, 상세, 완성 결과를 표시<br>게스트가 만든 스토리의 식별자와 제작 중 입력을 로컬에 보관 | 사용자 역할과 무관하게 같은 계약으로 호출할 수 있는 엔드포인트<br>화면에 그대로 표시할 수 있는 응답<br>연결이 끊겨도 결과를 되찾을 수 있는 경로 |
| AI 서버 | 간편 제작의 스토리라인, 스토리 설정, 인물 이미지와 표지 생성<br>요청 사이에 상태를 남기지 않음 | 생성에 필요한 데이터를 요청마다 빠짐없이 전달<br>생성 결과의 검증과 저장은 백엔드가 맡음 |
| 채팅 | 스토리를 바탕으로 플레이를 진행 | 독자의 읽기 권한에 맞는 스토리 설정<br>시작 설정, 주요 사건, 엔딩, 기본 주인공 이름 |

<br>

### 2-2 기능 요구사항

| 기능 | 백엔드가 보장하는 것 |
|---|---|
| 탐색 | 발행 상태인 공개 회원 스토리만 목록과 검색에 노출<br>기본 정렬은 인기순이며 최신순, 좋아요순, 채팅순 선택 가능<br>최신순은 페이지를 넘기는 사이에 새 스토리가 추가되어도 중복과 누락 없음<br>로그인 여부와 무관하게 같은 결과 |
| 장르 | 제공 장르 전체와 대표 장르를 정해진 순서로 제공<br>이름 전체, 이름 일부, 초성, 별칭으로 검색 가능 |
| 상세 | 채팅 시작에 필요한 설정, 인물과 소개, 주요 사건, 로어북, 도달한 엔딩을 한 번에 제공<br>이름 토큰은 기본 주인공 이름으로 치환해 제공<br>읽을 수 없는 스토리는 존재 여부를 드러내지 않음 |
| 내 스토리 목록 | 회원이 소유한 스토리 목록은 서버에서 조회<br>게스트는 로컬에 보관한 식별자로 일괄 조회 |
| 간편 제작 | 태그 선택, 스토리라인 후보 3편, 완성 결과 제공<br>AI 응답 대기가 길어 연결이 끊겨도 결과를 되찾을 수 있음<br>같은 요청을 다시 보내도 두 번 만들거나 두 번 과금하지 않음<br>AI 서버가 응답하지 않거나 오류를 반환하면 실패로 응답<br>차감한 이프와 사용한 체험 횟수를 복원하며 같은 요청으로 재시도 가능<br>인물 이미지나 표지 생성 실패는 완성을 막지 않음<br>완성본은 검수 없이 바로 제공<br>선택한 화풍을 인물 이미지와 표지에 적용<br>없음을 선택하면 이미지를 생성하지 않음 |
| 일반 제작 | 회원만 등록 가능<br>폼 전체를 한 번에 접수하고 제출본 식별자를 즉시 반환<br>승인된 것만 스토리로 생성하며 AI 생성과 과금 없음<br>장르는 제공 장르의 정식 이름만 허용 |
| 스토리 수정 | 제작 방식과 무관하게 같은 폼으로 수정<br>보낸 항목만 바꾸고 나머지는 유지<br>시작 설정과 인물은 식별자로 지정해 진행 중인 채팅과 이미지의 연결 유지<br>공개 범위만 바꾸는 요청은 검수 없이 바로 반영<br>검수 중에는 다른 수정과 이미지 삭제를 거절 |
| 수정 반영 | 승인 전 제출본은 목록, 상세, 검색, 채팅에 노출하지 않음<br>승인 후에는 소유자의 채팅과 공개 스토리의 다른 독자 채팅에 다음 턴부터 새 설정 적용<br>지난 턴은 유지<br>비공개로 바꾼 뒤 고친 내용은 소유자에게만 반영<br>해당 스토리의 채팅을 이어가는 다른 독자는 마지막 공개본을 계속 사용 |
| 이미지 | 스토리 등록 전후 모두 클라이언트가 직접 업로드할 수 있는 presigned URL 제공<br>표지와 인물 이미지는 등록과 수정 폼으로 추가하고 삭제는 바로 반영<br>표지가 없으면 빈 값으로 응답하고 서버가 대체 이미지를 고르지 않음<br>삭제해도 지난 채팅의 이미지는 계속 표시 |
| 소셜 | 회원만 가능하며 읽을 수 있는 스토리에만 남길 수 있음<br>좋아요와 신고는 같은 요청을 반복해도 동일한 결과 보장 |
| 임시 저장 | 회원의 작성 중 입력을 초안으로 보관<br>초안 전체를 한 번에 저장하고 같은 내용을 다시 받아도 결과가 같음<br>기준 버전이 현재와 다르면 덮어쓰지 않고 거절<br>입력 내용은 해석하지 않고 보관만 하며 검증은 등록 시점에 수행<br>등록이나 완성을 접수하면 그 초안은 삭제<br>초안 목록에 진행 중인 생성 요청을 함께 제공 |
| 삭제 | 소유자만 삭제하며 검수 중에도 가능<br>삭제 후 목록, 상세, 검색, 일괄 조회에서 제외<br>해당 스토리의 제출본도 함께 삭제<br>이미 삭제된 스토리는 없는 것으로 응답 |

<br>

### 2-3 AI 서버와의 역할 분담

| 판단과 작업 | 담당 |
|---|---|
| 입력의 개수, 길이, 인물 이름 중복 검증 | 백엔드 |
| 스토리라인, 스토리 설정, 주요 사건, 엔딩, 인물 외형과 소개, 인물 이미지와 표지 생성 | AI 서버<br>이미지 실패는 완성 실패가 아님 |
| 생성 본문의 주인공 이름을 이름 토큰으로 바꾸고 실제 이름을 별도로 전달 | AI 서버 |
| 생성 결과의 검증, 저장, 과금과 체험 한도, 복구와 중복 방지 | 백엔드<br>주요 사건이나 엔딩 이름이 중복되거나 이름 토큰에 대응하는 주인공 이름이 없으면 불완전한 응답으로 판단해 저장하지 않음 |
| 로어북 선별 | 백엔드가 장르를 기준으로 선별해 완성 요청에 포함 |
| 이름 토큰을 기본 주인공 이름으로 치환 | 백엔드<br>스토리 응답에서만 치환하고 저장 원문은 유지 |

<br>

### 2-4 제품 제약

**1. 간편 제작 입력**

| 항목 | 상한 |
|---|---|
| 제공 장르 | 20개 |
| 직접 입력 장르 | 없음 |
| 주변 인물 | 5명 |
| 인물당 특징 | 3개 |
| 인물 이름 | 30자 |
| 추가 정보 | 13개, 항목당 100자 |

<br>

**2. 일반 제작과 수정 입력**

| 항목 | 상한 |
|---|---|
| 제목 | 100자 |
| 한 줄 소개 | 255자 |
| 상세 설명 | 제한 없음 |
| 장르 | 1~8개 |
| 기본 주인공 이름 | 30자 |
| 시작 설정 | 1개 이상, 이름 100자 |
| 시작 설정당 추천 입력 | 정확히 3개 |
| 시작 설정당 엔딩 | 10개, 이름 100자 |
| 주요 사건 | 10개, 이름 100자 |
| 인물 | 6명, 이름 100자 |
| 인물 소개 | 150자 |

<br>

**3. 이미지**

| 항목 | 상한 |
|---|---|
| 표지 | 1장 |
| 인물당 이미지 | 10장 |
| 이미지 1장 용량 | 5MB |
| 형식 | JPEG, PNG, WebP |

<br>

**4. 조회와 한도**

| 항목 | 값 |
|---|---|
| 목록 페이지 크기 | 기본 20, 최대 50 |
| 일괄 조회 | 100개 |
| 검색어 | 2~100자 |
| 장르 검색어 | 30자 |
| 검수 중인 제출본 | 스토리당 1건 |
| 게스트 체험 | 스토리라인 생성 5회, 완성 1회 |
| 회원당 초안 | 5개 |
| 초안 입력 크기 | 64KB |

<br>

### 2-5 데이터 보존

| 대상 | 요구사항 |
|---|---|
| 스토리 | 삭제해도 기록을 보존하고 조회에서만 제외<br>진행 중 채팅의 참조는 끊기지 않아야 함 |
| 이미지 객체 | 지난 채팅 본문이 참조하는 객체는 보존 |
| 생성 요청 기록 | 복구를 위해 보존 |
| 검수 제출본 | 스토리를 삭제하면 그 스토리의 제출본도 삭제 |
| 공개본 | 소유자가 비공개로 바꾼 뒤 수정해도 다른 독자는 마지막 공개본을 봄 |
| 엔딩 도달 기록 | 제작자가 엔딩을 수정해도 회원의 도달 기록 유지 |
| 좋아요와 신고 | 보존 |
| 초안 | 등록이나 완성 접수, 회원 탈퇴 시 삭제<br>자동 만료 없음 |
