# 1. 배경

이 문서는 마냑의 스토리 제작과 탐색, STORY 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 설명한다.

<br>

### 1-1 도메인

STORY 도메인은 채팅의 바탕이 되는 스토리의 제작, 탐색, 조회와 관리를 다룬다. 스토리는 세계관, 등장인물, 주인공, 규칙, 시작 상황을 묶은 설정이며 채팅은 이 설정을 바탕으로 진행된다. 채팅을 시작하려면 스토리가 필요하다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 사용자는 간편 제작과 일반 제작으로 스토리를 만든다. 제작 방식과 무관하게 같은 폼으로 수정할 수 있다. 마냑 공식 계정은 오리지널 스토리를 제공한다.

| 제작과 수정 | 사용자가 하는 일 |
|---|---|
| 간편 제작 | 태그와 인물 선택<br>스토리라인 후보 3편 중 1편 선택<br>추가 정보 입력 |
| 일반 제작 | 제목, 소개, 장르, 스토리 설정, 시작 설정, 추천 입력, 엔딩, 주요 사건, 인물, 인물 소개, 표지, 인물 이미지 직접 입력 |
| 수정 | 수정 폼에서 변경할 항목만 수정해 제출<br>표지와 인물 이미지 교체 또는 삭제<br>공개 범위 변경 |
| 임시 저장 | 작성 중인 간편 제작과 일반 제작 입력을 초안으로 보관<br>제작 탭에서 이어서 작성하거나 삭제 |

<br>

### 1-3 백엔드의 역할

AI 서버는 요청 사이의 상태를 저장하지 않는다. 검수 도메인은 제출본을 판정한다. 제작 진행, 저장, 권한, 과금, 검수 접수와 반영, 검색은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 간편 제작 진행 저장과 복구 | 진행 상태와 결과 저장<br>연결이 끊긴 요청의 결과 복구<br>같은 요청의 중복 실행 방지 |
| 일반 제작과 수정 접수 | 입력 검수 요청<br>검수 승인 시 저장 또는 반영<br>검수 중인 스토리에 대한 다른 쓰기 요청 거절 |
| 조회 | 공개 목록, 오리지널 목록, 검색, 제공 장르, 로어북 카탈로그, 내 스토리 목록, 상세, 수정 폼 제공<br>이름 토큰 치환 |
| 이미지 저장과 연결 | 스토리 등록 전후의 업로드 경로 제공<br>AI가 생성하거나 사용자가 업로드한 표지와 인물 이미지를 저장하고 스토리에 연결<br>표지와 인물 이미지 삭제 |
| 접근 판정 | 누가 어떤 스토리를 읽고 쓸 수 있는지 판정<br>스토리가 비공개로 바뀐 뒤에도 채팅을 이어가는 다른 독자에게는 마지막 공개본 제공 |
| 초안 보관 | 회원의 작성 중 입력을 초안으로 저장<br>등록이나 완성을 접수하면 그 초안 삭제 |
| 소셜 | 좋아요와 신고 기록 |
| 다른 도메인에 전달 | 채팅: 스토리 설정과 공개 스냅샷<br>검수: 검수 제출본<br>알림: 완성 이벤트<br>이프: 소모 요청 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자 | 간편 제작, 삭제, 스토리라인 평가, 복구 조회<br>체험 한도 내에서 스토리 제작<br>제작한 스토리는 비공개로 유지 |
| 회원 | 로그인한 사용자 | 간편 제작과 일반 제작, 임시 저장, 수정, 공개 범위 변경, 이미지 업로드와 삭제, 좋아요, 신고<br>공개 목록에 실리는 스토리의 작성자 |
| 공식 계정 | 운영팀이 지정한 회원 | 소유한 공개 스토리를 오리지널 스토리로 제공 |
| 클라이언트 | 사용자가 쓰는 앱 | 요청을 보내고 결과를 표시함<br>게스트가 만든 스토리의 식별자와 제작 중 입력을 로컬에 보관함 |
| AI 서버 | 스토리 설정을 생성하는 서버 | 간편 제작의 스토리라인 생성, 스토리 완성, 인물 이미지와 표지 생성 |
| 운영자 | 팀 구성원 | 태그, 로어북, 화풍을 등록하고 공식 계정을 설정함 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 스토리 | 채팅의 바탕이 되는 설정 묶음 |
| 간편 제작 진행 | 간편 제작 1회의 입력과 결과를 관리하는 단위<br>스토리라인 후보와 선택 결과, 인물, 태그를 묶음 |
| 생성 요청 | 스토리라인 생성 또는 스토리 완성 요청 한 건<br>복구와 중복 방지의 기준 |
| 스토리라인 | AI가 생성한 이야기 전개 방향 후보<br>간편 제작 1회에 3편 제공 |
| 완성 | 선택한 스토리라인과 추가 정보를 스토리 설정으로 확장하는 AI 작업 |
| 시작 설정 | 채팅을 시작하는 장면<br>스토리당 1개 이상<br>추천 입력과 엔딩은 각 시작 설정에 속함 |
| 주요 사건 | 채팅에서 도달할 목표 사건 목록<br>스토리당 최대 10개 |
| 엔딩 | 시작 설정별로 정의한 이야기의 결말<br>이름으로 식별하며 최소 턴 수와 달성 조건 포함 |
| 인물과 인물 이미지 | 스토리의 등장인물과 인물별 이미지 여러 장 |
| 표지 | 스토리 대표 이미지<br>AI가 생성하거나 사용자가 업로드한 이미지 사용<br>이미지가 없으면 빈 값 유지 |
| 공개 스냅샷 | 스토리가 마지막으로 공개 상태였을 때의 표시 정보와 생성에 필요한 데이터<br>소유자가 비공개로 바꾼 뒤 다른 독자가 이어서 플레이하는 채팅에 사용함 |
| 검수 제출본 | 일반 제작 등록 또는 수정 입력을 담은 기록<br>승인된 것만 스토리에 반영함 |
| 수정 폼 | 소유자가 스토리를 수정할 때 조회하는 수정 가능 항목 전체 |
| 공개 범위 | 공개 또는 비공개<br>공개 범위만 바꾸는 수정은 검수 없이 바로 반영 |
| 오리지널 스토리 | 공식 계정이 소유한 공개 스토리 |
| 기본 주인공 이름 | 스토리에 저장한 주인공 이름<br>스토리 응답에서 이름 토큰을 이 이름으로 치환 |
| 이름 토큰 | 저장된 스토리 원문에서 주인공 이름을 나타내는 문자열<br>응답과 AI 요청에서만 실제 이름으로 치환하고 저장 원문은 유지 |
| 제공 장르 | 서버가 관리하는 장르 197개와 대표 장르 15개<br>별칭과 초성으로 검색 |
| 인물 소개 | 스토리 상세에 표시하는 주변 인물 설명<br>스토리 완성 결과에 포함되거나 일반 제작에서 사용자가 입력 |
| 화풍 | 간편 제작의 인물 이미지와 표지에 적용하는 그림체<br>없음을 선택하면 이미지를 생성하지 않음 |
| 초안 | 회원이 작성 중인 제작 입력을 서버에 보관한 것<br>등록 전 입력이라 스토리가 아님 |
