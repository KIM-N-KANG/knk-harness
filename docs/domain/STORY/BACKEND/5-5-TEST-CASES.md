# 5-5 테스트 케이스

이 문서는 STORY 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에, 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 커서 인코딩, 이름 검증, 토큰 치환과 텍스트 길이 제한, 객체 키 생성, URL 조합, 이미지 단계 제한 시간, 검색 문서 변환 | 없음 | CI |
| 통합 | 컨트롤러부터 저장까지 | AI 서버는 스텁, S3와 OpenSearch는 모의 객체 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 마이그레이션 | 시드와 이름 변경 마이그레이션의 결과 | 없음 | CI |
| 수동 | 엔드포인트 호출 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션을 건너뛰므로 전체 테스트를 통과해도 DB 제약이 검증된 것은 아니다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| AI 서버 | 통합 테스트는 테스트용 AI 클라이언트를 등록해 고정 응답을 반환하고 호출 횟수와 전달 헤더를 검사<br>완성 푸시 테스트만 스텁 설정을 켬 |
| S3 | presign과 연결은 업로드 저장소를 모의 객체로 교체<br>저장소 단위 테스트는 예외를 발생시키는 테스트용 S3 클라이언트와 실제 서명기로 서명 파라미터와 미구성 동작만 검사 |
| OpenSearch | 검색 API는 OpenSearch 클라이언트와 색인기를 모의 객체로 교체<br>실제 질의는 Testcontainers의 OpenSearch 컨테이너로 Docker가 있을 때만 실행 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약과 인덱스는 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 시간과 회수 | 오래된 `PENDING`은 `updated_at`을 임계값보다 과거로 둔 행을 직접 INSERT해 재현<br>이미지 단계 제한 시간은 0 또는 짧은 제한 시간으로 소진 상태 재현 |
| 시드 데이터 | 제공 장르는 테스트마다 명시적으로 준비<br>기대값은 테스트 리소스의 카탈로그와 대표 목록 파일 |
| 외부 발송과 비밀값 | 테스트 프로파일이 Slack 웹훅, 구글 폼, 스케줄러를 끄고 JWT와 OAuth는 더미 값 사용 |

### 5-5-2 조회와 목록

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 노출 조건과 정렬 | 비공개, 초안, 삭제, 게스트 소유 스토리가 섞인 목록<br>정렬 4종과 커서 | 회원 소유 공개 스토리만 반환<br>인기순 기본, 동률은 `publicId` 내림차순<br>최신순과 집계 정렬 모두 커서로 이어 읽음 |
| 커서 검증 | 다른 정렬의 커서, 옛 `p` 접두, 만료 토큰 | 정렬 불일치와 `p` 커서는 400<br>만료나 위조 토큰이 붙어도 목록 반환 |
| 오리지널 | 공식 계정 설정 유무 | 공식 계정 소유 공개 스토리만<br>미설정이면 빈 배열이고 커서 검증은 유지 |
| 상세 | 읽기 가능과 불가, 회원과 게스트 | 상세 필드와 인물 소개, 읽기 판정 404, `isOwner`와 `isLiked`, 인물 대표 이미지 |
| 일괄 조회 | 없는 ID, 읽을 수 없는 ID, 중복 ID, 형식이 틀린 ID 포함 요청 | 제외와 요청 순서 유지, 중복은 한 건 |
| 이름 토큰 표시 | 기본 주인공 이름이 있는 스토리의 상세, 수정 폼, 공개 스냅샷 | 응답은 치환, 수정 폼과 스냅샷은 원문 |
| 활성 엔딩과 도달 집계 | 레거시 엔딩 행, 도달 기록 | 활성 엔딩만 노출, 도달 엔딩 이름 집계 |

### 5-5-3 제공 장르

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 조회와 검색 | 게스트 요청, 빈 질의, 별칭, 초성, 공백과 대소문자, 31자 질의 | 전체 197개와 대표 15개 순서<br>검색 순위에 따라 중복 없이 반환<br>비활성 별칭 제외<br>30자 허용, 31자 400<br>`simple/tags`는 대표와 인물만 |
| 입력 검증 | 정식 이름, 별칭, 비활성, 커스텀, 공백, 9개, 31자 원소<br>PATCH의 기존 커스텀 유지와 제거 | 정규화와 첫 위치를 유지하는 중복 제거<br>원본 인덱스별 `INVALID_GENRE`, 형식 위반은 `BAD_REQUEST`<br>기존 장르 유지 예외와 제거 후 재추가 거절<br>이미 접수된 제출본은 승인 시 재검증 없음 |
| 직접 입력 장르 | `customGenreTags`에 정식 이름, 공백, 빈 문자열, 긴 값 | 모두 `CUSTOM_GENRE_NOT_ALLOWED` |

### 5-5-4 간편 제작

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 과금과 한도 | 회원 완성, 게스트 한도 소진, 저장 실패 | 이프 차감과 환불, 게스트 402, 실패 시 복원 |
| 컴파일 저장 | 로어북 선별, 사건과 엔딩, 인물 외형과 이미지, 인물 소개, 사건 또는 엔딩 이름이 중복된 응답 | 저장 순서와 길이에 맞춘 자르기, 로어북 연결<br>이름을 정규화해 소개 연결<br>소개만 있는 이름은 제외<br>사건 또는 엔딩 이름 중복은 502이고 스토리 미저장<br>이미지 실패 시 `image_url` 없이 저장 |
| 복구와 멱등 | 같은 `requestId` 재요청, `PENDING`, 회수, 타인 소유 | 저장 결과 재응답, 409, 회수 재실행, 소유 판정 |
| 화풍 선택 | 누락, 활성 코드, 비활성 또는 미등록 코드, `NONE` | `ANIME` 기본값, 통과, 400, 이미지 없이 저장 |
| AI 응답 없음 | 연결 실패, 읽기 시간 초과, 빈 본문 | 502, 이프 환불과 게스트 횟수 복원, 요청 행 `FAILED`, 스토리 미저장<br>같은 `requestId` 재요청으로 재실행 |
| AI 오류 응답 | 4xx, 5xx 응답 | 502, 환불과 복원, 요청 행 `FAILED` |
| AI 응답 형식 오류 | 역직렬화 실패, 사건이나 엔딩 이름 중복, 생성 본문에 토큰이 있는데 주인공 이름 없음 | 502, 환불과 복원, 스토리 미저장 |
| AI 응답의 이미지 부분 실패 | 일부 인물 이미지와 표지에 `error` 또는 업로드 실패 | 201, 해당 이미지만 `null`, 스토리는 저장 |
| 평가 | 설정, 덮어쓰기, 취소, 타인 | 멱등 취소, 소유 403 |
| 완성 푸시 | 회원과 게스트 완성, 멱등 재요청 | 회원에게만 발행<br>재요청에는 발행하지 않음 |

<br>

### 5-5-5 등록, 수정, 이미지, 소셜

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 등록 접수 | 회원과 미인증 요청, 승인 적용 | 202, 401, 승인 시 스토리 생성 |
| 수정 | 수정 폼, 공개 범위 단독, 시작 설정과 인물 동기화, 인물 이름 변경 | 즉시 반영과 접수 구분, `id` 매칭, 이미지 접두 변경 |
| 이름 검증 | 엔딩, 사건, 인물, 이미지 이름 중복 | 400 |
| presign과 연결 | 소유자, 게스트 소유, 타인, 미인증, 형식과 크기, 다른 스토리의 키, 미완료 업로드 | 발급 경로, 400, 401, 403, 404, `UPLOAD_NOT_FOUND` |
| 표지와 인물 이미지 삭제 | 삭제와 재삭제, 공개 스토리의 이미지 변경 | 키와 URL이 null, 204 멱등<br>공개 스냅샷 갱신 |
| 좋아요와 신고 | 반복 요청, 미인증, 정지, 읽기 불가 | 멱등, 401, 403, 404, 신고 알림 1회 |
| 삭제 | 소유자, 타인, 재삭제 | 403, 404 우선, 재삭제 404 |
| 초안 저장 | 같은 내용 재전송, 다른 내용과 `baseVersion` 일치, 불일치, 6번째 신규, 다른 ID 동시 신규, 타인 ID, 경로 변형 이미지 키, 64KB 초과 | 버전과 시각 유지, 버전 +1과 `createdAt` 보존, 409 응답과 현재 값인 `version`, `updatedAt`, 400 `DRAFT_LIMIT_EXCEEDED`, 5개 상한 유지, 404, 400, `DRAFT_PAYLOAD_TOO_LARGE` |
| 초안 목록과 상세 | 초안과 회수 기준 안팎의 `PENDING` 생성 요청, `STORY_DRAFT`의 생성 요청 연결 | 생성 시각 내림차순, 회수 가능한 요청 제외, `generation`에 복구 조회 결과 |
| 초안 삭제 | 등록, 완성, 재제출 접수의 `draftId`, 타인 초안, 회원 탈퇴 | 접수 트랜잭션에서 내 초안만 삭제, 타인 초안 유지, 탈퇴 시 전부 삭제 |
| 공개 스냅샷 격리 | 공개와 비공개 상태의 수정 | 공개 상태에서만 갱신, 비공개 전환 후 수정 내용 미반영 |

### 5-5-6 검색

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 검색 API | 미설정, 빈 인덱스, 공개 철회 | 503, 빈 200, 응답 전 재검사 |
| 질의와 커서 | 검색어 길이, 커서 해시 | 2~100자 검증, 해시 불일치 거절 |
| 색인 | 문서 변환, 색인 실패, 기동 | 치환된 제목 색인, 실패가 요청에 영향 없음, 인덱스 생성 |

### 5-5-7 공통 오류와 관측

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 오류 응답 형식 | 필수 입력이 빠진 400 | `status`, `code`, `message`, `path`, `details` 필드 |
| Sentry 전송과 태그 | 500, 상태 예외로 만든 5xx, 404와 409, 406과 415 | 5xx만 캡처하고 `endpoint`, `http_method`, `status_code` 태그와 `duration_ms`<br>4xx는 미전송 |
| 인증 수준과 귀속 | 불필요 경로의 만료와 위조 토큰, 선택 경로의 회원 귀속과 간편 제작 진행 가로채기, 동의 게이트 허용 목록 | 401 없음, 회원 귀속, 미동의 회원 403 |
| 디바이스 ID 해시 | 원본 디바이스 ID | 해시만 기록, 원문 미보관 |
| AI 호출 기록 | 성공, 실패, MDC `unknown`, 컬럼 길이 초과 | `SUCCEEDED` 또는 `FAILED` 적재, 실패 예외 전파, `meta` 반영, 잘라서 적재 |
| 지표 outcome | 성공, 502, 경쟁 409, AI 전 4xx | `success`, `failure`, `rejected` 구분, 회수 재구성은 타이머 미기록 |
