# 3-3 STORY 화면 표현

기준: [화면 흐름](3-2-INTERACTION-FLOWS.md), [화면 구성](3-1-INFORMATION-ARCHITECTURE.md).

### 3-3-1 홈과 제작 목록

| 영역 | 표현 |
|---|---|
| 홈 목록 | 별도 섹션 제목 없이 두 열 그리드. 이미지가 없으면 기본 심벌 |
| 홈 필터 | 헤더 아래에 붙이며 아래로 스크롤하면 숨고 위로 스크롤하거나 맨 위에 가까우면 보인다. 높이와 목록 위치를 바꾸지 않는다 |
| 필터와 정렬 | 전체와 오리지널 단일 선택 칩, 오른쪽 고정 정렬 버튼. 좁으면 칩만 가로 스크롤. 선택한 정렬은 체크하고 선택 뒤 닫는다 |
| 홈 카드 | 표지 아래 제목과 @작성자 각각 한 줄 말줄임, 동일 높이. 턴 수는 표지 배지, 오리지널 표시는 대상 카드에만 표시 |
| 제작 카드 | 패딩을 포함한 전체 영역이 클릭 대상. 제목과 한 줄 소개 최대 두 줄, 장르 한 줄과 넘친 개수 +N. 집계가 넘치면 배지 단위 줄바꿈 |
| 집계 | 1,000 미만은 원값, 이상은 K와 M 단위 소수점 한 자리 버림. 누락된 수는 0 |
| 메타 | 공개 범위 다음 제작일. 모르는 공개 범위는 생략. 당일은 기기 시간대의 경과 시간으로 방금 전, 분, 시간, 그 외는 KST 날짜 |
| 진행 카드 날짜 | 처음 임시 저장 시각을 KST `yyyy-MM-dd HH:mm`으로 표시. 초안은 버튼 위, 완성 중은 본문 아래. 시각 없는 이전 기록은 생략 |
| 로딩 | 첫 조회는 상단 진행 표시와 지연 스켈레톤. 홈은 카드 6개, 지연 전 빈 영역. 다음 페이지는 하단 스피너 |
| 빈 상태 | 홈 “아직 스토리가 없어요”, 제작 “아직 만든 스토리가 없어요”. 제작은 FAB 유지 |
| 오류 | “스토리를 불러오지 못했어요”와 다시 시도. 다음 페이지 실패는 기존 목록 아래 재시도 |
| 옵션 | 대상 종류 “내가 만든 스토리”, “채팅”, “만들던 스토리”와 제목. 가능한 수정, 신고, 삭제 순서 |

### 3-3-2 상세와 이미지

| 영역 | 표현 |
|---|---|
| 히어로 | 3:4 표지, 없으면 회색 기본 심벌. 표지 위 좋아요 수와 턴 수 배지 |
| 헤더 | 히어로 위에 겹쳐 배경을 투명에서 기본 바탕으로 연속 전환한다. 이미지가 있으면 흰 아이콘에서 기본 전경색으로, 없으면 처음부터 기본 전경색. 로딩과 오류는 불투명 |
| 제목 | 본문 제목이 헤더 아래로 가려지면 같은 제목을 페이드로 표시한다. 늦게 본문을 받아도 동작한다 |
| 시작 | 주인공 선택 다음 시작 상황 선택. “선택된 시작 상황을 바탕으로 스토리가 진행돼요”. 시작 상황은 CHAT의 장면 표현을 사용한다 |
| 엔딩 | 선택한 시작 상황의 엔딩 이름과 “엔딩은 시작 상황마다 달라져요”. 조건과 에필로그는 숨긴다 |
| 인물 선택 | 한 명이면 큰 카드만 표시. 두 명 이상이면 섹션 제목 16px 아래 4:3 썸네일, 간격 8px, 약 3.5개가 보이는 가로 줄과 가장자리 페이드 |
| 선택 썸네일 | 기본 전경색 2px 테두리, 미선택 불투명도 50%. 테두리와 불투명도를 함께 전환하고 눌림 확대를 두지 않는다. 선택 항목을 가운데로 이동하되 좌우 16px 경계 유지 |
| 인물 카드 | 썸네일 아래 8px, 모서리 20px, 4:3 이미지. 두 명 이상이면 좌우 가운데 반투명 원형 화살표, 첫 항목의 이전과 마지막의 다음은 숨김 |
| 인물 본문 | 이미지 아래 구분선, 가로 16px와 세로 14px. 이름 아래 4px 간격의 14px 일반 글자 소개. 소개가 없으면 생략 |
| 메타 | 앞 내용에서 16px, 섹션 간 32px. 작성자에는 @를 붙이지 않고 제작일은 KST. 소유자만 공개 범위 표시 |
| 새 채팅 CTA | “새 채팅 시작하기” 14px. 아래 11px 흐린 보조 줄에 페르소나와 시작 상황. 각각 최대 5자와 10자 뒤 말줄임, 시작 상황이 없으면 해당 부분 생략 |
| 좋아요 | CTA 왼쪽과 간격 16px. 미선택 윤곽선과 선택 빨간 채움. 판정 전 비활성으로 폭을 유지하고 소유 스토리로 확정되면 숨김 |
| 시작 중 | 기존 버튼 문구와 크기를 유지하며 스피너와 비활성 상태로 표시 |
| 없는 상세 | “스토리를 찾을 수 없어요”. 재시도는 두지 않는다 |
| 뷰어 | 닫기 X, 바깥 클릭과 뒤로가기. 두 번 탭하면 지점을 기준으로 2.5배, 다시 하면 복원. 핀치는 1~5배, 이동은 이미지 경계 안으로 제한 |

### 3-3-3 제작 선택과 간편 제작

| 영역 | 표현 |
|---|---|
| 제작 선택 | 헤더 “스토리 제작”. 간편 제작 “키워드만 고르면 AI가 이미지까지 담긴 스토리를 완성해드려요”, 일반 제작 “스토리 설정, 엔딩 등 스토리에 필요한 내용을 직접 입력해요” |
| 간편 제작 헤더 | “스토리 간편 제작”, 임시 저장, 닫기 X |
| 단계 | 키워드, 스토리라인, 추가 정보 세 칸을 같은 폭으로 표시 |
| 키워드 | 장르 최대 3개, 인물 특징 최대 3개. 필수 라벨에 별표. 카테고리 탭은 같은 폭이며 별도 설명을 반복하지 않는다 |
| 선택 부족 | “키워드를 하나 이상 선택해주세요”. 푸터는 오류가 있을 때만 공간을 늘리고 선택하면 안내를 내린다 |
| 직접 입력 | 빈 값은 “키워드를 입력해주세요”. 추가 버튼은 항상 제공하고 성공이나 닫기 때 오류를 지운다. IME 조합 Enter로 확정하지 않는다 |
| 인물 | 이름 30자 카운터. 기본 정보 “비워두면 랜덤으로 설정해요”, 주변 인물 특징 “선택하지 않으면 랜덤으로 설정해요” |
| 인물 없음 | “주변 인물이 랜덤으로 생성돼요” |
| 중복 이름 | 칸 “이미 사용한 이름이에요”, 푸터 “인물 이름이 겹치지 않게 해주세요” |
| 장르 검색 | “장르 검색 및 선택”, 왼쪽 검색 아이콘과 오른쪽 펼침 표시. 입력 폭의 목록, 선택 체크 |
| 장르 조회 상태 | “장르를 불러오고 있어요”, “검색 결과가 없어요”, “장르를 불러오지 못했어요. 다시 시도” |
| 태그 조회 실패 | “키워드를 불러오지 못했어요. 다시 시도” |
| 스토리라인 | 첫 번째, 두 번째, 세 번째 선택 탭. 선택한 키워드 보기는 “선택한 키워드들이에요”, “이 키워드들을 이용해서 스토리라인 세 개를 만들었어요” |
| 생성 대기 | 순환 문구와 시머, 15초 및 30초 지연 힌트 |
| 추가 정보 | 선택 스토리라인은 처음부터 한 줄로 접고 길이와 무관하게 더보기와 접기를 항상 표시 |
| 자유 입력 | “추가 정보 (최대 10개)”, 초기 빈 행 하나. 행 추가는 스크롤만 이동 |
| 화풍 | 자유 입력 아래 “이미지 스타일”과 필수 별표, 서버 순서로 3열 3:4 미리보기. 이름은 아래 중앙의 흐린 바탕 위, 선택은 primary 테두리 |
| 화풍 조회 상태 | 로딩 자리 표시, 실패 “이미지 스타일 목록을 불러오지 못했어요”와 다시 시도. 이미지 없음은 기본 심벌 |
| 화풍 미선택 | 푸터 “이미지 스타일을 선택해주세요”. 선택하면 제거 |
| 공개 | 이미지 스타일 아래 “공개” 스위치와 “누구나 스토리를 찾아보고 플레이할 수 있어요” |
| 비용 | CTA 위 “스토리 완성 비용”과 “N 이프”. 제작 체험이 남으면 정가 취소선과 “0 이프”, 없으면 정가만 표시 |
| 재선택 확인 | “스토리라인을 바꿀까요?”, “입력한 추가 정보는 모두 사라져요”. 닫기와 파괴적 다시 선택하기 |
| 입력 내용 거절 | “수위가 높아 만들 수 없어요”. 키워드 푸터에 보이고 다음 생성 시 내린다 |

### 3-3-4 일반 제작과 수정 폼

| 영역 | 표현 |
|---|---|
| 헤더 | 신규 “스토리 일반 제작”과 임시 저장 및 닫기. 수정 “스토리 수정”과 닫기만 표시 |
| 탭 | 일곱 탭 한 줄 가로 스크롤. 주요 사건 외 필수 항목이 있는 탭에는 별표 |
| 하단 | 첫 탭 다음, 마지막 이전과 등록하기, 나머지 이전과 다음. 수정 마지막은 저장하기, 진행 중 저장하는 중 |
| 이미지 | 왼쪽 미리보기와 오른쪽 이미지 추가, 변경과 삭제. 표지 “3:4 비율의 이미지를 추천해요”, 인물 “4:3 비율의 이미지를 추천해요”, 다음 줄 “(JPG, PNG, WEBP / 최대 5MB)” |
| 분량 배분 | 묘사 N, 대사 M의 한 줄 슬라이더 |
| 시작 상황 칩 | 빈 이름 “시작 상황 N”, 그 외 공백 제거한 이름 최대 8자와 말줄임. 첫 칩 외 오른쪽 X, 선택 칩 primary 배경. 최대에서 추가 칩 비활성 유지 |
| 반복 항목 | 회색 머리 줄에 이름 또는 순번, N/상한, 접기와 삭제. 접기 버튼은 높이 32px와 글자 12px. 펼친 상태로 시작 |
| 접힌 항목 | 펼치기로 복귀하며 탭과 시작 상황 이동에도 상태 유지. 연속 접힌 머리 줄은 간격 없이 붙인다. 인물 한 명이어도 접기는 제공 |
| 주요 사건 | 위 안내와 사건 추가. 추가한 이름 칸을 스크롤하되 초점 유지. 최대에서 추가 버튼 비활성 유지 |
| 등록 | “장르 (최대 8개)”, 주요 내용, 공개 스위치. 맨 아래 경고 아이콘이 있는 회색 금지 내용 안내 |
| 필수 오류 | 빨간 탭, 오류 테두리와 설명. “{칸 이름}을/를 입력해 주세요”, “추천 입력을 모두 채워 주세요”, “성별을 선택해 주세요”, “장르를 1개 이상 선택해 주세요” |
| 최소 길이 오류 | 한 글자 입력 뒤 칸을 벗어나면 설명 대신 "{칸 이름}은/는 2자 이상 입력해 주세요". 이름, 인물 소개, 특징은 해당 칸 이름 사용. 추천 입력은 설명 한 자리와 해당 칸 오류 테두리. 이름 중복 오류가 우선 |
| 이름 토큰 오류 | "{username}을 쓰려면 이름을 입력해 주세요" |
| 오류 우선순위 | 같은 줄은 이름 오류를 성별보다 먼저 표시. 다른 시작 상황 오류는 칩을 빨갛게 표시. 첫 등록 시도 뒤 편집에 따라 바로 갱신 |
| 삭제 확인 | “작성한 내용을 삭제할까요?”, “삭제하면 작성한 내용이 사라져요”, 그대로 두기와 삭제하기 |

### 3-3-5 저장과 실패 문구

| 상황 | 제목과 설명 또는 안내 |
|---|---|
| 저장 성공 | “임시 저장했어요” |
| 새 제작 상한 | “만들고 있는 스토리는 5개까지 둘 수 있어요” |
| 서버 초안 상한 | “임시 저장은 5개까지 할 수 있어요” |
| 용량 초과 | “내용이 길어서 임시 저장하지 못했어요” |
| 저장 실패 | “작성 내용을 저장하지 못했어요” |
| 불러오기 실패 | “작성 내용을 불러오지 못했어요”와 다시 시도 |
| 초안 없음 | “만들던 스토리를 찾지 못했어요” |
| 저장 충돌 | “다른 곳에서 먼저 저장한 내용이 있어요”, “지금 내용으로 저장하면 다른 곳에서 저장한 내용은 사라져요”. 남겨두기와 파괴적 저장하기 |
| 저장 전 이탈 | “임시 저장하지 않은 내용이 있어요”, “지금 나가면 입력한 내용이 사라져요”. 닫기와 나가기 |
| 저장 후 편집 이탈 | 같은 제목과 “지금 나가면 임시 저장한 뒤에 만든 내용은 사라져요”. 닫기와 나가기 |
| 저장본만 있을 때 이탈 | “스토리 만들기를 그만둘까요?”, “만들던 내용은 제작 탭의 이어서 만들기에서 계속할 수 있어요”. 계속 만들기와 나가기 |
| 접수 후 이탈 | “스토리 만들기를 그만둘까요?”, “등록을 요청한 내용은 제작 탭에서 확인할 수 있어요”. 계속 만들기와 나가기 |
| 접수 뒤 수정 후 이탈 | “등록하지 않은 수정 내용이 있어요”, “지금 나가면 등록을 요청한 뒤에 고친 내용은 사라져요”. 닫기와 나가기 |
| 수정 이탈 | “저장하지 않은 내용이 있어요”, “지금 나가면 수정한 내용이 사라져요”. 닫기와 나가기 |
| 이미지 형식과 크기 | “JPG, PNG, WEBP 이미지만 올릴 수 있어요”, “5MB 이하 이미지만 올릴 수 있어요” |
| 이미지 업로드 실패 | “이미지를 올리지 못했어요” |
| 등록 이미지 오류 | “이미지 크기나 장수를 줄여 주세요”, “올린 이미지를 찾지 못했어요. 이미지를 다시 올려 주세요” |
| 생성과 채팅 실패 | “스토리를 완성하지 못했어요”, “채팅을 시작하지 못했어요” |

### 3-3-6 초안과 제출본 표현

| 상태 | 표현 |
|---|---|
| 간편 제작 초안 | “만들고 있는 스토리”, “이어서 만들기” |
| 키워드 초안 | “키워드를 선택하고 있었어요” |
| 생성 중 | “스토리라인을 만들고 있어요” |
| 선택 초안 | “스토리라인을 선택하고 있었어요” |
| 추가 정보 초안 | “추가 정보를 입력하고 있었어요”. 서버 초안은 선택 본문 최대 두 줄, 없으면 선택 단계 문구 |
| 일반 제작 초안 | 입력 제목과 한 줄 소개, 표지. 없으면 “만들고 있는 스토리”, “일반 제작으로 만들고 있었어요”, 기본 심벌 |
| 완성 중 | 마스코트 표지와 시머 제목. 플랫폼 문구를 사용하고 버튼과 더보기는 두지 않는다 |
| 초안 삭제 | “만들던 스토리를 삭제할까요?” 확인 |
| 검토 중 카드 | “검토 중”, “검토가 끝나면 알려드릴게요”. 주 동작 없이 등록 취소 |
| 반려 카드 | “반려”, 사유 개수 또는 “내용을 수정해 다시 등록해 주세요”. 수정하기와 삭제 |
| 실패 카드 | “검토 실패”, 이미지 문제는 “이미지를 바꿔 다시 등록해 주세요”, 그 외 다시 등록 안내 |
| 등록 취소 확인 | “등록을 취소할까요?”, “검토 중인 스토리를 지우고 등록을 취소해요”. 성공 “등록을 취소했어요” |
| 제출본 삭제 확인 | “스토리를 삭제할까요?”, “삭제하면 입력한 내용이 사라져요” |
| 검토 시작 | “스토리를 검토하고 있어요” |
| 등록 반려와 실패 토스트 | “스토리가 검토를 통과하지 못했어요” |
| 반려 폼 | “검토를 통과하지 못했어요”, “표시된 곳을 고쳐 다시 등록해 주세요” |
| 실패 폼 | “검토를 마치지 못했어요”, 이미지 오류는 “표시된 이미지를 바꿔 다시 등록해 주세요”, 그 외 “검토 중 문제가 생겼어요. 다시 등록해 주세요” |
| 사유 없음 | “등록할 수 없는 내용이 있어요” |
| 이미지 사유 | 형식 “이미지 형식이나 크기를 확인해 주세요”, 읽기 “이미지를 읽을 수 없어요. 다른 이미지로 바꿔 주세요”, 그 외 “이미지를 확인하지 못했어요. 다른 이미지로 바꿔 주세요” |
| 특정 칸 없는 사유 | 해당 탭은 빨갛게 표시하고 폼 위에 “{탭 이름}: 사유”. 알 수 없는 경로는 사유만 목록 표시 |
| 수정 결과 | 성공 “스토리를 수정했어요”. 반려와 실패 안내의 “다시 등록해 주세요”는 “다시 저장해 주세요”로 변경 |
| 검토 중 수정 | “수정 내용을 검토하고 있어요”, “검토가 끝나면 다시 수정할 수 있어요” |
| 지연 | 신규 “검토가 늦어지고 있어요. 끝나면 제작 탭에 추가돼요”, 수정 “검토가 늦어지고 있어요. 끝나면 스토리에 반영돼요” |
| 오류 | 등록 “스토리를 등록하지 못했어요”, 수정 “스토리를 수정하지 못했어요”, 검토 중 충돌 “아직 검토 중이에요” |
