### 3-3-1 홈과 제작 목록

| 영역 | 표현 |
|---|---|
| 홈 목록 | 섹션마다 이름 제목 아래 가로로 넘기는 카드 줄. 한 화면에 카드 두 장이 보이고 셋째 카드는 표지 가장자리 16px만 보여 옆으로 넘길 수 있음을 알린다. 더 보기 없음 |
| 탐색 목록 | 별도 섹션 제목 없이 화면 좌우 끝까지 붙인 두 열 그리드([C-022](DECISIONS.md#c-022)) |
| 탐색 타일 | 위에 3:4 표지를 모서리 없이 채우고 아래에 검은 글 영역을 붙인다. 표지 아래쪽은 그 검정으로 옅어지는 덮개로 잇고, 글 영역에 제목 한 줄, 한 줄 소개 두 줄과 장르 배지 한 줄을 둔다. 소개와 장르는 비어도 자리를 지켜 모든 타일 높이가 같다. 턴 수 배지와 작성자는 두지 않고 오리지널은 왼쪽 위 태그. 이미지가 없으면 기본 심벌 |
| 탐색 새로 섞기 | 칸 자리는 그대로 두고 칸마다 이전 표지 위에 새 표지를 겹쳐 바꾼다. 왼쪽 위 칸부터 대각선 순서로 퍼진다. 새 표지는 이미지를 받은 뒤 나타나고 이전 표지는 새 표지가 다 나타난 뒤 걷어 내 빈 칸을 보이지 않는다. 상세 복귀와 다음 페이지는 바로 표시 |
| 홈 카드 | 표지 위에는 왼쪽 위 오리지널 태그와 오른쪽 아래 턴 수 배지를 둔다. 표지 아래 제목 한 줄, 한 줄 소개 두 줄(옆 카드와 높이 맞춤), 장르 배지 한 줄 순서로 크기와 굵기, 색을 한 단계씩 낮춘다. 장르가 한 줄을 넘으면 제작 카드와 같이 +N으로 줄인다. 작성자는 두지 않는다. 이미지가 없으면 기본 심벌 |
| 제작 구역 | 진행 중과 내 스토리 순서. 구역 제목 옆에 개수를 작게 둔다. 완성 중 카드는 내 스토리 구역 맨 위에 두고 개수에 포함해 완성 교체 때 구역 제목과 개수가 바뀌지 않는다. 카드가 없는 구역은 제목도 두지 않는다 |
| 제작 카드 | 패딩을 포함한 전체 영역이 클릭 대상. 제목과 한 줄 소개 최대 두 줄, 장르 한 줄과 넘친 개수 +N. 집계가 넘치면 배지 단위 줄바꿈 |
| 집계 | 1,000 미만은 원값, 이상은 K와 M 단위 소수점 한 자리 버림. 누락된 수는 0 |
| 메타 | 공개 범위는 표지 왼쪽 위 배지로 두고 공개는 밝은 배지, 비공개는 어두운 배지로 명암만 달리하며 제작일만 오른쪽 아래에 둔다. 모르는 공개 범위는 생략. 당일은 기기 시간대의 경과 시간으로 방금 전, 분, 시간, 그 외는 KST 날짜 |
| 진행 카드 날짜 | 처음 임시 저장 시각을 KST `yyyy-MM-dd HH:mm`으로 표시. 초안은 버튼 위, 완성 중은 본문 아래. 시각 없는 이전 기록은 생략 |
| 로딩 | 첫 조회는 상단 진행 표시와 지연 스켈레톤. 홈은 섹션 2개와 섹션마다 카드 3장, 탐색은 타일과 같은 높이의 칸 12장, 지연 전 빈 영역. 탐색 다음 페이지는 하단 스피너 |
| 빈 상태 | 홈과 탐색 “아직 스토리가 없어요”, 제작 “아직 만든 스토리가 없어요”. 홈은 카드가 있는 섹션이 없을 때 표시. 제작은 FAB 유지 |
| 오류 | “스토리를 불러오지 못했어요”와 다시 시도. 다음 페이지 실패는 기존 목록 아래 재시도 |
| 옵션 | 대상 종류 “내가 만든 스토리”, “채팅”, “만들던 스토리”와 제목. 가능한 수정, 신고, 삭제 순서 |

### 3-3-2 상세와 이미지

| 영역 | 표현 |
|---|---|
| 히어로 | 3:4 표지, 없으면 회색 기본 심벌. 표지 위 좋아요 수와 턴 수 배지 |
| 헤더 | 히어로 위에 겹쳐 배경을 투명에서 기본 바탕으로 연속 전환한다. 이미지가 있으면 흰 아이콘에서 기본 전경색으로, 없으면 처음부터 기본 전경색. 로딩과 오류는 불투명 |
| 제목 | 본문 제목이 헤더 아래로 가려지면 같은 제목을 페이드로 표시한다. 늦게 본문을 받아도 동작한다 |
| 시작 | 주인공 선택 다음 시작 상황 선택. 주인공 선택의 기본 항목은 “스토리 기본 주인공”. 주인공 선택 목록은 다섯 줄 남짓 높이를 넘으면 그 안에서 스크롤하고 “페르소나 생성하기”는 구분선 아래에 고정한다. 주인공 선택 안내는 “선택한 페르소나가 되어 스토리를 진행해요. 채팅을 시작하기 전까지 바꿀 수 있어요”. 시작 상황 안내는 “선택된 시작 상황을 바탕으로 스토리가 진행돼요”. 시작 상황은 CHAT의 장면 표현을 사용한다 |
| 엔딩 | 선택한 시작 상황의 엔딩 이름과 “엔딩은 시작 상황마다 달라져요”. 조건과 에필로그는 숨긴다 |
| 인물 선택 | 한 명이면 큰 카드만 표시. 두 명 이상이면 섹션 제목 16px 아래 4:3 썸네일, 간격 8px, 약 3.5개가 보이는 가로 줄과 가장자리 페이드 |
| 선택 썸네일 | 기본 전경색 2px 테두리, 미선택 불투명도 50%. 테두리와 불투명도를 함께 전환하고 눌림 확대를 두지 않는다. 선택 항목을 가운데로 이동하되 좌우 16px 경계 유지 |
| 인물 카드 | 썸네일 아래 8px, 모서리 20px, 4:3 이미지. 두 명 이상이면 좌우 가운데 반투명 원형 화살표, 첫 항목의 이전과 마지막의 다음은 숨김 |
| 인물 본문 | 이미지 아래 구분선, 가로 16px와 세로 14px. 이름 아래 4px 간격의 14px 일반 글자 소개. 소개가 없으면 생략 |
| 메타 | 앞 내용에서 16px, 섹션 간 32px. 작성자에는 @를 붙이지 않고 제작일은 KST. 소유자만 공개 범위 표시 |
| 새 채팅 CTA | “새 채팅 시작하기” 한 줄. 누르면 시작 시트를 열고, 고른 페르소나와 시작 상황은 버튼에 반복하지 않는다 |
| 시작 시트 | 제목 “이대로 시작할까요?”, 설명 “페르소나와 시작 상황은 시작하기 전까지 바꿀 수 있어요”. 둥근 회색 카드 하나에 페르소나와 시작 상황 행을 구분선으로 나누고, 아래에 전체 폭 “채팅 시작하기” |
| 시작 시트 행 | 흐린 라벨 아래 굵은 값, 오른쪽 펼침 화살표. 시작 상황은 값 아래 상황 설명 글을 두 줄까지 보인다. 펼치면 값 대신 선택지 목록을 보이고 고른 항목은 본문 Select처럼 배경을 깔고 기본 글자색과 체크. 목록은 다섯 줄 남짓 높이를 넘으면 그 안에서 스크롤하고, 열 때 고른 항목이 보이도록 맞춘다. 펼치고 접을 때 높이가 부드럽게 바뀐다. 페르소나 목록 아래에는 글자 시작선에 맞춘 구분선과 더하기 아이콘의 “페르소나 생성하기”를 고정해 목록을 스크롤해도 그대로 둔다. 선택지 사이는 본문 Select처럼 조금 띄운다. 시작 상황이 하나뿐이면 화살표 없이 펼치지 않는다 |
| 좋아요 | CTA 왼쪽과 간격 16px. 미선택 윤곽선과 선택 빨간 채움. 판정 전 비활성으로 폭을 유지하고 소유 스토리로 확정되면 숨김 |
| 시작 중 | 시트의 “채팅 시작하기”가 문구와 크기를 유지하며 스피너와 비활성 상태로 바뀌고, 그동안 시트를 닫지 않는다 |
| 없는 상세 | “스토리를 찾을 수 없어요”. 재시도는 두지 않는다 |
| 뷰어 | 닫기 X, 바깥 클릭과 뒤로가기. 두 번 탭하면 지점을 기준으로 2.5배, 다시 하면 복원. 핀치는 1~5배, 이동은 이미지 경계 안으로 제한 |

### 3-3-3 제작 선택과 간편 제작

| 영역 | 표현 |
|---|---|
| 제작 선택 | 헤더 “스토리 제작”. 간편 제작 “키워드만 고르면 AI가 이미지까지 담긴 스토리를 완성해드려요”, 일반 제작 “스토리 설정, 엔딩 등 스토리에 필요한 내용을 직접 입력해요” |
| 간편 제작 헤더 | “스토리 간편 제작”, 임시 저장, 닫기 X |
| 단계 | 키워드, 스토리라인, 추가 정보 세 칸을 같은 폭으로 표시 |
| 키워드 | 장르 최대 3개, 인물 특징 최대 3개. 필수 라벨에 별표. 카테고리 탭은 같은 폭이며 별도 설명을 반복하지 않는다 |
| 선택 부족 | “키워드를 하나 이상 선택해주세요”. 푸터는 오류가 있을 때만 공간을 늘리고 선택하면 안내를 내린다 |
| 직접 입력 | 빈 값은 “키워드를 입력해주세요”. 추가 버튼은 항상 제공하고 성공이나 닫기 때 오류를 지운다. IME 조합 Enter로 확정하지 않는다 |
| 인물 | 이름 30자 카운터. 기본 정보 “비워두면 랜덤으로 설정해요”, 주변 인물 특징 “선택하지 않으면 랜덤으로 설정해요” |
| 인물 없음 | “주변 인물이 랜덤으로 생성돼요” |
| 중복 이름 | 칸 “이미 사용한 이름이에요”, 푸터 “인물 이름이 겹치지 않게 해주세요” |
| 장르 검색 | “장르 검색 및 선택”, 왼쪽 검색 아이콘과 오른쪽 펼침 표시. 입력 폭의 목록, 선택 체크 |
| 장르 조회 상태 | “장르를 불러오고 있어요”, “검색 결과가 없어요”, “장르를 불러오지 못했어요. 다시 시도” |
| 태그 조회 실패 | “키워드를 불러오지 못했어요. 다시 시도” |
| 스토리라인 | 첫 번째, 두 번째, 세 번째 선택 탭. 선택한 키워드 보기는 “선택한 키워드들이에요”, “이 키워드들을 이용해서 스토리라인 세 개를 만들었어요” |
| 생성 대기 | 순환 문구와 시머, 15초 및 30초 지연 힌트 |
| 추가 정보 | 선택 스토리라인은 처음부터 한 줄로 접고 길이와 무관하게 더보기와 접기를 항상 표시 |
| 자유 입력 | “추가 정보 (최대 10개)”, 초기 빈 행 하나. 행 추가는 스크롤만 이동 |
| 화풍 | 자유 입력 아래 “이미지 스타일”과 필수 별표, 서버 순서로 3열 3:4 미리보기. 이름은 아래 중앙의 흐린 바탕 위, 선택은 primary 테두리 |
| 화풍 조회 상태 | 로딩 자리 표시, 실패 “이미지 스타일 목록을 불러오지 못했어요”와 다시 시도. 이미지 없음은 기본 심벌 |
| 화풍 미선택 | 푸터 “이미지 스타일을 선택해주세요”. 선택하면 제거 |
| 공개 | 이미지 스타일 아래 “공개” 스위치와 “누구나 스토리를 찾아보고 플레이할 수 있어요” |
| 비용 | CTA 위 “스토리 완성 비용”과 “N 이프”. 제작 체험이 남으면 정가 취소선과 “0 이프”, 없으면 정가만 표시 |
| 재선택 확인 | “스토리라인을 바꿀까요?”, “입력한 추가 정보는 모두 사라져요”. 닫기와 파괴적 다시 선택하기 |
| 입력 내용 거절 | “수위가 높아 만들 수 없어요”. 키워드 푸터에 보이고 다음 생성 시 내린다 |

### 3-3-4 일반 제작과 수정 폼

| 영역 | 표현 |
|---|---|
| 헤더 | 신규 “스토리 일반 제작”과 임시 저장 및 닫기. 수정 “스토리 수정”과 닫기만 표시 |
| 탭 | 일곱 탭 한 줄 가로 스크롤. 주요 사건 외 필수 항목이 있는 탭에는 별표 |
| 하단 | 첫 탭 다음, 마지막 이전과 등록하기, 나머지 이전과 다음. 수정 마지막은 저장하기, 진행 중 저장하는 중 |
| 이미지 | 왼쪽 미리보기와 오른쪽 이미지 추가, 변경과 삭제. 표지 “3:4 비율의 이미지를 추천해요”, 인물 “4:3 비율의 이미지를 추천해요”, 다음 줄 “(JPG, PNG, WEBP / 최대 5MB)” |
| 분량 배분 | 묘사 N, 대사 M의 한 줄 슬라이더 |
| 시작 상황 칩 | 빈 이름 “시작 상황 N”, 그 외 공백 제거한 이름 최대 8자와 말줄임. 첫 칩 외 오른쪽 X, 선택 칩 primary 배경. 최대에서 추가 칩 비활성 유지 |
| 반복 항목 | 회색 머리 줄에 이름 또는 순번, N/상한, 접기와 삭제. 접기 버튼은 높이 32px와 글자 12px. 펼친 상태로 시작 |
| 접힌 항목 | 펼치기로 복귀하며 탭과 시작 상황 이동에도 상태 유지. 연속 접힌 머리 줄은 간격 없이 붙인다. 인물 한 명이어도 접기는 제공 |
| 주요 사건 | 위 안내와 사건 추가. 추가한 이름 칸을 스크롤하되 초점 유지. 최대에서 추가 버튼 비활성 유지 |
| 등록 | “장르 (최대 8개)”, 주요 내용, 공개 스위치. 맨 아래 경고 아이콘이 있는 회색 금지 내용 안내 |

장르는 생성 요청의 선택 순서로 쉼표로 잇고 마지막 이름의 받침에 따라 으로와 로를 고른다. 받침이 없거나 ㄹ이거나 한글이 아니면 로다. 장르 이름을 얻지 못하면 “장르”를 넣는다.

대화창은 화면 가운데의 카드이며 뒤 화면을 딤으로 덮어 조작을 막는다. 좌상단 둥근 프로필에서 마냑 마스코트가 말하듯 움직이고 동작 줄이기에서는 서 있는 첫 자세로 멈춘다. 프로필 옆에 이름 “마냑”과 대사를 두고 대사는 두 줄 문구를 한 번에 보인다. 보조 버튼은 배경 없는 글자 버튼, 주 버튼은 오른쪽이다. 단계가 바뀌면 대화창을 유지한 채 문구만 바꾼다. 대화창 접근 가능한 이름은 “스토리 만들기 안내”이고 마스코트는 장식이다.
