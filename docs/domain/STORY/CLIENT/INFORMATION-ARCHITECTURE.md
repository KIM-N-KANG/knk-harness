# STORY 화면 구성

기준: [요구사항](REQUIREMENTS.md).

<br>

### 화면과 진입

| 화면 | 진입 | 정보 순서와 접근 조건 |
|---|---|---|
| 홈 | 메인 홈 탭 | 필터와 정렬, 공개 스토리 그리드. 새 제작과 내 스토리는 제작 탭에 둔다 |
| 제작 | 메인 제작 탭 | 초안과 생성 중 기록, 신규 검수 제출본, 완성 중 요청, 내 스토리. 새 제작 FAB |
| 스토리 상세 | 홈과 제작 카드, 공유와 외부 링크 | 표지와 제목, 소개와 장르, 엔딩 이력, 주요 내용, 주인공과 시작 상황, 주변 인물, 작성자와 제작일. 하단 새 채팅 CTA |
| 이미지 뷰어 | 상세 표지나 인물 이미지 | 원본 이미지와 닫기. 상세 위에서 연다 |
| 제작 방식 선택 | 제작 FAB | 간편 제작과 일반 제작. 일반 제작은 회원만 진입한다 |
| 간편 제작 | 새 제작 또는 초안 이어서 만들기 | 키워드, 스토리라인, 추가 정보의 세 단계. 완성은 제출 동작이며 편집 단계가 아니다 |
| 일반 제작 | 제작 방식 선택 또는 초안 | 스토리 프로필, 스토리 설정, 주인공(나), 주변 인물, 시작 상황 설정, 주요 사건, 등록의 일곱 탭 |
| 제출본 재제출 | 제작 탭 반려와 실패 카드 | 접수된 입력과 사유를 같은 일반 제작 폼에 표시한다 |
| 스토리 수정 | 소유 스토리 카드와 상세의 옵션 | 일반 제작과 같은 탭. 임시 저장 없이 기존 값과 변경을 구분한다 |
| 웹 제작 안내 | 해당 제작 단계 또는 완성 중 카드 | 인사, 키워드, 스토리라인, 추가 정보, 완성 중의 순서 |
| Android 가입 온보딩 | 신규 가입 완료 | 오리지널 스토리 캐러셀과 채팅 시작, 직접 만들기 |

페르소나 관리는 ACCOUNT, 신고는 MODERATION, 채팅방과 공유본은 CHAT 화면이다.

<br>

### 목록과 옵션

| 대상 | 정보와 동작 |
|---|---|
| 홈 카드 | 표지, 턴 수, 제목, 작성자. 카드 옵션을 두지 않는다 |
| 내 스토리 카드 | 표지, 제목, 한 줄 소개, 장르, 집계, 공개 범위와 제작일 |
| 초안 카드 | 표지나 기본 심벌, 제목과 중단 단계, 최초 저장 시각, 이어서 만들기, 더보기 삭제 |
| 완성 중 카드 | 대기 표지, 제목과 안내, 최초 저장 시각. 버튼과 더보기를 두지 않는다 |
| 검수 제출본 | 입력 제목과 표지, 상태, 등록 시각과 사유 요약. 검토 중은 등록 취소, 반려와 실패는 수정하기 및 삭제 |
| 옵션 시트 | 대상 종류와 제목, 가능한 수정하기, 신고하기, 삭제 순서. 동작이 없으면 진입점을 숨긴다 |

초안과 생성 중 묶음, 완성 중 묶음은 각각 최초 저장 시각 최신순이다. 시각 없는 이전 기록은 뒤에 둔다. 제출본은 등록 요청 최신순이다.
