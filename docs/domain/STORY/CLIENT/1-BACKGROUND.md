# 1 STORY 클라이언트 배경

<br>

### 1-1 사용자와 목적

사용자는 공개된 스토리를 탐색하거나 직접 만든 스토리를 관리하고, 설정과 인물을 확인한 뒤 원하는 시작 상황으로 채팅한다. 제작할 때는 키워드로 AI의 도움을 받거나 설정을 직접 작성한다. 여러 제작을 병행하고 화면을 떠나더라도 저장한 입력과 접수된 요청을 구분해 이어갈 수 있어야 한다.

| 범위 | 책임 |
|---|---|
| STORY | 홈 탐색, 제작 탭, 상세, 간편 제작과 일반 제작, 수정, 초안과 생성 복구, 좋아요 |
| ACCOUNT | 회원과 게스트, 소유 목록, 로그인과 동의, 페르소나 관리 |
| CHAT | 채팅방의 플레이와 진행, 공유본 열람 |
| PAYMENT | 제작 비용과 체험, 이프 부족과 충전 |
| MODERATION | 금지 내용과 검수 기준, 신고. STORY는 결과에 따른 제작 화면을 담당 |
| NOTIFICATION | 제작 완료와 검수 결과 알림의 전달 |
| BACKEND와 AI | 공개와 소유권 판정, 저장, 생성, 입력 검증과 검수 실행 |

<br>

### 1-2 용어

| 용어 | 의미 |
|---|---|
| 탐색 | 홈에서 공개된 스토리를 찾아보는 이용 |
| 제작 탭 | 내가 만든 스토리, 저장한 초안과 진행 중 제작을 관리하는 곳 |
| 간편 제작 | 키워드, 스토리라인, 추가 정보로 스토리를 완성하는 방식 |
| 일반 제작 | 설정, 인물, 시작 상황과 엔딩을 폼에 직접 작성하는 방식 |
| 초안 | 사용자가 저장하여 이어서 편집할 수 있는 입력 |
| 진행 기록 | 생성 요청과 결과를 복구하기 위해 기기에 남기는 기록 |
| 제출본 | 일반 제작 등록이나 수정 요청을 서버가 접수한 입력과 검수 상태 |
