# 3-2 화면 흐름: 안드로이드

기준: [공통 흐름](../3-2-INTERACTION-FLOWS.md), [Android 화면](3-1-INFORMATION-ARCHITECTURE.md).

### 3-2-1 제작과 상세

| 조작 | 결과 |
|---|---|
| 키워드에서 생성 | 키워드 목적지를 스토리라인 목적지로 대체 |
| 추가 정보의 다시 선택하기 | 손실 확인 후 스토리라인으로 복귀. 일반 뒤로가기로 키워드 편집에 돌아가지 않음 |
| 헤더 닫기와 시스템 뒤로가기 | 퍼널 이탈 확인. 잃을 것이 없으면 제작 탭으로 즉시 복귀 |
| 스토리라인 내용 거절 | 같은 초안의 키워드 목적지로 교체. 거절된 요청의 선택 입력을 미저장 편집으로 채움 |
| 추가 정보 조작 | 추가와 삭제, 추천 토글 및 스토리라인 접기는 키보드 유지. 입력 삭제는 다음 칸, 없으면 이전 칸으로 초점 이동. 마지막 삭제와 본문 빈 곳 탭은 키보드 닫기 |
| 일반 제작 승인 | 폼을 닫고 상세 위에 채팅방. 채팅 생성 실패는 상세 |
| 수정 완료 | 진입했던 상세 또는 제작 탭으로 돌아가 갱신 |
| 카드 더보기와 길게 누르기 | 같은 옵션 시트. 옵션을 닫고 삭제 확인 또는 신고를 연다 |
| 상세 삭제 | 메인 셸까지 정리하고 제작 탭 선택 |
| 저장 충돌 | 일반 제작 보조는 남겨두기, 간편 제작 보조는 닫기. 저장하기는 파괴적 동작이며 성공 토스트 표시 |

<br>

### 3-2-2 가입 온보딩

1. 좌우로 넘기거나 옆 카드를 눌러 가운데 스토리를 바꾼다. 마지막 다음에 첫 스토리로 이어지며 한 편이면 넘기지 않는다.
2. 가운데 카드나 상세 보기는 상세를 온보딩 위에 연다. 상세 뒤로가기는 온보딩이다.
3. 채팅 시작하기는 가운데 스토리의 기본 시작 설정과 기본 주인공으로 하나의 채팅을 만든다. 실패하면 토스트와 함께 온보딩을 유지한다.
4. 바로 채팅을 시작하면 뒤로가기는 홈이다. 상세에서 채팅을 시작하면 뒤로가기는 해당 상세, 그 다음은 홈이다.
5. 직접 만들기는 새 간편 제작을 열고 온보딩을 완료한다. 퍼널 이탈과 제출은 제작 탭으로 돌아간다.
6. 완료 전 시스템 뒤로가기는 앱을 떠난다. 외부 링크 화면을 닫으면 온보딩으로 돌아온다.
