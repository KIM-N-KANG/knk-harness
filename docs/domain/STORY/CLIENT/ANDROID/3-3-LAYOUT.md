### 3-3-1 목록과 제작

| 요소 | 표현 |
|---|---|
| 홈 섹션 | 셸 여백 바로 아래에서 시작해 섹션 사이 32dp, 마지막 아래 16dp. 이름은 titleLarge 한 줄 말줄임, 카드 줄과 12dp. 카드가 셋 이상이면 이름 줄 오른쪽 끝에 이전, 다음 화살표를 둔다. backgroundNeutral 원 28dp에 16dp 꺾쇠, 사이 4dp, 넘길 곳이 없는 방향은 불투명도 40%로 끈다. 누르면 카드 한 장씩 부드럽게 넘겨 카드 시작점에 맞추고, 넘기는 중에 다시 누르면 가던 목적지에서 한 장 더 간다. 시스템 애니메이션 배율이 0이면 바로 옮긴다. 카드 폭은 (줄 폭 − 48dp) ÷ 2, 카드 사이 8dp라 셋째 카드가 오른쪽 끝에 16dp 보인다 |
| 홈 카드 | 표지 아래 제목 bodyLargeStrong 한 줄, 2dp 아래 소개 bodyMedium 두 줄 자리 고정(minLines), 8dp 아래 웹과 같은 높이 20dp의 Compact 장르 뱃지 한 줄. 제목과 소개는 LineBreak.Simple로 글자 단위로 끊는다 |
| 탐색 그리드 | 셸 여백 밖 여백 없이 두 열, 타일 사이 2dp([A-091](DECISIONS.md#a-091)). 타일은 위에 각진 3:4 표지와 폭 72dp ORIGINAL 태그, 아래에 검은 글 영역을 둔다. 표지 아래 절반은 검정에서 위로 감속 곡선 13단계로 옅어지는 덮개로 글 영역과 잇는다. 글 영역은 표지 아래 24dp에 겹쳐 올라가고, 좌우와 아래 12dp 안쪽에 흰 제목 bodyMediumStrong 한 줄, 2dp 아래 흰 80% 소개 bodySmall 두 줄, 6dp 아래 높이 18dp Tiny 장르 뱃지(흰 15% 바탕, 넘치면 +N) 한 줄. 소개와 장르는 비어도 자리를 지켜 모든 타일 높이가 같다. 턴 수와 작성자는 없다. 골격은 같은 높이의 칸 12장. 화면 읽기는 타일 하나를 제목과 오리지널 표시로 읽는다 |
| 탐색 새로 섞기 | 칸 순번으로 자리를 지키고 칸 안에서 새 표지를 그림을 받은 뒤 불투명도 0, 크기 96%에서 420ms로 겹친다. 두 열 기준 대각선 한 칸마다 45ms, 최대 450ms 늦추고 이전 표지는 새 표지가 다 나타난 뒤 걷는다. 시스템 애니메이션 배율이 0이면 지연 없이 바로 바뀐다 |
| 제작 구역 | 구역 제목 bodyLargeStrong과 6dp 옆 개수 labelLarge를 세로 가운데로 맞추고, 위 8dp(내 스토리가 진행 중 뒤에 오면 24dp), 아래 4dp. 공개 범위 뱃지는 표지 왼쪽 위 8dp의 Compact 알약이고 공개는 흰 90% 바탕과 검은 글자, 비공개는 흐린 어두운 바탕과 흰 글자 |
| 인물 카드 화살표 | 보이는 원은 32dp 그대로 두고, 누름 영역은 이미지 좌우 끝에서 폭 48dp, 이미지 높이 전체의 세로 띠로 넓힌다. 원은 띠 안에서 좌우 8dp, 세로 가운데. 띠 위에서는 확대 대신 인물을 넘기고 눌림 리플은 원에만 그린다 |
| 상세 하단 | 메타 정보가 보이기 시작하면 CTA와 페이드를 surface에서 backgroundNeutral로 전환. 끝에서는 메타와 같은 색 |
| 채팅 시작 시트 | 시트 위 회색 카드는 다크에서 시트 바탕보다 한 단계 밝은 채움. 고른 선택지는 눌림 리플과 같은 반투명 채움과 체크. 선택지는 48dp 높이로 5줄 반을 넘으면 목록 안에서 스크롤하고 열 때 고른 항목 위 두 칸부터 보인다. 본문을 끌어도 시트는 내려가지 않고 핸들 끌기, 바깥 탭과 뒤로가기로만 닫는다. 생성 중에는 이 셋으로도 닫지 않는다 |
| 상세 셀렉트 메뉴 | 항목 최소 40dp, 값 항목은 5줄 반을 넘으면 메뉴 안에서 스크롤. “페르소나 생성하기”는 구분선 아래 흐린 색으로 스크롤 밖에 고정 |
| 표지 없음 | 기본 심벌, backgroundNeutral과 textDisabled. 상세 헤더는 투명에서 surface로, 아이콘은 처음부터 text |
| 카드 옵션 | 대상 종류와 제목, 항목 목록. 카드 축소판을 넣지 않는다 |
| 초안 조회 | 헤더 아래 늦게 나타나는 중앙 스피너, 실패는 같은 자리의 안내와 재시도 |
| 완성 중 | 공통 마스코트 표지와 시머 제목, “스토리가 완성되면 알림으로 알려드려요” |
| 화풍 | 세 칸씩의 행, 이름을 흐린 바탕 위에 표시. RadioButton 역할과 화풍 이름 하나, 바깥 brand 테두리로 선택해 자리 유지 |
| 크롭 | 바텀 시트 검은 판 위 고정 비율 창, 창 밖은 어둡게 표시. 이동과 확대 범위를 구성 변경에 유지 |

### 3-3-2 가입 온보딩

| 영역 | 표현 |
|---|---|
| 헤드라인 | “마음에 드는 스토리를 골라 / 바로 채팅을 시작해보세요” |
| 제작 | “마음에 드는 스토리가 없나요?”와 오른쪽 “직접 만들기” |
| 캐러셀 | 가운데 카드와 양옆 일부. 옆 카드는 축소와 낮은 불투명도 |
| 카드 | 위 표지, 구분선 아래 한 줄 제목과 “상세 보기”, 소개 최대 두 줄 |
| 하단 | “채팅 시작하기” |
| 로딩 | 같은 자리의 카드 골격 |
| 실패 | “스토리를 불러오지 못했어요”와 “다시 시도” |
| 빈 목록 | “지금은 보여드릴 스토리가 없어요”. 직접 만들기는 계속 제공 |
| 낮은 화면 | 캐러셀 높이를 유지하고 화면을 세로 스크롤해 카드가 지나치게 작아지지 않게 함 |

카드 가운데 선택과 진행 요청은 회전, 다크 모드와 글자 크기 변경에도 유지한다.

### 3-3-3 제작 안내

| 요소 | 표현 |
|---|---|
| 창 | 웹 카드와 같은 모양. 검정 50% 딤 위 세로 가운데, 좌우 12dp만 남긴 폭. 모서리 20dp, surface 배경, 안쪽 16dp. 다크 모드에만 1dp 경계 |
| 프로필 | 48dp 원, backgroundBrandSubtle 위 brand 마스코트. 몸은 프로필 폭의 66% |
| 이름과 대사 | 프로필 옆 12dp. “마냑”은 labelLarge와 textBrand, 4dp 아래 대사는 bodyLarge(16sp, 행간 24sp) |
| 버튼 | 대사 아래 16dp의 오른쪽 정렬, 간격 4dp. 보이는 높이 40dp, 보조는 text 색 글자 버튼, 주 버튼은 brand 채움 |
| 모션 | 창 전환 없이 카드가 250ms 동안 0.95배에서 커지며 나타난다. 단계가 바뀌면 창을 유지하고 문구만 200ms 교차 페이드. 마스코트는 5초 동안 두 번 말하고 쉬며 몸을 프로필 폭 3.5%까지 띄우고 좌우 3도 기울인다. 애니메이터 배율이 0이면 서 있는 첫 자세 |
