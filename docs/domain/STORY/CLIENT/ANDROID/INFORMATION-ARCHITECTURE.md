# Android STORY 화면 구성

기준: [공통 화면](../INFORMATION-ARCHITECTURE.md), [Android 요구사항](REQUIREMENTS.md).

<br>

### 목적지

| 목적지 | 진입과 구조 |
|---|---|
| 홈과 제작 | 메인 탭. 제작 FAB에서 방식 선택 |
| 상세 | 목록과 외부 진입. 상세 위 이미지 뷰어와 옵션 시트 |
| 방식 선택 | 간편 제작과 일반 제작. 두 제작 화면은 공용 쌓이는 화면과 같은 수평 이동 |
| 간편 제작 | 키워드, 스토리라인, 추가 정보 각각의 목적지. 같은 초안 ID 공유 |
| 일반 제작 | 새 초안 또는 이어서 만들기, 첫 프로필 탭 |
| 재제출 | 제출본 ID로 입력과 사유 조회 |
| 수정 | 소유 스토리 ID로 편집 폼 조회 |
| 가입 온보딩 | 신규 회원 메인 백스택의 루트. 헤더 뒤로가기, 건너뛰기와 하단 탭 없음 |

초안의 재개 경로와 새로운 제작을 구분한다. 새 제작의 진입은 제작 FAB이며 카드 이어서 만들기는 새 제작 상한으로 막지 않는다.
