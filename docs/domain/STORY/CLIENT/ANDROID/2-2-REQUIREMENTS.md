# 2-2 요구사항: 안드로이드

기준: [공통 요구사항](../2-2-REQUIREMENTS.md).

### 2-2-1 목록과 상세

STORY-US-001부터 STORY-US-006, STORY-US-019, STORY-US-023, STORY-US-024.

| 조건 | Android 적용 |
|---|---|
| 사용자 | 로그인한 회원. 게스트 목록 판별과 로그인 필요 시트는 적용하지 않는다 |
| 홈 섹션 | 탭에 돌아와도 다시 읽지 않고 당겨서 새로고침으로 서버와 맞춘다. 새로고침 실패는 보던 섹션을 두고 토스트로 알린다 |
| 탐색 순서 | 하단 탭으로 다른 탭에서 들어올 때만 새로 섞어 맨 위부터 보인다. 이미 탐색이면 탭을 다시 눌러도, 상세에서 돌아와도, 회전해도 보던 순서와 위치를 유지한다. 프로세스가 다시 시작되면 새 순서다 |
| 스토리 검색 | 탐색 헤더의 검색 버튼으로 셸 위 전체 화면을 연다. 처음 열 때만 입력에 초점을 둔다. 상세에서 돌아오거나 회전해도 입력, 제출한 검색어, 결과와 위치를 유지하고, 프로세스가 다시 시작되면 제출한 검색어로 처음부터 다시 찾는다. 최근 검색어는 기기 파일에 남겨 로그아웃과 계정 전환에도 유지한다 |
| 새로고침 | 목록을 움직이지 않고 표시자만 헤더 아래에서 내린다. 표시자 뒤에 별도 배경을 두지 않는다 |
| 소유권 | 상세 isOwner로 수정과 삭제, 좋아요 비노출을 결정한다. 제목이나 클라이언트 추측은 사용하지 않는다 |
| 좋아요 | 상세의 상태와 수를 즉시 바꾸고 실패하면 복원한다. 요청 중과 응답 후 0.5초 연타를 막는다. 홈에는 좋아요 수를 표시하지 않는다 |
| 상세 복귀 | 턴 수 등을 갱신하되 첫 스켈레톤으로 돌아가지 않는다. 읽던 스크롤 위치는 목적지의 저장 상태로 유지하고, 목록에서 새로 연 상세는 맨 위에서 시작한다 |
| 페르소나 | 같은 상세의 선택은 구성 변경과 채팅 복귀에 유지한다. 채팅 시작 시트의 열림과 펼친 행도 구성 변경에 유지한다. 시트에서 페르소나 생성으로 떠나면 이동 전에 시트를 걷고 복귀 때 다시 연다. 생성 후 미리 선택은 프로세스 메모리이며 재실행 뒤 남지 않는다. 삭제된 페르소나는 복귀 때 기본으로 바꾼다 |
| 이미지 뷰어 | 시스템 뒤로가기는 뷰어만 닫고 없는 이미지는 열지 않는다 |

### 2-2-2 제작 수명과 보존

STORY-US-007부터 STORY-US-018.

| 조건 | Android 적용 |
|---|---|
| 저장 계기 | 저장 버튼과 실제 앱 백그라운드 전환. 탭과 단계 이동, 회전, 테마 변경, 이미지 선택기 왕복은 제외 |
| 저장 버튼 | 요청 중과 성공 뒤 2초 동안 잠근다. 그동안 편집해도 잠금을 유지하며 성공은 토스트로 알리고 모양은 유지 |
| 백그라운드 저장 | 성공과 실패 모두 조용히 처리. 실패는 미저장 상태 유지 |
| 초안 조회 | 새 화면도 프로세스 복원을 위해 조회하지만 없는 초안 안내는 카드로 재개할 때만 표시 |
| 조회 실패 | 헤더 아래 오류와 재시도. 이어 갈 스토리라인이 없으면 같은 초안의 키워드 단계로 새로 시작 |
| 입력 유지 | 폼, 탭, 접기, 삭제 확인, 크롭과 진행 요청은 구성 변경에서 유지. 프로세스 종료는 마지막 저장본 또는 접수 제출본에서 복구 |
| 키워드 저장 | 입력을 모두 지운 뒤 저장하면 초안을 삭제한다. 초기 빈 주변 인물만으로 입력이 있다고 보지 않는다. 재개 카테고리는 첫 탭 |
| 경고 판정 | 활성 스토리라인 탭 변경은 저장할 변경이지만 이탈 시 내용 손실 경고에는 포함하지 않는다. 접기만 변경하는 것은 저장 입력이 아니다 |
| 첫 목록 | 내 스토리, 서버 초안, 제출본을 한 스켈레톤으로 준비하고 기기 완성 요청은 위에 즉시 표시. 복귀 조회는 조용히 갱신 |
| FAB | 로컬 초안이나 완성 요청 카드 또는 제출본이 있으면 서버 목록 오류에도 유지. 로컬 진행이 없는 첫 조회와 오류에는 숨김 |
| 초안 분기 | 다른 곳에서 저장한 서버 카드로 재개할 때 같은 ID의 기존 기기 기록은 별도 기기 초안으로 보존 |
| 계정 변경 | 제작 기록은 소유 계정별 보존. 다른 계정의 기록을 읽거나 덮지 않는다. 같은 계정 재로그인은 이어갈 수 있다 |
| 일반 제작 응답 유실 | 신규 등록을 자동 재전송하지 않고 제작 탭에서 확인하도록 안내 |
| 이미지 | Photo Picker 결과의 실제 형식과 크기를 확인. 업로드 중 등록과 임시 저장을 막고 실패 및 취소는 이전 이미지 유지 |

### 2-2-3 신규 가입 온보딩

STORY-US-021.

처음 가입한 회원은 오리지널 스토리 안내에서 시작한다. 기존 회원 로그인과 저장 세션 시작은 홈이다. 오리지널 채팅순 목록을 돌려보며 선택한 이야기로 채팅하거나 간편 제작을 시작할 수 있다. 목록이 없거나 실패해도 직접 만들기는 허용한다.

채팅 시작 또는 직접 만들기로 완료한다. 완료 전 뒤로가기는 앱 이탈이며 재실행하면 안내로 돌아온다. 알림과 웹 링크는 온보딩 위에 열고 닫으면 온보딩으로 돌아온다. 완료는 이 기기의 회원 기록으로 관리하고 로그아웃 때 지운다. 다른 기기와 재설치 후의 기존 회원 로그인은 온보딩을 열지 않는다.

가운데 스토리와 진행 중 채팅 생성은 구성 변경에 유지한다. 가입한 실행에서는 초대 코드 시트를 열지 않고 이후 실행의 홈에서 ACCOUNT의 초대 흐름을 적용한다.

### 2-2-4 간편 제작 첫 진입 안내

STORY-US-020. 공통 [제작 안내](../2-2-REQUIREMENTS.md#2-2-9-사용-안내와-접근성)를 로그인한 회원에게 적용한다.

| 조건 | Android 적용 |
|---|---|
| 기록 단위 | 기기. 다른 계정으로 로그인해도 마친 안내를 다시 열지 않는다 |
| 간섭 | 진입 판정과 조회 실패, 생성 중과 생성 실패, 저장 충돌, 이탈과 인물 삭제 확인, 선택 키워드 시트, 재선택 확인, 이프 부족 시트, 완성 요청 중에는 열지 않는다. 제작 탭은 옵션 시트, 삭제 확인과 신고 시트가 열린 동안 열지 않는다 |
| 초대 코드 시트 | 홈에서만 열려 제작 안내와 겹치지 않는다 |
| 구성 변경 | 열린 단계를 유지하고 단계 노출을 다시 기록하지 않는다 |
| 백그라운드와 프로세스 종료 | 열린 채 떠난 단계는 기록하지 않아 다음에 그 화면이 보일 때 다시 연다 |
