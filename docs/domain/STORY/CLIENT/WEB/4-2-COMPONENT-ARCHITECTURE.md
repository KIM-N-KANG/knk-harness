### 4-2-1 책임과 의존

| 경계 | 책임 |
|---|---|
| stories 목록과 상세 | 공개 탐색, 상세와 좋아요, 시작 설정과 채팅 시작 |
| stories 공용 | 장르 카탈로그와 검색, 제작 저장과 복구, 초안 변환, 안내와 공용 카드 |
| stories 간편 제작 | 세 단계 입력과 자기 세션 기록. 다른 제작의 요청을 복구하지 않는다 |
| studio 제작 탭 | 서버와 기기 기록 병합, 제출본 및 내 스토리 목록, 진행 카드 조회 |
| studio 일반 제작 | 등록과 수정 및 재제출에 같은 폼 사용. baseline, 검증, 설정 글 변환과 이미지 입력 |
| 서버 조회 | 인증 없는 공개 목록과 오리지널 상세의 제한된 공개 초기값. 브라우저의 인증 조회와 분리 |
| 저장소 | 편집과 완성 테이블, 원자적 전환과 세대 검사. 네트워크 및 분석은 트랜잭션 밖 |
| 공용 모션 | 접는 반복 항목과 푸터, 마스코트 재료. 도메인 장면의 시간 계산과 그리기는 STORY가 조립 |

<br>

### 4-2-2 폼과 표시

일반 제작 화면이 일곱 탭 입력을 소유하고 글 칸은 하나의 공용 입력으로 그린다. 요청 필드와 라벨 및 길이 제한은 필드 정의를 사용한다. 등록 검증은 칸 키, 탭, 시작 상황과 접는 항목 ID를 탭 순서대로 반환하며 화면은 같은 오류 목록을 칸과 탭에 전달한다. 첫 오류 공개는 탭이 제공하는 동작으로 접힌 항목을 펼친 뒤 스크롤한다.

설정 글의 분해와 재조합, 주인공과 주변 인물 변환, 중복 이름 판정은 순수 변환으로 분리한다. 인물 입력은 타 기능 내부를 import하지 않고 일반 제작이 소유한다. 단일 인물, 시작 상황, 엔딩과 사건은 안정 ID로 접기와 검수 사유를 연결한다.

이미지 선택, 파일 검사, 크롭과 업로드, 미리보기 해제는 이미지 입력이 책임진다. 표지와 주변 인물은 같은 칸에 비율과 폭을 전달한다. 업로드가 끝날 때 인물의 다른 편집을 덮지 않도록 해당 이미지 필드만 함수형 갱신한다.

제작 안내는 퍼널과 제작 탭에서 함께 쓰므로 stories 공용 경계에 둔다. 안내 판정과 저장, 대화창과 마스코트 그리기를 분리한다. 마스코트 안무는 시간에서 자세를 계산하는 순수 함수이며 그리기는 API나 폴링을 소유하지 않는다.
