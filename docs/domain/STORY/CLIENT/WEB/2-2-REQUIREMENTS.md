# 2-2 요구사항: 웹

기준: [공통 요구사항](../2-2-REQUIREMENTS.md).

### 2-2-1 탐색과 검색 노출

STORY-US-001, STORY-US-003, STORY-US-004, STORY-US-023, STORY-US-024.

| 조건 | 결과 |
|---|---|
| 탐색 순서 | 같은 문서 안에서 상세로 갔다 뒤로가면 받은 순서와 위치를 그대로 보인다. 새로고침과 새 탭은 새 순서로 맨 위에서 시작한다 |
| 검색어 보존 | 제출한 검색어를 주소에 남겨 새로고침과 상세 복귀에서 같은 검색 결과를 다시 보인다. 검색어를 바꿔도 방문 기록을 늘리지 않는다 |
| 홈 첫 표시 | 홈 목록을 서버에서 읽을 수 있으면 첫 HTML에 섹션 이름과 카드를 포함한다. 실패하면 클라이언트 조회로 이어간다. 탐색은 첫 HTML에 카드를 넣지 않는다 |
| 상세 첫 표시 | 현재 공개인 오리지널만 공개 본문과 작품 메타데이터를 첫 HTML에 넣는다. 개인별 엔딩과 권한, 숨겨진 설정, 프롤로그와 엔딩 조건 및 에필로그는 제외 |
| 권한 확인 | 공개 초기 본문만 있을 때 채팅 시작과 좋아요를 비활성화하고 소유자 기능은 인증된 조회 후 표시한다 |
| 검색 | 홈과 공개 오리지널 상세를 사이트맵에 싣는다. 사용자 스토리와 판정 실패 및 현재 공개 여부를 확인하지 못한 상세는 noindex, nofollow |
| 수집 | 상세 robots 메타데이터를 읽을 수 있도록 상세 수집은 허용한다. 개인화, 인증, 제작과 API는 제외 |
| 검색 화면 색인 | 스토리 검색 화면은 검색어와 관계없이 noindex. 결과의 상세 링크는 따라갈 수 있다 |
| 익명 오류 | 익명 404로 페이지 전체를 미존재로 확정하지 않는다. 이후 인증된 클라이언트 조회로 소유자의 비공개 스토리를 열 수 있어야 한다 |

검색엔진의 스니펫 길이, 사이트링크 선택과 순서 및 노출을 보장하지 않는다.

### 2-2-2 제작과 보존

STORY-US-007부터 STORY-US-018, STORY-US-020.

| 상황 | 결과 |
|---|---|
| 직접 주소와 새로고침 | 새 제작을 연다. 기존 기록은 제작 카드에 남기고 재개는 카드의 이어서 만들기로만 한다 |
| 새 제작 상한 | FAB과 직접 주소 및 공유 CTA의 새 세션 진입에서 확인한다. FAB 조회 중에는 이동을 허용하고 입력 화면 진입 때 다시 확인 |
| 진입 조회 | 이관과 최초 조회가 끝나기 전 빈 초안으로 판단하지 않는다. 조회 중 편집과 제출을 막고 실패 때 재개 의도를 유지해 재시도 |
| 일반 제작 저장 | 버튼과 탭 이동 및 화면 숨김. 입력이 없으면 저장하지 않으며 기본 분량 배분과 공개 범위만으로 입력이 있다고 보지 않는다 |
| 간편 제작 저장 | 버튼과 화면 숨김. 카테고리와 단계 이동은 저장하지 않는다. 생성 명령과 결과는 즉시 보관 |
| 이탈 | 닫기와 브라우저 및 마우스 뒤로가기는 같은 확인을 거친다. 새로고침과 탭 닫기 및 주소 이동은 미저장 변경이 있을 때 기본 브라우저 확인창 |
| 브라우저 종료 | 숨김 때 저장을 시작하지만 강제 종료까지 완료를 보장하지 않는다. 저장 시도가 이탈 확인을 대체하지 않는다 |
| 이전 저장소 이관 | 입력과 요청 ID, 최초 시각과 순서를 유지한다. 성공 전에 원본을 지우지 않으며 손상 원문도 보존한다. 이관 뒤 삭제한 초안이 다시 살아나지 않는다 |
| 완료와 실패 | 완료 목록을 받을 때까지 기존 화면과 카드를 유지한다. 확정 실패는 추가 정보 초안과 사유 안내로 복귀하며 이 경로에서 로그인 시트를 열지 않는다 |
| 계정 종료 | 로그아웃, 탈퇴, 만료에 제작 기록을 정리하고 이전 세대의 늦은 저장과 결과 반영을 차단한다 |
| 이름 입력 | 간편 제작 인물 이름의 `]`는 필드와 푸터 오류로 생성 차단 |

<br>

### 2-2-3 웹 첫 제작 안내

공통 [제작 안내](../2-2-REQUIREMENTS.md#2-2-9-사용-안내와-접근성)를 게스트와 회원 모두에게 적용한다. 별도 첫 방문 온보딩 페이지는 두지 않는다. 로그인 필요 시트와 초대 코드 시트도 간섭 대상이다. localStorage 접근이 막힌 환경에서는 진입마다 다시 열릴 수 있다.
