### 3-3-1 목록과 상세

| 요소 | 웹 표현 |
|---|---|
| 제작 카드 | 표지 폭 128px, 3:4. 가로 16px와 세로 8px 패딩, 열 간격 16px. 글 영역 위아래 4px, 제목 16px와 두께 500. 골격도 동일 |
| 옵션 | 기본 24px 버튼과 16px 아이콘. 제목 첫 줄 중심보다 위로 1px 보정 |
| 홈 | 표지 아래 글 좌우 4px. ORIGINAL 태그 72×26px |
| 상세 | 헤더 56px, 스켈레톤 펄스 1.4초, Select 옵션 모서리 12px, 메타 패딩과 행 간격 16px |
| 좋아요 | 48px 아이콘 버튼과 16px CTA 간격, aria-pressed와 aria-busy. 조회 전 비활성 상태 유지 |
| FAB | 오른쪽 아래 고정. plus와 만들기, 스크롤하면 아이콘만 남고 접근성 이름 스토리 만들기 유지. hover 3% 확대, 배경 불투명도 유지 |
| 완료 교체 | opacity 200ms ease-out, 나머지 행의 위치만 200ms 이동. 동작 줄이기는 즉시 교체 |
| 상세 하단 | 메타 영역이 다가오면 CTA와 스크롤 빈 영역을 기본 배경에서 메타 배경으로 연결. 본문 자체는 기본 배경 유지 |
| 진입 조회 | 초안 재개와 상한 확인은 헤더 없는 중앙 스피너. 실패는 조회 안내와 재시도 |

### 3-3-2 제작 입력과 이미지

| 요소 | 표현 |
|---|---|
| 방식 카드 | 세로 두 장, 모서리 20px와 테두리. 일러스트 아래 구분선과 제목 및 설명. 작은 화면에도 스크롤 없이 보이며 남은 높이를 나눔 |
| 접근성 | 각 방식은 제목과 설명을 이름으로 가진 링크 하나. 일러스트는 장식으로 제외 |
| 간편 탭과 푸터 | 전체 폭 3등분, 선택선이 기준선을 덮음. 본문 위 16px와 아래 32px, 선택 키워드 및 비용 행 40px와 CTA 간격 8px |
| 입력 배치 | 키워드 그룹 간 24px. 이름과 성별 폭 3:2. 주변 인물 가로 16px, 머리 이름과 삭제 14px, 순번 12px |
| 추가 정보 | 스토리라인, 추천, 자유 입력, 화풍 간 24px. 마지막 아래 16px. 제목 줄 높이 동일. 행 삭제 X는 Tab 순서에서 제외 |
| 일반 저장 | 버튼 높이 40px. 저장 중 문구 자리 스피너. 성공 토스트 1.5초, 연타는 이전 토스트 교체 |
| 크롭 | 바텀 시트 안 고정 비율 프레임을 처음 중앙에 맞춤. 끌기와 핀치 및 확대 슬라이더 1~3배. 아래 자르기와 닫기 순 |
| 업로드 | 미리보기 위 스피너. 취소와 실패는 기존 이미지 유지. 미리보기와 같은 선택 버튼을 별도 제공하므로 미리보기는 키보드와 보조 기술 대상에서 제외 |
| 접기 | 높이와 투명도를 전환하며 닫힌 입력은 초점과 보조 기술에서 제외. 동작 줄이기는 즉시 전환 |

### 3-3-3 일반 제작 도움말

| 칸 | 문구 |
|---|---|
| 제목 | 스토리 목록과 상세에 보이는 제목이에요. 스토리의 특징이 드러나게 지어주세요 |
| 한 줄 소개 | 스토리 상세에 보이는 소개 글이에요. 스토리의 핵심을 한 문장으로 적어주세요 |
| 주인공 기본 정보 | 스토리 속에서 기본으로 쓰이는 이름과 성별이에요. {username}을 넣은 곳은 이 이름으로 바뀌고, 페르소나로 플레이할 때는 페르소나 이름으로 바뀌어요 |
| 주인공 특징 | 내가 어떤 사람인지에 따라 주변 인물들의 반응이 달라져요 |
| 프롤로그 | 채팅을 시작하면 첫 화면에 보이는 도입 글이에요. {username}을 쓰면 사용자의 페르소나 이름으로 바뀌어요 |
| 주변 인물 기본 정보 | 이 이름과 성별로 스토리에 등장해요 |
| 주변 인물 특징 | 인물의 성격이 대화와 행동에 드러나요 |
| 인물 소개 | 스토리 상세에서 이름 아래에 보이는 소개 글이에요. 어떤 인물인지 한 문장으로 적어주세요 |
| 인물 이미지 | 이 이미지를 바탕으로 상황에 맞게 인물의 모습이 실시간으로 바뀌어요 |
| 주요 사건 | 채팅이 엔딩을 향하도록 이야기의 방향을 잡아 주는 사건이에요. 모든 시작 상황에 함께 쓰이며, 주인공(나)이 겪을 큰 위기나 전환점을 적어주세요 |
| 사건 이름 | 채팅과 스토리 상세에는 보이지 않고, AI가 사건을 구분할 때 쓰는 이름이에요 |
| 사건 설명 | AI가 이 사건을 장면으로 풀어낼 때 참고하는 내용이에요. 무슨 일이 벌어지고 어떤 방향으로 풀릴 수 있는지 적어주세요 |
| 키 문장 | 주인공(나)의 행동이 이 사건과 관련되는지 AI가 판단하는 기준 문장이에요. 할 법한 행동을 한 문장으로 적어주세요 |
| 장르 | 스토리 목록과 상세에 보이는 장르예요 |
| 주요 내용 | 스토리 상세의 주요 내용에 보이는 글이에요. 한 줄 소개보다 자세한 줄거리와 볼거리를 적어주세요 |
| 등록 주의 | 노골적인 성적 표현, 지나치게 잔혹한 묘사, 혐오를 부추기는 내용은 등록할 수 없어요. 이런 내용을 올리면 이용이 제한될 수 있어요 |

플레이스홀더는 유실역 설정을 이어 사용한다. 한 줄은 “예: 본문”, 여러 줄은 “예:” 다음 줄에서 시작하며 문장은 마침표로 끝내고 이름에는 붙이지 않는다. 세계관 예시는 절 제목 없이 세계 설정, 전개 방식은 `# 문체 톤`을 포함한다. 프롤로그는 `*…*` 서술과 `이름: 대사`를 쓰고 “안내 방송: {username} 님, 종점입니다.”로 토큰 사용을 보여준다.

AI가 읽는 설정과 프롤로그 및 추천 입력은 `{username}`과 조사를 사용한다. 소개와 주요 내용 및 상황 설명은 “주인공”으로 부른다. 추천 입력의 행동 지문에는 주어를 쓰지 않고 토큰은 자기소개에만 쓴다. 사용자에게 보이는 여러 줄 예시는 문단 사이를 비운다. 인물 소개 예시는 “예: 유실물 보관소를 지키는 무뚝뚝한 관리인. 맡긴 것 없이는 아무것도 내주지 않는다.”이며 n/150 카운터를 둔다.

### 3-3-4 제작 안내와 대기

| 안내 | 문구 | 버튼 |
|---|---|---|
| 인사 | “반가워요! 키워드로 스토리 만들고” / “스토리 속 등장인물과 대화해 보세요.” | 건너뛰기, 시작하기 |
| 키워드 | “장르와 인물을 골라 주세요.” / “내가 주인공인 1인칭 스토리예요.” | 확인 |
| 스토리라인 | “{장르}로 만든 스토리라인 3개예요.” / “마음에 드는 하나를 골라 주세요.” | 확인 |
| 추가 정보 | “마지막이에요!” / “원하는 설정을 더하면 완성돼요.” | 확인 |
| 완성 중 | “곧 스토리가 완성돼요.” / “그동안 오리지널 스토리 어때요?” | 닫기, 오리지널 스토리 보기 |

장르는 생성 요청의 선택 순서로 쉼표로 잇고 마지막 이름의 받침에 따라 으로와 로를 고른다. 받침이 없거나 ㄹ이면 로다.

앱 프레임 전체 딤 위 가운데에 모서리 20px 카드, 좌상단 48px 마스코트 프로필을 둔다. 이름 마냑은 primary 14px, 대사는 16px와 행간 24px로 한 번에 보인다. 버튼 높이 40px, 보조는 배경 없는 글자 버튼, 주 버튼은 오른쪽이다. 열릴 때 카드에 초점을 둔다. 다크 모드에만 카드 테두리를 둔다.

완성 중 카드는 “스토리를 완성 중이에요”, “조금만 기다리면 완성된 스토리를 볼 수 있어요”와 마스코트 표지다. 마스코트는 키워드와 스토리라인 선택, 졸기와 에너지 드링크, 빠른 집필, 베레모와 붓으로 인물화 그리기, 소품 던지기와 달리기 및 벽 점프를 쉼과 함께 이어간다. 그림은 달을 등진 옆얼굴과 날리는 머리 및 목도리이며 막마다 눈 표정을 바꾼다. 미세 포인터 환경은 포인터를 바라보고 벗어나면 안무로 돌아간다. 동작 줄이기는 바닥 가운데 선 장면으로 멈춘다. 문구 전환과 시머는 각각 4초다.

### 3-3-5 스토리라인과 조회 상태

| 요소 | 표현 |
|---|---|
| 선택 키워드 | 40px 정사각 중립 버튼과 8px 간격. 펼친 내용은 제목과 설명 8px, 아래 32px, 그룹 24px, 칩 높이 40px와 간격 8px |
| 본문 | MaruBuri 16px, 자간 -2%, 행간 175%. 후보 탭을 바꾸면 본문 위로 이동 |
| 하단 여백 | 키워드 패널 16px, 스토리라인 패널 32px |
| 15초 지연 | 스토리라인을 잡는 데 시간이 조금 더 걸리고 있어요 |
| 30초 지연 | 장면 흐름을 다시 맞춰보고 있어요 |
| 첫 생성 실패 | 스토리라인을 만들지 못했어요 |
| 재생성 실패 | 스토리라인을 다시 만들지 못했어요. 이전 결과는 유지 |
| 빈 결과 | 생성된 스토리라인이 없어요. 후보 탭 3개는 비활성 |
| 평가 성공 | 좋아요를 남겼어요 또는 싫어요를 남겼어요. 취소는 토스트 없음 |
| 평가 실패 | 평가 저장에 실패했어요 |
| 화풍 조회 실패 | 중앙의 48px outline 버튼으로 다시 불러오기 |
