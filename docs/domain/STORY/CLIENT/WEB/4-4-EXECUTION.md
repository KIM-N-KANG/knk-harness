### 4-4-1 조회와 공개 렌더

| 작업 | 실행 |
|---|---|
| 홈 | 서버가 전체와 인기순 첫 페이지를 5초 제한으로 읽어 무한 Query 초기 데이터로 사용. 실패는 클라이언트 조회 |
| 공개 목록 캐시 | 60초 revalidate. 홈은 동적 searchParams 대신 클라이언트 useSearchParams와 기본 목록 Suspense 폴백으로 ISR 유지 |
| 쿼리 URL 새로고침 | 기본 목록 HTML 뒤에 선택한 조건을 클라이언트 조회 |
| 오리지널 판정 | filter=original 목록을 50개씩 최대 10페이지. 한 페이지라도 실패하면 전체 판정 실패로 상세 색인 금지, 사이트맵은 정적 공개 페이지만 |
| 상세 | 공개 오리지널 목록에 있는 ID만 인증 없는 no-store 조회, 5초 제한. ID와 PUBLISHED 및 PUBLIC을 확인하고 React cache로 한 렌더 안 재사용 |
| 공개 초기값 | 허용 필드만 명시적으로 추출. 시작 상황은 ID와 이름, 상황 설명과 엔딩 이름, 제작자는 닉네임만. Query 캐시에 넣지 않아 브라우저가 즉시 인증 조회 |
| 상세 조회 실패 | 서버 notFound로 전체 페이지를 끝내지 않고 클라이언트 조회 유지. 이미지 없음은 브랜드 이미지 메타데이터 |
| 좋아요 | 진행 중 상세 조회 취소와 스냅숏 저장 후 낙관 반영. 실패 복원, 204 성공 시 상세와 공개 목록 쿼리 무효화. ref로 전체 요청 구간 중복 차단 |
| 장르 검색 | 입력 후 200ms 대기, 이전 결과 유지, 실제 요청 200ms 이상만 로딩. 빈 검색어는 전체 목록 키 재사용, 캐시는 공용 Query 정책 |

### 4-4-2 저장과 복구

1. 진입 의도를 한 번 읽고 이관과 조회를 완료한다. 새 회원 세션은 병합 카드로 상한을 확인한다. 서버 목록 실패는 기기 기록만 세고 기기 기록 실패는 막지 않는다.
2. 서버 저장은 직렬 처리하며 화면 숨김은 keepalive로 보낸다. visibilitychange(hidden)와 pagehide를 중복 없이 처리하고 종료 시 완료를 보장하지 않는다.
3. 버튼 저장은 첫 누름 즉시 처리하고 1초 안의 추가 누름을 무시한다. 바뀌지 않아 쓰지 않은 버튼 저장도 성공 토스트를 보인다. 탭 이동과 숨김 성공은 조용히 처리한다.
4. 완성 기록을 추가하고 원 생성 초안만 제거한 뒤 POST하고 제작 탭으로 replace한다. 언마운트 후에도 응답을 판정한다.
5. 성공과 네트워크 오류 및 동일 요청 409는 카드 조회로 판정한다. 그 외 확정 오류는 추가 정보 초안으로 되돌리고 토스트를 표시한다.
6. 퍼널 3초와 카드 5초 조회는 보이는 동안만 수행한다. 같은 실행의 원 POST가 MutationCache에 진행 중이면 쿼리와 캐시 결과 판정을 모두 보류해 등록 전 404와 이전 FAILED를 소비하지 않는다. 원 POST 종료 뒤 기록이 남으면 즉시 조회한다.
7. 새로고침 뒤에는 메모리 원 POST가 없으므로 즉시 복구한다. 구버전 createdStoryId를 가진 초안은 기존 채팅 재시도 경로로 복원한다.

### 4-4-3 일반 제작과 이미지

| 작업 | 실행 |
|---|---|
| 진입 | 기기 레거시 기록을 먼저, 없으면 서버 초안 상세를 읽고 제공 장르 목록을 받은 뒤 폼 구성 |
| 등록 | 클라이언트 검증 후 생성 훅으로 요청. 202 뒤 초안 삭제와 저장 중단은 화면을 떠났어도 완료 |
| 검수 | 1초 간격, 60초 상한. 입력과 탭을 inert로 잠금. 검토 토스트는 1.5초, 언마운트 때 토스트와 AbortController 조회 정리 |
| 승인 | 내 스토리 목록 무효화, 이탈용 더미 히스토리 정리, 채팅 시작. 실패는 상세 |
| 재제출 | submissionId와 카탈로그를 받은 뒤 접수된 폼으로 열고 초안 저장 금지. 이미지는 blob null과 서버 URL |
| 수정 | baseline 대비 JSON이 다른 필드만 요청. 표지 삭제를 먼저 실행. PATCH 200은 성공 복귀, 202는 submissionId로 검수 조회. 공개 범위만 보내도 응답 상태를 확인하며 결과 뒤 상세와 수정 폼 및 내 스토리 쿼리 무효화 |
| presign 업로드 | 생성 API로 URL을 받은 뒤 S3 직접 PUT. 서명의 Content-Type 그대로 사용 |
| 크롭 | 긴 변 최대 1440px, 작은 원본 확대 없음. 흰 배경 위 JPEG 품질 0.9로 생성. 취소는 업로드하지 않음 |
| 크롭 제스처 | 크롭 영역과 슬라이더의 동작을 시트 닫기 제스처에서 제외 |
| 접기 | 높이와 투명도 전환 중만 overflow hidden. 접는 순간 inert, 완전히 닫히면 visibility hidden. 완료 여부를 상태로 유지 |
| 스크롤 | 입력 스크롤러와 탭 줄을 positioned 기준으로 둬 숨은 파일 입력이나 선택 탭의 offset이 앱 프레임을 밀지 않게 함 |

### 4-4-4 표시 수명과 모션

- 홈 바는 한 방향으로 8px 이상 이동할 때 숨김을 바꾸고 상단 64px에서는 항상 보인다. translate만 사용하고 숨은 뒤 invisible로 초점에서 제외한다. 사라짐 150ms 가속, 나타남 300ms 감속이며 동작 줄이기는 전이하지 않는다.
- 상세 헤더의 DOM이 지연 로딩 뒤 나타나도 스크롤 listener와 IntersectionObserver를 연결한다. 하단 배경은 남은 거리와 메타 높이 두 배, 최소 160px로 smoothstep과 oklab 보간을 적용한다. passive listener, requestAnimationFrame과 ResizeObserver는 언마운트 때 해제한다.
- FAB은 메인 스크롤 래퍼의 overlayContainer에 absolute 포털해 목록 끝이나 당김 변환을 따라가지 않는다. 완료 전환은 같은 ul에서 popLayout을 사용하고 기존 ID key와 DOM을 유지한다.
- ORIGINAL SVG는 배경만 반투명으로 두고 블러를 모서리에 클리핑한다. next/image unoptimized로 제공하며 dangerouslyAllowSVG는 켜지 않는다.
- 완성 표지는 공용 마스코트 안무와 그리기를 조립한 37.71초 루프다. 표지 폭 0.6의 세로 캔버스, 84칸 격자 붓길을 붓털 끝으로 따른다. 채팅과 붓 및 안무 재료를 공유하고 도메인 소품만 별도 그린다. 테마 색을 sRGB로 읽고 소품은 별도 캔버스에 불투명하게 그린 뒤 한 번에 투명도를 적용한다.
- 제작 방식 일러스트는 CSS 타임라인과 테마 토큰을 사용한다. 탭이 가려지면 다음 단계에서 멈추고 언마운트 때 타이머를 정리한다.
- 제작 안내는 200ms 뒤 열고 앱 프레임 포털로 표시한다. 카드에 초점을 두며 조작 없이 열린 안내는 더미 히스토리를 쌓지 않는다. 홈 이동 전 열린 히스토리 레이어를 소비한다.
- 안내 마스코트는 프로필 폭 66%, 5초 말하기 두 번과 쉼. 몸을 폭 3.5%까지 띄우고 좌우 3도 기울이며 동작 줄이기는 첫 자세다.
