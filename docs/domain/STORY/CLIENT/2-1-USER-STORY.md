# 2-1 유저 스토리

<br>

### 2-1-1 사용자 목표

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| STORY-US-001 | 탐색하는 사용자 | 공개된 스토리를 종류와 정렬 기준에 따라 찾아보고 싶다 | 취향에 맞는 이야기를 발견하고 싶다 |
| STORY-US-002 | 제작한 사용자 | 내 스토리와 만들던 스토리를 상태별로 구분해 보고 싶다 | 이어서 할 작업을 찾고 싶다 |
| STORY-US-003 | 스토리를 고르는 사용자 | 소개, 시작 상황과 주변 인물을 확인하고 이미지를 확대하고 싶다 | 플레이하기 전에 이야기의 내용을 알고 싶다 |
| STORY-US-004 | 플레이하려는 사용자 | 페르소나와 시작 상황을 골라 새 채팅을 시작하고 싶다 | 같은 이야기를 원하는 주인공과 상황으로 즐기고 싶다 |
| STORY-US-005 | 엔딩을 본 사용자 | 이전에 도달한 엔딩과 시작 상황별 엔딩 이름을 확인하고 싶다 | 이미 즐긴 내용과 다음 목표를 구분하고 싶다 |
| STORY-US-006 | 마음에 드는 스토리를 찾은 회원 | 다른 사람의 스토리에 좋아요를 남기거나 취소하고 싶다 | 내 선호를 표현하고 싶다 |
| STORY-US-007 | 제작을 시작하는 사용자 | 간편 제작과 일반 제작 중 원하는 방식을 고르고 싶다 | 빠른 제작과 세밀한 제작을 상황에 맞게 선택하고 싶다 |
| STORY-US-008 | 간편 제작 사용자 | 장르를 고르고 인물의 이름, 성별과 특징을 정하고 싶다 | 원하는 설정은 직접 정하고 나머지는 AI에게 맡기고 싶다 |
| STORY-US-009 | 간편 제작 사용자 | 생성된 스토리라인을 비교하고 다시 만들거나 평가하고 싶다 | 마음에 드는 전개를 고르고 추천 품질에 의견을 남기고 싶다 |
| STORY-US-010 | 간편 제작 사용자 | 추천과 직접 입력으로 세부 설정을 더하고 이미지 스타일과 공개 범위를 고르고 싶다 | 완성할 이야기의 내용과 분위기를 정하고 싶다 |
| STORY-US-011 | 간편 제작 사용자 | 작성한 추가 정보가 사라지기 전에 확인하고 스토리라인을 다시 고르고 싶다 | 실수로 작성한 내용을 잃고 싶지 않다 |
| STORY-US-012 | 간편 제작을 제출한 사용자 | 완성을 기다리는 동안 다른 작업을 하고 결과를 확인하고 싶다 | 한 제작을 기다리느라 다른 이용이 막히지 않았으면 한다 |
| STORY-US-013 | 일반 제작 회원 | 세계관, 인물, 시작 상황과 엔딩을 직접 작성해 등록하고 싶다 | 세밀한 설정이 플레이에 반영되기를 원한다 |
| STORY-US-014 | 스토리 소유 회원 | 기존 스토리의 설정과 이미지를 수정하고 싶다 | 플레이하면서 발견한 아쉬운 내용을 고치고 싶다 |
| STORY-US-015 | 작성 중인 사용자 | 입력을 저장하고 나중에 같은 제작을 이어가고 싶다 | 우발적인 이탈로 작업을 잃고 싶지 않다 |
| STORY-US-016 | 여러 스토리를 만드는 사용자 | 새 제작, 이어서 만들기와 초안 삭제를 각각 선택하고 싶다 | 다른 제작과 진행 중인 요청을 보존하고 싶다 |
| STORY-US-017 | 응답을 놓친 사용자 | 이미 접수된 생성 결과를 확인하고 실패한 입력을 다시 사용할 수 있으면 좋겠다 | 중복 생성이나 입력 손실 없이 복구하고 싶다 |
| STORY-US-018 | 검수 중인 제작자 | 검토 상태와 반려 사유를 확인하고 취소하거나 고쳐 다시 제출하고 싶다 | 등록되지 않은 이유를 이해하고 제작을 마무리하고 싶다 |
| STORY-US-019 | 스토리를 정리하는 소유자 | 내 스토리를 확인한 뒤 삭제하고 싶다 | 원하지 않는 스토리를 정리하고 싶다 |
| STORY-US-020 | 간편 제작을 처음 쓰는 웹 사용자 | 각 제작 단계에서 사용법을 안내받고 싶다 | 처음에도 흐름을 이해하고 완성하고 싶다 |
| STORY-US-021 | Android에 처음 가입한 회원 | 오리지널 스토리를 고르거나 직접 제작을 시작하고 싶다 | 가입 직후 첫 이야기를 쉽게 시작하고 싶다 |
| STORY-US-022 | 이야기의 무대를 정하는 사용자 | 장르와 배경 키워드를 골라 세계관을 정하고 싶다 | 무대가 되는 세계를 먼저 또렷하게 정하고 싶다 |
