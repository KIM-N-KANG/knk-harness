# 6-5 AI 평가 구현

스토리라인 평가 CLI는 아직 구현하지 않았다.

<br>

### 6-5-1 스토리라인 생성

**1. 구성과 격리**

| 구성 요소 | 책임 |
|---|---|
| 평가 CLI | 실행 종류, 데이터셋과 설정 선택 <br> 실행 ID 관리 |
| 데이터 로더 | 생성 입력, 후보 본문과 선택 라벨 읽기 <br> 사례와 후보의 대응 검사 |
| 생성 실행기 | configuration 구성과 운영 생성 코드 호출 <br> 생성 결과와 호출 기록 수집 |
| 채점 실행기 | 후보별 독립 호출과 점수 검사 <br> 후보와 점수 연결 |
| 결과 집계기 | 실행 종류별 결과 비교와 집계 |
| 결과 저장기 | 실행 설정, 단계별 결과와 오류 저장 <br> 보고서 작성 |

| 대상 | 규칙 |
|---|---|
| 배포 | 평가 CLI, 데이터셋과 실행 결과를 운영 배포에서 제외 |
| 저장 | 평가 데이터와 실행 결과를 Git에서 제외 |
| 서비스 반영 | 평가로 생성한 후보는 실제 제작 진행과 사용자 데이터에 반영하지 않음 |
| 프롬프트 | 스토리라인 프롬프트와 평가 모델 프롬프트를 구분해 버전 관리 |

<br>

**2. CLI 실행 종류**

| 실행 | 입력 | 동작 |
|---|---|---|
| 사전 검사 | 데이터셋과 실행 설정 | 데이터와 configuration 검사 후 실행 대상 출력 <br> 모델 호출 없음 |
| 평가 모델 검증 | train 또는 test의 기존 후보와 선택 라벨 | 기존 후보 채점 후 같은 요청의 사용자 선택과 점수 순위 비교 <br> 스토리라인 생성 호출 없음 |
| 스토리라인 생성 | test의 생성 입력과 configuration 목록 | configuration별 운영 생성 코드 호출 <br> 후보와 생성 기록 저장 |
| 생성 결과 채점 | 저장한 후보와 채점 설정 | 후보별 독립 채점 <br> 요청별 최고 점수와 평균 점수 계산 |
| 보고서 생성 | 저장한 실행 결과 | 검증 결과 또는 configuration별 품질, 출력 안정성, 시간과 비용을 표와 그래프로 출력 <br> 모델 호출 없음 |

<br>

**3. 실행 설정과 데이터 검사**

| 항목 | 처리 |
|---|---|
| configuration | 기반 모델과 지원 effort 조합으로 구성 <br> 지원하지 않는 조합 제외 |
| 스토리라인 프롬프트 | grid search마다 한 버전으로 고정 |
| 평가 모델 | `gpt-6-astra`, 추론 강도 `high` |
| 평가 모델 프롬프트 | 같은 비교 실행에서 버전과 채점 기준 고정 |
| 검증 데이터 | 요청별 후보 3편, 선택 라벨 `1` 하나와 `0` 두 개의 대응 확인 |
| 생성 데이터 | 장르 태그, 주인공과 주변 인물 정보를 운영 입력 스키마로 검사 |
| 재생성과 이탈 사례 | 평가 데이터셋에서 제외 <br> 재생성 참고 자료는 평가 입력과 분리 |
| 입력 분리 | 선택 라벨은 검증 결과 비교에만 사용 <br> 생성 입력과 평가 모델 입력에 전달하지 않음 |

<br>

**4. 운영 코드 공유**

| 항목 | 실행 규칙 |
|---|---|
| 공유 원칙 | 운영의 생성 코드 재사용 <br> 평가용 생성 로직 복제와 재구현 금지 |
| 입력 검증 | 운영의 요청 정규화와 입력 스키마 사용 |
| 프롬프트 조립 | 운영의 스토리라인 프롬프트 조립기 사용 |
| 모델 호출 | 운영의 공통 LLM 호출 사용 <br> 모델과 effort는 호출 설정으로 전달 |
| 출력 처리 | 운영의 파싱, 후보 검사, 보완과 최종 출력 조립 사용 |
| 실행 범위 | 스토리라인 후보와 추천 추가 정보 생성까지 실행 <br> 컴파일, 인물 이미지와 썸네일 생성은 실행하지 않음 |

<br>

**5. 채점과 집계**

| 항목 | 처리 |
|---|---|
| 채점 설정 | 평가 모델, 반복 횟수와 점수 집계 기준 적용. ([6-4-1 스토리라인 생성](6-4-AI-EVALUATION-METHOD.md#6-4-1-스토리라인-생성)) |
| 호출 격리 | 후보별 각 회차를 독립 호출 <br> 이전 채점 결과를 다음 호출에 전달하지 않음 |
| 채점 입력 | 스토리라인 본문 한 편과 `sample_id` 전달 <br> 다른 후보와 점수, 선택 라벨, 추천 추가 정보 제외 |
| 결과 연결 | 실행기가 요청과 후보에 대응하는 `sample_id` 관리 <br> `results` 배열의 결과 1개를 입력의 `sample_id`와 대조해 해당 후보에 연결 |
| 결과 검사 | `results` 배열의 결과 수가 1개가 아니거나 `sample_id`가 입력과 다르면 채점 실패 <br> `score`가 0~100점 정수가 아니거나 `reason`, `evidence`가 문자열이 아니거나 누락되면 채점 실패 |
| 검증 결과 | 기존 후보의 집계 점수와 사용자 선택 라벨로 일치 여부 계산 |
| 생성 결과 | 새 후보 3편의 최고 점수와 평균 점수 계산 <br> 기존 후보의 선택 라벨을 새 후보에 적용하지 않음 |
| 집계 조건 | 요청의 모든 후보가 정해진 반복 채점을 완료한 뒤 요청별 결과 계산 |
| 출력 안정성 | 최초 검사, 복구와 최종 결과로 실패율과 복구율 집계 ([6-4-1 스토리라인 생성](6-4-AI-EVALUATION-METHOD.md#6-4-1-스토리라인-생성)) <br> 생성 실패 요청도 집계에 포함 |
| 시간과 비용 | 평가 모델 호출 기록과 스토리라인 생성 기록을 분리 <br> 실패 요청과 재생성, 보완 호출 포함 |

<br>

**6. 실행 관리**

| 항목 | 처리 |
|---|---|
| 단계 분리 | 생성 결과 저장 후 채점 <br> 평가 모델 프롬프트 변경 시 저장한 후보 재채점 가능 |
| 실패 구분 | 입력 검사, 생성, 채점 단계별 실패 기록 <br> 실패를 점수 0으로 대체하지 않음 |
| 재개 | 완료된 생성과 채점 결과 재사용 <br> 미완료 대상만 실행 <br> 실패 후 재실행 이력은 보존하고 원래 실패를 성공으로 덮어쓰지 않음 <br> 재사용 결과는 중복 집계하지 않음 |
| 재사용 조건 | 데이터, 입력, configuration과 스토리라인 프롬프트가 같아야 생성 결과 재사용 <br> 채점 결과는 평가 모델, effort와 평가 모델 프롬프트도 같아야 재사용 |
| 설정 변경 | 별도 실행으로 기록 <br> 이전 조건의 결과와 합치지 않음 |
| 누락 | 실패하거나 완료되지 않은 요청과 후보 수를 결과에 표시 |

<br>

**7. 결과 기록**

| 기록 | 내용 |
|---|---|
| 실행 정보 | 실행 ID, 실행 종류, 코드 버전, 데이터셋 이름과 해시, train/test 구분 |
| 생성 설정 | configuration ID, 요청한 모델과 실제 호출 모델, effort, 스토리라인 프롬프트 버전과 해시 |
| 생성 결과 | 요청별 후보 3편과 추천 추가 정보, 생성과 보완의 호출 기록 |
| 출력 검사 | 요청과 호출별 최초 생성, 전체 재생성, 인물 보완 구분과 시도 순서 <br> 파싱 결과, 구조 검증 결과, 병합 후 검사 결과와 실패 단계 <br> 최초 실패, 형식 복구 여부와 최종 생성 상태를 각각 보존 <br> 기존 호출 기록에 검사 결과가 없으면 측정 불가로 표시 |
| 채점 설정 | 평가 모델, effort, 평가 모델 프롬프트 버전과 해시, 반복 횟수 |
| 채점 결과 | 요청과 후보별 `sample_id`, 반복 회차별 `score`, `reason`, `evidence`, 채점 상태와 오류 <br> 후보별 평균 점수 |
| 검증 결과 | 기존 후보의 선택 라벨, 후보별 점수와 선택 일치 여부 |
| 품질 비교 | configuration과 요청별 최고 점수와 평균 점수 |
| 토큰, 시간과 비용 | 생성과 채점의 호출별 토큰 사용량(입력, 추론, 출력, 캐시), 소요 시간과 비용 |
| TTFT | grid search 생성 호출 시작부터 첫 본문 수신까지의 시간(초) |
| 공급자 호출 기록 | 요청과 응답 ID, 종료 사유, 응답 메타데이터 |
| 기록 연결과 출처 | configuration, 입력과 호출에 연결 <br> 직접 측정값과 공급자 로그 값의 출처 구분 |
| 미측정 값 | 제공되지 않거나 측정하지 못한 값은 0과 구분 |
| 실행 상태 | 완료, 실패와 미완료 대상, 새 실행과 재사용 여부 |
