# 3-1 화면 구성

<br>

### 3-1-1 화면과 진입

| 화면 또는 영역 | 진입 | 정보 순서 |
|---|---|---|
| 채팅 목록 | 메인 채팅 탭 | 최근 활동순 카드, 카드 옵션 |
| 채팅방 | 목록 또는 스토리 상세의 채팅 시작 | 헤더, 대화, 추천, 입력 툴바와 입력창 |
| 채팅 응답 시트 | 헤더 모델 버튼 | AI 모델, 응답 길이 |
| 채팅 설정 시트 | 입력 툴바 설정 버튼 | 채팅 기능, 입력 모드 |
| 채팅 메뉴 | 헤더 더보기 | 제목, 회원 잔액과 내역, 새 채팅, 공유, 회원 신고, 삭제 |
| 채팅 메뉴의 이프 내역 | 메뉴 이프 카드의 내역 | 돌아가기, 제목, 새로고침, 이프 내역 목록 |
| 이미지 뷰어 | 본문 이미지 | 원본, 닫기 |
| 재생성 확인 | 마지막 AI 응답의 다시 생성 버튼 | 제목, 응답 교체 안내, 그대로 두기와 다시 생성하기 |
| 입력 수정 편집기 | 사용자 입력의 입력 수정 버튼 | 원래 입력을 채운 입력칸, 취소와 보내기 |
| 입력 수정 확인 | 편집기의 보내기 | 제목, 사라질 턴 수 또는 응답 교체 안내, 그대로 두기와 수정하기 |
| 포크 확인 | AI 응답의 포크 버튼 | 제목, 지금 채팅 유지 안내, 닫기와 새 채팅 시작하기 |
| 공유본 | 공유 링크 | 고정 헤더, AI 안내와 프롤로그, 턴, 고정 제작 CTA |
| 피드백 | 마이의 피드백 메뉴 | 안내, 본문과 카운터, 선택 이메일, 제출 |

참조 스토리가 없을 때의 메뉴와 플랫폼별 공유 수단은 적용 범위를 따른다. ([2-2-1](2-2-REQUIREMENTS.md#2-2-1-적용-범위와-목록))
