# 2-2 요구사항

<br>

### 2-2-1 적용 범위와 목록

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 사용자 | 웹은 회원과 동의한 게스트, Android는 로그인한 회원 | CHAT-US-001, CHAT-US-002 |
| 목록 | 서버 최근 활동순 유지. 완료 턴이 없는 새 채팅과 참조 스토리가 삭제된 채팅도 유지 | CHAT-US-001 |
| 빈 목록 | 채팅이 없다는 안내만 표시. 별도 제작 CTA 없음 | CHAT-US-001 |
| 재진입 | 저장된 상세를 새로 확인할 때까지 로딩. 생성 중이면 같은 생성을 이어받음 | CHAT-US-002, CHAT-US-009 |
| 시작 | 스토리 상세에서 선택한 시작 설정과 회원 페르소나 사용. 생략하면 서버 기본. 목록에서는 생성하지 않음 | CHAT-US-002 |
| 페르소나 | 게스트는 기본 주인공. 시작 후 변경 불가. 헤더에는 페르소나 대신 스토리 제목만 표시 | CHAT-US-004 |
| 삭제 | 확인 후 삭제. 목록에서는 해당 카드만 제거, 방에서는 목록으로 복귀. 실패하면 복구하고 재시도 가능 | CHAT-US-003 |
| 삭제된 참조 | 제목 대체 표시, 새 채팅과 신고 숨김. 빈 제목이나 공백뿐인 제목도 같은 처리 | CHAT-US-003, CHAT-US-004 |
| 공유 전달 | 웹은 링크 복사와 성공 안내. Android는 시스템 공유 시트로 전달하고 성공 토스트 없음 | CHAT-US-014 |
| 공유 열람 | 로그인과 설치가 필요 없는 웹 화면. 읽기 전용이며 열람자의 서재에 저장하지 않음 | CHAT-US-015 |

로그인, 동의와 목록 소유권은 ACCOUNT를 따른다. ([ACCOUNT 요구사항](../../ACCOUNT/CLIENT/2-2-REQUIREMENTS.md))

### 2-2-2 입력과 추천

| 요구 | 조건과 결과 |
|---|---|
| 입력 모드 | 일반 텍스트와 상황 및 대사 블럭. 같은 전송과 추천 규칙 사용 |
| 전송 가능 | 공백 제거 후 입력이 있고 생성 중이 아닐 때. 입력이 없으면 보이는 추천 중 무작위 하나를 전송. 추천도 없으면 비활성 |
| 길이 | 서버 상한 3000자. 클라이언트는 길이 초과 입력을 차단하지 않음 |
| 블럭 수 | 상황과 대사 합계 50개부터 추가 금지. 모드 전환과 추천 파싱 결과가 상한을 넘으면 내용을 자르지 않고 추가만 금지 |
| 블럭 순번 | 종류별 표시 전용. 전송 내용에는 넣지 않음 |
| 강조 | 선택 영역을 상황 강조로 감싸기. 상황과 대사를 빈 줄로 구분해 전송 |
| 추천 사용 | 채우기는 편집, 본문 선택은 즉시 전송. 마지막 턴에만 표시하며 턴이 없으면 처음 추천 사용 |
| 추천 켜짐 | 확정 본문 이후 마지막 턴의 추천 생성. 다시 들어왔을 때도 생성 중이 아니고 마지막 턴에 추천이 없으면 생성 |
| 추천 꺼짐 | 생성 요청과 표시, 무작위 전송 대상에서 제외. 저장된 추천을 삭제하지 않으며 다시 켜면 재사용 |
| 추천 실패 | 추천 자리에 오류와 재시도. 직접 입력은 계속 가능. 추천 생성은 무료 |
| 입력 잠금 | 생성과 이어받기 중 입력과 전송 및 재생성 잠금. 설정 버튼은 사용 가능 |
| 설정 적용 | 진행 중 요청은 시작 시점 값을 유지. 변경값은 다음 요청부터 적용 |

CHAT-US-005, CHAT-US-006, CHAT-US-007, CHAT-US-018의 입력과 선택 결과다. 추천 내용의 사건 방향은 AI가 정하고 클라이언트는 수신한 선택지 3개를 표시한다.

### 2-2-3 생성, 실패와 복구

| 상황 | 사용자 결과 |
|---|---|
| 생성 중 | 도착한 텍스트와 이미지를 즉시 순서대로 표시. 중복 전송 금지 |
| 정상 완료 | 확인한 확정 본문으로 한 번에 교체. 본문이나 이미지가 사라졌다 다시 나타나지 않음. 목록 활동 갱신 |
| 명시적 실패 | 미확정 입력과 응답 제거, 저장된 결과 확인과 실패 안내. 재생성은 이전 확정 본문과 이미지 복원 |
| 종료 결과 없는 끊김 | 같은 생성을 이어받음. 생성과 과금을 새로 시작하지 않음 |
| 끝내 이어받지 못함 | 서버 저장 결과 확인. 이어쓰기는 새 턴이 있으면 완료, 없거나 여전히 같은 생성 중이거나 상세 실패면 실패 안내. 재생성은 임의 복원하지 않고 확정 본문 표시 |
| 다른 생성 발견 | 그 생성을 이어받음 |
| 다른 기기의 생성 중 거절 | 보낸 입력을 되돌리고 진행 중 응답을 이어받음. 실패 토스트 없음 |
| 낡은 마지막 턴으로 거절 | 보낸 입력을 되돌리고 최신 대화 표시. 실패 토스트 없음 |
| 생성 시작 불가 | 과금 없이 실패 안내 후 다시 전송 가능 |
| 화면 이탈 | 클라이언트 수신만 중단. 서버의 생성과 저장은 계속되며 취소 실패 안내 없음 |
| Android 백그라운드 | 수신만 중단. 복귀 때 상세 확인 후 진행 중이면 이어받음. 구성 변경은 이탈로 보지 않음 |
| 이어받기 한계 | 완료 스트림은 5분 보관. 생성 ID를 받기 전에 나갔다 완료 후 돌아온 재생성은 성공 여부 구분 불가. 나가 있는 동안 실패한 이어쓰기는 이전 턴만 보일 수 있음 |

CHAT-US-002, CHAT-US-006, CHAT-US-009, CHAT-US-011의 복구 결과다. 회원의 이프 부족과 웹 게스트 소진은 입력을 유지하며 PAYMENT를 따른다. ([PAYMENT 요구사항](../../PAYMENT/CLIENT/2-2-REQUIREMENTS.md#2-2-5-이프-부족과-입력-보존))

### 2-2-4 읽기, 이미지와 엔딩

| 요구 | 조건과 결과 |
|---|---|
| 순서 | AI 생성 안내, 프롤로그, 사용자 입력과 AI 응답의 턴, 진행 중 응답 순 |
| 이름 | 서버가 치환한 이름을 그대로 사용. 클라이언트에서 이름 토큰이나 조사 치환 없음 |
| 이미지 순서 | 받은 위치와 횟수 유지. 인물 이름별 정렬이나 중복 제거, 완료까지 표시 지연 없음 |
| 이미지 보안 | 허용 URL만 요청. 유효 마커 원문은 숨김. 허용하지 않은 저장 마커 모양 문자열은 일반 본문 유지 |
| 이미지 실패 | 실패한 이미지 블록만 제거. 깨진 아이콘과 URL을 남기지 않고 본문과 이후 수신 유지 |
| 확대 | 원본 전체를 표시하고 탭으로 전체 화면 뷰어. 이미지 자체 탭으로 닫지 않음 |
| 진입 위치 | 턴이 있으면 마지막 메시지, 없으면 프롤로그. 공유본은 항상 프롤로그 |
| 새 턴 | 사용자 입력을 위에 고정. 응답 추가로 읽는 위치를 강제로 아래로 끌지 않음 |
| 수동 스크롤 | 생성 중 옮긴 위치를 완료 뒤에도 유지. 하단 이동 버튼으로 최신 내용 이동 |
| 헤더 | 본문 빈 곳 탭으로 표시 전환. 스크롤로 바꾸지 않으며 본문 높이와 읽던 위치 유지. 입력 영역은 계속 표시 |
| 재생성 | 마지막 AI 응답만 가능. 사용자 입력 유지. 생성 중 비활성, 엔딩 도달 턴은 버튼 없음 |
| 엔딩 | 서버가 확정한 도달 턴에만 표시. 이후 입력과 선택지는 계속 사용 가능 |
| 동작 줄이기 | 장식 모션 대신 정지 표현. 내용과 조작은 유지 |

CHAT-US-004, CHAT-US-008, CHAT-US-011, CHAT-US-012, CHAT-US-013의 읽기 계약이다.

### 2-2-5 모델, 비용과 기기 설정

| 요구 | 조건과 결과 |
|---|---|
| 모델 | 서버 목록의 이름, 순서와 가격 사용. 회원의 적용 모델은 채팅별 서버 값 |
| 모델 변경 | 선택 후 시트 닫기. 변경 실패는 이전 선택으로 복구하고 안내. 이미 선택한 모델은 저장하지 않음 |
| 긴 응답 | 채팅별 저장. 값이 없으면 꺼짐. 실패 시 복구, 시트는 열린 채 유지. 추가 비용 없음 |
| 웹 게스트 | 라이트로 표시와 생성. 다른 모델 선택은 저장 없이 로그인 안내. 긴 응답은 로그인 없이 변경 가능 |
| 턴 체험 | 라이트에만 적용. 다른 모델은 체험이 남아 있어도 모델 정가 적용 |
| 총 비용 | 모델 턴 비용과 켠 이미지 비용의 합. 잔여 체험이 있거나 무제한인 항목만 0으로 계산 |
| 비용 미확인 | 필요한 값이 하나라도 없으면 숫자 자리표시. 임의 가격 확정 없음 |
| 설정 기본값 | 실시간 이미지 꺼짐, AI 추천 입력과 블럭 입력 켜짐. 저장한 기존 선택 유지 |
| 설정 수명 | 기기별 보존. 회원 계정과 분리하며 로그아웃과 계정 전환에 지우지 않음 |

CHAT-US-017, CHAT-US-018과 적용 비용을 다룬다. 잔여와 잔액의 기준은 PAYMENT에서 제공한다. ([체험 요구사항](../../PAYMENT/CLIENT/2-2-REQUIREMENTS.md#2-2-3-체험))

### 2-2-6 처음 사용 안내

| 안내 | 조건과 종료 |
|---|---|
| 첫 채팅 투어 | 기기 열람 기록 없음, 턴 0개, 생성 중 아님, 웹 동의 시트 없음. 준비 후 약 200ms에 한 번 노출 |
| 노출 판정 | 노출 순간 기록. 조건이 안 맞으면 기록하지 않고 다음 새 채팅에서 판정. 재열람 진입점 없음 |
| 동의 대기 중 | 투어 열지 않음. 그 사이 전송돼 턴이 생기면 이번 방에서는 건너뜀 |
| 투어 종료 | 다음, 완료 또는 건너뛰기. 뒤로가기는 방 이탈 없이 건너뛰기. 없는 대상의 스텝은 생략, 전부 없으면 열지 않음 |
| 투어 저장 실패 | 기록이 없어 재진입 때 다시 보일 수 있음 |
| 추천 인라인 안내 | 턴 0개에서 노출 순간 별도 기기 기록. 같은 방에서는 유지, 재진입부터 숨김 |
| 실시간 이미지 안내 | 정상 이어쓰기 완료 누적 2회 순간 이미지가 꺼져 있으면 약 0.5초 뒤 설정 시트와 안내. 재생성, 실패와 중단은 세지 않음 |
| 다음 요청과 경합 | 다음 전송이나 재생성이 시작되면 완료 뒤 다시 대기. 기기 2회 순간 한 번만 판정하며 당시 켜져 있으면 이후에도 열지 않음 |
| 이미지 안내 종료 | 켜기, 확인, 딤 또는 뒤로가기는 안내만 닫고 설정 시트 유지. 시트를 닫으면 안내도 종료 |
| 이미지 기록 실패 | 횟수를 읽거나 저장하지 못하면 안내를 열지 않음 |
| 접근성 | 투어 뒤 화면은 조작과 보조기술에서 제외. 이미지 안내는 강조된 스위치와 카드만 조작 가능 |

CHAT-US-010, CHAT-US-018의 안내 조건이다.

### 2-2-7 공유와 피드백

| 요구 | 조건과 결과 | 유저 스토리 |
|---|---|---|
| 공유 발급 | 확인 없이 발급. 턴 0개도 가능. 진행 중 중복 조작 금지, 실패는 시트 유지와 재시도 | CHAT-US-014 |
| 공유 내용 | 발급 시점의 프롤로그, 턴, 강조, 이미지와 엔딩 표시. 입력, 추천, 재생성, 메뉴, 투어와 생성 UI 없음 | CHAT-US-015 |
| 공유 실패 | 없는 채팅과 잘못된 링크 포함 안내와 홈 이동. 임의 빈 채팅으로 표시하지 않음 | CHAT-US-015 |
| 공유 개인정보 | 열람자의 서재 저장 없음. 분석 이벤트와 오류 수집에 공유 식별자 없음 | CHAT-US-015 |
| 피드백 본문 | 필수. UI 500자 입력 상한과 카운터. 공백만 있으면 제출 오류 | CHAT-US-016 |
| 회신 이메일 | 선택. 입력하면 이메일 형식, 최대 320자. 비어 있으면 미입력 | CHAT-US-016 |
| 피드백 제출 | 빈 본문에도 버튼 활성. 제출 시 검증. 진행 중 입력과 버튼 잠금 | CHAT-US-016 |
| 피드백 결과 | 성공 안내와 폼 초기화, 실패 안내와 입력 유지 | CHAT-US-016 |
| 자유 입력 보호 | 입력과 대화 원문을 로그나 분석 이벤트에 수집하지 않음 | CHAT-US-005, CHAT-US-016 |
