## C-001. 인물 이미지를 수신 위치에 즉시 표시

- 결정일: 원문 미기재 · 기록 확정 상태: Accepted
- 근거: [이관 원문 C:965](https://github.com/KIM-N-KANG/knk-harness/blob/2d77abce078b75e168d8f924e3759e3bb624515a/docs/product-specs/3-1-client.md#L965-L999)
- **맥락:** 인물 이미지가 스트리밍 도중 도착하지만 완료 이벤트에서 한꺼번에 표시하는 선택지가 있었습니다.
- **결정:** `character_image`는 수신 위치에 즉시 표시하고 저장된 턴은 마커로 복원합니다.
- **이유:** 완료까지 기다리면 이미지가 한꺼번에 나타나 읽는 위치와 순서가 바뀝니다.
- **주요 영향:** 진행 중 조각과 확정 본문은 같은 순서를 유지하고 오류 후에도 수신된 이미지를 임의로 재배치하지 않습니다.
