# 3-3 CHAT 화면 표현

<br>

### 3-3-1 목록과 채팅방

| 요소 | 표시 |
|---|---|
| 목록 카드 | 썸네일, 스토리 제목, 마지막 장면, 턴 수, 상대 활동 시각. 카드 전체가 방 진입 |
| 썸네일 없음 | 기본 심벌 |
| 빈 마지막 장면 | "채팅을 시작하고 이야기를 이어가 보세요" |
| 참조 스토리 삭제 | 보조색 "삭제된 스토리". 목록과 헤더에 동일 적용 |
| 목록 로딩 | 실제 카드 행과 같은 지연 골격 |
| 빈 목록 | "아직 진행중인 채팅이 없어요". 별도 CTA 없음 |
| 목록 또는 방 오류 | "채팅을 불러오지 못했어요"와 다시 시도 |
| 방 헤더 | 스토리 제목, 모델 버튼, 더보기 순. 페르소나 이름 없음 |
| 대화 | "이 채팅은 AI로 생성된 가상의 내용이에요"를 작은 보조색 가운데 정렬로 두고 프롤로그, 턴 순 |
| 강조 | `**볼드**`는 굵게, `*...*`는 서술과 독백 강조 |
| 스크롤 | 하단이 아닐 때 "맨 아래로 이동" 버튼 |
| 헤더 숨김 | 본문 위에 겹쳐 페이드. 높이를 접지 않으며 목록 위 여백으로 첫 본문 보호. 숨긴 헤더는 접근성 및 초점 대상에서 제외 |
| 엔딩 | 확정 AI 응답의 위 왼쪽에 엔딩 이름 배지. 프라이머리 10% 배경과 전경색, 보조 배지 크기. 긴 이름 줄바꿈 |

<br>

### 3-3-2 입력, 추천과 비용

| 요소 | 표시 |
|---|---|
| 블럭 라벨 | 종류별 "상황 1", "대사 1". 숫자 자리 두 자리 폭 확보 |
| 블럭 추가와 삭제 | 아래에서 자라거나 같은 변을 잡고 접힘. 전체 입력 교체에는 칸별 모션 없음 |
| 전송 버튼 | 입력 있으면 위쪽 화살표, 없으면 채워진 재생 아이콘. 생성 중 스피너와 "응답을 받는 중" 접근성 이름 |
| 잠긴 입력 안내 | "응답을 만드는 중이에요. 끝나면 입력할 수 있어요". 반복 탭은 직전 토스트 교체 |
| 추천 | 마지막 턴 아래 3개. 로딩은 골격 칩 3개, 실패는 오류와 재시도. 같은 묶음의 등장은 한 번 |
| 비용 버튼 | 전송 왼쪽 4px. 이프 마크, 비용과 작은 안내 아이콘. 접근성 이름 "이프 안내" |
| 할인 표시 | 적용가가 정가보다 작으면 취소선 정가와 적용가. 같으면 "N 이프"만 표시 |
| 비용 미확인 | 숫자 자리만 쉬머. 두 입력 모드와 전송, 랜덤, 스피너 상태에서 같은 자리 |
| 비용 팝오버 | 버튼 위 오른쪽 정렬, 제목 "한 턴에 쓰는 이프". AI 응답, 켠 경우 실시간 이미지, 구분선, 합계 순 |
| AI 응답 항목 | 오른쪽에 모델 이름. 긴 응답이면 이름 뒤 ", 긴 응답". 항목별 정가와 체험 적용가 |
| 체험 안내 | 적용되는 체험이 남으면 "무료 체험 N회 남음" 또는 "무료 체험 무제한". 비적용과 소진은 줄 없음 |
| 합계 | 이프 마크와 정가 및 적용가를 굵게 표시 |

### 3-3-3 설정과 메뉴

| 요소 | 표시와 동작 |
|---|---|
| 모델 버튼 | 보조 버튼, 모델 이름과 아래 셰브론. 비용 없음. 접근성 이름 "AI 모델 선택"과 이름. 모델을 모르거나 목록에 없으면 숨김 |
| 채팅 응답 시트 | 제목 "채팅 응답", "AI 모델"과 "응답 길이" 그룹 |
| 모델 칸 | 서버 순서, 8px 간격, 입력 배경과 기본 테두리. 굵은 이름, 턴 비용 배지, 보조색 설명 |
| 설명 | LITE "빠르고 가볍게 주고받아요", AURORA "풍부한 묘사로 몰입감을 더해요". 모르는 코드는 설명 없음 |
| 선택한 모델 | 프라이머리 테두리와 연한 배경. 배지는 화면 배경색 캡슐과 프라이머리 글자 |
| 긴 응답 | 자 아이콘, "긴 응답", "한 번에 더 많은 장면을 보여줘요", 오른쪽 스위치 |
| 모델 저장 실패 | "AI 모델을 바꾸지 못했어요" |
| 긴 응답 저장 실패 | "긴 응답 설정을 바꾸지 못했어요" |
| 채팅 설정 버튼 | 입력 추가 버튼 오른쪽 설정 아이콘. 접근성 이름과 시트 제목 "채팅 설정" |
| 채팅 기능 그룹 | "실시간 이미지": "대화에 따라 인물 한 명의 표정과 모습이 달라져요". "AI 추천 입력": "AI가 다음 전개를 추천해줘요" |
| 입력 모드 그룹 | "블럭 입력": "상황과 대사를 나눠서 입력해요" |
| 설정 행 | 아이콘, 라벨과 설명, 오른쪽 스위치. 실시간 이미지 라벨 오른쪽에 이미지 비용만 표시 |
| 이미지 비용 안내 | 이미지 체험을 다 쓴 회원에게만 배지 왼쪽 "실시간 이미지 안내" 버튼. "이미지를 만들지 못한 경우 사용된 이프가 자동으로 취소돼요" 팝오버 |
| 메뉴 | "채팅 메뉴", 회원 이프 카드, "새 채팅 시작하기", "공유하기", 회원 "신고하기", 위험색 "삭제하기" 순 |
| 새 채팅과 공유 요청 중 | 해당 항목 오른쪽 스피너와 중복 클릭 금지 |
| 삭제 확인 | "채팅을 삭제할까요?", "삭제하면 목록에서 사라지며 되돌릴 수 없어요", "남겨두기"와 위험색 "삭제하기" |
| 삭제 중 | 문구 공간을 유지한 중앙 스피너, 접근성 이름 "삭제 중". 두 버튼과 배경 닫기 잠금 |

### 3-3-4 생성 대기와 이미지

| 상태 또는 요소 | 표시 |
|---|---|
| 첫 조각 전, 이미지 꺼짐 | "다음 내용 준비 중" 쉬머, 접근성 이름 "답변을 작성하고 있어요". 본문과 같은 글꼴, 크기와 행간 |
| 첫 조각 전, 이미지 켜짐 | "어울리는 표정 찾는 중" → "다음 내용 준비 중" → "장면 완성 중" → "다음 대사 고민 중". 접근성 이름 "다음 장면을 만들고 있어요" |
| 이미지 대기 배치 | 순환 문구 아래 20px, 4:3 장면 썸네일 자리. 첫 표시 가능한 텍스트나 이미지에 대기를 페이드로 교체 |
| 높이 | 대기가 차지한 높이를 본문이 그만큼 자랄 때까지 최소 높이로 유지. 재생성도 동일 |
| 이미지 | 수신 즉시 4:3 영역 예약, 원본 전체 표시. 추가 등장 지연과 중복 이름 캡션 없음 |
| 인물 접근성 | 대체 텍스트 "{name} 인물 이미지", 버튼 이름 "{name} 인물 이미지 크게 보기" |
| 장면 접근성 | "장면 이미지", "장면 이미지 크게 보기" |
| 실패한 이미지 | 블록 제거. 깨진 아이콘, 대체 텍스트와 URL 원문을 남기지 않음 |

이미지 대기의 마스코트는 처음 한 번 화가 베레모와 붓을 준비하고, 작은 4:3 도화지에 밤 창가에서 달을 보는 인물화를 그린다. 밑그림, 밑칠, 인물과 마무리 순서로 진행하며 약 15초에 사인한다. 이후에도 기다리면 그림을 올려다보고 종이를 넘겨 같은 그림을 반복한다.

그림은 적은 획과 느린 붓끝으로 표현한다. 밑그림 뒤 숨을 돌리고 인물 뒤 고민하며, 물감 색을 바꿀 때 발치 물그릇에 붓을 헹군다. 붓은 몸과 따로 움직여 끌림, 눌림과 획 끝의 튕김을 표현한다. 인물은 옆선, 머리카락과 표정을 갖춘다. 마스코트는 브랜드 색, 그림과 소품은 회색과 옅은 색을 쓴다. 동작 줄이기에서는 완성한 그림을 보는 장면으로 정지한다.

### 3-3-5 안내와 공유본

| 요소 | 표시 |
|---|---|
| 투어 | 딤, 대상 하이라이트와 카드. 기본 중앙 정렬, 가장자리에서는 해당 변 정렬. 카드가 화면과 앱 프레임을 벗어나지 않음 |
| 스텝 | 블럭 모드는 상황과 대사 추가 함께 강조, 일반 모드는 상황 추가만 강조. 다음은 설정, 전송 |
| 추천 힌트 | "AI가 추천하는 입력이에요", "탭하면 바로 전송되고, 연필 버튼으로 고쳐서 보낼 수 있어요" |
| 이미지 안내 | 설정 시트가 자리 잡은 뒤 전체 딤. 실시간 이미지 행만 모서리 있는 하이라이트, 시트 가장자리에서 8px 안쪽과 내부 여백 8px |
| 안내 카드 | 딤이 반쯤 나타날 때 강조 행 바로 아래. "실시간 이미지를 켜보세요", "대화에 따라 달라지는 인물의 모습을 볼 수 있어요", "확인" |
| 공유 실패 | "공유 링크 생성에 실패했어요" |
| 공유본 헤더 | 홈 링크 로고와 스토리 제목. 본문과 함께 나타나며 계속 표시 |
| 공유본 본문 | AI 생성 안내, 프롤로그와 턴. 원본의 강조, 이미지와 엔딩 배지 유지. 메시지별 순차 등장 없음 |
| 공유본 CTA | "나만의 스토리 만들고 채팅하기" 고정 |
| 공유본 조회 실패 | "공유된 채팅을 찾을 수 없어요"와 홈 이동 |

### 3-3-6 피드백

| 요소 | 표시 |
|---|---|
| 헤더 | 뒤로가기와 "피드백", 하단 탭 없음 |
| 제목과 설명 | "써보면서 아쉬웠던 점이 있나요?", "불편한 점이나 바라는 기능을 알려주세요" |
| 안내 | "보내주신 피드백은 다음 개선에 꼼꼼히 참고할게요" |
| 본문 | 카운터 `0 / 500` |
| 이메일 | "답변이 필요하시면 이메일을 남겨주세요" |
| 제출 | "피드백 보내기". 진행 중 문구 공간을 유지한 "피드백 전송 중" 스피너 |
| 빈 본문 | 버튼 위 "피드백 내용을 입력해주세요". 유효 입력에서 제거 |
| 성공 | "소중한 피드백을 보내주셔서 감사해요" |
| 실패 | "피드백 전송에 실패했어요" |
