# 2-1 유저 스토리

<br>

### 2-1-1 사용자 목표

| ID | 사용자 | 원하는 것 | 이유 |
|---|---|---|---|
| CHAT-US-001 | 채팅을 이어가는 사용자 | 채팅의 제목, 마지막 장면과 활동 시각을 함께 보고 싶다 | 이어서 볼 채팅을 찾고 싶다 |
| CHAT-US-002 | 이전에 채팅한 사용자 | 채팅을 다시 열어 저장된 이력과 진행 중인 응답을 이어 보고 싶다 | 화면을 떠나도 이야기의 맥락을 잃지 않고 싶다 |
| CHAT-US-003 | 채팅을 정리하는 사용자 | 원하지 않는 채팅을 삭제하고 싶다 | 내 목록을 정리하고 싶다 |
| CHAT-US-004 | 플레이하는 사용자 | 프롤로그와 대화 이력을 순서대로 읽고 싶다 | 이야기의 맥락을 이해하고 싶다 |
| CHAT-US-005 | 입력하는 사용자 | 상황과 대사를 구분하거나 강조해 편한 입력 방식으로 보내고 싶다 | 의도한 행동과 감정을 표현하고 싶다 |
| CHAT-US-006 | 응답을 기다리는 사용자 | 생성 진행 상태와 도착한 내용을 보고 싶다 | 중복 전송 없이 기다리며 이야기에 몰입하고 싶다 |
| CHAT-US-007 | 다음 입력이 막막한 사용자 | AI 추천을 고쳐 쓰거나 바로 보내고 싶다 | 직접 쓰는 자유를 유지하면서 다음 전개의 도움을 받고 싶다 |
| CHAT-US-008 | 대화를 읽는 사용자 | 새 응답과 이전 내용을 원하는 위치에서 읽고 싶다 | 응답이 늘어나도 읽던 위치를 잃지 않고 싶다 |
| CHAT-US-009 | 연결이나 생성이 실패한 사용자 | 저장된 결과를 확인하고 입력을 유지한 채 다시 시도하고 싶다 | 성공 여부를 잘못 이해하거나 입력을 잃고 싶지 않다 |
| CHAT-US-010 | 처음 채팅하는 사용자 | 입력과 설정 사용법을 안내받고 싶다 | 첫 채팅을 시작하는 방법을 이해하고 싶다 |
| CHAT-US-011 | 응답을 바꾸려는 사용자 | 마지막 AI 응답을 다시 생성하고 싶다 | 어색한 전개를 바꾸어 이야기를 이어가고 싶다 |
| CHAT-US-012 | 플레이하는 사용자 | 장면에 맞는 이미지를 본문 위치에서 바로 보고 확대하고 싶다 | 응답이 끝날 때까지 기다리지 않고 이야기에 몰입하고 싶다 |
| CHAT-US-013 | 엔딩에 도달한 사용자 | 엔딩 도달을 확인한 뒤에도 계속 대화하고 싶다 | 완성의 성취감과 이후 전개를 함께 즐기고 싶다 |
| CHAT-US-014 | 이야기를 공유하는 사용자 | 지금까지 진행한 채팅을 링크로 전달하고 싶다 | 내가 만든 이야기를 다른 사람에게 보여주고 싶다 |
| CHAT-US-015 | 공유 링크를 받은 사람 | 로그인이나 설치 없이 공유된 이야기를 읽고 싶다 | 부담 없이 이야기를 구경하고 싶다 |
| CHAT-US-016 | 서비스를 이용하는 사용자 | 개선 의견을 보내고 필요하면 회신 이메일을 남기고 싶다 | 불편한 점을 알리고 접수 결과를 확인하고 싶다 |
| CHAT-US-017 | 응답 방식을 고르는 회원 | 모델과 응답 길이를 바꾸고 적용 비용을 확인하고 싶다 | 원하는 묘사와 비용에 맞춰 플레이하고 싶다 |
| CHAT-US-018 | 채팅 설정을 바꾸는 사용자 | 이미지, 추천 입력과 입력 모드를 골라 계속 쓰고 싶다 | 내 기기의 이용 방식에 맞추고 싶다 |
