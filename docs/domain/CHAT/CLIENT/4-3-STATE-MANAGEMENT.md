# 4-3 상태 관리

<br>

### 4-3-1 확정 상태와 진행 상태

| 상태 | 소유와 교체 조건 |
|---|---|
| 확정 턴 | 상세 응답. 클라이언트의 미확정 버블과 분리 |
| 진행 응답 | 도착 순서의 텍스트와 이미지 조각 목록. 스트림을 다시 시작하면 초기화 |
| 완료 교체 | 진행 조각을 먼저 지우지 않고 상세 성공 때 확정 턴과 한 번에 교체 |
| 명시적 실패 | 낙관적 사용자 버블과 진행 조각 함께 제거. 재생성의 이전 본문과 이미지, 입력 수정의 숨긴 턴 함께 복구 |
| 입력 수정 편집 | 대상 턴과 고치던 입력. 수정 완료에만 비우고 실패와 거절에는 유지. 대상 턴이 상세에서 사라지면 표시하지 않음 |
| 진행 중 숨김 | 재생성과 입력 수정은 대상 턴 자리에 진행 블록. 입력 수정은 그 뒤 확정 턴을 화면에서만 숨김 |
| 결과 불명 | 이전 응답을 임의 확정하지 않고 상세 결과 사용 |
| 추천 | 서버 상세의 마지막 턴이 기준. 별도 생성의 성공 응답이나 completed의 choices로 직접 교체하지 않음 |
| 설정 | 이미지와 추천 및 입력 모드는 기기, 모델과 긴 응답은 채팅별 서버 상태 |
| 요청 스냅샷 | 시작 시점 설정을 진행 블록과 요청에 함께 사용. 중간 설정 변경과 분리 |
| 읽던 위치 | 진행 조각과 확정 턴 교체에서 유지. 로딩이 줄어 앵커가 내려앉지 않게 최소 높이 보존 |

이벤트와 복구 결과를 구현한다. ([4-1 연동 계약](4-1-CONTRACT.md), [2-2-3 복구](2-2-REQUIREMENTS.md#2-2-3-생성-실패와-복구))
