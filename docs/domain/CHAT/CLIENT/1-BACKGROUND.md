# 1 배경

<br>

### 1-1 사용자와 목적

사용자는 스토리의 프롤로그를 읽고 상황과 대사를 입력해 이야기를 이어간다. 이전 채팅을 다시 열거나 원하는 응답으로 바꾸고, 지난 입력을 고치거나 원하는 장면에서 새 채팅으로 갈라 이어간다. 진행한 이야기는 링크로 전달한다. 응답이 늦거나 연결이 끊겨도 저장된 결과와 진행 상태를 구분할 수 있어야 한다.

| 범위 | 책임 |
|---|---|
| CHAT | 채팅 목록과 플레이, 입력과 추천, 모델과 응답 길이, 이미지와 엔딩, 공유, 서비스 피드백 |
| STORY | 채팅을 시작할 스토리와 시작 설정 선택, 스토리 상세와 제작 |
| ACCOUNT | 회원과 게스트, 동의, 페르소나 관리, 게스트 목록 소유권 |
| PAYMENT | 정책과 체험 잔여, 잔액, 이프 부족 안내와 충전 |
| MODERATION | 참조 스토리 신고와 입력 검수 |
| BACKEND와 AI | 생성과 저장, 과금, 모델 목록, 선택지 내용과 엔딩 판정 |

<br>

### 1-2 용어

| 용어 | 의미 |
|---|---|
| 턴 | 사용자 입력, AI 응답, 다음 선택지로 구성한 한 번의 진행 |
| 이어쓰기 | 다음 사용자 입력으로 새 턴을 만드는 동작 |
| 재생성 | 마지막 턴의 사용자 입력은 유지하고 AI 응답을 다시 만드는 동작 |
| 입력 수정 | 완료된 턴의 사용자 입력을 고쳐 그 턴부터 새 턴 하나로 다시 만드는 동작 |
| 숨긴 턴 | 입력 수정으로 고친 턴부터 마지막 턴까지 화면에서 빠진 턴 |
| 포크 | 지정한 턴의 AI 응답까지를 복사한 새 채팅을 만드는 동작. 원래 채팅은 그대로 남음 |
| 생성 이어받기 | 서버에서 진행 중이거나 보관 중인 같은 응답을 다시 받는 동작 |
| 추천 입력 | 첫 시작의 제안 또는 마지막 턴의 선택지. 편집하거나 바로 전송 가능 |
| 공유본 | 공유한 시점까지의 채팅을 누구나 읽을 수 있는 스냅샷 |
