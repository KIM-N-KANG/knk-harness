# 3-3 CHAT 웹 표현

<br>

### 3-3-1 입력과 본문

| 요소 | 웹 값 |
|---|---|
| 서사 본문 | 공용 서사 서체. 본문 16px와 행간 28px, 추천 14px와 행간 24.5px |
| 일반 입력 | 최대 높이 `20dvh` |
| 비용 | 12px 보조색. 버튼과의 간격은 공통 화면 표현의 4px 적용 |
| 메시지 여백 | 세로 20px, 가로 16px |
| 추천 | 위 12px, 항목 간 8px. 8px 이동과 300ms ease-out, 80ms 순차 지연. 같은 묶음은 한 번 |
| 재생성 | 아래 여백 20px, 추천 위 12px |
| 이미지 | 4:3, 원본 맞춤, 좌우 16px, 모서리 20px, 1px 시맨틱 테두리 |
| 이미지 간격 | 앞 텍스트에서 40px, 뒤 텍스트까지 20px. 첫 이미지 위 추가 여백 없음 |
| 공유 진입 | 전체 opacity 150ms. 메시지별 순차 등장 없음 |
| 복사 성공 | "채팅 공개 링크가 복사되었어요" |
| 피드백 | 필드 행 간격 24px, 필드 그룹 아래 32px. 본문 하단 fade 바로 아래 CTA, 추가 상단 패딩 없음 |

<br>

### 3-3-2 목록과 대기 모션

| 요소 | 표현 |
|---|---|
| 목록 재정렬 | 보이는 목록의 행이 새 위치로 이동. stiffness 360, damping 32, mass 0.6 스프링 |
| 겹침 | 위 행이 앞에 놓이며 배경색으로 뒤 행의 글자 겹침 방지 |
| 행 추가와 제거 | opacity 200ms ease-out. 처음 목록 표시는 모션 없음 |
| 동작 줄이기 | 재정렬과 행 페이드 없이 즉시 교체 |
| 응답 대기 | 500ms EASE_OUT 등장. 첫 조각에 대기 150ms 퇴장과 본문 200ms 등장 |
| 대기 패딩 | 좌우 16px. 이미지 켜짐은 위아래 20px, 꺼짐은 16px |
| 순환 문구 | 전환과 쉬머 각각 4초, y 8px에서 0으로 500ms |
| 장면 썸네일 | 문구 아래 20px. 옅은 배경, 테두리 없음. 150ms 지연 뒤 600ms로 opacity, y 16px와 scale 0.97에서 등장 |
| 동작 줄이기 대기 | 페이드만 사용하고 그림 안무는 정지 |

본문의 순서와 접근성 이름은 공통 표현을 적용한다. ([공통 3-3](../3-3-LAYOUT.md))
