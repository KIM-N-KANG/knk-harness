# 4-2 컴포넌트 구조: 웹

<br>

### 4-2-1 책임

| 구성 | 책임 |
|---|---|
| 채팅 목록 훅 | 회원 API와 게스트 목록 소유권, 활동순 목록. 회원과 게스트 목록에 같은 미리보기 변환 적용 |
| 채팅방 | 상세, 생성과 설정, 입력, 추천, 투어와 화면 조립 |
| 스트림 훅 | 이어쓰기, 재생성, 입력 수정, 재진입을 같은 생성 추적 경로로 연결. 진행 블록이 대신하는 턴 ID 제공 |
| 메시지 목록 | 대상 턴 자리의 진행 블록과 입력 수정 중 뒤 턴 숨김, 편집 중 흐림 |
| 턴 항목 | 확정 버블, 입력 수정 편집기와 턴 아래 버튼. 편집 상태와 포크 요청은 채팅방이 관리 |
| 생성 추적 | SSE 수신과 재연결, 상세 확인, 종료 결과 구분 |
| 메시지 파서와 공용 렌더 | 스트림, 상세, 프롤로그와 공유본의 같은 조각 표현 |
| 컴포저 | 일반 입력, 블럭, 추천 파싱, 강조와 전송 입력 변환 |
| 모델 훅 | 모델 목록과 상세 설정, 낙관적 저장과 실패 복구 |
| 채팅 메뉴 | 메뉴와 이프 내역 화면 전환, 내역 화면의 뒤로가기 레이어. 시트 높이는 보이는 화면을 측정해 애니메이션하며 CSS의 auto 높이 보간에 맡기지 않음. 내역 목록은 PAYMENT의 my 공용 목록 사용 |
| 공유본 | 스냅샷 조회와 읽기 전용 렌더. 채팅 생성 UI와 분리 |
| 피드백 폼 | 검증, 플랫폼 고정, 제출 잠금과 결과 처리 |

이미지 블록은 텍스트 문단의 형제이며 HTML `p` 안에 중첩하지 않는다. 공통 상태와 연동 계약을 따른다. ([공통 4-1](../4-1-CONTRACT.md))
