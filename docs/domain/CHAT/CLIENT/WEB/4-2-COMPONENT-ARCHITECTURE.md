# 4-2 컴포넌트 구조: 웹

<br>

### 4-2-1 책임

| 구성 | 책임 |
|---|---|
| 채팅 목록 훅 | 회원 API와 게스트 목록 소유권, 활동순 목록 |
| 채팅방 | 상세, 생성과 설정, 입력, 추천, 투어와 화면 조립 |
| 스트림 훅 | 이어쓰기, 재생성, 재진입을 같은 생성 추적 경로로 연결 |
| 생성 추적 | SSE 수신과 재연결, 상세 확인, 종료 결과 구분 |
| 메시지 파서와 공용 렌더 | 스트림, 상세, 프롤로그와 공유본의 같은 조각 표현 |
| 컴포저 | 일반 입력, 블럭, 추천 파싱, 강조와 전송 입력 변환 |
| 모델 훅 | 모델 목록과 상세 설정, 낙관적 저장과 실패 복구 |
| 공유본 | 스냅샷 조회와 읽기 전용 렌더. 채팅 생성 UI와 분리 |
| 피드백 폼 | 검증, 플랫폼 고정, 제출 잠금과 결과 처리 |

이미지 블록은 텍스트 문단의 형제이며 HTML `p` 안에 중첩하지 않는다. 공통 상태와 연동 계약을 따른다. ([공통 4-1](../4-1-CONTRACT.md))
