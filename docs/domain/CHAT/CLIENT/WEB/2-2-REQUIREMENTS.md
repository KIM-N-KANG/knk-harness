# 2-2 요구사항: 웹

<br>

### 2-2-1 진입과 입력

| 상황 | 결과 |
|---|---|
| 게스트 | 동의 후 체험. 소진과 회원 전용 모델 선택은 로그인 안내 |
| 전송 | 버튼, 폼 제출, Shift 없는 Enter. IME 조합 중 Enter는 전송하지 않음 |
| 전송 후 | 입력 비우기와 포커스 유지. 생성 중 입력 잠금 |
| 작성 도구 | 삭제 X는 Tab 순서에서 제외하되 클릭과 터치 허용 |
| 모바일 | 주소창과 키보드 변화에도 입력창, CTA와 마지막 메시지가 가려지지 않음. 이중 스크롤과 위치 튐 없음 |
| 공유 발급 | 웹 열람 링크 복사 후 성공 토스트, 메뉴 닫기 |
| 공유 열람 | 유효 공유본 색인 허용, 조회 불가 URL은 색인과 링크 추적 금지 |
| 공유 CTA | 간편 제작 퍼널로 바로 진입. 동의와 체험은 해당 진입 조건 적용 |

공통 입력과 게스트 범위를 구체화한다. ([공통 2-2](../2-2-REQUIREMENTS.md))
