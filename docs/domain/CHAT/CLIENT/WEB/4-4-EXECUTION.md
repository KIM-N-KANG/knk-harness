# 4-4 CHAT 웹 실행

<br>

### 4-4-1 수신과 재연결

| 단계 | 실행 |
|---|---|
| SSE | fetch와 ReadableStream. 공용 요청 타임아웃 래퍼를 우회하여 클라이언트 시간 상한 없음 |
| 끊김 | 아는 생성 ID로 즉시 재연결. 실패하면 상세에서 진행 중 생성 재확인 |
| 상한 | 첫 재연결 포함 최대 4회, 실패 뒤 대기 1초, 2초, 4초 |
| 상세 실패 | 생성 완료로 처리하지 않고 다음 차례로 넘김 |
| ID 변경 | 따라가는 수신이 없을 때만 다른 생성 이어받기 |
| 상한 소진 | 같은 생성을 곧바로 다시 따라가지 않음. 무한 재연결 방지 |
| 상세 진입 | `refetchOnMount: 'always'`. 마운트 이후 첫 조회 종료 전 로딩 |
| 요청 | 첫 턴 null도 포함해 lastTurnId 항상 전달 |
| 완료와 추천 | 공통 확정 교체와 선택지 생성 순서 사용 |

<br>

### 4-4-2 설정과 공유

| 작업 | 실행 |
|---|---|
| 모델과 긴 응답 | 상세 캐시를 먼저 변경하고 해당 필드만 저장. 오류 시 이전 필드 값 복구와 토스트 |
| 게스트 모델 | 다른 모델은 저장 요청 없이 로그인 안내 |
| 이미지 안내 | 정상 이어쓰기 완료만 기기 횟수에 반영. 두 번째 완료의 설정으로 예약 판단 |
| 공유 메타데이터 | 공유본과 스토리 썸네일 조회. 제목, 마커를 뺀 프롤로그 발췌와 이미지 사용. 이미지 없으면 브랜드 이미지 |
| 공유 조회 실패 | 기본 제목과 noindex, nofollow. 화면 조회는 계속 |
| 공유 열람 | 스냅샷 조회, SSE와 주기 재조회 없음 |

### 4-4-3 이미지 허용과 안무

이미지 URL은 HTTPS, 정확한 `cdn.manyak.app` 또는 `dev-cdn.manyak.app` 호스트, `/characters/generated/`, `/characters/originals/`, `/characters/uploaded/`, `/chat-images/`, `/scenes/originals/` 경로를 모두 검사한다. Next 이미지 최적화 허용과 별개로 검사한다. 저장 마커의 문법은 공통 계약을 사용한다. ([공통 4-1-4](../4-1-CONTRACT.md#4-1-4-이미지와-텍스트))

마스코트 대기의 계산은 아래 조건을 유지한다.

| 구성 | 현재 실행 조건 |
|---|---|
| 준비와 반복 | 준비 1.3초 한 번 후 밑그림, 휴식, 밑칠, 인물, 딴짓, 마무리, 완성, 종이 넘기기의 8막 16.43초 반복. 시작부터 15초에 사인 |
| 그림 | 11획, 모든 획 초당 격자 160칸보다 느리게. 무대 폭 0.54인 4:3 도화지 한 장에 층으로 누적 |
| 층 | 지난 막은 완성, 미래 막은 시작 전. 밤 창은 달 원을 뺀 영역, 달빛은 진행만큼 채우며 종이 안으로 자름 |
| 붓 | 몸 회전과 별도 붓 회전으로 붓털 끝을 길에 맞춤. 누름은 폭만 바꾸며 붓끝 계산에서 제외 |
| 길 | 84×63 격자의 절대 SVG M, L, Q, C. 앞뒤 방향 평균으로 기울임 |
| 동작 | 획 사이 점프에서 붓 튕김, 휴식에는 세우기, 번뜩임 점프에 한 바퀴 회전 |
| 색과 헹굼 | 휴식, 딴짓, 종이 넘기기 중간에 연필 회색, 회색, 옅은 초록, 연필 회색으로 변경. 물그릇은 헹굼 때 붓끝 위치 |
| 종이와 배율 | 위 가장자리 축으로 넘겨 뒷면과 흐려짐 표시. 바탕 점 제외 소품과 마스코트는 중심 기준 0.72배, 포인터 좌표도 같은 배율 역변환 |
| 색상 | 브랜드 색은 마스코트, 선과 소품은 보조 및 3차 전경색. 밑칠은 종이와 연필 혼합, 달빛과 볼터치는 옅은 브랜드 색 |
| 포인터와 모션 | hover와 fine pointer에서 눈이 포인터를 따름. 동작 줄이기는 완성 그림을 올려다보는 정지 장면 |

화면의 문구, 순서와 간격은 앞 단계에서 정한다. ([3-3](3-3-LAYOUT.md))
