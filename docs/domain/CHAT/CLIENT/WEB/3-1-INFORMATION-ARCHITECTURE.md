# 3-1 CHAT 웹 경로

<br>

### 3-1-1 URL과 셸

| 경로 | 화면 | 접근과 셸 |
|---|---|---|
| `/chats` | 채팅 목록 | 회원과 게스트. 메인 헤더와 하단 탭 |
| `/chats/{chatId}` | 채팅방 | 본인 채팅. 자체 채팅 헤더와 입력, 하단 탭 없음 |
| `/share/{shareId}` | 공유본 | 공개 열람. 로고와 제목, 제작 CTA |
| `/my/feedback` | 피드백 | 회원과 게스트. 뒤로가기 헤더, 하단 탭 없음 |

공유본의 정보 순서는 공통 화면 구성을 따른다. ([공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md))
