# CHAT 웹 이동

<br>

### 진입과 뒤로가기

| 시작 | 이동 |
|---|---|
| 스토리 상세의 채팅 시작 | 상세 위에 채팅방 추가. 뒤로가기는 상세, 다음은 상세 이전 화면 |
| 방 메뉴의 새 채팅 | 현재 방을 새 방으로 교체. 이전 방으로 돌아가지 않음 |
| 앱 안 이동으로 연 방 | 헤더 뒤로가기는 이전 화면 |
| 주소나 알림으로 직접 연 방 | 헤더 뒤로가기는 `/chats`로 교체 |
| 방 삭제 | 가장 가까운 아래 탭 기록까지 되돌린 뒤 채팅 탭. 찾을 수 없거나 이전 문서의 기록이면 현재 화면 교체 |
| 목록 삭제 | 목록에 머물고 해당 카드만 제거 |
| 피드백 뒤로가기 | 앱 안 기록이 있으면 뒤로, 직접 진입이면 `/my`로 교체 |
| 공유 | 발급과 복사 성공 후 메뉴 닫기. 실패는 메뉴 유지 |

투어, 이미지 안내와 뷰어의 뒤로가기는 현재 오버레이부터 닫는다. 사용자 조작 없이 자동 열린 안내는 공용 히스토리 조건에 따라 화면 기록을 추가하지 않을 수 있다. 입력과 응답 분기는 공통 흐름을 적용한다. ([공통 3-2](../INTERACTION-FLOWS.md))
