# 4-2 CHAT Android 구성

<br>

### 4-2-1 책임과 경계

| 구성 | 책임 |
|---|---|
| chat data | DTO와 Repository 구현, SSE 전송과 이벤트 변환, 완료 시 목록 변경 신호 |
| chat domain | 상세, 턴, 진행 중 생성과 Repository 계약 |
| 채팅방 ViewModel | 단일 생성 작업, 재연결과 확정, 설정과 안내 상태, 분석 이벤트 |
| 목록 ViewModel | 활동 변경 신호와 화면 복귀 조회 |
| 컴포저 | 커서와 선택 영역, 강조 삽입, 블럭별 초점. 변경은 Intent로 전달 |
| designsystem | 텍스트와 이미지 조각 파서, 인물 이미지, 전체 화면 뷰어, 마스코트와 순환 문구 |
| my | 피드백 API와 폼, 입력 검증과 제출 |
| app | 화면 진입, 스택 교체와 탭 복귀 조립 |

목록과 채팅방은 같은 참조 스토리 유효 조건을 사용한다. Composable 재구성으로 도메인 호출과 복구를 시작하지 않는다. 파서는 스토리 상세의 상황 설명에서도 재사용한다. ([공통 4-1](../4-1-CONTRACT.md))
