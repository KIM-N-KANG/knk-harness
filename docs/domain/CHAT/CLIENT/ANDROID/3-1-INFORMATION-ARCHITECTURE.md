# 3-1 CHAT Android 화면 구성

<br>

### 3-1-1 목적지와 화면 내부 상태

| 영역 | 위치 |
|---|---|
| 목록 | 메인 채팅 탭 |
| 채팅방 | 목록 또는 스토리 상세 위의 별도 목적지 |
| 메뉴와 설정, 모델 시트 | 현재 채팅방 안의 시트 |
| 투어와 이미지 안내 | 현재 채팅방과 설정 시트 위의 안내 |
| 이미지 뷰어 | 현재 화면 내부 상태. 별도 목적지 없음 |
| 공유 전달 | Android 시스템 공유 시트. 수신자는 웹 공유본 열람 |
| 피드백 | 마이에서 여는 화면 |

공통 정보 순서와 로그인 범위를 따른다. ([공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md), [2-2](2-2-REQUIREMENTS.md))
