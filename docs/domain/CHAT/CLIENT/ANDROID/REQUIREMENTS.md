# CHAT Android 요구사항

<br>

### 화면과 수명

| 상황 | 결과 |
|---|---|
| 사용자 | 로그인 필수. 게스트 동의와 로그인 전환 분기 비적용 |
| 공유 발급 | 발급한 웹 링크를 Android 공유 시트로 전달. 복사 성공 토스트 없이 메뉴 닫기 |
| 목록 갱신 | 당겨 새로고침할 때 기존 목록 유지. 실패는 하단이나 토스트. 첫 로딩, 빈 목록과 전체 오류에서는 불필요한 당김 없음 |
| 헤더 | 빈 본문 탭으로만 전환. 텍스트 선택은 제공하지 않음. 버튼, 추천, 이미지와 키보드 닫기 탭 제외 |
| 헤더 수명 | 구성 변경에서 숨김 유지. 로딩과 실패, 투어 중에는 항상 표시 |
| 작성 버튼 | 상황과 대사 추가, 강조와 삭제 탭은 포커스 유지. 빈 영역과 본문 탭은 키보드 닫기 |
| 입력칸 삭제 | 현재 칸 삭제 시 다음 칸, 없으면 이전 칸으로 초점 이동. 마지막 칸 삭제, 모드 교체와 전송 잠금은 편집 종료 |
| 구성 변경 | 입력 잠금, 누적 응답과 스크롤 앵커 유지. 투어 스텝, 이미지 안내와 설정 시트 유지 |
| 앱 백그라운드 | 수신만 중단. 복귀 시 상세로 확정과 진행 상태 확인 |
| 방 이탈과 프로세스 종료 | 이미지 안내 예약과 표시 상태 복원 없음. 기기 기록으로 다시 안내하지 않음 |
| 안내 접근성 | 투어 뒤 본문과 이미지 안내의 나머지 설정 항목을 보조기술에서 제외 |

공통 목록, 공유와 생성 요구를 적용한다. ([공통 2-2](../REQUIREMENTS.md))
