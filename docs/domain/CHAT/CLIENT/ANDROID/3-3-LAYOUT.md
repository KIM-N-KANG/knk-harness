# 3-3 화면 배치: 안드로이드

<br>

### 3-3-1 배치와 접근성

| 요소 | Android 표현 |
|---|---|
| 메시지 | 밴드 배치와 기존 Android 디자인 시스템 서사 서체 및 간격 |
| 헤더 | 목록 위 겹침, 200ms 페이드. 헤더 높이만큼 목록 위 여백 |
| 투어 | 같은 화면 위 딤과 카드. 회전 뒤 대상을 다시 측정하며 현재 스텝 유지 |
| 이미지 안내 | 시트 위 별도 안내. 강조된 스위치와 카드만 접근 가능 |
| 응답 대기 | 공통 4:3 그림과 순환 문구. 첫 조각에 대기를 같은 자리의 본문으로 교체 |
| 이미지 | 공통 4:3과 원본 맞춤, 풀스크린 뷰어. 상세와 같은 UI 사용 |
| 목록 재정렬 | 새 활동순으로 카드가 이동. Android 공용 모션 사용 |
| 턴 아래 버튼 행 | 다시 생성과 포크를 32dp 고스트 아이콘 버튼으로 나란히. 왼쪽 12dp, 아래 20dp, 추천 위 12dp. 잠기면 아이콘을 비활성 색으로 |
| 입력 수정 버튼 | 사용자 입력 배경 안 오른쪽 아래 32dp 고스트 아이콘 버튼. 본문 아래 20dp, 배경 아래 20dp, 오른쪽 12dp |
| 아이콘 | 입력 수정은 `pen-outline`, 포크는 `split-stroke-rounded` SVG를 옮긴 벡터 드로어블 |
| 편집기 | 사용자 입력과 같은 배경, 세로 20dp와 가로 16dp. 컴포저와 같은 입력칸이 내용만큼 자람. 버튼 행 위 12dp, 버튼 사이 8dp. 취소는 글자형, 보내기는 주 동작 작은 버튼이며 잠기면 비활성 색 |
| 고치는 중 흐림 | 고치는 턴의 응답과 뒤의 턴, 추천 영역을 불투명도 40% |
| 확인 창 | 앱 확인 다이얼로그. 왼쪽 글자 버튼, 오른쪽 확정 버튼. 사라질 뒤 턴이 있는 입력 수정만 danger 색, 나머지는 주 동작 색. 머무르는 버튼은 [Android 공통 배치](../../../../ui/ANDROID/3-3-LAYOUT.md)대로 세 창 모두 "닫기"이며 공통 문구의 "그대로 두기"를 대신함. 포크 확인의 확정 버튼은 "시작하기" |
| 메뉴 이프 카드 | 시트 위 보조 채움 바탕이라 다크에서도 시트와 구분. "내역"은 눌림 오버레이 톤을 한 겹 더한 바탕(라이트는 카드보다 진하고 다크는 밝음)과 기본 글자색. 강조색은 "충전"만 사용. 두 버튼 간격 4dp |
| 메뉴와 이프 내역 전환 | 시트 높이를 크기 전환으로 이어서 바꿈. 들어오는 화면은 24dp 가로 밀림과 페이드, 나가는 화면은 페이드. 시스템 애니메이션 배율 적용 |
| 이프 내역 화면 | 화면 높이의 70%. 머리글 고정, 목록만 스크롤. 목록을 끝까지 끌어도 시트는 닫히지 않음 |
| 이프 내역 머리글 | 돌아가기 아이콘과 "새로고침" 글자를 목록 줄 양쪽 선에 맞춤. 창 제목 "이프 내역". 열릴 때 초점을 옮기지 않음. 새로고침 중 문구 자리를 유지한 가운데 스피너와 잠금. 첫 조회 중에도 잠금 |

공통 문구와 이미지 대기의 그림을 적용하고 색, 서체와 간격은 기존 Android 토큰을 사용한다. ([공통 3-3](../3-3-LAYOUT.md))
