# 3-3 화면 배치: 안드로이드

<br>

### 3-3-1 배치와 접근성

| 요소 | Android 표현 |
|---|---|
| 메시지 | 밴드 배치와 기존 Android 디자인 시스템 서사 서체 및 간격 |
| 헤더 | 목록 위 겹침, 200ms 페이드. 헤더 높이만큼 목록 위 여백 |
| 투어 | 같은 화면 위 딤과 카드. 회전 뒤 대상을 다시 측정하며 현재 스텝 유지 |
| 이미지 안내 | 시트 위 별도 안내. 강조된 스위치와 카드만 접근 가능 |
| 응답 대기 | 공통 4:3 그림과 순환 문구. 첫 조각에 대기를 같은 자리의 본문으로 교체 |
| 이미지 | 공통 4:3과 원본 맞춤, 풀스크린 뷰어. 상세와 같은 UI 사용 |
| 목록 재정렬 | 새 활동순으로 카드가 이동. Android 공용 모션 사용 |

공통 문구와 이미지 대기의 그림을 적용하고 색, 서체와 간격은 기존 Android 토큰을 사용한다. ([공통 3-3](../3-3-LAYOUT.md))
