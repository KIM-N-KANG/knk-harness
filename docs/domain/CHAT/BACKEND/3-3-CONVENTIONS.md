# 3-3 구현 컨벤션

이 문서는 CHAT 도메인 코드를 작성하거나 수정할 때 반드시 지킬 규칙과 구현자가 선택할 수 있는 사항을 정한다.

트랜잭션과 잠금은 동시성에, 로그 이벤트 규칙은 관측에, 이름 토큰 치환과 후보 이름 구분은 처리 흐름에, 구현 위치는 AGENTS.md에 있다. ([5-2 동시성](5-2-CONCURRENCY.md), [5-4-5 구조화 로그 이벤트](5-4-OBSERVABILITY.md#5-4-5-구조화-로그-이벤트), [4-1-14 후보 이름 구분](4-1-PIPELINES.md#4-1-14-후보-이름-구분), [AGENTS.md](AGENTS.md))

<br>

### 3-3-1 이름과 용어

| 대상 | 규칙 |
|---|---|
| 패키지 | 채팅 패키지 아래에 API, 서비스, 저장, 모델, 전송 객체, AI 호출, 설정을 나눔<br>피드백은 별도 패키지 |
| 모델 이름 | 테이블의 단수형 |
| 전송 객체 | 요청은 `Request`, 응답은 `Response`, SSE 이벤트는 `Event`를 접미사로 사용<br>와이어 필드는 camelCase<br>AI 요청 필드는 snake_case, AI 완료 이벤트는 camelCase<br>DB 컬럼은 snake_case |
| AI 응답 역직렬화 | 알 수 없는 필드는 무시함<br>누락된 선택지 배열은 빈 배열로 처리 |
| 용어 | 용어집을 따름<br>턴 ID는 AI 응답 메시지의 PK |

<br>

### 3-3-2 계층 책임

| 계층 | 하는 일 | 하지 않는 일 |
|---|---|---|
| API 계층 | 형식 검증, 요청자 식별, 상태 코드 지정, SSE 응답의 문자 집합 지정, 잔액 부족 예외의 거절 응답 변환 | 비즈니스 판정, 저장 계층 호출 |
| 서비스 | 처리 순서 관리, 소유권 판정, 과금과 환불, AI 요청 조립, 스트림 중계, 응답 직전 이름 토큰 치환 | HTTP 세부 규칙, 직렬화 |
| 턴 저장 | 저장 트랜잭션 경계, 채팅 행 잠금, 판정 반영 | AI 호출, 과금 |
| 저장 계층 | 쿼리<br>잠금이 필요한 조회 메서드는 이름에 잠금 여부 표시 | 비즈니스 판정 |
| 외부 호출 | 호출과 변환<br>AI 호출과 S3 호출은 DB 트랜잭션 밖에서 수행<br>객체 존재 확인만 저장 트랜잭션 안에서 수행 | 재시도 정책 결정 |

<br>

### 3-3-3 요청 검증과 오류

| 대상 | 규칙 |
|---|---|
| 개별 필드의 길이, 필수 여부, 허용값 | 요청 객체의 필드에 애너테이션으로 선언 |
| 선택 기록 필드 | 형식 검증을 선언하지 않음<br>잘못된 값은 기록만 건너뛰고 턴은 진행 |
| 스트림 시작 전 실패 | 일반 오류 응답<br>스트림 시작 후 실패는 `error` 이벤트 |
| AI 오류 | AI 서버가 보낸 코드와 메시지를 그대로 중계<br>백엔드 자체 실패는 고정 코드와 문구 |

<br>

### 3-3-4 비동기와 이벤트

| 대상 | 규칙 |
|---|---|
| 턴 작업 | 검증, 과금, 조립은 요청 스레드에서 동기로 끝냄<br>AI 호출, 중계, 저장은 전용 실행기에서 수행 |
| 실행기 포화 | 작업이 거부되면 즉시 환불하고 스트림을 오류로 닫음 |
| 환불 판정 | 워커 종료 시 한 곳에서 판정<br>스트림 완료 콜백은 시작 전 취소만 처리 |
| 피드백 전달 | 애플리케이션 이벤트로 발행하고 리스너가 커밋 후 비동기 발송<br>발송 실패는 로그만 남김 |

<br>

### 3-3-5 테스트와 검증 도구

| 대상 | 규칙 |
|---|---|
| 작성 순서 | 동작을 바꾸는 작업은 실패하는 테스트를 먼저 작성 |
| 엔드포인트 변경 | 통합 테스트와 수동 호출 파일을 함께 갱신 |
| 동시성 | 잠금과 환불 규칙 변경은 동시 요청 테스트로 고정 |

<br>

### 3-3-6 구현자가 선택할 수 있는 것

| 선택 가능 | 조건 |
|---|---|
| 서비스 내부의 메서드 분할과 이름 | 없음 |
| 테스트 픽스처와 스텁의 구성 | 없음 |
| 조회 쿼리의 작성 방식 | 없음 |
| 로그 필드 추가 | 사용자 입력과 AI 본문 원문을 넣지 않음 |
