# 5-5 테스트 케이스

이 문서는 CHAT 도메인 코드의 계약과 오류 처리 규칙을 검증할 테스트 범위, 입력과 상황, 기대 결과를 정한다.

실행 명령과 수동 호출 파일 위치는 AGENTS.md에, 기대 결과의 상태 코드는 계약에 있다. ([AGENTS.md](AGENTS.md), [4-2 계약](4-2-CONTRACT.md))

<br>

### 5-5-1 테스트 범위

| 종류 | 확인 범위 | 외부 호출 | 실행 |
|---|---|---|---|
| 단위 | 후보 이름 구분, 선택지 비교 정규화, 거부 분류, 실시간 이미지 검증, AI 요청 직렬화, 실행기 설정, 환불 지표 등록 | 없음 | CI |
| 통합 | 컨트롤러부터 저장까지, SSE 이벤트 순서 | AI 서버는 테스트용 클라이언트로, S3는 모의 객체로 대체 | CI<br>H2, 스키마 자동 생성, 마이그레이션 비활성 |
| 동시성 | 이어쓰기와 재생성, 동시 재생성, 동시 공유 발급, 선택 기록 경쟁 | 지연을 넣은 테스트용 AI 클라이언트 | CI |
| 수동 | 엔드포인트 호출 | 실행 환경의 실제 의존성 | 서버 저장소의 HTTP 요청 파일 |

테스트 프로파일은 마이그레이션을 건너뛰므로 전체 테스트를 통과해도 DB 제약이 검증된 것은 아니다.

**외부 의존성과 테스트 데이터**

| 대상 | 방법 |
|---|---|
| AI 서버 | 통합 테스트는 테스트용 AI 클라이언트를 등록해 고정 토큰과 완료 결과를 반환하고 요청 본문과 헤더를 검사<br>오류 이벤트, 지연, 완료 없는 종료를 시나리오로 주입 |
| S3 | 업로드 위치 발급과 객체 확인은 업로드 저장소를 모의 객체로 교체 |
| Redis | 체험 카운터는 PAYMENT 도메인의 테스트 구성을 사용 |
| DB | 통합 테스트는 공유 H2의 PostgreSQL 모드<br>CHECK 제약과 인덱스는 실제 PostgreSQL에서 DB 문서 생성 스크립트로 검증 |
| 스토리 데이터 | 공개 스토리, 비공개 전환 스토리, 공개본이 있는 스토리를 각각 준비 |
| 외부 발송과 비밀값 | 테스트 프로파일이 Slack 웹훅, Google Form을 끄고 JWT는 더미 값 사용 |

<br>

### 5-5-2 생성, 조회, 삭제, 공유

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 채팅 생성 | 공개 스토리, 비공개 스토리의 소유자와 타인, 삭제된 스토리, 시작 설정 지정과 타 스토리 소속, 게스트의 페르소나 지정, 소유자 없는 스토리에 회원 | 201과 치환된 프롤로그, 404, 404, 지정 시작 설정 또는 404, 401, 403 |
| 페르소나 스냅샷 | 페르소나로 시작 후 원본 수정과 삭제 | 생성과 상세의 이름 유지, AI 요청의 주인공 본문이 설명으로 대체 |
| 일괄 조회 | 없는 ID, 형식 오류, 타인 소유, 회원의 소유자 없는 채팅, 빈 배열, 101개 | 제외와 갱신 시각 내림차순, 400 |
| 카드 데이터 | 공개 스토리, 비공개로 전환한 스토리, 엔딩 행이 교체된 스토리 | 현재 제목, 공개본 제목, 보관한 엔딩 이름 |
| 상세 | 소유자, 타인, 게스트 채팅에 회원, 턴 0개, 시스템 메시지 포함 | 턴 쌍과 선택지, 403, 403, 추천 입력 유무, 짝 없는 메시지 제외 |
| 삭제 | 소유자, 타인, 재삭제 | 204, 403, 404 |
| 공유 발급과 열람 | 같은 턴 수 재발급, 턴 진행 후 발급, 원본 삭제, 익명과 비공개 스토리 | 같은 토큰, 새 토큰, 404, 공개본 제목과 공유 범위에 포함된 턴만 반환 |
| 공유 범위 | 시스템 메시지가 포함된 채팅의 N번째 턴까지, 공유 범위에 포함된 턴 재생성 | 마지막 턴 누락 없음, 활성본 반영 |

### 5-5-3 턴 진행

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 이벤트 순서 | 정상 턴 | `started`, `token`, `completed` 순서와 `completed`의 저장 본문, 빈 선택지 |
| AI 요청 구성 | 턴 2개 있는 채팅, 입력 출처 지정, 시작 설정 참조 끊김 | 전체 내역과 이번 입력 분리, `user_source` 전달과 생략, 보관한 프롤로그 |
| 헤더 | 간편 제작 스토리와 일반 제작 스토리, 재생성 | 생성 요청 ID 헤더 유무, 턴 번호와 재생성 값 |
| 비공개 전환 격리 | 소유자가 비공개로 바꾼 뒤 설정, 사건, 엔딩, 인물 이미지 수정 | 타인의 채팅은 공개본으로 AI 요청 구성, 소유자 채팅은 현재 값 |
| 과금 | 회원 체험 잔여, 체험 소진, 잔액 부족, 게스트 한도 소진, 디바이스 헤더 누락 | 체험 소모, 선차감, 402, 402, 400과 모두 스트림 미개시 |
| AI 오류 이벤트 | AI가 `error` 전송 | 같은 코드와 문구의 `error`, 환불과 복원, 턴 미저장 |
| AI 스트림 실패 | 연결 실패, 이벤트 간 시간 초과, `completed` 없는 종료 | `AI_STREAM_FAILED`, 환불, Sentry 캡처 |
| 저장 후 전송 실패 | `completed` 전송 직전 연결 끊김 | 턴 저장 유지, 환불 없음 |
| 실행기 거부 | 포화된 실행기 | 즉시 환불, 스트림 오류 종료, 거부 로그 |
| 전체 상한 | 백그라운드 작업이 시간 한도를 초과 | 백그라운드 작업 취소, 이벤트 없는 종료, 저장 전이면 환불 |
| 저장 전 취소 | AI 대기 중 시간 초과, 연결 종료, 스트림 오류 뒤 늦은 완료 결과 반환 | 턴 미저장, 환불 1회, 턴 결과 지표 `failure` |
| 저장 진입 후 취소 | 저장 진입 뒤 취소 콜백, 이후 저장 커밋 | 턴 저장 유지, 환불 없음, 턴 결과 지표 `success` |
| 선택 기록 | 유효한 선택, 범위 밖 순번, 현재 마지막 턴이 아닌 턴, 다른 채팅의 턴, 고쳐 보낸 입력, 공백과 NFC 차이 | 기록, 생략 3종과 WARN, `is_edited` true, false |
| 판정 반영 | 목표 사건 지정과 해제, 완결 사건, 엔딩 도달, 후보 밖 이름, 최소 턴 미달 | 상태 갱신, 조인 행과 이름 스냅샷, `ENDED`와 도달 표식, 무시, 무시 |
| 엔딩 후보 | 최소 턴 미달 엔딩, 이미 도달한 채팅 | 후보 제외, 빈 배열 |
| 후보 이름 구분 | 치환 뒤 같은 이름의 후보 3개 | ` (2)`, ` (3)` 전달과 원문 복원 |
| 회원 도달 집계 | 회원 도달, 게스트 도달, 두 채팅의 동시 도달, 엔딩 행 교체 후 도달 | 집계 1건, 미집계, 1건과 턴 저장 유지, 이름만으로 기록 |

### 5-5-4 재생성과 선택지

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 재생성 | 마지막 턴, 현재 마지막 턴이 아닌 턴, 턴 0개, `ENDED` 채팅, 0 이하 `turnId` | 교체와 이력 보관, 409, 404, 409, 400 |
| 재생성 요청 | 턴 3개 채팅 | `history`는 2턴, `user_input`은 마지막 입력, 판정 미반영 |
| 재생성 경쟁 | AI 호출 중 이어쓰기 커밋, 동시 재생성 2건 | 결과 폐기, `error` 전송, 환불, 한 건만 성공하고 재생성 횟수 +1 |
| 선택지 | 마지막 턴, 현재 마지막 턴이 아닌 턴, 다른 채팅의 턴, 이미 있는 선택지, AI 실패 | 저장과 응답, 409, 409, AI 호출 없이 기존 값, 502 |
| 선택지 경쟁 | AI 호출 중 재생성 커밋, 동시 호출 2건 | 409, 먼저 저장한 값 |

### 5-5-6 피드백과 공통

| 확인 항목 | 입력과 상황 | 기대 결과 |
|---|---|---|
| 피드백 | 본문만, 선택 필드 전부, 빈 이메일, 2,001자, 잘못된 플랫폼 | 201, 201과 User-Agent 저장, `null` 저장, 400, 400 |
| 피드백 전달 | 저장 성공, 저장 롤백, 웹훅 실패 | 커밋 후 1회 전달, 미전달, 201 유지 |
| 오류 응답 형식 | 필수 입력이 빠진 400 | `status`, `code`, `message`, `path`, `details` 필드 포함 |
| 정지 계정 | 생성, 이어쓰기, 재생성, 선택지 | 403과 스트림 미개시 |
| AI 호출 기록 | 본문 성공과 실패, 선택지 | `chat_response`, `choice_generation` 행과 `meta`, 실패 코드 |
| 지표 | 저장 성공, AI 실패, 402, 시작 전 취소 | `success`, `failure`, `rejected`, `cancelled` |
| 분석 이벤트 | 저장 성공, 도달 턴, 저장 전 실패, 저장 후 전송 실패 | 성공 이벤트, `ending_id` 포함, 실패 이벤트, 중복 실패 없음 |
