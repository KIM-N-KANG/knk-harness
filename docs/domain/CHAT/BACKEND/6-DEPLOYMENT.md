# 6. 배포

이 문서는 CHAT 도메인이 포함된 서버의 배포 단위와 의존 대상, 배포 경로, 이 도메인이 읽는 환경 변수와 시크릿, 설정 변경, 적용과 복구 절차를 정한다.

서버 전체 배포 절차 중 CHAT 도메인과 관련된 항목만 다룬다.

대기 한도는 오류 처리에, 관측 스택과 조회 도구는 관측에 있다. ([5-3-5 재시도와 시간 한도](5-3-ERROR-HANDLING.md#5-3-5-재시도와-시간-한도), [5-4-1 관측 스택](5-4-OBSERVABILITY.md#5-4-1-관측-스택))

<br>

### 6-1 배포 단위와 의존성

배포 단위는 서버 컨테이너 하나다. CHAT만 따로 배포하지 않는다. 다음은 이 도메인이 기동과 처리에 쓰는 의존 대상이다.

| 의존 대상 | 내용 | CHAT 도메인이 쓰는 것 |
|---|---|---|
| PostgreSQL | 기동 시 마이그레이션 적용 | 채팅, 메시지, 선택지, 버전 이력, 거쳐온 사건, 공유, 피드백 테이블 |
| AI 서버 | 운영은 독립 ECS 서비스, 개발은 같은 태스크의 컨테이너 | 턴 스트림, 선택지<br>스텁이면 불필요 |
| S3 assets 버킷과 CloudFront | Terraform 관리 | 실시간 이미지 경로 `chat-images/*`의 presigned PUT과 HEAD<br>AI 서버의 업로드 허용 호스트에 버킷 주소 등록 |
| Redis | 체험 카운터 | PAYMENT 도메인의 서비스로 접근 |
| Slack 웹훅, Google Form | 피드백 전달 | 커밋 후 비동기 발송 |
| Data Prepper | 트레이스를 받아 OpenSearch에 적재 | 트레이스 전송 |

<br>

| 의존 대상 | 연결과 설정 실패 시 동작 |
|---|---|
| AI 서버 | 주소에 `http` 또는 `https` 스킴이나 호스트가 없으면 기동 실패<br>연결 실패와 이벤트 간 시간 초과는 스트림 실패로 응답하고 환불<br>선택지 호출 실패는 AI 실패로 응답 |
| PostgreSQL | 연결 불가는 기동 실패 |
| S3 assets 버킷 | 버킷과 이미지 제공 기본 URL 중 하나라도 비면 실시간 이미지 자리를 발급하지 않고 턴은 진행<br>업로드 경로의 IAM 권한이 없으면 AI의 업로드가 실패해 인물 기본 이미지로 대체<br>AI 허용 호스트에 없으면 AI가 생성을 생략 |
| Redis | 지연 연결이라 기동은 진행<br>회원 체험 카운터 장애는 예약 실패로 보고 이프 차감으로 폴백<br>체험 복원 실패는 환불 실패 지표로 기록 |
| Slack 웹훅, Google Form | 미설정이면 해당 전달 생략<br>실패는 접수 결과에 영향 없음 |
| Data Prepper | 추적을 켜고 주소가 비면 기동 실패<br>추적이 꺼지면 스팬을 만들되 전송하지 않음 |

<br>

### 6-2 배포 경로

테스트와 빌드를 마친 뒤 이미지를 게시하고 배포한다. `main` push는 같은 소스 트리의 `dev` 성공 실행이 있으면 테스트를 다시 실행하지 않는다. `dev`로 PR을 올리면 테스트와 빌드만 한다.

| 단계 | 개발 | 운영 |
|---|---|---|
| 자동 시작 | `dev` push | `main` push |
| 머지 규칙 | 기능 브랜치에서 `dev`로 squash | `release/vX.Y.Z`에서 `main`으로 merge commit |
| 이미지 태그 | 커밋 SHA 앞 7자리, 환경 태그 `dev` | 커밋 SHA 앞 7자리, 안정화 후 `latest` |
| 상태 검사 | 배포 완료, 서버와 AI 컨테이너 정상, health `UP` | 동일 |

<br>

### 6-3 환경 변수와 시크릿

환경 변수가 설정 파일의 값보다 우선한다. 설정은 기동 시 읽으므로 변경 뒤 새 태스크를 시작해야 적용된다. 값은 Terraform이 태스크 정의에 주입하고 시크릿은 Secrets Manager에서 주입한다. AWS 자원에는 태스크 역할로 접근하므로 별도 접근 키를 주입하지 않는다. 이 도메인이 읽는 설정만 적는다. 기본값이 "빈 값"이면 변수가 없어도 빈 문자열로 기동한다. "없음"이면 변수가 없을 때 기동에 실패한다.

<br>

**1. AI 연동과 스트림**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_AI_BASE_URL` | 없음 | 운영 태스크 환경 변수, Cloud Map 내부 주소<br>개발 태스크 환경 변수 `http://localhost:8000` | |
| `MANYAK_AI_CHAT_STUB` | `false` | 주입 없음 | |
| `MANYAK_CHAT_SSE_CONCURRENCY` | 64 | 주입 없음 | 턴 워커 스레드 수 |
| `MANYAK_CHAT_SSE_QUEUE_CAPACITY` | 100 | 주입 없음 | 대기 큐 크기<br>초과하면 거부 |

<br>

**2. 이미지 저장소**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_IMAGE_BASE_URL` | `https://cdn.manyak.app` | 주입 없음 | 프리셋 표지 키를 URL로 조합할 때만 사용 |
| `MANYAK_CHARACTER_IMAGE_BUCKET`, `MANYAK_CHARACTER_IMAGE_REGION`, `MANYAK_CHARACTER_IMAGE_BASE_URL` | 빈 값 | 개발과 운영 태스크 환경 변수, assets 버킷과 CDN 주소 | 버킷과 base URL이 둘 다 있어야 실시간 이미지 활성화 |

<br>

**3. 정책과 한도**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_CREDIT_CHAT_TURN_COST` | 20 | 주입 없음 | 런타임 값은 PAYMENT 정책이 우선 |
| `MANYAK_CREDIT_CHAT_IMAGE_COST` | 0 | 주입 없음 | 0이면 이미지 무료<br>런타임 값은 PAYMENT 정책이 우선 |
| `MANYAK_GUEST_TRIAL_CHAT_TURN_LIMIT` | 5 | 주입 없음 | 회원 체험에도 같은 값 |
| `MANYAK_GUEST_TRIAL_CHAT_IMAGE_LIMIT` | 5 | 주입 없음 | 회원 체험에도 같은 값 |

<br>

**4. 피드백 전달**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_SLACK_FEEDBACK_WEBHOOK_URL` | 빈 값 | 운영 Secrets Manager | |
| `MANYAK_GOOGLE_FORM_FEEDBACK_ID` | 빈 값 | 운영 설정 파일 | 비어 있으면 폼 전달 생략 |
| `MANYAK_GOOGLE_FORM_FEEDBACK_BODY_ENTRY` | 설정 파일 값 | 주입 없음 | 폼 항목 ID<br>폼을 바꾸면 함께 갱신 |

<br>

**5. 관측**

| 이름 | 기본값 | 주입 출처 | 비고 |
|---|---|---|---|
| `MANYAK_TRACING_ENABLED` | `false` | 운영 Terraform 변수 | |
| `MANYAK_OTLP_TRACES_ENDPOINT` | 빈 값 | 추적을 켠 운영 환경에 Data Prepper 내부 주소 주입 | 추적을 켜면 필수 |
| `MANYAK_OTLP_METRICS_ENABLED` | `false` | 운영 Terraform 변수, 전송 URL과 인증 헤더는 Secrets Manager | Grafana Cloud로 전송 |
| `SENTRY_DSN` | 빈 값 | 개발과 운영 Secrets Manager | |

### 6-4 배포 조건

| 확인 항목 | 기준 | 자동 여부와 한계 |
|---|---|---|
| 와이어 계약 변경 | SSE 이벤트나 응답 형식이 바뀌면 서버와 클라이언트를 함께 배포<br>AI 계약이 바뀌면 서버와 AI 서버를 함께 배포 | 수동 검토<br>운영은 같은 서비스를 두 레포가 갱신하므로 순서를 워크플로가 보장하지 않음 |
| S3 경로 권한과 AI 허용 호스트 | Terraform apply와 AI 설정이 서버 배포보다 먼저<br>늦으면 실시간 이미지가 기본 이미지로 대체 | 수동 적용 |
| 컬럼 제거 | 그 컬럼을 읽는 구버전 태스크가 사라진 다음 릴리스에서 수행 | 수동 검토 |
| 마이그레이션 | 기동 시 실행하므로 새 마이그레이션은 해당 코드보다 먼저 적용<br>마이그레이션은 재실행해도 같은 결과 | 기동 시 자동 적용<br>마이그레이션 경로 변경 PR은 `tbls lint`와 `dbdoc/` 비교가 CI 자동 |
| 코드 테스트 | 전체 테스트 통과 | CI 자동 |
| 컨테이너 기동 | 컨테이너 헬스체크와 `/actuator/health` `UP` | CI 자동<br>AI 서버 실제 호출과 업로드 동작은 검사하지 않음 |

<br>

### 6-5 설정 변경

| 변경 대상 | 변경 위치와 적용 | 확인 조건 |
|---|---|---|
| 턴과 이미지 소모 이프 | 운영 중 조정은 `credit_policies`의 `chat_turn_cost`, `chat_image_cost` 오버라이드, 스냅샷 갱신 주기 60초<br>기본값 변경은 코드 수정 후 재빌드 | 턴 비용은 1 이상, 이미지 비용은 0 이상<br>정책 반영 뒤 턴 요청의 차감량 |
| 체험 한도 | 환경 변수 변경 후 새 태스크 | 카운터는 초기화하지 않으므로 축소 시 이미 새 한도 이상 쓴 기기는 즉시 소진 상태 |
| AI 시간 한도 | 코드 기본값 변경 후 이미지 재빌드 | 이벤트 간격 한도보다 스트림 전체 상한이 길게 유지 |
| 워커 수와 큐 | 환경 변수 변경 후 새 태스크 | `chat.turn.queue` 대기 시간과 거부 로그 |
| 이미지 저장소 | assets 모듈 출력이 태스크 정의로 전달되므로 버킷과 CDN 변경 후 Terraform apply<br>AI 허용 호스트 갱신 | 턴 요청의 자리 발급, AI 업로드 성공, 본문의 실시간 마커 |
| 피드백 전달 | 웹훅 시크릿과 폼 ID 변경 후 새 태스크 | 피드백 등록 뒤 채널 수신 |
| 추적과 지표 전송 | 운영 Terraform 변수 `tracing_enabled`, `enable_otlp_metrics` 변경 후 apply | 지표는 시크릿의 전송 URL과 인증 헤더가 먼저 채워져야 함 |

### 6-6 적용과 복구

**1. 적용 순서**

와이어 계약이 바뀌면 배포 조건의 순서를 먼저 맞춘다.

| 순서 | 작업 | 확인 항목 |
|---|---|---|
| 1 | 설정과 인프라 확인 | 새 시크릿 키의 주입 참조, S3 경로 권한, AI 허용 호스트, 마이그레이션 순서<br>Terraform 변경은 서버 배포보다 먼저 apply |
| 2 | 동반 배포 확인 | AI 서버, 클라이언트와 함께 배포해야 하는 변경인지와 그 순서 |
| 3 | 배포 실행 | 운영은 AI 레포의 배포와 겹치지 않는지 확인 |
| 4 | 적용 결과 확인 | 배포 후 확인 항목 |

<br>

**2. 진행 중인 요청**

| 상황 | 처리와 한계 |
|---|---|
| 운영 롤링 교체 중 진행 중인 턴 | ALB 타깃 해제 대기 240초가 스트림 전체 상한보다 길므로 기존 태스크에서 완료<br>새 태스크로 이전하지 않음 |
| 태스크 강제 종료 중 진행 중인 턴 | 저장 전이면 환불 코드가 돌지 못할 수 있음<br>PAYMENT의 선차감 대사 배치가 턴 차감을 보정하고 이미지 차감은 보정하지 않음 |
| 개발 stop-then-start | 교체 중 모든 요청 실패<br>데이터 컨테이너 재시작 |
| AI 호출 중 AI 서버 교체 | 스트림이 끊기면 스트림 실패로 응답하고 환불<br>클라이언트가 같은 입력을 다시 보냄 |

<br>

**3. 복구**

자동 복구가 실행돼도 서비스가 정상으로 돌아오지 않았을 수 있으므로 실제 서버 상태를 확인한다.

| 상황 | 복구 방식 | 한계와 확인 사항 |
|---|---|---|
| 새 태스크 헬스체크 실패 | 직전 배포로 자동 복귀 | 환경 태그가 실패한 이미지를 가리킬 수 있으므로 다음 재배포 전에 태그 확인 |
| 배포는 정상이나 동작 오류 | revert 커밋 릴리스 또는 이전 이미지를 환경 태그로 다시 태깅한 뒤 새 배포 | health 기반 자동 복구는 동작 오류를 탐지하지 않음 |
| 마이그레이션 적용 후 되돌리기 | 적용된 마이그레이션은 되돌리지 않음 | 새 컬럼은 구버전 코드와 호환하게 추가 |
| 설정 오류 | 잘못된 Terraform 값이나 시크릿을 이전 호환 값으로 복구 후 apply | 이미지 태그 복원만으로 설정은 복원되지 않음 |

<br>

### 6-7 배포 후 확인

| 확인 항목 | 자료 | 기준 |
|---|---|---|
| 기동 | 해당 배포 ID의 태스크 상태, 헬스체크 `/actuator/health`, 스모크 테스트 | 의도한 이미지로 기동, `UP` |
| 턴 실패 | `manyak.chat.turn.result`의 `failure` 비율 | 배포 전과 같은 수준 |
| 환불 | `manyak.chat.turn.refund`의 `failure` | 0 |
| AI 호출 | `ai_call_logs`의 `STARTED` 잔존, `turn_number IS NULL`인 `SUCCEEDED` | 호출 중 중단 없음 |
| 실시간 이미지 | 새 턴 본문의 `chat-images/` 마커 | 자리 발급과 업로드 성공 |
| 스트림 | 이어쓰기 호출의 `started`부터 `completed`까지 | 이벤트 순서와 한글 인코딩 정상 |

### 6-8 배포 실패 진단

| 실패 상황 | 확인할 자료와 위치 | 원인별 조치 |
|---|---|---|
| 기동 중 설정 검증 실패 | 시작 로그의 예외 메시지 | AI 주소 스킴과 호스트, 워커 수 1 미만, 추적 주소 누락 중 해당 값 수정 후 apply |
