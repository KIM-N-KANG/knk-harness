# 1. 배경

이 문서는 마냑의 채팅 플레이, CHAT 도메인에서 백엔드가 맡는 역할, 관련 주체와 공통 용어를 설명한다.

<br>

### 1-1 도메인

CHAT 도메인은 스토리를 바탕으로 사용자와 AI가 번갈아 이야기를 이어가는 플레이를 다룬다. 사용자가 입력을 보내면 AI가 다음 장면을 쓴다. 백엔드는 그 결과를 턴으로 기록한다. 채팅은 스토리 하나와 시작 설정 하나에서 시작한다. 턴이 쌓일수록 이야기가 길어진다.

<br>

### 1-2 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 함께 이야기를 이어가는 AI 인터랙티브 스토리 서비스다. 채팅은 서비스의 핵심 플레이 화면이다. 사용자는 프롤로그를 읽고 입력을 보낸다. AI 응답은 실시간으로 표시된다. 장면에 어울리는 인물 이미지가 본문에 표시된다. 선택지는 다음 행동을 입력하도록 돕는다. 이야기가 주요 사건을 거쳐 엔딩에 도달하면 그 턴에 엔딩 표시가 붙는다.

| 플레이 | 사용자가 하는 일 |
|---|---|
| 시작 | 스토리와 시작 설정을 골라 채팅을 열고 프롤로그와 추천 입력을 봄<br>회원은 페르소나를 골라 주인공 이름과 설명을 바꿀 수 있음 |
| 모델 등급 | 채팅마다 응답을 쓸 모델 등급을 고름<br>등급마다 턴당 이프 가격이 다르고 언제든 바꿀 수 있음 |
| 이어쓰기 | 입력창에 글을 적거나 선택지를 골라 전송<br>AI 응답이 토큰 단위로 표시되고 완료되면 턴으로 남음 |
| 재생성 | 마음에 들지 않는 마지막 AI 응답을 같은 입력으로 다시 생성 |
| 목록과 재개 | 진행 중인 채팅을 카드로 보고 이어가거나 삭제 |
| 공유 | 지금까지의 채팅을 링크로 공유<br>링크를 받은 사람은 로그인 없이 읽기 전용으로 열람 |
| 피드백 | 불편한 점이나 바라는 기능을 적어 보냄 |

<br>

### 1-3 백엔드의 역할

AI 서버는 요청 사이의 상태를 저장하지 않는다. 이야기의 기록과 진행 상태, 과금, 접근 판정은 백엔드가 맡는다.

| 작업 | 역할 |
|---|---|
| 채팅 생성과 기록 | 채팅, 메시지, 선택지를 저장<br>시작 시점의 프롤로그와 페르소나를 스냅샷으로 보관 |
| 턴 진행 | 스토리 설정, 대화 내역, 진행 상태를 모아 AI에 전달<br>AI 응답을 실시간으로 중계하고 완료 시 한 턴으로 저장 |
| 진행 상태 보관 | 목표 사건, 거쳐온 사건, 도달 엔딩을 채팅 단위로 보관하고 매 턴 AI에 다시 전달 |
| 실시간 이미지 | 턴마다 이미지 업로드 위치를 발급하고 AI가 올린 결과를 검증해 기록 |
| 모델 등급 | 등급 목록과 가격을 제공하고 채팅에 선택한 등급을 보관<br>턴마다 AI에 보낼 등급과 차감할 가격을 정함 |
| 과금과 한도 | 턴과 이미지에 이프를 선차감하거나 체험 횟수를 예약<br>턴 가격은 채팅에 선택한 등급을 따름<br>실패 시 이프를 환불하고 체험 횟수를 복원 |
| 접근 판정 | 채팅 소유자만 이어쓰기와 조회가 가능하도록 판정<br>스토리가 비공개로 바뀐 뒤에는 마지막 공개본으로 AI 입력을 구성 |
| 공유 | 발급 시점까지의 채팅을 읽기 전용 링크로 제공 |
| 피드백 | 제보를 저장하고 운영 채널에 전달 |
| 다른 도메인에 전달 | 스토리: 엔딩 도달 집계<br>이프: 소모와 환불 요청<br>계정: 이관 시 채팅 소유권 이전 |

<br>

### 1-4 주체

| 주체 | 정의 | 이 도메인에서 하는 일 |
|---|---|---|
| 게스트 | 로그인 없이 서비스를 쓰는 사용자 | 체험 한도 안에서 채팅 시작, 이어쓰기, 재생성, 공유, 삭제<br>채팅 식별자를 기기에 보관 |
| 회원 | 로그인한 사용자 | 이프를 써서 채팅, 페르소나 선택, 모델 등급 선택, 엔딩 도달 집계<br>내 채팅 목록 조회 |
| 링크를 받은 사람 | 공유 링크를 가진 누구나 | 로그인 없이 공유된 채팅 열람 |
| 클라이언트 | 사용자가 쓰는 앱 | 요청을 보내고 스트림을 표시<br>본문의 이미지 마커 위치에 이미지를 표시<br>게스트가 만든 채팅의 식별자를 로컬에 보관 |
| AI 서버 | 턴 본문을 생성하는 서버 | 본문 생성과 스트리밍, 등급에 따른 모델 선택, 사건과 엔딩 판정, 인물 이미지 선택과 실시간 이미지 생성, 선택지 생성 |
| 운영자 | 팀 구성원 | 피드백 확인, 이프 정책값과 모델 등급의 이름, 가격, 노출 조정 |

<br>

### 1-5 공통 용어

| 용어 | 의미 |
|---|---|
| 채팅 | 스토리 하나와 시작 설정 하나에서 시작한 플레이 기록<br>메시지, 선택지, 진행 상태를 묶음 |
| 턴 | 사용자 입력 하나와 그에 대한 AI 응답 하나의 쌍<br>턴 ID는 AI 응답 메시지의 ID |
| 이어쓰기 | 새 사용자 입력으로 다음 턴을 만드는 요청 |
| 재생성 | 마지막 턴의 AI 응답을 같은 사용자 입력으로 다시 만들어 교체하는 요청<br>턴 수는 늘지 않음 |
| 생성 중 키 | 채팅별 이어쓰기와 재생성의 중복 실행을 막고 생성 중 상태를 보관하는 Redis 키<br>`chat:{chatId}:generating` |
| 생성 ID | 이어쓰기나 재생성 작업 하나를 식별하는 UUID 문자열 `generationId`<br>채팅 자체의 ID와 구분 |
| 생성 마감 | 요청 접수부터 큐 대기를 포함해 적용하는 생성 작업의 시간 한도 |
| 재연결 | 기존 생성 ID로 SSE 연결을 다시 여는 요청 |
| 이어받기 | 같은 생성의 이벤트를 처음부터 다시 받고 새 이벤트를 이어서 받는 동작 |
| 활성본 | 재생성으로 교체된 뒤 현재 표시되는 AI 응답과 선택지<br>이전 결과는 버전 이력으로 보관 |
| 선택지 | AI가 제안하는 다음 행동 후보 3개<br>턴 본문과 별도 요청으로 생성 |
| 선택 기록 | 사용자가 직전 턴에서 고른 선택지와 수정 여부를 기록 |
| 프롤로그 | 시작 설정의 도입부 본문<br>채팅 생성 시점의 값을 보관 |
| 페르소나 | 회원이 만든 주인공 프로필<br>채팅 시작 시 이름과 설명을 스냅샷으로 복사 |
| 플레이 이름 | 이 채팅에서 주인공을 부르는 이름<br>페르소나 이름이 있으면 그 이름, 없으면 스토리의 기본 주인공 이름 |
| 목표 사건 | AI가 이 채팅의 진행 목표로 판정한 주요 사건과 해당 사건의 진행 턴 수 |
| 거쳐온 사건 | 이 채팅에서 완결된 주요 사건의 누적 목록 |
| 엔딩 도달 | AI가 이번 턴에 엔딩 조건이 충족됐다고 판정한 것<br>채팅당 최초 1회만 인정 |
| 인물 이미지 | 스토리에 저장된 인물의 이미지<br>AI가 대사 앞에 넣을 이미지를 고름 |
| 실시간 이미지 | 턴 진행 중 AI가 장면에 맞게 새로 생성하는 인물 이미지<br>턴당 1장 |
| 이미지 마커 | AI 응답 본문 안에서 이미지가 들어갈 위치를 나타내는 `[[URL]]` 줄 |
| 공유 | 발급 시점의 턴 수까지만 보이는 읽기 전용 링크 |
| 체험 한도 | 게스트와 회원이 무료로 쓸 수 있는 턴과 이미지 횟수 |
| 모델 등급 | 턴 본문을 쓸 AI 모델의 등급<br>기본(`BASIC`)과 고급(`ADVANCED`)이 있고 등급마다 턴당 이프 가격이 있음<br>채팅 단위로 선택해 보관 |
| 유효 등급 | 채팅에 보관한 등급이 노출 중이면 그 등급, 아니면 새 채팅의 기본 등급 |
| 청구 등급 | 한 턴에서 실제로 AI에 보내고 가격을 매기는 등급<br>게스트와 회원 체험 턴은 기본 등급, 그 외는 유효 등급 |
