# 5-1 MODERATION 공통 검증

<br>

### 5-1-1 검증 경계

| 유저 스토리 | 사전조건과 절차 | 기대 결과 |
|---|---|---|
| MODERATION-US-001 | 회원과 게스트, 삭제된 스토리, 상세와 목록 및 채팅 메뉴 | 허용된 회원 진입만 제공하며 같은 참조 스토리를 대상으로 함 |
| MODERATION-US-001 | 사유 미선택, 각 사유 선택, 상세 0자와 500자 및 초과 | 선택 전 비활성, 선택 입력 상한, 빈 상세의 null 전송 |
| MODERATION-US-001 | 느린 전송 중 중복 제출과 바깥 탭 및 닫기 | 로딩 표시와 입력 및 닫기 잠금 |
| MODERATION-US-001 | 성공, 실패 뒤 재전송, 닫은 뒤 재진입 | 성공 시 닫기, 실패 시 입력 보존, 닫은 뒤 새 폼 |

[요구사항](2-2-REQUIREMENTS.md)과 [연동 계약](4-1-CONTRACT.md)을 판정 기준으로 사용한다. 실제 실행 결과는 PR과 CI에 기록한다.
