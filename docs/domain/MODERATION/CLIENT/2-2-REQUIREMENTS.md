# 2-2 MODERATION 요구사항

기준: [신고 목표](2-1-USER-STORY.md).

<br>

### 2-2-1 신고 조건과 결과

MODERATION-US-001은 웹과 Android에 적용한다.

| 조건 | 요구사항 |
|---|---|
| 접근 | 회원에게만 신고를 제공한다. 게스트에는 신고 항목을 두지 않는다 |
| 대상 | 상세, 제작 목록, 채팅 목록과 채팅방의 스토리다. 채팅을 신고할 때도 참조 스토리를 대상으로 한다 |
| 삭제된 참조 | 제목이 없는 삭제된 참조 스토리에는 신고를 제공하지 않는다 |
| 사유 | 도배와 홍보, 부적절한 내용, 기타의 세 사유 중 하나를 선택한다. 행 전체로 선택할 수 있다 |
| 상세 | 선택 입력, 최대 500자와 글자 수 표시. 작성하지 않아도 신고할 수 있다 |
| 제출 | 사유를 선택하기 전에는 비활성이다. 전송 중 입력, 전송과 닫기를 잠그고 크기를 유지한 로딩 표시를 사용한다 |
| 성공 | 접수 안내 뒤 시트를 닫는다 |
| 실패 | 실패 안내와 함께 시트, 선택한 사유와 상세 입력을 유지한다 |
| 재신고 | 같은 회원이 같은 스토리를 다시 신고할 수 있다. 서버의 멱등 처리를 사용한다 |
| 취소 | 전송 중이 아닐 때 닫을 수 있다. 다시 열 때 이전 입력을 남기지 않는다 |

제작 입력 거절과 검수 상태의 사용자 결과는 [STORY 요구사항](../../STORY/CLIENT/2-2-REQUIREMENTS.md)을 따른다. 신고 접수 여부로 검수 상태를 바꾸지 않는다.
