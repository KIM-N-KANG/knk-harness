# 웹 MODERATION 구성

기준: [연동 계약](../CONTRACT.md), [웹 표현](LAYOUT.md).

<br>

### 공용 경계

스토리 공용 신고 시트를 상세, 제작 카드, 채팅 카드와 채팅 메뉴가 함께 사용한다. 각 진입점은 대상 storyId, 분석 source, 열림과 닫힘만 전달한다. 옵션 항목은 공용 버튼으로 그린다. 신고 시트가 API 전송과 결과 토스트를 소유하며 채팅 삭제와 새 채팅 시작은 기존 기능 경계에 남긴다.

상세는 신고와 삭제 모두 불가하면 메뉴 트리거를 숨긴다. 삭제된 채팅 참조는 조회 계층에서 신고 ID를 null로 바꿔 시트가 열리지 않게 한다.
