# MODERATION 클라이언트 배경

<br>

### 사용자와 책임

부적절한 스토리를 발견한 회원이 이용 중인 화면에서 같은 기준으로 신고하고 접수 결과를 확인한다. 신고 접수와 콘텐츠의 자동 검수는 별개다. 접수 성공을 곧바로 삭제나 제재 완료로 표시하지 않는다.

| 범위 | 담당 |
|---|---|
| 클라이언트 신고 | 회원의 진입, 사유와 선택 상세 입력, 전송과 결과 안내 |
| 신고 API | STORY 백엔드의 스토리 접근 판정과 신고 접수 |
| 검수 기준과 실행 | MODERATION 제공자 |
| 검수 상태와 입력 복구 | STORY의 제작 및 수정 화면 |
| 검수 완료 알림 | NOTIFICATION의 전달과 진입 |

15세 이용가와 콘텐츠 검수 정책은 제공자의 책임이다. 기존 클라이언트 계약에 없는 수위 전환 설정이나 자체 판정을 추가하지 않는다.
