# 3-1 화면 구성

기준: [요구사항](2-2-REQUIREMENTS.md).

<br>

### 3-1-1 진입과 정보

| 진입 | 대상과 구성 |
|---|---|
| 스토리 상세 | 해당 스토리 옵션의 신고하기 |
| 제작 목록 | 해당 스토리 카드 옵션의 신고하기 |
| 채팅 목록 | 해당 채팅 카드가 참조하는 스토리의 신고하기 |
| 채팅방 | 메뉴에서 참조 스토리의 신고하기 |
| 신고 시트 | 제목, 설명, 사유, 선택 상세, 신고하기와 닫기 순서 |

별도 화면 URL이나 목적지를 만들지 않고 현재 화면 위 시트를 사용한다. 각 진입점은 같은 입력과 결과 계약을 사용한다. 홈 카드에는 신고 옵션을 추가하지 않는다.
