# 3-3 화면 배치

기준: [화면 흐름](3-2-INTERACTION-FLOWS.md).

### 3-3-1 신고 시트

| 요소 | 문구와 표현 |
|---|---|
| 제목 | 이 스토리를 신고할까요? |
| 설명 | 부적절하거나 불쾌한 내용이 있으면 알려주세요 |
| 사유 | “도배·홍보”, “부적절한 내용”, “기타” 순서의 라디오 선택 |
| 상세 라벨 | 자세한 내용 (선택) |
| 플레이스홀더 | 어떤 점이 문제였는지 알려주세요 |
| 글자 수 | 현재 글자 수 / 500 |
| 제출 | 파괴적 강조의 신고하기 |
| 보조 | 닫기 |
| 접수 성공 | 신고가 접수되었어요 |
| 접수 실패 | 신고를 접수하지 못했어요 |

선택한 라디오 상태와 전송 중 비활성 상태를 보조 기술에 전달한다. 스피너로 바꿔도 제출 버튼 크기를 유지한다.
