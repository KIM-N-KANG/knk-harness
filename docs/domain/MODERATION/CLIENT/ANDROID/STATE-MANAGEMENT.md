### 소유권과 전송

각 화면 ViewModel의 상태에 신고 시트 열림, 선택 사유, 상세와 전송 여부를 포함한다. 공용 컨트롤러는 상태를 별도로 보관하지 않고 전이와 결과 이벤트를 보낸다. 구성 변경에서도 같은 화면 상태를 유지한다.

닫힘 전이는 초기 상태로 바꾸며 실패 전이는 전송 여부만 해제한다. 제출 Job이 실행 중이면 추가 제출을 무시하고, 대상이나 사유가 없으면 전송하지 않는다. 화면이 제공한 코루틴 스코프에서 요청을 실행한다.
