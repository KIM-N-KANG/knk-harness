# 관측

<br>

### 요청 조회

| 조회 위치 | 확인 항목 |
|---|---|
| Langfuse `게시물 검수` | 요청 입력, 최종 결과, 제출본 식별자, 프롬프트 버전과 호출 기록 |
| Langfuse `검수 모델 호출` | 시도별 모델, 공급자, 입력, 검증한 결과, 사용량과 소요 시간 |
| Sentry `feature=story_moderation` | 이미지 준비, 모델 호출과 응답 검사 오류 |
| 서버 로그 | 이미지 준비 성공과 실패 수, 모델 호출 사용량, 호출 실패 유형 |

<br>

| 식별자 | 연결 대상 |
|---|---|
| `request_id` | 백엔드 요청과 AI 관측 기록 |
| `submission_id` | 검수 제출본 |
| `story_id` | 기존 스토리, 요청에 있을 때만 기록 |

<br>

### 기록 항목

| 단위 | 기록 내용 |
|---|---|
| 요청 입력과 출력 | 미디어를 제거한 게시물과 최종 검수 결과 |
| 요청 metadata | 식별자, `prompt_versions.MODERATION`, 호출별 `calls` |
| 모델 호출 입력 | 검수 필드, 이미지별 경로와 MIME 타입 및 바이트 수 |
| 모델 호출 출력 | 검증한 판정과 위반 목록, 실행 오류 |
| 호출 기록 | `attempt`, `model`, `provider`, `input_tokens`, `output_tokens`, `duration_ms`, `result`, `error_type` |
| 호출 실패 | 하위 호출을 오류로 표시하고 예외 타입 기록<br>대체 호출로 복구해도 실패한 시도 보존 |

<br>

### 오류 확인

| 오류 | Sentry 기록 | 확인 항목 |
|---|---|---|
| 이미지 준비 실패 | 요청당 한 건으로 묶어 대표 이미지 오류 코드 기록 | 최종 `image_errors`의 경로와 원인 |
| 이미지 판독 불가 | `IMAGE_UNREADABLE` | 해당 이미지 경로와 모델 결과 |
| 모델 응답 검사 실패 | `invalid_ai_response` | 실패한 시도의 모델과 응답 검사 위치 |
| 모델 호출 실패 | 공통 오류 분류, 공급자와 모델 | 호출 실패 유형, 시간과 대체 호출 결과 |

<br>

### 집계

| 항목 | 기준 |
|---|---|
| 내용 반려 | `decision=REJECTED`, `error_code=null` |
| 검수 실패 | 최종 `error_code`가 있는 요청 |
| 대체 호출 | `calls`에 두 번째 시도가 있는 요청 |
| 처리 시간 | 요청 추적 시간과 호출별 `duration_ms` 구분 |
| 모델 비용 | 수집한 호출별 사용량과 모델 단가로 집계<br>기본과 대체 호출 모두 포함 |
| 사용량 누락 | 0으로 대체하거나 입력 길이로 추정하지 않음 |
| 캐시 토큰 | 입력 합계에서 분리해 중복 집계 방지 |

<br>

### 수집 조건과 실패 처리

| 항목 | 기준 |
|---|---|
| Langfuse 활성화 | 키 설정, 일본 리전, `prod` 환경 |
| 표본 비율 | `LANGFUSE_SAMPLE_RATE`, 기본값 `1.0` |
| Sentry 활성화 | `SENTRY_DSN` 설정 |
| 미디어 정제 | 요청, 결과와 호출 기록의 URL 및 base64 제거<br>모델에 전달하는 원본은 유지 |
| 텍스트 | 정제한 게시물 텍스트와 위반 이유는 Langfuse에 기록 |
| 관측 실패 | 검수 결과와 원래 예외를 유지하고 경고 기록 |
| 미수집 | 비활성화, 표본 제외와 전송 실패로 기록이 누락될 수 있음 |
