# 테스트 케이스

<br>

### 테스트 범위

| 종류 | 확인 범위 | 외부 의존성 |
|---|---|---|
| 단위 | 입력 준비, 이미지 처리, 프롬프트 조립, 응답 검사와 대체 호출 | 모델과 HTTP 응답 대체 |
| API | 요청 검증, HTTP 상태와 응답 필드 | 이미지 준비와 모델 호출 대체 |
| 관측 | 기록 정제, 요청별 격리, 관측 장애 | 관측 전송 대체 |
| 실제 모델 통합 | 승인·반려 이미지 데이터셋의 판정 | 다운로드만 로컬 파일로 대체, 실제 프롬프트와 모델 호출 |

<br>

### 입력과 API

| ID | 입력과 상황 | 기대 결과 |
|---|---|---|
| API-01 | 선택 필드 생략, `null`, 빈 문자열과 빈 배열 | 요청 허용, 전달된 내용으로 검수 |
| API-02 | 제출본 식별자 누락, 잘못된 UUID, 하위 필드 타입 오류 | HTTP 422, 이미지와 모델 호출 없음<br>오류 응답에서 입력 원문 제외 |
| API-03 | 기본 주인공 이름, 인물 설명, 식별자와 공개 설정 포함 | 콘텐츠는 모델 입력에 반영<br>식별자와 공개 설정은 판정에서 제외 |
| API-04 | 공백과 긴 문자열, 빈 이미지 주소 | 텍스트 원문 보존<br>빈 이미지 주소는 이미지 없음으로 처리 |
| API-05 | 승인, 내용 위반, 검수 실패 | 모두 HTTP 200<br>네 응답 필드와 빈 배열, `null` 유지<br>실행 실패만 `error_code` 포함 |

<br>

### 이미지 준비

| ID | 입력과 상황 | 기대 결과 |
|---|---|---|
| IMG-01 | 지원 형식의 실제 바이트, 확장자와 내용 불일치 | 실제 바이트로 형식 판별 |
| IMG-02 | 허용하지 않은 주소, 리다이렉트, 다운로드 실패 | `IMAGE_DOWNLOAD_FAILED`<br>금지 주소에 연결하지 않고 리다이렉트 미추적 |
| IMG-03 | 비이미지, 미지원 형식, 장당 크기 상한과 상한 초과 | 상한까지 허용, 형식 위반과 초과는 `IMAGE_INVALID` |
| IMG-04 | base64 변환 또는 텍스트와 JSON 추가로 전체 용량 초과 | 모델 호출 없음, 용량 오류 반환 |
| IMG-05 | 여러 이미지의 성공과 실패, 완료 순서 뒤바뀜 | 입력 순서와 원래 경로 유지<br>정상 이미지로 검수하되 오류가 남으면 승인하지 않음 |
| IMG-06 | 이미지 전체 실패 | 모델 호출 없이 이미지 오류 반환 |
| IMG-07 | 5장 초과 입력, 일부 다운로드 지연 | 동시 다운로드 최대 5장<br>시간 초과 시 미완료 작업 취소, 완료 결과 보존 |

<br>

### 모델 호출과 결과

| ID | 입력과 상황 | 기대 결과 |
|---|---|---|
| MOD-01 | 템플릿 구분자와 자리표시자가 포함된 게시물, 실제 이미지 | 게시물을 데이터로 삽입, 입력을 다시 치환하지 않음<br>이미지 경로와 바이너리 연결 |
| MOD-02 | 기본 모델이 유효한 승인 또는 반려 반환 | 호출 1회, SDK 재시도와 대체 호출 없음 |
| MOD-03 | 기본 모델 호출 실패, 빈 출력, JSON 오류 또는 비정상 종료 | 같은 메시지로 대체 모델 최대 1회 호출 |
| MOD-04 | 승인에 위반 목록 포함, 반려 사유 없음, 잘못된 기준 코드 | 응답 검사 실패, 임의 승인 없음 |
| MOD-05 | 존재하지 않는 경로와 유효한 위반 경로가 함께 반환됨 | 없는 경로만 제외<br>유효한 항목이 모두 사라지면 응답 검사 실패 |
| MOD-06 | 이미지 판독 불가와 내용 위반이 함께 반환됨 | 대체 호출 없음<br>이미지 오류와 내용 위반을 분리해 보존 |
| MOD-07 | 기본과 대체 모델 모두 실패 | `REJECTED`, `MODEL_CALL_FAILED`<br>기존 이미지 오류가 있으면 대표 오류 우선순위 적용 |
| MOD-08 | 호출 제한 시간 초과, 요청 전체 시간 소진 | 시간이 남으면 대체 호출<br>전체 시간 소진 시 추가 호출 없음 |
| MOD-09 | 요청 취소 또는 코드 결함 | 검수 판정으로 바꾸지 않고 전파<br>API의 처리하지 않은 내부 오류는 HTTP 500 |

<br>

### 관측

| ID | 입력과 상황 | 기대 결과 |
|---|---|---|
| OBS-01 | 입력과 결과에 URL, base64 포함 | 관측 기록에서 제거, 원본 입력은 유지 |
| OBS-02 | 사용량 누락, 캐시 토큰 포함 | 누락을 0으로 기록하지 않음<br>캐시 토큰 중복 합산 없음 |
| OBS-03 | 서로 다른 제출본의 동시 요청 | 식별자와 호출 기록이 요청별로 분리 |
| OBS-04 | 관측 전송 실패 | 검수 결과 유지 |
