# 6-1 AI 실행

### 6-1-1 게시물 검수

```mermaid
%%{init: {"flowchart": {"curve": "basis", "htmlLabels": true, "nodeSpacing": 24, "rankSpacing": 48}}}%%
flowchart LR
    A["<b>입력 준비</b>"] --> B["<b>프롬프트 조립</b>"]
    B --> C["<b>모델 검수</b>"]
    C --> D["<b>응답 검사</b>"]
    D --> E["<b>결과 조립</b>"]
    classDef data fill:#E8F2E8,stroke:#527A59,color:#182D1D
    classDef task fill:#F5D9C9,stroke:#B97450,color:#452B1D
    classDef code fill:#F4F6F4,stroke:#9BA99E,color:#253C2C
    class E data
    class C task
    class A,B,D code
```

<br>

**1. 모델 및 파라미터**

| 항목 | 기본 모델 | 대체 모델 |
|---|---|---|
| 모델 설정 | `MODERATION_MODEL`<br>기본값 `gpt-6-luna` | `MODERATION_FALLBACK_MODEL`<br>기본값 `deepseek-flash` |
| 추론 설정 | `high` | 비추론 |
| 출력 형식 | JSON Schema | JSON 객체 |
| 생성 온도, 출력 토큰 한도 | 지정하지 않음 | 지정하지 않음 |
| 호출 제한 시간 | 기본 60초, 요청의 남은 시간 이내 | 기본 모델과 같음 |
| SDK 재시도 | 없음 | 없음 |

<br>

**2. 입력 전처리**

| 대상 | 처리 |
|---|---|
| 게시물 | 검수 필드만 추출하고 원문과 배열 순서 유지<br>식별자와 `null` 필드 제외 |
| 이미지 | 최대 5장씩 동시 다운로드, 실제 파일의 형식과 크기 확인<br>전체 준비 시간 기본 30초 |
| 이미지 일부 실패 | 실패한 주소만 모델 입력에서 제외, 배열 인덱스 유지 |
| 이미지 전체 실패 | 모델 호출 없이 실패 반환 |
| 이미지 없음 | 텍스트만 검수 |
| 전송 용량 | 모델 요청 본문을 조립한 뒤 상한 검사 |

<br>

**3. 프롬프트 조립**

| 템플릿 부분 | 들어가는 값 |
|---|---|
| `MODERATION-TEMPLATE.md`의 `[SYSTEM]` | 검수 기준과 출력 규칙 |
| `[USER]`의 `{post_json}` | 검수 필드 JSON<br>`<`, `>`는 유니코드 이스케이프 |
| 사용자 메시지의 이미지 부분 | 이미지별 입력 경로와 base64 이미지 |

<br>

**4. 모델 호출과 형식 검사**

| 대상 | 검사 |
|---|---|
| 종료 사유 | `stop` 또는 값 없음만 허용 |
| 출력 형식 | JSON 스키마와 필드 타입 확인 |
| 승인 | 위반 목록이 비어 있어야 함 |
| 반려 | 입력에 없는 경로 제외<br>유효한 항목이 남고 각 사유가 공백이 아니어야 함 |
| 판독 불가 | `rule=null`은 이미지 경로에서만 허용 |

<br>

**5. 대체 호출**

| 항목 | 처리 |
|---|---|
| 실행 조건 | 기본 모델 호출 또는 응답 검사 실패 |
| 입력 | 같은 프롬프트와 준비된 이미지 |
| 횟수 | 대체 모델 최대 1회 |
| 제외 조건 | 정상 반려, 이미지 판독 불가 |
| 전체 시간 | 입력 준비부터 기본 150초, 남은 시간이 없으면 호출 종료 |

<br>

**6. 최종 출력**

| 대상 | 처리 |
|---|---|
| 위반 목록 | 입력 경로로 텍스트와 이미지 유형 부여 |
| 이미지 오류 | 준비 오류와 판독 오류를 경로별로 합치고 입력 순서로 정렬 |
| 승인 여부 | 이미지 오류가 있으면 반려, 없으면 검증한 모델 판정 사용 |
