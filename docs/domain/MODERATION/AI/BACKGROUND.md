# 배경

<br>

### 서비스 배경

마냑은 사용자가 스토리와 세계관을 만들고 채팅으로 AI와 이야기를 이어가는 서비스이다. 일반 제작에서는 사용자가 설정을 직접 작성하고, 간편 제작에서는 AI가 만든 설정과 이미지를 사용한다. 공개한 스토리는 다른 사용자가 탐색하고 플레이한다. 서비스의 콘텐츠 기준은 15세 이용가이다.

<br>

### 모더레이션 도입 배경

일반 제작에서는 제작자가 스토리의 글을 직접 작성하고 이미지를 등록한다. 이 과정에서 서비스 정책인 15세 이용가 기준에 맞지 않는 글이나 이미지가 포함될 수 있다. 별도의 검수 없이 게시하면 다른 사용자가 해당 콘텐츠를 탐색하거나 플레이하면서 접하게 된다.

개발자가 게시물마다 글과 이미지를 직접 확인하기는 어렵고, 게시물이 늘수록 검수에 드는 시간과 부담도 커진다. 이에 게시 전 검수를 자동화하기 위해 AI 모더레이션 태스크를 도입한다. AI는 서비스가 정한 기준으로 글과 이미지를 검사하고, 위반 위치와 이유를 반환한다.

<br>

### 태스크의 목적과 범위

AI는 백엔드가 전달한 게시물의 텍스트와 실제 이미지를 검사해 게시 전 검수를 수행한다. 콘텐츠 기준과 금지 항목은 서비스가 정한다.

| 주체 | 역할 |
|---|---|
| 제작자 | 스토리의 글과 이미지 작성, 수정 |
| 백엔드 | 검수 대상 전달, 결과에 따른 게시 상태와 노출 관리 |
| AI 서버 | 금지 항목 판정, 승인 여부와 위반 위치, 기준, 이유 반환 |

<br>

### 공통 용어

| 용어 | 뜻 |
|---|---|
| 모더레이션 | 서비스 콘텐츠 기준에 따른 검사와 게시 가능 여부 판단<br>본 문서에서는 게시물 검수를 뜻함 |
| 검수 대상 게시물 | 백엔드가 검수를 요청한 스토리의 텍스트와 이미지 |
| 내용 위반 | 입력에서 확인한 내용이 서비스의 금지 항목에 해당함 |
| 검수 실패 | 이미지 준비나 모델 호출 문제로 검수를 완료하지 못함 |
