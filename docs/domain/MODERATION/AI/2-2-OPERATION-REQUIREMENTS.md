# 2-2 운영 요구사항

<br>

### 2-2-1 태스크의 유저

운영 관점에서 요구사항을 정하고 결과를 확인하는 주체는 AI 담당자와 제품 정책 담당자이다. AI 담당자는 검수 품질, 처리 시간과 비용을 관리하고, 제품 정책 담당자는 콘텐츠 기준을 정한다.

<br>

### 2-2-2 성능

| 지표 | 측정 기준 | 목표값 |
|---|---|---|
| Precision | 내용 위반으로 판정한 게시물 중 실제 위반 게시물의 비율 | 미정 |
| Recall | 실제 위반 게시물 중 내용 위반으로 판정한 비율 | 미정 |
| F1-score | 2 × Precision × Recall / (Precision + Recall) | 미정 |

<br>

### 2-2-3 시간

| 항목 | 목표값 | 상한 |
|---|---|---|
| 검수 요청 1건의 처리 시간 | 미정 | 8초 |
