# 2-1 유저 스토리

<br>

### 2-1-1 태스크의 유저

이 태스크의 유저는 자신이 만든 스토리를 게시하려는 제작자이다. 제작자는 백엔드와 클라이언트를 통해 검수 결과를 확인하고, 반려되면 위반 위치와 이유를 보고 글이나 이미지를 수정한다.

<br>

### 2-1-2 성능에 대한 기대

| 기대 |
|---|
| 내가 제출한 글과 이미지가 서비스의 콘텐츠 기준에 맞는지 알 수 있음 |
| 단어나 소재만으로 반려하지 않고 표현과 맥락을 함께 판단함 |
| 반려되면 어느 글이나 이미지가 어떤 기준을 위반했는지 알 수 있음 |
| 위반 이유를 읽고 무엇을 수정해야 하는지 이해할 수 있음 |
