# DECISIONS.md

현재 적용 기준은 각 명세에 두고 결정 당시의 이유와 대체 관계는 이 문서에 기록한다.

<br>

### 1. 기록 규칙

- 결정 하나를 표 하나로 기록한다. 기존 ID, 날짜, 당시 상태와 근거를 유지한다.
- 상태와 구현 설명은 원본의 기록 시점을 기준으로 해석한다. 현재 적용 여부나 배포 완료를 과거 기록만으로 단정하지 않는다.
- 결정이 바뀌면 새 ID로 기록하고 대체하는 결정과 적용 범위를 명시한다.
- 원문에 구분되지 않은 배경, 대안과 영향은 추측해서 보충하지 않는다.

**C-010. 필수 동의 시트에 동의하지 않고 나가는 로그아웃 버튼을 둠**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-07 |
| 상태 | Accepted (원문 기록 기준) |
| 관계 | 필수 동의 시트에 동의 없이 나가는 버튼을 두지 않던 공통 계약(2026-09-19)을 대체한다. 배경 탭, 스와이프, Escape로 닫지 않는 규칙과 뒤로가기를 동의하지 않음으로 보는 규칙은 유지한다. |
| 배경 | 시트를 거절하는 경로가 뒤로가기뿐이었다. 웹에서는 Chrome의 history manipulation intervention이 사용자 조작 없이 히스토리 항목을 쌓은 화면을 뒤로가기 버튼에서 건너뛰어, OAuth 직후 자동으로 열린 시트에서 뒤로가기를 누르면 시트가 닫히지 않고 Google 계정 선택 화면으로 이동했다. 화면에는 거절 수단이 보이지 않아 사용자가 시트에 갇혔다. ([Chromium 문서](https://chromium.googlesource.com/chromium/src/+/127.0.6533.99/docs/history_manipulation_intervention.md)) |
| 채택 | "동의하기" 아래에 보조 버튼 "로그아웃"을 두고, 조회 실패 단계에도 같은 버튼을 둔다. 동작은 뒤로가기와 같아 가입 전이면 가입을 취소하고 이미 로그인한 세션이면 로그아웃한다. 웹과 Android가 같은 계약을 따른다. |
| 대안 | 원문에 별도 항목으로 구분하지 않음 |
| 이유 | 버튼은 브라우저의 히스토리 정책과 무관하게 동작한다. 사용자는 소셜 로그인을 마친 상태로 인식하므로 가입 전에도 "로그아웃"이 결과를 가장 잘 설명하고, 403 안내 시트의 기존 문구와도 같다. Android는 시스템 뒤로가기가 확실히 처리되지만 거절 수단이 화면에 보이지 않는 문제는 같아 계약을 함께 바꾼다. |
| 영향 | 동의 시트의 비주얼 기준 이미지가 바뀐다. Android는 [KNK-1602](https://kimandkang.atlassian.net/browse/KNK-1602)로 따라오며 그 전까지 두 플랫폼의 시트 구성이 다르다. 웹의 히스토리 재진입 정리는 [W-028](WEB/DECISIONS.md#w-028)에 둔다. |
| 근거 | [공통 동의 모델](3-2-INTERACTION-FLOWS.md#3-2-1-로그인과-필수-동의) |
| 출처 | 사용자 확정 결정. ([KNK-1600](https://kimandkang.atlassian.net/browse/KNK-1600)) |

**C-023. 사업자 정보는 마이 하단에 법적 문서 링크와 함께 둔다**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-27 |
| 상태 | Accepted |
| 배경 | 사업자 등록 뒤 전자상거래법의 사업자 정보 표시가 필요해졌다. 강경현은 서비스 안내 페이지와 이프 충전 화면 아래에 상호, 대표, 사업자등록번호, 통신판매업 신고번호, 주소, 전화, 이메일을 표시하도록 요청했다(2026-11-27 Slack). |
| 채택 | 마이 맨 아래에 서비스 이용약관과 개인정보 처리방침 링크, 사업자 정보를 함께 둔다. 서비스 안내와 이프 충전 화면에는 두지 않는다. 호스팅서비스 제공자 상호는 표시하지 않는다. 웹과 Android가 같은 계약을 따른다. |
| 대안 | 서비스 안내와 이프 충전 화면 아래 표시(요청안), 마이 하단과 두 화면 모두 표시 |
| 이유 | 사용자가 다른 국내 서비스(제타)처럼 마이 하단 한 곳에 모으도록 정했다. |
| 영향 | Android 새 버전을 먼저 배포하고 웹을 그 뒤에 배포해 두 플랫폼의 표시 시점을 맞춘다. 약관 제3조가 사업자 정보 위치를 마이 화면 하단으로 안내하므로 Android가 빠지면 Android 이용자에게 사실과 달라진다. |
| 근거 | [2-2-7 사업자 정보와 문서 링크](2-2-REQUIREMENTS.md#2-2-7-사업자-정보와-문서-링크), [3-3-7 홈과 마이 하단 사업자 정보](3-3-LAYOUT.md#3-3-7-홈과-마이-하단-사업자-정보) |
| 출처 | 사용자 확정 결정. ([KNK-2146](https://kimandkang.atlassian.net/browse/KNK-2146)) |

<a id="c-024-마이의-서비스-안내를-없애고-법적-문서는-마이-하단-링크로-연다"></a>

**C-024. 마이의 서비스 안내를 없애고 법적 문서는 마이 하단 링크로 연다**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-27 |
| 상태 | Accepted |
| 배경 | [C-023](#c-023)으로 서비스 이용약관과 개인정보 처리방침 링크가 마이 하단에 생겼다. 서비스 안내는 게스트 이용 안내, AI 콘텐츠 안내, 문의와 약관 및 정책 링크를 담은 문서였고 법적 문서의 상시 진입점 역할도 했다(웹 `/about`, Android 앱 안 문서 화면). |
| 채택 | 웹과 Android 모두 마이의 서비스 안내 메뉴와 서비스 안내 화면을 없앤다. 웹은 `/about`을 제공하지 않고 사이트맵에서 뺀다. 법적 문서의 상시 진입점은 마이 하단 링크가 맡는다. `client_serviceInfo_viewed`는 보내지 않는다. 공통 목표 `CLIENT-US-002`는 폐기하고 ID를 재사용하지 않는다. |
| 대안 | 서비스 안내 유지(마이 하단 링크와 법적 문서 진입점 중복), Android만 제거(두 플랫폼의 마이 구성이 갈림) |
| 이유 | 사용자가 마이 하단 링크와 겹치는 서비스 안내를 없애도록 정했다. |
| 영향 | 게스트 저장 한계와 이관, AI 콘텐츠 안내는 별도 안내 화면 없이 게스트 동의와 법적 문서가 맡는다. 이미 설치된 이전 Android 버전의 서비스 안내 메뉴는 웹 `/about`을 열므로 웹 제거 뒤에는 웹의 미존재 안내가 보이며, 그 화면에 앱 안내 배너가 뜨지 않도록 `/about`은 배너 제외 경로로 남긴다. |
| 근거 | [공통 UI 화면 구성](../../../ui/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-화면과-진입점), [C-023](#c-023) |
| 출처 | 사용자 확정 결정. ([KNK-2147](https://kimandkang.atlassian.net/browse/KNK-2147)) |

<a id="c-025-사업자-정보를-홈-하단에도-두고-호스팅-제공자와-공정위-링크를-더한다"></a>

**C-025. 사업자 정보를 홈 하단에도 두고 호스팅 제공자와 공정위 링크를 더한다**

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-27 |
| 상태 | Accepted |
| 관계 | [C-023](#c-023)의 "마이 하단에만 둔다"와 "호스팅서비스 제공자 상호는 표시하지 않는다"를 대체한다. 마이 하단 표시와 문서 링크 배치는 유지한다. |
| 배경 | 강경현이 전자상거래법 시행규칙 제7조가 사업자 정보를 사이버몰 초기 화면에 표시하고 공정거래위원회 사업자정보 공개 페이지도 초기 화면에 연결하도록 하며, 호스팅서비스 제공자 상호도 필수 항목이라고 알려 왔다(2026-11-27 Slack). 모바일은 접어 두거나 차례로 보여도 된다고 했다. |
| 채택 | 홈 맨 아래에 사업자 정보 푸터를 더하고 사업자 정보는 접어 둔다. 문서 링크와 공정위 사업자정보 확인 링크는 접어도 보인다. 마이 하단은 펼친 채 유지한다. 두 곳 모두 호스팅서비스 제공자(Vercel Inc., Oracle Corporation)와 공정위 링크를 더한다. 웹과 Android가 같은 계약을 따른다. |
| 대안 | 마이에서 홈으로 옮기기(약관 제3조의 "마이 화면 하단" 안내를 다시 고쳐야 함), 마이 하단만 유지(초기 화면 표시 요건과 어긋날 수 있음) |
| 이유 | 사용자가 홈에 추가하고 마이도 유지하도록 정했다. 약관 제3조 안내를 그대로 둘 수 있다. |
| 영향 | 웹 호스팅이 바뀌면 호스팅서비스 제공자 값을 고친다. 신고번호와 같은 사이트 상수라 문서 버전과 무관하다. |
| 근거 | [2-2-7 사업자 정보와 문서 링크](2-2-REQUIREMENTS.md#2-2-7-사업자-정보와-문서-링크), [3-3-7 홈과 마이 하단 사업자 정보](3-3-LAYOUT.md#3-3-7-홈과-마이-하단-사업자-정보) |
