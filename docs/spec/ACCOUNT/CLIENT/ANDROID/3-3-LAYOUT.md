# 3-3 화면 배치: 안드로이드

<br>

### 3-3-1 공통 화면의 Android 표현

| 영역 | 표시 |
|---|---|
| 가입 혜택 | "지금 가입하고 N 이프 받기". N 바로 앞 이프 마크, 특정 공급자를 가리키지 않음 |
| 로그인 실패와 종료 안내 | 가입 혜택 배지 위 |
| 시작 화면 | 로고 심벌, 확인이 길어지면 제자리에서 튀는 로딩. 시스템 스플래시는 첫 프레임까지만 유지. 심벌은 64dp brand이고 확인이 지연 스피너 기준(300ms)보다 길어지면 튀기 시작한다. 한 번의 점프는 800ms로 앞 22% 동안 바닥을 누르듯 가로로 퍼지고 나머지 동안 심벌 폭 45% 높이의 포물선. 공중에서 위아래로 살짝 늘어나며 눈이 위를 보고, 착지할 때 찡그린다. 바닥의 brand 18% 타원 그림자는 높이 뜰수록 작고 옅다. 눈은 3200ms마다 깜빡인다. 확인이 끝나거나 실패하면 하던 점프를 착지까지 마치고 멈추며, 실패 화면에도 같은 심벌을 멈춘 채 둔다 |
| 조회 실패 재시도 | 앱의 공통 문구 "다시 시도". 동의 조회 실패 시트는 아래 문구 |
| 동의 조회 실패 | 제목 "약관 동의 내역을 불러오지 못했어요", 설명 "확인이 끝나야 서비스를 이용할 수 있어요", "다시 시도하기"와 보조 로그아웃 |
| 프로필 헤더 | 행 전체가 프로필 수정으로 가는 버튼. 웹과 같이 닉네임 바로 뒤 4dp에 마이 메뉴 행과 같은 16dp textSubtlest 꺾쇠(긴 닉네임은 말줄임, 꺾쇠 유지). 사방 16dp 여백을 눌림 영역에 넣어 리플이 화면 폭 전체에 번진다 |
| 연동 계정 칩 | 웹 배지와 같은 높이 24dp, 로고 12dp(이 칩 안에서만), 로고와 이름 사이 6dp, 가로 8dp, 세로 여백 없음. 연동된 제공자는 border 실선 칩, 미연동은 같은 모양의 borderStrong 점선(3dp 대시, 3dp 간격) 버튼으로 선의 모양이 상태를 말한다. 둘 다 연동되면 점선 버튼이 사라진다. 카카오 로고는 컨테이너 없이 text 단색 |
| 프로필 이미지 | 웹과 같은 96dp 원(빈 자리는 backgroundNeutral), 48px 인라인 썸네일을 먼저 깐 뒤 원본으로 바꾼다. 오른쪽 아래에 32dp text 원과 surface 2dp 경계의 연필 배지(16dp, textInverse)를 얹고 원 전체가 버튼 |
| 프로필 프리셋 | 4열, 격자 높이는 화면의 70% 이내에서 스크롤. 제목 titleLarge 아래 16dp에 원형 칸, 칸 사이 8dp. 제목은 고정되고 시트 위 스크림이 남는다. 고른 칸은 바깥 2dp borderBrand 테두리를 150ms 동안 채우고 리플 없음. 받는 동안 같은 칸 수의 원형 골격 |
| 홈과 마이 하단 사업자 정보 | 마이는 계정 섹션 아래에 항상 펼쳐 두고, 홈은 마지막 섹션 아래에 처음에는 접어 둔다. 바탕은 화면과 같고, 본문과 40dp 띄운 뒤 좌우 16dp 안쪽에 1dp border 가로 구분선을 둔다. 보이는 여백은 구분선 아래 20dp, 맨 아래 16dp이고 48dp 터치 줄이 품은 여백만큼 여백을 덜어 맞춘다. 라벨과 값 모두 bodySmall(12sp)과 textSubtle. 쌍 사이 가로 12dp와 세로 4dp, 라벨과 값 사이 4dp이고 쌍마다 라벨과 값을 한 번에 읽는다. 홈의 "사업자 정보" 버튼은 최소 48dp 높이이고 글자 뒤 2dp에 16dp textSubtle 꺾쇠를 두며 펼치면 꺾쇠가 위로 돈다. 상태는 "펼쳐짐", "접힘"으로 읽고 펼침 여부는 구성 변경과 탭 이동에도 유지한다. 문서 링크 세 개는 각각 최소 48dp 높이의 버튼이고 링크와 세로선 사이 8dp, 세로선은 1dp 폭 12dp 높이 border이며 좁으면 다음 줄로 넘어간다. Android에는 웹의 링크 묶음 랜드마크에 해당하는 구조가 없어 묶음 이름은 두지 않고 각 링크를 버튼으로 읽는다. 마이는 메뉴가 화면보다 짧으면 스크롤 영역의 최소 높이를 화면에 맞춰 맨 아래에 붙인다. 홈은 섹션 목록의 마지막 항목으로 두어 목록이 있을 때만 보이고, 섹션이 화면보다 짧아도 맨 아래에 붙이지 않는다 |
| 동의 시트 | 공통 배치, 끌어내리기와 바깥 탭 차단. 전체 화면 문서 창은 시트 위 표시 |

나머지 문구와 배치는 공통 ACCOUNT 화면을 적용한다. ([공통 3-3](../3-3-LAYOUT.md))
