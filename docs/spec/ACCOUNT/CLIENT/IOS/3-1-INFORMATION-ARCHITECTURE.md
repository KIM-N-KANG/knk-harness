# 3-1 화면 구성: iOS

<br>

### 3-1-1 진입 화면

상태별 루트 화면과 메인 셸은 공통 UI를 따른다. ([공통 UI 루트와 셸](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-루트와-셸))

| 화면 | 위치와 진입 |
|---|---|
| 로그인 화면 | 로그인 그래프의 루트 |
| 가입 동의 시트 | 로그인 화면 위 시트 |
| 회원 동의 시트 | 저장 세션은 시작 화면 위, 새 로그인 뒤는 로그인 화면 위 |
| 동의 조회 실패 | 저장 세션은 시작 화면 안 실패 자리, 새 로그인 뒤는 시트 안 실패 단계 |
| 법적 문서 | 로그인 화면에서는 로그인 그래프 스택에 쌓음. 동의 시트에서는 시트 위 전체 화면 덮개 |
| 정리 실패 재시도 | 루트 화면. 로그인 버튼 없음 |

공통 화면 구성과 iOS 진입 요구사항을 적용한다. ([공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md), [2-2-1](2-2-REQUIREMENTS.md#2-2-1-진입과-동의))

<br>

### 3-1-2 마이와 문서

| 화면 | 진입과 복귀 |
|---|---|
| 프로필 수정 | 마이 프로필 행 전체. 안쪽 연동 버튼은 자기 동작 유지. 마이 탭 스택에 쌓고 마이로 복귀 |
| 페르소나 관리 | 이프 카드 아래, 이벤트 위의 페르소나 관리. 마이 탭 스택 |
| 페르소나 생성과 수정 | 관리 목록 또는 스토리 상세에서 진입해 그 탭 스택에 쌓음. 들어온 화면으로 복귀 |
| 친구 초대와 탈퇴 | 마이 회원 메뉴. 마이 탭 스택 |
| 법적 문서 | 홈과 마이 하단 문서 링크에서 진입한 탭 스택에 쌓음. 하단의 사업자정보 확인은 앱 밖 브라우저 |
| 문서 닫기 | 진입한 화면 또는 체크가 유지된 동의 시트 |

탭 바 표시는 공통 UI의 규칙을 따른다. ([공통 UI 루트와 셸](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-루트와-셸))
