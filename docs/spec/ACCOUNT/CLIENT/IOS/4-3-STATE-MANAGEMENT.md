# 4-3 상태 관리: iOS

<br>

### 4-3-1 세션과 토큰

| 상태와 저장 | 처리 |
|---|---|
| 세션 | `SessionState`의 `Pending`, `Guest`, 회원, `CleanupFailed`. 읽을 수 있는 토큰 쌍으로 회원 판정, `/auth/me` 성공을 로그인 성립 조건으로 삼지 않음. `Guest`는 내부 세션 상태이며 게스트 기능 이용을 뜻하지 않음 ([I-063](DECISIONS.md#i-063)) |
| 토큰 저장 | Keychain의 일반 암호 항목 하나에 access, refresh와 만료 스냅샷을 JSON으로 저장. 접근 시점은 첫 잠금 해제 후 기기 전용(`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`), iCloud 키체인 동기화 끔. 생체 인증이나 기기 암호 확인을 요구하는 접근 제어 없음 ([I-061](DECISIONS.md#i-061)) |
| 노출 | `ManyakAuth`의 Data와 토큰 포트 안에서만 취급. UI, 로그, Crashlytics와 분석 전달 금지 |
| 읽기 결과 | 없음, 사용 가능, 손상, 읽기 실패. 결과별 처리는 [시작과 재설치 판정](4-4-EXECUTION.md#4-4-4-시작과-재설치-판정) |
| 설치 표시 | 기기 suite의 값 하나. 앱 삭제와 함께 지워지는 UserDefaults로 첫 실행을 판정하고 앱 삭제 뒤에도 남는 Keychain 항목을 정리 ([I-064](DECISIONS.md#i-064)) |
| 만료 스냅샷 | 토큰 쌍, `expiresIn`, 받은 시각의 벽시계 값 |
| 만료 판정 | 60초 여유. 벽시계 경과와 같은 프로세스 안에서 잰 `ContinuousClock`(잠자기 중에도 증가하는 단조 시계) 경과 중 큰 값. 벽시계 경과가 음수이면 만료. 프로세스를 새로 시작하면 벽시계만 사용 ([I-065](DECISIONS.md#i-065)) |
| 계정 격리 | `SessionGate` 액터 안에서 세대 확인, 결과 반영과 종료 장벽 전환. 취소만으로 늦은 결과 반영을 막지 않음 |

`SessionGate`는 세대 번호와 종료 표시를 가진다. 인증 작업은 시작할 때 세대를 받고 결과를 쓸 때 같은 액터 격리 안에서 세대를 다시 확인한다. 반영 블록 안에서 `await`하면 액터 재진입으로 확인과 쓰기 사이에 장벽이 닫힐 수 있으므로 세대 확인과 쓰기 사이에 `await`를 두지 않는다. 종료가 시작되면 세대를 올리고 등록된 인증 작업을 취소한 뒤 끝날 때까지 기다린다.

<br>

### 4-3-2 가입 대기와 회원 동의

| 대상 | 수명과 조건 |
|---|---|
| 가입 대기 코드 | `ManyakAuth` 저장소의 프로세스 메모리 필드만 사용. Entity, 디스크, Keychain, 로그, Crashlytics와 분석에 포함 금지 |
| 대기 항목 | 필요한 항목과 요구 버전만 공개. 새 로그인 시 이전 대기 폐기, 새 대기 공개 시 직전 종료 안내 제거 |
| 가입 완료 반영 | 같은 인증 작업에서 토큰 저장 → 회원 공개 → 대기 해제. 선택 동의 답을 가입 취소로 오인해 지우지 않음 |
| 회원 동의 | 필수 항목 모두 `needsConsent: false`일 때 완료. 필드 누락은 `Serialization`, 미완료 유지 |
| 완료 저장 | 메모리만 유지, 영속 완료 플래그 없음. 회원 정리에서 제거 |
| 동의 조회 | 회원 전환마다 별도 작업, 회원 아니면 비움. 조회가 세션 상태 관찰을 막지 않음 |
| 늦은 응답 | 세션 세대 확인과 반영으로 거부 |
| 요구 변경 | 버전 불일치 또는 기록 뒤 `needsConsent` 잔존 시 재조회와 체크 초기화 |
| 선택 동의 | OS 알림 권한과 무관하게 체크 항목 제공. 앱 루트 수명에서 답 유지, 권한 응답 뒤 알림 저장 경로에 전달하고 소비 |
| 시작 경로 | 시작 화면에서 복원한 회원과 로그인 후 전환 구분. 앱 루트 수명, 프로세스 재시작 때 재판정 |

시트의 로그아웃 버튼은 제출 중 잠기며 회원이면 세션 종료, 가입 대기이면 대기 취소이다.

### 4-3-3 프로필과 페르소나

| 대상 | 갱신과 수명 |
|---|---|
| 회원 자동 조회 | 세션과 동의 완료를 결합해 프로필과 체험 잔여 조회. 조건 해제 시 취소 |
| 프로필 갱신 | 로그인, 저장 세션 시작, 연동, 마이 탭 루트 표시와 출석 및 초대 성공. 마이 탭 루트 표시는 마이 탭 선택, 하위 화면에서 루트로 복귀, 마이 탭이 보이는 중의 포그라운드 복귀를 뜻하며 반복되는 `onAppear`를 계기로 쓰지 않음. 표시로 인한 갱신은 직전 조회 성공 뒤 5초 안이면 생략 |
| 프로필 캐시 | 회원 suite에 마지막 응답 저장. 재실행 첫 표시에 사용 |
| 갱신 중 | 기존 프로필 유지. 캐시 없으면 연동 칩 골격 2개, 비거나 실패하면 연동 버튼 추정 금지 |
| 프로필 편집 | 캐시에서 초기값 한 번, 없으면 조회. 입력과 프리셋, 시트 및 이탈 확인은 화면 Store 수명 |
| 저장 응답 | 같은 세대일 때만 프로필 캐시에 반영. 프리셋은 첫 시트 열기 때 조회해 화면 수명 동안 사용 |
| 작성자 표시 | 최초 값 이후 닉네임 변경 시 홈 첫 페이지 조용히 재조회. 상세는 진입 때 서버 조회 |
| 페르소나 목록 | 회원 메모리 상태. 진입 때 재조회, 변경 성공 응답을 먼저 반영 후 목록 재조회 |
| 생성 항목 전달 | 목록 재조회 실패에도 새 항목의 상세 미리 선택 유지. 메모리에만 두고 회원 정리에 참여 |
| 상세 선택 | 직접 고른 값은 컨트롤에서 즉시 읽음. 없는 ID는 기본 주인공. 다른 선택 또는 채팅 시작 시 생성 미리 선택 소비 |
| 채팅 복귀 | 시작할 때 직접 선택값으로 확정해 탭 스택에 남은 상세의 선택 유지 |
| 목록 표시 상태 | 펼침은 화면 상태, 옵션과 삭제 대상은 Store. 입력은 프로세스 종료 뒤 복원 안 함 |

### 4-3-4 초대와 종료 상태

| 대상 | 저장과 복구 |
|---|---|
| 초대 대기 | 회원 suite의 미완료 표시와 메모리의 가입 실행 여부 결합. 가입 실행은 미표시, 다음 실행부터 대기 |
| 닫기 기록 | 회원 suite의 표시 삭제와 현재 실행의 닫힘 기록. UserDefaults가 쓰기 결과를 돌려주지 않아 기록 실패 상태 없음 ([I-067](DECISIONS.md#i-067)) |
| 보상과 닫기 | 지급 결과와 닫힘을 별도 상태로 둠. 현재 실행의 닫힘으로 재표시 및 재제출 차단, 보상 재요청 없음 |
| 종료 저널 | 세대, 단계, 새 기기 ID 후보를 Application Support의 파일 하나에 원자적으로 기록. 쓰기 결과를 확인한 뒤 다음 단계. 성공 단계만 체크포인트 ([I-066](DECISIONS.md#i-066)) |
| 정리 중 | 공개 상태 `Pending`, 장벽 닫힘. 이전 계정 결과 반영 금지 |
| 정리 실패 | 필수 단계마다 3회 시도(200ms, 400ms 간격) 후 `CleanupFailed`, 저널 유지, 새 로그인 차단 |
| 재기동 | 같은 기기 ID 후보로 성공 단계 다음부터 멱등 재개. 재개한 정리는 종료 안내 없이 `Guest` 공개 |
| 제작 데이터 | 제작 데이터베이스 행은 삭제하지 않고 소유 회원 ID로 격리. 탈퇴 성공만 종료 전에 그 회원의 행 삭제를 시도 ([STORY I-122](../../../STORY/CLIENT/IOS/DECISIONS.md#i-122), [STORY iOS 제작 데이터베이스](../../../STORY/CLIENT/IOS/4-3-STATE-MANAGEMENT.md#4-3-2-제작-데이터베이스)) |

### 4-3-5 정리 대상과 기기 귀속

회원 데이터를 가진 저장소는 `UserScopedStore`를 구현하고 앱 타깃의 등록 배열 한 곳에 등록한다. 정리 단계는 모든 항목을 실행하고 하나라도 실패하면 단계 실패로 본다. 항목 사이 순서에 의존하지 않는다. 회원 suite에 값을 두는 저장소는 메모리 값만 지우고 디스크 값은 회원 suite 항목이 지운다. 결과를 돌려주지 않는 정리는 호출이 끝나면 성공으로 본다.

| 등록 항목 | 소유 타깃 | 정리 |
|---|---|---|
| 회원 동의 완료 | `ManyakLegal` | 메모리 완료 상태 해제 |
| 프로필 캐시 | `ManyakMy` | 메모리 값 해제 |
| 초대 안내 대기 | `ManyakMy` | 메모리 값 해제 |
| 페르소나 목록과 생성 항목 | `ManyakMy` | 메모리 값 해제 |
| 스토리 온보딩 표시 | `ManyakOnboarding` | 메모리 값 해제 ([STORY iOS 가입 안내](../../../STORY/CLIENT/IOS/4-3-STATE-MANAGEMENT.md#4-3-4-장르-기기-기록과-가입-안내)) |
| 광고 동의 질문 기록 | `ManyakNotification` | 메모리 값 해제 ([NOTIFICATION iOS 저장 위치](../../../NOTIFICATION/CLIENT/IOS/4-3-STATE-MANAGEMENT.md#4-3-1-저장-위치와-수명)) |
| 알림 정리 | `ManyakNotification` | 기기 FCM 토큰 삭제, 알림 센터의 이 앱 알림 제거. 범위는 NOTIFICATION ([NOTIFICATION iOS 저장 위치](../../../NOTIFICATION/CLIENT/IOS/4-3-STATE-MANAGEMENT.md#4-3-1-저장-위치와-수명)) |
| 체험 잔여 | `ManyakCredit` | 메모리 값 해제 ([PAYMENT iOS 값과 수명](../../../PAYMENT/CLIENT/IOS/4-3-STATE-MANAGEMENT.md#4-3-1-값과-수명)) |
| 회원 suite | `ManyakCommon` | suite 전체 삭제. 삭제 결과를 돌려주지 않으므로 남은 키가 없는지 다시 읽어 판정 |
| 이미지 캐시 | `ManyakDesignSystem`. 앱 타깃이 감싸 등록 | Nuke 설정이 쓰는 메모리와 디스크 캐시 전체 ([I-062](DECISIONS.md#i-062)) |
| HTTP 응답 캐시 | `ManyakNetwork` | 요청 계층이 응답 캐시를 쓰면 전체 삭제 |

`ManyakDesignSystem`은 `ManyakCommon`에 의존하지 않으므로 캐시 비우기만 공개하고 앱 타깃이 `UserScopedStore`로 감싼다. 아래 값은 기기 귀속이라 등록하지 않고 로그아웃에도 남긴다.

| 기기 귀속 값 | 소유 타깃 | 처리 |
|---|---|---|
| 테마 선택 | `ManyakCommon` | 유지 |
| 채팅 기기 설정과 안내 기록 | `ManyakChat` | 유지 |
| 최근 검색 | `ManyakHome` | 유지 |
| 공지 읽음 | `ManyakNotice` | 유지 |
| 기기 토큰 삭제 미완료 표시 | `ManyakNotification` | 유지. 기기 토큰 삭제나 다음 등록이 성공하면 지움 |
| 제작 안내 단계 | `ManyakCreate` | 유지 |
| 제작 데이터베이스 | `ManyakCreate` | 유지하고 소유 회원 ID로 격리. 탈퇴 성공은 종료 전에 그 회원의 행 삭제 시도 |
| 기기 ID | `ManyakCommon` | 로그아웃 정리에서 새 값으로 교체 |
| 설치 표시 | `ManyakAuth` | 유지 |
| 종료 저널 | `ManyakAuth` | 정리 완료 때 삭제 |
