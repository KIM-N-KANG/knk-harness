# 3-3 화면 배치: iOS

<br>

### 3-3-1 공통 화면의 iOS 표현

길이 단위는 pt이고 글자 토큰과 색 토큰은 공통 UI의 디자인 토큰이다. ([공통 UI 디자인 토큰](../../../../ui/IOS/3-3-LAYOUT.md#3-3-7-디자인-토큰))

| 영역 | 표시 |
|---|---|
| 가입 혜택 | "지금 가입하고 N 이프 받기". N 바로 앞 이프 마크, 특정 제공자를 가리키지 않음. 배지 바탕은 아래 배경 그림을 흐리게 비추는 흐림 재질이고 천천히 떠올랐다 내려앉음. 동작 줄이기에서는 멈춤 |
| 로그인 실패와 종료 안내 | 가입 혜택 배지 위 |
| 시작 화면 | 64pt brand 로고 심벌을 실행 화면과 같은 위치와 크기로 둠. 확인이 지연 스피너 기준(300ms)보다 길어지면 제자리에서 튀기 시작. 한 번의 점프는 800ms로 앞 22% 동안 바닥을 누르듯 가로로 퍼지고 나머지 동안 심벌 폭 45% 높이의 포물선. 공중에서 위아래로 살짝 늘어나며 눈이 위를 보고 착지할 때 찡그림. 바닥의 brand 18% 타원은 높이 뜰수록 작고 옅음. 눈은 3200ms마다 깜빡임. 확인이 끝나거나 실패하면 하던 점프를 착지까지 마치고 멈추며 실패 화면에도 같은 심벌을 멈춘 채 둠. 동작 줄이기에서는 튀기와 깜빡임 없이 멈춘 심벌 |
| 조회 실패 재시도 | 앱의 공통 문구 "다시 시도". 동의 조회 실패는 아래 문구 |
| 동의 조회 실패 | 제목 "약관 동의 내역을 불러오지 못했어요", 설명 "확인이 끝나야 서비스를 이용할 수 있어요", "다시 시도하기"와 보조 로그아웃. 저장 세션의 시작 화면에는 로그아웃 없음 |
| 프로필 헤더 | 행 전체가 프로필 수정으로 가는 버튼. 닉네임 바로 뒤 4pt에 마이 메뉴 행과 같은 16pt textSubtlest 꺾쇠(긴 닉네임은 말줄임, 꺾쇠 유지). 사방 16pt 여백까지 눌림 영역이고 눌리면 화면 폭 전체에 overlayPressed |
| 연동 계정 칩 | 높이 24pt, 로고 12pt(이 칩 안에서만), 로고와 이름 사이 6pt, 가로 8pt, 세로 여백 없음. 연동된 제공자는 border 실선 칩, 미연동은 같은 모양의 borderStrong 점선(3pt 대시, 3pt 간격) 버튼으로 선의 모양이 상태를 말함. 둘 다 연동되면 점선 버튼이 사라짐. 카카오 로고는 컨테이너 없이 text 단색. 점선 버튼은 보이는 크기를 유지하고 터치 영역만 44pt |
| 프로필 이미지 | 96pt 원(빈 자리는 backgroundNeutral). 48px 인라인 썸네일을 먼저 깐 뒤 원본으로 바꿈. 오른쪽 아래에 32pt text 원과 surface 2pt 경계의 연필 배지(16pt, textInverse)를 얹고 원 전체가 버튼 |
| 프로필 프리셋 | 4열, 격자 높이는 화면의 70% 이내에서 스크롤. 제목 titleLarge 아래 16pt에 원형 칸, 칸 사이 8pt. 제목은 고정. 고른 칸은 바깥 2pt borderBrand 테두리, 눌림 덮개 없음. 받는 동안 같은 칸 수의 원형 골격 |
| 홈과 마이 하단 사업자 정보 | 홈은 섹션 목록, 마이는 마지막 메뉴 묶음 바로 아래에 같은 푸터를 항상 펼쳐 둠. 화면 쪽 간격 없이 붙이고 위 내용과의 48pt는 푸터가 가짐. 바탕은 화면과 같고 좌우 gutter 16pt 안쪽에 1pt border 가로 구분선. 구분선 아래 16pt에 사업자 정보. 라벨과 값 모두 bodySmall과 textSubtle. 쌍 사이 가로 12pt와 세로 4pt, 라벨과 값 사이 4pt이고 줄 바꿈은 쌍 단위이며 VoiceOver는 쌍마다 라벨과 값을 한 번에 읽음. 문서 링크 세 개는 각각 터치 영역 44pt 이상의 버튼이고 링크와 세로선 사이 8pt, 세로선은 1pt 폭 12pt 높이 border. 좁거나 글자가 크면 다음 줄로 넘어가고 세로선은 같은 줄의 링크 사이에만 둠. 링크 묶음은 접근성 묶음 하나로 두고 이름은 "약관 및 정책". 맨 아래 보이는 여백 16pt. 내용이 화면보다 짧아도 화면 맨 아래로 밀지 않음. 홈의 첫 로딩 골격, 빈 상태와 오류 상태는 안내를 남은 영역 가운데에 두고 푸터를 그 아래 화면 끝에 둠 |
| 동의 시트 | 공통 배치. 끌기 표시 없음, 끌어내리기와 바깥 탭 닫기 차단. 전체 화면 문서 창은 시트 위 표시 |

나머지 문구와 배치는 공통 ACCOUNT 화면을 적용한다. ([공통 3-3](../3-3-LAYOUT.md))
