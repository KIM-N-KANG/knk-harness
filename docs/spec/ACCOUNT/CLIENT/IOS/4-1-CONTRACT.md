# 4-1 연동 계약: iOS

<br>

### 4-1-1 서버와 문서

| 대상 | 연동 |
|---|---|
| 서버 | 공통 ACCOUNT 요청과 응답 사용 |
| 소셜 로그인 | `/auth/social/{provider}`, `/auth/social/complete`. `provider`는 `google`, `kakao`만 사용. 구버전 `/auth/login/{provider}` 미사용 |
| 제공자 ID 토큰 | Google은 서버 클라이언트 ID를 대상(`aud`)으로 받은 ID 토큰, Kakao는 서버 허용 목록과 같은 카카오 앱의 ID 토큰 |
| 가입 완료 | `X-Manyak-Consent-Token`으로 대기 코드 전달. 광고 동의 답은 본문에 포함하지 않음 |
| 계정 연동 | 재인증 enum은 대문자, 제공자 경로는 소문자 |
| 법적 문서 | 설정된 웹 호스트의 HTTPS `/terms`, `/privacy`를 앱 안 웹 보기(WKWebView)로 표시 |
| 사업자정보 확인 | 공정거래위원회 사업자정보 공개 페이지 HTTPS 주소를 시스템 URL 열기로 앱 밖 브라우저에서 엶. 열기 결과가 실패면 실패 토스트 |
| 외부 HTTP(S) | 시스템 URL 열기. 열기 결과가 실패면 실패 토스트 |
| 차단 | 다른 스킴과 같은 호스트의 문서 외 페이지. 웹의 클라이언트 라우팅 링크 제거도 필요하며 웹 보기의 이동 검사로 대체하지 않음 |
| 앱 버전 헤더 | `X-Manyak-App-Version` 미전송 ([IOS 기반 네트워크 요청](../../../../platform/CLIENT/IOS/3-EXECUTION.md#3-2-네트워크-요청)) |

서버 형식과 사용자 결과의 변환은 공통 계약을 사용한다. 서버 로그인 제공자에 `apple`은 없다. ([공통 4-1](../4-1-CONTRACT.md), [4-2-2 소셜 인증](../../BACKEND/4-2-CONTRACT.md#4-2-2-소셜-인증))

<br>

### 4-1-2 식별 정보

| 값 | 전달 |
|---|---|
| 기기 UUID | 기기 suite에 지속. 최초 로그인과 API 및 Amplitude 이벤트 전에 같은 값 주입. 빈 값 전송 금지. 로그아웃 정리에서 새 값으로 교체 |
| 세션 ID | 인증과 무인증 HTTP 요청 모두 현재 Amplitude SDK 세션 값을 `X-Manyak-Session-Id`로 전달. 미설정 또는 음수이면 생략 |
| 분석 사용자 | 시작 시 이전 식별 해제. 회원 세션, 프로필과 필수 동의가 모두 준비된 뒤 설정 |
| 제공자 프로필 | SDK가 돌려준 이메일, 이름과 사진을 저장하거나 서버, 분석과 로그로 보내지 않음. 서버에는 ID 토큰만 전달 |

회원 체험 시드에 사용된 기기 식별자는 정상 흐름에서 되돌릴 수 없으므로 초기 주입 순서를 유지한다.
