# 2-2 요구사항: iOS

<br>

### 2-2-1 진입과 동의

공통 요구사항의 iOS 적용 범위를 구체화한다. ([공통 2-2-1](../2-2-REQUIREMENTS.md#2-2-1-적용-범위))

| 상황 | 조건과 결과 |
|---|---|
| 비로그인 | 로그인 필수. 게스트 온보딩, 로컬 서재와 이관, 게스트 체험 선차단 비적용 |
| 로그인 제공자 | Google과 Kakao. Sign in with Apple 없음 ([I-060](DECISIONS.md#i-060)) |
| 법적 문서 | 로그인 전 열람 허용, 닫으면 진입 화면 복귀 |
| 가입 대기 | 로그인 화면 위 동의 시트. 새 로그인은 이전 대기 폐기. 앱을 떠났다 돌아오면 같은 시트, 프로세스 종료 뒤에는 로그인부터 재개 |
| 가입 대기 취소 | 시트의 로그아웃 버튼만 대기 취소. 끌어내리기와 바깥 탭으로 닫히지 않음. 제출 중 잠금 |
| 가입 완료 후 확인 | 서버 필수 동의 재확인까지 로그인 화면과 진행 표시 유지, 소셜 버튼 잠금 |
| 저장 세션 기동 | 실행 화면 뒤 앱 안 시작 화면에서 동의 확인. 완료하면 로그인 화면 없이 메인 셸 |
| 시작 조회 실패 | 일시 실패는 재시도만 제공. 앱을 떠나도 세션 유지 ([I-069](DECISIONS.md#i-069)) |
| 시작 재동의 | 시작 화면 위 동의 시트. 시트의 로그아웃은 세션 종료 |
| 권한 거절 | 이용 제한과 로그아웃만 표시. 일반 403과 계정 정지를 혼동하지 않음 |
| 동의 전 | 회원 화면 생성, 외부 진입 소비, 분석 식별, 푸시 등록, 프로필 및 회원 체험 조회 차단 |
| 동의 완료 | 메인 셸과 알림 권한 요청 → 선택 동의 처리 → 초대 안내 → 광고 재질문 |
| 첫 회원 화면 | 신규 가입은 스토리 온보딩. 초대 안내는 가입 실행을 건너뛴 다음 실행의 홈 |
| 세션 판정 중 | 로그인과 회원 화면 어느 쪽도 확정하지 않음 |
| 정리 실패 | 복구와 재시도 화면, 완료 전 새 로그인 금지 |
| 일시적 세션 복원 실패 | 네트워크 실패만으로 세션 폐기하지 않음. 무한 대기 금지 |
| 재설치 | 앱을 지우고 다시 설치한 첫 실행은 이전 세션을 되살리지 않고 로그인 화면 ([I-061](DECISIONS.md#i-061)) |
| 제공자 앱 전환 | 카카오톡 앱으로 전환한 동안 앱 프로세스가 끝나면 돌아와도 진행 표시를 복원하지 않고 로그인 화면 |

첫 스토리 온보딩의 내용은 STORY 계약에 있다. ([STORY iOS 신규 가입 온보딩](../../../STORY/CLIENT/IOS/2-2-REQUIREMENTS.md#2-2-3-신규-가입-온보딩))

### 2-2-2 편집과 법적 문서

| 대상 | 조건과 결과 |
|---|---|
| 프로필 | 저장과 이탈 후 마이 복귀. 미저장 변경이 있거나 저장 중이면 공통 UI iOS 이탈 확인 규칙의 대상. 미저장 변경은 뒤로 버튼이 이탈 확인을 띄우고 저장 중에는 이동 없음 ([공통 UI iOS 이탈 확인](../../../../ui/IOS/2-2-REQUIREMENTS.md#2-2-1-화면과-기기), [I-068](DECISIONS.md#i-068)) |
| 프로필 반영 | 마이와 재실행 프로필 갱신. 홈 작성자는 조용히 재조회하고 실패를 알리지 않음 |
| 페르소나 | 저장 후 스토리 상세 또는 관리 목록 복귀. 기존 채팅 유지 |
| 편집 상태 | 입력, 선택한 프리셋과 시트 및 확인창은 백그라운드 복귀와 테마 및 글자 크기 변경에서 유지. 프로세스 종료 뒤 복원하지 않음 |
| 문서 창 | 동의 시트 위 전체 화면 덮개로 열고 닫으면 체크 유지 |
| 문서 링크 | 앱 안 문서 화면, 외부 HTTP(S)는 앱 밖 브라우저. 같은 호스트의 문서 외 경로와 다른 스킴 차단 |
| 게스트 안내 | 웹 브라우저 전용임을 표시 |
| 초대 | 시스템 복사와 공유 시트, 서버 보상 수치 사용 |
| 안내 닫기 기록 | 현재 실행에서 시트 닫기와 재표시 및 재제출 차단. 기록이 기기에 남지 않았으면 다음 실행에서 다시 확인 |
| 보상 후 닫기 | 지급 결과 안내 후 닫기. 보상 재요청 없음. 지급 후 닫기 실패 표시 없음 ([I-067](DECISIONS.md#i-067)) |
| 탈퇴 | 앱 안 회원 탈퇴 화면에서 완료. 서버 성공 확인 뒤 세션 종료 |
