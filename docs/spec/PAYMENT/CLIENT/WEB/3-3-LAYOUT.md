# 3-3 화면 배치: 웹

<br>

### 3-3-1 충전 탭

| 요소 | 표시 |
|---|---|
| 탭 | 구매, 무료 충전, 내역의 밑줄 탭 |
| 상품 행 | 왼쪽 기본 "N 이프"와 이프 마크, 오른쪽 강조색 "N원" 버튼 |
| 보너스 | 있는 상품만 기본 수치 아래 강조색 굵은 "+N 이프". 이프 마크 자리만큼 들여 맞춤 |
| 상품 간격 | 구분선 없이 16px |
| 구매 안내 | 상품 목록 32px 아래, 상자 없이 좌우 16px. 14px semibold 제목 8px 아래 12px 보조 글자색 글머리표 목록 하나(행 20px, 항목 사이 4px). 어절 단위 줄바꿈. 문구는 아래 표 |
| 요청 중 | 누른 가격 버튼에 "결제 준비 중" 스피너. 모든 가격 버튼 비활성 |
| 상품 조회 중 | 상품 줄 골격 |
| 상품 조회 실패 | "충전 상품을 불러오지 못했어요"와 "다시 시도하기" |
| 구매 시작 실패 | "결제를 시작하지 못했어요" 토스트 |
| 무료 충전 초대 메뉴 | 출석 상자 32px 아래 |
| 내역 행 | 위아래 여백 8px. 라벨과 날짜는 공통 표현 |

구매 안내 문구는 다음과 같다. 제목은 "환불과 이프 이용 안내"이고 항목은 이 순서로 둔다.

| 순서 | 항목 |
|---|---|
| 1 | "결제일로부터 7일 안에 구매한 이프를 하나도 쓰지 않았다면 전액 환불받을 수 있어요" |
| 2 | "7일이 지났거나 구매한 이프를 조금이라도 썼다면 환불받을 수 없어요" |
| 3 | "만 19세 미만이 법정대리인 동의 없이 결제했다면 본인이나 법정대리인이 취소할 수 있어요" |
| 4 | "구매한 이프는 적립일로부터 5년, 무료로 받은 이프는 30일 동안 쓸 수 있어요" |
| 5 | "기간이 지난 이프는 사라지고 되돌릴 수 없어요" |
| 6 | "만료일이 가까운 이프부터 먼저 써요" |
| 7 | "탈퇴하면 남은 이프는 사라져요" |
| 8 | "환불과 취소는 {문의 이메일}으로 요청해 주세요" |

### 3-3-2 결제 확인 카드

잔액 상자 아래에 "결제 확인" 카드와 닫기 버튼을 둔다.

| 상태 | 표시 |
|---|---|
| 확인 중 | 스피너와 "결제를 확인하고 있어요" |
| 완료 | "N 이프가 충전됐어요". N은 주문 적립 총량 |
| 환불 | "환불된 주문이에요" |
| 없는 주문 | "확인할 수 없는 주문이에요" |
| 대기 초과 | "아직 결제 확인이 안 됐어요"와 "다시 확인" |
| 조회 실패 | "결제 확인에 실패했어요"와 "다시 확인" |

잔액, 출석, 내역과 부족 시트는 공통 표현을 사용한다. ([공통 3-3](../3-3-LAYOUT.md), [결제 결과 요구사항](2-2-REQUIREMENTS.md#2-2-2-구매와-적립-확인))
