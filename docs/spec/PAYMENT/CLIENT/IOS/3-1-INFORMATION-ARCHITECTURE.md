# 3-1 화면 구성: iOS

<br>

### 3-1-1 진입과 목적지

| 시작 | 목적지 | 처음 표시 |
|---|---|---|
| 마이 이프 카드의 충전 | 마이 탭 스택의 이프 충전 | 무료 충전 탭 |
| 채팅방의 부족 시트, 채팅 메뉴 이프 카드의 충전 | 시트를 닫고 채팅방이 있는 탭 스택의 이프 충전 | 무료 충전 탭 |
| 간편 제작의 부족 시트 | 퍼널을 걷어 낸 제작 탭 스택의 이프 충전 | 무료 충전 탭 |
| 푸시의 `/my/credits` | 마이 탭의 루트와 이프 충전 | `tab=history`만 내역 탭, 그 밖은 무료 충전 탭 |
| 알림함 이프 알림 카드의 `/my/credits` | 이프 충전. 쌓는 탭은 NOTIFICATION | 푸시와 같은 탭 해석 |
| 앱 열기 링크의 `/my/credits` | 홈 탭 루트 | 해당 없음 |
| 무료 충전의 친구 초대 | 같은 탭 스택의 친구 초대 | ACCOUNT의 초대 화면 |
| 회원 채팅 메뉴 이프 카드의 내역 | 같은 시트의 이프 내역 | 첫 페이지. 배치와 흐름은 CHAT |

이프 충전은 진입한 탭의 스택에 쌓이고 탭 바를 숨긴다. 구매 탭, 상품 목록, 결제 확인과 웹 충전 화면으로 가는 진입은 두지 않는다. 처음 탭의 조건은 iOS 요구사항, 탭 바와 푸시 목적지의 탭은 공통 UI, 알림함 카드의 이동은 NOTIFICATION이 정한다.
