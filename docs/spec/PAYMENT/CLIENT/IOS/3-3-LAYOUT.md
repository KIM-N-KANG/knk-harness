# 3-3 화면 배치: iOS

<br>

### 3-3-1 공통 표현과 iOS 요소

| 요소 | iOS 표현 |
|---|---|
| 헤더 | 시스템 내비게이션 바의 뒤로 버튼과 가운데 제목 "이프 충전". 오른쪽 요소 없음 |
| 탭 | "무료 충전", "내역" 순의 밑줄 탭. VoiceOver에 선택 상태 전달 |
| 잔액과 탭 | 위에 고정. 탭 내용만 스크롤하고 당겨서 새로고침도 탭 내용에 둠 |
| 잔액 수치 | 고정폭 숫자. "내 이프"와 수치를 한 요소로 읽고 이프 마크는 탐색 대상에서 제외 |
| 출석 여부 미확인 | 무료 충전 탭의 "출석 하기" 비활성 |
| 출석 요청 중 | 무료 충전 탭과 부족 시트 모두 버튼 문구를 "출석 체크 중"으로 바꾸고 잠금. 스피너로 대체하지 않음 |
| 내역 목록 | 충전 내역 탭과 채팅 메뉴의 이프 내역이 같은 행, 골격, 빈 상태와 오류 표현 사용. 증감량은 고정폭 숫자. 행 하나를 사유, 대상, 날짜, 증감량 순의 한 요소로 읽음 |
| 부족 시트 | 시스템 시트 한 단계 높이. 제목, 설명, 주 버튼 "이프 충전하기", 오늘 미출석일 때 중립 버튼 "출석 체크하기", 글자 버튼 "닫기" 순. 처리 중 세 버튼 비활성 |
| 충전 이동 준비 중 | 간편 제작의 초안 저장을 기다리는 동안 "이프 충전하기" 문구 자리에 스피너 |
| 토스트 | 출석 결과와 실패, 새로고침 실패 "새로고침하지 못했어요"는 짧은 표시 |
| 색, 서체와 간격 | `ManyakTheme` 토큰 사용 |
| 두지 않는 요소 | 구매 탭, 상품과 가격, 구매 안내 버튼과 툴팁, 결제 확인 카드, 웹 충전 링크 |

잔액, 내역, 출석과 부족 문구는 공통 표현을 적용한다. 시트 잠금, 토스트와 접근성의 공용 규칙은 공통 UI를 따른다. ([공통 3-3](../3-3-LAYOUT.md), [공통 UI IOS 3-3](../../../../ui/IOS/3-3-LAYOUT.md), [I-085](DECISIONS.md#i-085))
