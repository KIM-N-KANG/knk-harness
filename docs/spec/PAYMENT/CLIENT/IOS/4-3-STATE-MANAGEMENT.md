# 4-3 상태 관리: iOS

<br>

### 4-3-1 값과 수명

| 상태 | 기준과 수명 |
|---|---|
| 정책 | 앱 수명 객체가 관찰 가능한 값으로 보관하고 조립 객체가 소비 Store에 넘김. 최초 실패는 자리표시, 기존 값이 있으면 유지. 로그아웃에도 유지 |
| 체험 | 회원 귀속 메모리 값. 디스크 저장 없음. `UserScopedStore`로 로그아웃 정리에서 비우고 `SessionGate` 세대가 다른 늦은 응답은 쓰지 않음 |
| 잔액과 출석 여부 | 회원 정보(ACCOUNT 세션 조회) 구독. 충전 Store가 화면 State로 전달 |
| 내역과 커서 | 충전 Store 수명. 충전 화면이 스택에서 빠지면 사라지고 다시 들어오면 새로 조회. 채팅 메뉴의 내역은 CHAT 상태 관리 |
| 처음 탭 | 라우트 값의 내역 여부로 초기화 |
| 사용자가 고른 탭 | 충전 Store State. 라우트에 다시 쓰지 않음. 테마와 글자 크기 변경에 유지, 프로세스 종료 뒤 복원하지 않음 |
| 부족 시트와 요청 잠금 | 각 채팅 또는 제작 Store State. 테마와 글자 크기 변경에 유지. 해당 화면이 스택에서 빠지거나 프로세스가 종료되면 복원하지 않음 |
| 출석 결과 안내 | 일회성 Effect. 수집이 끊긴 동안 Store가 보관했다가 한 번 전달 |

알 수 없는 체험 잔여로 적용가를 확정하지 않는다. 조회 실패는 기존 체험 값을 유지하되 로그아웃 정리에서 반드시 비운다. ([공통 2-2-3](../2-2-REQUIREMENTS.md#2-2-3-체험), [IOS 기반 2-4](../../../../platform/CLIENT/IOS/2-STATE-MANAGEMENT.md#2-4-로컬-저장))
