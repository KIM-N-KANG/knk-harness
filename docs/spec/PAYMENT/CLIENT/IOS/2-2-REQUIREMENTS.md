# 2-2 요구사항: iOS

<br>

### 2-2-1 충전 화면

| 상황 | 조건과 결과 |
|---|---|
| 적용 범위 | 회원 잔액, 무료 충전, 내역 제공. 구매 화면, 구매 탭, StoreKit 결제와 웹 구매 안내 없음 |
| 구매 유도 | 화면, 시트, 토스트와 접근성 이름 어디에도 웹 결제로 유도하는 문구, 버튼, 링크 없음. 앱에서 결제 절차를 시작하지 않음 |
| 초기 탭 | 앱 안 진입은 무료 충전. 푸시와 알림함 카드의 `/my/credits`는 `tab` 값이 정확히 `history`일 때만 내역 |
| 다른 쿼리 | `purchase`, `free`, 모르는 값, 대소문자가 다른 값과 미지정은 무료 충전. 같은 키가 여러 번 오면 첫 값만 사용. UTM 등 무시 |
| 앱 열기 링크 | `manyak://manyak.app/my/credits`는 쿼리와 관계없이 충전 화면이 아닌 홈 |
| 탭 선택 | 처음 탭만 목적지로 전달. 이후 선택은 화면 상태이며 테마와 글자 크기 변경에서 유지 |
| 잔액과 출석 | 화면 진입과 화면이 보이는 중의 포그라운드 복귀 때 회원 정보 갱신. 미수신을 0으로 표시하지 않음 |
| 당겨서 새로고침 | 무료 충전은 회원 정보, 내역은 회원 정보와 첫 페이지 갱신 |
| 갱신 실패 | 기존 목록 유지, 오류 안내 |

공통 적용 범위를 구체화한다. 앱 열기 링크의 목적지는 공통 UI가 정한다. ([공통 2-2-1](../2-2-REQUIREMENTS.md#2-2-1-적용-범위), [진입 목적지](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-2-진입-목적지))

### 2-2-2 부족 안내와 수명

| 상황 | 결과 |
|---|---|
| 시트와 출석 요청 중 상태 | 테마와 글자 크기 변경에서 유지. 시트를 연 화면이 스택에서 빠지거나 프로세스가 종료되면 복원하지 않음 |
| 채팅에서 충전 | 시트를 닫고 같은 탭 스택의 채팅방 위에 충전 열기. 채팅방과 입력은 스택에 남음 |
| 간편 제작에서 충전 | 버튼 임시 저장과 같은 저장을 기다림. 성공하면 퍼널을 걷고 제작 탭 루트 위에 충전 열기 |
| 제작 저장 실패와 충돌 | 시트와 퍼널 유지. 기존 저장 실패 안내 |
| 충전 뒤 뒤로가기 | 채팅은 같은 방과 입력, 제작은 초안 카드가 있는 제작 탭 루트 |
| 외부 진입으로 시트 닫힘 | 이탈 확인 없음. 시트를 연 화면이 스택에 남으면 입력 유지. 화면이 빠지면 진행 중 출석 요청 취소, 결과 안내 없음 |
| 제출 뒤 확정된 완성 실패 | 이프 부족이어도 "스토리를 완성하지 못했어요". 복구 응답에 실패 사유가 없음 |

게스트 소진과 로그인 안내는 iOS에 적용하지 않는다. ([공통 2-2-3](../2-2-REQUIREMENTS.md#2-2-3-체험))

### 2-2-3 출석 후 이프 부족

구매 경로가 없으므로 오늘 출석을 마친 회원은 앱 안에서 이프를 바로 늘리지 못할 수 있다.

| 상황 | 결과 |
|---|---|
| 오늘 미출석 | 시트에 "출석 체크하기". 성공하면 결과 안내와 함께 시트를 닫고 사용자가 같은 동작을 다시 실행 |
| 오늘 출석 완료 또는 출석 여부 미확인 | 시트에 "이프 충전하기"와 "닫기"만. 출석 버튼 자리를 다른 안내로 채우지 않음 |
| 그 상태로 충전 이동 | 무료 충전 탭의 "출석 완료" 비활성, 초기화 시각 안내와 친구 초대 줄만 보임. 구매 탭, 구매 안내와 외부 링크 없음 |
| 시트 닫기 | 입력과 기존 콘텐츠 유지. 같은 동작을 다시 실행하면 선검사나 서버 판정으로 같은 시트 |
| 이용 재개 | 다음 KST 자정 뒤 출석하거나 친구 초대 보상으로 잔액이 적용가 이상이 된 뒤 같은 동작을 다시 실행 |

PAYMENT-US-004의 iOS 결과다. ([공통 2-2-5](../2-2-REQUIREMENTS.md#2-2-5-이프-부족과-입력-보존))
