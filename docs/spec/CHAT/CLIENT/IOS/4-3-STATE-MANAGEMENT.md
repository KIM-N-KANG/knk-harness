# 4-3 상태 관리: iOS

<br>

### 4-3-1 소유와 수명

| 상태 | 소유와 수명 |
|---|---|
| 입력, 진행 응답과 잠금 | 채팅방 Store. 테마와 글자 크기 변경, 탭 전환과 백그라운드에 유지. 방 이탈과 프로세스 종료에 사라짐 |
| 생성 단계 | 채팅방 Store의 단계 값 하나. 단계별로 생성 종류, 요청 스냅샷, 대신하는 턴 ID, 전송 시점 확정 턴 수, 아는 생성 ID와 판정할 결과를 가짐 |
| 설정 시트와 투어 스텝 | 채팅방 Store. 같은 방에서는 스텝 유지, 도달 이벤트 중복 없음 |
| 입력 수정 편집 | Store의 대상 턴 ID와 고치던 입력. 기기 저장 없음. 대상 턴이 목록에 없으면 편집기를 그리지 않음 |
| 턴 확인 창 | Store. 재생성, 입력 수정, 포크와 삭제 중 하나. 입력 수정은 앞뒤 공백을 뺀 입력과 사라질 턴 수를 함께 보관 |
| 진행 중 숨김 | Store의 대신하는 턴 ID와 입력 수정 여부. 확정, 실패와 정리에서 해제 |
| 포크 요청 | Store 잠금. 원래 방이 스택에 남으므로 성공 뒤 이동 Effect를 보낸 뒤 해제 |
| 삭제 요청 | Store 잠금. 처리 중 방 전체 조작 차단. 성공은 이동 Effect, 실패는 잠금 해제와 토스트 |
| 모델 시트와 헤더 숨김 | 화면 상태. 같은 방에서 유지 |
| 메뉴의 이프 내역 | 채팅방 Store. 메뉴 화면이면 없음. 돌아가기와 시트 닫기에서 비움 |
| 뷰어 URL | 채팅방 Store. 라우트와 저장 상태에 넣지 않음. 상세에서 이미지가 사라지면 닫기 |
| 이미지, 추천과 입력 모드 | UserDefaults 기기 suite의 `chat_realtime_image_enabled`(기본 false), `chat_choices_enabled`(기본 true), `chat_input_mode`(기본 블럭). `UserScopedStore` 비참여 |
| 설정 읽기 | 진입 시 한 번 읽고 화면 상태가 기준. 저장 결과가 방금 선택을 되돌리지 않음 |
| 투어와 추천 힌트 기록 | 기기 suite `chat_tour_seen`, `chat_choices_hint_seen`. 로그아웃과 계정 전환에 유지 |
| 이미지 완료 횟수 | 기기 suite `chat_completed_turn_count`. 한 소유자가 읽고 1 늘려 쓰며 3에서 중단. 기기 suite를 열지 못하면 횟수를 모르는 것으로 봄 |
| 이미지 안내 예약과 표시 | Store의 `Task`와 상태. 영속 저장 없음. 백그라운드에 취소하지 않음 |
| 요청 설정 | 생성 단계에 전송 시점 이미지 설정 보관. 요청과 진행 블록이 같은 값 사용 |
| 모델과 긴 응답 | 서버 상세 기준, 기기 저장 없음 |
| 블럭별 초점 | 화면의 초점 상태. 상태 복구 보장에 포함하지 않음 |
| 로딩 높이와 읽던 위치 | 화면 상태에 측정 높이와 기준 항목 보관. 본문이 자랄 때까지 최소 높이 |

모델과 긴 응답 저장 실패는 그 사이 같은 필드를 다시 바꾸지 않았을 때만 이전 값으로 되돌린다. 기기 suite와 회원 suite의 구분과 저장 식별자 유지는 IOS 기반을 따른다. 공통 확정과 진행 상태의 경계를 적용한다. ([IOS 기반 로컬 저장](../../../../platform/CLIENT/IOS/2-STATE-MANAGEMENT.md#2-4-로컬-저장), [공통 4-3](../4-3-STATE-MANAGEMENT.md))
