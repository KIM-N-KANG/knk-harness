# 3-1 화면 구성: iOS

<br>

### 3-1-1 라우트와 화면 내부 상태

| 영역 | 위치 |
|---|---|
| 목록 | 채팅 탭 루트 |
| 채팅방 | 진입한 탭 스택의 라우트. 목록에서는 채팅 탭, 스토리 상세에서는 상세가 있는 탭. 탭 바 숨김 |
| 채팅방 헤더 | 채팅방이 대화 위에 겹쳐 그리는 헤더. 시스템 내비게이션 바 없음 |
| 메뉴와 설정, 모델 시트 | 현재 채팅방의 시스템 시트 |
| 재생성, 입력 수정, 포크와 삭제 확인 | 현재 채팅방의 시스템 알림창 |
| 입력 수정 편집기 | 고치는 턴의 사용자 입력 자리. 별도 라우트 없음 |
| 포크한 채팅방 | 같은 탭 스택에서 원래 채팅방 위의 라우트 |
| 메뉴의 이프 내역 | 메뉴 시트 안의 화면 전환. 별도 라우트 없음 |
| 투어 | 현재 채팅방 위 덮개 |
| 이미지 안내 | 설정 시트 내용 위 덮개 |
| 이미지 뷰어 | 탭 바와 헤더를 덮는 전체 화면 덮개. 라우트와 저장 상태에 넣지 않음 |
| 공유 전달 | iOS 시스템 공유 시트. 수신자는 웹 공유본 열람 |
| 피드백 | 마이 탭 스택의 라우트. 탭 바 숨김 |

하단 탭 표시 분류와 전체 화면 덮개의 범위는 공통 UI IOS를 따른다. 공통 정보 순서와 로그인 범위를 적용한다. ([공통 UI IOS 3-1-1](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-루트와-셸), [공통 3-1](../3-1-INFORMATION-ARCHITECTURE.md), [2-2](2-2-REQUIREMENTS.md))
