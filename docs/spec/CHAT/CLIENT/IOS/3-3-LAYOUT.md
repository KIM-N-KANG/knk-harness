# 3-3 화면 배치: iOS

<br>

### 3-3-1 채팅방과 목록

| 요소 | iOS 표현 |
|---|---|
| 채팅방 셸 | 탭 바 없음. 대화가 화면 끝까지 그려지고 헤더가 위에, 입력 영역이 아래에 붙음. 입력 영역은 홈 표시기 위, 키보드가 열리면 키보드 바로 위 |
| 헤더 | 대화 위에 겹친 화면 헤더. 왼쪽 뒤로 아이콘 버튼(접근성 이름 "뒤로"), 스토리 제목(bodyLargeStrong 한 줄, 넘치면 말줄임), 모델 버튼, 더보기 순. 200ms 페이드로 숨김과 표시. 헤더 실제 높이만큼 대화 위 여백 |
| 헤더와 안전 영역 | 헤더 바탕은 상태 바 영역까지 덮고 버튼과 제목은 안전 영역 안. 숨긴 헤더는 VoiceOver 탐색과 터치에서 제외 |
| 메시지 | 사용자 입력은 전체 폭 밴드(backgroundNeutral), AI 응답과 프롤로그는 배경 없는 본문. 좌우 gutter, 위아래 passage 간격 |
| 본문 글자 | 사용자 입력, AI 응답, 프롤로그와 응답 대기 문구는 bodyReading(MaruBuri)과 text 색. AI 생성 안내는 bodySmall, textSubtle, 가운데 정렬. 입력칸과 편집기는 bodyMedium |
| 큰 글자 | 본문은 Dynamic Type 전 단계로 커지고 줄 높이는 토큰 비율을 유지. 헤더 제목과 모델 이름만 한 줄 말줄임. 엔딩 배지, 블럭 라벨과 비용 숫자는 줄을 바꾸거나 자리를 넓힘. 입력 영역은 내용만큼 자라고 키보드 위 남은 높이를 넘으면 입력 영역 안에서 스크롤 |
| 아이콘 버튼 | 턴 아래 버튼과 입력 수정 버튼은 보이는 크기 32pt의 고스트 아이콘 버튼과 터치 영역 44pt. 작은 조작의 터치 영역끼리 겹치지 않음. 아이콘은 Asset Catalog의 원본 SVG(입력 수정 `pen-outline`, 포크 `split-stroke-rounded`) |
| 투어 | 채팅방 전체 위 덮개. 딤 tourScrim은 대상 버튼을 6pt 넓힌 control 모양으로 뚫고, 스텝이 바뀌면 구멍이 200ms로 다음 대상에 옮겨 감. 헤더와 상태 바 영역도 덮음 |
| 투어 카드 | surfaceRaised, control 모서리, 안쪽 16pt, 폭 288pt(좁으면 좌우 16pt를 남기고 줄어듦), 그림자 없음. 하이라이트 아래 12pt, 아래 공간이 모자라면 위. 가로는 하이라이트 중앙, 가장자리에서는 그쪽 변. 제목 bodyLargeStrong, 설명 bodyMedium과 textSubtle. 아래 줄에 6pt 스텝 점(현재 textSubtle, 나머지 border), 건너뛰기(작은 글자 버튼), 다음과 완료(작은 주 버튼), 사이 4pt. 스텝마다 200ms에 8pt 아래에서 올라옴 |
| 이미지 안내 | 설정 시트가 다 올라온 뒤 시트 내용 전체를 tourScrim으로 덮고 실시간 이미지 행만 control 모양으로 뚫음. 하이라이트는 시트 좌우에서 8pt 안쪽이고 행 내용도 같은 여백. 카드는 행 아래 12pt, 투어 카드와 같은 모양에 오른쪽 아래 작은 주 버튼 "확인". 공간보다 길면 카드 안에서 스크롤. 딤 550ms, 카드는 200ms 뒤 450ms로 등장, 퇴장 300ms |
| 작은 버튼 | 안내 카드와 실패 안내 아래 버튼. 보이는 최소 높이 controlSmall 32pt, 가로 12pt, labelSmall, menuItem 모서리, 터치 영역 44pt. 주 동작은 brand와 textInverse, 테두리형(선택지 실패의 다시 시도)은 surfaceRaised와 border 1pt, 글자형은 바탕 없는 text |
| 목록 카드 | 표지 폭 56pt, thumbnail 모서리. 글 영역은 표지 높이를 최소로 잡고 위아래 2pt, 제목과 미리보기는 위, 메타 줄(턴 수, 날짜)은 아래 끝이며 미리보기와 최소 8pt. 카드 목록 아래 여백 8pt. 큰 글자에서는 글 영역이 표지보다 길어져도 잘리지 않음. 골격도 같은 배치 |
| 목록 재정렬 | 새 활동순으로 카드가 이동. 동작 줄이기에서는 이동 없이 교체 |
| 응답 대기 | 공통 4:3 그림과 순환 문구. 첫 조각에 대기를 같은 자리의 본문으로 교체 |
| 턴 아래 버튼 행 | 다시 생성과 포크를 나란히. 왼쪽 12pt, 아래 20pt, 추천 위 12pt. 잠기면 아이콘을 비활성 색으로 |
| 입력 수정 버튼 | 사용자 입력 밴드 안 오른쪽 아래. 본문 아래 20pt, 밴드 아래 20pt, 오른쪽 12pt |
| 편집기 | 사용자 입력과 같은 밴드, 세로 20pt와 가로 16pt. 입력칸이 내용만큼 자람. 버튼 행 위 12pt, 버튼 사이 8pt. 취소는 글자형, 보내기는 주 동작 작은 버튼이며 잠기면 비활성 색 |
| 고치는 중 흐림 | 고치는 턴의 응답과 뒤의 턴, 추천 영역을 불투명도 40% |

공통 문구, 헤더 겹침과 이미지 대기 그림을 적용하고 색, 글자와 간격은 `ManyakTheme` 토큰을 쓴다. ([공통 3-3](../3-3-LAYOUT.md), [공통 UI IOS 글자와 아이콘](../../../../ui/IOS/3-3-LAYOUT.md#3-3-5-글자와-아이콘))

### 3-3-2 시트, 알림창과 뷰어

| 요소 | iOS 표현 |
|---|---|
| 채팅 응답과 채팅 설정 시트 | 시스템 시트. 높이 단계 하나로 내용에 맞춤. 주 동작이 없어 닫기 버튼 없음 |
| 확인 알림창 | 시스템 알림창. 머무르는 버튼은 취소 역할의 "닫기"이며 공통 문구의 "그대로 두기"와 "남겨두기"를 대신함. 삭제와 사라질 뒤 턴이 있는 입력 수정의 확정은 파괴 역할, 다시 생성, 마지막 턴 입력 수정과 포크는 기본 역할. 포크 확인의 확정 버튼은 "시작하기" |
| 삭제 중 | 알림창은 확정과 함께 닫힘. 채팅방은 화면 가운데 시스템 진행 표시(접근성 이름 "삭제 중")와 전체 조작 잠금, 목록은 해당 카드에 진행 표시와 카드 조작 잠금. 300ms 안에 끝나면 진행 표시 없음 |
| 메뉴 | 시스템 시트에 공통 순서의 항목. 진행 중 항목은 오른쪽 20pt 스피너와 탭 차단 |
| 메뉴 이프 카드 | 시트 위 보조 채움 바탕이라 다크에서도 시트와 구분. "내역"은 overlayPressed를 한 겹 더한 바탕과 기본 글자색. 강조색은 "충전"만, 두 버튼 간격 4pt. "충전"은 PAYMENT의 iOS 이프 충전 화면으로 이동 |
| 메뉴와 이프 내역 전환 | 시트를 닫지 않고 시트 높이를 메뉴 높이에서 화면 높이의 70%로 이어서 바꿈. 들어오는 화면은 24pt 가로 밀림과 페이드, 나가는 화면은 페이드. 동작 줄이기에서는 페이드만 |
| 이프 내역 화면 | 화면 높이의 70%. 머리글 고정, 목록만 스크롤. 목록을 끝까지 끌어도 시트는 닫히지 않음 |
| 이프 내역 머리글 | 돌아가기 아이콘과 "새로고침" 글자를 목록 행 양쪽 선에 맞춤. 열릴 때 초점을 옮기지 않음. 새로고침 중 문구 자리를 유지한 가운데 스피너와 잠금. 첫 조회 중에도 잠금 |
| 공유 시트 | 메뉴 시트가 닫힌 뒤 시스템 공유 시트에 발급한 웹 링크. 링크 앞 안내 문장은 미정 |
| 이미지 뷰어 | 공통 UI IOS의 전체 화면 뷰어. 상태 바 글자 밝게, 닫기 아이콘 버튼(접근성 이름 "닫기")은 안전 영역 안. 인물과 장면 이미지 같은 UI |
| 토스트 | 채팅의 실패, 저장 실패와 잠긴 입력 안내는 모두 짧은 표시 |

시트 높이, 알림창 역할, 뷰어 조작과 토스트 표시는 공통 UI IOS를 따른다. 이프 부족 시트와 충전 화면의 내용은 PAYMENT가 정한다. ([공통 UI IOS 시트와 덮개](../../../../ui/IOS/3-3-LAYOUT.md#3-3-3-시트-알림창과-덮개), [공통 UI IOS 화면 상태](../../../../ui/IOS/3-3-LAYOUT.md#3-3-4-공통-화면-상태), [PAYMENT iOS 표현](../../../PAYMENT/CLIENT/IOS/3-3-LAYOUT.md#3-3-1-공통-표현과-ios-요소))
