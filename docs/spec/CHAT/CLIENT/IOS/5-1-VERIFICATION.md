공유본 열람 CHAT-US-015는 웹 검증을 적용한다. iOS는 발급한 링크의 공유 시트 전달과 실제 웹 열람을 기기에서 확인한다. 단위 테스트는 서버 저장과 환불, 실제 백그라운드 전환, 키보드와 VoiceOver 결과를 대체하지 않는다. 시뮬레이터 결과를 실기기 통과로 표시하지 않으며 이 문서는 실행 결과가 아니다.

시나리오는 [공통 검증](../5-1-VERIFICATION.md)과 [iOS 요구사항](2-2-REQUIREMENTS.md)을 따른다.
