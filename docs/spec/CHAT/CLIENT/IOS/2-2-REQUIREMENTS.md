# 2-2 요구사항: iOS

<br>

### 2-2-1 화면과 수명

| 상황 | 결과 |
|---|---|
| 사용자 | 로그인 필수. 게스트 동의, 게스트 모델 안내와 로그인 전환 분기 비적용 |
| 채팅방 화면 | 진입한 탭 스택에 쌓이고 탭 바를 숨김. 뒤로가기는 가장자리 밀기와 헤더의 뒤로 버튼. 시스템 뒤로가기 비적용 |
| 공유 발급 | 발급한 웹 링크를 iOS 시스템 공유 시트로 전달. 복사 성공 토스트 없이 메뉴 닫기 |
| 목록 갱신 | 당겨 새로고침할 때 기존 목록 유지. 실패는 토스트. 첫 로딩, 빈 목록과 전체 오류에서는 당김 없음 |
| 헤더 | 빈 본문 탭으로만 전환. 텍스트 선택은 제공하지 않음. 버튼, 추천, 이미지와 키보드 닫기 탭 제외. 로딩과 실패, 투어 중에는 항상 표시 |
| 작성 버튼 | 상황과 대사 추가, 강조와 삭제 탭은 키보드와 초점 유지. 본문 빈 곳 탭은 키보드 닫기 |
| 입력칸 삭제 | 현재 칸 삭제 시 다음 칸, 없으면 이전 칸으로 초점 이동. 마지막 칸 삭제, 모드 교체와 전송 잠금은 편집 종료 |
| 키보드 | 입력 영역과 편집기는 키보드 위에 보임. 키보드가 열리고 닫혀도 읽던 줄 유지. 키보드의 줄바꿈은 줄바꿈이고 전송은 버튼으로만 |
| 글자 크기 | 본문, 입력과 안내는 Dynamic Type 전 단계로 커지고 잘리지 않음. 테마와 글자 크기 변경에 입력 잠금, 누적 응답, 읽던 위치, 투어 스텝, 이미지 안내와 시트 유지 |
| 앱 백그라운드 | 진행 중 수신을 끊음. 포그라운드 복귀 때 서버 상태로 확정과 진행 상태를 확인하고 진행 중이면 이어받음. 새 생성과 과금을 시작하지 않음 |
| 프로세스 종료 | 다음 실행은 선택 탭 루트에서 시작하고 채팅방을 다시 열지 않음. 방에 다시 들어오면 상세로 이어받기 판정 |
| 방 이탈 | 이미지 안내 예약과 표시 상태 복원 없음. 기기 기록으로 다시 안내하지 않음 |
| 안내 접근성 | 투어 뒤 본문과 이미지 안내의 나머지 설정 항목을 VoiceOver 탐색에서 제외 |
| 투어와 뒤로 조작 | 투어가 열린 동안 방을 떠나는 뒤로 조작 없음. 건너뛰기, 다음, 완료로만 종료 |
| 입력 수정 편집기 | 열리면 입력칸에 초점과 끝 커서. 보내기는 버튼으로만. 테마와 글자 크기 변경에 고치던 입력과 확인 창 유지 |
| 포크 | 로그인 필수라 게스트 로그인 안내 분기 비적용. 성공하면 원래 방 위에 새 방, 뒤로가기는 원래 방 |
| 피드백 | 마이 탭 스택의 하단 탭 없는 화면 |

공통 목록, 공유, 생성과 입력 수정 및 포크 요구를 적용한다. 화면 셸, 탭 바 숨김과 글자 크기 규칙은 공통 UI IOS를 따른다. ([공통 2-2](../2-2-REQUIREMENTS.md), [공통 UI IOS 요구사항](../../../../ui/IOS/2-2-REQUIREMENTS.md#2-2-1-화면과-기기))
