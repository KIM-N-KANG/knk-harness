# 6 배포: iOS

<br>

### 6-1 저장 호환

| 대상 | 규칙 |
|---|---|
| 제작 데이터베이스 첫 출시 | GRDB 마이그레이션 하나로 [현재 테이블 세 개](4-3-STATE-MANAGEMENT.md#4-3-2-제작-데이터베이스)를 만든다. Android Room 버전 1에서 6까지의 변환과 이전 형식 값은 옮기지 않는다 ([I-110](DECISIONS.md#i-110), [I-112](DECISIONS.md#i-112)) |
| 이후 스키마 변경 | 등록한 마이그레이션은 고치지 않고 새 마이그레이션을 뒤에 더한다. 열 추가는 기존 행이 의미를 잃지 않는 기본값이나 null로 한다. 스키마가 바뀌면 데이터베이스를 지우는 개발용 동작을 켜지 않는다 |
| JSON 열 | 새 필드는 기본값과 함께 더하고 모르는 키는 무시해 이전 앱이 쓴 행을 다음 앱이 읽는다. 해석하지 못한 행은 지우지 않는다 |
| 서버 초안 | schemaVersion 1과 웹, Android, iOS payload 호환. 다른 mode 또는 버전은 불러오기 실패 |
| 제작 이미지 | 임시 파일만 두므로 출시 사이에 옮길 파일이 없다 |

마이그레이션은 이전 출시 빌드가 만든 데이터베이스를 새 빌드로 여는 검증으로 확인한다. 실행 환경과 결과는 PR에 남긴다.
