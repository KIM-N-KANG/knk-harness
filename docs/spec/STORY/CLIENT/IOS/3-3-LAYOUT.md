# 3-3 화면 배치: iOS

기준: [공통 표현](../3-3-LAYOUT.md), [iOS 흐름](3-2-INTERACTION-FLOWS.md).

막대, 시트, 알림창, 눌림, 터치 영역과 토스트의 공용 규칙은 [공통 UI iOS 배치](../../../../ui/IOS/3-3-LAYOUT.md)를 따른다. 이 세트의 토스트는 모두 짧은 표시다.

<br>

### 3-3-1 목록과 상세

| 요소 | 표현 |
|---|---|
| 홈 섹션 | 탭 루트 헤더 아래에서 시작해 섹션 사이 32pt. 이름은 titleLarge 한 줄 말줄임, 카드 줄과 12pt. 이름 줄에 넘기는 버튼을 두지 않고 손으로 끌어 넘기며 스냅과 가장자리 페이드는 없다. 카드 줄은 좌우 gutter 16pt, 카드 사이 8pt이고 카드 폭은 줄 폭에서 40pt를 뺀 값의 절반이라 처음 화면에 두 장과 셋째 카드의 앞 8pt가 보인다. 끝까지 넘기면 마지막 카드 오른쪽에 16pt가 남는다. 골격은 섹션 2개와 실제 줄과 같은 배치의 카드 3장 |
| 홈 카드 | 표지 아래 제목 bodyLargeStrong 한 줄, 2pt 아래 소개 bodyMedium과 textSubtle 두 줄 자리 고정, 8pt 아래 최소 높이 20pt Compact 장르 뱃지 한 줄(넘치면 +N). 글자는 표지 가장자리에서 좌우 4pt 안쪽이며 제목과 소개는 글자 단위로 줄을 바꾼다. 표지 위에는 왼쪽 위 ORIGINAL 태그와 오른쪽 아래 턴 수 Compact 뱃지만 둔다. 골격은 표지, 제목 줄, 소개 줄 자리 |
| 홈 맨 아래 | 마지막 섹션 끝에서 48pt 아래 구분선 밑에 사업자 정보와 문서 링크. 첫 로딩 골격, 빈 상태와 오류 상태에서는 안내 아래 화면 끝에 같은 푸터 ([ACCOUNT iOS 사업자 정보](../../../ACCOUNT/CLIENT/IOS/3-3-LAYOUT.md#3-3-1-공통-화면의-ios-표현)) |
| 탐색 그리드 | 화면 좌우 끝까지 두 열, 타일 사이 2pt. 타일은 위에 각진 3:4 표지와 폭 72pt ORIGINAL 태그, 아래에 검은 글 영역. 표지 아래 절반은 검정에서 위로 감속 곡선을 따라 옅어지는 덮개로 글 영역과 잇는다. 글 영역은 표지 아래 24pt에 겹쳐 올라가고 좌우와 아래 12pt 안쪽에 textOnImage 제목 bodyMediumStrong 한 줄, 2pt 아래 textOnImageSubtle 소개 bodySmall 두 줄, 6pt 아래 최소 높이 18pt Tiny 장르 뱃지(backgroundOnImage 바탕, 넘치면 +N) 한 줄. 소개와 장르가 비어도 자리를 지켜 모든 타일 높이가 같다. VoiceOver는 타일 하나를 제목과 오리지널 표시로 읽는다 |
| 탐색 골격 | 표지와 글 영역을 border 한 면으로 채운 타일 높이의 칸 12장. 면 아래쪽 글 자리에 제목, 소개 두 줄, 장르 막대를 borderStrong으로 두고 면과 막대가 함께 맥동한다. 다음 페이지 조회 중에는 스피너 대신 목록 끝에 같은 칸 4개를 잇고 마지막 줄이 한 칸만 차 있으면 5개로 빈 칸부터 채운다. VoiceOver는 첫 골격 칸 하나만 “스토리 불러오는 중”으로 읽고 나머지 칸은 탐색 대상에서 뺀다 |
| 탐색 새로 섞기 | 칸 순번으로 자리를 지키고 칸 안에서 새 표지를 그림을 받은 뒤 불투명도 0, 크기 96%에서 420ms로 겹친다. 두 열 기준 대각선 한 칸마다 45ms, 최대 450ms 늦추고 이전 표지는 새 표지가 다 나타난 뒤 걷는다. 동작 줄이기에서는 지연과 크기 변화 없이 바로 바꾼다 |
| 탐색 검색 버튼 | 탐색 루트 내비게이션 바 오른쪽 항목에서 알림 버튼 바로 왼쪽. 24pt 돋보기 아이콘 버튼이며 간격은 시스템 막대 배치를 따른다 |
| 스토리 검색 | 내비게이션 바의 시스템 뒤로 버튼 오른쪽에 최소 높이 40pt 입력. 입력 왼쪽에 16pt 돋보기, 글자가 있으면 오른쪽 끝에 16pt x의 지우기 버튼. 키보드 입력 키는 검색. 검색 전 구역은 좌우 gutter 16pt, 위 8pt, 아래 16pt, 구역 사이 32pt. 구역 제목 titleMediumStrong, 제목과 칩 사이 8pt. 전체 삭제는 labelSmall과 textSubtle 글자 버튼이고 글자 끝을 오른쪽 여백에 맞춘다. 칩은 최소 높이 40pt, bodyMedium, backgroundNeutral 알약, 사이 8pt. 최근 검색어 칩은 왼쪽 14pt 안쪽, 글자 최대 폭 192pt, 오른쪽 14pt x의 삭제 버튼. 대표 장르 칩은 좌우 14pt. 결과는 탐색 그리드와 같은 타일, 골격, 다음 페이지 골격과 재시도 |
| 제작 구역 | 구역 제목 titleMediumStrong과 6pt 옆 개수 labelLarge, textSubtle을 세로 가운데로 맞춘다. 좌우 gutter 16pt, 위 8pt(내 스토리가 진행 중 뒤에 오면 24pt), 아래 4pt |
| 표지 뱃지 | 턴 수, 좋아요와 공개 범위 뱃지는 Compact 알약이고 바탕은 뒤 표지를 흐리는 시스템 재질 위에 색을 덮는다. 공개 범위는 표지 왼쪽 위 8pt, 공개는 흰 90% 바탕, 검은 글자와 지구본, 비공개는 흐린 어두운 바탕, 흰 글자와 자물쇠 |
| 제작 카드 | 표지 폭 128pt. 글 영역은 표지 높이를 최소로 잡고 위아래 4pt, 메타 줄에는 제작일만. 좋아요 수와 턴 수는 표지 오른쪽 아래 뱃지이고 한 줄에 들지 않으면 뱃지 단위로 줄을 바꾼다. 골격도 같은 배치 |
| 검수 제출본 카드 | 제작 카드와 같은 표지 폭과 card 모서리, 제목 bodyLargeStrong, 설명 bodyMedium, KST 날짜 칩. 상태 뱃지는 bodySmall 알약, 가로 8pt, 세로 2pt. 검토 중은 backgroundNeutral과 textSubtle, 반려와 실패는 backgroundDangerSubtle과 textDanger |
| 완성 중 카드 | 마스코트 표지와 제목 시머, “스토리가 완성되면 알림으로 알려드려요”. iOS는 푸시를 첫 출시의 선행 조건으로 두므로 문구를 그대로 씀 ([NOTIFICATION iOS 호환과 출시 조건](../../../NOTIFICATION/CLIENT/IOS/6-DEPLOYMENT.md#6-2-호환과-출시-조건)) |
| 제작 진입 버튼 | 탭 바 위 오른쪽 아래의 brand 알약 FAB. 아이콘과 라벨 textInverse, 라벨 labelLarge. 목록 맨 위에서만 라벨을 펼치고 내리면 아이콘만 남으며 접근 가능한 이름은 라벨과 같다. 그림자 없음 |
| 상세 헤더 | 시스템 내비게이션 바. 히어로를 지나는 동안 막대 바탕을 투명에서 surface로 연속 전환하고 이미지가 있으면 버튼 색을 textOnImage에서 text로 함께 바꾼다. 본문 제목이 막대 아래로 가려지면 같은 제목을 페이드로 표시한다. 표지가 없거나 로딩과 오류이면 처음부터 surface와 text ([I-117](DECISIONS.md#i-117)) |
| 상세 구획 | 주요 내용, 채팅 시작 상황, 주변 인물 사이 32pt, 끝의 메타 블록은 바로 위 구획과 16pt. 시작 상황의 “상황 이름”과 “엔딩” 제목 옆에 같은 정보 툴팁 버튼 |
| 주변 인물 줄 | 인물이 둘 이상이면 제목 아래 4:3 썸네일 줄을 화면 끝까지 가로 스크롤로 두고 세 장 반이 보이는 폭으로 잡는다. 간격 8pt, thumbnail 모서리, border 1pt, 잘라 채움. 고른 썸네일은 바깥 2pt text 테두리, 나머지는 불투명도 50%이고 두 변화가 150ms 동안 함께 바뀐다. 선택 표시가 반응이라 눌림 덮개가 없다. 남은 쪽 가장자리 40pt는 투명하게 지우고 고른 썸네일을 좌우 16pt 경계 안에서 줄 가운데로 스크롤한다. 줄과 카드 사이 6pt |
| 주변 인물 카드 | overlay 모서리, border 1pt, surfaceRaised. 위는 원본 전체를 담은 4:3 인물 이미지이고 누르면 전체 화면 뷰어. 구분선 아래 좌우 16pt, 위아래 14pt에 이름 bodyLargeStrong과 4pt 아래 소개 bodyMedium(어절 단위 줄바꿈). 카드를 좌우로 밀어도 옆 인물로 넘어간다. 이미지 좌우 가운데에 표지 뱃지와 같은 바탕의 32pt 원형 이전, 다음 버튼을 두고 누름 영역은 이미지 좌우 끝에서 폭 48pt, 이미지 높이 전체의 세로 띠로 넓힌다. 원은 띠 안에서 좌우 8pt, 세로 가운데. 띠 위에서는 확대 대신 인물을 넘기고 첫 인물과 마지막 인물에서는 해당 방향 버튼을 숨긴다. 이미지가 없거나 불러오지 못하면 기본 심벌로 카드 높이를 유지한다 |
| 상세 하단 | “새 채팅 시작하기” 주 버튼과 왼쪽 16pt 좋아요 버튼을 홈 표시기 위에 고정. 메타 정보가 보이기 시작하면 버튼 뒤 바탕과 페이드를 surface에서 backgroundNeutral로 바꾸고 끝에서는 메타와 같은 색, 위로 스크롤하면 원래 색. 진행률을 200ms로 따라간다. 메타 정보가 없는 상세는 surface 유지 |
| 채팅 시작 시트 | 제목 titleLarge와 8pt 아래 설명 bodyLarge, textSubtle. 24pt 아래 control 모서리의 backgroundNeutralRaised 카드 하나에 페르소나 행과 시작 상황 행을 surfaceRaised 1pt 선으로 나눈다. 행은 16pt 여백에 라벨 bodyMedium과 textSubtle, 4pt 아래 값 bodyLargeStrong, 시작 상황은 상황 설명 두 줄, 오른쪽 20pt 꺾쇠. 한 번에 한 행만 펼치며 누르면 값이 접히고 선택지 목록이 스프링으로 펼쳐지고 꺾쇠가 돈다. 펼침이 반응이라 행에 눌림 덮개가 없다. 선택지는 menuItem 모서리, 가로 8pt, 세로 12pt, bodyLarge, 최소 높이 48pt, 사이 4pt이고 고른 항목은 overlayPressed 채움과 체크. 다섯 줄 반을 넘으면 목록 안에서 스크롤하고 열 때 고른 항목 위 두 칸부터 보인다. 페르소나 목록 아래에는 글자 시작선에 맞춘 구분선과 textSubtle 더하기 아이콘의 “페르소나 생성하기”를 스크롤 밖에 고정한다. 시작 상황이 하나면 꺾쇠 없이 펼치지 않는다. 카드 아래 24pt에 전체 폭 주 버튼 “채팅 시작하기”, 생성 중에는 라벨 자리를 유지한 스피너와 시트 잠금 |
| 상세 셀렉트 메뉴 | 항목 최소 높이 44pt, 값 항목은 다섯 줄 반을 넘으면 메뉴 안에서 스크롤. “페르소나 생성하기”는 구분선 아래 textSubtle로 스크롤 밖에 고정 |
| 표지 없음 | 기본 심벌, backgroundNeutral과 textDisabled |
| 카드 옵션 | 대상 종류와 제목, 항목 목록. 카드 축소판을 넣지 않는다 |
| 초안 조회 | 헤더 아래 늦게 나타나는 가운데 스피너, 실패는 같은 자리의 안내와 재시도 |

### 3-3-2 가입 온보딩

| 영역 | 표현 |
|---|---|
| 화면 | 헤더와 탭 바 없이 상태 바 아래 안전 영역에서 시작하고 하단 버튼은 홈 표시기 위 |
| 헤드라인 | “마음에 드는 스토리를 골라 / 바로 채팅을 시작해보세요”, headlineSmall |
| 제작 | textSubtle 질문 “마음에 드는 스토리가 없나요?” 옆 textBrand 글자 버튼 “직접 만들기”(아이콘 없음)로 주 동작보다 낮춘다 |
| 캐러셀 | 가운데 카드와 양옆 일부. 카드는 화면 폭의 76%(최대 360pt)와 남은 높이에 들어가는 3:4 중 작은 쪽이고 카드 사이 12pt. 남은 높이는 글자 크기를 따라 커지는 글자 영역 높이를 뺀 값이다. 옆 카드는 가운데에서 멀어진 만큼 88%로 줄고 불투명도 40%로 내려가며 축소 기준점을 가운데 쪽 변에 둬 넘기는 동안 간격이 그대로다 |
| 카드 | 위 표지, 구분선 아래 한 줄 제목과 “상세 보기”, 소개 최대 두 줄. surfaceRaised, border 1pt, featureCard 모서리. 표지는 각지게 두고 카드가 깎으며 표지 위에는 아무것도 얹지 않는다. 글자 영역은 좌우 16pt, 위아래 14pt. 제목 bodyLargeStrong과 text, 오른쪽 “상세 보기” labelSmall과 12pt 꺾쇠, textSubtlest. 4pt 아래 소개 bodyMedium과 textSubtle은 두 줄 자리 고정 |
| 카드 그림자 | 흰 글자 영역이 같은 밝기의 바탕에 묻히지 않게 두는 그림자 예외. 넓게 퍼지고 옅어 윤곽 없이 카드 아래만 살짝 가라앉게 하며 옆 카드를 흐리는 처리가 그림자를 자르지 않는다. 바깥 선택 테두리는 없다 |
| 하단 | “채팅 시작하기” 한 줄 주 버튼, 최소 높이 48pt. 생성 중에는 라벨 자리를 유지한 스피너 |
| 로딩 | 같은 자리의 카드 골격 세 장. 상태가 바뀔 때 300ms 교차 페이드 |
| 실패 | “스토리를 불러오지 못했어요”와 “다시 시도” |
| 빈 목록 | “지금은 보여드릴 스토리가 없어요”. 직접 만들기는 계속 제공 |
| 낮은 화면 | 쓸 수 있는 높이가 600pt 미만이면 캐러셀 높이를 420pt로 고정하고 화면을 세로 스크롤 |

### 3-3-3 제작 안내

| 요소 | 표현 |
|---|---|
| 창 | tourScrim 딤이 탭 바를 포함한 화면 전체를 덮고 그 위 세로 가운데에 좌우 12pt만 남긴 폭의 카드. 모서리 20pt, surface 배경, 안쪽 16pt. 다크 모드에만 border 1pt 경계 |
| 프로필 | 48pt 원, backgroundBrandSubtle 위 brand 마스코트. 몸은 프로필 폭의 66% |
| 이름과 대사 | 프로필 옆 12pt. “마냑”은 labelLarge와 textBrand, 4pt 아래 대사는 bodyLarge |
| 버튼 | 대사 아래 16pt의 오른쪽 정렬, 간격 4pt. 보이는 높이 40pt, 보조는 text 색 글자 버튼, 주 버튼은 brand 채움 |
| 모션 | 카드가 250ms 동안 0.95배에서 커지며 나타난다. 단계가 바뀌면 카드와 딤을 유지한 채 문구만 200ms 교차 페이드. 마스코트는 5초 동안 두 번 말하고 쉬며 몸을 프로필 폭 3.5%까지 띄우고 좌우 3도 기울인다. 동작 줄이기에서는 서 있는 첫 자세로 멈추고 카드와 문구는 페이드만 쓴다 |
| VoiceOver | 열리면 초점이 대화창 안으로 들어가고 아래 화면과 탭 바는 탐색 대상에서 빠진다 |

### 3-3-4 제작 퍼널

퍼널, 일반 제작, 재제출과 수정은 탭 바를 숨긴 화면이다. 밑줄 탭, 칩, 텍스트 필드와 버튼은 공용 컴포넌트를 쓴다.

| 요소 | 표현 |
|---|---|
| 헤더 | 시스템 내비게이션 바에 뒤로 버튼 없이 가운데 제목 bodyLargeStrong, 오른쪽 임시 저장과 닫기. 수정은 닫기만 |
| 단계 표시 | 헤더 아래 높이 3pt 막대 분절, 양끝 알약, 분절 사이 12pt, 좌우 gutter 16pt. 완료 textDisabled, 현재 stepIndicatorActive, 미도달 border이며 brand를 쓰지 않는다. 보이는 단계 이름 없이 막대 묶음을 한 VoiceOver 요소로 두고 현재 단계 이름과 순서를 읽힌다 |
| 하단 버튼 | 주 버튼(다음, 스토리라인 만들기)과 보조 버튼(이전, 다시 만들기)이 같은 폭으로 하단을 나눈다. 홈 표시기 위에 두고 키보드가 열린 동안 숨긴다 |
| 키워드 칩 | 제공 태그와 직접 입력 태그는 surfaceRaised 바탕과 border, 선택은 backgroundBrandSubtle, borderBrand, textBrand. 최소 높이 40pt, control 모서리, 선택 변화가 반응이라 눌림 덮개 없음. 상한에 도달하면 미선택 칩과 추가 버튼을 textDisabled로 내린다 |
| 추가 버튼 | “키워드 추가”, “인물 추가”, “정보 추가”는 키워드 칩 모양에 backgroundNeutral 채움, border와 16pt `+` 아이콘. 인물 추가와 정보 추가는 폭을 채우지 않고 가운데 |
| 카테고리 탭 | 밑줄 탭에 잠금 textDisabled, 필수 표시 `*` textDanger. 스크롤 시 탭만 상단에 고정하고 각 카테고리 내용은 탭 아래에서 시작 |
| 주변 인물 머리 줄 | 접기와 삭제 버튼은 보이는 높이 32pt와 labelSmall, 접기 화살표 12pt. 입력 영역은 위 변을 붙잡은 높이와 투명도로 여닫고 화살표 회전과 인물 추가 위 간격도 함께 움직인다. 튕김 없는 약 0.3초 스프링. 접힌 항목 다음에는 목록 간격이 없다. 주변 인물이 0명이면 인물 추가 버튼 위에 랜덤 생성 안내 |
| 스토리라인 대기 | 문구는 4초마다 글자별 25ms 시차로 교차하고 전체 문구 위에 4초 시머가 지나간다. 앞의 점 3개는 1초 주기로 160ms씩 늦게 떠올랐다 내려온다. 이전과 다음 문구를 겹쳐 그려 글자 폭 차이로 흔들리지 않는다. 문구 3종과 15초, 30초 지연 힌트. 동작 줄이기에서는 시머와 점 움직임 없이 문구만 페이드 |
| 스토리라인 단계 | 순번 탭은 카테고리 탭과 같고 잠금과 필수 표시가 없다. 본문은 bodyReading, `**…**`는 굵게, 단일 `*…*`는 textNarration. 평가 버튼(좋아요, 별로예요)은 보이는 크기 40pt 정사각 칩에 16pt 아이콘, 키워드 칩과 같은 선택 문법이며 별로예요 활성은 backgroundDangerSubtle, borderDanger, textDanger. 하단은 다시 만들기와 선택하기. 선택한 키워드 보기는 시트 |
| 추가 정보 단계 | 선택한 스토리라인은 backgroundNeutral 상자에 bodyReading, 기본 한 줄 말줄임과 가운데 더보기, 접기(textSubtle과 16pt 꺾쇠). 추천은 키워드 칩 문법의 여러 줄 칩을 폭을 채워 세로로 나열. 자유 입력은 여러 줄 텍스트 필드와 오른쪽 아래 글자 수, 행 오른쪽 삭제는 textSubtle 아이콘 버튼. 섹션 사이 24pt, 제목과 내용 사이 8pt. 하단은 다시 선택하기와 스토리 완성하기 |
| 이미지 스타일 | 서버 순서의 3열 그리드, 칸 사이 8pt. 칸은 border 1pt, card 모서리의 3:4 표지(미리보기가 없으면 기본 심벌)이고 아래 가운데에 표지 뱃지와 같은 바탕의 알약에 이름 labelSmall, textInverse. 고른 칸은 바깥 2pt borderBrand 테두리를 150ms 동안 채우고 나머지를 흐리지 않으며 눌림 덮개 없음. 칸마다 화풍 이름과 선택 상태를 가진 한 VoiceOver 요소. 받는 동안 골격 칸 여섯 개, 실패하면 가운데 textSubtle 안내와 재시도. 고르지 않고 완성을 누르면 비용 행과 주 버튼 사이에 textDanger 안내 |
| 장르 검색 | 장르 칩 위 입력은 텍스트 필드의 표면, 모서리, 글꼴, 포커스 경계에 왼쪽 돋보기와 오른쪽 펼침 아이콘(16pt, textSubtle). 메뉴는 입력 폭으로 아래에 열려 키보드 위 남은 공간 안에서 스크롤하고 control 모서리, surfaceRaised, border 1pt, selectMenuElevation 그림자. 항목 높이 40pt와 사이 4pt이며 터치 영역은 사이 간격까지 넓힌다. 최대 높이 240pt. 선택은 체크, 3개면 새 선택만 비활성. 로딩 문구는 요청이 200ms 이상 걸릴 때만 보이고 결과가 아직 없으면 입력 높이의 빈 공간을 유지한다 |
| 분량 배분 | 묘사 N, 대사 M 값은 고정폭 숫자로 그려 슬라이더를 움직여도 글자 폭이 흔들리지 않는다. 이 세트에서 고정폭 숫자를 쓰는 자리는 여기뿐이다 |
| 이미지 자르기 | 전체 화면 덮개의 검은 판 위 고정 비율 창(표지 3:4, 인물 4:3), 창 밖은 어둡게. 이동과 핀치 확대로 맞추고 창 밖으로 이미지가 비지 않게 범위를 제한한다 |
