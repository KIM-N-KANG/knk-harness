# 3-1 화면 구성: iOS

기준: [공통 화면](../3-1-INFORMATION-ARCHITECTURE.md), [iOS 요구사항](2-2-REQUIREMENTS.md).

<br>

### 3-1-1 목적지

화면은 진입한 탭의 NavigationStack에 쌓고 탭 바 표시는 [공통 UI iOS 규칙](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-루트와-셸)를 따른다. 외부 진입의 탭과 스택은 [진입 목적지](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-2-진입-목적지)가 정한다.

| 목적지 | 위치와 구조 |
|---|---|
| 홈, 제작과 탐색 | 각 탭의 루트. 제작 FAB에서 방식 선택 |
| 상세 | 진입한 탭의 스택. 그 위에 페르소나 생성, 채팅방과 수정을 같은 스택에 쌓음 |
| 스토리 검색 | 탐색 탭 스택. 결과 타일의 상세도 같은 스택 |
| 방식 선택 | 제작 탭 스택. 간편 제작과 일반 제작으로 이어짐 |
| 간편 제작 | 키워드, 스토리라인, 추가 정보 각각의 라우트. 같은 초안 ID 공유 |
| 일반 제작 | 새 초안 또는 이어서 만들기. 첫 프로필 탭에서 시작하는 라우트 하나 |
| 재제출 | 제작 탭 스택. 제출본 ID로 입력과 사유 조회 |
| 수정 | 상세 옵션 또는 제작 카드 옵션을 연 탭의 스택. 소유 스토리 ID로 편집 폼 조회 |
| 이미지 뷰어, 이미지 자르기 | 탭 바와 내비게이션 바를 덮는 전체 화면 덮개. 라우트 없음. 뷰어는 [공통 UI iOS 화면 구성](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md), 자르기는 [I-115](DECISIONS.md#i-115) |
| 가입 온보딩 | 회원 루트에서 메인 셸 대신 표시. 상세를 쌓는 자체 스택을 가지며 탭 바, 뒤로 조작과 건너뛰기 없음 ([I-119](DECISIONS.md#i-119)) |
| 제작 안내 | 간편 제작 세 화면과 제작 탭 위에서 앱 화면 전체를 덮는 대화창. 별도 라우트 없음 |

초안의 재개 경로와 새로운 제작을 구분한다. 새 제작의 진입은 제작 FAB이며 카드 이어서 만들기는 새 제작 상한으로 막지 않는다.
