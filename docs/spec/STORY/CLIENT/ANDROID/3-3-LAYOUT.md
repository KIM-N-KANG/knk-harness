### 3-3-1 목록과 제작

| 요소 | 표현 |
|---|---|
| 홈 섹션 | 셸 여백 바로 아래에서 시작해 섹션 사이 32dp, 마지막 섹션 아래에는 여백 없이 사업자 정보 푸터가 붙는다. 이름은 titleLarge 한 줄 말줄임, 카드 줄과 12dp. 이름 줄에 넘기는 버튼은 두지 않고 손으로 끌어 넘기며 스냅과 가장자리 페이드는 없다([A-102](DECISIONS.md#a-102)). 카드 줄은 좌우 여백 16dp, 카드 사이 8dp이고 카드 폭은 (줄 폭 − 40dp) ÷ 2라 처음 화면에 두 장과 셋째 카드의 앞 8dp가 보인다. 카드 시작점이 왼쪽 여백에 맞은 자리에서는 앞뒤 카드가 양옆에 8dp씩 보이고, 끝까지 넘기면 마지막 카드 오른쪽에 여백 16dp가 남는다. 골격은 섹션 2개와 실제 줄과 같은 배치의 카드 3장 |
| 홈 카드 | 표지 아래 제목 bodyLargeStrong 한 줄, 2dp 아래 소개 bodyMedium과 textSubtle 두 줄 자리 고정(minLines), 8dp 아래 웹과 같은 높이 20dp의 Compact 장르 뱃지 한 줄(넘치면 +N). 글자는 표지 가장자리에서 좌우 4dp 안쪽이고 작성자는 없다. 제목과 소개는 LineBreak.Simple로 글자 단위로 끊는다. 표지 위에는 왼쪽 위 ORIGINAL 태그와 오른쪽 아래 턴 수 Compact 뱃지만 둔다. 골격은 표지, 제목 줄, 소개 줄 자리 |
| 홈 맨 아래 | 마지막 섹션 끝에서 48dp 아래 구분선 밑에 마이와 같은 사업자 정보와 문서 링크. 목록 아래 여백은 두지 않는다. 표현은 [ACCOUNT Android 표현](../../../ACCOUNT/CLIENT/ANDROID/3-3-LAYOUT.md#3-3-1-공통-화면의-android-표현) |
| 탐색 그리드 | 셸 여백 밖 여백 없이 두 열, 타일 사이 2dp([A-091](DECISIONS.md#a-091)). 타일은 위에 각진 3:4 표지와 폭 72dp ORIGINAL 태그, 아래에 검은 글 영역을 둔다. 표지 아래 절반은 검정에서 위로 감속 곡선 13단계로 옅어지는 덮개로 글 영역과 잇는다. 글 영역은 표지 아래 24dp에 겹쳐 올라가고, 좌우와 아래 12dp 안쪽에 흰 제목 bodyMediumStrong 한 줄, 2dp 아래 흰 80% 소개 bodySmall 두 줄, 6dp 아래 높이 18dp Tiny 장르 뱃지(흰 15% 바탕, 넘치면 +N) 한 줄. 소개와 장르는 비어도 자리를 지켜 모든 타일 높이가 같다. 턴 수와 작성자는 없다. 골격은 표지와 글 영역을 border 한 면으로 채운 같은 높이의 칸 12장이고, 면 아래쪽 글 자리에 제목, 소개 두 줄, 장르 막대를 borderStrong으로 둔다. 투명도는 면에만 걸어 면과 막대가 함께 맥동한다. 다음 페이지 조회 중에는 스피너 대신 목록 끝에 같은 골격 칸 4개를 잇고, 마지막 줄이 한 칸만 차 있으면 5개로 빈 칸부터 채운다. 낭독기는 첫 골격 칸 하나만 “스토리 불러오는 중”으로 읽고, 그 칸은 live region으로 표시한다. 화면 읽기는 타일 하나를 제목과 오리지널 표시로 읽는다 |
| 탐색 새로 섞기 | 칸 순번으로 자리를 지키고 칸 안에서 새 표지를 그림을 받은 뒤 불투명도 0, 크기 96%에서 420ms로 겹친다. 두 열 기준 대각선 한 칸마다 45ms, 최대 450ms 늦추고 이전 표지는 새 표지가 다 나타난 뒤 걷는다. 시스템 애니메이션 배율이 0이면 지연 없이 바로 바뀐다 |
| 탐색 검색 버튼 | 탐색 헤더 오른쪽 알림 버튼 바로 왼쪽의 48dp 아이콘 버튼과 24dp 돋보기. 두 버튼 사이에 따로 간격을 두지 않는다 |
| 스토리 검색 | 하단 탭 없이 헤더에 뒤로가기와 높이 40dp 입력(오른쪽 16dp 여백). 입력 왼쪽에 16dp 돋보기, 글자가 있으면 오른쪽 끝에 20dp 지우기 버튼과 16dp x. 키보드 입력 키는 검색. 검색 전 구역은 좌우 16dp, 위 8dp, 아래 16dp, 구역 사이 32dp. 구역 제목은 titleMediumStrong, 제목과 칩 사이 8dp. 전체 삭제는 높이 32dp 글자 버튼(labelSmall, textSubtle)이고 글자 끝을 오른쪽 여백에 맞춘다. 칩은 높이 40dp, bodyMedium, backgroundNeutral 알약, 사이 8dp. 최근 검색어 칩은 왼쪽 14dp 안쪽과 최대 글자 폭 192dp, 오른쪽 40dp 삭제 버튼과 14dp x. 대표 장르 칩은 좌우 14dp. 결과는 탐색 그리드와 같은 타일, 골격, 다음 페이지 골격과 재시도 |
| 제작 구역 | 구역 제목 titleMediumStrong(18sp, 검색 화면 구역 제목과 같음)과 6dp 옆 개수 labelLarge와 textSubtle을 세로 가운데로 맞추고(기준선에 맞추면 개수가 내려앉아 보임), 좌우 16dp, 위 8dp(내 스토리가 진행 중 뒤에 오면 24dp), 아래 4dp. 카드가 없는 구역은 제목도 두지 않는다. 공개 범위 뱃지는 표지 왼쪽 위 8dp의 Compact 알약이고 공개는 흰 90% 바탕, 검은 글자와 지구본, 비공개는 흐린 어두운 바탕, 흰 글자와 자물쇠 |
| 제작 카드 | 표지 폭 128dp. 글 영역은 표지 높이를 최소로 잡고 위아래 4dp, 메타 줄에는 제작일만. 좋아요 수와 턴 수는 표지 오른쪽 아래 Compact 뱃지이고 한 줄에 들지 않으면 뱃지 단위로 줄을 바꾼다. 골격도 같은 배치 |
| 검수 제출본 카드 | 제작 카드와 같은 표지 폭과 card 모서리, 제목 bodyLargeStrong, 설명 bodyMedium, KST 날짜 칩. 상태 뱃지는 알약 bodySmall, 가로 8dp, 세로 2dp. 검토 중은 backgroundNeutral과 textSubtle, 반려와 실패는 backgroundDangerSubtle과 textDanger |
| 제작 진입 버튼 | 제작 탭 오른쪽 아래 brand 알약 확장 FAB, 아이콘과 라벨 textInverse, 라벨 labelLarge. 목록 맨 위에서만 라벨을 펼치고 내리면 아이콘만 남는다. 고도 0 |
| 상세 구획 | 주요 내용, 채팅 시작 상황, 주변 인물 사이 32dp, 끝의 메타 블록은 바로 위 구획과 16dp. 메타 블록 위 간격은 블록 밖 별도 항목이라 하단 배경 전환이 회색 블록이 보일 때 시작한다. 시작 상황의 “상황 이름”과 “엔딩” 제목 옆에 같은 정보 툴팁 버튼 |
| 주변 인물 줄 | 인물이 둘 이상이면 제목 아래 4:3 썸네일 줄을 화면 끝까지 가로 스크롤로 두고 세 장 반이 보이는 폭으로 잡는다. 간격 8dp, thumbnail 모서리, border 1dp, 잘라 채움. 고른 썸네일은 바깥 2dp text 테두리, 나머지는 불투명도 50%이고 두 변화가 150ms 동안 함께 바뀐다(테두리는 이미지 투명도와 분리). 눌림 리플 없음. 남은 쪽 가장자리 40dp는 투명하게 지우고 고른 썸네일을 줄 가운데로 스크롤한다. 줄과 카드 사이는 테두리 여백을 빼고 6dp |
| 주변 인물 카드 | overlay 모서리, border 1dp, surfaceRaised. 위는 4:3 인물 이미지(원본 전체, 누르면 전체 화면 뷰어), 구분선 아래 좌우 16dp, 위아래 14dp에 이름 bodyLargeStrong과 4dp 아래 소개 bodyMedium(어절 단위 줄바꿈). 카드를 좌우로 밀어도 옆 인물로 넘어가며 밑줄 탭 밀기와 같은 감각이다. 이미지 좌우 가운데의 이전, 다음 버튼은 표지 뱃지와 같은 흐린 바탕이고 첫 인물과 마지막 인물에서는 해당 방향 버튼을 숨긴다. 이미지가 없거나 불러오지 못하면 표지 없음과 같은 기본 심벌을 남겨 카드 높이를 유지한다 |
| 인물 카드 화살표 | 보이는 원은 32dp 그대로 두고, 누름 영역은 이미지 좌우 끝에서 폭 48dp, 이미지 높이 전체의 세로 띠로 넓힌다. 원은 띠 안에서 좌우 8dp, 세로 가운데. 띠 위에서는 확대 대신 인물을 넘기고 눌림 리플은 원에만 그린다 |
| 상세 하단 | 메타 정보가 보이기 시작하면 CTA와 페이드를 surface에서 backgroundNeutral로 전환. 끝에서는 메타와 같은 색, 위로 스크롤하면 원래 색. 처음 보일 때 진행률 0에서 시작해 200ms로 따라간다. 메타 정보가 없는 상세는 surface 유지 |
| 채팅 시작 시트 | 제목 titleLarge와 8dp 아래 설명 bodyLarge, textSubtle. 24dp 아래 control 모서리의 backgroundNeutralRaised 카드 하나에 페르소나 행과 시작 상황 행을 surfaceRaised 1dp 선으로 나눈다. 행은 16dp 여백에 라벨 bodyMedium과 textSubtle, 4dp 아래 값 bodyLargeStrong, 시작 상황은 상황 설명 두 줄, 오른쪽 20dp 꺾쇠. 행은 펼침과 꺾쇠 회전이 반응이라 리플이 없고, 누르면 값이 접히고 선택지 목록이 셀렉트 꺾쇠와 같은 스프링으로 펼쳐진다. 선택지는 menuItem 모서리, 가로 8dp, 세로 12dp, bodyLarge, 사이 4dp. 페르소나 목록 아래 글자 시작선에 맞춘 구분선과 textSubtle 더하기 아이콘의 “페르소나 생성하기”를 스크롤 밖에 고정한다. 시작 상황이 하나면 꺾쇠 없이 펼치지 않는다. 카드 아래 24dp에 전체 폭 brand “채팅 시작하기”, 생성 중에는 라벨 자리를 유지한 스피너. 시트 위 회색 카드는 다크에서 시트 바탕보다 한 단계 밝은 채움. 고른 선택지는 눌림 리플과 같은 반투명 채움과 체크. 선택지는 48dp 높이로 5줄 반을 넘으면 목록 안에서 스크롤하고 열 때 고른 항목 위 두 칸부터 보인다. 본문을 끌어도 시트는 내려가지 않고 핸들 끌기, 바깥 탭과 뒤로가기로만 닫는다. 생성 중에는 이 셋으로도 닫지 않는다 |
| 상세 셀렉트 메뉴 | 항목 최소 40dp, 값 항목은 5줄 반을 넘으면 메뉴 안에서 스크롤. “페르소나 생성하기”는 구분선 아래 흐린 색으로 스크롤 밖에 고정 |
| 표지 없음 | 기본 심벌, backgroundNeutral과 textDisabled. 상세 헤더는 투명에서 surface로, 아이콘은 처음부터 text |
| 카드 옵션 | 대상 종류와 제목, 항목 목록. 카드 축소판을 넣지 않는다 |
| 초안 조회 | 헤더 아래 늦게 나타나는 중앙 스피너, 실패는 같은 자리의 안내와 재시도 |
| 완성 중 | 공통 마스코트 표지와 시머 제목, “스토리가 완성되면 알림으로 알려드려요” |
| 화풍 | 세 칸씩의 행, 이름을 흐린 바탕 위에 표시. RadioButton 역할과 화풍 이름 하나, 바깥 brand 테두리로 선택해 자리 유지 |
| 크롭 | 바텀 시트 검은 판 위 고정 비율 창, 창 밖은 어둡게 표시. 이동과 확대 범위를 구성 변경에 유지 |

### 3-3-2 가입 온보딩

| 영역 | 표현 |
|---|---|
| 헤드라인 | “마음에 드는 스토리를 골라 / 바로 채팅을 시작해보세요” |
| 제작 | “마음에 드는 스토리가 없나요?”와 오른쪽 “직접 만들기” |
| 캐러셀 | 가운데 카드와 양옆 일부. 카드는 화면 폭의 76%(최대 360dp)와 남은 높이에 들어가는 3:4 중 작은 쪽, 카드 사이 12dp. 옆 카드는 가운데에서 멀어진 만큼 88%로 줄고 불투명도 40%로 내려가며, 축소 기준점을 가운데 쪽 변에 둬 넘기는 동안 간격이 그대로다. 카드 폭은 글자 영역 높이(sp로 읽어 글자 크기를 따름)를 뺀 남은 높이로도 제한한다 |
| 카드 | 위 표지, 구분선 아래 한 줄 제목과 “상세 보기”, 소개 최대 두 줄. surfaceRaised, border 1dp, featureCard 모서리. 표지는 각지게 두고 카드가 깎으며 표지 위에는 아무것도 얹지 않는다. 글자 영역은 좌우 16dp, 위아래 14dp. 제목 bodyLargeStrong과 text, 오른쪽 “상세 보기” labelSmall과 12dp 꺾쇠, textSubtlest. 4dp 아래 소개 bodyMedium과 textSubtle은 두 줄 높이 고정 |
| 카드 그림자 | 흰 글자 영역이 같은 밝기의 바탕에 묻히지 않게 두는 그림자 예외. 높이 16dp로 넓게 퍼뜨리고 그림자 색을 30%로 눌러 윤곽 없이 카드 아래만 살짝 가라앉게 한다. 옆 카드를 흐리는 반투명 층이 그림자를 자르지 않게 그 층의 높이로 그린다. 바깥 선택 테두리는 없다 |
| 헤드라인과 제작 | 헤드라인 headlineSmall. 대안 줄은 textSubtle 질문 옆 textBrand 글자 버튼(아이콘 없음)으로 주 동작보다 낮춘다 |
| 하단 | “채팅 시작하기” 한 줄 주 버튼, 높이 48dp. 생성 중에는 라벨 자리를 유지한 스피너 |
| 로딩 | 같은 자리의 카드 골격 세 장. 상태가 바뀔 때 300ms 교차 페이드 |
| 실패 | “스토리를 불러오지 못했어요”와 “다시 시도” |
| 빈 목록 | “지금은 보여드릴 스토리가 없어요”. 직접 만들기는 계속 제공 |
| 낮은 화면 | 창 높이 600dp 미만이면 캐러셀 높이를 420dp로 고정하고 화면을 세로 스크롤해 카드가 지나치게 작아지지 않게 함 |

카드 가운데 선택과 진행 요청은 회전, 다크 모드와 글자 크기 변경에도 유지한다.

### 3-3-3 제작 안내

| 요소 | 표현 |
|---|---|
| 창 | 웹 카드와 같은 모양이라 앱 다이얼로그와 따로 둔다. 검정 50% 딤 위 세로 가운데, 좌우 12dp만 남긴 폭. 모서리 20dp, surface 배경, 안쪽 16dp. 다크 모드에만 1dp 경계. 바깥 탭으로 닫지 않는다 |
| 프로필 | 48dp 원, backgroundBrandSubtle 위 brand 마스코트. 몸은 프로필 폭의 66% |
| 이름과 대사 | 프로필 옆 12dp. “마냑”은 labelLarge와 textBrand, 4dp 아래 대사는 bodyLarge(16sp, 행간 24sp) |
| 버튼 | 대사 아래 16dp의 오른쪽 정렬, 간격 4dp. 보이는 높이 40dp, 보조는 text 색 글자 버튼, 주 버튼은 brand 채움 |
| 모션 | 창 전환 없이 카드가 250ms 동안 0.95배에서 커지며 나타난다. 단계가 바뀌면 같은 호출 자리에서 다시 그려 창을 유지하고 문구만 200ms 교차 페이드(단계마다 창을 새로 열면 딤이 두 번 페이드돼 깜빡임). 마스코트는 5초 동안 두 번 말하고 쉬며 몸을 프로필 폭 3.5%까지 띄우고 좌우 3도 기울인다. 애니메이터 배율이 0이면 서 있는 첫 자세 |

### 3-3-4 제작 퍼널

퍼널은 셸을 두르지 않는 전체 화면이라 헤더와 하단 버튼을 화면이 직접 그린다. 밑줄 탭, 칩, 텍스트 필드와 버튼의 공용 규칙은 Android 디자인 시스템을 따른다. ([DESIGN.md 컴포넌트](../../../../../../manyak-android/DESIGN.md#컴포넌트))

| 요소 | 표현 |
|---|---|
| 헤더 | TopAppBar 위에 색만 얹고 화면 제목 bodyLargeStrong(웹 제작 헤더와 같은 크기)과 오른쪽 임시 저장, 닫기 버튼. 높이 64dp, 구분선과 그림자 없음 |
| 단계 표시 | 헤더 아래 높이 3dp 막대 분절, 양끝 알약, 분절 사이 12dp, 좌우 16dp. 완료 textDisabled, 현재 stepIndicatorActive, 미도달 border(backgroundNeutral은 surface 위에서 거의 안 보임). 채움에 brand를 쓰지 않는다(진행 표시는 동작이 아님). 단계 이름은 시각 라벨 없이 접근성 텍스트로만 두고 막대들은 하나의 시맨틱으로 묶는다 |
| 하단 버튼 | 주 버튼(다음, 스토리라인 만들기)과 보조 버튼(이전, 다시 만들기)이 같은 폭(1:1)으로 하단을 나눈다 |
| 키워드 칩 | 제공, 커스텀 태그는 흰 바탕과 border 칩, 선택은 backgroundBrandSubtle, borderBrand, textBrand. 높이 40dp, control 모서리, 선택 변화가 반응이라 리플 없음. 상한에 도달하면 미선택 칩과 추가 버튼을 textDisabled로 내린다 |
| 추가 버튼 | “키워드 추가”, “인물 추가”, “정보 추가”는 키워드 칩과 같은 모양에 backgroundNeutral 채움과 border, 16dp `+` 아이콘. 인물 추가와 정보 추가는 폭을 채우지 않고 가운데 |
| 카테고리 탭 | 밑줄 탭에 잠금 textDisabled, 필수 표시 `*` textDanger. 스크롤 시 탭만 상단에 고정하고 각 카테고리 내용은 탭 아래에서 시작 |
| 주변 인물 머리 줄 | 접기와 삭제 버튼 32dp, labelSmall, 접기 화살표 12dp. 입력 영역은 위 변을 붙잡은 높이와 투명도로 여닫고 화살표 회전과 인물 추가 위 간격도 함께 움직인다. 웹과 같은 튕김 없는 약 0.3초 스프링. 접힌 항목 다음에는 목록 간격이 없다. 주변 인물이 0명이면 인물 추가 버튼 위에 랜덤 생성 안내 |
| 스토리라인 대기 | 문구는 4초마다 글자별 25ms 시차로 교차하고 전체 문구 위에 4초 시머가 지나간다. 앞의 점 3개는 1초 주기로 160ms씩 늦게 떠올랐다 내려온다. 이전, 다음 문구를 별도 레이아웃으로 겹쳐 글자 폭 차이로 흔들리지 않는다. 문구 3종과 15초, 30초 지연 힌트 |
| 스토리라인 단계 | 순번 탭은 카테고리 탭과 같고 잠금과 필수 표시가 없다. 본문은 bodyReading, `**…**` 볼드와 단일 `*…*` textNarration. 평가 버튼(좋아요, 별로예요)은 40dp 정사각 칩에 16dp 아이콘, 키워드 칩과 같은 선택 문법이며 별로예요 활성은 backgroundDangerSubtle, borderDanger, textDanger. 하단은 다시 만들기와 선택하기. 웹의 선택 키워드 드로어는 두지 않는다 |
| 추가 정보 단계 | 선택한 스토리라인은 backgroundNeutral 상자에 bodyReading, 기본 한 줄 말줄임과 가운데 더보기, 접기(textSubtle과 16dp 꺾쇠). 추천은 키워드 칩 문법의 여러 줄 칩을 폭을 채워 세로 나열. 자유 입력은 여러 줄 텍스트 필드와 오른쪽 아래 글자 수, 행 오른쪽 삭제는 textSubtle 아이콘 버튼. 섹션 사이 24dp, 제목과 내용 사이 8dp. 하단은 다시 선택하기와 스토리 완성하기 |
| 이미지 스타일 | 서버 순서의 3열 그리드, 칸 사이 8dp. 칸은 border 1dp, card 모서리의 3:4 표지(미리보기가 없으면 기본 심벌)이고 아래 가운데에 표지 뱃지와 같은 흐린 알약에 이름 labelSmall, textInverse. 고른 칸은 바깥 2dp borderBrand 테두리를 150ms 동안 채우고 나머지를 흐리지 않으며 리플 없음. 받는 동안 골격 칸 여섯 개, 실패하면 가운데 textSubtle 안내와 “다시 불러오기”. 고르지 않고 완성을 누르면 비용 행과 CTA 사이에 textDanger 안내 |
| 장르 검색 | 장르 칩 위 입력은 텍스트 필드의 표면, 모서리, 글꼴, 포커스 경계에 왼쪽 돋보기와 오른쪽 펼침 아이콘(16dp, textSubtle). 메뉴는 입력 폭으로 아래에 열려 화면과 키보드의 가용 공간 안에서 스크롤하고 control 모서리, surfaceRaised, border 1dp, 4dp 그림자. 항목 높이 40dp, 사이 4dp, 최대 높이 240dp. 선택은 체크, 3개면 새 선택만 비활성. 항목을 누르면 칩과 같은 선택을 토글하고 메뉴와 키보드를 닫으며 입력을 비운다. 대표 장르 칩은 순서를 유지하고 목록 밖 장르는 처음 선택할 때만 끝에 붙는다 |
| 장르 검색 로딩 | 빈 검색어는 받은 전체 장르를 즉시 보인다. 화면 수명 안의 성공 결과를 재사용하고, 캐시에 없는 검색은 기존 목록을 유지한다. 입력 대기 250ms 뒤 요청이 200ms 이상 걸릴 때만 로딩 문구를 보이고, 결과가 아직 없으면 입력 높이의 빈 공간을 유지한다 |
| 완성 중 카드 | 마스코트 표지와 제목 시머, 앱의 완성 알림 안내 문구. 채팅 대기 문구는 공용 시머 브러시에 2초 주기와 색을 유지 |
