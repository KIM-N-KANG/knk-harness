## 3-3-2. 내비게이션·화면 계약

### 메인 탭 셸

- 홈·채팅·제작·마이의 네 탭을 제공합니다. 탭별 스크롤·화면 상태를 보존합니다.
- 다른 탭의 시스템 뒤로가기는 홈으로, 홈의 뒤로가기는 앱 밖으로 이동합니다. 탭 방문 순서를 화면 이력으로 쌓지 않습니다.
- 헤더·하단 탭은 탭 전환 중 같은 위치를 유지합니다. 아이콘·라벨·주변 터치 영역이 같은 탭을 선택하고 접근성 이름과 선택 여부를 한 번씩 읽어야 합니다.
- 상세는 진입한 탭 위에서 열고 닫으면 그 탭으로 복귀합니다. 상세에서 스토리 삭제에 성공하면 상세를 닫고 제작 탭으로 이동합니다. 상세에서 채팅을 시작하면 뒤로가기로 상세에 돌아오고 다시 뒤로가면 원래 탭으로 돌아갑니다.
- 확인 다이얼로그의 머무르는 왼쪽 버튼은 모두 "닫기"로 표기합니다. 공통 계약의 카드와 채팅 삭제 확인 "남겨두기", 일반 제작 임시 저장 충돌 확인의 "남겨두기", 웹 일반 제작 이탈 경고의 "계속 만들기"도 Android에서는 "닫기"로 표시합니다.

### 웹에서 앱 열기

- 웹의 [앱 안내 배너](3-2-web-spec.md#앱-안내-배너)가 여는 전용 스킴 링크 `manyak://manyak.app{경로}`를 받습니다. `/stories/{id}`는 그 스토리 상세, `/notices`는 공지사항 목록, `/notices/{noticeId}`는 그 공지 상세(목록을 먼저 쌓아 뒤로가기가 목록으로 감), 그 밖의 경로는 홈을 엽니다. 허용 경로와 해석에 실패했을 때의 처리는 알림 `deepLink`와 같습니다.
- 특정 회원에게 보낸 링크가 아니므로 수신자를 비교하지 않습니다. 로그인 전이면 목적지를 보류하고 로그인 뒤에 엽니다.
- `https://manyak.app` 일반 링크는 받지 않습니다. 다른 앱에서 누른 manyak.app 링크는 지금처럼 브라우저로 열립니다.

## 3-3-4. 디바이스·접근성·상태 복원

- 지원 OS·빌드 버전은 Android 빌드 설정을 기준으로 확인합니다. 화면은 제스처·3버튼 내비게이션과 시스템 바의 안전 영역을 확보합니다.
- 하단 탭의 터치 타깃은 48dp 이상입니다. 화면은 한 열로 구성하고 세로 스크롤과 넓은 창의 본문 폭 상한을 제공합니다. 전체 접근성·글자 크기 지원 범위는 별도 확정이 필요합니다.
- 회전·테마 변경 시 편집 중 입력·선택·입력 확인 다이얼로그·탭·목록 스크롤과 진행 중 요청 표시를 유지합니다. 사용자 입력이 필요한 시트의 입력도 보존합니다.
- 구성 변경 시 옵션·메뉴 시트는 열린 채 유지하고, 말풍선(팝오버)은 닫히며 포커스·키보드·장식 애니메이션은 재개를 보장하지 않습니다.
- 앱 재시작 시 복원 가능한 식별자로 화면 데이터를 다시 읽습니다. 제작은 마지막 저장본·진행 요청에서 복구하며 저장되지 않은 편집의 프로세스 종료 복원은 보장하지 않습니다.
- 법적 문서는 구성 변경 시 열람 위치를 유지합니다. 상세·채팅의 이미지 뷰어는 구성 변경 시 열린 이미지를 유지하며 프로세스 재시작 복원 대상이 아닙니다. 확대·이동 상태는 구성 변경 또는 뷰어를 닫을 때 초기화합니다.
