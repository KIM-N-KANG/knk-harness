# 4-3 상태 관리: iOS

기준: [공통 상태](../4-3-STATE-MANAGEMENT.md), [iOS 구성](4-2-COMPONENT-ARCHITECTURE.md).

<br>

### 4-3-1 저장 위치와 수명

| 상태 | 기준 |
|---|---|
| 공지 읽음 | `ManyakNotice`가 UserDefaults 기기 suite의 키 하나에 둔 최신순 ID 배열, 최대 100개. `UserScopedStore`에 참여하지 않음 |
| 공지 안 읽음 | 메인 셸 수명 객체가 목록 첫 페이지(기본 크기 20건)와 읽은 ID로 계산. 읽은 ID가 바뀌면 조회 없이 다시 계산 |
| 알림함 | 알림함 Store의 두 분류 목록, 커서와 선택 분류. 디스크 저장과 프로세스 종료 뒤 복원 없음 |
| 알림 읽음 | 목록 조회와 읽음 요청을 알림함 데이터 계층의 actor 하나로 직렬화. 모두 읽음 실패는 두 목록과 수 복원 |
| 안 읽은 수 | 메인 셸 수명 객체. 조회 실패는 0으로 둠 |
| 토큰 등록 | 앱 수명 등록기 actor. 마지막으로 성공한 세션 세대와 토큰을 메모리에만 둠. 토큰 값 영구 저장과 재전송 큐 없음 |
| 기기 토큰 삭제 미완료 | UserDefaults 기기 suite의 표시 하나. 세션 종료 정리의 기기 토큰 삭제가 실패하면 남기고 삭제나 새 등록이 성공하면 지움 |
| 알림 권한 | 시스템 권한 상태가 기준. 앱이 질문 여부를 따로 저장하지 않음 |
| 보류 진입 | 앱 타깃 메모리. 프로세스 종료와 세션 종료에서 폐기 |
| 광고 질문 | UserDefaults 회원 suite. 거절 0, 1, 2와 첫 거절 뒤 재진입 횟수 |
| 검수 화면 관찰 | 프로세스 메모리의 대기 제출본과 표시한 결과. 디스크 복원 안 함 |
| 표시 중 알림 | 시스템 알림 센터. 세션 종료 정리에서 모두 제거 |

공지 읽음 쓰기 실패는 조용히 무시해 다음에 점이 다시 보일 수 있다. 회원 알림 목록, 수신 대기 메시지와 보류 목적지를 다음 계정으로 넘기지 않는다. 기기 토큰 삭제 미완료 표시는 로그아웃 정리 뒤에도 남아야 하므로 회원 suite에 두지 않는다.
