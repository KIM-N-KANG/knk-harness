# 3-1 화면 구성: iOS

기준: [공통 화면](../3-1-INFORMATION-ARCHITECTURE.md), [iOS 요구사항](2-2-REQUIREMENTS.md).

<br>

### 3-1-1 목적지

공지 목록과 상세, 알림함과 알림 설정은 진입한 탭의 스택에 쌓는 하위 화면이다. 홈, 채팅과 제작 탭 루트의 종은 알림함으로, 마이 공지사항 메뉴는 공지 목록으로 간다. 알림 설정은 마이와 알림함에서 연다. 하단 탭 표시는 [공통 UI IOS 루트와 셸](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-루트와-셸)을 따른다.

| 알림함 카드 목적지 | 여는 곳 |
|---|---|
| 스토리 상세 | 알림함 위 |
| 공지 목록 | 알림함 위 |
| 공지 상세 | 알림함 위. 공지 목록을 거치지 않음 |
| 이프 충전 | 알림함 위. 처음 여는 탭은 [PAYMENT iOS](../../../PAYMENT/CLIENT/IOS/2-2-REQUIREMENTS.md#2-2-1-충전-화면) |
| 제작 탭 | 알림함을 연 탭의 스택을 루트로 되돌린 뒤 제작 탭 루트 |

알림함 카드의 deepLink는 푸시와 같은 해석기로 고르며 해석에 실패하면 공지 ID, 스토리 ID 순서로 대체한다. 푸시와 앱 열기 링크의 허용 경로, 선택 탭과 스택은 [진입 목적지](../../../../ui/IOS/3-1-INFORMATION-ARCHITECTURE.md#3-1-2-진입-목적지)를 따른다.
