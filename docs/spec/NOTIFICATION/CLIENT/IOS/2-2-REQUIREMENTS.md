# 2-2 요구사항: iOS

기준: [공통 요구사항](../2-2-REQUIREMENTS.md).

<br>

### 2-2-1 기기와 수명

| 조건 | 결과 |
|---|---|
| 공지 목록 | 눌림 덮개. 기존 목록에서만 당겨서 새로고침, 실패는 목록 유지와 토스트 |
| 공지 표시 갱신 | 메인 셸이 처음 나타날 때, 하위 화면에서 탭 루트로 돌아올 때와 포그라운드 복귀 때 첫 페이지를 읽어 판정. 탭 루트 사이 전환은 계기가 아님. 실패하면 새 공지 점과 배지 끔 |
| 알림함 갱신 | 같은 계기에 안 읽은 수 갱신. 앱이 앞에 있을 때 현재 회원의 알림을 받아도 갱신. 실패하면 헤더 점 끔 |
| 알림함 유지 | 알림함이 탭 스택에 있는 동안 선택 분류, 분류별 목록과 스크롤 유지. 새 진입과 프로세스 종료 뒤는 소식 |
| 개인 알림 수명 | 회원 화면 수명에만 유지. 루트가 바뀌면 이전 목록을 표시하지 않음 |
| 권한 요청 | 실행마다 필수 동의를 마친 회원 화면이 처음 나타날 때 권한이 미결정이면 시스템 요청 창. 답한 뒤에는 시스템이 다시 묻지 않고 앱도 다시 요청하지 않음 ([I-143](DECISIONS.md#i-143)) |
| 권한 거부 | 세션과 토큰 등록을 막지 않음. 알림 설정에서 시스템 설정으로 가는 안내 제공 |
| 광고 질문 | 회원 귀속 기록, 로그아웃 정리. 질문 기록 저장 실패는 시트 유지 |
| 동의 알림 | 기기 알림이 꺼진 채 동의한 결과를 닫으면 “기기 알림이 꺼져 있어 알림 설정에서 켜야 받을 수 있어요” 안내 |
| 비적용 | 알림 채널과 채널별 중요도, 앱이 data 전용 메시지로 알림을 직접 만드는 방식, 표시 전 5초 수신자 확인, 잠금 화면에 제목만 공개하는 설정 |

알림 설정 토글은 행 전체가 아닌 스위치가 받는다. 광고 행에서 개인정보 처리방침을 연다.

### 2-2-2 수신, 표시와 정리

NOTIFICATION-US-003.

| 조건 | 결과 |
|---|---|
| 서버 선행 변경 전 | 서버가 iOS 토큰 등록과 표시형 알림을 받기 전에는 토큰을 등록하지 않아 푸시를 받지 않음. 알림함과 설정은 그대로 제공 ([I-140](DECISIONS.md#i-140)) |
| 앱 종료, 백그라운드 | 서버가 실은 제목과 본문을 시스템이 표시. 앱 코드가 실행되지 않아 수신자 대조와 중복 억제 없음 ([I-142](DECISIONS.md#i-142)) |
| 포그라운드 | 수신 회원이 현재 회원으로 확인될 때만 시스템 배너와 알림 목록으로 표시. 다른 회원, 수신자 없음, 회원 확인 전 알림은 표시하지 않음 ([I-144](DECISIONS.md#i-144)) |
| 검수 결과 중복 | 앱이 앞에 있을 때만 해당 제출본 결과를 기다리는 화면 또는 같은 결과를 보여 준 뒤 2분 안의 같은 알림 표시를 억제 |
| 잠금 화면 | 사용자의 시스템 미리보기 설정을 따름 |
| 앱 아이콘 배지 | 숫자 표시는 미정. 앱이 숫자를 올리지 않음 |
| 알림 탭 | 수신 회원이 현재 회원이면 허용된 목적지, 다르거나 수신자가 없거나 목적지가 없으면 홈. 로그인 전 탭의 보류와 폐기는 [공통 UI IOS 외부 진입](../../../../ui/IOS/2-2-REQUIREMENTS.md#2-2-2-외부-진입) |
| 세션 종료 | 사용자 로그아웃은 서버 토큰 삭제를 시도. 탈퇴한 회원의 토큰은 서버가 지움. 모든 종료에서 기기의 FCM 토큰 삭제, 알림 센터의 이 앱 알림 제거와 배지 0. 실패해도 로그아웃을 막지 않음 ([I-145](DECISIONS.md#i-145)) |
| 남은 알림 | 실행과 포그라운드 복귀 때 알림 센터에 남은 알림 중 수신 회원이 현재 회원이 아닌 알림 제거 |
