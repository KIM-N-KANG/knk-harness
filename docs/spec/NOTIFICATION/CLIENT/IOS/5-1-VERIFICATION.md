# 5-1 검증: iOS

기준: [공통 검증](../5-1-VERIFICATION.md), [iOS 실행](4-4-EXECUTION.md).

신규 시나리오는 실행 완료 표시가 아니다. 실제 환경과 결과는 PR 및 CI에 기록한다. 시뮬레이터 결과를 실기기 통과로 표시하지 않는다.

<br>

단위 테스트와 대역은 실제 APNs와 FCM 전달, 시스템 권한 창, 백그라운드와 종료 상태 표시, 알림 탭 결과를 대신하지 않는다. Xcode에서 설치한 빌드는 개발용 APNs 환경을 쓰므로 TestFlight 빌드에서 수신을 다시 확인한다.
