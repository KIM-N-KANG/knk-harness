# 3-3 화면 배치: iOS

기준: [공통 표현](../3-3-LAYOUT.md), [iOS 흐름](3-2-INTERACTION-FLOWS.md).

<br>

### 3-3-1 목록과 헤더

| 요소 | 표현 |
|---|---|
| 공지와 알림 제목 | 한 줄 말줄임. 안 읽음 점은 제목과 별도 요소로 줄 끝에 두어 말줄임에 잘리지 않음. 점만 있는 줄 없음 |
| 목록 안 읽음 점 | 제목 끝의 unreadDotInline 6pt backgroundDangerBold 원. 제목은 굵게 |
| 헤더 종 | 홈, 채팅과 제작 탭 루트의 내비게이션 바 오른쪽 아이콘 버튼. 안 읽음이면 아이콘 오른쪽 위에 unreadDot 8pt backgroundDangerBold 원 |
| 알림함 헤더 | 하위 화면 헤더, 제목 알림. 오른쪽에 글자 버튼 모두 읽음과 톱니 아이콘 버튼 |
| 분류 탭 | 밑줄 탭. 안 읽음이 있는 탭은 라벨 오른쪽 위에 unreadDotInline 점 |
| 공지 행 | 눌림 덮개 |
| 날짜 | 공지 게시일과 수정일은 KST YYYY-MM-DD, 알림 카드는 상대 시각 |
| 재시도 | “다시 시도”. 목록 새로고침 실패는 “새로고침하지 못했어요” |

<br>

### 3-3-2 설정과 동의

| 요소 | 표현 |
|---|---|
| 기기 알림 꺼짐 | 설정 행 위 안내 영역에 “기기 알림 설정이 꺼져 있어요”와 중립 버튼 “알림 켜기” |
| 설정 행 | 라벨과 설명, 오른쪽 스위치. VoiceOver는 행 하나로 라벨, 설명과 켜짐 상태를 한 번 읽고 스위치가 조작을 받음 |
| 꺼짐 동안 | 세 스위치 비활성, 라벨과 설명 textDisabled, 저장된 값 표시 유지. 광고 행의 처리방침 버튼은 활성 |
| 광고 행 | 라벨 옆 아이콘 버튼으로 앱 안 개인정보 처리방침 화면을 같은 탭 스택에 엶 |
| 재질문 시트 | 시스템 시트. 주 버튼 광고 알림 받기와 그 아래 닫기 글자 버튼. 끌어내리기와 바깥 탭은 닫기와 같은 거절. 저장 중 끌어내리기와 닫기 잠금 |
| 처리 결과 | 시스템 알림창. 전송자, 일시, 처리 내용 세 줄과 확인 |

토스트는 기기 알림 꺼짐 안내만 긴 표시이고 설정 저장 실패, 모두 읽음 실패, 공지와 알림 목록의 새로고침 실패는 짧은 표시다. ([공통 UI IOS 토스트](../../../../ui/IOS/3-3-LAYOUT.md#3-3-4-공통-화면-상태))
