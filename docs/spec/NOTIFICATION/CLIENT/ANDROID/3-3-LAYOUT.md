### 3-3-1 목록과 설정

공지와 알림 제목은 한 줄로 줄이고 안 읽음 점은 별도 요소로 줄 끝에 남겨 말줄임에 잘리지 않게 한다. 목록의 점은 제목 끝의 6dp backgroundDangerBold 원이고 제목이 함께 굵어지며 보조 기술 이름은 “새 공지”다. 헤더 종 버튼은 아이콘 오른쪽 위에 8dp 같은 색 원을 surface 2dp 테두리로 띄우고 접근 이름을 “새 공지사항 있음”으로 바꾼다. 점만 있는 줄은 두지 않는다. 공지 목록은 앱 공용 눌림 리플을 사용한다. 재시도 문구는 “다시 시도”, 목록 새로고침 실패는 “새로고침하지 못했어요”다.

공지 상세의 게시일과 수정일은 KST yyyy-MM-dd다. 설정 스위치와 시트의 닫기는 앱 공용 디자인과 접근성 규칙을 사용한다. 검수 결과 시스템 알림의 잠금 화면 공개 버전에는 제목만 보인다.
