이 문서는 **마냑 서비스 사용자가 각 화면에서 무엇을, 왜 하고 싶어 하는지**를 유저 스토리로 정리합니다. [`1-background.md`](1-background.md)가 정의한 주요 기능과 사용자 흐름을 화면 단위의 사용자 요구로 풀어 쓰며, 기능 스펙과 분석 스펙을 작성할 때 "한 화면에서 사용자가 기대하는 행동"의 기준으로 사용합니다.

## 2-1 사용자 정의

마냑 MVP(Phase 0)는 로그인 없이 익명 사용자 기준으로 동작하며, Phase 1부터 소셜 로그인(Google·Kakao)과 회원 계정을 도입합니다([`roadmap.md §R-3`](../planning/roadmap.md)). 서비스 이용 대상은 만 14세 이상으로 제한합니다(2026-08-29 사용자 정책 결정, 서비스 이용약관 제3조·개인정보 처리방침 제14항). 익명 식별자 정책은 [`6-analytics.md §6-2`](6-analytics.md)를 따릅니다.

Phase 1·Phase 2 범위의 유저 스토리는 ID 옆에 `Phase 1`·`Phase 2` 라벨을 붙입니다. 라벨이 없는 스토리는 모두 MVP 범위입니다.

유저 스토리에 등장하는 사용자는 다음과 같이 나뉩니다.

| 사용자 구분            | 설명                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| 사용자                 | 마냑을 사용하는 만 14세 이상의 사람. MVP에서는 전원 게스트(익명)이고, Phase 1부터 게스트와 회원이 공존한다. |
| 게스트                 | 로그인 없이 마냑을 사용하는 익명 사용자. 데이터는 기기 단위로 기억된다.                        |
| 회원                   | `Phase 1` 소셜 로그인(Google·Kakao)으로 가입한 사용자. 닉네임·프로필 이미지를 갖고 이프를 적립·소모한다. 소셜 제공자가 다르면 별개 계정이다. |
| 처음 온 사용자         | 마냑에 처음 진입한 사용자. 시작 방법을 안내받아야 한다.                                        |
| 처음 만드는 사용자     | 스토리 생성 흐름을 처음 사용하는 사용자. 단계별 가이드가 필요하다.                             |
| 처음 플레이하는 사용자 | 채팅을 처음 사용하는 사용자. 채팅 사용법 안내가 필요하다.                                      |

> 온보딩 안내가 필요한 사용자(처음 온 · 처음 만드는 · 처음 플레이하는)는 동일한 익명 사용자가 각 화면을 처음 사용하는 상태를 가리킵니다. 온보딩은 한 번만 노출합니다([US-8-3](#2-8-공통--네비게이션)).
