### 2-2-1 지원과 접근성

CLIENT-US-001, CLIENT-US-003.

| 항목 | 조건 |
|---|---|
| 브라우저 | 최신 모바일 Chrome과 Safari 필수. 최신 데스크톱 Chrome과 Safari는 같은 모바일 셸로 권장 |
| 화면 | 폭 상한이 있는 한 열. 주요 CTA가 첫 화면에 보이고 가로 넘침 및 입력 중 레이아웃 붕괴 없음 |
| 화면 높이 | 도구 막대 변화에 따른 동적 높이. 안전 영역을 확보하고 본문만 스크롤 |
| 테마 | 문서와 앱 배경을 연결하고 넓은 화면의 좌우 여백만 구별. 루트 오류 화면에도 적용 |
| 키보드 | 모든 클릭 요소에 접근과 보이는 포커스. 입력 라벨과 오류 연결 |
| 모달 | 내부로 포커스를 이동하되 팝업 자체가 기본. 필요한 특정 요소만 예외 |
| 상태 | 로딩과 상태를 보조기술에 알리고 색상만으로 구별하지 않음 |
| 모바일 입력 | 주소창과 키보드 변화에 CTA, 입력과 마지막 메시지 가림, 이중 스크롤과 위치 튐 없음 |
| 모션 | 전환과 스트리밍에 잔상이나 입력 차단 없음. 동작 줄이기에서는 장식 모션 제거 |

### 2-2-2 문서와 검색

CLIENT-US-002. 서비스 안내와 법적 문서는 로그인 전에도 같은 본문을 읽을 수 있다. 공개 홈, 서비스 안내, 법적 문서와 공개 오리지널 상세는 사이트맵에 싣는다. 유효한 채팅 공유본은 색인을 허용하되 사이트맵에는 나열하지 않는다.

개인화, 인증, 제작과 API는 수집에서 제외한다. 로그인 이어가기 주소, 조회 불가 공유본과 사용자 스토리 상세는 noindex, nofollow다. 오리지널 여부나 공개 상세를 확인하지 못하면 상세 색인을 허용하지 않는다. robots.txt가 상세 메타데이터 판독을 막지 않아야 한다. 검색 결과의 스니펫과 사이트링크 선택 및 순서를 보장하지 않는다.

### 2-2-3 앱 안내와 소개 링크

CLIENT-US-004.

| 조건 | 결과 |
|---|---|
| Android 인앱 | 매 접속 앱 배너 |
| Android 일반 브라우저 | 첫 번째와 세 번째 접속 앱 배너 |
| iOS 인앱 | 매 접속 외부 브라우저 안내 |
| iOS Safari와 Chrome | 첫 번째와 세 번째 접속 홈 화면 추가 안내 |
| 제외 | 서비스 안내, 법적 문서, 앱 소개 링크, 데스크톱, 설치본, 크롤러와 다른 iOS 브라우저 |
| 접속 단위 | 새 탭에서 최초로 배너 대상 여부를 판정할 때. 같은 탭의 새로고침과 이동은 같은 접속. 제외 화면만 본 경우 집계하지 않음 |
| 닫기 | 해당 접속 동안만 숨김. 다음 노출 대상 접속은 다시 안내 |
| 설치 후 목적지 | 디퍼드 딥링크 없음 |

앱 소개 링크는 메신저에 앱 제목과 설명 및 브랜드 이미지를 제공한다. 검색 색인은 허용하지 않되 링크 추적은 허용한다. 탭마다 자동 이동은 한 번이며 앱 복귀, 같은 탭 새로고침과 복원에서 반복하지 않는다.
