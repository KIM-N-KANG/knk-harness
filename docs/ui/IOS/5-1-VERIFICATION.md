### 5-1-2 기록 규칙

- iPad의 iPhone 호환 모드와 가로 방향은 검증하지 않는다.
- 읽는 본문 줄 상자의 위아래 여백은 Android 앱과 같은 화면을 나란히 놓고 큰 글자와 기본 크기에서 비교한다.
- UI 테스트는 CI에서 돌리지 않으며 실행 결과는 PR에 남긴다. ([IOS 기반 검증](../../platform/CLIENT/IOS/4-VERIFICATION.md))
