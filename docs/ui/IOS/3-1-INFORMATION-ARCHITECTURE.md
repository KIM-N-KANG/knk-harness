# 3-1 화면 구성: iOS

기준: [공통 화면](../3-1-INFORMATION-ARCHITECTURE.md), [iOS 요구사항](2-2-REQUIREMENTS.md).

<br>

### 3-1-1 루트와 셸

앱의 루트 화면은 세션과 동의 상태로 정한다. 각 화면의 내용과 동의 조건은 [ACCOUNT 화면](../../spec/ACCOUNT/CLIENT/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-화면과-진입)과 연결한다.

| 상태 | 루트 화면 |
|---|---|
| 세션 미판정, 세션 종료 정리 중 | 앱 안 시작 화면 |
| 비로그인 | 로그인 그래프. 가입 동의 시트 포함 |
| 저장 세션의 동의 확인 | 시작 화면, 필요한 경우 회원 동의 시트 |
| 새 로그인 뒤 동의 확인 | 로그인 화면과 진행 표시, 필요한 경우 회원 동의 시트 |
| 동의 완료 회원 | 메인 셸. 신규 가입은 메인 셸 대신 스토리 온보딩을 먼저 표시 |
| 종료 정리 실패 | 정리 실패 재시도 화면 |

메인 셸은 홈, 채팅, 제작, 탐색, 마이 순서의 다섯 탭이다. 탭마다 NavigationStack(탭 안에서 화면을 쌓고 되돌리는 시스템 스택)을 두고 상세와 하위 화면은 진입한 탭의 스택에 쌓는다. 탐색은 다른 탭에서 들어올 때 탐색 스택이 루트이면 새 순서로 맨 위부터 보인다. ([STORY iOS 목록과 상세](../../spec/STORY/CLIENT/IOS/2-2-REQUIREMENTS.md#2-2-1-목록과-상세))

하단 탭은 다섯 탭 루트에서만 보이고 탭 루트 위에 쌓은 모든 하위 화면에서 숨긴다. 새 화면도 같은 규칙을 따른다. ([I-042](DECISIONS.md#i-042))

| 화면 | 탭 바 |
|---|---|
| 다섯 탭 루트 | 표시 |
| 탭 스택에 쌓은 모든 하위 화면 | 숨김 |
| 전체 화면 이미지 뷰어, 동의 시트 위 문서 창 | 탭 바와 내비게이션 바를 덮는 전체 화면 |

마이의 화면 섹션에서 테마를 바꾼다. 정책 문서는 홈과 마이 하단 링크에서 앱 안 문서 화면으로 열며 진입한 탭의 스택에 쌓는다.

<br>

### 3-1-2 진입 목적지

전용 앱 열기 링크와 푸시는 경로를 https 주소로 해석해 목적지를 고른다. 푸시가 보내는 경로 값은 [NOTIFICATION 푸시 데이터](../../spec/NOTIFICATION/BACKEND/4-2-CONTRACT.md#4-2-10-푸시-데이터)가 정한다.

| https 경로 | 목적지 | 푸시 | 앱 열기 링크 |
|---|---|---|---|
| `/stories/{storyId}` | 스토리 상세 | 허용 | 허용 |
| `/notices` | 공지 목록 | 허용 | 허용 |
| `/notices/{noticeId}` | 공지 목록 위 공지 상세 | 허용 | 허용 |
| `/studio` | 제작 탭 | 허용 | 홈 |
| `/my/credits` | 이프 충전 화면. `tab` 쿼리로 처음 여는 탭은 [PAYMENT iOS](../../spec/PAYMENT/CLIENT/IOS/2-2-REQUIREMENTS.md#2-2-1-충전-화면)가 정함 | 허용 | 홈 |
| 그 밖의 경로와 해석 실패 | 홈 | 홈 | 홈 |

화면 목적지는 현재 선택한 탭의 스택 위에 쌓고 탭을 바꾸지 않는다. 탭 목적지는 그 탭을 선택하고 그 탭의 스택은 그대로 둔다. 어느 경우에도 쌓여 있던 화면은 걷지 않는다. 스택 맨 위가 이미 같은 목적지이면 다시 쌓지 않는다. ([I-043](DECISIONS.md#i-043))

| 목적지 | 종류 | 여는 방식 |
|---|---|---|
| 스토리 상세 | 화면 | 현재 탭 스택 위에 상세 |
| 공지 목록 | 화면 | 현재 탭 스택 위에 목록 |
| 공지 상세 | 화면 | 현재 탭 스택 위에 목록, 그 위에 상세 |
| 이프 충전 | 화면 | 현재 탭 스택 위에 충전 |
| 제작 탭 | 탭 | 제작 탭 선택. 목록 즉시 새로고침 |
| 홈 | 탭 | 홈 탭 선택 |
