# 3-1 화면 구성: iOS

기준: [공통 화면](../3-1-INFORMATION-ARCHITECTURE.md), [iOS 요구사항](2-2-REQUIREMENTS.md).

### 3-1-1 루트와 셸

앱의 루트 화면은 세션과 동의 상태로 정한다. 각 화면의 내용과 동의 조건은 [ACCOUNT 화면](../../spec/ACCOUNT/CLIENT/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-화면과-진입)과 연결한다.

| 상태 | 루트 화면 |
|---|---|
| 세션 미판정, 세션 종료 정리 중 | 앱 안 시작 화면 |
| 비로그인 | 로그인 그래프. 가입 동의 시트 포함 |
| 저장 세션의 동의 확인 | 시작 화면, 필요한 경우 회원 동의 시트 |
| 새 로그인 뒤 동의 확인 | 로그인 화면과 진행 표시, 필요한 경우 회원 동의 시트 |
| 동의 완료 회원 | 메인 셸. 신규 가입은 스토리 온보딩을 먼저 표시 |
| 종료 정리 실패 | 정리 실패 재시도 화면 |

메인 셸은 홈, 채팅, 제작, 탐색, 마이 순서의 다섯 탭이다. 탭마다 NavigationStack(탭 안에서 화면을 쌓고 되돌리는 시스템 스택)을 두고 상세와 하위 화면은 진입한 탭의 스택에 쌓는다. 탐색은 다른 탭에서 들어올 때만 새 순서로 맨 위부터 보인다. ([STORY 탐색과 제작 목록](../../spec/STORY/CLIENT/2-2-REQUIREMENTS.md#2-2-2-탐색과-제작-목록))

하단 탭 표시는 화면별로 아래와 같다. 목록에 없는 새 화면은 [하단 탭 표시 조건](2-2-REQUIREMENTS.md#2-2-1-화면과-기기)으로 정한다. ([I-042](DECISIONS.md#i-042))

| 화면 | 탭 바 |
|---|---|
| 다섯 탭 루트 | 표시 |
| 스토리 검색, 공지 목록과 상세, 알림함, 알림 설정, 법적 문서, 오픈소스 고지, 친구 초대, 페르소나 관리 | 표시 |
| 스토리 상세, 채팅방, 제작 방식 선택과 그 뒤의 제작 화면, 스토리 수정 | 숨김. 하단 고정 동작이나 입력창 |
| 프로필 수정, 페르소나 생성과 수정, 회원 탈퇴 | 숨김. 하단 고정 동작 |
| 피드백, 이프 충전 | 숨김. 공통 화면 계약의 하단 탭 없음([CHAT 피드백](../../spec/CHAT/CLIENT/3-3-LAYOUT.md#3-3-6-피드백), [PAYMENT 잔액과 무료 충전](../../spec/PAYMENT/CLIENT/3-3-LAYOUT.md#3-3-1-잔액과-무료-충전)) |
| 전체 화면 이미지 뷰어, 동의 시트 위 문서 창 | 탭 바와 내비게이션 바를 덮는 전체 화면 |

마이의 화면 섹션에서 테마를 바꾼다. 정책 문서는 홈과 마이 하단 링크에서 앱 안 문서 화면으로 열며 진입한 탭의 스택에 쌓는다.

### 3-1-2 진입 목적지

전용 앱 열기 링크와 푸시는 경로를 https 주소로 해석해 목적지를 고른다. 푸시가 보내는 경로 값은 [NOTIFICATION 푸시 데이터](../../spec/NOTIFICATION/BACKEND/4-2-CONTRACT.md#4-2-10-푸시-데이터)가 정한다.

| https 경로 | 목적지 | 푸시 | 앱 열기 링크 |
|---|---|---|---|
| `/stories/{storyId}` | 스토리 상세 | 허용 | 허용 |
| `/notices` | 공지 목록 | 허용 | 허용 |
| `/notices/{noticeId}` | 공지 목록 위 공지 상세 | 허용 | 허용 |
| `/studio` | 제작 탭 | 허용 | 홈 |
| `/my/credits` | 이프 충전 화면. `tab` 쿼리로 처음 여는 탭은 [PAYMENT](../../spec/PAYMENT/CLIENT/3-1-INFORMATION-ARCHITECTURE.md#3-1-1-진입과-정보-순서)가 정함 | 허용 | 홈 |
| 그 밖의 경로와 해석 실패 | 홈 | 홈 | 홈 |

목적지는 아래 탭과 스택으로 연다. 다른 탭의 스택은 그대로 둔다. ([I-043](DECISIONS.md#i-043))

| 목적지 | 선택 탭 | 선택 탭의 스택 |
|---|---|---|
| 스토리 상세 | 홈 | 루트, 상세 |
| 공지 목록 | 홈 | 루트, 목록 |
| 공지 상세 | 홈 | 루트, 목록, 상세 |
| 제작 탭 | 제작 | 루트. 목록 즉시 새로고침 |
| 이프 충전 | 마이 | 루트, 충전 |
| 홈 | 홈 | 루트 |
