### 2-2-1 화면과 기기

CLIENT-US-001, CLIENT-US-003.

| 항목 | 조건 |
|---|---|
| 메인 탭 | 다섯 탭마다 화면 스택을 따로 둠. 탭을 오가도 각 탭의 하위 화면, 선택과 읽던 위치 유지 |
| 뒤로가기 | 화면 왼쪽 가장자리 밀기와 내비게이션 바의 뒤로 버튼으로 한 화면씩 복귀. 탭 루트에는 뒤로가기 없음 |
| 이탈 확인 | 떠나기 전에 확인이 필요하거나 떠날 수 없는 동안에만 가장자리 밀기를 끔. 그동안 떠나는 조작은 화면이 그린 버튼만 받음. 확인이 필요 없는 동안에는 가장자리 밀기를 그대로 둠. 화면 어디서나 미는 뒤로가기 제스처가 있으면 같은 규칙을 적용. 조건에 따라 켜고 끄는 구현이 되지 않으면 대상 화면에서 항상 끔. 대상 화면과 조건은 각 도메인 ([I-052](DECISIONS.md#i-052)) |
| 비적용 | Android의 기기 뒤로가기 버튼과 예측형 뒤로가기, 다른 탭 뒤로가기의 홈 이동, 홈에서 앱 종료 |
| 하단 탭 표시 | 다섯 탭 루트에서만 표시. 탭 루트 위에 쌓은 모든 하위 화면에서 숨김 ([I-042](DECISIONS.md#i-042)) |
| 조작 범위 | 모든 조작 요소의 터치 영역 44pt 이상. 탭 아이콘과 라벨은 한 조작이며 이름과 선택 상태를 한 번씩 낭독 |
| 기기와 방향 | iPhone 전용, 세로 고정. iPad의 iPhone 호환 모드 실행은 지원과 검증 대상 아님 |
| 레이아웃 | 내용과 조작 요소는 안전 영역 안. 상태 바, Dynamic Island(화면 위쪽 카메라 영역), 홈 표시기와 키보드에 가리지 않음. 배경은 화면 끝까지 |
| 시스템 모양 | 탭 바, 내비게이션 바, 시트와 알림창은 iOS 시스템 모양과 시스템 기본 전환 |
| 테마 | 시스템 설정, 라이트, 다크 중 선택. 기본은 시스템 설정. 기기에 저장해 다음 실행과 로그아웃 뒤에도 유지. 시트, 알림창과 토스트에도 같은 테마 |
| 글자 크기 | Dynamic Type(iOS의 시스템 글자 크기 설정) 전 단계, 접근성 크기 포함, 상한 없음. 글자를 고정 높이에 가두거나 잘라 내지 않음. 한 줄로 정한 자리만 말줄임 |
| 동작 줄이기 | 시스템 설정이 켜지면 장식 애니메이션 제거 |
| 구성 변경 | 테마와 글자 크기 변경에서 입력, 선택, 시트, 탭, 스크롤과 요청 상태 유지. 회전과 화면 재생성 규칙 비적용 |
| 프로세스 종료 | 시스템이 종료한 뒤 다시 열면 선택한 탭만 복원하고 각 탭은 루트에서 시작. 저장 완료 데이터와 보류 상태는 각 도메인 조건으로 복구. 저장 전 입력은 복구하지 않음 |
| 햅틱 | 길게 눌러 옵션 시트가 열리는 순간 한 번. 그 밖의 조작에 앱이 햅틱을 더하지 않음 |
| 문구 | 한국어만. Android 앱과 같은 문장 |
| 지원 범위 | 최소 iOS 버전과 빌드 기준은 [IOS 기반](../../platform/CLIENT/IOS/5-DEPLOYMENT.md)을 따름 |

### 2-2-2 외부 진입

CLIENT-US-004. 앱은 로그인한 회원 화면을 제공하고 게스트 체험을 앱에 추가하지 않는다.

| 진입 | 조건과 결과 |
|---|---|
| 전용 앱 열기 링크 | `manyak://manyak.app{경로}`만 앱 진입. 스토리 상세, 공지 목록과 공지 상세를 열고 그 밖의 경로는 홈. 수신자 비교 없음 |
| 다른 스킴과 호스트 | 앱 진입으로 해석하지 않고 현재 화면 유지 |
| 일반 https 링크 | 앱이 받지 않고 브라우저에서 열림. Universal Links(https 링크를 앱이 받는 Apple 방식)는 후속 결정 |
| 푸시 알림 탭 | 허용된 푸시 목적지를 열고 그 밖은 홈. 수신 회원이 현재 회원과 다르면 홈 ([NOTIFICATION 푸시와 계정 격리](../../spec/NOTIFICATION/CLIENT/2-2-REQUIREMENTS.md#2-2-4-푸시와-계정-격리)) |
| 로그인 전 진입 | 목적지를 보류하고 회원, 필수 동의와 프로필 확인 뒤 소비. 푸시는 로그인 뒤 수신자를 다시 비교 |
| 보류 대체와 폐기 | 소비 전 새 진입이 이전 진입을 대체. 세션 종료와 프로세스 종료에서 폐기 |
| 웹 배너와 앱 소개 링크 | 전용 앱 열기 링크로 iOS 앱을 엶. iOS 기기에서 배너를 보이는 조건과 앱이 없을 때의 대체는 WEB 세트의 후속 변경 ([I-053](DECISIONS.md#i-053)) |
