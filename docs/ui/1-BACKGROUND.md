### 1-1 범위

사용자는 스토리 탐색, 제작과 채팅 사이를 이동하면서 화면 위치와 입력을 유지하고, 서비스 이용 방법과 처리 결과를 일관되게 확인해야 한다.

| 공용 범위 | 도메인 경계 |
|---|---|
| 앱 셸, 내비게이션, 테마, 서비스 안내 | 계정과 동의는 ACCOUNT, 작품은 STORY, 플레이는 CHAT |
| 앱 안내 배너와 앱 공유 링크 | 알림 수신과 푸시 진입은 NOTIFICATION |
| 화면 상태와 접근성 | 비용과 결제는 PAYMENT, 신고는 MODERATION |

웹은 게스트와 회원을, Android 앱은 로그인한 회원을 대상으로 한다. 게스트 체험과 회원의 데이터 보존 조건은 ACCOUNT에서 정한다. 공용 화면을 이유로 도메인 권한과 입력 조건을 바꾸지 않는다.
