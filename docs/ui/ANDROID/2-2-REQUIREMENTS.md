# 2-2 요구사항: 안드로이드

### 2-2-1 화면과 기기

CLIENT-US-001, CLIENT-US-003.

| 항목 | 조건 |
|---|---|
| 메인 탭 | 각 탭의 선택과 읽던 위치 유지. 다른 탭 뒤로가기는 홈, 홈에서는 앱 밖 |
| 조작 범위 | 탭 아이콘과 라벨 및 주변 터치 영역은 같은 동작. 접근성 이름과 선택 상태는 중복 낭독하지 않음 |
| 레이아웃 | 헤더와 하단 탭 위치 고정, 폭을 제한한 한 열 스크롤. 시스템 바, 제스처와 3버튼 내비게이션 안전 영역 확보 |
| 구성 변경 | 회전과 테마 변경에서 입력, 선택, 다이얼로그, 탭, 스크롤과 요청 상태 보존 |
| 일시 UI | 옵션 시트는 유지, 팝오버는 닫음. 포커스와 키보드 및 장식 애니메이션의 재개는 보장하지 않음 |
| 프로세스 재생성 | 식별자로 다시 조회하고 저장 완료 데이터와 보류 상태 복구. 저장 전 입력 전체의 복구는 보장하지 않음 |
| 문서와 뷰어 | 문서 읽던 위치 유지. 열린 이미지 URL은 회전에 유지하지만 프로세스 재생성에는 복구하지 않음. 확대와 이동은 회전 또는 닫기에 초기화 |
| 지원 범위 | OS와 빌드 기준은 현재 빌드 설정에 따름. 전체 글자 확대 및 접근성의 미확정 범위를 임의로 추가하지 않음 |

<br>

### 2-2-2 서비스 안내와 외부 진입

CLIENT-US-002, CLIENT-US-004. 서비스 안내에는 공통 본문과 웹 전용 게스트 이용 안내를 표시한다. 앱은 로그인한 회원 화면을 제공하고 게스트 체험을 앱에 추가하지 않는다.

웹 배너의 전용 스킴으로 같은 스토리 또는 홈을 연다. 공지 목록과 상세도 허용된 경로로 처리하며 다른 경로는 홈으로 간다. 일반 https 링크는 브라우저에서 열고 앱이 가로채지 않는다. 전용 앱 진입은 로그인 뒤 진행하며 푸시 수신자와 같은 계정 비교를 적용하지 않는다.
