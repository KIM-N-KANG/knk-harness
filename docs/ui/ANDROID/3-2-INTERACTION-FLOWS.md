### 3-2-1 탭과 화면 복귀

| 조작 | 결과 |
|---|---|
| 탭 전환 | 해당 탭의 상태와 스크롤 유지 |
| 메인 탭 뒤로 | 홈이 아니면 홈, 홈이면 앱 밖. 방문 탭을 역순으로 순회하지 않음 |
| 상세 위 채팅 시작 | 채팅 뒤로가기는 상세, 다시 뒤로가기는 상세 진입 탭 |
| 상세 삭제 | 상세를 걷어내고 제작 탭으로 복귀 |
| 옵션에서 삭제 또는 신고 | 옵션 시트를 닫고 다음 확인이나 신고 시트 표시 |
| 열린 오버레이 뒤로 | 최상위만 닫고 잠금 중이면 유지 |

도메인별 화면 종료와 저장 조건은 각 도메인 흐름을 따른다. UI 재구성 때문에 화면 이동이나 데이터 요청을 다시 실행하지 않는다.

<br>

### 3-2-2 앱 링크

전용 링크를 받으면 회원과 프로필을 확인한다. 로그인 전에는 목적지를 보류하고 로그인 뒤 해당 화면을 연다. 스토리는 같은 스토리, 공지는 목록 또는 목록 위 상세, 허용되지 않은 경로는 홈이다. 푸시 수신자 검증과 앱 링크의 진입을 구분한다.
