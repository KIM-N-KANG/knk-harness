### 3-3-1 테마와 상태

| 상태 | 표현 |
|---|---|
| 테마 | 시스템 설정은 모니터, 라이트는 해, 다크는 달 아이콘. 오른쪽 현재 선택 문구도 함께 변경 |
| 최초 로딩 | 지연 전 빈 영역, 지연 후 해당 화면의 로딩 표시 |
| 요청 버튼 | 비활성, 기존 문구 공간의 중앙 스피너. 접근 가능한 이름 유지 |
| 목록 실패 | 재시도 가능한 오류 안내 |
| 변경 요청 실패 | 실패 토스트 |
| 라우트 또는 렌더 오류 | “문제가 발생했어요”와 재시도 |
| 없는 경로 | “페이지를 찾을 수 없어요”와 홈 링크 |

<br>

### 3-3-2 서비스 안내

서비스 안내 제목 아래에 게스트 이용 안내, AI 콘텐츠 안내와 문의를 둔다. 게스트 이용 안내에는 “웹 브라우저에서 이용할 때만 적용돼요”를 표시하고 다음 내용을 사용한다.

- 로그인 없이도 스토리를 둘러볼 수 있어요. 게스트 이용 안내에 동의하면 체험 한도 안에서 스토리를 만들고 채팅할 수 있어요. 한도를 모두 사용하면 로그인이 필요해요.
- 게스트로 만든 스토리와 채팅은 이 브라우저에 연결돼요. 브라우저 데이터를 지우거나 기기를 바꾸면 다시 불러오기 어려울 수 있어요.
- 처음 로그인한 뒤 회원 필수 동의를 마치면 이 브라우저의 스토리와 채팅을 계정으로 옮겨요. 이관은 계정마다 한 번만 제공해요.

문의는 “서비스 개선 의견은 마이 > 피드백에서 보내주세요.”라는 링크 없는 텍스트다. 이프 수치 고지와 별도 “이프 안내” 제목은 두지 않는다.
