# 2-2 요구사항

기준: [사용자 목표](2-1-USER-STORY.md).

<br>

### 2-2-1 적용 범위

| 항목 | 공통 | 웹 | Android | iOS |
|---|---|---|---|---|
| CLIENT-US-001 | 홈, 채팅, 제작, 탐색, 마이 다섯 탭과 현재 선택 표시. 탐색은 다른 탭에서 들어올 때 새 순서로 맨 위부터 보임 ([STORY 탐색과 제작 목록](../spec/STORY/CLIENT/2-2-REQUIREMENTS.md#2-2-2-탐색과-제작-목록)) | 탭 이동은 기록 교체, 문서 수명 안에서 스크롤 복원 | 탭별 상태 유지, 다른 탭 뒤로가기는 홈, 홈에서는 앱 밖 | 탭별 화면 스택과 상태 유지, 탭 루트에는 뒤로가기 없음. 시스템이 앱을 종료한 뒤의 실행에서만 선택 탭 복원 |
| CLIENT-US-003 | 시스템 설정이 기본, 사용자가 선택한 테마를 기기에 보존하고 즉시 적용 | 브라우저별 저장 | 앱 기기별 저장 | 앱 기기별 저장 |
| CLIENT-US-004 | 웹에서 앱 또는 설치 안내로 연결 | 기기와 방문 횟수에 따라 배너, 앱 소개 링크 제공 | 전용 앱 열기 링크를 받고 로그인 이후 목적지 진입 | 전용 앱 열기 링크를 받고 로그인 이후 목적지 진입. 웹 배너와 앱 소개 링크는 같은 전용 링크로 iOS 앱을 엶 |

### 2-2-2 이동과 화면 상태

| 조건 | 요구사항 |
|---|---|
| 오버레이 뒤로가기 | 시트, 다이얼로그, 전체 이미지, 안내 중 최상위 하나만 닫음. 드롭다운과 팝오버 및 선택 메뉴는 이 규칙의 대상이 아님 |
| 처리 중 잠금 | 전송이나 삭제 등 잠금 상태에서는 뒤로가기로 닫지 않음. 취소 의미가 있는 기능은 해당 도메인 조건 적용 |
| 자동 표시 웹 오버레이 | 사용자가 열지 않은 안내는 별도 뒤로가기 기록을 만들지 않으며 뒤로가기로 화면을 떠남 |
| 최초 조회 | 빠른 응답에서 로딩 표시가 깜빡이지 않도록 지연. 지연 전에는 표시하지 않음 |
| 빈 상태 | 정상 조회가 성공하고 결과가 없을 때만 표시 |
| 조회 실패 | 최초 실패는 오류와 재시도, 추가 실패는 기존 목록과 수동 재시도 유지 |
| 요청 버튼 | 중복 실행을 막고 기존 문구 공간과 접근 가능한 이름 유지 |
| 입력 오류 | 해당 필드 가까이 표시하고 필드와 연결. 폼 또는 요청 전체의 실패는 토스트 |
| 오류 노출 | 서버 원본 메시지와 스택을 사용자에게 그대로 보여주지 않음 |
| 데이터 보호 | 자유 입력 원문과 토큰을 로그나 분석 이벤트에 넣지 않음 |

인증과 세션 종료는 [ACCOUNT 요구사항](../spec/ACCOUNT/CLIENT/2-2-REQUIREMENTS.md)을 따른다. 목록 재시도 횟수와 자동 재조회는 플랫폼별 조건이며 웹의 기본값을 Android와 iOS에 적용하지 않는다.

<br>

### 2-2-3 접근성

조작 요소에는 접근 가능한 이름을 제공하고 상태를 색상만으로 구별하지 않는다. 웹의 키보드 조작, 화면 크기와 모션 조건, Android의 시스템 바와 구성 변경 및 iOS의 안전 영역과 VoiceOver는 각 플랫폼의 적용 조건 안에서 구체화한다. 웹과 Android에는 확정하지 않은 전체 글자 확대 지원 범위를 추가하지 않는다. iOS는 시스템 글자 크기(Dynamic Type)의 접근성 크기를 포함한 전 단계를 지원한다.
